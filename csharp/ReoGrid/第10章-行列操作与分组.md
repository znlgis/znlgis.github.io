# 第十章：行列操作与分组

表格里的内容常常是分层的：季度报表下面挂三个月，一年的数据下面挂十二个月。把这些行列收起来、需要时再展开，就是分组（也叫大纲）。这一章讲两件事：怎么按区域创建分组，怎么控制分组的大纲层级。

分组只影响显示，不影响数据。折叠起来的行仍在工作表里，公式、汇总、导出都会把它们算进去。把分组当成折叠文件夹，而不是删除，可以避免很多误解。

## 10.1 行列分组

GroupRows 与 GroupColumns 接收起止下标，把一段连续行列归入同一组。示例分别封装了行分组和列分组，参数是起始与结束位置，包含两端。区域内部的每一行都成为同组的成员，界面上出现一个可以点击的折叠按钮。

分组的粒度是整行或整列，不能只对某几列的部分行分组。需要更细的层次时，可以嵌套：外层分一段大区间，内层在区间里再分小节。嵌套层数不宜过多，超过三层后用户很难记住自己在哪一层。

折叠与展开用 CollapseGroup 与 ExpandGroup，参数是一个位置，用来指明要操作哪一个分组。示例把它包装成带布尔开关的 ToggleGroup，调用方按需要传 true 或 false。

```csharp
public class RowColumnGrouping
{
    private Worksheet sheet;
    
    // 创建行分组
    public void CreateRowGroup(int startRow, int endRow)
    {
        sheet.GroupRows(startRow, endRow);
    }
    
    // 创建列分组
    public void CreateColumnGroup(int startCol, int endCol)
    {
        sheet.GroupColumns(startCol, endCol);
    }
    
    // 展开/折叠分组
    public void ToggleGroup(int row, int col, bool expand)
    {
        if (expand)
            sheet.ExpandGroup(row, col);
        else
            sheet.CollapseGroup(row, col);
    }
}
```

分组是按区域创建的，但展开与折叠是按组操作的。同一区域重复调用 GroupRows 通常不会叠加出两个组，是否合并取决于实现；需要多层结构时，应明确使用大纲层级，而不是反复分组同一段。

折叠后的行高通常变为零或不显示，行号仍然连续，用户可以看到「这里有一段被收起」。展开后恢复原来的行高，行高值本身没有丢失。

分组与排序、筛选会互相影响。先分组再排序，组的位置可能不再连续；有分组时改动行列结构，插入的行不一定自动并入相邻分组。批量改结构前先把分组展开，改完再重新组织。

## 10.2 大纲视图

大纲层级决定折叠按钮的缩进与层数。SetRowOutlineLevel 给某一行设置层级，1 是最外层，数字越大越靠内。设置层级之后，控件按层级绘制左侧的加减号，用户可以逐级展开。

层级是逐行设置的，示例只处理一行，实际使用时通常循环一段区域，按业务结构给每行分配层级。小的汇总行设为 1 级，明细行设为 2 级，需要更细时继续加层。

大纲视图与分组共用同一套折叠机制。用大纲层级组织出来的结构，本质上就是一组嵌套的折叠区域，区别在于层级是按行标注的，而分组是按区域一次性创建的。

```csharp
public class OutlineView
{
    public void SetOutlineLevel(Worksheet sheet, int row, int level)
    {
        sheet.SetRowOutlineLevel(row, level);
    }
}
```

层级设置完要检查折叠按钮的位置是否符合预期。层级写错时会得到「折叠了不该折叠的行」或者「按钮全部在最外层」的效果，这类问题从界面上看很直观，把层级打印出来对照业务结构更快。

大纲层级不会自动根据内容推断。程序不会因为某行是「小计」就把它设成层级 1，需要业务代码自己判断并设置。判断逻辑通常来自数据里的类型字段，或者固定的行模板。

## 10.3 本章小结

本章介绍了行列分组和大纲功能。

分组与大纲解决的是一件事：让长表按结构折叠。使用时记住几点：

- 分组按区域创建，参数是起止下标，包含两端；
- 折叠与展开按组操作，一次只作用于一个分组；
- 大纲层级按行标注，1 是最外层，适合做多层嵌套；
- 折叠只影响显示，数据、公式、导出都不受影响。

设计分组结构时，先想清楚用户需要看到哪一层。季度报表默认展开季度、收起月份，年度报表默认全部收起只留合计，这类默认状态比功能本身更影响体验。

分组状态不随文件保存，重新打开后需要重新应用。把它写进初始化流程，和冻结窗格、列宽一起设置，用户拿到的就是排好版的表格。
