# 第十三章：打印与页面设置

屏幕上的表格和纸上的表格是两回事：纸有固定尺寸，超出部分会被分页切开，颜色和边框在黑白打印机上也会变样。这一章讲怎么把工作表打印出来，以及打印前要设置的页面参数。

打印涉及三层设置：打印动作（直接打印、预览）、页面设置（方向、纸张、页边距、缩放）、页眉页脚。三层都建立在工作表对象上，因此不同工作表可以有不同的打印配置，一份工作簿里可以既有纵向的明细表，也有横向的汇总表。

## 13.1 打印基础

打印有三个入口：直接打印当前工作表、打开打印预览、以及工作表级的打印。直接打印会使用系统默认打印机和当前页面设置，用户看不到中间过程，适合确定结果的批量输出。

打印预览是给用户看的。预览窗口里能看到分页位置、页边距效果和页眉页脚，用户可以在这里返回去调列宽或缩放，不必真的打一张出来才发现问题。界面上通常把预览作为打印按钮的默认动作。

工作表级的 sheet.Print 只打印该表，不受其他工作表影响。多表打印要么逐张调用，要么走工作簿级接口，具体支持情况看版本。

```csharp
public class PrintingBasics
{
    private ReoGridControl grid;
    
    // 直接打印
    public void Print()
    {
        grid.Print();
    }
    
    // 打印预览
    public void PrintPreview()
    {
        grid.PrintPreview();
    }
    
    // 打印特定工作表
    public void PrintWorksheet(Worksheet sheet)
    {
        sheet.Print();
    }
}
```

打印失败最常见的原因是环境问题：没有安装打印机、默认打印机离线、驱动异常。这些异常会从打印调用里抛出来，捕获后给用户一句明确的提示，比静默失败好排查。


打印是同步阻塞操作，数据量大或打印机响应慢时界面会卡住。批量打印时应当在后台执行并给出进度，避免用户误以为程序无响应。

## 13.2 页面设置

页面设置通过 sheet.PrintSettings 访问，示例依次配置方向、纸张、页边距和缩放。这些设置属于工作表，改的是这一张表的打印行为。

方向与纸张要匹配数据形状：列多行少用横向，行多列少用纵向。纸张尺寸用枚举指定，A4 是最常用的；如果有固定模板要求 B5 或 Letter，就在这里换。

页边距的四个数字分别控制左、右、上、下留白。装订或打孔的场景左侧要留宽一些，页眉页脚占用的空间也在这部分里，边距设得过小会导致页眉被裁掉。

```csharp
using unvell.ReoGrid.Print;

public class PageSetup
{
    public void ConfigurePageSettings(Worksheet sheet)
    {
        var settings = sheet.PrintSettings;
        
        // 页面方向
        settings.PageOrientation = PrintPageOrientation.Portrait;  // 纵向
        // settings.PageOrientation = PrintPageOrientation.Landscape;  // 横向
        
        // 页面大小
        settings.PaperSize = PrintPaperSize.A4;
        
        // 页边距
        settings.Margins = new PrintMargins
        {
            Left = 20,
            Right = 20,
            Top = 25,
            Bottom = 25
        };
        
        // 缩放
        settings.ScalingMode = PrintScalingMode.FitToPages;
        settings.FitToPages = new System.Drawing.Size(1, 1);  // 适应1页
    }
}
```

缩放模式决定内容怎么塞进纸张。FitToPages 表示按页数缩放，示例设成 1×1，把整张表缩到一页；代价是缩放比例过小时字会很小。数据确实放不下时，宁可分成两页，也不要把字号压到看不清。

页边距的数值单位随版本不同，可能是毫米，也可能是百分之一英寸。示例里的 20、25 不能凭直觉当毫米用，先在预览里看一眼实际留白，再决定要不要调。

页面设置改完不会自动重新分页，需要重新预览或打印才生效。做「适应一页」的调整时，按「改设置 → 预览 → 再改」的循环走，比一次设很多参数再验证更高效。

## 13.3 页眉页脚

页眉页脚用占位符拼字符串，写法沿用 Excel 的习惯：&D 是日期，&T 是时间，&P 是当前页码，&N 是总页数。示例的「&P / &N」会渲染成「1 / 3」这样的形式。

页眉分左中右三个位置，页脚同样。位置由字段名决定：LeftText 靠左、CenterText 居中、RightText 靠右，三个位置可以同时使用，也可以留空。

占位符之外的内容按原样输出，中文、空格、标点都可以。想让某些文字加粗或换字号，是否支持还要看版本对格式化代码的实现，不支持的代码会原样打印出来，上线前预览确认。

```csharp
public class HeaderFooter
{
    public void SetHeaderFooter(Worksheet sheet)
    {
        var settings = sheet.PrintSettings;
        
        // 页眉
        settings.Header.LeftText = "&D";  // 日期
        settings.Header.CenterText = "销售报表";
        settings.Header.RightText = "&P / &N";  // 页码 / 总页数
        
        // 页脚
        settings.Footer.LeftText = "公司名称";
        settings.Footer.CenterText = "";
        settings.Footer.RightText = "&T";  // 时间
    }
}
```

页码类占位符只在分页后才有意义。整表单页打印时 &P 和 &N 都会显示 1，看起来像没有生效，其实是只有一页。测试页眉页脚用一张会分成多页的表，才能看出区别。

页眉页脚里不要放太长内容。位置宽度有限，文字过长会被截断，而且不同打印机对页边距的解释略有差异，在 A 机器上刚好放下的内容，换台机器可能就挤出边界。

## 13.4 本章小结

本章介绍了打印和页面设置功能。

打印链路可以拆成四段来记：

- 动作：Print 直接输出，PrintPreview 先看效果；
- 页面：方向、纸张、页边距决定纸面布局；
- 缩放：FitToPages 把内容压进指定页数，注意可读性；
- 页眉页脚：用 &D、&T、&P、&N 这类占位符拼内容。

打印质量主要取决于打印前的准备，而不是打印动作本身。列宽是否够、分页是否落在合理位置、表头是否在每页重复，这些在预览里都能看到，也都能在没有浪费纸的情况下改好。

如果表格需要多页打印，考虑把标题行设为重复打印。ReoGrid 是否提供「顶端标题行」这类设置随版本而异，没有的话退而求其次：把表头做进页眉，或者在每页手工插入表头行。
