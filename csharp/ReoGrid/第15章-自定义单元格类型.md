# 第十五章：自定义单元格类型

普通单元格只能显示文本和数字。要在表格里放按钮、复选框、下拉框、进度条，就要用单元格类型（CellBody）。它接管一个单元格的绘制和鼠标响应，看上去像嵌进表格里的小控件。

单元格类型与样式是两套机制。样式改的是字体颜色边框，单元格类型决定这个格子怎么画、怎么响应点击。一个单元格可以既有样式又有类型，类型绘制时能从 Cell.Style 取到字体等属性。

## 15.1 自定义单元格类型基础

ReoGrid允许创建自定义的单元格类型，实现特殊的显示和交互。

自定义类型继承 CellBody，重写需要的方法。OnPaint 负责绘制，参数里有绘图上下文，通过它拿到绘图对象和单元格区域；OnMouseDown 这类方法负责响应鼠标，返回布尔值表示事件是否被消费。

重写绘制方法时通常先调用基类的实现，把默认的文本和背景画出来，再叠上自己的图形。完全自己画也可以，但要注意选中状态、背景色、边框这些默认视觉元素，否则格子看起来和周围不一致。

自定义类型可以通过 SetCellBody 挂到单元格上，也可以挂到区域。示例只演示了单个格子的挂法，按区域挂载时同一个实例会服务多个格子，实例内部不要缓存某个具体单元格的引用。

```csharp
using unvell.ReoGrid.CellTypes;

public class CustomCellType : CellBody
{
    public override void OnPaint(CellDrawingContext dc)
    {
        // 自定义绘制逻辑
        base.OnPaint(dc);
    }
    
    public override bool OnMouseDown(CellMouseEventArgs e)
    {
        // 自定义鼠标事件处理
        return base.OnMouseDown(e);
    }
}
```

CellBody 的生命周期比想象中长。它跟着单元格存在，直到被替换或工作表销毁；初始化时不要做重活，绘制方法里也不要每次 new 画笔、字体这类 GDI 对象，否则滚动时会频繁分配、频繁回收，界面会明显变慢。

绘图坐标的基准是单元格区域。上下文里给出的矩形随滚动变化，绘制内容要限制在这个矩形内，超出部分可能画到相邻格子上。需要裁剪时用上下文的裁剪功能，别自己算偏移。

状态变化后要请求重绘。修改了自定义类型内部的数值，不通知控件刷新的话，界面上还是旧的样子。示例的进度条在 Progress 的 setter 里调了 RequestInvalidate，就是做这件事。

## 15.2 内置单元格类型

ReoGrid 自带几种常用类型，不用从零实现。ButtonCell 显示一个按钮，Click 事件里写响应；CheckBoxCell 是带勾选框的格子，CheckChanged 事件里读 IsChecked；DropdownListCell 是下拉候选，构造时把选项一次传进去。

这几种类型的行为与普通控件相近，但值仍然存在单元格里。复选框勾选后，单元格的 Data 通常是布尔值，读数据时按 bool 取；按钮类型没有值，只是触发动作。用之前想清楚数据要不要跟着变。

示例把它们挂在前几行的第一列，实际使用时按列语义排布：状态列放复选框，操作列放按钮，分类列放下拉。同一列统一用一种类型，视觉和交互都更清楚。

```csharp
public class BuiltInCellTypes
{
    public void UseBuiltInTypes(Worksheet sheet)
    {
        // 按钮单元格
        var buttonCell = new ButtonCell("Click Me");
        buttonCell.Click += (s, e) =>
        {
            MessageBox.Show("按钮被点击");
        };
        sheet.SetCellBody(0, 0, buttonCell);
        
        // 复选框单元格
        var checkBoxCell = new CheckBoxCell();
        checkBoxCell.CheckChanged += (s, e) =>
        {
            Console.WriteLine($"复选框状态: {checkBoxCell.IsChecked}");
        };
        sheet.SetCellBody(1, 0, checkBoxCell);
        
        // 下拉列表单元格
        var comboBoxCell = new DropdownListCell("选项1", "选项2", "选项3");
        sheet.SetCellBody(2, 0, comboBoxCell);
    }
}
```

内置类型的构造参数比较固定：按钮传显示文本，下拉传候选字符串，复选框不带参数。事件回调里不要直接改其它单元格的结构（插行、删行），容易在绘制过程中触发重入，改成投递到消息循环里延后执行更稳。

按钮点击后通常要做业务动作，动作里可能弹窗、保存、跳转。这些操作会打断控件的输入状态，必要时先调用控件的结束编辑，把当前未提交的输入落盘，再做后续处理。

复选框的状态事件里不宜做重计算。用户连续点击多个复选框时事件会密集触发，把汇总逻辑合并到空闲时执行，体验更好。

## 15.3 图像单元格

ImageCell 把一张图片画进单元格。构造时传入 Image 对象，示例从文件加载。图片会按单元格区域缩放，原始尺寸与格子比例不一致时会变形，需要保持比例的话在类型内部自己算缩放。

从文件加载的 Image 持有系统资源，不再使用时应当释放。单元格类型被替换或工作表销毁时，把图片 Dispose 掉，否则反复加载会累积句柄，长时间运行后可能出现 GDI 资源耗尽。

图片较多时不要每格都从磁盘读一次。缓存 Image 实例按需复用，或者用统一尺寸的缩略图，既省内存也省加载时间。

```csharp
public class ImageCellType
{
    public void UseImageCell(Worksheet sheet, string imagePath)
    {
        var imageCell = new ImageCell(Image.FromFile(imagePath));
        sheet.SetCellBody(0, 0, imageCell);
    }
}
```

图像单元格适合放图标、缩略图、状态标识。列宽行高有限，图片细节太多会看不清，用小尺寸的图标或简化的色块，比放截图更合适。

图片路径来自用户或配置时要做校验。文件不存在、格式不支持都会在加载时抛异常，捕获后显示一个占位图，比让整张表加载失败要好。

## 15.4 自定义进度条单元格

进度条例子的结构值得拆开看：一个内部字段保存进度，属性里做范围钳制并触发重绘，绘制方法先铺背景条，再按比例画前景条，最后把百分比文字画在中间。

绘制时用的是单元格的矩形，进度条的宽度等于矩形宽度乘以进度值。矩形随滚动和列宽变化，每次绘制都重新计算，不缓存坐标。

文字叠在色条上要保证可读性。示例直接用黑色字，进度条颜色偏深时看不清；做法是条短时画在条外，条长时按对比色切换，或者给文字加半透明底色。

```csharp
public class ProgressBarCell : CellBody
{
    private float progress = 0;
    
    public float Progress
    {
        get => progress;
        set
        {
            progress = Math.Max(0, Math.Min(1, value));
            this.Cell?.Worksheet?.RequestInvalidate();
        }
    }
    
    public override void OnPaint(CellDrawingContext dc)
    {
        var bounds = this.Cell.Bounds;
        
        // 绘制背景
        dc.Graphics.FillRectangle(new SolidBrush(Color.LightGray), bounds);
        
        // 绘制进度
        var progressWidth = bounds.Width * progress;
        dc.Graphics.FillRectangle(
            new SolidBrush(Color.Green),
            bounds.X, bounds.Y, progressWidth, bounds.Height
        );
        
        // 绘制文本
        var text = $"{(progress * 100):F0}%";
        dc.Graphics.DrawString(text, this.Cell.Style.Font, Brushes.Black, bounds);
    }
}

// 使用示例
public class UseProgressBar
{
    public void Example(Worksheet sheet)
    {
        var progressCell = new ProgressBarCell { Progress = 0.75f };
        sheet.SetCellBody(0, 0, progressCell);
    }
}
```

进度值钳制在 0 到 1 之间，越界时截断而不是抛异常。外部数据不可靠，负数或超过 100% 的情况都可能有，截断能保证界面不出现荒谬的图形。

每次改进度都会触发一次重绘。批量更新很多行的进度时，逐行触发会让界面持续刷新，用挂起重绘的方式合并成一次刷新，滚动会顺很多。

进度条适合表达单个任务的完成度。整列都是进度条时，考虑加个汇总行显示整体进度，用户不需要自己看平均。

## 15.5 本章小结

本章介绍了自定义单元格类型的创建和使用。

单元格类型的关键点汇总如下：

- 继承 CellBody，重写 OnPaint 绘制、重写鼠标方法响应交互；
- 挂载用 SetCellBody，一个实例可以服务多格，内部不要缓存具体单元格；
- 状态变化后请求重绘，否则界面停留在旧状态；
- 绘图对象不要每次创建，GDI 资源用完要释放；
- 内置的按钮、复选框、下拉、图像类型优先直接用，不够再自己写。

自定义类型适合「一格里要放一个小控件」的场景。如果只是改显示效果，用样式或条件格式就够了，不必引入类型；如果整个页面都是控件，用普通 WinForms/WPF 控件叠在表格上反而更简单。
