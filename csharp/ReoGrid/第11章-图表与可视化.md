# 第十一章：图表与可视化

数字列读起来慢，图形一眼就能看出趋势。ReoGrid 内建了几种常用图表，直接绑定工作表的区域，单元格数据变化后图表跟着刷新。这一章讲三件事：怎么创建图表、数据源怎么指定、创建后怎么配置标题图例与坐标轴。

图表在 ReoGrid 里属于浮动对象，和单元格不在同一层。它悬浮在工作表之上，有独立的位置和尺寸，可以拖动、可以叠在数据旁边。理解这一点，就不会在单元格样式里找图表的配置。

图表的数据来自区域引用，不是数据副本。改单元格的值，图表重绘后显示新值；改区域范围，要重新指定数据源。这类刷新依赖控件的重绘时机，不是每次赋值都立刻可见。

## 11.1 创建图表

创建图表的步骤固定：选图表类型、给位置和尺寸、指定数据源、加入浮动对象集合。示例用对象初始化器一次写完这四个部分，可读性比逐行赋值好。

Location 与 Size 决定图表放在哪、多大。坐标以工作表左上角为原点，单位是像素；示例把图表放在 (360, 20)，尺寸 360×220，通常放在数据区域的右侧，避免遮挡数据。

ColumnChart 是柱状图，LineChart 是折线图，PieChart 是饼图。三者创建方式一致，差别在图形本身的适用场景：柱状图比大小，折线图看趋势，饼图看占比。选错图表类型比配色不当更影响阅读。

```csharp
using unvell.ReoGrid.Chart;
using unvell.ReoGrid.Graphics;

public class ChartCreation
{
    public void CreateColumnChart(Worksheet sheet)
    {
        // 创建柱状图：B2:C10 为数值区，A2:A10 为行标题，B1:C1 为列标题
        var chart = new ColumnChart
        {
            Location = new Point(360, 20),
            Size = new Size(360, 220),
            Title = "销售数据",
            DataSource = new WorksheetChartDataSource(
                sheet, sheet.Ranges["A2:A10"], sheet.Ranges["B2:C10"])
            {
                CategoryNameRange = sheet.Ranges["B1:C1"],
            },
        };
        sheet.FloatingObjects.Add(chart);
    }
    
    public void CreateLineChart(Worksheet sheet)
    {
        // 创建折线图：B2:B20 为数值区，A2:A20 为行标题
        var chart = new LineChart
        {
            Location = new Point(360, 20),
            Size = new Size(360, 220),
            DataSource = new WorksheetChartDataSource(
                sheet, sheet.Ranges["A2:A20"], sheet.Ranges["B2:B20"]),
        };
        sheet.FloatingObjects.Add(chart);
    }
    
    public void CreatePieChart(Worksheet sheet)
    {
        // 创建饼图：B2:B5 为数值区，A2:A5 为分类名
        var chart = new PieChart
        {
            Location = new Point(360, 20),
            Size = new Size(360, 220),
            DataSource = new WorksheetChartDataSource(
                sheet, sheet.Ranges["A2:A5"], sheet.Ranges["B2:B5"]),
        };
        sheet.FloatingObjects.Add(chart);
    }
}
```

数据源用 WorksheetChartDataSource 构造，参数包括工作表、行标题区域、数值区域。示例里第一个区域给的是 A2:A10 这类标签列，第二个区域是 B2:C10 这类数值块，再通过 CategoryNameRange 指定列标题。

行列标题与数值区的关系容易搞反。判断标准很简单：数值区的行列数要能和标题区的长度对上，对不上时图表仍能画出来，但图例会缺项或者分类全变成序号。出图后先看图例和横轴标签，比对着代码猜更快。

饼图只需要一组数值，所以示例给的数值区是单列 B2:B5，分类名来自 A2:A5。给饼图传多列数值时，通常只画第一条系列，其余被忽略，具体行为以当前版本为准。

## 11.2 图表配置

图表创建后通过属性调整外观。Title 是图表标题，TitleFont 控制字体、字号与是否加粗；Legend.Visible 控制图例显示，Legend.Position 决定图例放在左、右、上、下哪一侧；PrimaryAxisX 与 PrimaryAxisY 的 Title 分别是横轴与纵轴的标题。

坐标轴标题要带单位。示例把纵轴写成「销售额(万元)」，读者不用回头查表就知道数量级。横轴写「月份」，比写「分类」更具体。

图例在系列少的时候可以省略，直接标在图形上更直观；系列超过三四个时，图例比标注更清晰。位置按图表形状选：宽扁的图把图例放右侧，方正的图放底部。

```csharp
public class ChartConfiguration
{
    public void ConfigureChart(Chart chart)
    {
        // 设置标题
        chart.Title = "月度销售趋势";
        chart.TitleFont = new Font("微软雅黑", 14, FontStyle.Bold);
        
        // 设置图例
        chart.Legend.Visible = true;
        chart.Legend.Position = LegendPosition.Right;
        
        // 设置坐标轴
        chart.PrimaryAxisX.Title = "月份";
        chart.PrimaryAxisY.Title = "销售额(万元)";
    }
}
```

配置改完需要重绘才可见。批量修改多个属性时，先在本地算好再一次性赋值，比逐个属性触发重绘更省资源；控件是否提供挂起重绘的入口取决于版本，找不到时接受一次重绘也可以。

图表与数据区域是弱关联。删除数据行不会自动删除图表，图表继续引用原区域，可能显示空白或错位；反过来先把图表删掉再改数据，能避免中间状态报错。

## 11.3 本章小结

本章介绍了图表创建和配置功能。

把创建流程压缩成四步：选类型、定位置、绑数据、加进浮动对象。配置则围绕标题、图例、坐标轴三项展开。

实践中有几点值得注意：

- 图表是浮动对象，位置尺寸以像素计，和数据单元格不在同一层；
- 数据源是区域引用，改值会刷新、改区域要重新指定；
- 行标题、列标题、数值区三者要对得上，否则图例或分类会错；
- 图表不会随数据删除自动清理，删数据前先处理图表。

图表的价值在「一眼看懂」。同一个数据块，用柱状图看各月高低、用折线图看全年走势、用饼图看结构占比，选型对了，装饰少一点也清楚。
