## 13.6 符号映射

### 13.6.1 映射文件格式

```xml
<SymbolMap version="1.0">
  <Mappings>
    <Type original="MyApp.CustomerManager" obfuscated="A" />
    <Method original="ProcessPayment" obfuscated="a" />
  </Mappings>
</SymbolMap>
```

### 13.6.2 映射工具

```bash
# 使用映射还原堆栈跟踪
dotNET_Reactor.SymbolMapper.exe \
    -map symbol_map.xml \
    -stacktrace error.log \
    -output resolved.log
```
