# 第03章：用户界面详解

## 3.1 主界面概览

.NET Reactor 提供了直观友好的图形用户界面（GUI），使得代码保护工作变得简单高效。本章将详细介绍界面的各个组成部分及其功能。

### 3.1.1 界面布局

主界面采用经典的 IDE 布局风格：

```
┌─────────────────────────────────────────────────────────────┐
│  菜单栏 (Menu Bar)                                           │
├─────────────────────────────────────────────────────────────┤
│  工具栏 (Toolbar)                                            │
├──────────────────┬──────────────────────────────────────────┤
│                  │                                          │
│  导航面板        │  主工作区                                 │
│  (Navigation)    │  (Main Workspace)                        │
│                  │                                          │
│  - Input Files   │  ┌────────────────────────────────┐    │
│  - Settings      │  │  文件列表 / 设置面板             │    │
│  - Protection    │  │                                │    │
│  - Licensing     │  │                                │    │
│  - Advanced      │  │                                │    │
│                  │  └────────────────────────────────┘    │
│                  │                                          │
├──────────────────┴──────────────────────────────────────────┤
│  状态栏 (Status Bar)                                         │
│  Ready | Licensed to: XXX | Version: 6.9.0.0                │
└─────────────────────────────────────────────────────────────┘
```

### 3.1.2 界面主题

.NET Reactor 支持多种界面主题：

1. **浅色主题（Light Theme）**
   - 默认主题
   - 适合明亮环境
   - 高对比度

2. **深色主题（Dark Theme）**
   - 适合暗光环境
   - 减少眼睛疲劳
   - 现代感更强

**切换主题：**
```
Tools → Options → Appearance → Theme
选择：Light / Dark / System Default
```

### 3.1.3 快捷键

掌握快捷键可以大大提高工作效率：

| 功能 | 快捷键 | 说明 |
|------|--------|------|
| 打开文件 | Ctrl+O | 添加要保护的程序集 |
| 保存项目 | Ctrl+S | 保存当前项目配置 |
| 开始保护 | F5 | 开始保护程序集 |
| 停止保护 | Shift+F5 | 停止正在进行的保护 |
| 项目设置 | Ctrl+P | 打开项目设置 |
| 混淆设置 | Ctrl+B | 打开混淆设置 |
| 许可证设置 | Ctrl+L | 打开许可证设置 |
| 查找 | Ctrl+F | 在日志中查找 |
| 帮助 | F1 | 打开帮助文档 |
| 关闭 | Alt+F4 | 关闭程序 |

## 3.2 菜单栏详解

### 3.2.1 File 菜单

**New Project（新建项目）**
```
快捷键：Ctrl+N
功能：创建新的保护项目
用途：开始一个新的程序集保护任务
```

**Open Project（打开项目）**
```
快捷键：Ctrl+O
功能：打开已保存的项目文件（.nrproj）
格式：XML 格式的项目配置文件
```

**Save Project（保存项目）**
```
快捷键：Ctrl+S
功能：保存当前项目配置
推荐：定期保存，便于重复使用相同配置
```

**Save Project As（另存项目）**
```
快捷键：Ctrl+Shift+S
功能：将项目保存为新文件
用途：创建项目模板或备份
```

**Recent Projects（最近项目）**
```
功能：显示最近打开的项目列表
快速访问：点击即可快速打开
数量限制：默认显示最近 10 个项目
```

**Import Settings（导入设置）**
```
功能：从其他项目或配置文件导入设置
支持格式：
- .nrproj（项目文件）
- .xml（设置文件）
- .ini（旧版配置）
```

**Export Settings（导出设置）**
```
功能：导出当前设置供其他项目使用
用途：
- 共享团队配置
- 创建配置模板
- 备份重要设置
```

**Exit（退出）**
```
快捷键：Alt+F4
功能：关闭 .NET Reactor
提示：未保存的更改会提示保存
```

### 3.2.2 Edit 菜单

**Add Files（添加文件）**
```
快捷键：Ctrl+A
功能：添加要保护的程序集
支持类型：
- .exe（可执行文件）
- .dll（动态链接库）
支持批量添加
```

**Remove Files（移除文件）**
```
快捷键：Delete
功能：从列表中移除选中的文件
注意：只是从项目中移除，不删除源文件
```

**Clear All（清空列表）**
```
快捷键：Ctrl+Delete
功能：清空所有文件
确认：会提示确认操作
```

**Select All（全选）**
```
快捷键：Ctrl+Shift+A
功能：选择文件列表中的所有项
用途：批量操作时使用
```

**Preferences（首选项）**
```
快捷键：Ctrl+,
功能：打开全局设置对话框
包含：
- 界面设置
- 默认保护选项
- 输出路径配置
- 临时文件管理
```

### 3.2.3 Project 菜单

**Project Settings（项目设置）**
```
快捷键：Ctrl+P
功能：配置项目级别的设置
包括：
- 输入文件
- 输出路径
- 搜索路径
- 依赖项处理
```

**Protection Settings（保护设置）**
```
功能：配置代码保护选项
主要设置：
- 混淆级别
- 加密选项
- NecroBit 设置
- 反调试功能
```

**Licensing Settings（许可证设置）**
```
快捷键：Ctrl+L
功能：配置软件许可证系统
包括：
- 许可证类型
- 试用期设置
- 硬件锁定
- 许可证服务器
```

**Build Configuration（构建配置）**
```
功能：选择保护的构建配置
选项：
- Debug（调试版本）
- Release（发布版本）
- 自定义配置

建议：通常只保护 Release 版本
```

**Target Platform（目标平台）**
```
功能：指定目标平台
选项：
- Any CPU
- x86（32 位）
- x64（64 位）
- ARM

注意：需要与原程序集匹配
```

### 3.2.4 Protection 菜单

**Start Protection（开始保护）**
```
快捷键：F5
功能：开始保护选中的程序集
过程：
1. 验证输入文件
2. 应用保护设置
3. 生成保护后的程序集
4. 验证输出
```

**Stop Protection（停止保护）**
```
快捷键：Shift+F5
功能：停止正在进行的保护任务
用途：发现配置错误时中止
```

**Batch Protection（批量保护）**
```
功能：批量保护多个程序集
特点：
- 可设置不同的保护级别
- 支持并行处理
- 统一的输出管理
```

**Verify Protected Assembly（验证保护）**
```
功能：验证保护后的程序集
检查项：
- 完整性验证
- 功能测试
- 签名验证
- 依赖项检查
```

**Deobfuscate（反混淆）**
```
功能：使用符号映射文件还原符号
用途：
- 调试保护后的程序
- 分析崩溃报告
- 性能分析

要求：需要保存符号映射文件
```

### 3.2.5 Tools 菜单

**License Manager（许可证管理器）**
```
功能：管理产品许可证
操作：
- 查看许可证信息
- 激活/停用许可证
- 更新许可证
- 管理许可证文件
```

**Assembly Browser（程序集浏览器）**
```
功能：浏览程序集结构
显示：
- 命名空间
- 类型
- 方法
- 属性
- 资源

用途：了解程序集结构，配置排除项
```

**String Encryptor（字符串加密器）**
```
功能：独立的字符串加密工具
用途：
- 加密配置文件中的字符串
- 生成加密代码片段
- 测试加密效果
```

**License Generator（许可证生成器）**
```
功能：生成许可证文件
步骤：
1. 选择许可证类型
2. 设置有效期
3. 配置限制条件
4. 生成许可证文件
```

**Symbol Mapper（符号映射器）**
```
功能：管理符号映射文件
操作：
- 查看映射关系
- 导出映射文件
- 导入映射文件
- 合并映射

用途：调试和错误追踪
```

**Log Viewer（日志查看器）**
```
功能：查看详细的保护日志
信息：
- 保护过程
- 警告信息
- 错误详情
- 性能统计

过滤：可按级别、时间过滤
```

**Options（选项）**
```
快捷键：Ctrl+Alt+O
功能：全局选项设置
分类：
- Appearance（外观）
- Behavior（行为）
- Performance（性能）
- Advanced（高级）
```

### 3.2.6 Help 菜单

**Help Contents（帮助内容）**
```
快捷键：F1
功能：打开完整的帮助文档
格式：HTML 帮助文件
包含：
- 用户手册
- API 参考
- 示例代码
- 常见问题
```

**Quick Start Guide（快速入门指南）**
```
功能：新手入门教程
内容：
- 基本概念
- 第一个项目
- 常用功能
- 最佳实践
```

**Video Tutorials（视频教程）**
```
功能：在线视频教程链接
主题：
- 入门教程
- 高级功能
- 实战案例
- 疑难解答
```

**Knowledge Base（知识库）**
```
功能：在线知识库链接
内容：
- 技术文章
- 解决方案
- 技巧集锦
- 版本历史
```

**Check for Updates（检查更新）**
```
功能：检查软件更新
自动：
- 检查新版本
- 下载更新
- 安装更新（可选）

建议：定期检查更新
```

**Report Bug（报告错误）**
```
功能：提交错误报告
信息收集：
- 错误描述
- 系统信息
- 日志文件
- 重现步骤

隐私：敏感信息会被过滤
```

**About（关于）**
```
功能：显示程序信息
内容：
- 版本号
- 许可证信息
- 版权声明
- 联系方式
```

## 3.3 工具栏详解

工具栏提供了常用功能的快速访问：

### 3.3.1 标准工具栏

```
┌─────────────────────────────────────────────────────────┐
│ [📁] [💾] [➕] [➖] [▶️] [⏹️] [⚙️] [🔍] [❓]         │
└─────────────────────────────────────────────────────────┘
  │    │    │    │    │    │    │    │    │
  │    │    │    │    │    │    │    │    └─ 帮助
  │    │    │    │    │    │    │    └────── 浏览程序集
  │    │    │    │    │    │    └─────────── 设置
  │    │    │    │    │    └──────────────── 停止保护
  │    │    │    │    └───────────────────── 开始保护
  │    │    │    └────────────────────────── 移除文件
  │    │    └─────────────────────────────── 添加文件
  │    └──────────────────────────────────── 保存项目
  └───────────────────────────────────────── 打开项目
```

**按钮说明：**

1. **Open Project（打开项目）**
   - 图标：📁
   - 提示：Open existing project
   - 快捷键：Ctrl+O

2. **Save Project（保存项目）**
   - 图标：💾
   - 提示：Save current project
   - 快捷键：Ctrl+S

3. **Add Files（添加文件）**
   - 图标：➕
   - 提示：Add assemblies to protect
   - 快捷键：Ctrl+A

4. **Remove Files（移除文件）**
   - 图标：➖
   - 提示：Remove selected assemblies
   - 快捷键：Delete

5. **Start Protection（开始保护）**
   - 图标：▶️
   - 提示：Start protection process
   - 快捷键：F5
   - 状态：活动时高亮

6. **Stop Protection（停止保护）**
   - 图标：⏹️
   - 提示：Stop protection process
   - 快捷键：Shift+F5
   - 状态：运行时可用

7. **Settings（设置）**
   - 图标：⚙️
   - 提示：Open protection settings
   - 快捷键：Ctrl+P

8. **Assembly Browser（程序集浏览器）**
   - 图标：🔍
   - 提示：Browse assembly structure
   - 功能：查看程序集内部结构

9. **Help（帮助）**
   - 图标：❓
   - 提示：Open help documentation
   - 快捷键：F1

**可选按钮：**

## 3.7 对话框和向导

### 3.7.1 项目向导（Project Wizard）

新建项目时的引导流程：

**步骤 1：选择项目类型**
```
○ Single Assembly Project（单程序集项目）
○ Multi-Assembly Project（多程序集项目）
○ Solution Protection（解决方案保护）
```

**步骤 2：添加文件**
```
拖放文件或点击 "Add Files" 按钮
支持：
- 单个文件
- 多个文件
- 整个文件夹
```

**步骤 3：选择保护级别**
```
○ Basic（基础）- 快速保护
○ Standard（标准）- 平衡保护
○ Advanced（高级）- 最大保护
○ Custom（自定义）- 自定义设置
```

**步骤 4：许可证配置**
```
☑ Enable Licensing（启用许可证）
  ○ Trial License（试用许可证）
  ○ Full License（完整许可证）
  ○ Custom License（自定义许可证）
```

**步骤 5：输出设置**
```
Output Folder: [Browse]
File Naming: 
  ○ Same Name（相同名称）
  ○ Add Suffix（添加后缀）
  ● Replace Original（替换原文件）
```

**步骤 6：完成**
```
☑ Start protection immediately（立即开始保护）
☑ Save project file（保存项目文件）

[Finish] [Cancel]
```
