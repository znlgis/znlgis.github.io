# 第九章：日志与审计

## 9.1 .NET 日志系统概述

日志是应用程序开发和运维中不可或缺的组成部分。它帮助开发者追踪程序运行状态、排查问题、分析性能瓶颈，以及满足合规审计要求。ASP.NET Core 提供了强大的内置日志框架（`Microsoft.Extensions.Logging`），Furion 在此基础上进行了增强和扩展。

### 9.1.1 日志级别

.NET 日志系统定义了以下日志级别（从低到高）：

| 级别 | 枚举值 | 说明 | 使用场景 |
|------|--------|------|---------|
| Trace | 0 | 最详细的诊断信息 | 开发调试时使用 |
| Debug | 1 | 调试信息 | 开发环境使用 |
| Information | 2 | 一般信息 | 记录正常业务流程 |
| Warning | 3 | 警告信息 | 潜在的问题 |
| Error | 4 | 错误信息 | 功能失败但不影响系统运行 |
| Critical | 5 | 严重错误 | 系统级故障 |
| None | 6 | 不记录任何日志 | 禁用日志 |

### 9.1.2 基本日志使用

```csharp
using Microsoft.Extensions.Logging;

public class OrderService : IDynamicApiController
{
    private readonly ILogger<OrderService> _logger;
    private readonly IRepository<Order> _orderRepo;

    public OrderService(ILogger<OrderService> logger, IRepository<Order> orderRepo)
    {
        _logger = logger;
        _orderRepo = orderRepo;
    }

    public async Task<Order> CreateOrder(CreateOrderInput input)
    {
        _logger.LogInformation("开始创建订单，用户ID：{UserId}，金额：{Amount}",
            input.UserId, input.Amount);

        try
        {
            var order = new Order
            {
                OrderNo = GenerateOrderNo(),
                Amount = input.Amount,
                UserId = input.UserId,
                Status = OrderStatus.Pending
            };

            var result = await _orderRepo.InsertNowAsync(order);

            _logger.LogInformation("订单创建成功，订单号：{OrderNo}",
                result.Entity.OrderNo);

            return result.Entity;
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "订单创建失败，用户ID：{UserId}，错误：{Message}",
                input.UserId, ex.Message);
            throw;
        }
    }

    private string GenerateOrderNo()
    {
        return $"ORD{DateTime.Now:yyyyMMddHHmmss}{Random.Shared.Next(1000, 9999)}";
    }
}
```

```csharp
using Microsoft.Extensions.Logging;

/// <summary>
/// 带有上下文信息的日志记录

public class ContextualLoggingService : IDynamicApiController
{

        }

        return "完成";
    }

    private Task ProcessStep1()
    {
        _logger.LogDebug("执行步骤1");
        return Task.CompletedTask;
    }

    private Task ProcessStep2()
    {
        _logger.LogDebug("执行步骤2");
        return Task.CompletedTask;
    }
}
```

## 9.4 Serilog 集成

Serilog 是 .NET 生态中最流行的结构化日志框架，Furion 可以无缝集成 Serilog。

### 9.4.1 安装 Serilog

```bash
dotnet add package Serilog
dotnet add package Serilog.AspNetCore
dotnet add package Serilog.Sinks.Console
dotnet add package Serilog.Sinks.File
dotnet add package Serilog.Sinks.Seq
dotnet add package Serilog.Enrichers.Environment
dotnet add package Serilog.Enrichers.Thread
```

### 9.4.2 配置 Serilog

```csharp
// Program.cs
using Serilog;
using Serilog.Events;

// 配置 Serilog
Log.Logger = new LoggerConfiguration()
    .MinimumLevel.Debug()
    .MinimumLevel.Override("Microsoft", LogEventLevel.Warning)
    .MinimumLevel.Override("Microsoft.Hosting.Lifetime", LogEventLevel.Information)
    .MinimumLevel.Override("Microsoft.EntityFrameworkCore", LogEventLevel.Warning)
    .Enrich.FromLogContext()
    .Enrich.WithEnvironmentName()
    .Enrich.WithMachineName()
    .Enrich.WithThreadId()
    // 控制台输出
    .WriteTo.Console(
        outputTemplate: "[{Timestamp:HH:mm:ss} {Level:u3}] {Message:lj}{NewLine}{Exception}")
    // 文件输出 - 按日期滚动
    .WriteTo.File(
        path: "logs/app-.log",
        rollingInterval: RollingInterval.Day,
        retainedFileCountLimit: 30,
        outputTemplate: "{Timestamp:yyyy-MM-dd HH:mm:ss.fff zzz} [{Level:u3}] {Message:lj}{NewLine}{Exception}",
        fileSizeLimitBytes: 100 * 1024 * 1024)  // 100MB
    // 错误日志单独输出
    .WriteTo.File(
        path: "logs/error-.log",
        rollingInterval: RollingInterval.Day,
        restrictedToMinimumLevel: LogEventLevel.Error,
        retainedFileCountLimit: 90)
    .CreateLogger();

try
{
    Log.Information("应用程序正在启动...");

    var builder = WebApplication.CreateBuilder(args);

    // 使用 Serilog
    builder.Host.UseSerilog();

    // ... 其他配置

    var app = builder.Build();

    // Serilog 请求日志中间件
    app.UseSerilogRequestLogging(options =>
    {
        options.MessageTemplate = "HTTP {RequestMethod} {RequestPath} responded {StatusCode} in {Elapsed:0.0000}ms";
        options.GetLevel = (httpContext, elapsed, ex) =>
        {
            if (ex != null) return LogEventLevel.Error;
            if (httpContext.Response.StatusCode > 499) return LogEventLevel.Error;
            if (elapsed > 5000) return LogEventLevel.Warning;
            return LogEventLevel.Information;
        };
        options.EnrichDiagnosticContext = (diagnosticContext, httpContext) =>
        {
            diagnosticContext.Set("RequestHost", httpContext.Request.Host.Value);
            diagnosticContext.Set("UserAgent", httpContext.Request.Headers["User-Agent"].ToString());
            diagnosticContext.Set("ClientIP", httpContext.Connection.RemoteIpAddress?.ToString());
        };
    });

    app.Run();
}
catch (Exception ex)
{
    Log.Fatal(ex, "应用程序启动失败");
}
finally
{
    Log.CloseAndFlush();
}
```

## 9.5 结构化日志

结构化日志是现代日志实践的核心，它将日志信息以结构化的方式存储，方便检索和分析。

### 9.5.1 结构化日志语法

```csharp
public class StructuredLoggingDemo : IDynamicApiController
{
    private readonly ILogger<StructuredLoggingDemo> _logger;

    public StructuredLoggingDemo(ILogger<StructuredLoggingDemo> logger)
    {
        _logger = logger;
    }

    public void Demo()
    {
        // 使用命名占位符（推荐）
        _logger.LogInformation("用户 {UserName} 在 {LoginTime} 登录系统",
            "张三", DateTime.Now);

        // 使用对象属性（结构化存储）
        var order = new { OrderNo = "ORD001", Amount = 99.99, UserId = 1 };
        _logger.LogInformation("新订单创建 {@Order}", order);

        // 使用析构操作符 $（只记录 ToString 结果）
        _logger.LogInformation("当前时间 {$Time}", DateTime.Now);

        // 避免使用字符串插值（会丢失结构化信息）
        // 错误示例：_logger.LogInformation($"用户 {userName} 登录");
        // 正确示例：_logger.LogInformation("用户 {UserName} 登录", userName);
    }
}
```

### 9.6.1 运行时动态调整日志级别

```csharp
/// <summary>
/// 日志级别管理服务
/// </summary>
public class LogLevelService : IDynamicApiController
{
    private readonly IConfiguration _configuration;

    public LogLevelService(IConfiguration configuration)
    {
        _configuration = configuration;
    }

    /// <summary>
    /// 获取当前日志级别配置
    /// </summary>
    public Dictionary<string, string> GetLogLevels()
    {
        var logLevels = new Dictionary<string, string>();
        var section = _configuration.GetSection("Logging:LogLevel");
        foreach (var child in section.GetChildren())
        {
            logLevels[child.Key] = child.Value;
        }
        return logLevels;
    }
}
```

## 9.7 请求日志（访问日志）

### 9.7.1 请求日志中间件

```csharp
/// <summary>
/// 请求日志中间件
/// </summary>
public class RequestLoggingMiddleware
{
    private readonly RequestDelegate _next;
    private readonly ILogger<RequestLoggingMiddleware> _logger;

    public RequestLoggingMiddleware(RequestDelegate next, ILogger<RequestLoggingMiddleware> logger)
    {
        _next = next;
        _logger = logger;
    }

    public async Task InvokeAsync(HttpContext context)
    {
        var stopwatch = System.Diagnostics.Stopwatch.StartNew();
        var requestId = context.TraceIdentifier;

        // 记录请求信息
        _logger.LogInformation(
            "请求开始 | RequestId: {RequestId} | {Method} {Path} | IP: {ClientIP} | UserAgent: {UserAgent}",
            requestId,
            context.Request.Method,
            context.Request.Path + context.Request.QueryString,
            context.Connection.RemoteIpAddress?.ToString(),
            context.Request.Headers["User-Agent"].ToString());

        // 记录请求体（仅 POST/PUT）
        if (context.Request.Method is "POST" or "PUT")
        {
            context.Request.EnableBuffering();
            var body = await ReadRequestBody(context.Request);
            if (!string.IsNullOrEmpty(body))
            {
                _logger.LogDebug("请求体 | RequestId: {RequestId} | Body: {Body}",
                    requestId, body);
            }
            context.Request.Body.Position = 0;
        }

        await _next(context);

        stopwatch.Stop();

        // 记录响应信息
        var logLevel = context.Response.StatusCode >= 500
            ? LogLevel.Error
            : context.Response.StatusCode >= 400
                ? LogLevel.Warning
                : LogLevel.Information;

        _logger.Log(logLevel,
            "请求结束 | RequestId: {RequestId} | 状态码: {StatusCode} | 耗时: {Elapsed}ms",
            requestId,
            context.Response.StatusCode,
            stopwatch.ElapsedMilliseconds);
    }

    private async Task<string> ReadRequestBody(HttpRequest request)
    {
        using var reader = new StreamReader(
            request.Body,
            encoding: System.Text.Encoding.UTF8,
            detectEncodingFromByteOrderMarks: false,
            leaveOpen: true);
        var body = await reader.ReadToEndAsync();
        return body.Length > 4096 ? body[..4096] + "...(truncated)" : body;
    }
}

// 注册中间件
app.UseMiddleware<RequestLoggingMiddleware>();
```

### 9.8.2 审计日志特性与过滤器

```csharp
/// <summary>
/// 审计日志特性
/// </summary>
[AttributeUsage(AttributeTargets.Method | AttributeTargets.Class)]
public class AuditLogAttribute : Attribute
{
    /// <summary>
    /// 模块名称
    /// </summary>
    public string Module { get; set; }

    /// <summary>
    /// 操作描述
    /// </summary>
    public string Action { get; set; }

    public AuditLogAttribute(string module, string action)
    {
        Module = module;
        Action = action;
    }
}

/// <summary>
/// 审计日志过滤器
/// </summary>
public class AuditLogFilter : IAsyncActionFilter
{
    private readonly IRepository<AuditLog> _auditLogRepo;
    private readonly ILogger<AuditLogFilter> _logger;

    public AuditLogFilter(IRepository<AuditLog> auditLogRepo, ILogger<AuditLogFilter> logger)
    {
        _auditLogRepo = auditLogRepo;
        _logger = logger;
    }

    public async Task OnActionExecutionAsync(ActionExecutingContext context, ActionExecutionDelegate next)
    {
        // 检查是否标记了审计日志特性
        var auditAttr = context.ActionDescriptor.EndpointMetadata
            .OfType<AuditLogAttribute>().FirstOrDefault();

        if (auditAttr == null)
        {
            await next();
            return;
        }

        var stopwatch = System.Diagnostics.Stopwatch.StartNew();

        var auditLog = new AuditLog
        {
            Module = auditAttr.Module,
            Action = auditAttr.Action,
            HttpMethod = context.HttpContext.Request.Method,
            RequestUrl = context.HttpContext.Request.Path + context.HttpContext.Request.QueryString,
            RequestParams = System.Text.Json.JsonSerializer.Serialize(context.ActionArguments),
            ClientIP = context.HttpContext.Connection.RemoteIpAddress?.ToString(),
            UserAgent = context.HttpContext.Request.Headers["User-Agent"].ToString(),
            UserId = GetCurrentUserId(context.HttpContext),
            UserName = GetCurrentUserName(context.HttpContext)
        };

        var executedContext = await next();
        stopwatch.Stop();

        auditLog.Elapsed = stopwatch.ElapsedMilliseconds;
        auditLog.IsSuccess = executedContext.Exception == null;

        if (executedContext.Exception != null)
        {
            auditLog.ExceptionMessage = executedContext.Exception.Message;
        }

        // 异步保存审计日志（不影响主流程）
        try
        {
            await _auditLogRepo.InsertNowAsync(auditLog);
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "审计日志保存失败");
        }
    }

    private int? GetCurrentUserId(HttpContext context)
    {
        var userIdStr = context.User?.FindFirstValue("UserId");
        return int.TryParse(userIdStr, out var userId) ? userId : null;
    }

    private string GetCurrentUserName(HttpContext context)
    {
        return context.User?.FindFirstValue("UserName");
    }
}

// 注册审计日志过滤器
```

### 9.9.1 异常日志记录策略

```csharp
/// <summary>
/// 异常日志服务
/// </summary>
public class ExceptionLogService
{
    private readonly ILogger<ExceptionLogService> _logger;
    private readonly IRepository<ExceptionLog> _exceptionLogRepo;

    public ExceptionLogService(
        ILogger<ExceptionLogService> logger,
        IRepository<ExceptionLog> exceptionLogRepo)
    {
        _logger = logger;
        _exceptionLogRepo = exceptionLogRepo;
    }

    /// <summary>
    /// 记录异常日志到数据库
    /// </summary>
    public async Task LogException(Exception exception, HttpContext httpContext)
    {
        var exceptionLog = new ExceptionLog
        {
            ExceptionType = exception.GetType().FullName,
            Message = exception.Message,
            StackTrace = exception.StackTrace,
            InnerException = exception.InnerException?.Message,
            Source = exception.Source,
            RequestUrl = httpContext.Request.Path + httpContext.Request.QueryString,
            HttpMethod = httpContext.Request.Method,
            ClientIP = httpContext.Connection.RemoteIpAddress?.ToString(),
            UserId = GetCurrentUserId(httpContext),
            OccurredTime = DateTime.Now
        };

        try
        {
            await _exceptionLogRepo.InsertNowAsync(exceptionLog);
        }
        catch (Exception ex)
        {
            // 数据库写入失败时，至少写入文件日志
            _logger.LogError(ex, "异常日志写入数据库失败，原始异常：{Message}", exception.Message);
        }
    }

    private int? GetCurrentUserId(HttpContext context)
    {
        var userIdStr = context.User?.FindFirstValue("UserId");
        return int.TryParse(userIdStr, out var userId) ? userId : null;
    }
}

/// <summary>
/// 异常日志实体
/// </summary>
public class ExceptionLog : Entity
{
    [MaxLength(500)]
    public string ExceptionType { get; set; }

    public string Message { get; set; }

    public string StackTrace { get; set; }

    public string InnerException { get; set; }

    [MaxLength(200)]
    public string Source { get; set; }

    [MaxLength(500)]
    public string RequestUrl { get; set; }

    [MaxLength(10)]
    public string HttpMethod { get; set; }

    [MaxLength(50)]
    public string ClientIP { get; set; }

    public int? UserId { get; set; }

    public DateTime OccurredTime { get; set; }
}
```

## 9.11 日志最佳实践

### 9.11.1 日志规范

| 规范项 | 说明 |
|--------|------|
| 使用结构化日志 | 使用命名占位符而非字符串插值 |
| 选择合适级别 | 根据信息重要程度选择日志级别 |
| 避免敏感信息 | 不要在日志中记录密码、密钥等敏感数据 |
| 控制日志量 | 生产环境避免使用 Debug/Trace 级别 |
| 包含上下文 | 日志应包含足够的上下文信息（RequestId、UserId等） |
| 统一格式 | 使用统一的日志消息模板 |
| 异常记录 | 异常日志应包含完整的堆栈信息 |
| 定期清理 | 设置日志文件保留策略，避免磁盘空间占满 |

### 9.11.2 日志使用规范示例

```csharp
/// <summary>
/// 日志使用规范示例
/// </summary>
public class LoggingBestPractices : IDynamicApiController
{
    private readonly ILogger<LoggingBestPractices> _logger;

    public LoggingBestPractices(ILogger<LoggingBestPractices> logger)
    {
        _logger = logger;
    }

    public async Task DemoLogging()
    {
        // ✅ 正确：使用结构化参数
        _logger.LogInformation("用户 {UserId} 执行了 {Action} 操作", 123, "CreateOrder");

        // ❌ 错误：使用字符串插值（丢失结构化信息）
        // _logger.LogInformation($"用户 {userId} 执行了 {action} 操作");

        // ✅ 正确：异常日志包含异常对象
        try
        {
            // 某些操作...
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "订单处理失败，订单号：{OrderNo}", "ORD001");
        }

        // ❌ 错误：不要记录敏感信息
        // _logger.LogInformation("用户登录，密码：{Password}", password);

        // ✅ 正确：脱敏处理
        _logger.LogInformation("用户登录，用户名：{UserName}", "张三");

        // ✅ 正确：使用 LoggerMessage.Define 提升性能（高频日志）
        LogUserAction(_logger, 123, "查询订单");
    }

    // 高性能日志（编译时生成，避免运行时装箱和字符串分配）
    private static readonly Action<ILogger, int, string, Exception> LogUserAction =
        LoggerMessage.Define<int, string>(
            LogLevel.Information,
            new EventId(1001, "UserAction"),
            "用户 {UserId} 执行操作：{Action}");
}
```

### 9.11.3 生产环境日志架构

推荐的生产环境日志架构如下：

```
应用日志 → Serilog → 多个 Sink
                        ├── Console（开发环境调试）
                        ├── File（本地文件备份）
                        ├── Elasticsearch（集中化存储和检索）
                        └── Seq / Grafana Loki（日志分析平台）
```

配置示例：

```csharp
Log.Logger = new LoggerConfiguration()
    .MinimumLevel.Information()
    .Enrich.FromLogContext()
    .Enrich.WithProperty("Application", "FurionApp")
    .Enrich.WithProperty("Environment", builder.Environment.EnvironmentName)
    // 开发环境：控制台
    .WriteTo.Conditional(
        _ => builder.Environment.IsDevelopment(),
        config => config.Console())
    // 所有环境：文件
    .WriteTo.File("logs/app-.log",
        rollingInterval: RollingInterval.Day,
        retainedFileCountLimit: 30)
    // 生产环境：Elasticsearch
    .WriteTo.Conditional(
        _ => builder.Environment.IsProduction(),
        config => config.Elasticsearch(new ElasticsearchSinkOptions(
            new Uri("http://elasticsearch:9200"))
        {
            IndexFormat = "app-logs-{0:yyyy.MM.dd}"
        }))
    .CreateLogger();
```
