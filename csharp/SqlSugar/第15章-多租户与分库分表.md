## 1. 多租户概述

### 1.1 什么是多租户

多租户（Multi-Tenancy）是一种软件架构模式，在同一个应用实例中为多个租户（客户/组织）提供服务。每个租户的数据彼此隔离，互不影响，但共享同一套应用程序代码和基础设施。

```
┌─────────────────────────────────────────────────────────┐
│                    应用程序（SaaS）                       │
│                                                         │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐              │
│  │  租户 A   │  │  租户 B   │  │  租户 C   │              │
│  │  公司甲   │  │  公司乙   │  │  公司丙   │              │
│  │  100用户  │  │  50用户   │  │  200用户  │              │
│  └────┬─────┘  └────┬─────┘  └────┬─────┘              │
│       │             │             │                     │
│  ┌────▼─────────────▼─────────────▼─────┐              │
│  │            数据隔离层                  │              │
│  │    确保租户之间数据互不可见             │              │
│  └──────────────────────────────────────┘              │
└─────────────────────────────────────────────────────────┘
```

### 1.2 多租户的典型场景

| 场景 | 说明 | 示例 |
|------|------|------|
| SaaS 平台 | 一套系统服务多个企业客户 | 在线 CRM、ERP、OA 系统 |
| 电商平台 | 多个商家共用一套系统 | 淘宝、京东商家后台 |
| 教育平台 | 多个学校使用同一个系统 | 在线教务管理系统 |
| 政务系统 | 多个部门共用一个平台 | 政务办公系统 |

### 1.3 SqlSugar 多租户支持

SqlSugar 通过 `SqlSugarScope`（单例模式）原生支持多租户架构，提供了以下核心能力：

- 多数据库连接配置与管理
- 动态切换数据库连接
- 租户级别的全局查询过滤
- 跨库联表查询
- 读写分离

## 2. 租户数据隔离策略

### 2.1 三种隔离策略

多租户数据隔离主要有三种策略，各有优缺点：

| 策略 | 隔离级别 | 成本 | 复杂度 | 说明 |
|------|---------|------|--------|------|
| 共享数据库，共享 Schema | 低 | 低 | 低 | 通过 TenantId 字段区分 |
| 共享数据库，独立 Schema | 中 | 中 | 中 | 每个租户独立的 Schema |
| 独立数据库 | 高 | 高 | 高 | 每个租户一个数据库 |

### 2.2 策略一：共享数据库 + TenantId

最常用且成本最低的方式，所有租户的数据存储在同一个数据库的同一张表中，通过 `TenantId` 字段区分：

```csharp
// 实体类中添加 TenantId 字段
public class BaseEntity
{
    [SugarColumn(IsPrimaryKey = true, IsIdentity = true)]
    public int Id { get; set; }

    /// <summary>
    /// 租户ID
    /// </summary>
    [SugarColumn(IsNullable = false)]
    public int TenantId { get; set; }

    public DateTime CreateTime { get; set; }
    public bool IsDeleted { get; set; }
}

[SugarTable("Orders")]
public class Order : BaseEntity
{
    public string OrderNo { get; set; }
    public decimal TotalAmount { get; set; }
    public int Status { get; set; }
}
```

```csharp
// 配置全局租户过滤器
public class TenantDbContext
{
    private readonly ISqlSugarClient _db;
    private readonly int _tenantId;

    public TenantDbContext(ISqlSugarClient db, ITenantProvider tenantProvider)
    {
        _db = db;
        _tenantId = tenantProvider.GetCurrentTenantId();

        // 配置全局过滤器
        _db.QueryFilter.AddTableFilter<BaseEntity>(it => it.TenantId == _tenantId);
    }

    public ISqlSugarClient Db => _db;
}
```

### 2.3 策略二：共享数据库 + 独立 Schema

每个租户使用同一个数据库中不同的 Schema（SQL Server）或不同的数据库前缀（MySQL）：

```csharp
// 根据租户动态设置表名
public class TenantTableService
{
    private readonly ISqlSugarClient _db;
    private readonly string _tenantSchema;

    public TenantTableService(ISqlSugarClient db, string tenantCode)
    {
        _db = db;
        _tenantSchema = $"tenant_{tenantCode}";
    }

    public List<Order> GetOrders()
    {
        return _db.Queryable<Order>()
            .AS($"{_tenantSchema}.Orders")  // 指定 Schema
            .ToList();
    }

    public int InsertOrder(Order order)
    {
        return _db.Insertable(order)
            .AS($"{_tenantSchema}.Orders")
            .ExecuteReturnIdentity();
    }
}
```

### 2.4 策略三：独立数据库

每个租户使用独立的数据库，隔离最彻底：

```csharp
// 租户数据库配置
public class TenantDbConfig
{
    public int TenantId { get; set; }
    public string TenantName { get; set; }
    public string ConnectionString { get; set; }
    public DbType DbType { get; set; }
}

// 动态获取租户连接
public class TenantConnectionFactory
{
    private readonly Dictionary<int, TenantDbConfig> _configs;

    public TenantConnectionFactory()
    {
        // 从主库加载租户配置
        _configs = LoadTenantConfigs();
    }

    public ConnectionConfig GetConnectionConfig(int tenantId)
    {
        if (!_configs.TryGetValue(tenantId, out var config))
        {
            throw new Exception($"租户 {tenantId} 的数据库配置不存在");
        }

        return new ConnectionConfig
        {
            ConfigId = $"tenant_{tenantId}",
            ConnectionString = config.ConnectionString,
            DbType = config.DbType,
            IsAutoCloseConnection = true
        };
    }
}
```

```csharp
var db = new SqlSugarScope(new List<ConnectionConfig>
{
    // 主库（默认）
    new ConnectionConfig
    {
        ConfigId = "main",
        ConnectionString = "Server=localhost;Database=MainDb;Uid=sa;Pwd=123456;",
        DbType = DbType.SqlServer,
        IsAutoCloseConnection = true
    },
    // 日志库
    new ConnectionConfig
    {
        ConfigId = "log",
        ConnectionString = "Server=localhost;Database=LogDb;Uid=sa;Pwd=123456;",
        DbType = DbType.SqlServer,
        IsAutoCloseConnection = true
    },
    // 报表库（MySQL）
    new ConnectionConfig
    {
        ConfigId = "report",
        ConnectionString = "Server=localhost;Database=ReportDb;Uid=root;Pwd=123456;",
        DbType = DbType.MySql,
        IsAutoCloseConnection = true
    }

```

## 4. GetConnection 与数据库切换

### 4.1 GetConnection 基本用法

使用 `GetConnection` 方法根据 `ConfigId` 获取指定数据库的连接：

```csharp
// 使用主库
var mainDb = db.GetConnection("main");
var users = mainDb.Queryable<User>().ToList();

// 使用日志库
var logDb = db.GetConnection("log");
var logs = logDb.Queryable<OperationLog>().ToList();

// 使用报表库
var reportDb = db.GetConnection("report");
var reports = reportDb.Queryable<SalesReport>().ToList();
```

### 4.2 通过实体特性指定数据库

使用 `[TenantAttribute]` 特性将实体绑定到特定数据库：

```csharp
// 实体绑定到特定数据库
[SugarTable("Users")]
[Tenant("main")]
public class User
{
    [SugarColumn(IsPrimaryKey = true, IsIdentity = true)]
    public int Id { get; set; }
    public string Name { get; set; }
}

[SugarTable("OperationLogs")]
[Tenant("log")]
public class OperationLog
{
    [SugarColumn(IsPrimaryKey = true, IsIdentity = true)]
    public int Id { get; set; }
    public string Action { get; set; }
    public DateTime CreateTime { get; set; }
}

// 使用时自动路由到对应数据库
var users = db.GetConnection("main").Queryable<User>().ToList();
var logs = db.GetConnection("log").Queryable<OperationLog>().ToList();
```

### 4.3 动态切换数据库

```csharp
// 场景：根据当前登录用户的租户信息切换数据库
public class TenantMiddleware
{
    private readonly RequestDelegate _next;

    public TenantMiddleware(RequestDelegate next)
    {
        _next = next;
    }

    public async Task InvokeAsync(HttpContext context, ISqlSugarClient db)
    {
        // 从请求头或 Token 中获取租户 ID
        var tenantId = context.Request.Headers["X-Tenant-Id"].FirstOrDefault();

        if (!string.IsNullOrEmpty(tenantId))
        {
            // 动态添加数据库连接
            var tenantConfig = GetTenantConfig(tenantId);
            db.AddConnection(tenantConfig);

            // 切换到租户数据库
            db.ChangeDatabase(tenantId);
        }

        await _next(context);
    }

    private ConnectionConfig GetTenantConfig(string tenantId)
    {
        // 从配置中心或数据库获取租户连接信息
        return new ConnectionConfig
        {
            ConfigId = tenantId,
            ConnectionString = $"Server=localhost;Database=Tenant_{tenantId};Uid=sa;Pwd=123456;",
            DbType = DbType.SqlServer,
            IsAutoCloseConnection = true
        };
    }
}
```

### 4.4 动态添加和移除连接

```csharp
// 动态添加新的数据库连接
db.AddConnection(new ConnectionConfig
{
    ConfigId = "new_tenant",
    ConnectionString = "Server=new-server;Database=NewTenantDb;...",
    DbType = DbType.SqlServer,
    IsAutoCloseConnection = true
});

// 使用新添加的连接
var newDb = db.GetConnection("new_tenant");
var data = newDb.Queryable<Order>().ToList();

// ChangeDatabase 切换默认连接
db.ChangeDatabase("new_tenant");
// 之后的操作都使用 new_tenant 连接
var data2 = db.Queryable<Order>().ToList();
```

## 5. 租户感知的查询过滤器

### 5.1 全局租户过滤器

SqlSugar 支持配置全局查询过滤器，自动为所有查询添加租户条件：

```csharp
public class TenantQueryFilterService
{
    private readonly ISqlSugarClient _db;

    public TenantQueryFilterService(ISqlSugarClient db, IHttpContextAccessor httpContext)
    {
        _db = db;
        var tenantId = GetTenantId(httpContext);

        // 添加全局过滤器：所有继承 ITenantEntity 的实体都会自动加上 TenantId 条件
        _db.QueryFilter.AddTableFilter<ITenantEntity>(it => it.TenantId == tenantId);

        // 软删除过滤器
        _db.QueryFilter.AddTableFilter<ISoftDelete>(it => it.IsDeleted == false);
    }

    private int GetTenantId(IHttpContextAccessor httpContext)
    {
        var claim = httpContext.HttpContext?.User?.FindFirst("TenantId");
        return claim != null ? int.Parse(claim.Value) : 0;
    }
}

// 接口定义
public interface ITenantEntity
{
    int TenantId { get; set; }
}

public interface ISoftDelete
{
    bool IsDeleted { get; set; }
}

// 实体类实现接口
[SugarTable("Orders")]
public class Order : ITenantEntity, ISoftDelete
{
    [SugarColumn(IsPrimaryKey = true, IsIdentity = true)]
    public int Id { get; set; }
    public string OrderNo { get; set; }
    public decimal TotalAmount { get; set; }
    public int TenantId { get; set; }
    public bool IsDeleted { get; set; }
}
```

### 5.2 临时禁用过滤器

```csharp
// 某些场景需要查询所有租户的数据（如管理后台）
var allOrders = db.Queryable<Order>()
    .ClearFilter()                    // 清除所有过滤器
    .ToList();

// 只清除特定类型的过滤器
var allOrders2 = db.Queryable<Order>()
    .ClearFilter<ITenantEntity>()     // 只清除租户过滤器，保留软删除过滤器
    .ToList();
```

### 5.3 插入时自动填充 TenantId

```csharp
// 配置 AOP 自动填充租户 ID
db.Aop.DataExecuting = (oldValue, entityInfo) =>
{
    // 插入时自动设置 TenantId
    if (entityInfo.OperationType == DataFilterType.InsertByObject)
    {
        if (entityInfo.EntityColumnInfo.PropertyName == "TenantId" &&
            entityInfo.EntityValue is ITenantEntity entity)
        {
            if (entity.TenantId == 0)
            {
                entityInfo.SetValue(currentTenantId);
            }
        }

        // 自动设置创建时间
        if (entityInfo.EntityColumnInfo.PropertyName == "CreateTime")
        {
            entityInfo.SetValue(DateTime.Now);
        }
    }

    // 更新时自动设置修改时间
    if (entityInfo.OperationType == DataFilterType.UpdateByObject)
    {
        if (entityInfo.EntityColumnInfo.PropertyName == "UpdateTime")
        {
            entityInfo.SetValue(DateTime.Now);
        }
    }
};
```

## 6. 跨库查询

### 6.1 跨库联表查询

SqlSugar 支持在不同数据库之间进行联表查询（要求数据库服务器相同或通过 LinkedServer 连通）：

```csharp
// 跨库查询：主库的 User 表和日志库的 OperationLog 表
var list = db.GetConnection("main")
    .Queryable<User>()
    .LeftJoin(db.GetConnection("log").Queryable<OperationLog>(),
        (u, l) => u.Id == l.UserId)
    .Select((u, l) => new
    {
        UserName = u.Name,
        Action = l.Action,
        LogTime = l.CreateTime
    })
    .ToList();
```

### 6.2 使用配置跨库

```csharp
// 通过实体的 Tenant 特性指定数据库
[SugarTable("Users")]
[Tenant("main")]
public class User
{
    [SugarColumn(IsPrimaryKey = true, IsIdentity = true)]
    public int Id { get; set; }
    public string Name { get; set; }
}

[SugarTable("OperationLogs")]
[Tenant("log")]
public class OperationLog
{
    [SugarColumn(IsPrimaryKey = true, IsIdentity = true)]
    public int Id { get; set; }
    public int UserId { get; set; }
    public string Action { get; set; }
    public DateTime CreateTime { get; set; }
}

// 跨库查询（SqlSugar 自动识别实体所属数据库）
var list = db.QueryableWithAttr<User>()
    .LeftJoin<OperationLog>((u, l) => u.Id == l.UserId)
    .Select((u, l) => new
    {
        u.Name,
        l.Action,
        l.CreateTime
    })
    .ToList();
```

### 6.3 跨库事务

```csharp
// 跨库事务（需要数据库支持分布式事务）
try
{
    // 开启跨库事务
    db.BeginTran();

    // 主库操作
    db.GetConnection("main").Insertable(new User
    {
        Name = "张三"
    }).ExecuteCommand();

    // 日志库操作
    db.GetConnection("log").Insertable(new OperationLog
    {
        UserId = 1,
        Action = "新增用户",
        CreateTime = DateTime.Now
    }).ExecuteCommand();

    // 提交事务
    db.CommitTran();
}
catch (Exception ex)
{
    // 回滚事务
    db.RollbackTran();
    throw;
}
```

## 7. 自动分表概述

### 7.1 什么是分表

分表（Table Sharding）是将一张大表按照某个规则拆分为多张小表的技术。当单表数据量达到千万级甚至上亿级时，查询性能会显著下降，此时需要通过分表来提升性能。

```
┌──────────────────────────────────────────────────┐
│                 原始表：Orders                     │
│              （1亿条数据，查询缓慢）                │
└──────────────────┬───────────────────────────────┘
                   │ 分表
                   ▼
┌──────────┬──────────┬──────────┬──────────┐
│Orders    │Orders    │Orders    │Orders    │
│_2024_01  │_2024_02  │_2024_03  │_2024_04  │
│100万条   │120万条   │110万条   │ 90万条   │
└──────────┴──────────┴──────────┴──────────┘
  每张子表数据量小，查询速度快
```

### 7.2 分表策略

| 策略 | 适用场景 | 说明 |
|------|---------|------|
| 按年分表 | 数据增长较慢 | 每年一张表，如 `Orders_2024` |
| 按月分表 | 最常用 | 每月一张表，如 `Orders_202401` |
| 按日分表 | 数据增长极快 | 每天一张表，如 `Orders_20240601` |
| 按周分表 | 特殊需求 | 每周一张表 |
| 自定义规则 | 特殊业务 | 按租户、按地区等 |

### 7.3 SqlSugar 分表能力

SqlSugar 提供了完善的自动分表功能：

- 自动创建子表
- 自动路由到正确的子表
- 支持跨表查询
- 支持分表的增删改查
- 支持自定义分表规则

## 8. SplitTable 特性配置

### 8.1 基本配置

使用 `[SplitTable]` 特性标记需要分表的实体类：

```csharp
[SugarTable("OrderLog")]
[SplitTable(SplitType.Month)]  // 按月分表
public class OrderLog
{
    [SugarColumn(IsPrimaryKey = true, IsIdentity = true)]
    public long Id { get; set; }

    public string OrderNo { get; set; }
    public string Content { get; set; }
    public int LogType { get; set; }

    /// <summary>
    /// 分表依据字段（必须标记 SplitField）
    /// </summary>
    [SplitField]
    public DateTime CreateTime { get; set; }
}
```

### 8.2 SplitType 枚举

`SplitType` 定义了分表的时间粒度：

| 枚举值 | 分表规则 | 表名示例 | 说明 |
|--------|---------|---------|------|
| `SplitType.Year` | 按年 | `OrderLog_2024` | 每年一张表 |
| `SplitType.Season` | 按季度 | `OrderLog_2024_1` | 每季度一张表 |
| `SplitType.Month` | 按月 | `OrderLog_202401` | 每月一张表 |
| `SplitType.Week` | 按周 | `OrderLog_202401_1` | 每周一张表 |
| `SplitType.Day` | 按日 | `OrderLog_20240601` | 每天一张表 |

### 8.3 多字段分表实体

```csharp
[SugarTable("AuditLog")]
[SplitTable(SplitType.Month)]
public class AuditLog
{
    [SugarColumn(IsPrimaryKey = true)]
    public long Id { get; set; }

    /// <summary>
    /// 操作用户
    /// </summary>
    public int UserId { get; set; }

    /// <summary>
    /// 操作模块
    /// </summary>
    public string Module { get; set; }

    /// <summary>
    /// 操作类型
    /// </summary>
    public string Action { get; set; }

    /// <summary>
    /// 操作详情
    /// </summary>
    [SugarColumn(ColumnDataType = "ntext")]
    public string Detail { get; set; }

    /// <summary>
    /// IP 地址
    /// </summary>
    public string IpAddress { get; set; }

    /// <summary>
    /// 分表字段
    /// </summary>
    [SplitField]
    public DateTime CreateTime { get; set; }
}
```

### 8.4 初始化分表

```csharp
// CodeFirst 初始化分表（自动创建当前月份和近几个月的子表）
db.CodeFirst
    .SplitTables()
    .InitTables<OrderLog>();

// 也可以手动创建指定时间范围的子表
db.CodeFirst
    .SplitTables()
    .InitTables<OrderLog>(
        DateTime.Parse("2024-01-01"),
        DateTime.Parse("2024-12-31"));
```

## 9. 按时间分表

### 9.1 按月分表（最常用）

```csharp
[SugarTable("SysLog")]
[SplitTable(SplitType.Month)]
public class SysLog
```

### 10.1 插入数据

```csharp
    Content = "订单创建",
    LogType = 1,
    CreateTime = DateTime.Now  // 根据此字段自动路由到 OrderLog_202406
};

db.Insertable(log)
    .SplitTable()
    .ExecuteCommand();
```


### 12.2 配置自定义分表规则

```csharp
// 在 ConnectionConfig 中配置自定义分表规则
var db = new SqlSugarScope(new ConnectionConfig
{
    ConnectionString = "...",
    DbType = DbType.SqlServer,
    IsAutoCloseConnection = true,
    ConfigureExternalServices = new ConfigureExternalServices
    {
        SplitTableService = new CustomSplitTableService()
    }
});

// 自定义分表服务
public class CustomSplitTableService : ISplitTableService
{
    public List<SplitTableInfo> GetAllTables(ISqlSugarClient db, EntityInfo entityInfo, List<DbTableInfo> tableInfos)
    {
        // 返回所有匹配的子表
        var prefix = entityInfo.DbTableName + "_";
        return tableInfos
            .Where(t => t.Name.StartsWith(prefix))
            .Select(t => new SplitTableInfo
            {
                TableName = t.Name
            })
            .ToList();
    }

    public object GetFieldValue(ISqlSugarClient db, EntityInfo entityInfo, SplitType splitType, object entityValue)
    {
        // 返回分表字段的值
        var splitColumn = entityInfo.Columns.First(c => c.IsArray);
        return splitColumn.PropertyInfo.GetValue(entityValue);
    }

    public string GetTableName(ISqlSugarClient db, EntityInfo entityInfo, SplitType splitType)
    {
        return entityInfo.DbTableName;
    }

    public string GetTableName(ISqlSugarClient db, EntityInfo entityInfo, SplitType splitType, object fieldValue)
    {
        // 根据字段值确定子表名称
        return $"{entityInfo.DbTableName}_{fieldValue}";
    }
}
```

### 12.3 按哈希分表

```csharp
// 按用户 ID 哈希取模分表
public class HashSplitService
{
    private const int TableCount = 8;  // 分8张表

    public string GetTableName(int userId)
    {
        var tableIndex = userId % TableCount;
        return $"UserOrder_{tableIndex}";
    }

    public List<Order> QueryByUserId(ISqlSugarClient db, int userId)
    {
        var tableName = GetTableName(userId);
        return db.Queryable<Order>()
            .AS(tableName)
            .Where(o => o.UserId == userId)
            .ToList();
    }

    public void Insert(ISqlSugarClient db, Order order)
    {
        var tableName = GetTableName(order.UserId);
        db.Insertable(order)
            .AS(tableName)
            .ExecuteCommand();
    }
}
```

## 13. 读写分离配置

### 13.1 读写分离概述

读写分离是通过将读操作路由到从库、写操作路由到主库来提升数据库性能的技术：

```
┌──────────────┐        ┌──────────────┐
│   应用程序    │        │   应用程序    │
└──────┬───────┘        └──────┬───────┘
       │                       │
       ▼                       ▼
┌──────────────┐        ┌──────────────┐
│  写操作(主库)  │ ─复制─▶ │  读操作(从库)  │
│  INSERT      │        │  SELECT      │
│  UPDATE      │        │  从库1        │
│  DELETE      │        │  从库2        │
└──────────────┘        └──────────────┘
```

### 13.2 SqlSugar 读写分离配置

```csharp
var db = new SqlSugarScope(new ConnectionConfig
{
    ConnectionString = "Server=master;Database=MyDb;Uid=sa;Pwd=123456;",
    DbType = DbType.SqlServer,
    IsAutoCloseConnection = true,

    // 从库配置
    SlaveConnectionConfigs = new List<SlaveConnectionConfig>
    {
        new SlaveConnectionConfig
        {
            HitRate = 10,  // 命中率权重
            ConnectionString = "Server=slave1;Database=MyDb;Uid=sa;Pwd=123456;"
        },
        new SlaveConnectionConfig
        {
            HitRate = 10,
            ConnectionString = "Server=slave2;Database=MyDb;Uid=sa;Pwd=123456;"
        }
    }
});

// 查询自动路由到从库
var list = db.Queryable<Student>().ToList();  // 走从库

// 写操作自动路由到主库
db.Insertable(new Student { Name = "测试" }).ExecuteCommand();  // 走主库
```

### 13.3 强制走主库

某些场景下（如刚写入后立即读取），需要强制从主库读取以确保数据一致性：

```csharp
// 强制走主库查询
var list = db.Queryable<Student>()
    .MasterTable()  // 强制从主库查询
    .Where(s => s.Id == 1)
    .ToList();
```

### 14.2 租户上下文服务

```csharp
/// <summary>
/// 租户上下文提供器
/// </summary>
public interface ITenantContext
{
    int TenantId { get; }
    string TenantCode { get; }
    SysTenant GetCurrentTenant();
}

public class TenantContext : ITenantContext
{
    private readonly IHttpContextAccessor _httpContext;
    private readonly ISqlSugarClient _masterDb;
    private SysTenant _cachedTenant;

    public TenantContext(IHttpContextAccessor httpContext, ISqlSugarClient masterDb)
    {
        _httpContext = httpContext;
        _masterDb = masterDb;
    }

    public int TenantId
    {
        get
        {
            var claim = _httpContext.HttpContext?.User?.FindFirst("TenantId");
            return claim != null ? int.Parse(claim.Value) : 0;
        }
    }

    public string TenantCode
    {
        get
        {
            var claim = _httpContext.HttpContext?.User?.FindFirst("TenantCode");
            return claim?.Value ?? string.Empty;
        }
    }

    public SysTenant GetCurrentTenant()
    {
        if (_cachedTenant == null)
        {
            _cachedTenant = _masterDb.Queryable<SysTenant>()
                .Where(t => t.Id == TenantId)
                .First();
        }
        return _cachedTenant;
    }
}
```

### 14.3 多租户完整示例

```csharp
// ASP.NET Core 完整配置
public static class MultiTenantExtensions
{
    public static IServiceCollection AddMultiTenant(
        this IServiceCollection services,
        IConfiguration config)
    {
        // 注册主库连接（管理租户信息）
        services.AddSingleton<ISqlSugarClient>(provider =>
        {
            return new SqlSugarScope(new ConnectionConfig
            {
                ConfigId = "master",
                ConnectionString = config.GetConnectionString("MasterDb"),
                DbType = SqlSugar.DbType.SqlServer,
                IsAutoCloseConnection = true
            },
            db =>
            {
                // 获取当前租户 ID
                var httpContext = provider.GetService<IHttpContextAccessor>();
                var tenantId = GetTenantId(httpContext);

                if (tenantId > 0)
                {
                    // 配置全局租户过滤
                    db.QueryFilter.AddTableFilter<ITenantEntity>(
                        it => it.TenantId == tenantId);
                }

                // 软删除过滤
                db.QueryFilter.AddTableFilter<ISoftDelete>(
                    it => it.IsDeleted == false);

                // 自动填充审计字段
                db.Aop.DataExecuting = (oldValue, entityInfo) =>
                {
                    if (entityInfo.OperationType == DataFilterType.InsertByObject)
                    {
                        switch (entityInfo.EntityColumnInfo.PropertyName)
                        {
                            case "TenantId":
                                entityInfo.SetValue(tenantId);
                                break;
                            case "CreateTime":
                                entityInfo.SetValue(DateTime.Now);
                                break;
                        }
                    }
                };
            });
        });

        // 注册租户上下文
        services.AddScoped<ITenantContext, TenantContext>();

        return services;
    }

    private static int GetTenantId(IHttpContextAccessor httpContext)
    {
        var claim = httpContext?.HttpContext?.User?.FindFirst("TenantId");
        return claim != null ? int.Parse(claim.Value) : 0;
    }
}
```

### 14.4 安全注意事项

| 风险 | 防护措施 | 说明 |
|------|---------|------|
| 租户数据泄露 | 全局过滤器 + 严格测试 | 确保所有查询都经过租户过滤 |
| 跨租户越权 | 验证请求的 TenantId | 防止用户伪造租户信息 |
| 连接字符串泄露 | 加密存储 | 不要明文存储数据库密码 |
| 分表数据混乱 | 严格校验分表字段 | 确保分表字段值正确 |
| 性能瓶颈 | 监控 + 告警 | 监控每个租户的数据量和查询性能 |
