## 1. 导航属性概述

### 1.1 什么是导航属性

导航属性（Navigation Property）是实体类中表示关联关系的属性。通过导航属性，你可以在代码中像访问普通属性一样访问关联的数据，而不需要手动编写 JOIN 查询。

```
传统方式：
  var order = db.Queryable<Order>().First();
  var details = db.Queryable<OrderDetail>().Where(d => d.OrderId == order.Id).ToList();

导航属性方式：
  var order = db.Queryable<Order>().Includes(o => o.Details).First();
  // order.Details 已自动填充
```

### 1.2 SqlSugar支持的关系类型

| 关系类型 | 说明 | 导航属性类型 | 示例 |
|---------|------|------------|------|
| 一对一 | OneToOne | 单个实体 | 用户 ↔ 用户详情 |
| 一对多 | OneToMany | List集合 | 订单 → 订单明细 |
| 多对一 | ManyToOne | 单个实体 | 订单明细 → 订单 |
| 多对多 | ManyToMany | List集合 | 学生 ↔ 课程 |

### 1.3 Navigate特性

SqlSugar 使用 `[Navigate]` 特性来配置导航属性：

```csharp
// Navigate特性参数说明
[Navigate(NavigateType.OneToOne, nameof(外键属性名))]
[Navigate(NavigateType.OneToMany, nameof(子表外键属性名))]
[Navigate(NavigateType.ManyToMany, typeof(中间表类型), nameof(中间表外键1), nameof(中间表外键2))]
```

### 1.4 导航属性 vs 手动JOIN

| 特性 | 导航属性 | 手动JOIN |
|------|---------|---------|
| 代码简洁性 | 高，链式调用 | 低，需要写JOIN语句 |
| 灵活性 | 中等 | 高 |
| 多级关联 | 支持（ThenInclude） | 复杂 |
| 性能 | 多次查询 | 一次查询 |
| 数据结构 | 自动填充到实体 | 需要手动映射 |
| 适用场景 | 通用CRUD | 复杂报表查询 |

## 2. 一对一关系配置

### 2.1 场景说明

一对一关系常见于将一个表拆分为多个表的场景，如用户基本信息和用户详情。

### 2.2 实体定义

```csharp
// 用户表（主表）
[SugarTable("User")]
public class UserInfo
{
    [SugarColumn(IsPrimaryKey = true, IsIdentity = true)]
    public int Id { get; set; }
    public string UserName { get; set; }
    public string Password { get; set; }
    public DateTime CreateTime { get; set; }

    // 一对一导航属性
    [Navigate(NavigateType.OneToOne, nameof(UserDetail.UserId))]
    public UserDetail Detail { get; set; }
}

// 用户详情表（从表）
[SugarTable("UserDetail")]
public class UserDetail
{
    [SugarColumn(IsPrimaryKey = true, IsIdentity = true)]
    public int Id { get; set; }

    // 外键
    public int UserId { get; set; }

    public string RealName { get; set; }
    public string Phone { get; set; }
    public string Address { get; set; }
    public DateTime? Birthday { get; set; }
}
```

### 2.3 另一种配置方式（外键在主表）

```csharp
// 当外键在主表时
[SugarTable("Student")]
public class Student
{
    [SugarColumn(IsPrimaryKey = true, IsIdentity = true)]
    public int Id { get; set; }
    public string Name { get; set; }

    // 外键在当前表
    public int ClassId { get; set; }

    // 一对一：学生属于一个班级
    [Navigate(NavigateType.OneToOne, nameof(ClassId))]
    public ClassInfo ClassInfo { get; set; }
}

[SugarTable("Class")]
public class ClassInfo
{
    [SugarColumn(IsPrimaryKey = true, IsIdentity = true)]
    public int Id { get; set; }
    public string ClassName { get; set; }
    public string TeacherName { get; set; }
}
```

### 2.4 查询一对一数据

```csharp
// 查询用户并加载详情
var user = db.Queryable<UserInfo>()
             .Includes(u => u.Detail)
             .Where(u => u.Id == 1)
             .First();

Console.WriteLine($"用户名：{user.UserName}");
Console.WriteLine($"真实姓名：{user.Detail?.RealName}");
Console.WriteLine($"手机号：{user.Detail?.Phone}");
```

### 2.5 一对一查询的SQL

```
执行了两条SQL：
SQL1: SELECT * FROM User WHERE Id = 1
SQL2: SELECT * FROM UserDetail WHERE UserId IN (1)

SqlSugar会自动将结果映射到导航属性中。
```

## 3. 一对多关系配置

### 3.1 场景说明

一对多是最常见的关系类型，如一个订单有多个订单明细、一个班级有多个学生。

### 3.2 实体定义

```csharp
// 订单表（一方）
[SugarTable("Order")]
public class Order
{
    [SugarColumn(IsPrimaryKey = true, IsIdentity = true)]
    public int Id { get; set; }
    public string OrderNo { get; set; }
    public decimal TotalAmount { get; set; }
    public string Status { get; set; }
    public DateTime CreateTime { get; set; }

    // 一对多导航属性：一个订单有多个明细
    [Navigate(NavigateType.OneToMany, nameof(OrderDetail.OrderId))]
    public List<OrderDetail> Details { get; set; }

    // 一对一导航属性：一个订单有一个物流信息
    [Navigate(NavigateType.OneToOne, nameof(OrderLogistics.OrderId))]
    public OrderLogistics Logistics { get; set; }
}

// 订单明细表（多方）
[SugarTable("OrderDetail")]
public class OrderDetail
{
    [SugarColumn(IsPrimaryKey = true, IsIdentity = true)]
    public int Id { get; set; }

    // 外键：指向订单表
    public int OrderId { get; set; }

    public string ProductName { get; set; }
    public int Quantity { get; set; }
    public decimal Price { get; set; }

    // 多对一导航属性：明细属于一个订单
    [Navigate(NavigateType.ManyToOne, nameof(OrderId))]
    public Order Order { get; set; }
}

// 物流信息表
[SugarTable("OrderLogistics")]
public class OrderLogistics
{
    [SugarColumn(IsPrimaryKey = true, IsIdentity = true)]
    public int Id { get; set; }
    public int OrderId { get; set; }
    public string TrackingNo { get; set; }
    public string Company { get; set; }
    public string Address { get; set; }
}
```

### 3.3 查询一对多数据

```csharp
// 查询订单并加载明细
var orders = db.Queryable<Order>()
               .Includes(o => o.Details)
               .Where(o => o.Status == "已完成")
               .ToList();

foreach (var order in orders)
{
    Console.WriteLine($"订单号：{order.OrderNo}，金额：{order.TotalAmount}");
    foreach (var detail in order.Details)
    {
        Console.WriteLine($"  商品：{detail.ProductName}，数量：{detail.Quantity}，单价：{detail.Price}");
    }
}
```

### 3.4 同时加载多个导航属性

```csharp
// 同时加载明细和物流信息
var order = db.Queryable<Order>()
              .Includes(o => o.Details)
              .Includes(o => o.Logistics)
              .Where(o => o.Id == 1)
              .First();

Console.WriteLine($"订单号：{order.OrderNo}");
Console.WriteLine($"明细数：{order.Details?.Count}");
Console.WriteLine($"物流单号：{order.Logistics?.TrackingNo}");
```

### 3.5 反向查询（多对一）

```csharp
// 从明细查询关联的订单
var details = db.Queryable<OrderDetail>()
                .Includes(d => d.Order)
                .Where(d => d.ProductName == "商品A")
                .ToList();

foreach (var detail in details)
{
    Console.WriteLine($"商品：{detail.ProductName}，所属订单：{detail.Order?.OrderNo}");
}
```

## 4. 多对多关系配置

### 4.1 场景说明

多对多关系需要通过中间表来实现，如学生和课程的关系：一个学生可以选多门课，一门课也有多个学生。

### 4.2 实体定义

```csharp
// 学生表
[SugarTable("Student")]
public class Student
{
    [SugarColumn(IsPrimaryKey = true, IsIdentity = true)]
    public int Id { get; set; }
    public string Name { get; set; }
    public int Age { get; set; }

    // 多对多导航属性：学生选修的课程
    [Navigate(typeof(StudentCourse), nameof(StudentCourse.StudentId), nameof(StudentCourse.CourseId))]
    public List<Course> Courses { get; set; }
}

// 课程表
[SugarTable("Course")]
public class Course
{
    [SugarColumn(IsPrimaryKey = true, IsIdentity = true)]
    public int Id { get; set; }
    public string CourseName { get; set; }
    public int Credit { get; set; }
    public string Teacher { get; set; }

    // 多对多导航属性：选修该课程的学生
    [Navigate(typeof(StudentCourse), nameof(StudentCourse.CourseId), nameof(StudentCourse.StudentId))]
    public List<Student> Students { get; set; }
}

// 中间表（必须定义）
[SugarTable("StudentCourse")]
public class StudentCourse
{
    [SugarColumn(IsPrimaryKey = true)]
    public int StudentId { get; set; }

    [SugarColumn(IsPrimaryKey = true)]
    public int CourseId { get; set; }

    // 中间表也可以有额外字段
    public decimal? Score { get; set; }
    public DateTime SelectTime { get; set; }
}
```

### 4.3 查询多对多数据

```csharp
// 查询学生及其选修的课程
var students = db.Queryable<Student>()
                 .Includes(s => s.Courses)
                 .ToList();

foreach (var student in students)
{
    Console.WriteLine($"学生：{student.Name}");
    foreach (var course in student.Courses ?? new List<Course>())
    {
        Console.WriteLine($"  课程：{course.CourseName}，学分：{course.Credit}");
    }
}
```

### 4.4 反向查询

```csharp
// 查询课程及其选课学生
var courses = db.Queryable<Course>()
                .Includes(c => c.Students)
                .Where(c => c.Credit >= 3)
                .ToList();

foreach (var course in courses)
{
    Console.WriteLine($"课程：{course.CourseName}，学生数：{course.Students?.Count}");
}
```

### 4.5 多对多中间表带额外字段

```csharp
// 查询学生选课信息（包含成绩）
var studentCourses = db.Queryable<StudentCourse>()
                       .Where(sc => sc.StudentId == 1)
                       .ToList();

// 或者使用联表查询获取完整信息
var result = db.Queryable<StudentCourse>()
               .LeftJoin<Student>((sc, s) => sc.StudentId == s.Id)
               .LeftJoin<Course>((sc, s, c) => sc.CourseId == c.Id)
               .Where((sc, s, c) => s.Id == 1)
               .Select((sc, s, c) => new
               {
                   StudentName = s.Name,
                   CourseName = c.CourseName,
                   Score = sc.Score
               })
               .ToList();
```

## 5. Includes急切加载

### 5.1 什么是急切加载

急切加载（Eager Loading）是指在查询主实体时，同时将关联的数据一并加载到内存中。与之相对的是延迟加载（Lazy Loading），SqlSugar 使用 `Includes` 方法实现急切加载。

```csharp
// 不使用Includes：只查询主表数据
var order = db.Queryable<Order>().First();
// order.Details 为 null

// 使用Includes：同时加载关联数据
var order = db.Queryable<Order>()
              .Includes(o => o.Details)
              .First();
// order.Details 已填充
```

### 5.2 加载多个导航属性

```csharp
// 同时加载多个导航属性
var order = db.Queryable<Order>()
              .Includes(o => o.Details)
              .Includes(o => o.Logistics)
              .First();
```

### 5.3 Includes与Where组合

```csharp
// 先过滤主表，再加载导航属性
var orders = db.Queryable<Order>()
               .Includes(o => o.Details)
               .Where(o => o.Status == "已完成")
               .OrderBy(o => o.CreateTime, OrderByType.Desc)
               .Take(10)
               .ToList();
```

### 5.4 Includes的执行原理

```
db.Queryable<Order>().Includes(o => o.Details).Where(o => o.Status == "已完成").ToList();

执行步骤：
  1. SQL1: SELECT * FROM Order WHERE Status = '已完成'
     → 假设得到订单ID为 [1, 2, 3]
  2. SQL2: SELECT * FROM OrderDetail WHERE OrderId IN (1, 2, 3)
     → 查询这些订单的所有明细
  3. 在内存中将明细数据映射到对应的订单实体

注意：Includes使用的是多次查询（N+1优化为2次查询），而不是JOIN。
```

### 5.5 Includes列表查询

```csharp
// 查询列表并加载导航属性
var students = db.Queryable<Student>()
                 .Includes(s => s.Courses)
                 .Where(s => s.Age >= 18)
                 .ToList();
```

## 6. 多级Includes

### 6.1 什么是多级加载

多级加载允许你加载嵌套的关联数据，如 学校 → 班级 → 学生。

### 6.2 实体定义

```csharp
// 学校
public class School
{
    [SugarColumn(IsPrimaryKey = true, IsIdentity = true)]
    public int Id { get; set; }
    public string SchoolName { get; set; }
    public string Address { get; set; }

    [Navigate(NavigateType.OneToMany, nameof(ClassInfo.SchoolId))]
    public List<ClassInfo> Classes { get; set; }
}

// 班级
public class ClassInfo
{
    [SugarColumn(IsPrimaryKey = true, IsIdentity = true)]
    public int Id { get; set; }
    public int SchoolId { get; set; }
    public string ClassName { get; set; }
    public string TeacherName { get; set; }

    [Navigate(NavigateType.OneToMany, nameof(Student.ClassId))]
    public List<Student> Students { get; set; }

    [Navigate(NavigateType.ManyToOne, nameof(SchoolId))]
    public School School { get; set; }
}

// 学生
public class Student
{
    [SugarColumn(IsPrimaryKey = true, IsIdentity = true)]
    public int Id { get; set; }
    public int ClassId { get; set; }
    public string Name { get; set; }
    public int Age { get; set; }

    [Navigate(NavigateType.ManyToOne, nameof(ClassId))]
    public ClassInfo ClassInfo { get; set; }
}
```

### 6.3 二级加载

```csharp
// 加载学校 → 班级 → 学生（三级数据）
var schools = db.Queryable<School>()
                .Includes(s => s.Classes, c => c.Students)  // Lambda参数实现多级
                .ToList();

foreach (var school in schools)
{
    Console.WriteLine($"学校：{school.SchoolName}");
    foreach (var cls in school.Classes ?? new List<ClassInfo>())
    {
        Console.WriteLine($"  班级：{cls.ClassName}");
        foreach (var student in cls.Students ?? new List<Student>())
        {
            Console.WriteLine($"    学生：{student.Name}");
        }
    }
}
```

### 6.4 使用ThenInclude

```csharp
// 另一种多级加载写法
var schools = db.Queryable<School>()
                .Includes(s => s.Classes.Where(c => c.ClassName.Contains("一班")).ToList(),
                          c => c.Students.Where(st => st.Age >= 18).ToList())
                .ToList();
```

### 6.5 多级加载的SQL执行

```
三级加载会执行3条SQL：
SQL1: SELECT * FROM School
SQL2: SELECT * FROM Class WHERE SchoolId IN (1, 2, 3)
SQL3: SELECT * FROM Student WHERE ClassId IN (10, 11, 12, 13, ...)

每一级增加一次数据库查询。
```

### 6.6 混合多级加载

```csharp
// 加载学校的班级和学生，同时加载班级对应的老师
var schools = db.Queryable<School>()
                .Includes(s => s.Classes, c => c.Students)
                .ToList();
```

## 7. 导航插入

### 7.1 基本导航插入

导航插入允许你在插入主表数据时，自动插入关联的子表数据，并自动处理外键关系。

```csharp
// 创建订单及其明细
var order = new Order
{
    OrderNo = "ORD20240101001",
    TotalAmount = 300m,
    Status = "待支付",
    CreateTime = DateTime.Now,
    Details = new List<OrderDetail>
    {
        new OrderDetail { ProductName = "商品A", Quantity = 2, Price = 100m },
        new OrderDetail { ProductName = "商品B", Quantity = 1, Price = 100m }
    }
};

// 导航插入：自动插入订单和明细，并设置明细的OrderId
db.InsertNav(order)
  .Include(o => o.Details)
  .ExecuteCommand();
```

### 7.2 导航插入的自动外键处理

```
导航插入执行步骤：
1. INSERT INTO Order (OrderNo, TotalAmount, ...) → 得到 OrderId = 1
2. 自动设置所有明细的 OrderId = 1
3. INSERT INTO OrderDetail (OrderId, ProductName, ...) VALUES (1, '商品A', ...), (1, '商品B', ...)
```

### 7.3 多级导航插入

```csharp
// 三级导航插入
var school = new School
{
    SchoolName = "第一中学",
    Address = "北京市朝阳区",
    Classes = new List<ClassInfo>
    {
        new ClassInfo
        {
            ClassName = "一班",
            TeacherName = "张老师",
            Students = new List<Student>
            {
                new Student { Name = "张三", Age = 18 },
                new Student { Name = "李四", Age = 17 }
            }
        },
        new ClassInfo
        {
            ClassName = "二班",
            TeacherName = "李老师",
            Students = new List<Student>
            {
                new Student { Name = "王五", Age = 19 }
            }
        }
    }
};

db.InsertNav(school)
  .Include(s => s.Classes)
  .ThenInclude(c => c.Students)
  .ExecuteCommand();
```

### 7.4 多对多导航插入

```csharp
// 多对多导航插入
var student = new Student
{
    Name = "新生",
    Age = 18,
    Courses = new List<Course>
    {
        new Course { Id = 1 }, // 已存在的课程
        new Course { Id = 2 }
    }
};

db.InsertNav(student)
  .Include(s => s.Courses)
  .ExecuteCommand();
// 自动插入学生记录和中间表记录
```

## 8. 导航更新

### 8.1 基本导航更新

```csharp
// 查询订单及明细
var order = db.Queryable<Order>()
              .Includes(o => o.Details)
              .InSingle(1);

// 修改订单信息
order.TotalAmount = 500m;

// 修改明细
order.Details[0].Quantity = 5;
order.Details[0].Price = 100m;

// 添加新明细
order.Details.Add(new OrderDetail
{
    ProductName = "新增商品",
    Quantity = 1,
    Price = 50m
});

// 导航更新
db.UpdateNav(order)
  .Include(o => o.Details)
  .ExecuteCommand();
```

### 8.2 导航更新的行为

```
导航更新的默认行为：
- 主表：更新主表记录
- 子表列表中存在的记录：更新
- 子表列表中新增的记录：插入
- 数据库中有但列表中没有的记录：默认不处理
```

### 8.3 导航更新选项

```csharp
// 配置导航更新行为：不在列表中的子表记录自动删除
db.UpdateNav(order)
  .Include(o => o.Details, new UpdateNavOptions
  {
      OneToManyInsertOrUpdate = true // 存在则更新，不存在则插入，多余则删除
  })
  .ExecuteCommand();
```

### 8.4 多对多导航更新

```csharp
// 更新学生选课信息
var student = db.Queryable<Student>()
                .Includes(s => s.Courses)
                .InSingle(1);

// 修改选课（重新分配课程）
student.Courses = new List<Course>
{
    new Course { Id = 1 },
    new Course { Id = 3 },
    new Course { Id = 5 }
};

db.UpdateNav(student)
  .Include(s => s.Courses)
  .ExecuteCommand();
// 自动更新中间表
```

## 9. 导航删除

### 9.1 基本导航删除

```csharp
// 查询订单及其关联数据
var order = db.Queryable<Order>()
              .Includes(o => o.Details)
              .Includes(o => o.Logistics)
              .InSingle(1);

// 导航删除：同时删除订单、明细和物流信息
db.DeleteNav(order)
  .Include(o => o.Details)
  .Include(o => o.Logistics)
  .ExecuteCommand();
```

### 9.2 多级导航删除

```csharp
// 三级级联删除
var school = db.Queryable<School>()
               .Includes(s => s.Classes, c => c.Students)
               .InSingle(1);

db.DeleteNav(school)
  .Include(s => s.Classes)
  .ThenInclude(c => c.Students)
  .ExecuteCommand();
// 删除顺序：先删学生，再删班级，最后删学校
```

### 9.3 多对多导航删除

```csharp
// 删除学生及其选课关系
var student = db.Queryable<Student>()
                .Includes(s => s.Courses)
                .InSingle(1);

db.DeleteNav(student)
  .Include(s => s.Courses) // 只删除中间表记录，不删除课程本身
  .ExecuteCommand();
```

### 9.4 选择性导航删除

```csharp
// 只删除子表数据，保留主表
// 方法：直接删除子表
db.Deleteable<OrderDetail>()
  .Where(d => d.OrderId == 1)
  .ExecuteCommand();
```

## 10. Mapper手动映射

### 10.1 什么是Mapper

`Mapper` 是 SqlSugar 提供的手动映射方法，当导航属性不满足需求或者需要更灵活的数据填充时，可以使用 `Mapper` 在查询结果上进行额外的数据加工。

### 10.2 基本Mapper用法

```csharp
// 使用Mapper手动填充关联数据
var orders = db.Queryable<Order>()
               .Mapper(o => o.Details, o => o.Details.First().OrderId)
               .Where(o => o.Status == "已完成")
               .ToList();
```

### 10.3 Mapper自定义逻辑

```csharp
// 自定义Mapper：可以执行任意逻辑
var students = db.Queryable<Student>()
                 .Mapper((s, cache) =>
                 {
                     // 为每个学生填充额外的计算数据
                     s.ClassInfo = cache.Get(list =>
                     {
                         // 一次性查询所有需要的班级数据
                         var classIds = list.Select(x => x.ClassId).Distinct().ToList();
                         return db.Queryable<ClassInfo>()
                                  .In(classIds)
                                  .ToList();
                     })
                     .FirstOrDefault(c => c.Id == s.ClassId);
                 })
                 .ToList();
```

### 10.4 Mapper与计算字段

```csharp
// DTO类
public class OrderDto
{
    public int Id { get; set; }
    public string OrderNo { get; set; }
    public decimal TotalAmount { get; set; }
    public int DetailCount { get; set; }  // 明细数量
    public List<OrderDetail> Details { get; set; }
}

// 使用Mapper填充计算字段
var orders = db.Queryable<Order>()
               .Select(o => new OrderDto
               {
                   Id = o.Id,
                   OrderNo = o.OrderNo,
                   TotalAmount = o.TotalAmount
               })
               .Mapper((dto, cache) =>
               {
                   var allDetails = cache.Get(list =>
                   {
                       var ids = list.Select(x => x.Id).ToList();
                       return db.Queryable<OrderDetail>()
                                .In(it => it.OrderId, ids)
                                .ToList();
                   });

                   dto.Details = allDetails.Where(d => d.OrderId == dto.Id).ToList();
                   dto.DetailCount = dto.Details.Count;
               })
               .ToList();
```

### 10.5 Mapper vs Includes的选择

| 特性 | Includes | Mapper |
|------|----------|--------|
| 使用简便性 | 简单，一行代码 | 较复杂，需要写Lambda |
| 灵活性 | 低，固定模式 | 高，可执行任意逻辑 |
| 性能控制 | 自动优化 | 手动控制查询 |
| 计算字段 | 不支持 | 支持 |
| 跨表聚合 | 不支持 | 支持 |
| 推荐场景 | 标准关联加载 | 复杂数据加工 |

## 11. Include与筛选条件

### 11.1 对子表数据进行过滤

有时候我们不想加载所有的子表数据，而是只加载满足条件的部分：

```csharp
// 只加载价格大于50的明细
var orders = db.Queryable<Order>()
               .Includes(o => o.Details.Where(d => d.Price > 50).ToList())
               .ToList();
```

### 11.2 对子表数据进行排序

```csharp
// 加载明细并按价格降序排列
var orders = db.Queryable<Order>()
               .Includes(o => o.Details
                              .Where(d => d.Quantity > 0)
                              .OrderByDescending(d => d.Price)
                              .ToList())
               .ToList();
```

### 11.3 对子表数据进行分页

```csharp
// 只取前5条明细
var orders = db.Queryable<Order>()
               .Includes(o => o.Details
                              .OrderBy(d => d.Id)
                              .Take(5)
                              .ToList())
               .ToList();
```

### 11.4 多级Include带条件

```csharp
// 多级Include都带条件
var schools = db.Queryable<School>()
                .Includes(s => s.Classes
                               .Where(c => c.ClassName.Contains("一"))
                               .ToList(),
                          c => c.Students
                               .Where(st => st.Age >= 18)
                               .ToList())
                .ToList();
```

### 11.5 Include中使用Select

```csharp
// 在Include中只选择需要的列
var orders = db.Queryable<Order>()
               .Includes(o => o.Details
                              .Select(d => new OrderDetail
                              {
                                  Id = d.Id,
                                  ProductName = d.ProductName,
                                  Price = d.Price
                              })
                              .ToList())
               .ToList();
```

### 11.6 条件Include的实际应用

```csharp
// 场景：查询订单列表页面
// 只需要展示最新3条明细和未发货的物流
var orderList = db.Queryable<Order>()
                  .Includes(o => o.Details
                                 .OrderByDescending(d => d.Id)
                                 .Take(3)
                                 .ToList())
                  .Where(o => o.CreateTime >= DateTime.Now.AddMonths(-1))
                  .OrderByDescending(o => o.CreateTime)
                  .ToPageList(1, 10);
```

## 12. 性能对比与最佳实践

### 12.1 Includes vs JOIN性能对比

| 场景 | Includes | JOIN |
|------|----------|------|
| 数据量小（<100） | 差异不大 | 差异不大 |
| 数据量中等 | 多次查询，稍慢 | 一次查询，较快 |
| 数据量大（>10000） | 可能有N+1问题 | 可能返回大量重复数据 |
| 多级关联 | 查询次数等于层级数 | JOIN复杂度高 |
| 一对多（多条子表） | 数据不重复，结构清晰 | 主表数据重复 |

### 12.2 N+1查询问题

```csharp
// ❌ N+1问题：在循环中查询关联数据
var orders = db.Queryable<Order>().ToList();
foreach (var order in orders)
{
    // 每个订单都执行一次查询，如果有100个订单就执行100+1次SQL
    order.Details = db.Queryable<OrderDetail>()
                      .Where(d => d.OrderId == order.Id)
                      .ToList();
}

// ✅ 使用Includes避免N+1问题
var orders = db.Queryable<Order>()
               .Includes(o => o.Details)  // 只执行2次SQL
               .ToList();
```

### 12.3 合理选择加载方式

```csharp
// 场景1：列表页面，只需要主表数据 → 不使用Includes
var orders = db.Queryable<Order>()
               .Select(o => new { o.Id, o.OrderNo, o.TotalAmount, o.Status })
               .ToPageList(pageIndex, pageSize);

// 场景2：详情页面，需要关联数据 → 使用Includes
var order = db.Queryable<Order>()
              .Includes(o => o.Details)
              .Includes(o => o.Logistics)
              .InSingle(id);

// 场景3：报表查询，需要聚合数据 → 使用JOIN
var report = db.Queryable<Order>()
               .LeftJoin<OrderDetail>((o, d) => o.Id == d.OrderId)
               .GroupBy((o, d) => o.OrderNo)
               .Select((o, d) => new
               {
                   OrderNo = o.OrderNo,
                   ItemCount = SqlFunc.AggregateCount(d.Id),
                   TotalQuantity = SqlFunc.AggregateSum(d.Quantity)
               })
               .ToList();
```

### 12.4 避免过度加载

```csharp
// ❌ 不推荐：加载所有层级的关联数据
var school = db.Queryable<School>()
               .Includes(s => s.Classes, c => c.Students)  // 可能加载大量数据
               .First();

// ✅ 推荐：按需加载，限制数据量
var school = db.Queryable<School>()
               .Includes(s => s.Classes
                               .Take(10)
                               .ToList(),
                          c => c.Students
                               .Take(50)
                               .ToList())
               .First();
```

### 12.5 缓存优化

```csharp
// 对于频繁查询的关联数据，考虑使用缓存
var categories = db.Queryable<Category>()
                   .WithCache(3600) // 缓存1小时
                   .ToList();
```

### 12.6 实用技巧总结

| 技巧 | 说明 |
|------|------|
| 按需加载 | 只在需要时才使用 Includes |
| 限制子表数量 | 在 Includes 中使用 Take 限制 |
| 过滤子表数据 | 在 Includes 中使用 Where 过滤 |
| 列表页用 JOIN | 列表页面使用 JOIN 获取聚合信息 |
| 详情页用 Includes | 详情页使用 Includes 获取完整数据 |
| 避免深层嵌套 | 多级 Includes 不超过3层 |
| 使用 Select 减少列 | 只查询需要的列 |
| 考虑使用 Mapper | 复杂数据加工使用 Mapper |

### 12.7 完整的服务层示例

```csharp
public class OrderService
{
    private readonly ISqlSugarClient _db;

    public OrderService(ISqlSugarClient db) => _db = db;

    // 列表查询：不加载导航属性，使用JOIN获取统计
    public PageResult<OrderListDto> GetPageList(int pageIndex, int pageSize, string keyword)
    {
        int total = 0;
        var list = _db.Queryable<Order>()
                      .LeftJoin<OrderDetail>((o, d) => o.Id == d.OrderId)
                      .WhereIF(!string.IsNullOrEmpty(keyword),
                               (o, d) => o.OrderNo.Contains(keyword))
                      .GroupBy((o, d) => new { o.Id, o.OrderNo, o.TotalAmount, o.Status, o.CreateTime })
                      .Select((o, d) => new OrderListDto
                      {
                          Id = o.Id,
                          OrderNo = o.OrderNo,
                          TotalAmount = o.TotalAmount,
                          Status = o.Status,
                          CreateTime = o.CreateTime,
                          DetailCount = SqlFunc.AggregateCount(d.Id)
                      })
                      .ToPageList(pageIndex, pageSize, ref total);

        return new PageResult<OrderListDto> { Items = list, Total = total };
    }

    // 详情查询：使用Includes加载全部关联数据
    public Order GetDetail(int id)
    {
        return _db.Queryable<Order>()
                  .Includes(o => o.Details)
                  .Includes(o => o.Logistics)
                  .InSingle(id);
    }

    // 创建：使用导航插入
    public int Create(Order order)
    {
        _db.InsertNav(order)
           .Include(o => o.Details)
           .ExecuteCommand();
        return order.Id;
    }

    // 更新：使用导航更新
    public void Update(Order order)
    {
        _db.UpdateNav(order)
           .Include(o => o.Details)
           .ExecuteCommand();
    }

    // 删除：使用导航删除
    public void Delete(int id)
    {
        var order = _db.Queryable<Order>()
                       .Includes(o => o.Details)
                       .InSingle(id);

        if (order != null)
        {
            _db.DeleteNav(order)
               .Include(o => o.Details)
               .ExecuteCommand();
        }
    }
}
```

## 13. 本章小结

本章全面介绍了 SqlSugar 的导航属性与关联查询：

- **导航属性概述**：`Navigate` 特性配置、支持的关系类型、与手动 JOIN 的对比
- **一对一关系**：外键在主表或从表的配置方式
- **一对多关系**：最常见的关联关系，父子表的数据加载
- **多对多关系**：通过中间表实现，支持中间表额外字段
- **Includes 急切加载**：一行代码加载关联数据，避免 N+1 问题
- **多级 Includes**：支持多层嵌套加载，Lambda 参数链式配置
- **导航插入**：`InsertNav` 自动处理外键，支持多级级联插入
- **导航更新**：`UpdateNav` 自动处理子表的增、改、删
- **导航删除**：`DeleteNav` 级联删除关联数据
- **Mapper 手动映射**：灵活的数据填充和加工方式
- **Include 带条件**：对子表数据进行过滤、排序、分页
- **性能最佳实践**：按需加载、避免过度加载、合理选择 Includes 或 JOIN

导航属性是 SqlSugar 中非常强大的功能，正确使用它可以大幅简化关联数据的操作代码，同时保持良好的性能。
