## 1. Updateable概述

### 1.1 什么是Updateable

`Updateable` 是 SqlSugar 中用于更新数据的核心对象。它采用链式调用的方式，允许开发者灵活地指定更新的列、条件、以及执行方式。与 EF Core 的全量更新不同，SqlSugar 默认只更新有值的列，避免了不必要的数据覆盖。

```csharp
// 最基础的更新用法
var result = db.Updateable(entity).ExecuteCommand();
```

### 1.2 核心方法一览

| 方法 | 说明 | 返回值 |
|------|------|--------|
| `ExecuteCommand()` | 执行更新，返回受影响行数 | `int` |
| `ExecuteCommandHasChange()` | 执行更新，返回是否有变化 | `bool` |
| `ExecuteAsync()` | 异步执行更新 | `Task<int>` |
| `UpdateColumns(...)` | 指定要更新的列 | `IUpdateable<T>` |
| `IgnoreColumns(...)` | 忽略不更新的列 | `IUpdateable<T>` |
| `Where(...)` | 设置更新条件 | `IUpdateable<T>` |
| `SetColumns(...)` | 通过表达式设置列值 | `IUpdateable<T>` |
| `WhereColumns(...)` | 以指定列作为条件（非主键） | `IUpdateable<T>` |

### 1.3 基本流程

更新操作的基本流程如下：

```
创建Updateable → 配置更新列 → 设置更新条件 → 执行更新
     ↓                ↓              ↓             ↓
db.Updateable()  UpdateColumns()   Where()   ExecuteCommand()
```

> **重要提示**：如果没有指定 `Where` 条件，SqlSugar 会默认以实体的主键作为更新条件。如果实体没有主键且未设置 `Where` 条件，将会抛出异常，以防止全表更新的危险操作。

## 2. 更新实体对象

### 2.1 按主键更新

最常用的更新方式是传入一个实体对象，SqlSugar 会自动以主键为条件进行更新：

```csharp
// 定义实体类
[SugarTable("Student")]
public class Student
{
    [SugarColumn(IsPrimaryKey = true, IsIdentity = true)]
    public int Id { get; set; }
    public string Name { get; set; }
    public int Age { get; set; }
    public string Email { get; set; }
    public DateTime? UpdateTime { get; set; }
}

// 按主键更新整个实体
var student = new Student
{
    Id = 1,
    Name = "张三",
    Age = 25,
    Email = "zhangsan@example.com",
    UpdateTime = DateTime.Now
};

// 生成SQL: UPDATE Student SET Name='张三', Age=25, Email='zhangsan@example.com', UpdateTime='...' WHERE Id=1
int rows = db.Updateable(student).ExecuteCommand();
Console.WriteLine($"更新了 {rows} 行数据");
```

### 2.2 先查后改

一种常见的更新模式是先从数据库中查询出实体，修改部分属性后再保存：

```csharp
// 先查询
var student = db.Queryable<Student>().InSingle(1);

// 修改部分属性
student.Name = "李四";
student.Age = 30;

// 再更新
db.Updateable(student).ExecuteCommand();
```

### 2.3 判断是否有变化

有时候我们不关心影响了多少行，只想知道是否有数据被更新：

```csharp
bool hasChange = db.Updateable(student).ExecuteCommandHasChange();
if (hasChange)
{
    Console.WriteLine("数据已更新");
}
else
{
    Console.WriteLine("没有数据被更新（可能条件不匹配或数据未变化）");
}
```

### 2.4 异步更新

在 ASP.NET Core 等异步场景中，推荐使用异步方法：

```csharp
// 异步更新
int rows = await db.Updateable(student).ExecuteCommandAsync();
```

## 3. 指定更新列

### 3.1 使用Lambda表达式指定列

当你只想更新实体的某几个属性时，可以使用 `UpdateColumns` 方法：

```csharp
// 只更新Name和Age列
db.Updateable(student)
  .UpdateColumns(s => new { s.Name, s.Age })
  .ExecuteCommand();
// 生成SQL: UPDATE Student SET Name=@Name, Age=@Age WHERE Id=@Id
```

### 3.2 使用字符串数组指定列

也可以通过字符串方式指定更新的列名：

```csharp
// 字符串方式指定列
db.Updateable(student)
  .UpdateColumns("Name", "Age")
  .ExecuteCommand();
```

### 3.3 使用表达式函数

当需要动态决定更新哪些列时，可以使用数组方式：

```csharp
// 动态构建更新列
string[] columnsToUpdate = { "Name", "Email" };
db.Updateable(student)
  .UpdateColumns(columnsToUpdate)
  .ExecuteCommand();
```

### 3.4 更新列的实际应用场景

```csharp
// 场景1：只更新密码
db.Updateable(user)
  .UpdateColumns(u => new { u.Password, u.UpdateTime })
  .ExecuteCommand();

// 场景2：只更新状态
db.Updateable(order)
  .UpdateColumns(o => new { o.Status, o.UpdateTime })
  .ExecuteCommand();

// 场景3：根据前端传入的字段动态更新
public void UpdateFields(Student entity, List<string> fields)
{
    db.Updateable(entity)
      .UpdateColumns(fields.ToArray())
      .ExecuteCommand();
}
```

## 4. 忽略更新列

### 4.1 使用Lambda忽略列

与指定列相反，`IgnoreColumns` 用于排除不想更新的列：

```csharp
// 忽略CreateTime列不更新
db.Updateable(student)
  .IgnoreColumns(s => new { s.CreateTime })
  .ExecuteCommand();
// 除了CreateTime外，其他列都会更新
```

### 4.2 忽略多个列

```csharp
// 忽略多个列
db.Updateable(student)
  .IgnoreColumns(s => new { s.CreateTime, s.CreateBy, s.Id })
  .ExecuteCommand();
```

### 4.3 使用字符串忽略

```csharp
// 字符串方式忽略
db.Updateable(student)
  .IgnoreColumns("CreateTime", "CreateBy")
  .ExecuteCommand();
```

### 4.4 通过特性忽略

在实体定义时，通过特性标记某些列始终不参与更新：

```csharp
public class Student
{
    [SugarColumn(IsPrimaryKey = true, IsIdentity = true)]
    public int Id { get; set; }

    public string Name { get; set; }

    // 标记为不可更新
    [SugarColumn(IsOnlyIgnoreUpdate = true)]
    public DateTime CreateTime { get; set; }

    // 标记为不可更新
    [SugarColumn(IsOnlyIgnoreUpdate = true)]
    public string CreateBy { get; set; }

    public DateTime? UpdateTime { get; set; }
}
```

### 4.5 忽略空值列（IgnoreNullColumns）

有时候实体中某些属性为 `null`，表示这些字段不需要更新：

```csharp
// 自动忽略值为null的列
db.Updateable(student)
  .IgnoreColumns(ignoreAllNullColumns: true)
  .ExecuteCommand();

// 等价写法
db.Updateable(student)
  .IgnoreNullColumns()
  .ExecuteCommand();
```

> **注意**：使用 `IgnoreNullColumns` 时要注意，如果你确实想将某个列设为 NULL，这种方式将无法实现。此时需要使用 `SetColumns` 表达式更新。

## 5. 条件更新

### 5.1 使用Where设置条件

当你不想以主键为条件更新，而是想根据业务条件更新时，可以使用 `Where` 方法：

```csharp
// 根据条件更新
db.Updateable(student)
  .Where(s => s.Age > 18)
  .ExecuteCommand();
// 生成SQL: UPDATE Student SET ... WHERE Age > 18
```

### 5.2 多条件组合

```csharp
// 多条件更新
db.Updateable(student)
  .Where(s => s.Age > 18 && s.Name == "张三")
  .ExecuteCommand();
```

### 5.3 使用WhereColumns指定条件列

当你的表没有主键，或者想用非主键字段作为更新条件时：

```csharp
// 以Name作为更新条件而非主键
db.Updateable(student)
  .WhereColumns(s => new { s.Name })
  .ExecuteCommand();
// 生成SQL: UPDATE Student SET Age=@Age, Email=@Email WHERE Name=@Name
```

### 5.4 组合条件更新

```csharp
// 使用多个WhereColumns
db.Updateable(student)
  .WhereColumns(s => new { s.Name, s.Age })
  .ExecuteCommand();
// 生成SQL: UPDATE Student SET Email=@Email WHERE Name=@Name AND Age=@Age
```

### 5.5 条件更新与安全性

```csharp
// 错误示范：没有条件的更新会全表更新（SqlSugar会阻止无主键无条件的更新）
// db.Updateable(student).ExecuteCommand(); // 如果实体没有主键配置，将抛出异常

// 正确做法：始终确保有明确的更新条件
db.Updateable(student)
  .Where(s => s.Id == 1)
  .ExecuteCommand();
```

## 6. 无实体更新

### 6.1 字典更新

当没有实体类时，可以使用字典进行更新：

```csharp
// 使用字典更新
var updateDict = new Dictionary<string, object>
{
    { "Name", "王五" },
    { "Age", 28 },
    { "UpdateTime", DateTime.Now }
};

db.Updateable(updateDict)
  .AS("Student")
  .WhereColumns("Id")
  .ExecuteCommand();
```

### 6.2 多个字典批量更新

```csharp
// 批量字典更新
var list = new List<Dictionary<string, object>>();
list.Add(new Dictionary<string, object>
{
    { "Id", 1 },
    { "Name", "张三" },
    { "Age", 25 }
});
list.Add(new Dictionary<string, object>
{
    { "Id", 2 },
    { "Name", "李四" },
    { "Age", 30 }
});

db.Updateable(list)
  .AS("Student")
  .WhereColumns("Id")
  .ExecuteCommand();
```

### 6.3 匿名对象更新

```csharp
// 匿名对象更新（需要指定表名和条件列）
db.Updateable<object>(new { Id = 1, Name = "赵六", Age = 35 })
  .AS("Student")
  .WhereColumns("Id")
  .ExecuteCommand();
```

### 6.4 DataTable更新

```csharp
// 使用DataTable更新
DataTable dt = new DataTable();
dt.Columns.Add("Id", typeof(int));
dt.Columns.Add("Name", typeof(string));
dt.Columns.Add("Age", typeof(int));

DataRow row = dt.NewRow();
row["Id"] = 1;
row["Name"] = "更新后的名字";
row["Age"] = 26;
dt.Rows.Add(row);

db.Updateable(dt)
  .AS("Student")
  .WhereColumns("Id")
  .ExecuteCommand();
```

### 6.5 动态更新场景

```csharp
// 根据前端传入的JSON动态更新
public int DynamicUpdate(string tableName, JObject data, string primaryKey)
{
    var dict = data.ToObject<Dictionary<string, object>>();
    return db.Updateable(dict)
             .AS(tableName)
             .WhereColumns(primaryKey)
             .ExecuteCommand();
}
```

## 7. 表达式更新SetColumns

### 7.1 基本表达式更新

`SetColumns` 允许你通过表达式直接设置列的值，非常适合不需要传入完整实体的场景：

```csharp
// 直接设置列值
db.Updateable<Student>()
  .SetColumns(s => s.Name == "新名字")
  .Where(s => s.Id == 1)
  .ExecuteCommand();
// 生成SQL: UPDATE Student SET Name='新名字' WHERE Id=1
```

### 7.2 多列表达式更新

```csharp
// 同时设置多个列
db.Updateable<Student>()
  .SetColumns(s => new Student
  {
      Name = "张三",
      Age = 25,
      UpdateTime = DateTime.Now
  })
  .Where(s => s.Id == 1)
  .ExecuteCommand();
```

### 7.3 列运算更新

```csharp
// 在原有值的基础上进行运算
db.Updateable<Student>()
  .SetColumns(s => s.Age == s.Age + 1) // 年龄加1
  .Where(s => s.Id == 1)
  .ExecuteCommand();
// 生成SQL: UPDATE Student SET Age = Age + 1 WHERE Id=1
```

### 7.4 条件表达式更新

```csharp
// 使用SQL条件表达式
db.Updateable<Student>()
  .SetColumns(s => s.Status == (s.Score >= 60 ? "通过" : "未通过"))
  .Where(s => s.ClassId == 1)
  .ExecuteCommand();
```

### 7.5 使用SetColumnsIF条件更新

```csharp
bool updateName = true;
bool updateAge = false;

db.Updateable<Student>()
  .SetColumnsIF(updateName, s => s.Name == "新名字")
  .SetColumnsIF(updateAge, s => s.Age == 30)
  .Where(s => s.Id == 1)
  .ExecuteCommand();
// 只有updateName为true时才更新Name列
```

### 7.6 拼接SQL片段

```csharp
// 使用SqlFunc进行更复杂的更新
db.Updateable<Student>()
  .SetColumns(s => s.UpdateTime == SqlFunc.GetDate()) // 使用数据库函数
  .Where(s => s.Id == 1)
  .ExecuteCommand();
// 生成SQL: UPDATE Student SET UpdateTime = GETDATE() WHERE Id=1
```

### 7.7 SetColumns与实体混合使用

```csharp
// 先传入实体，再用SetColumns覆盖某些字段
db.Updateable(student)
  .SetColumns(s => s.UpdateTime == DateTime.Now) // 强制设置更新时间
  .ExecuteCommand();
```

## 8. 批量更新

### 8.1 列表批量更新

传入一个实体列表，SqlSugar 会自动生成批量更新的 SQL：

```csharp
// 批量更新（列表）
var students = new List<Student>
{
    new Student { Id = 1, Name = "张三", Age = 25 },
    new Student { Id = 2, Name = "李四", Age = 30 },
    new Student { Id = 3, Name = "王五", Age = 28 }
};

db.Updateable(students).ExecuteCommand();
```

### 8.2 分页批量更新

当数据量较大时，建议使用分页方式避免一次生成过长的 SQL：

```csharp
// 分页批量更新，每次更新500条
db.Updateable(students)
  .PageSize(500)
  .ExecuteCommand();
```

### 8.3 批量更新指定列

```csharp
// 批量更新时只更新指定列
db.Updateable(students)
  .UpdateColumns(s => new { s.Name, s.Age })
  .PageSize(500)
  .ExecuteCommand();
```

### 8.4 高性能批量更新（BulkUpdate）

对于大量数据的更新，SqlSugar 提供了 `BulkUpdate` 方法：

```csharp
// 使用BulkUpdate进行高性能批量更新
// 内部使用数据库特有的批量操作，性能远超逐条更新
db.Fastest<Student>().BulkUpdate(students);
```

### 8.5 BulkUpdate指定列

```csharp
// BulkUpdate指定更新列
db.Fastest<Student>()
  .BulkUpdate(students, new string[] { "Name", "Age" });
```

### 8.6 批量更新性能对比

| 方式 | 1000条耗时 | 10000条耗时 | 适用场景 |
|------|-----------|------------|---------|
| `Updateable(list).ExecuteCommand()` | ~500ms | ~5s | 小批量更新 |
| `Updateable(list).PageSize(500)` | ~600ms | ~3s | 中等批量 |
| `Fastest<T>().BulkUpdate()` | ~100ms | ~500ms | 大批量更新 |

### 8.7 使用Storageable批量更新

`Storageable` 可以智能判断数据是插入还是更新：

```csharp
// 存在则更新，不存在则插入
db.Storageable(students)
  .ExecuteCommand();
```

```csharp
// 自定义判断条件
db.Storageable(students)
  .SplitUpdate(s => s.Any(a => a.Id == s.Item.Id))  // 存在则更新
  .SplitInsert(s => !s.Any())                        // 不存在则插入
  .ExecuteCommand();
```

## 9. 乐观锁更新

### 9.1 什么是乐观锁

乐观锁是一种并发控制机制，它假设并发冲突很少发生。在更新时检查数据是否被其他事务修改过，如果被修改则更新失败，避免覆盖他人的更改。

### 9.2 配置乐观锁字段

```csharp
public class Order
{
    [SugarColumn(IsPrimaryKey = true, IsIdentity = true)]
    public int Id { get; set; }

    public string OrderNo { get; set; }
    public decimal Amount { get; set; }
    public string Status { get; set; }

    // 乐观锁版本号字段
    [SugarColumn(IsEnableUpdateVersionValidation = true)]
    public long Version { get; set; }
}
```

### 9.3 使用乐观锁更新

```csharp
// 查询数据（会包含当前版本号）
var order = db.Queryable<Order>().InSingle(1);

// 修改数据
order.Amount = 200m;

// 更新时自动检查版本号
// 如果版本号与数据库中的不一致，更新将失败（返回0行受影响）
try
{
    var result = db.Updateable(order)
                   .ExecuteCommand();
    if (result > 0)
    {
        Console.WriteLine("更新成功，版本号已自动递增");
    }
}
catch (VersionExceptions ex)
{
    Console.WriteLine($"乐观锁冲突：{ex.Message}");
    // 处理冲突：重新查询并更新
}
```

### 9.4 乐观锁工作原理

```
用户A查询: SELECT * FROM Order WHERE Id=1  → Version=1
用户B查询: SELECT * FROM Order WHERE Id=1  → Version=1

用户A更新: UPDATE Order SET Amount=200, Version=2 WHERE Id=1 AND Version=1  → 成功
用户B更新: UPDATE Order SET Amount=300, Version=2 WHERE Id=1 AND Version=1  → 失败（Version已变为2）
```

### 9.5 时间戳版本号

除了数字版本号，SqlSugar 也支持时间戳类型的乐观锁：

```csharp
public class Product
{
    [SugarColumn(IsPrimaryKey = true)]
    public int Id { get; set; }

    public string Name { get; set; }
    public decimal Price { get; set; }

    // 使用DateTime作为版本号
    [SugarColumn(IsEnableUpdateVersionValidation = true)]
    public DateTime UpdateVersion { get; set; }
}
```

### 9.6 批量更新的乐观锁

```csharp
// 批量更新也支持乐观锁
var orders = db.Queryable<Order>().ToList();
foreach (var order in orders)
{
    order.Amount += 10;
}

try
{
    db.Updateable(orders).ExecuteCommand();
}
catch (VersionExceptions ex)
{
    Console.WriteLine($"批量更新存在乐观锁冲突：{ex.Message}");
}
```

## 10. 空值列处理

### 10.1 默认行为

SqlSugar 默认会更新所有列，包括值为 `null` 的列。这在某些场景下可能不是你期望的行为。

```csharp
var student = new Student
{
    Id = 1,
    Name = "张三",
    Email = null  // 这个null值也会被更新到数据库
};

// 默认行为：Email列会被设置为NULL
db.Updateable(student).ExecuteCommand();
// SQL: UPDATE Student SET Name='张三', Email=NULL WHERE Id=1
```

### 10.2 忽略空值列

```csharp
// 忽略null值的列，不更新Email
db.Updateable(student)
  .IgnoreColumns(ignoreAllNullColumns: true)
  .ExecuteCommand();
// SQL: UPDATE Student SET Name='张三' WHERE Id=1（不包含Email）
```

### 10.3 部分列允许空值更新

当你想忽略大部分空值列，但某些列需要允许设置为 `null` 时：

```csharp
// 忽略空值列，但Email列允许为null
db.Updateable(student)
  .IgnoreColumns(ignoreAllNullColumns: true)
  .UpdateColumns(s => s.Email) // 强制包含Email列
  .ExecuteCommand();
```

### 10.4 使用SetColumns处理空值

```csharp
// 明确将某列设置为null
db.Updateable<Student>()
  .SetColumns(s => s.Email == null)
  .Where(s => s.Id == 1)
  .ExecuteCommand();
// SQL: UPDATE Student SET Email=NULL WHERE Id=1
```

### 10.5 空值与默认值的区别

```csharp
// 区分null和默认值
public class Student
{
    public int Id { get; set; }
    public string Name { get; set; }

    // int类型默认值为0，不是null
    public int Age { get; set; }  // 默认为0

    // 可空类型才能区分是否被赋值
    public int? Score { get; set; }  // 默认为null
}

// 建议：对于需要区分"未赋值"和"零值"的场景，使用可空类型
```

### 10.6 全局配置空值处理

```csharp
// 在创建SqlSugarClient时全局配置
var db = new SqlSugarClient(new ConnectionConfig
{
    ConnectionString = connectionString,
    DbType = DbType.SqlServer,
    IsAutoCloseConnection = true,
    MoreSettings = new ConnMoreSettings
    {
        // 全局忽略null值列更新
        IsAutoRemoveDataCache = true
    }
});
```

## 11. 导航更新SubUpdateable

### 11.1 什么是导航更新

导航更新允许你在更新主表数据的同时，自动更新关联的子表数据。这在父子关系的数据操作中非常有用。

### 11.2 实体定义

```csharp
// 订单实体（主表）
public class Order
{
    [SugarColumn(IsPrimaryKey = true, IsIdentity = true)]
    public int Id { get; set; }
    public string OrderNo { get; set; }
    public decimal TotalAmount { get; set; }
    public DateTime UpdateTime { get; set; }

    // 导航属性：一对多
    [Navigate(NavigateType.OneToMany, nameof(OrderDetail.OrderId))]
    public List<OrderDetail> Details { get; set; }
}

// 订单明细实体（子表）
public class OrderDetail
{
    [SugarColumn(IsPrimaryKey = true, IsIdentity = true)]
    public int Id { get; set; }
    public int OrderId { get; set; }
    public string ProductName { get; set; }
    public int Quantity { get; set; }
    public decimal Price { get; set; }
}
```

### 11.3 导航更新操作

```csharp
// 查询订单及其明细
var order = db.Queryable<Order>()
              .Includes(o => o.Details)
              .InSingle(1);

// 修改订单信息
order.TotalAmount = 500m;
order.UpdateTime = DateTime.Now;

// 修改明细
order.Details[0].Quantity = 10;
order.Details[0].Price = 50m;

// 导航更新：同时更新订单和明细
db.UpdateNav(order)
  .Include(o => o.Details)
  .ExecuteCommand();
```

### 11.4 导航更新的模式

```csharp
// 模式1：更新主表和子表（默认）
db.UpdateNav(order)
  .Include(o => o.Details)
  .ExecuteCommand();

// 模式2：只更新子表，不更新主表
db.UpdateNav(order)
  .Include(o => o.Details, new UpdateNavOptions
  {
      ManyToManyIsUpdateA = false  // 不更新主表
  })
  .ExecuteCommand();
```

### 11.5 多级导航更新

```csharp
// 三级导航更新
// School -> Classes -> Students
db.UpdateNav(school)
  .Include(s => s.Classes)
  .ThenInclude(c => c.Students)
  .ExecuteCommand();
```

### 11.6 导航更新与删除子表

```csharp
// 导航更新时，如果子表列表中缺少了某些记录，
// 可以配置自动删除不在列表中的子表记录
db.UpdateNav(order)
  .Include(o => o.Details, new UpdateNavOptions
  {
      OneToManyInsertOrUpdate = true  // 子表存在则更新，不存在则插入
  })
  .ExecuteCommand();
```

## 12. UpdateRange与范围更新

### 12.1 基本范围更新

`UpdateRange` 用于批量更新一个列表中的所有实体：

```csharp
// UpdateRange是Updateable(list)的简化写法
var students = new List<Student>
{
    new Student { Id = 1, Name = "张三更新", Age = 26 },
    new Student { Id = 2, Name = "李四更新", Age = 31 },
    new Student { Id = 3, Name = "王五更新", Age = 29 }
};

db.UpdateRange(students);
// 等价于 db.Updateable(students).ExecuteCommand();
```

### 12.2 带条件的范围更新

```csharp
// 使用Where对整个表进行条件更新
db.Updateable<Student>()
  .SetColumns(s => s.Status == "已毕业")
  .Where(s => s.GraduationDate <= DateTime.Now)
  .ExecuteCommand();
```

### 12.3 子查询更新

```csharp
// 使用子查询更新
db.Updateable<Student>()
  .SetColumns(s => s.ClassName == SqlFunc.Subqueryable<Class>()
                                         .Where(c => c.Id == s.ClassId)
                                         .Select(c => c.Name))
  .Where(s => s.ClassId > 0)
  .ExecuteCommand();
// SQL: UPDATE Student SET ClassName = (SELECT Name FROM Class WHERE Id = Student.ClassId) WHERE ClassId > 0
```

### 12.4 跨表更新

```csharp
// 使用Join方式跨表更新
db.Updateable<Student>()
  .InnerJoin<Class>((stu, cls) => stu.ClassId == cls.Id)
  .SetColumns((stu, cls) => new Student
  {
      ClassName = cls.Name
  })
  .ExecuteCommand();
```

### 12.5 使用SQL语句更新

```csharp
// 执行原生SQL更新
db.Ado.ExecuteCommand(
    "UPDATE Student SET Name=@name WHERE Id=@id",
    new { name = "张三", id = 1 }
);

// 或使用SqlQueryable
db.Ado.ExecuteCommand(
    "UPDATE Student SET Age = Age + 1 WHERE ClassId = @classId",
    new SugarParameter("@classId", 1)
);
```

## 13. 性能优化与最佳实践

### 13.1 性能优化建议

| 建议 | 说明 |
|------|------|
| 使用 `UpdateColumns` 指定更新列 | 减少不必要的列更新 |
| 使用 `PageSize` 分批更新 | 避免生成超长SQL |
| 使用 `BulkUpdate` 大批量更新 | 性能最佳 |
| 使用 `SetColumns` 表达式更新 | 不需要查询实体，直接更新 |
| 避免循环中逐条更新 | 改用批量更新方式 |

### 13.2 常见反模式

```csharp
// ❌ 反模式1：循环中逐条更新
foreach (var student in students)
{
    db.Updateable(student).ExecuteCommand(); // 每次循环都执行一次SQL
}

// ✅ 正确做法：批量更新
db.Updateable(students).ExecuteCommand();
```

```csharp
// ❌ 反模式2：更新所有列
db.Updateable(student).ExecuteCommand(); // 更新了所有列

// ✅ 正确做法：只更新需要变化的列
db.Updateable(student)
  .UpdateColumns(s => new { s.Name, s.Age })
  .ExecuteCommand();
```

```csharp
// ❌ 反模式3：先查后改（简单场景不需要）
var student = db.Queryable<Student>().InSingle(1);
student.Name = "新名字";
db.Updateable(student).ExecuteCommand(); // 多了一次查询

// ✅ 正确做法：直接使用SetColumns
db.Updateable<Student>()
  .SetColumns(s => s.Name == "新名字")
  .Where(s => s.Id == 1)
  .ExecuteCommand();
```

### 13.3 更新操作对照表

| 场景 | 推荐方式 | 说明 |
|------|---------|------|
| 更新单个实体全部字段 | `Updateable(entity)` | 自动以主键为条件 |
| 更新实体部分字段 | `Updateable(entity).UpdateColumns(...)` | 指定更新列 |
| 无实体条件更新 | `SetColumns(...).Where(...)` | 无需查询实体 |
| 批量更新（小量） | `Updateable(list)` | 自动参数化 |
| 批量更新（中量） | `Updateable(list).PageSize(500)` | 分批执行 |
| 批量更新（大量） | `Fastest<T>().BulkUpdate()` | 性能最佳 |
| 存在更新不存在插入 | `Storageable(list)` | 智能合并 |
| 级联更新 | `UpdateNav(entity).Include(...)` | 自动处理关联 |
| 无实体无类更新 | 字典/匿名对象 + `.AS("表名")` | 灵活场景 |
| 带乐观锁的更新 | 实体配置 `IsEnableUpdateVersionValidation` | 并发安全 |

### 13.4 日志与调试

```csharp
// 打印更新SQL
db.Aop.OnLogExecuting = (sql, pars) =>
{
    Console.WriteLine($"SQL: {sql}");
    Console.WriteLine($"参数: {string.Join(", ", pars.Select(p => $"{p.ParameterName}={p.Value}"))}");
};
```

### 13.5 安全注意事项

> **警告**：更新操作是一个敏感操作，错误的更新条件可能导致大量数据被错误修改。建议：
>
> 1. 始终在更新前确认条件的正确性
> 2. 在重要业务中使用事务
> 3. 定期备份数据
> 4. 使用乐观锁防止并发冲突
> 5. 在生产环境开启 SQL 日志记录

## 14. 本章小结

本章全面介绍了 SqlSugar 的更新数据操作：

- **Updateable 概述**：链式调用、默认以主键为条件、多种执行方法
- **更新实体对象**：按主键更新、先查后改、异步更新
- **指定更新列**：`UpdateColumns` 通过 Lambda 或字符串指定需要更新的列
- **忽略更新列**：`IgnoreColumns` 排除不需要更新的列，支持特性标记
- **条件更新**：`Where` 自定义更新条件，`WhereColumns` 使用非主键列作为条件
- **无实体更新**：字典、匿名对象、DataTable 等无需定义实体的更新方式
- **表达式更新**：`SetColumns` 直接设置列值，支持运算、条件表达式和 SQL 函数
- **批量更新**：列表更新、分页更新、`BulkUpdate` 高性能更新、`Storageable` 智能合并
- **乐观锁**：版本号机制防止并发冲突
- **空值处理**：`IgnoreNullColumns` 忽略空值列，`SetColumns` 明确设置空值
- **导航更新**：`UpdateNav` 自动处理主子表关联更新
- **性能优化**：避免循环更新、使用批量操作、只更新变化列

掌握这些更新操作后，你可以高效、安全地修改数据库中的数据，应对从简单的单条更新到复杂的批量更新、关联更新等各种场景。
