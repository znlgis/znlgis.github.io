## 1. 分页查询概述

在实际业务系统中，数据表往往包含成千上万甚至上百万条记录。如果一次性将所有数据查询并返回给前端，不仅会消耗大量的内存和网络带宽，还会导致页面加载缓慢，严重影响用户体验。因此，**分页查询** 是几乎所有数据驱动应用的必备功能。

### 1.1 分页的基本原理

分页的核心思想是将大量数据按照固定的"页大小（PageSize）"拆分成多个"页"，每次只查询和返回一页的数据。

```
┌───────────────────────────────────────────────────┐
│                    总数据集（1000条）                │
├──────────┬──────────┬──────────┬──────────┬────────┤
│  第1页    │  第2页    │  第3页    │  第4页    │ ...   │
│ 1-20条   │ 21-40条  │ 41-60条  │ 61-80条  │       │
│ PageSize │ PageSize │ PageSize │ PageSize │       │
│   = 20   │   = 20   │   = 20   │   = 20   │       │
└──────────┴──────────┴──────────┴──────────┴────────┘
```

### 1.2 分页方式对比

| 分页方式 | SQL 实现 | 适用场景 | 优缺点 |
|---------|---------|---------|--------|
| OFFSET/FETCH | `OFFSET n ROWS FETCH NEXT m ROWS ONLY` | SQL Server 2012+、PostgreSQL | 标准 SQL，跳页方便 |
| ROW_NUMBER | `ROW_NUMBER() OVER(ORDER BY ...)` | SQL Server 所有版本 | 兼容性好，性能中等 |
| LIMIT/OFFSET | `LIMIT m OFFSET n` | MySQL、SQLite、PostgreSQL | 语法简单，深页性能差 |
| 游标分页 | `WHERE Id > @lastId LIMIT m` | 大数据量顺序翻页 | 性能最优，不支持跳页 |

> SqlSugar 会根据不同的数据库类型自动生成对应的分页 SQL，开发者无需关心底层实现。

### 1.3 SqlSugar 分页 API 概览

SqlSugar 提供了多种分页方式：

| 方法 | 说明 | 返回值 |
|------|------|--------|
| `ToPageList(pageIndex, pageSize)` | 基础分页 | `List<T>` |
| `ToPageList(pageIndex, pageSize, ref totalCount)` | 分页 + 总数 | `List<T>` |
| `ToPageListAsync(pageIndex, pageSize, refAsync)` | 异步分页 | `Task<List<T>>` |
| `ToOffsetPage(pageIndex, pageSize)` | 偏移量分页 | `List<T>` |
| `ToOffsetPage(pageIndex, pageSize, ref totalCount)` | 偏移量分页 + 总数 | `List<T>` |

## 2. 基础分页：ToPageList

### 2.1 基本用法

`ToPageList` 是 SqlSugar 最常用的分页方法，接受页码和每页大小两个参数：

```csharp
// 查询第1页，每页20条
var list = db.Queryable<Student>()
    .ToPageList(1, 20);

// 查询第3页，每页10条
var list2 = db.Queryable<Student>()
    .OrderBy(s => s.Id)
    .ToPageList(3, 10);
```

> **注意**：`pageIndex` 从 **1** 开始，不是从 0 开始。

### 2.2 生成的 SQL

以 SQL Server 为例，`ToPageList(2, 10)` 生成的 SQL 大致如下：

```sql
SELECT * FROM [Student] ORDER BY [Id] ASC
OFFSET 10 ROWS FETCH NEXT 10 ROWS ONLY
```

以 MySQL 为例：

```sql
SELECT * FROM `Student` ORDER BY `Id` ASC
LIMIT 10 OFFSET 10
```

### 2.3 配合条件查询

分页通常与条件查询结合使用：

```csharp
var list = db.Queryable<Student>()
    .Where(s => s.Age > 18)
    .Where(s => s.IsActive == true)
    .OrderBy(s => s.CreateTime, OrderByType.Desc)
    .ToPageList(1, 20);
```

### 2.4 配合 Select 投影

```csharp
var list = db.Queryable<Student>()
    .Where(s => s.IsActive == true)
    .Select(s => new StudentDto
    {
        Id = s.Id,
        Name = s.Name,
        ClassName = s.ClassName
    })
    .ToPageList(1, 20);
```

## 3. 带总数的分页查询

### 3.1 使用 ref 获取总数

在实际分页场景中，前端不仅需要当前页的数据，还需要知道总记录数以计算总页数和显示分页控件：

```csharp
int totalCount = 0;
var list = db.Queryable<Student>()
    .Where(s => s.Age > 18)
    .OrderBy(s => s.Id)
    .ToPageList(1, 20, ref totalCount);

Console.WriteLine($"总记录数：{totalCount}");
Console.WriteLine($"总页数：{Math.Ceiling((double)totalCount / 20)}");
Console.WriteLine($"当前页数据量：{list.Count}");
```

### 3.2 生成的 SQL

带总数的分页查询会生成两条 SQL：

```sql
-- 第一条：查询总数
SELECT COUNT(1) FROM [Student] WHERE [Age] > 18

-- 第二条：查询当前页数据
SELECT * FROM [Student] WHERE [Age] > 18 ORDER BY [Id] ASC
OFFSET 0 ROWS FETCH NEXT 20 ROWS ONLY
```

### 3.3 性能考虑

当数据量非常大时，`COUNT` 查询可能会成为性能瓶颈。可以考虑以下优化策略：

```csharp
// 策略1：仅在第一页查询时获取总数，后续页使用缓存的总数
int totalCount = 0;
if (pageIndex == 1)
{
    var list = db.Queryable<Student>()
        .Where(s => s.Age > 18)
        .ToPageList(pageIndex, pageSize, ref totalCount);
    
    // 缓存 totalCount
    CacheHelper.Set("student_total", totalCount, TimeSpan.FromMinutes(5));
}
else
{
    totalCount = CacheHelper.Get<int>("student_total");
    var list = db.Queryable<Student>()
        .Where(s => s.Age > 18)
        .ToPageList(pageIndex, pageSize);
}
```

```csharp
// 策略2：使用估算总数（适用于不需要精确总数的场景）
// 先查询前 N+1 条判断是否还有更多
var list = db.Queryable<Student>()
    .Where(s => s.Age > 18)
    .Take(pageSize + 1)
    .Skip((pageIndex - 1) * pageSize)
    .ToList();

bool hasMore = list.Count > pageSize;
if (hasMore)
{
    list = list.Take(pageSize).ToList();
}
```

## 4. 异步分页查询

### 4.1 基本异步分页

在 ASP.NET Core 等异步编程模型中，建议使用异步分页方法：

```csharp
// 基础异步分页
var list = await db.Queryable<Student>()
    .OrderBy(s => s.Id)
    .ToPageListAsync(1, 20);
```

### 4.2 异步分页带总数

异步分页带总数需要使用 `RefAsync` 类型：

```csharp
RefAsync<int> totalCount = 0;
var list = await db.Queryable<Student>()
    .Where(s => s.Age > 18)
    .OrderBy(s => s.Id)
    .ToPageListAsync(1, 20, totalCount);

Console.WriteLine($"总记录数：{totalCount.Value}");
```

### 4.3 在 Controller 中使用

```csharp
[ApiController]
[Route("api/[controller]")]
public class StudentController : ControllerBase
{
    private readonly ISqlSugarClient _db;

    public StudentController(ISqlSugarClient db)
    {
        _db = db;
    }

    [HttpGet("list")]
    public async Task<IActionResult> GetList(int pageIndex = 1, int pageSize = 20)
    {
        RefAsync<int> total = 0;
        var list = await _db.Queryable<Student>()
            .OrderBy(s => s.CreateTime, OrderByType.Desc)
            .ToPageListAsync(pageIndex, pageSize, total);

        return Ok(new
        {
            Code = 200,
            Data = list,
            Total = total.Value,
            PageIndex = pageIndex,
            PageSize = pageSize,
            TotalPages = (int)Math.Ceiling((double)total.Value / pageSize)
        });
    }
}
```

## 5. 偏移量分页：ToOffsetPage

### 5.1 ToOffsetPage 介绍

`ToOffsetPage` 与 `ToPageList` 类似，但在某些数据库上会生成不同的分页 SQL。它使用标准的 `OFFSET...FETCH` 语法：

```csharp
// 基本用法
var list = db.Queryable<Student>()
    .OrderBy(s => s.Id)
    .ToOffsetPage(1, 20);

// 带总数
int totalCount = 0;
var list2 = db.Queryable<Student>()
    .OrderBy(s => s.Id)
    .ToOffsetPage(1, 20, ref totalCount);
```

### 5.2 ToPageList 与 ToOffsetPage 的区别

| 特性 | ToPageList | ToOffsetPage |
|------|-----------|-------------|
| 默认分页方式 | 根据数据库类型自动选择 | 强制使用 OFFSET/FETCH |
| SQL Server | 使用 ROW_NUMBER 或 OFFSET | 使用 OFFSET/FETCH |
| MySQL | 使用 LIMIT/OFFSET | 使用 LIMIT/OFFSET |
| 性能 | 因数据库而异 | 在 SQL Server 2012+ 上性能更优 |

### 5.3 异步偏移量分页

```csharp
RefAsync<int> total = 0;
var list = await db.Queryable<Student>()
    .OrderBy(s => s.Id)
    .ToOffsetPageAsync(1, 20, total);
```

## 6. 自定义分页封装

### 6.1 分页请求模型

在实际项目中，通常需要封装统一的分页请求和响应模型：

```csharp
/// <summary>
/// 分页请求基类
/// </summary>
public class PageRequest
{
    private int _pageIndex = 1;
    private int _pageSize = 20;

    /// <summary>
    /// 页码（从1开始）
    /// </summary>
    public int PageIndex
    {
        get => _pageIndex;
        set => _pageIndex = value < 1 ? 1 : value;
    }

    /// <summary>
    /// 每页大小（最大100）
    /// </summary>
    public int PageSize
    {
        get => _pageSize;
        set => _pageSize = value > 100 ? 100 : (value < 1 ? 1 : value);
    }

    /// <summary>
    /// 排序字段
    /// </summary>
    public string OrderBy { get; set; }

    /// <summary>
    /// 是否降序
    /// </summary>
    public bool IsDesc { get; set; } = true;
}
```

### 6.2 分页响应模型

```csharp
/// <summary>
/// 分页响应基类
/// </summary>
public class PageResult<T>
{
    /// <summary>
    /// 当前页数据
    /// </summary>
    public List<T> Items { get; set; }

    /// <summary>
    /// 总记录数
    /// </summary>
    public int TotalCount { get; set; }

    /// <summary>
    /// 当前页码
    /// </summary>
    public int PageIndex { get; set; }

    /// <summary>
    /// 每页大小
    /// </summary>
    public int PageSize { get; set; }

    /// <summary>
    /// 总页数
    /// </summary>
    public int TotalPages => (int)Math.Ceiling((double)TotalCount / PageSize);

    /// <summary>
    /// 是否有上一页
    /// </summary>
    public bool HasPrevPage => PageIndex > 1;

    /// <summary>
    /// 是否有下一页
    /// </summary>
    public bool HasNextPage => PageIndex < TotalPages;
}
```

### 6.3 分页扩展方法

```csharp
/// <summary>
/// SqlSugar 分页扩展方法
/// </summary>
public static class SqlSugarPageExtensions
{
    /// <summary>
    /// 同步分页查询
    /// </summary>
    public static PageResult<T> ToPageResult<T>(
        this ISugarQueryable<T> queryable,
        PageRequest request)
    {
        int totalCount = 0;
        var list = queryable
            .ToPageList(request.PageIndex, request.PageSize, ref totalCount);

        return new PageResult<T>
        {
            Items = list,
            TotalCount = totalCount,
            PageIndex = request.PageIndex,
            PageSize = request.PageSize
        };
    }

    /// <summary>
    /// 异步分页查询
    /// </summary>
    public static async Task<PageResult<T>> ToPageResultAsync<T>(
        this ISugarQueryable<T> queryable,
        PageRequest request)
    {
        RefAsync<int> totalCount = 0;
        var list = await queryable
            .ToPageListAsync(request.PageIndex, request.PageSize, totalCount);

        return new PageResult<T>
        {
            Items = list,
            TotalCount = totalCount.Value,
            PageIndex = request.PageIndex,
            PageSize = request.PageSize
        };
    }
}
```

### 6.4 使用封装后的分页

```csharp

[HttpPost("search")]
public async Task<IActionResult> Search([FromBody] StudentSearchRequest request)
```

## 7. 动态表达式概述

在实际开发中，查询条件往往不是固定的。用户可能根据不同的搜索条件动态组合查询，例如：

- 按姓名搜索
- 按年龄范围筛选
- 按状态过滤
- 按创建时间排序

这些条件可能存在也可能不存在，需要根据用户的输入 **动态构建** 查询表达式。

### 7.1 传统方式的问题

```csharp
// ❌ 传统拼接 SQL 方式 —— 存在 SQL 注入风险
string sql = "SELECT * FROM Student WHERE 1=1";
if (!string.IsNullOrEmpty(name))
    sql += $" AND Name LIKE '%{name}%'";  // 危险！SQL注入
if (age > 0)
    sql += $" AND Age = {age}";
```

### 7.2 SqlSugar 动态查询方案

SqlSugar 提供了多种安全且优雅的动态查询方案：

| 方案 | 说明 | 适用场景 |
|------|------|---------|
| `WhereIF` | 条件满足时才添加 Where | 简单条件判断 |
| `Expressionable` | 表达式树构建器 | 复杂动态条件组合 |
| `SqlFunc` | SQL 函数封装 | 需要使用数据库函数 |
| 动态 `OrderBy` | 动态排序 | 用户自定义排序字段 |

## 8. Expressionable 动态条件构建

### 8.1 基本概念

`Expressionable` 是 SqlSugar 提供的一个表达式构建器，可以动态地组合多个查询条件：

```csharp
// 创建表达式构建器
var exp = Expressionable.Create<Student>();

// 动态添加条件
exp.And(s => s.IsActive == true);

if (!string.IsNullOrEmpty(name))
{
    exp.And(s => s.Name.Contains(name));
}

if (age > 0)
{
    exp.And(s => s.Age == age);
}

// 使用构建的表达式
var list = db.Queryable<Student>()
    .Where(exp.ToExpression())
    .ToList();
```

### 8.2 链式调用

`Expressionable` 支持链式调用，使代码更加简洁：

```csharp
var list = db.Queryable<Student>()
    .Where(
        Expressionable.Create<Student>()
            .And(s => s.IsActive == true)
            .AndIF(!string.IsNullOrEmpty(name), s => s.Name.Contains(name))
            .AndIF(minAge > 0, s => s.Age >= minAge)
            .AndIF(maxAge > 0, s => s.Age <= maxAge)
            .ToExpression()
    )
    .ToList();
```

### 8.3 OrIF 条件

`OrIF` 方法在条件满足时添加 OR 条件：

```csharp
var exp = Expressionable.Create<Student>();

// 搜索关键字：在姓名或邮箱中匹配
if (!string.IsNullOrEmpty(keyword))
{
    exp.Or(s => s.Name.Contains(keyword));
    exp.Or(s => s.Email.Contains(keyword));
}

// 基础条件始终生效
exp.And(s => s.IsActive == true);

var list = db.Queryable<Student>()
    .Where(exp.ToExpression())
    .ToList();
```

### 8.4 嵌套条件

对于复杂的嵌套条件（如 `A AND (B OR C)`），可以使用多个 Expressionable 组合：

```csharp
// 目标 SQL：WHERE IsActive = 1 AND (Name LIKE '%张%' OR Email LIKE '%zhang%')
var innerExp = Expressionable.Create<Student>()
    .Or(s => s.Name.Contains("张"))
    .Or(s => s.Email.Contains("zhang"))
    .ToExpression();

var list = db.Queryable<Student>()
    .Where(s => s.IsActive == true)
    .Where(innerExp)
    .ToList();
```

## 9. 组合条件：And 与 Or

### 9.1 And 条件

`And` 方法始终添加 AND 条件：

```csharp
var exp = Expressionable.Create<Student>();

exp.And(s => s.IsActive == true);
exp.And(s => s.Age >= 18);
exp.And(s => s.SchoolId == 1);

// 生成 SQL：WHERE IsActive = 1 AND Age >= 18 AND SchoolId = 1
var list = db.Queryable<Student>()
    .Where(exp.ToExpression())
    .ToList();
```

### 9.2 Or 条件

`Or` 方法添加 OR 条件：

```csharp
var exp = Expressionable.Create<Student>();

exp.Or(s => s.Name == "张三");
exp.Or(s => s.Name == "李四");
exp.Or(s => s.Name == "王五");

// 生成 SQL：WHERE Name = '张三' OR Name = '李四' OR Name = '王五'
var list = db.Queryable<Student>()
    .Where(exp.ToExpression())
    .ToList();
```

### 9.3 And 与 Or 混合使用

```csharp
var exp = Expressionable.Create<Student>();

// 基础条件（AND）
exp.And(s => s.IsActive == true);
exp.And(s => s.SchoolId == 1);

// 搜索条件（OR）—— 使用内部表达式
var searchExp = Expressionable.Create<Student>()
    .Or(s => s.Name.Contains(keyword))
    .Or(s => s.Email.Contains(keyword))
    .Or(s => s.Phone.Contains(keyword))
    .ToExpression();

// 组合：IsActive AND SchoolId = 1 AND (Name LIKE OR Email LIKE OR Phone LIKE)
var list = db.Queryable<Student>()
    .Where(exp.ToExpression())
    .Where(searchExp)
    .ToList();
```

### 9.4 实际场景：多条件搜索

```csharp
public List<Student> SearchStudents(StudentSearchDto dto)
{
    var exp = Expressionable.Create<Student>();

    // 状态过滤
    exp.And(s => s.IsDeleted == false);

    // 姓名模糊搜索
    exp.AndIF(!string.IsNullOrEmpty(dto.Name),
        s => s.Name.Contains(dto.Name));

    // 年龄范围
    exp.AndIF(dto.MinAge.HasValue,
        s => s.Age >= dto.MinAge.Value);
    exp.AndIF(dto.MaxAge.HasValue,
        s => s.Age <= dto.MaxAge.Value);

    // 班级筛选（多选）
    exp.AndIF(dto.ClassIds != null && dto.ClassIds.Any(),
        s => dto.ClassIds.Contains(s.ClassId));

    // 注册时间范围
    exp.AndIF(dto.StartDate.HasValue,
        s => s.CreateTime >= dto.StartDate.Value);
    exp.AndIF(dto.EndDate.HasValue,
        s => s.CreateTime <= dto.EndDate.Value);

    // 关键字搜索（姓名或邮箱）
    if (!string.IsNullOrEmpty(dto.Keyword))
    {
        var keywordExp = Expressionable.Create<Student>()
            .Or(s => s.Name.Contains(dto.Keyword))
            .Or(s => s.Email.Contains(dto.Keyword))
            .ToExpression();
        
        return db.Queryable<Student>()
            .Where(exp.ToExpression())
            .Where(keywordExp)
            .OrderBy(s => s.CreateTime, OrderByType.Desc)
            .ToList();
    }

    return db.Queryable<Student>()
        .Where(exp.ToExpression())
        .OrderBy(s => s.CreateTime, OrderByType.Desc)
        .ToList();
}
```

## 10. WhereIF 条件查询

### 10.1 基本用法

`WhereIF` 是 SqlSugar 中最简洁的动态条件构建方式。当第一个参数为 `true` 时，才会添加对应的 Where 条件：

```csharp
string name = "张三";
int? age = null;
bool? isActive = true;

var list = db.Queryable<Student>()
    .WhereIF(!string.IsNullOrEmpty(name), s => s.Name.Contains(name))
    .WhereIF(age.HasValue, s => s.Age == age.Value)
    .WhereIF(isActive.HasValue, s => s.IsActive == isActive.Value)
    .ToList();

// 由于 age 为 null，实际生成的 SQL 只包含 Name 和 IsActive 条件：
// SELECT * FROM Student WHERE Name LIKE '%张三%' AND IsActive = 1
```

### 10.2 多条件组合

```csharp
public async Task<PageResult<StudentDto>> GetStudentList(StudentQueryDto query)
{
    RefAsync<int> total = 0;

    var list = await db.Queryable<Student>()
        // 基础条件
        .Where(s => s.IsDeleted == false)
        // 动态条件
        .WhereIF(!string.IsNullOrEmpty(query.Name),
            s => s.Name.Contains(query.Name))
        .WhereIF(!string.IsNullOrEmpty(query.StudentNo),
            s => s.StudentNo == query.StudentNo)
        .WhereIF(query.ClassId > 0,
            s => s.ClassId == query.ClassId)
        .WhereIF(query.Gender.HasValue,
            s => s.Gender == query.Gender.Value)
        .WhereIF(query.MinScore.HasValue,
            s => s.Score >= query.MinScore.Value)
        .WhereIF(query.MaxScore.HasValue,
            s => s.Score <= query.MaxScore.Value)
        .WhereIF(query.StartDate.HasValue,
            s => s.CreateTime >= query.StartDate.Value)
        .WhereIF(query.EndDate.HasValue,
            s => s.CreateTime < query.EndDate.Value.AddDays(1))
        // 排序
        .OrderBy(s => s.CreateTime, OrderByType.Desc)
        // 投影
        .Select(s => new StudentDto
        {
            Id = s.Id,
            Name = s.Name,
            Age = s.Age,
            ClassName = s.ClassName
        })
        // 分页
        .ToPageListAsync(query.PageIndex, query.PageSize, total);

    return new PageResult<StudentDto>
    {
        Items = list,
        TotalCount = total.Value,
        PageIndex = query.PageIndex,
        PageSize = query.PageSize
    };
}
```

### 10.3 WhereIF 与 Expressionable 对比

| 特性 | WhereIF | Expressionable |
|------|---------|---------------|
| 语法简洁度 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ |
| 条件复杂度 | 简单 AND 条件 | 支持 AND/OR 嵌套 |
| 灵活性 | 中等 | 高 |
| 可读性 | 高 | 中等 |
| 推荐场景 | 简单筛选 | 复杂搜索逻辑 |

> **最佳实践**：简单的 AND 条件筛选使用 `WhereIF`，需要 OR 条件组合时使用 `Expressionable`。

### 11.3 安全的动态排序封装

```csharp
/// <summary>
/// 动态排序帮助类（防止 SQL 注入）
/// </summary>
public static class DynamicOrderHelper
{
    // 允许排序的字段白名单
    private static readonly Dictionary<string, string> AllowedFields = new()
    {
        { "id", "Id" },
        { "name", "Name" },
        { "age", "Age" },
        { "score", "Score" },
        { "createtime", "CreateTime" }
    };

    public static ISugarQueryable<T> ApplyOrder<T>(
        ISugarQueryable<T> queryable,
        string field,
        bool isDesc = false)
    {
        // 验证字段是否在白名单中
        if (string.IsNullOrEmpty(field) ||
            !AllowedFields.TryGetValue(field.ToLower(), out var safeField))
        {
            // 默认按 Id 降序
            return queryable.OrderBy("Id DESC");
        }

        var orderType = isDesc ? "DESC" : "ASC";
        return queryable.OrderBy($"{safeField} {orderType}");
    }
}

// 使用
var query = db.Queryable<Student>();
query = DynamicOrderHelper.ApplyOrder(query, request.SortField, request.IsDesc);
var list = query.ToPageList(request.PageIndex, request.PageSize);
```

### 11.4 多字段动态排序

```csharp
public class SortItem
{
    public string Field { get; set; }
    public bool IsDesc { get; set; }
}

public static ISugarQueryable<T> ApplyMultiOrder<T>(
    ISugarQueryable<T> queryable,
    List<SortItem> sorts)
{
    if (sorts == null || !sorts.Any())
    {
        return queryable.OrderBy("Id DESC");
    }

    var orderParts = new List<string>();
    foreach (var sort in sorts)
    {
        if (AllowedFields.TryGetValue(sort.Field.ToLower(), out var safeField))
        {
            orderParts.Add($"{safeField} {(sort.IsDesc ? "DESC" : "ASC")}");
        }
    }

    if (orderParts.Any())
    {
        return queryable.OrderBy(string.Join(", ", orderParts));
    }

    return queryable.OrderBy("Id DESC");
}
```

### 13.3 搜索服务实现

```csharp
public class StudentService
{
    private readonly ISqlSugarClient _db;

    public StudentService(ISqlSugarClient db)
    {
        _db = db;
    }

    public async Task<PageResult<StudentListDto>> SearchAsync(StudentSearchRequest request)
    {
        var query = _db.Queryable<Student>()
            // 基础条件：排除已删除
            .Where(s => s.IsDeleted == false)
            // 精确匹配
            .WhereIF(!string.IsNullOrEmpty(request.StudentNo),
                s => s.StudentNo == request.StudentNo)
            // 模糊搜索
            .WhereIF(!string.IsNullOrEmpty(request.Name),
                s => s.Name.Contains(request.Name))
            // 下拉选择
            .WhereIF(request.ClassId.HasValue && request.ClassId > 0,
                s => s.ClassId == request.ClassId.Value)
            // 范围查询
            .WhereIF(request.MinAge.HasValue,
                s => s.Age >= request.MinAge.Value)
            .WhereIF(request.MaxAge.HasValue,
                s => s.Age <= request.MaxAge.Value)
            // 状态筛选
            .WhereIF(request.Status.HasValue && request.Status == 1,
                s => s.IsActive == true)
            .WhereIF(request.Status.HasValue && request.Status == 2,
                s => s.IsActive == false)
            // 时间范围
            .WhereIF(request.StartDate.HasValue,
                s => s.CreateTime >= request.StartDate.Value)
            .WhereIF(request.EndDate.HasValue,
                s => s.CreateTime < request.EndDate.Value.AddDays(1));

        // 全局关键字搜索（OR 条件）
        if (!string.IsNullOrEmpty(request.Keyword))
        {
            query = query.Where(
                Expressionable.Create<Student>()
                    .Or(s => s.Name.Contains(request.Keyword))
                    .Or(s => s.StudentNo.Contains(request.Keyword))
                    .Or(s => s.Email.Contains(request.Keyword))
                    .Or(s => s.Phone.Contains(request.Keyword))
                    .ToExpression()
            );
        }

        // 动态排序
        query = ApplySort(query, request);

        // 分页查询
        return await query
            .Select(s => new StudentListDto
            {
                Id = s.Id,
                Name = s.Name,
                StudentNo = s.StudentNo,
                Age = s.Age,
                ClassName = s.ClassName,
                IsActive = s.IsActive,
                CreateTime = s.CreateTime
            })
            .ToPageResultAsync(request);
    }

    private ISugarQueryable<Student> ApplySort(
        ISugarQueryable<Student> query,
        StudentSearchRequest request)
    {
        return request.OrderBy?.ToLower() switch
        {
            "name" => query.OrderBy(s => s.Name,
                request.IsDesc ? OrderByType.Desc : OrderByType.Asc),
            "age" => query.OrderBy(s => s.Age,
                request.IsDesc ? OrderByType.Desc : OrderByType.Asc),
            "score" => query.OrderBy(s => s.Score,
                request.IsDesc ? OrderByType.Desc : OrderByType.Asc),
            _ => query.OrderBy(s => s.CreateTime, OrderByType.Desc)
        };
    }
}
```

```csharp
public class OrderService
{
    private readonly ISqlSugarClient _db;

    public OrderService(ISqlSugarClient db)
    {
        _db = db;
    }

    public async Task<PageResult<OrderListDto>> SearchOrdersAsync(OrderSearchRequest request)

        var query = _db.Queryable<Order, Customer>(
            (o, c) => o.CustomerId == c.Id)
            .Where((o, c) => o.IsDeleted == false)
            // 订单号精确搜索
            .WhereIF(!string.IsNullOrEmpty(request.OrderNo),

            .WhereIF(request.Status.HasValue,
                (o, c) => o.Status == request.Status.Value)
            // 多个状态
            .WhereIF(request.StatusList != null && request.StatusList.Any(),
                (o, c) => request.StatusList.Contains(o.Status))
            // 支付方式
            .WhereIF(request.PayType.HasValue,
                (o, c) => o.PayType == request.PayType.Value)
            // 金额范围
            .WhereIF(request.MinAmount.HasValue,
                (o, c) => o.TotalAmount >= request.MinAmount.Value)
            .WhereIF(request.MaxAmount.HasValue,
                (o, c) => o.TotalAmount <= request.MaxAmount.Value)
            // 时间范围
            .WhereIF(request.StartDate.HasValue,
                (o, c) => o.CreateTime >= request.StartDate.Value)
            .WhereIF(request.EndDate.HasValue,
                (o, c) => o.CreateTime < request.EndDate.Value.AddDays(1));

        // 分页查询
        RefAsync<int> total = 0;
        var list = await query
            .Select((o, c) => new OrderListDto
            {
                Id = o.Id,
                OrderNo = o.OrderNo,
                CustomerName = c.Name,
                TotalAmount = o.TotalAmount,
                StatusText = SqlFunc.IIF(o.Status == 0, "待支付",
                             SqlFunc.IIF(o.Status == 1, "已支付",
                             SqlFunc.IIF(o.Status == 2, "已发货",
                             SqlFunc.IIF(o.Status == 3, "已完成", "已取消")))),
                CreateTime = o.CreateTime,
                PayTime = o.PayTime
            })
            .OrderBy(o => o.CreateTime, OrderByType.Desc)
            .ToPageListAsync(request.PageIndex, request.PageSize, total);

        return new PageResult<OrderListDto>
        {
            Items = list,
            TotalCount = total.Value,
            PageIndex = request.PageIndex,
            PageSize = request.PageSize
        };
    }
```

## 15. 性能优化与注意事项

### 15.1 分页性能优化

| 优化策略 | 说明 | 效果 |
|---------|------|------|
| 添加索引 | 为排序字段和筛选字段添加索引 | 显著提升 |
| 避免深分页 | 避免查询第1000页以后的数据 | 防止性能急剧下降 |
| 缓存总数 | 首页查询时缓存总数 | 减少一次 COUNT 查询 |
| 覆盖索引 | 只查询索引包含的字段 | 避免回表查询 |
| 游标分页 | 使用上一页最后一条的 ID 分页 | 深页场景性能最优 |

### 15.2 深分页优化

```csharp
// ❌ 深分页性能差
var list = db.Queryable<Order>()
    .OrderBy(o => o.Id)
    .ToPageList(10000, 20);  // 第10000页，需要跳过199980条数据

// ✅ 使用游标分页优化
var list = db.Queryable<Order>()
    .Where(o => o.Id > lastMaxId)  // 上一页最后一条记录的 ID
    .OrderBy(o => o.Id)
    .Take(20)
    .ToList();
```

### 15.3 Select 投影优化

```csharp
// ❌ 查询所有字段
var list = db.Queryable<Order>()
    .ToPageList(1, 20);

// ✅ 只查询需要的字段
var list = db.Queryable<Order>()
```

### 15.4 动态查询注意事项

