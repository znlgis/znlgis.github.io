## 1. Insertable概述

### 1.1 什么是Insertable

`Insertable` 是 SqlSugar 中用于插入数据的核心对象。通过链式调用的方式，你可以灵活地配置插入行为，包括忽略列、指定列、返回自增ID等。

```csharp
// 基础用法
db.Insertable(entity).ExecuteCommand();
```

### 1.2 Insertable的特点

| 特点 | 说明 |
|------|------|
| 链式调用 | 支持方法链式调用，代码简洁 |
| 自动参数化 | 自动处理参数化，防止 SQL 注入 |
| 灵活控制 | 可控制插入的列、忽略的列 |
| 多种返回值 | 支持返回受影响行数、自增ID、雪花ID等 |
| 批量支持 | 支持批量插入和高性能 BulkCopy |

### 1.3 执行方法汇总

| 方法 | 返回值 | 说明 |
|------|--------|------|
| `ExecuteCommand()` | `int` | 返回受影响的行数 |
| `ExecuteReturnIdentity()` | `int` | 返回自增ID（int） |
| `ExecuteReturnBigIdentity()` | `long` | 返回自增ID（long） |
| `ExecuteReturnEntity()` | `T` | 返回插入后的实体（含自增ID） |
| `ExecuteReturnSnowflakeId()` | `long` | 返回雪花ID |
| `ExecuteReturnSnowflakeIdList()` | `List<long>` | 返回多条雪花ID |
| `ExecuteCommandIdentityIntoEntity()` | `bool` | 插入并将自增ID回写到实体 |

## 2. 插入单条记录

### 2.1 基础插入

```csharp
// 定义实体
var student = new Student()
{
    Name = "张三",
    Age = 20,
    ClassId = 1,
    CreateTime = DateTime.Now
};

// 执行插入，返回受影响行数
int result = db.Insertable(student).ExecuteCommand();
Console.WriteLine($"插入了 {result} 条记录");
```

生成的 SQL：

```sql
INSERT INTO Student (Name, Age, ClassId, CreateTime)
VALUES (@Name, @Age, @ClassId, @CreateTime)
```

> **注意**：自增主键列会自动忽略，不会出现在 INSERT 语句中。

### 2.2 异步插入

```csharp
// 异步执行插入
int result = await db.Insertable(student).ExecuteCommandAsync();
```

### 2.3 插入并返回受影响行数

```csharp
var student = new Student()
{
    Name = "李四",
    Age = 22,
    ClassId = 2
};

int affectedRows = db.Insertable(student).ExecuteCommand();

if (affectedRows > 0)
{
    Console.WriteLine("插入成功！");
}
else
{
    Console.WriteLine("插入失败！");
}
```

## 3. 插入多条记录

```csharp
// 批量插入
var students = new List<Student>()

    new Student { Name = "李四", Age = 21, ClassId = 1 },
```

### 3.2 使用PageSize分批插入

```csharp
// 每次插入100条

    .ExecuteCommand();
```

### 3.3 批量插入的SQL生成

```csharp
// 默认情况下，SqlSugar 使用多行 VALUES 语法
```

## 4. 返回自增ID

### 4.1 ExecuteReturnIdentity - 返回int类型ID

```csharp
var student = new Student()
{
    Name = "张三",
    Age = 20,
    ClassId = 1
};

// 返回自增ID（int）
int newId = db.Insertable(student).ExecuteReturnIdentity();
Console.WriteLine($"新插入记录的ID: {newId}");
```

生成的 SQL：

```sql
-- MySQL
INSERT INTO Student (Name, Age, ClassId) VALUES (@Name, @Age, @ClassId);
SELECT LAST_INSERT_ID();

-- SQL Server
INSERT INTO Student (Name, Age, ClassId) VALUES (@Name, @Age, @ClassId);
SELECT SCOPE_IDENTITY();
```

### 4.2 ExecuteReturnBigIdentity - 返回long类型ID

当自增ID可能超过 int 范围时使用：

```csharp
// 返回自增ID（long）
long newId = db.Insertable(student).ExecuteReturnBigIdentity();
Console.WriteLine($"新插入记录的ID: {newId}");
```

### 4.3 ExecuteReturnEntity - 返回完整实体

```csharp
// 返回插入后的完整实体（包含自增ID）
Student insertedStudent = db.Insertable(student).ExecuteReturnEntity();
Console.WriteLine($"ID: {insertedStudent.Id}, Name: {insertedStudent.Name}");
```

> **说明**：`ExecuteReturnEntity()` 内部会先执行插入，然后将自增ID回写到实体对象中并返回。

### 4.4 ExecuteCommandIdentityIntoEntity - 回写ID到实体

```csharp
var student = new Student()
{
    Name = "张三",
    Age = 20
};

Console.WriteLine($"插入前 ID: {student.Id}");  // 输出: 0

bool success = db.Insertable(student).ExecuteCommandIdentityIntoEntity();

Console.WriteLine($"插入后 ID: {student.Id}");  // 输出: 自增ID值
```

### 4.5 ExecuteReturnSnowflakeId - 返回雪花ID

如果使用雪花ID而非数据库自增：

```csharp
// 配置雪花ID
StaticConfig.CustomSnowFlakeFunc = () =>
{
    return YitIdHelper.NextId();  // 使用 Yitter.IdGenerator
};

// 实体类中配置雪花ID
public class Order
{
    [SugarColumn(IsPrimaryKey = true)]
    public long Id { get; set; }  // 雪花ID不用 IsIdentity

    public string OrderNo { get; set; }
    public decimal Amount { get; set; }
}

// 插入并返回雪花ID
long snowflakeId = db.Insertable(new Order
{
    OrderNo = "ORD20240101001",
    Amount = 99.99m
}).ExecuteReturnSnowflakeId();

Console.WriteLine($"雪花ID: {snowflakeId}");
```

### 4.6 批量插入返回雪花ID列表

```csharp
var orders = new List<Order>()
{
    new Order { OrderNo = "ORD001", Amount = 100 },
    new Order { OrderNo = "ORD002", Amount = 200 },
    new Order { OrderNo = "ORD003", Amount = 300 }
};

List<long> ids = db.Insertable(orders).ExecuteReturnSnowflakeIdList();

for (int i = 0; i < ids.Count; i++)
{
    Console.WriteLine($"订单 {orders[i].OrderNo} 的ID: {ids[i]}");
}
```

## 5. 忽略列与指定列

### 5.1 IgnoreColumns - 忽略指定列

```csharp
// 插入时忽略 CreateTime 和 UpdateTime
var student = new Student()
{
    Name = "张三",
    Age = 20,
    ClassId = 1,
    CreateTime = DateTime.Now,
    UpdateTime = DateTime.Now
};

db.Insertable(student)
    .IgnoreColumns(it => new { it.CreateTime, it.UpdateTime })
    .ExecuteCommand();
```

生成的 SQL：

```sql
INSERT INTO Student (Name, Age, ClassId) VALUES (@Name, @Age, @ClassId)
```

### 5.2 使用字符串名称忽略列

```csharp
// 通过列名字符串忽略
db.Insertable(student)
    .IgnoreColumns("CreateTime", "UpdateTime")
    .ExecuteCommand();
```

### 5.3 IgnoreColumns - 忽略NULL值的列

```csharp
// 忽略值为 NULL 的列（让数据库使用默认值）
db.Insertable(student)
    .IgnoreColumns(ignoreNullColumn: true)
    .ExecuteCommand();
```

> **应用场景**：当数据库列有默认值（如 `CreateTime DEFAULT GETDATE()`），并且实体中该属性为 null 时，忽略该列让数据库使用默认值。

### 5.4 InsertColumns - 只插入指定列

```csharp
// 只插入 Name 和 Age 列
db.Insertable(student)
    .InsertColumns(it => new { it.Name, it.Age })
    .ExecuteCommand();
```

生成的 SQL：

```sql
INSERT INTO Student (Name, Age) VALUES (@Name, @Age)
```

### 5.5 使用字符串名称指定列

```csharp
// 通过列名字符串指定
db.Insertable(student)
    .InsertColumns("Name", "Age", "ClassId")
    .ExecuteCommand();
```

### 5.6 通过特性配置忽略列

```csharp
public class Student
{
    [SugarColumn(IsPrimaryKey = true, IsIdentity = true)]
    public int Id { get; set; }

    public string Name { get; set; }

    public int Age { get; set; }

    // 插入时忽略此列
    [SugarColumn(IsOnlyIgnoreInsert = true)]
    public DateTime? UpdateTime { get; set; }

    // 查询和插入时都忽略
    [SugarColumn(IsIgnore = true)]
    public string TempField { get; set; }
}
```

常用的忽略特性：

| 特性 | 说明 |
|------|------|
| `IsOnlyIgnoreInsert = true` | 仅插入时忽略 |
| `IsOnlyIgnoreUpdate = true` | 仅更新时忽略 |
| `IsIgnore = true` | 所有操作都忽略 |
| `IsIdentity = true` | 自增列，插入自动忽略 |

## 8. Storageable插入或更新

### 8.1 什么是Storageable

`Storageable` 是 SqlSugar 提供的"存储"功能，支持根据条件判断是插入还是更新，类似于数据库的 `MERGE` 或 `INSERT ON DUPLICATE KEY UPDATE` 操作。

### 8.2 基础Storageable用法

```csharp
var student = new Student()
{
    Id = 1,
    Name = "张三（更新）",
    Age = 21
};

// 如果存在则更新，不存在则插入
db.Storageable(student).ExecuteCommand();
```

### 8.3 批量Storageable

```csharp
var students = new List<Student>()
{
    new Student { Id = 1, Name = "张三", Age = 20 },   // 已存在 → 更新
    new Student { Id = 2, Name = "李四", Age = 21 },   // 已存在 → 更新
    new Student { Id = 0, Name = "新同学", Age = 22 }, // 不存在 → 插入
};

// 批量处理
var result = db.Storageable(students).ExecuteCommand();
```

### 8.4 自定义判断条件

```csharp
// 根据 Name 判断是否存在（而不是主键）
var result = db.Storageable(students)
    .WhereColumns(it => it.Name)  // 根据 Name 判断
    .ExecuteCommand();
```

### 8.5 Storageable分组处理

```csharp
// 高级用法：根据条件分组处理
var storageResult = db.Storageable(students)
    .SplitInsert(it => !it.Any())                    // 不存在的执行插入
    .SplitUpdate(it => it.Any())                     // 存在的执行更新
    .SplitError(it => string.IsNullOrEmpty(it.Item.Name))  // Name为空的标记为错误
    .SplitIgnore(it => it.Item.Age < 0)              // Age小于0的忽略
    .ToStorage();

// 分别执行
int insertCount = storageResult.AsInsertable.ExecuteCommand();     // 执行插入
int updateCount = storageResult.AsUpdateable.ExecuteCommand();     // 执行更新
var errorList = storageResult.ErrorList;                            // 错误列表
var ignoreList = storageResult.IgnoreList;                          // 忽略列表

Console.WriteLine($"插入: {insertCount}, 更新: {updateCount}");
Console.WriteLine($"错误: {errorList.Count}, 忽略: {ignoreList.Count}");
```

### 8.6 Storageable与数据库特定语法

```csharp
// MySQL: INSERT ... ON DUPLICATE KEY UPDATE
// 使用数据库原生的 upsert 语法（性能更好）
db.Storageable(students)
    .DefaultAddElseUpdate()
    .ExecuteCommand();
```

### 8.7 Storageable实际应用场景

```csharp
// 场景：同步第三方数据
public void SyncExternalData(List<ProductDto> externalProducts)
{
    var products = externalProducts.Select(p => new Product
    {
        ExternalId = p.Id,
        Name = p.Name,
        Price = p.Price,
        UpdateTime = DateTime.Now
    }).ToList();

    // 根据 ExternalId 判断是插入还是更新
    var result = db.Storageable(products)
        .WhereColumns(it => it.ExternalId)
        .ToStorage();

    // 插入新数据
    if (result.InsertList.Any())
    {
        result.AsInsertable.ExecuteCommand();
    }

    // 更新已有数据
    if (result.UpdateList.Any())
    {
        result.AsUpdateable
            .UpdateColumns(it => new { it.Name, it.Price, it.UpdateTime })
            .ExecuteCommand();
    }

    Console.WriteLine($"新增: {result.InsertList.Count}, 更新: {result.UpdateList.Count}");
}
```

## 9. 条件插入

### 9.1 WhereIF条件插入

```csharp
bool includeCreateTime = true;

db.Insertable(student)
    .IgnoreColumnsIF(!includeCreateTime, it => it.CreateTime)
    .ExecuteCommand();
```

### 9.2 事务插入

```csharp
// 使用事务确保数据一致性
try
{
    db.Ado.BeginTran();

    // 插入班级
    var classInfo = new ClassInfo { ClassName = "三年一班" };
    int classId = db.Insertable(classInfo).ExecuteReturnIdentity();

    // 插入学生
    var students = new List<Student>()
    {
        new Student { Name = "张三", Age = 20, ClassId = classId },
        new Student { Name = "李四", Age = 21, ClassId = classId }
    };

    db.Insertable(students).ExecuteCommand();

    db.Ado.CommitTran();
    Console.WriteLine("事务提交成功！");
}
catch (Exception ex)
{
    db.Ado.RollbackTran();
    Console.WriteLine($"事务回滚: {ex.Message}");
}
```

### 9.3 使用工作单元

```csharp
// 使用 SqlSugarScope 的工作单元模式（推荐）
using (var tran = db.UseTran())
{
    var classInfo = new ClassInfo { ClassName = "三年二班" };
    int classId = db.Insertable(classInfo).ExecuteReturnIdentity();

    var student = new Student
    {
        Name = "王五",
        Age = 22,
        ClassId = classId
    };
    db.Insertable(student).ExecuteCommand();

    tran.CommitTran();
}
```

### 9.4 条件判断后插入

```csharp
// 判断是否存在后再插入
var existStudent = db.Queryable<Student>()
    .Any(it => it.Name == "张三" && it.ClassId == 1);

if (!existStudent)
{
    db.Insertable(new Student
    {
        Name = "张三",
        Age = 20,
        ClassId = 1
    }).ExecuteCommand();
}
```

## 10. SubInsertable导航插入

### 10.1 什么是导航插入

导航插入（`SubInsertable`）允许你在插入父记录的同时，自动插入子记录，SqlSugar 会自动处理外键关系。

### 10.2 一对多导航插入

```csharp
// 实体定义
public class ClassInfo
{
    [SugarColumn(IsPrimaryKey = true, IsIdentity = true)]
    public int Id { get; set; }
    public string ClassName { get; set; }

    [Navigate(NavigateType.OneToMany, nameof(Student.ClassId))]
    public List<Student> Students { get; set; }
}

public class Student
{
    [SugarColumn(IsPrimaryKey = true, IsIdentity = true)]
    public int Id { get; set; }
    public string Name { get; set; }
    public int ClassId { get; set; }
}

// 导航插入：同时插入班级和学生
var classInfo = new ClassInfo
{
    ClassName = "三年一班",
    Students = new List<Student>
    {
        new Student { Name = "张三", Age = 20 },
        new Student { Name = "李四", Age = 21 },
        new Student { Name = "王五", Age = 22 }
    }
};

// 自动插入班级，并将班级ID赋值给学生的ClassId后插入学生
db.InsertNav(classInfo)
    .Include(it => it.Students)
    .ExecuteCommand();
```

### 10.3 多级导航插入

```csharp
// 三级导航插入：学校 → 班级 → 学生
public class School
{
    [SugarColumn(IsPrimaryKey = true, IsIdentity = true)]
    public int Id { get; set; }
    public string SchoolName { get; set; }

    [Navigate(NavigateType.OneToMany, nameof(ClassInfo.SchoolId))]
    public List<ClassInfo> Classes { get; set; }
}

var school = new School
{
    SchoolName = "第一中学",
    Classes = new List<ClassInfo>
    {
        new ClassInfo
        {
            ClassName = "三年一班",
            Students = new List<Student>
            {
                new Student { Name = "张三" },
                new Student { Name = "李四" }
            }
        },
        new ClassInfo
        {
            ClassName = "三年二班",
            Students = new List<Student>
            {
                new Student { Name = "王五" },
                new Student { Name = "赵六" }
            }
        }
    }
};

// 三级导航插入
db.InsertNav(school)
    .Include(it => it.Classes)
        .ThenInclude(c => c.Students)
    .ExecuteCommand();
```

### 10.4 多对多导航插入

```csharp
// 多对多：学生 ↔ 课程（通过中间表）
var student = new Student
{
    Name = "张三",
    Courses = new List<Course>
    {
        new Course { CourseName = "数学" },
        new Course { CourseName = "英语" }
    }
};

db.InsertNav(student)
    .Include(it => it.Courses)
    .ExecuteCommand();
// SqlSugar 会自动插入中间表的记录
```

### 10.5 导航插入与事务

```csharp
// 导航插入默认使用事务
// 如果需要自定义事务行为
db.Ado.BeginTran();
try
{
    db.InsertNav(classInfo)
        .Include(it => it.Students)
        .ExecuteCommand();

    db.Ado.CommitTran();
}
catch
{
    db.Ado.RollbackTran();
    throw;
}
```

## 11. 性能优化与批量插入

### 11.1 普通批量插入

```csharp
// 普通批量插入（使用多行 VALUES 语法）
var students = GenerateTestData(10000);

var sw = Stopwatch.StartNew();

db.Insertable(students)
    .PageSize(1000)  // 每批1000条
    .ExecuteCommand();

sw.Stop();
Console.WriteLine($"普通批量插入 10000 条耗时: {sw.ElapsedMilliseconds}ms");
```

### 11.2 BulkCopy高性能插入

`BulkCopy` 使用数据库原生的批量插入机制，性能远超普通插入：

```csharp
// BulkCopy 大批量插入
var students = GenerateTestData(100000);

var sw = Stopwatch.StartNew();

db.Fastest<Student>().BulkCopy(students);

sw.Stop();
Console.WriteLine($"BulkCopy 100000 条耗时: {sw.ElapsedMilliseconds}ms");
```

### 11.3 性能对比

| 插入方式 | 10,000条 | 100,000条 | 适用场景 |
|---------|----------|-----------|---------|
| 逐条插入 | ~10s | ~100s | 不推荐批量使用 |
| 普通批量（PageSize=1000） | ~2s | ~20s | 一般场景 |
| BulkCopy | ~0.5s | ~2s | 大批量数据 |

### 11.4 BulkCopy配置

```csharp
// BulkCopy 详细配置
db.Fastest<Student>()
    .PageSize(50000)           // 每批条数
    .BulkCopy(students);
```

### 11.5 BulkCopy支持的数据库

| 数据库 | 支持情况 | 底层技术 |
|--------|---------|---------|
| SQL Server | ✅ 支持 | `SqlBulkCopy` |
| MySQL | ✅ 支持 | `MySqlBulkLoader` |
| PostgreSQL | ✅ 支持 | `COPY` 命令 |
| Oracle | ✅ 支持 | `OracleBulkCopy` |
| SQLite | ✅ 支持 | 事务批量插入 |

### 11.6 BulkMerge（大批量合并）

```csharp
// 大批量合并（存在更新，不存在插入）
db.Fastest<Student>().BulkMerge(students);
```

### 11.7 性能优化建议

> **最佳实践**：
>
> 1. **小批量（< 100条）**：使用 `Insertable` 即可
> 2. **中等批量（100 ~ 10,000条）**：使用 `Insertable` + `PageSize()`
> 3. **大批量（> 10,000条）**：使用 `Fastest.BulkCopy()`
> 4. **超大批量（> 100,000条）**：使用 `Fastest.BulkCopy()` + 分批处理

```csharp
// 超大批量插入示例
public async Task BulkInsertLargeData(List<Student> allData)
{
    int batchSize = 50000;
    int totalBatches = (int)Math.Ceiling((double)allData.Count / batchSize);

    for (int i = 0; i < totalBatches; i++)
    {
        var batch = allData.Skip(i * batchSize).Take(batchSize).ToList();
        db.Fastest<Student>().BulkCopy(batch);
        Console.WriteLine($"已完成第 {i + 1}/{totalBatches} 批");
    }

    Console.WriteLine($"全部完成，共插入 {allData.Count} 条记录");
}
```

## 12. 常见问题与最佳实践

### 12.1 自增ID不生效

**问题**：插入后获取的自增ID为0。

**原因**：实体类的主键列没有配置 `IsIdentity = true`。

```csharp
// 正确配置
public class Student
{
    [SugarColumn(IsPrimaryKey = true, IsIdentity = true)]  // 必须标记 IsIdentity
    public int Id { get; set; }
}
```

### 12.2 插入时间精度问题

**问题**：DateTime 插入后精度丢失。

**解决方案**：

```csharp
// 在实体类中指定列精度
[SugarColumn(ColumnDataType = "datetime2")]  // SQL Server
public DateTime CreateTime { get; set; }

[SugarColumn(ColumnDataType = "datetime(3)")]  // MySQL，精确到毫秒
public DateTime CreateTime { get; set; }
```

### 12.3 插入默认值处理

```csharp
// 方式1：在实体构造函数中设置默认值
public class Student
{
    public Student()
    {
        CreateTime = DateTime.Now;
        IsEnabled = true;
    }

    public DateTime CreateTime { get; set; }
    public bool IsEnabled { get; set; }
}

// 方式2：忽略列让数据库使用默认值
db.Insertable(student)
    .IgnoreColumns(ignoreNullColumn: true)
    .ExecuteCommand();
```

### 12.4 插入特殊字符

```csharp
// SqlSugar 自动参数化处理，无需担心特殊字符和SQL注入
var student = new Student
{
    Name = "O'Brien",  // 包含单引号
    Age = 20
};

db.Insertable(student).ExecuteCommand();
// SqlSugar 会自动使用参数化查询，安全处理特殊字符
```

### 12.5 插入操作的日志记录

```csharp
// 在 Aop 中监控所有插入操作
db.Aop.OnLogExecuting = (sql, pars) =>
{
    if (sql.TrimStart().StartsWith("INSERT", StringComparison.OrdinalIgnoreCase))
    {
        Console.WriteLine($"[INSERT] {sql}");
        Console.WriteLine($"[PARAMS] {string.Join(", ", pars.Select(p => $"{p.ParameterName}={p.Value}"))}");
    }
};
```

### 12.6 插入操作最佳实践总结

| 场景 | 推荐方式 | 说明 |
|------|---------|------|
| 插入单条记录 | `Insertable(entity).ExecuteCommand()` | 最简单直接 |
| 插入并获取ID | `Insertable(entity).ExecuteReturnIdentity()` | 返回自增ID |
| 批量插入（中等量） | `Insertable(list).PageSize(1000).ExecuteCommand()` | 分批处理 |
| 大批量插入 | `Fastest<T>().BulkCopy(list)` | 性能最佳 |
| 存在则更新 | `Storageable(list).ExecuteCommand()` | 智能合并 |
| 级联插入 | `InsertNav(entity).Include(...).ExecuteCommand()` | 自动处理外键 |
| 无实体插入 | 字典/DataTable + `.AS("表名")` | 灵活场景 |

## 13. 本章小结

本章全面介绍了 SqlSugar 的插入数据操作：

- **Insertable 概述**：链式调用、自动参数化、多种执行方法
- **单条插入**：`ExecuteCommand` 返回受影响行数
- **批量插入**：列表插入、`PageSize` 分批处理
- **返回自增ID**：`ExecuteReturnIdentity`（int）、`ExecuteReturnBigIdentity`（long）、`ExecuteReturnEntity`（完整实体）、雪花ID
- **忽略列与指定列**：`IgnoreColumns`、`InsertColumns`、通过特性配置
- **字典与DataTable插入**：无需实体类的灵活插入方式
- **Storageable**：智能判断插入或更新，支持分组处理
- **条件插入**：事务支持、条件判断
- **导航插入**：`InsertNav` 自动处理父子关系和外键
- **性能优化**：`BulkCopy` 高性能插入、`BulkMerge` 大批量合并、性能对比和分批策略

掌握这些插入操作后，你可以高效、安全地将数据写入数据库，应对从简单的单条插入到百万级数据批量导入的各种场景。
