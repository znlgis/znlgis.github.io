## 1. Queryable概述

### 1.1 什么是Queryable

`Queryable` 是 SqlSugar 中用于构建查询语句的核心对象。通过链式调用的方式，你可以灵活地组合各种查询条件，最终生成高效的 SQL 语句并执行。

```csharp
// 获取 Queryable 对象
var query = db.Queryable<Student>();

// 链式调用构建查询
var list = db.Queryable<Student>()
    .Where(it => it.Age > 18)
    .OrderBy(it => it.Id)
    .ToList();
```

### 1.2 Queryable的特点

| 特点 | 说明 |
|------|------|
| 链式调用 | 支持方法链式调用，代码简洁优雅 |
| Lambda表达式 | 使用 C# 原生 Lambda 表达式，编译时检查 |
| 延迟执行 | 查询在调用终结方法（如 `ToList()`）时才执行 |
| 自动参数化 | 自动将参数化处理，防止 SQL 注入 |
| 多数据库兼容 | 同一套代码支持不同数据库 |

### 1.3 Queryable的生命周期

```
创建 Queryable ──→ 添加条件/排序/投影 ──→ 调用终结方法 ──→ 执行SQL并返回结果
     ↑                    ↑                     ↑
  db.Queryable<T>()   .Where/.OrderBy/.Select   .ToList()/.First()/.Count()
```

> **重要**：Queryable 在调用终结方法（如 `ToList()`、`First()`、`Count()`）之前不会执行任何 SQL 操作。

## 2. 基础查询方法

### 2.1 ToList - 查询列表

```csharp
// 查询所有学生
List<Student> list = db.Queryable<Student>().ToList();

// 异步查询
List<Student> list = await db.Queryable<Student>().ToListAsync();
```

生成的 SQL：

```sql
SELECT * FROM Student
```

### 2.2 First - 查询第一条

```csharp
// 查询第一条记录（无结果返回 null）
Student student = db.Queryable<Student>().First();

// 带条件查询第一条
Student student = db.Queryable<Student>().First(it => it.Id == 1);

// 异步版本
Student student = await db.Queryable<Student>().FirstAsync(it => it.Id == 1);
```

生成的 SQL：

```sql
SELECT TOP 1 * FROM Student WHERE Id = @Id0
```

### 2.3 Single - 查询唯一一条

`Single` 与 `First` 类似，但如果查询结果有多条记录，会抛出异常：

```csharp
// 查询唯一一条记录
Student student = db.Queryable<Student>().Single(it => it.Id == 1);

// 如果结果超过1条，会抛出异常
```

### 2.4 Count - 查询总数

```csharp
// 获取记录总数
int count = db.Queryable<Student>().Count();

// 带条件的总数
int count = db.Queryable<Student>().Count(it => it.Age > 18);

// 异步版本
int count = await db.Queryable<Student>().CountAsync();
```

生成的 SQL：

```sql
SELECT COUNT(1) FROM Student
SELECT COUNT(1) FROM Student WHERE Age > @Age0
```

### 2.5 Any - 判断是否存在

```csharp
// 判断是否有数据
bool exists = db.Queryable<Student>().Any();

// 判断指定条件是否有数据
bool exists = db.Queryable<Student>().Any(it => it.Name == "张三");
```

生成的 SQL：

```sql
SELECT COUNT(1) FROM Student WHERE Name = @Name0
```

### 2.6 ToDataTable - 返回DataTable

```csharp
// 返回 DataTable 格式
DataTable dt = db.Queryable<Student>().ToDataTable();
```

### 2.7 Max / Min / Sum / Avg

```csharp
// 最大值
int maxAge = db.Queryable<Student>().Max(it => it.Age);

// 最小值
int minAge = db.Queryable<Student>().Min(it => it.Age);

// 求和
int totalAge = db.Queryable<Student>().Sum(it => it.Age);

// 平均值
int avgAge = db.Queryable<Student>().Avg<int>(it => it.Age);
```

## 3. Where条件查询

### 3.1 基础Lambda条件

```csharp
// 等于
var list = db.Queryable<Student>()
    .Where(it => it.Id == 1)
    .ToList();

// 不等于
var list = db.Queryable<Student>()
    .Where(it => it.Name != "张三")
    .ToList();

// 大于、小于
var list = db.Queryable<Student>()
    .Where(it => it.Age > 18 && it.Age < 30)
    .ToList();

// 大于等于、小于等于
var list = db.Queryable<Student>()
    .Where(it => it.Age >= 18 && it.Age <= 30)
    .ToList();
```

### 3.2 多条件查询

```csharp
// AND 条件（多个 Where 方法）
var list = db.Queryable<Student>()
    .Where(it => it.Age > 18)
    .Where(it => it.Name != null)
    .Where(it => it.ClassId == 1)
    .ToList();

// 等价于
var list = db.Queryable<Student>()
    .Where(it => it.Age > 18 && it.Name != null && it.ClassId == 1)
    .ToList();
```

生成的 SQL：

```sql
SELECT * FROM Student WHERE Age > @Age0 AND Name IS NOT NULL AND ClassId = @ClassId0
```

### 3.3 OR条件

```csharp
// OR 条件
var list = db.Queryable<Student>()
    .Where(it => it.Age > 18 || it.Name == "张三")
    .ToList();

// AND 和 OR 组合
var list = db.Queryable<Student>()
    .Where(it => it.ClassId == 1 && (it.Age > 18 || it.Name == "张三"))
    .ToList();
```

生成的 SQL：

```sql
SELECT * FROM Student WHERE ClassId = @ClassId0 AND (Age > @Age0 OR Name = @Name0)
```

### 3.4 动态条件（WhereIF）

根据条件动态添加 Where 子句，非常适合搜索页面的多条件查询：

```csharp
string name = "张三";       // 来自用户输入
int? age = null;            // 用户未填写
int? classId = 1;           // 来自用户选择

var list = db.Queryable<Student>()
    .WhereIF(!string.IsNullOrEmpty(name), it => it.Name.Contains(name))
    .WhereIF(age.HasValue, it => it.Age == age.Value)
    .WhereIF(classId.HasValue, it => it.ClassId == classId.Value)
    .ToList();
```

> **说明**：`WhereIF` 的第一个参数为 `true` 时才会添加该条件，否则忽略。这样可以避免繁琐的 `if-else` 判断。

### 3.5 WhereClass - 实体类条件

```csharp
// 使用实体对象作为查询条件
var searchModel = new Student()
{
    Name = "张三",
    ClassId = 1
};

// 实体中非默认值的属性会作为条件
var list = db.Queryable<Student>()
    .WhereClass(searchModel)
    .ToList();
```

### 3.6 Where拼接SQL字符串

在某些特殊场景下，可以使用原生 SQL 字符串：

```csharp
// 使用原生SQL条件
var list = db.Queryable<Student>()
    .Where("Age > @age AND ClassId = @classId",
        new { age = 18, classId = 1 })
    .ToList();
```

> **注意**：即使使用字符串方式，也要使用参数化（`@参数名`），避免 SQL 注入。

### 3.7 条件构造器（ConditionalModel）

对于动态查询场景，可以使用条件构造器：

```csharp
var conditions = new List<IConditionalModel>()
{
    new ConditionalModel()
    {
        FieldName = "Name",
        ConditionalType = ConditionalType.Like,
        FieldValue = "张"
    },
    new ConditionalModel()
    {
        FieldName = "Age",
        ConditionalType = ConditionalType.GreaterThan,
        FieldValue = "18"
    },
    new ConditionalModel()
    {
        FieldName = "ClassId",
        ConditionalType = ConditionalType.Equal,
        FieldValue = "1"
    }
};

var list = db.Queryable<Student>()
    .Where(conditions)
    .ToList();
```

支持的条件类型：

| ConditionalType | 对应SQL | 说明 |
|----------------|---------|------|
| `Equal` | `=` | 等于 |
| `NotEqual` | `<>` | 不等于 |
| `GreaterThan` | `>` | 大于 |
| `GreaterThanOrEqual` | `>=` | 大于等于 |
| `LessThan` | `<` | 小于 |
| `LessThanOrEqual` | `<=` | 小于等于 |
| `Like` | `LIKE '%x%'` | 模糊查询 |
| `LikeLeft` | `LIKE '%x'` | 左模糊 |
| `LikeRight` | `LIKE 'x%'` | 右模糊 |
| `In` | `IN (...)` | 包含 |
| `NotIn` | `NOT IN (...)` | 不包含 |
| `IsNullOrEmpty` | `IS NULL OR = ''` | 空或空字符串 |
| `IsNot` | `IS NOT NULL` | 非空 |

## 4. 模糊查询

### 4.1 Contains - 包含（LIKE）

```csharp
// LIKE '%张%'
var list = db.Queryable<Student>()
    .Where(it => it.Name.Contains("张"))
    .ToList();
```

生成的 SQL：

```sql
SELECT * FROM Student WHERE Name LIKE '%张%'
```

### 4.2 StartsWith - 以指定字符开头

```csharp
// LIKE '张%'
var list = db.Queryable<Student>()
    .Where(it => it.Name.StartsWith("张"))
    .ToList();
```

生成的 SQL：

```sql
SELECT * FROM Student WHERE Name LIKE '张%'
```

### 4.3 EndsWith - 以指定字符结尾

```csharp
// LIKE '%三'
var list = db.Queryable<Student>()
    .Where(it => it.Name.EndsWith("三"))
    .ToList();
```

生成的 SQL：

```sql
SELECT * FROM Student WHERE Name LIKE '%三'
```

### 4.4 SqlFunc.Contains - 指定模式

```csharp
// 自定义模糊匹配
var list = db.Queryable<Student>()
    .Where(it => SqlFunc.Contains(it.Name, "张"))
    .ToList();
```

### 4.5 NOT LIKE

```csharp
// NOT LIKE
var list = db.Queryable<Student>()
    .Where(it => !it.Name.Contains("张"))
    .ToList();
```

生成的 SQL：

```sql
SELECT * FROM Student WHERE Name NOT LIKE '%张%'
```

## 5. In查询与Between查询

### 5.1 In查询

```csharp
// 使用数组实现 IN 查询
var ids = new int[] { 1, 2, 3, 4, 5 };
var list = db.Queryable<Student>()
    .Where(it => ids.Contains(it.Id))
    .ToList();
```

生成的 SQL：

```sql
SELECT * FROM Student WHERE Id IN (1, 2, 3, 4, 5)
```

### 5.2 使用List实现In查询

```csharp
// 使用 List
var nameList = new List<string> { "张三", "李四", "王五" };
var list = db.Queryable<Student>()
    .Where(it => nameList.Contains(it.Name))
    .ToList();
```

生成的 SQL：

```sql
SELECT * FROM Student WHERE Name IN ('张三', '李四', '王五')
```

### 5.3 NOT IN查询

```csharp
// NOT IN
var excludeIds = new int[] { 1, 2, 3 };
var list = db.Queryable<Student>()
    .Where(it => !excludeIds.Contains(it.Id))
    .ToList();
```

生成的 SQL：

```sql
SELECT * FROM Student WHERE Id NOT IN (1, 2, 3)
```

### 5.4 Between查询

```csharp
// 使用 SqlFunc.Between
var list = db.Queryable<Student>()
    .Where(it => SqlFunc.Between(it.Age, 18, 25))
    .ToList();
```

生成的 SQL：

```sql
SELECT * FROM Student WHERE Age BETWEEN 18 AND 25
```

### 5.5 日期范围查询

```csharp
// 日期范围
var startDate = new DateTime(2024, 1, 1);
var endDate = new DateTime(2024, 12, 31);

var list = db.Queryable<Student>()
    .Where(it => it.CreateTime >= startDate && it.CreateTime <= endDate)
    .ToList();

// 或使用 Between
var list = db.Queryable<Student>()
    .Where(it => SqlFunc.Between(it.CreateTime, startDate, endDate))
    .ToList();
```

## 6. 空值检查

### 6.1 判断NULL

```csharp
// IS NULL
var list = db.Queryable<Student>()
    .Where(it => it.Name == null)
    .ToList();

// IS NOT NULL
var list = db.Queryable<Student>()
    .Where(it => it.Name != null)
    .ToList();
```

生成的 SQL：

```sql
SELECT * FROM Student WHERE Name IS NULL
SELECT * FROM Student WHERE Name IS NOT NULL
```

### 6.2 判断空字符串

```csharp
// 判断不为空且不为空字符串
var list = db.Queryable<Student>()
    .Where(it => !string.IsNullOrEmpty(it.Name))
    .ToList();

// 使用 SqlFunc
var list = db.Queryable<Student>()
    .Where(it => SqlFunc.IsNullOrEmpty(it.Name) == false)
    .ToList();
```

### 6.3 IFNULL / ISNULL 函数

```csharp
// 对空值设置默认值
var list = db.Queryable<Student>()
    .Select(it => new
    {
        it.Id,
        Name = SqlFunc.IsNull(it.Name, "未知"),  // IFNULL(Name, '未知')
        Age = SqlFunc.IsNull(it.Age, 0)            // IFNULL(Age, 0)
    })
    .ToList();
```

## 7. 排序操作

### 7.1 OrderBy - 升序

```csharp
// 按 Id 升序
var list = db.Queryable<Student>()
    .OrderBy(it => it.Id)
    .ToList();

// 等价于
var list = db.Queryable<Student>()
    .OrderBy(it => it.Id, OrderByType.Asc)
    .ToList();
```

### 7.2 OrderByDescending - 降序

```csharp
// 按 Id 降序
var list = db.Queryable<Student>()
    .OrderByDescending(it => it.Id)
    .ToList();

// 等价于
var list = db.Queryable<Student>()
    .OrderBy(it => it.Id, OrderByType.Desc)
    .ToList();
```

### 7.3 多字段排序

```csharp
// 先按班级升序，再按年龄降序
var list = db.Queryable<Student>()
    .OrderBy(it => it.ClassId)
    .OrderByDescending(it => it.Age)
    .ToList();

// 使用 OrderBy 同时指定多个字段
var list = db.Queryable<Student>()
    .OrderBy(it => new { it.ClassId, Age = SqlFunc.Desc(it.Age) })
    .ToList();
```

生成的 SQL：

```sql
SELECT * FROM Student ORDER BY ClassId ASC, Age DESC
```

### 7.4 条件排序（OrderByIF）

```csharp
string sortField = "age";  // 来自用户选择
bool isDesc = true;        // 来自用户选择

var list = db.Queryable<Student>()
    .OrderByIF(sortField == "age", it => it.Age, isDesc ? OrderByType.Desc : OrderByType.Asc)
    .OrderByIF(sortField == "name", it => it.Name, isDesc ? OrderByType.Desc : OrderByType.Asc)
    .OrderByIF(sortField == "id", it => it.Id, isDesc ? OrderByType.Desc : OrderByType.Asc)
    .ToList();
```

### 7.5 使用字符串排序

```csharp
// 使用字符串指定排序
var list = db.Queryable<Student>()
    .OrderBy("ClassId ASC, Age DESC")
    .ToList();
```

## 8. Select投影查询

```csharp
public class StudentDto
```

```csharp
// 使用计算列
var list = db.Queryable<Student>()
```

### 8.6 使用SqlFunc函数

```csharp
    })

```

## 9. 分组与聚合

### 9.1 GroupBy基础用法

```csharp
// 按班级分组统计人数
var list = db.Queryable<Student>()
    .GroupBy(it => it.ClassId)
    .Select(it => new
    {
        ClassId = it.ClassId,
        Count = SqlFunc.AggregateCount(it.Id)
    })
    .ToList();
```

生成的 SQL：

```sql
SELECT ClassId, COUNT(Id) AS Count FROM Student GROUP BY ClassId
```

### 9.2 多字段分组

```csharp
// 按班级和年龄分组
var list = db.Queryable<Student>()
    .GroupBy(it => new { it.ClassId, it.Age })
    .Select(it => new
    {
        it.ClassId,
        it.Age,
        Count = SqlFunc.AggregateCount(it.Id)
    })
    .ToList();
```

### 9.3 Having条件

```csharp
// 查询人数大于5的班级
var list = db.Queryable<Student>()
    .GroupBy(it => it.ClassId)
    .Having(it => SqlFunc.AggregateCount(it.Id) > 5)
    .Select(it => new
    {
        ClassId = it.ClassId,
        StudentCount = SqlFunc.AggregateCount(it.Id)
    })
    .ToList();
```

生成的 SQL：

```sql
SELECT ClassId, COUNT(Id) AS StudentCount
FROM Student
GROUP BY ClassId
HAVING COUNT(Id) > 5
```

### 9.4 聚合函数详解

SqlSugar 支持以下聚合函数：

| 函数 | 说明 | 示例 |
|------|------|------|
| `SqlFunc.AggregateCount` | 计数 | `SqlFunc.AggregateCount(it.Id)` |
| `SqlFunc.AggregateSum` | 求和 | `SqlFunc.AggregateSum(it.Score)` |
| `SqlFunc.AggregateMax` | 最大值 | `SqlFunc.AggregateMax(it.Age)` |
| `SqlFunc.AggregateMin` | 最小值 | `SqlFunc.AggregateMin(it.Age)` |
| `SqlFunc.AggregateAvg` | 平均值 | `SqlFunc.AggregateAvg(it.Score)` |
| `SqlFunc.AggregateDistinctCount` | 去重计数 | `SqlFunc.AggregateDistinctCount(it.ClassId)` |

### 9.5 综合聚合查询示例

```csharp
// 综合统计：每个班级的各项统计
var list = db.Queryable<Student>()
    .GroupBy(it => it.ClassId)
    .Select(it => new
    {
        ClassId = it.ClassId,
        StudentCount = SqlFunc.AggregateCount(it.Id),
        MaxAge = SqlFunc.AggregateMax(it.Age),
        MinAge = SqlFunc.AggregateMin(it.Age),
        AvgAge = SqlFunc.AggregateAvg(it.Age),
        TotalAge = SqlFunc.AggregateSum(it.Age)
    })
    .OrderByDescending(it => SqlFunc.AggregateCount(it.Id))
    .ToList();
```

生成的 SQL：

```sql
SELECT ClassId,
       COUNT(Id) AS StudentCount,
       MAX(Age) AS MaxAge,
       MIN(Age) AS MinAge,
       AVG(Age) AS AvgAge,
       SUM(Age) AS TotalAge
FROM Student
GROUP BY ClassId
ORDER BY COUNT(Id) DESC
```

## 10. Distinct与分页

### 10.1 Distinct去重

```csharp
// 去重查询
var list = db.Queryable<Student>()
    .Distinct()
    .Select(it => it.ClassId)
    .ToList();
```

生成的 SQL：

```sql
SELECT DISTINCT ClassId FROM Student
```

### 10.2 Take / Top - 取前N条

```csharp
// 取前10条
var list = db.Queryable<Student>()
    .Take(10)
    .ToList();

// 等价于
var list = db.Queryable<Student>()
    .Top(10)
    .ToList();
```

生成的 SQL：

```sql
-- SQL Server
SELECT TOP 10 * FROM Student

-- MySQL
SELECT * FROM Student LIMIT 10
```

### 10.3 Skip - 跳过N条

```csharp
// 跳过前5条，取接下来的10条
var list = db.Queryable<Student>()
    .Skip(5)
    .Take(10)
    .ToList();
```

### 10.4 ToPageList - 标准分页

```csharp
// 分页查询
int pageIndex = 1;   // 当前页码（从1开始）
int pageSize = 10;   // 每页条数
int totalCount = 0;  // 总记录数（输出参数）

var list = db.Queryable<Student>()
    .Where(it => it.Age > 18)
    .OrderBy(it => it.Id)
    .ToPageList(pageIndex, pageSize, ref totalCount);

Console.WriteLine($"当前第 {pageIndex} 页，每页 {pageSize} 条");
Console.WriteLine($"总共 {totalCount} 条记录");
Console.WriteLine($"总共 {Math.Ceiling((double)totalCount / pageSize)} 页");
```

### 10.5 异步分页

```csharp
// 异步分页查询
RefAsync<int> totalCount = new RefAsync<int>();

var list = await db.Queryable<Student>()
    .Where(it => it.Age > 18)
    .OrderBy(it => it.Id)
    .ToPageListAsync(pageIndex, pageSize, totalCount);

Console.WriteLine($"总记录数: {totalCount.Value}");
```

### 10.6 ToOffsetPage - 大数据分页

对于大数据量场景，使用 `ToOffsetPage` 可以获得更好的性能：

```csharp
// 大数据分页（使用 OFFSET...FETCH）
var list = db.Queryable<Student>()
    .OrderBy(it => it.Id)
    .ToOffsetPage(pageIndex, pageSize);
```

生成的 SQL（SQL Server）：

```sql
SELECT * FROM Student
ORDER BY Id
OFFSET 0 ROWS FETCH NEXT 10 ROWS ONLY
```

### 10.7 完整分页示例

```csharp
/// <summary>
/// 分页查询服务方法
/// </summary>
public PageResult<StudentDto> GetStudentPage(StudentQueryDto query)
{
    int totalCount = 0;

    var list = db.Queryable<Student>()
        // 动态条件
        .WhereIF(!string.IsNullOrEmpty(query.Name), it => it.Name.Contains(query.Name))
        .WhereIF(query.Age.HasValue, it => it.Age == query.Age)
        .WhereIF(query.ClassId.HasValue, it => it.ClassId == query.ClassId)
        // 排序
        .OrderBy(it => it.Id, OrderByType.Desc)
        // 投影到 DTO
        .Select(it => new StudentDto
        {
            Id = it.Id,
            Name = it.Name,
            Age = it.Age
        })
        // 分页
        .ToPageList(query.PageIndex, query.PageSize, ref totalCount);

    return new PageResult<StudentDto>
    {
        Data = list,
        Total = totalCount,
        PageIndex = query.PageIndex,
        PageSize = query.PageSize
    };
}

// 查询参数 DTO
public class StudentQueryDto
{
    public string Name { get; set; }
    public int? Age { get; set; }
    public int? ClassId { get; set; }
    public int PageIndex { get; set; } = 1;
    public int PageSize { get; set; } = 10;
}

// 分页结果 DTO
public class PageResult<T>
{
    public List<T> Data { get; set; }
    public int Total { get; set; }
    public int PageIndex { get; set; }
    public int PageSize { get; set; }
    public int TotalPages => (int)Math.Ceiling((double)Total / PageSize);
}
```

## 11. SQL调试与输出

### 11.1 查看生成的SQL

开发过程中，查看生成的 SQL 对于调试非常重要：

```csharp
// 方式1：通过 Aop 打印所有执行的 SQL
db.Aop.OnLogExecuting = (sql, pars) =>
{
    Console.WriteLine("=== SQL ===");
    Console.WriteLine(sql);
    Console.WriteLine("=== 参数 ===");
    foreach (var p in pars)
    {
        Console.WriteLine($"{p.ParameterName} = {p.Value}");
    }
    Console.WriteLine("============");
};
```

### 11.2 获取SQL但不执行

```csharp
// 方式2：只获取 SQL 不执行
var sqlInfo = db.Queryable<Student>()
    .Where(it => it.Age > 18)
    .OrderBy(it => it.Id)
    .ToSql();

Console.WriteLine($"SQL: {sqlInfo.Key}");
Console.WriteLine($"参数: {string.Join(", ", sqlInfo.Value.Select(p => $"{p.ParameterName}={p.Value}"))}");
```

### 11.3 SQL执行时间统计

```csharp
// 方式3：统计 SQL 执行时间
db.Aop.OnLogExecuted = (sql, pars) =>
{
    // 获取执行时间
    Console.WriteLine($"SQL执行时间: {db.Ado.SqlExecutionTime.TotalMilliseconds}ms");

    // 记录慢查询
    if (db.Ado.SqlExecutionTime.TotalSeconds > 1)
    {
        Console.WriteLine($"[慢查询警告] 执行时间: {db.Ado.SqlExecutionTime.TotalSeconds}s");
        Console.WriteLine($"SQL: {sql}");
    }
};
```

### 11.4 完整参数化SQL还原

```csharp
// 获取完整的可执行 SQL（参数值已替换）
db.Aop.OnLogExecuting = (sql, pars) =>
{
    // 使用 UtilMethods 还原完整SQL
    var fullSql = UtilMethods.GetSqlString(DbType.MySql, sql, pars);
    Console.WriteLine($"完整SQL: {fullSql}");
};
```

### 11.5 结合日志框架

```csharp
// 结合 Serilog 或 NLog 等日志框架
db.Aop.OnLogExecuting = (sql, pars) =>
{
    // 使用你的日志框架记录
    Log.Information("SqlSugar执行SQL: {Sql}", sql);
};

db.Aop.OnLogExecuted = (sql, pars) =>
{
    var elapsed = db.Ado.SqlExecutionTime.TotalMilliseconds;
    if (elapsed > 1000)
    {
        Log.Warning("SqlSugar慢查询: {Sql}, 耗时: {Elapsed}ms", sql, elapsed);
    }
};

// 捕获错误
db.Aop.OnError = (exp) =>
{
    Log.Error(exp, "SqlSugar执行出错: {Message}", exp.Message);
};
```

### 11.6 调试技巧总结

| 方法 | 适用场景 | 说明 |
|------|---------|------|
| `Aop.OnLogExecuting` | 全局监控 | 记录所有执行的 SQL |
| `Aop.OnLogExecuted` | 性能监控 | 记录执行耗时 |
| `ToSql()` | 单条调试 | 获取 SQL 但不执行 |
| `Aop.OnError` | 错误处理 | 捕获 SQL 执行错误 |
| `UtilMethods.GetSqlString` | 还原SQL | 将参数化SQL还原为完整SQL |

## 12. 本章小结

本章详细介绍了 SqlSugar 的基础查询操作：

- **Queryable 概述**：链式调用、延迟执行、自动参数化的查询构建器
- **基础查询方法**：`ToList`、`First`、`Single`、`Count`、`Any`、`Max/Min/Sum/Avg`
- **Where 条件查询**：Lambda 表达式、多条件组合、动态条件（`WhereIF`）、条件构造器
- **模糊查询**：`Contains`（LIKE）、`StartsWith`、`EndsWith`
- **In 与 Between 查询**：数组/列表的 `Contains` 实现 IN、`SqlFunc.Between` 范围查询
- **空值检查**：`== null`、`IsNullOrEmpty`、`SqlFunc.IsNull` 默认值
- **排序**：`OrderBy`、`OrderByDescending`、多字段排序、条件排序
- **Select 投影**：指定列、匿名类型、DTO 映射、计算列
- **分组聚合**：`GroupBy`、`Having`、`AggregateCount/Sum/Max/Min/Avg`
- **Distinct 与分页**：去重、`Take/Skip`、`ToPageList` 标准分页、大数据分页
- **SQL 调试**：`Aop.OnLogExecuting`、`ToSql()`、执行时间统计、慢查询告警

掌握这些基础查询操作后，你已经可以处理大部分日常开发中的数据查询需求了。
