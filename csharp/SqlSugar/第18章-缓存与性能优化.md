# 第18章：缓存与性能优化

## 18.1 SqlSugar缓存机制

### 18.1.1 缓存概述

SqlSugar提供了内置的查询缓存机制，可以将频繁查询的结果缓存到内存中，减少数据库访问次数，显著提升应用性能。

### 18.1.2 ICacheService接口

SqlSugar通过`ICacheService`接口定义缓存行为，开发者可以使用默认实现或自定义缓存策略。

```csharp
public interface ICacheService
{
    void Add<V>(string key, V value);
    void Add<V>(string key, V value, int cacheDurationInSeconds);
    bool ContainsKey<V>(string key);
    V Get<V>(string key);
    IEnumerable<string> GetAllKey<V>();
    V GetOrCreate<V>(string key, Func<V> create, int cacheDurationInSeconds = int.MaxValue);
    void Remove<V>(string key);
}
```

## 18.2 内置缓存使用

### 18.2.1 配置缓存

```csharp
var db = new SqlSugarClient(new ConnectionConfig()
{
    ConnectionString = "连接字符串",
    DbType = DbType.SqlServer,
    IsAutoCloseConnection = true,
    // 使用内置缓存
    MoreSettings = new ConnMoreSettings()
    {
        IsAutoRemoveDataCache = true // 自动清除相关缓存
    }
});
```

### 18.2.2 查询缓存

```csharp
// 使用WithCache进行查询缓存
var list = db.Queryable<User>()
    .WithCache(60) // 缓存60秒
    .ToList();

// 第二次调用会直接从缓存获取
var list2 = db.Queryable<User>()
    .WithCache(60)
    .ToList();

// 带条件的缓存查询
var user = db.Queryable<User>()
    .Where(u => u.Id == 1)
    .WithCache(300)
    .First();
```

### 18.2.3 自动缓存失效

当开启`IsAutoRemoveDataCache`后，对表进行增删改操作时，SqlSugar会自动清除该表相关的缓存。

```csharp
// 查询并缓存
var users = db.Queryable<User>().WithCache().ToList();

// 插入新数据后，User表的缓存会自动清除
db.Insertable(new User { Name = "新用户" }).ExecuteCommand();

// 再次查询会从数据库获取最新数据
var freshUsers = db.Queryable<User>().WithCache().ToList();
```

## 18.3 自定义缓存实现

### 18.3.1 Redis缓存实现

```csharp
public class RedisCacheService : ICacheService
{
    private readonly IDatabase _redis;

    public RedisCacheService(string connectionString)
    {
        var connection = ConnectionMultiplexer.Connect(connectionString);
        _redis = connection.GetDatabase();
    }

    public void Add<V>(string key, V value)
    {
        _redis.StringSet(key, JsonConvert.SerializeObject(value));
    }

    public void Add<V>(string key, V value, int cacheDurationInSeconds)
    {
        _redis.StringSet(key, JsonConvert.SerializeObject(value),
            TimeSpan.FromSeconds(cacheDurationInSeconds));
    }

    public bool ContainsKey<V>(string key)
    {
        return _redis.KeyExists(key);
    }

    public V Get<V>(string key)
    {
        var value = _redis.StringGet(key);
        if (value.IsNullOrEmpty) return default;
        return JsonConvert.DeserializeObject<V>(value);
    }

    public IEnumerable<string> GetAllKey<V>()
    {
        var server = _redis.Multiplexer.GetServer(_redis.Multiplexer.GetEndPoints()[0]);
        return server.Keys(pattern: "SqlSugarCache:*").Select(k => k.ToString());
    }

    public V GetOrCreate<V>(string key, Func<V> create, int cacheDurationInSeconds = int.MaxValue)
    {
        if (ContainsKey<V>(key))
            return Get<V>(key);

        var result = create();
        Add(key, result, cacheDurationInSeconds);
        return result;
    }

    public void Remove<V>(string key)
    {
        _redis.KeyDelete(key);
    }
}

// 注册Redis缓存
var db = new SqlSugarClient(new ConnectionConfig()
{
    ConnectionString = "连接字符串",
    DbType = DbType.SqlServer,
    IsAutoCloseConnection = true,
    ConfigureExternalServices = new ConfigureExternalServices()
    {
        DataInfoCacheService = new RedisCacheService("localhost:6379")
    }
});
```

### 18.3.2 MemoryCache实现

```csharp
public class MemoryCacheService : ICacheService
{
    private static readonly MemoryCache _cache = new MemoryCache(new MemoryCacheOptions());

    public void Add<V>(string key, V value)
    {
        _cache.Set(key, value);
    }

    public void Add<V>(string key, V value, int cacheDurationInSeconds)
    {
        _cache.Set(key, value, TimeSpan.FromSeconds(cacheDurationInSeconds));
    }

    public bool ContainsKey<V>(string key)
    {
        return _cache.TryGetValue(key, out _);
    }

    public V Get<V>(string key)
    {
        return _cache.Get<V>(key);
    }

    public IEnumerable<string> GetAllKey<V>()
    {
        // MemoryCache不支持遍历所有key，需自行维护
        return new List<string>();
    }

    public V GetOrCreate<V>(string key, Func<V> create, int cacheDurationInSeconds = int.MaxValue)
    {
        return _cache.GetOrCreate(key, entry =>
        {
            entry.AbsoluteExpirationRelativeToNow = TimeSpan.FromSeconds(cacheDurationInSeconds);
            return create();
        });
    }

    public void Remove<V>(string key)
    {
        _cache.Remove(key);
    }
}
```

## 18.4 性能优化策略

### 18.4.1 连接管理优化

```csharp
// 推荐：使用IsAutoCloseConnection
var db = new SqlSugarClient(new ConnectionConfig()
{
    ConnectionString = "连接字符串",
    DbType = DbType.SqlServer,
    IsAutoCloseConnection = true // 自动管理连接，用完即关
});

// 推荐：使用SqlSugarScope（单例模式）
public static SqlSugarScope Db = new SqlSugarScope(new ConnectionConfig()
{
    ConnectionString = "连接字符串",
    DbType = DbType.SqlServer,
    IsAutoCloseConnection = true
});
```

### 18.4.2 查询性能优化

```csharp
// 1. 只查需要的列
var names = db.Queryable<User>()
    .Select(u => u.Name)
    .ToList();

// 2. 使用First代替ToList().FirstOrDefault()
var user = db.Queryable<User>()
    .Where(u => u.Id == 1)
    .First(); // 生成 TOP 1

// 3. 使用Any代替Count判断是否存在
bool exists = db.Queryable<User>()
    .Where(u => u.Name == "张三")
    .Any(); // 比Count高效

// 4. 分页查询避免大偏移量
var page = db.Queryable<User>()
    .OrderBy(u => u.Id)
    .ToOffsetPage(1, 20); // 使用OFFSET分页

// 5. 大数据量使用流式查询
db.Queryable<Order>().ForEach(order =>
{
    ProcessOrder(order);
}, 1000); // 每次读取1000条
```

### 18.4.3 写入性能优化

```csharp
// 1. 批量插入使用BulkCopy
db.Fastest<User>().BulkCopy(largeList);

// 2. 批量更新使用BulkUpdate
db.Fastest<User>().BulkUpdate(largeList);

// 3. 大量数据分页处理
db.Fastest<User>().PageSize(50000).BulkCopy(largeList);

// 4. 插入忽略不必要的列
db.Insertable(user)
    .IgnoreColumns(u => new { u.CreateTime, u.UpdateTime })
    .ExecuteCommand();

// 5. 更新只更新变化的列
db.Updateable(user)
    .UpdateColumns(u => new { u.Name, u.Age })
    .ExecuteCommand();
```

### 18.4.4 SQL优化建议

```csharp
// 1. 避免SELECT *
// 不推荐
var list = db.Queryable<User>().ToList();
// 推荐
var list = db.Queryable<User>()
    .Select(u => new { u.Id, u.Name })
    .ToList();

// 2. 合理使用索引，Where条件匹配索引字段
var users = db.Queryable<User>()
    .Where(u => u.Email == "test@example.com") // Email上应有索引
    .First();

// 3. 避免在Where中使用函数
// 不推荐
.Where(u => u.Name.Substring(0, 1) == "张")
// 推荐
.Where(u => u.Name.StartsWith("张"))

// 4. 使用参数化查询（SqlSugar默认参数化，无需额外处理）
```

### 18.4.5 二级缓存策略

```csharp
// 配置表维度的缓存策略
public class CacheConfig
{
    // 字典表 - 长时间缓存
    public static List<DictItem> GetDictItems(ISqlSugarClient db)
    {
        return db.Queryable<DictItem>()
            .WithCache(3600) // 缓存1小时
            .ToList();
    }

    // 用户信息 - 中等缓存
    public static User GetUser(ISqlSugarClient db, int id)
    {
        return db.Queryable<User>()
            .Where(u => u.Id == id)
            .WithCache(300) // 缓存5分钟
            .First();
    }

    // 实时数据 - 不缓存
    public static List<Order> GetRecentOrders(ISqlSugarClient db)
    {
        return db.Queryable<Order>()
            .OrderBy(o => o.CreateTime, OrderByType.Desc)
            .Take(20)
            .ToList(); // 不使用缓存
    }
}
```

## 18.5 性能监控

### 18.5.1 SQL执行时间统计

```csharp
db.Aop.OnLogExecuted = (sql, pars) =>
{
    var time = db.Ado.SqlExecutionTime;

    // 统计各级别SQL数量
    if (time.TotalMilliseconds < 100)
        Interlocked.Increment(ref _fastCount);
    else if (time.TotalMilliseconds < 1000)
        Interlocked.Increment(ref _normalCount);
    else
        Interlocked.Increment(ref _slowCount);
};
```

## 18.6 本章小结

本章详细介绍了SqlSugar的缓存与性能优化：

- **查询缓存**：使用WithCache实现查询结果缓存，支持自动失效
- **自定义缓存**：通过ICacheService接口实现Redis等分布式缓存
- **连接优化**：使用IsAutoCloseConnection和SqlSugarScope管理连接
- **查询优化**：按需查询列、使用First/Any、流式查询大数据
- **写入优化**：BulkCopy批量插入、按需更新列
- **SQL优化**：避免全表扫描、合理使用索引、参数化查询
- **性能监控**：SQL执行时间统计和慢SQL告警

性能优化是一个系统工程，需要从连接管理、SQL编写、缓存策略、索引设计等多个维度综合考虑。
