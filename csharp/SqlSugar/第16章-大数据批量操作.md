## 1. 批量操作概述

### 1.1 为什么需要批量操作

在企业级应用中，经常需要处理大量数据的导入、导出、迁移和同步。如果使用逐条插入/更新的方式，性能将会非常低下：

```
┌─────────────────────────────────────────────────────────┐
│                    逐条插入 10万条数据                     │
│                                                         │
│  ┌───┐  ┌───┐  ┌───┐  ┌───┐       ┌───┐               │
│  │ 1 │→│ 2 │→│ 3 │→│ 4 │→ ... →│10万│               │
│  └───┘  └───┘  └───┘  └───┘       └───┘               │
│                                                         │
│  每条数据：建立连接 → 发送SQL → 等待响应 → 关闭连接       │
│  总耗时：约 300-600 秒                                   │
├─────────────────────────────────────────────────────────┤
│                    BulkCopy 10万条数据                    │
│                                                         │
│  ┌──────────────────────────────────┐                   │
│  │  一次性批量写入 10万条            │                   │
│  │  使用数据库原生批量协议           │                   │
│  └──────────────────────────────────┘                   │
│                                                         │
│  总耗时：约 1-3 秒                                       │
└─────────────────────────────────────────────────────────┘
```

### 1.2 SqlSugar 批量操作 API

| 方法 | 说明 | 性能 | 适用场景 |
|------|------|------|---------|
| `Fastest<T>().BulkCopy()` | 极速批量插入 | ⭐⭐⭐⭐⭐ | 大批量插入 |
| `Fastest<T>().BulkUpdate()` | 极速批量更新 | ⭐⭐⭐⭐⭐ | 大批量更新 |
| `Fastest<T>().BulkMerge()` | 批量合并（Upsert） | ⭐⭐⭐⭐ | 插入或更新 |
| `Insertable(list).ExecuteCommand()` | 普通批量插入 | ⭐⭐⭐ | 中等数据量 |
| `Insertable(list).PageSize(1000)` | 分页批量插入 | ⭐⭐⭐⭐ | 中大数据量 |

### 1.3 性能对比概览

以 10 万条数据为例的大致性能参考：

| 操作方式 | 耗时 | 内存占用 | 说明 |
|---------|------|---------|------|
| 逐条 Insert | 300-600秒 | 低 | 不推荐 |
| Insertable(list) | 30-60秒 | 中 | 拼接 SQL |
| Insertable + PageSize | 15-30秒 | 中 | 分批拼接 SQL |
| Fastest.BulkCopy | 1-3秒 | 高 | 数据库原生协议 |

## 2. BulkCopy 批量插入

### 2.1 基本用法

`Fastest<T>().BulkCopy()` 使用数据库原生的批量插入协议，是 SqlSugar 中最快的插入方式：

```csharp
// 准备测试数据
var list = new List<Student>();
for (int i = 0; i < 100000; i++)
{
    list.Add(new Student
    {
        Name = $"学生{i}",
        Age = 18 + (i % 10),
        ClassId = (i % 20) + 1,
        Score = 60 + (i % 40),
        CreateTime = DateTime.Now
    });
}

// BulkCopy 批量插入
db.Fastest<Student>().BulkCopy(list);
```

### 2.2 指定列插入

```csharp
// 只插入指定列
db.Fastest<Student>()
    .BulkCopy(list, new string[] { "Name", "Age", "ClassId" });
```

### 2.3 异步批量插入

```csharp
// 异步 BulkCopy
await db.Fastest<Student>().BulkCopyAsync(list);
```

### 2.4 自增列处理

```csharp
// 默认情况下，BulkCopy 会忽略自增列
// 如果需要保留原始 ID 值（如数据迁移）
db.Fastest<Student>()
    .SetIdentity(true)  // 保留自增 ID
    .BulkCopy(list);
```

### 2.5 BulkCopy 的工作原理

不同数据库的 BulkCopy 底层实现不同：

| 数据库 | 底层技术 | 说明 |
|--------|---------|------|
| SQL Server | `SqlBulkCopy` | ADO.NET 原生批量复制 |
| MySQL | `LOAD DATA LOCAL INFILE` 或 `MySqlBulkCopy` | MySQL 原生批量加载 |
| PostgreSQL | `COPY FROM STDIN` | PostgreSQL 原生 COPY 协议 |
| Oracle | `OracleBulkCopy` | Oracle 原生批量复制 |
| SQLite | 多行 INSERT | SQLite 无原生 BulkCopy |

```csharp
// SQL Server BulkCopy 底层执行流程：
// 1. 将 List<T> 转换为 DataTable
// 2. 创建 SqlBulkCopy 对象
// 3. 映射列名
// 4. 使用 SqlBulkCopy.WriteToServer 一次性写入
// 这个过程绕过了 SQL 解析，直接通过 TDS 协议传输二进制数据
```

## 3. BulkUpdate 批量更新

### 3.1 基本用法

```csharp
// 批量更新（根据主键匹配）
var list = db.Queryable<Student>()
    .Where(s => s.ClassId == 1)
    .ToList();

// 修改数据
foreach (var item in list)
{
    item.Score += 5;  // 加5分
}

// 批量更新
db.Fastest<Student>().BulkUpdate(list);
```

### 3.2 指定更新列

```csharp
// 只更新 Score 和 UpdateTime 列
db.Fastest<Student>()
    .BulkUpdate(list, new string[] { "Score", "UpdateTime" });
```

### 3.3 指定匹配列

```csharp
// 使用非主键列进行匹配更新
db.Fastest<Student>()
    .BulkUpdate(list,
        new string[] { "Score", "UpdateTime" },  // 更新列
        new string[] { "StudentNo" });            // 匹配列（替代主键）
```

### 3.4 异步批量更新

```csharp
await db.Fastest<Student>().BulkUpdateAsync(list);
```

### 3.5 BulkUpdate 工作原理

```
┌──────────────────────────────────────────────────┐
│               BulkUpdate 执行流程                  │
│                                                  │
│  1. 创建临时表                                    │
│  2. BulkCopy 数据到临时表                         │
│  3. UPDATE 主表 SET ... FROM 临时表 WHERE 主键匹配 │
│  4. 删除临时表                                    │
└──────────────────────────────────────────────────┘
```

```sql
-- BulkUpdate 生成的 SQL 类似：
-- 步骤1：创建临时表
CREATE TABLE #TempStudent (Id INT, Score DECIMAL, UpdateTime DATETIME)

-- 步骤2：BulkCopy 到临时表
-- （使用 SqlBulkCopy 协议，无 SQL 语句）

-- 步骤3：批量更新
UPDATE S SET
    S.Score = T.Score,
    S.UpdateTime = T.UpdateTime
FROM Student S
INNER JOIN #TempStudent T ON S.Id = T.Id

-- 步骤4：清理
DROP TABLE #TempStudent
```

## 4. BulkMerge 批量合并

### 4.1 概念说明

`BulkMerge`（又称 Upsert）是一种"有则更新，无则插入"的操作，等同于 SQL Server 的 `MERGE` 语句或 MySQL 的 `INSERT ... ON DUPLICATE KEY UPDATE`：

```
┌──────────────────────────────────────────────────┐
│                 BulkMerge 逻辑                    │
│                                                  │
│  对于每条数据：                                   │
│    ├─ 如果主键已存在 → UPDATE 更新                │
│    └─ 如果主键不存在 → INSERT 插入                │
└──────────────────────────────────────────────────┘
```

### 4.2 基本用法

```csharp
var list = new List<Student>
{
    new Student { Id = 1, Name = "张三（更新）", Age = 20 },   // 已存在，更新
    new Student { Id = 2, Name = "李四（更新）", Age = 21 },   // 已存在，更新
    new Student { Id = 0, Name = "新学生1", Age = 18 },        // 不存在，插入
    new Student { Id = 0, Name = "新学生2", Age = 19 }         // 不存在，插入
};

// BulkMerge：有则更新，无则插入
db.Fastest<Student>().BulkMerge(list);
```

### 4.3 指定合并列

```csharp
// 指定更新的列和匹配的列
db.Fastest<Student>()
    .BulkMerge(list,
        new string[] { "Name", "Age", "UpdateTime" },   // 更新列
        new string[] { "StudentNo" });                    // 匹配列
```

### 4.4 异步批量合并

```csharp
await db.Fastest<Student>().BulkMergeAsync(list);
```

### 4.5 使用场景

| 场景 | 说明 |
|------|------|
| 数据同步 | 从外部系统同步数据，新增或更新 |
| Excel 导入 | 导入时可能包含已有数据 |
| 缓存预热 | 将缓存数据批量写回数据库 |
| 配置更新 | 批量更新系统配置 |

## 5. BulkDelete 批量删除

### 5.1 基本用法

```csharp
// 根据主键批量删除
var deleteList = new List<Student>
{
    new Student { Id = 1 },
    new Student { Id = 2 },
    new Student { Id = 3 }
};

db.Fastest<Student>().BulkDelete(deleteList);
```

### 5.2 根据条件批量删除

```csharp
// 使用条件批量删除（非 Fastest）
db.Deleteable<Student>()
    .Where(s => s.IsActive == false)
    .ExecuteCommand();

// 使用 IN 批量删除
var ids = new List<int> { 1, 2, 3, 4, 5 };
db.Deleteable<Student>()
    .In(ids)
    .ExecuteCommand();
```

### 5.3 批量软删除

```csharp
// 批量软删除（更新 IsDeleted 字段）
var ids = new List<int> { 1, 2, 3, 4, 5 };
db.Updateable<Student>()
    .SetColumns(s => s.IsDeleted == true)
    .SetColumns(s => s.DeleteTime == DateTime.Now)
    .Where(s => ids.Contains(s.Id))
    .ExecuteCommand();

// 使用 BulkUpdate 实现批量软删除
var deleteList = ids.Select(id => new Student
{
    Id = id,
    IsDeleted = true,
    DeleteTime = DateTime.Now
}).ToList();

db.Fastest<Student>()
    .BulkUpdate(deleteList, new string[] { "IsDeleted", "DeleteTime" });
```

## 6. PageSize 分批处理

### 6.1 Insertable 分批插入

当数据量较大但不想使用 BulkCopy 时，可以使用 `PageSize` 分批插入：

```csharp
// 每批 1000 条，分批插入
db.Insertable(list)
    .PageSize(1000)
    .ExecuteCommand();
```

### 6.2 分批插入的优势

```
┌─────────────────────────────────────────────────────────┐
│  不分批：一次性生成超长 SQL                               │
│  INSERT INTO Student VALUES (1,'a',18),(2,'b',19),...    │
│  SQL 长度可能超过数据库限制，导致失败                     │
├─────────────────────────────────────────────────────────┤
│  使用 PageSize(1000)：                                   │
│  第1批：INSERT INTO Student VALUES (1,'a')...(1000条)    │
│  第2批：INSERT INTO Student VALUES (1001,'b')...(1000条) │
│  第3批：...                                              │
│  每批 SQL 大小可控，稳定可靠                              │
└─────────────────────────────────────────────────────────┘
```

### 6.3 分批与 BulkCopy 对比

| 特性 | PageSize 分批 | BulkCopy |
|------|-------------|----------|
| 性能 | 中等 | 极高 |
| 触发器 | ✅ 会触发 | ❌ 通常不触发 |
| 自增返回 | ✅ 可返回 | ❌ 无法返回 |
| 数据库兼容 | 所有数据库 | 部分特性因库而异 |
| SQL 日志 | ✅ 有完整 SQL | ❌ 无 SQL 日志 |

### 6.4 分批更新和删除

```csharp
// 分批更新
db.Updateable(list)
    .PageSize(1000)
    .ExecuteCommand();

// 分批删除大量数据
var allIds = db.Queryable<Student>()
    .Where(s => s.IsDeleted == true)
    .Select(s => s.Id)
    .ToList();

// 每批删除 5000 条，避免长事务
foreach (var batch in allIds.Chunk(5000))
{
    db.Deleteable<Student>()
        .In(batch.ToList())
        .ExecuteCommand();
}
```

## 7. DataTable 批量操作

### 7.1 DataTable 批量插入

有时数据源是 `DataTable`（如从 Excel 读取或第三方接口返回），SqlSugar 支持直接操作 DataTable：

```csharp
// 从 DataTable 批量插入
DataTable dt = GetDataTableFromExcel("students.xlsx");

// 方式1：使用 Insertable
db.Insertable(dt)
    .AS("Student")          // 指定目标表名
    .ExecuteCommand();

// 方式2：使用 Fastest BulkCopy
db.Fastest<DataTable>()
    .AS("Student")
    .BulkCopy("Student", dt);
```

### 7.2 DataTable 列映射

```csharp
// 当 DataTable 列名与数据库列名不一致时
DataTable dt = new DataTable();
dt.Columns.Add("姓名", typeof(string));
dt.Columns.Add("年龄", typeof(int));
dt.Columns.Add("班级", typeof(string));

// 添加数据
dt.Rows.Add("张三", 18, "一班");
dt.Rows.Add("李四", 19, "二班");

// 列映射
dt.Columns["姓名"].ColumnName = "Name";
dt.Columns["年龄"].ColumnName = "Age";
dt.Columns["班级"].ColumnName = "ClassName";

db.Fastest<DataTable>()
    .AS("Student")
    .BulkCopy("Student", dt);
```

### 7.3 从查询结果生成 DataTable

```csharp
// 查询结果转为 DataTable
DataTable dt = db.Queryable<Student>()
    .Where(s => s.ClassId == 1)
    .Select(s => new { s.Name, s.Age, s.Score })
    .ToDataTable();

// 将 DataTable 写入另一个表
db.Fastest<DataTable>()
    .AS("StudentBackup")
    .BulkCopy("StudentBackup", dt);
```

## 8. 性能基准测试

### 8.1 插入性能对比

以下为 10 万条数据在 SQL Server 上的测试结果（仅供参考，实际性能取决于硬件和配置）：

```csharp
// 性能测试代码
public class BulkPerformanceTest
{
    private readonly ISqlSugarClient _db;

    public BulkPerformanceTest(ISqlSugarClient db) => _db = db;

    public void RunTest()
    {
        var data = GenerateTestData(100000);

        // 测试1：逐条插入
        var sw1 = Stopwatch.StartNew();
        foreach (var item in data)
        {
            _db.Insertable(item).ExecuteCommand();
        }
        sw1.Stop();
        Console.WriteLine($"逐条插入：{sw1.Elapsed.TotalSeconds:F2}秒");

        // 测试2：普通批量插入
        var sw2 = Stopwatch.StartNew();
        _db.Insertable(data).ExecuteCommand();
        sw2.Stop();
        Console.WriteLine($"普通批量：{sw2.Elapsed.TotalSeconds:F2}秒");

        // 测试3：分批插入
        var sw3 = Stopwatch.StartNew();
        _db.Insertable(data).PageSize(5000).ExecuteCommand();
        sw3.Stop();
        Console.WriteLine($"分批插入：{sw3.Elapsed.TotalSeconds:F2}秒");

        // 测试4：BulkCopy
        var sw4 = Stopwatch.StartNew();
        _db.Fastest<Student>().BulkCopy(data);
        sw4.Stop();
        Console.WriteLine($"BulkCopy：{sw4.Elapsed.TotalSeconds:F2}秒");
    }

    private List<Student> GenerateTestData(int count)
    {
        return Enumerable.Range(1, count)
            .Select(i => new Student
            {
                Name = $"Student_{i}",
                Age = 18 + (i % 10),
                Score = 60 + (i % 40),
                CreateTime = DateTime.Now
            })
            .ToList();
    }
}
```

### 8.2 测试结果参考

| 数据量 | 逐条插入 | 普通批量 | 分批(5000) | BulkCopy |
|--------|---------|---------|-----------|----------|
| 1,000 | 3秒 | 0.5秒 | 0.5秒 | 0.05秒 |
| 10,000 | 30秒 | 5秒 | 3秒 | 0.2秒 |
| 100,000 | 300秒 | 50秒 | 25秒 | 1.5秒 |
| 1,000,000 | 3000秒+ | 超时 | 250秒 | 15秒 |

> **结论**：当数据量超过 1 万条时，强烈建议使用 `BulkCopy`。

### 8.3 更新性能对比

| 数据量 | 逐条更新 | 普通批量 | BulkUpdate |
|--------|---------|---------|-----------|
| 1,000 | 3秒 | 1秒 | 0.1秒 |
| 10,000 | 30秒 | 10秒 | 0.5秒 |
| 100,000 | 300秒 | 100秒 | 3秒 |

## 9. 内存优化策略

### 9.1 分批加载数据

当要处理的数据量很大时，不应一次性将所有数据加载到内存：

```csharp
// ❌ 一次性加载 100 万条到内存
var allData = db.Queryable<Order>().ToList();  // 可能导致 OOM

// ✅ 分批加载处理
int pageSize = 10000;
int pageIndex = 1;
while (true)
{
    var batch = db.Queryable<Order>()
        .OrderBy(o => o.Id)
        .ToPageList(pageIndex, pageSize);

    if (batch.Count == 0)
        break;

    // 处理当前批次
    ProcessBatch(batch);

    pageIndex++;

    // 帮助 GC 回收
    batch = null;
}
```

### 9.2 使用 IEnumerable 流式读取

```csharp
// 流式读取，不会一次性加载所有数据到内存
var query = db.Queryable<Order>()
    .Where(o => o.Status == 3)
    .OrderBy(o => o.Id);

// 逐条处理
foreach (var order in query.ToEnumerable())
{
    // 每次只加载一条到内存
    ProcessOrder(order);
}
```

### 9.3 使用数据流进行大数据转移

```csharp
// 数据迁移：从源库读取，分批写入目标库
public async Task MigrateData(ISqlSugarClient sourceDb, ISqlSugarClient targetDb)
{
    int batchSize = 50000;
    int totalCount = sourceDb.Queryable<Order>().Count();
    int totalPages = (int)Math.Ceiling((double)totalCount / batchSize);

    Console.WriteLine($"总记录数：{totalCount}，分 {totalPages} 批处理");

    for (int page = 1; page <= totalPages; page++)
    {
        // 从源库分批读取
        var batch = sourceDb.Queryable<Order>()
            .OrderBy(o => o.Id)
            .ToPageList(page, batchSize);

        // 批量写入目标库
        await targetDb.Fastest<Order>().BulkCopyAsync(batch);

        Console.WriteLine($"已完成第 {page}/{totalPages} 批，共 {batch.Count} 条");

        // 释放内存
        batch.Clear();
        batch = null;

        // 适当延迟，减少数据库压力
        if (page % 10 == 0)
        {
            GC.Collect();
            await Task.Delay(100);
        }
    }
}
```

### 9.4 大对象字段优化

```csharp
// 如果表中有大文本或二进制字段，分批处理时应避免加载这些字段
var batch = db.Queryable<Document>()
    .Select(d => new Document
    {
        Id = d.Id,
        Title = d.Title,
        Status = d.Status
        // 不加载 Content（大文本字段），减少内存占用
    })
    .ToPageList(pageIndex, pageSize);
```

## 10. 流式查询大数据集

### 10.1 ForEach 流式处理

对于超大数据集，使用 `ForEach` 可以逐条处理而不必将所有数据加载到内存：

```csharp
// 流式处理百万级数据
db.Queryable<Order>()
    .Where(o => o.CreateTime.Year == 2024)
    .ForEach(order =>
    {
        // 逐条处理
        ProcessOrder(order);
    }, batchSize: 1000);  // 每次内部加载 1000 条
```

### 10.2 使用 DataReader 模式

```csharp
// 使用 DataReader 模式读取大数据
using (var reader = db.Queryable<Order>()
    .Where(o => o.Status == 3)
    .ToDataReader())
{
    while (reader.Read())
    {
        var orderId = reader.GetInt32(0);
        var orderNo = reader.GetString(1);
        var amount = reader.GetDecimal(2);

        // 逐条处理
        ProcessOrder(orderId, orderNo, amount);
    }
}
```

### 10.3 异步流式读取

```csharp
// .NET 8+ 支持 IAsyncEnumerable
await foreach (var order in db.Queryable<Order>()
    .Where(o => o.Status == 3)
    .ToAsyncEnumerable())
{
    await ProcessOrderAsync(order);
}
```

## 11. BulkQuery 查询优化

### 11.1 大数据量查询优化

当查询结果集很大时，SqlSugar 提供了一些优化方法：

```csharp
// 只查询需要的列，减少数据传输
var list = db.Queryable<Order>()
    .Select(o => new { o.Id, o.OrderNo, o.TotalAmount })
    .ToList();

// 使用 Take 限制结果数量
var top100 = db.Queryable<Order>()
    .OrderBy(o => o.TotalAmount, OrderByType.Desc)
    .Take(100)
    .ToList();
```

### 11.2 NoLock 无锁查询

```csharp
// SQL Server 使用 WITH(NOLOCK) 提升查询性能
var list = db.Queryable<Order>()
    .With(SqlWith.NoLock)
    .Where(o => o.Status == 3)
    .ToList();
// SQL: SELECT * FROM Orders WITH(NOLOCK) WHERE Status = 3
```

### 11.3 索引优化建议

```csharp
/// <summary>
/// 百万级数据高效插入

public async Task InsertMillionRecords()

    int totalCount = 1_000_000;
    int batchSize = 100_000;    // 每批 10 万条
    int batches = totalCount / batchSize;

    var sw = Stopwatch.StartNew();

        var batch = Enumerable.Range(i * batchSize + 1, batchSize)

                ClassId = (n % 50) + 1,
                Score = 60 + (n % 40),
                CreateTime = DateTime.Now
            })

        await db.Fastest<Student>().BulkCopyAsync(batch);

        Console.WriteLine($"已插入第 {i + 1}/{batches} 批（{(i + 1) * batchSize} 条）");

        // 释放当前批次内存
        batch.Clear();
        batch = null;
    }

    sw.Stop();
    Console.WriteLine($"总计插入 {totalCount} 条，耗时：{sw.Elapsed.TotalSeconds:F2}秒");
}
```

```csharp
/// <summary>

public async Task UpdateMillionRecords()
{
    int batchSize = 50000;
    int pageIndex = 1;

    while (true)
    {
        // 分批读取
        var batch = db.Queryable<Student>()
            .Where(s => s.NeedUpdate == true)
            .OrderBy(s => s.Id)
            .ToPageList(pageIndex, batchSize);

        if (batch.Count == 0)
            break;

        // 修改数据
        foreach (var student in batch)
        {
            student.Score = RecalculateScore(student);
            student.UpdateTime = DateTime.Now;
            student.NeedUpdate = false;
        }

        // 批量更新
        await db.Fastest<Student>()
            .BulkUpdateAsync(batch, new string[] { "Score", "UpdateTime", "NeedUpdate" });

        Console.WriteLine($"已更新第 {pageIndex} 批，共 {batch.Count} 条");
        pageIndex++;

        batch.Clear();
    }
}
```

```csharp
/// <summary>
/// 带错误恢复的分批导入
/// </summary>
public async Task<ImportResult> BulkImportWithRecovery(List<Student> allData)
{
    var result = new ImportResult();
    int batchSize = 10000;
    var batches = allData.Chunk(batchSize).ToList();

    for (int i = 0; i < batches.Count; i++)
    {
        var batch = batches[i].ToList();

        try
        {
            await db.Fastest<Student>().BulkCopyAsync(batch);
            result.SuccessCount += batch.Count;
            Console.WriteLine($"第 {i + 1}/{batches.Count} 批成功，共 {batch.Count} 条");
        }
        catch (Exception ex)
        {
            Console.WriteLine($"第 {i + 1} 批失败：{ex.Message}");

            // 降级为逐条插入，记录失败的行
            foreach (var item in batch)
            {
                try
                {
                    await db.Insertable(item).ExecuteCommandAsync();
                    result.SuccessCount++;
                }
                catch (Exception itemEx)
                {
                    result.FailedItems.Add(new FailedItem
                    {
                        Data = item,
                        Error = itemEx.Message
                    });
                    result.FailCount++;
                }
            }
        }
    }

    return result;
}

public class ImportResult
{
    public int SuccessCount { get; set; }
    public int FailCount { get; set; }
    public List<FailedItem> FailedItems { get; set; } = new();
}

public class FailedItem
{
    public object Data { get; set; }
    public string Error { get; set; }
}
```

```csharp
/// <summary>
/// 插入前进行数据验证
/// </summary>
public async Task<ImportResult> ValidateAndBulkInsert(List<Student> data)
{
    var validData = new List<Student>();
    var invalidData = new List<ValidationError>();

    foreach (var item in data)
    {
        var errors = ValidateStudent(item);
        if (errors.Any())
        {
            invalidData.Add(new ValidationError
            {
                Data = item,
                Errors = errors
            });
        }
        else
        {
            validData.Add(item);
        }
    }

    // 只插入通过验证的数据
    if (validData.Any())
    {
        await db.Fastest<Student>().BulkCopyAsync(validData);
    }

    return new ImportResult
    {
        SuccessCount = validData.Count,
        FailCount = invalidData.Count,
        ValidationErrors = invalidData
    };
}

private List<string> ValidateStudent(Student s)
{
    var errors = new List<string>();

    if (string.IsNullOrEmpty(s.Name))
        errors.Add("姓名不能为空");

    if (s.Name?.Length > 50)
        errors.Add("姓名长度不能超过50个字符");

    if (s.Age < 0 || s.Age > 150)
        errors.Add($"年龄 {s.Age} 不合法");

    if (s.Score < 0 || s.Score > 100)
        errors.Add($"成绩 {s.Score} 不合法");

    return errors;
}
```

```csharp
public class ExcelImportService
{
    private readonly ISqlSugarClient _db;

    public ExcelImportService(ISqlSugarClient db) => _db = db;

    /// <summary>
    /// 导入 Excel 数据
    /// </summary>
    public async Task<ImportResult> ImportFromExcel(Stream excelStream)
    {
        // 1. 读取 Excel（使用 MiniExcel 或 NPOI）
        var excelData = MiniExcel.Query<StudentImportDto>(excelStream).ToList();

        // 2. 数据验证
        var validData = new List<Student>();
        var errors = new List<string>();

        for (int i = 0; i < excelData.Count; i++)

            var validationErrors = ValidateRow(row, i + 2);  // 第2行开始是数据

                errors.AddRange(validationErrors);
                continue;

            validData.Add(MapToEntity(row));
        }

        // 3. 批量写入数据库
        if (validData.Any())
        {
            await _db.Fastest<Student>().BulkMergeAsync(validData);
        }

        return new ImportResult
        {
            SuccessCount = validData.Count,
            FailCount = excelData.Count - validData.Count,
            Errors = errors
        };
    }

    private Student MapToEntity(StudentImportDto dto)
    {
        return new Student
        {
            StudentNo = dto.StudentNo,
            Name = dto.Name?.Trim(),
            Age = dto.Age,
            ClassId = dto.ClassId,
            Score = dto.Score,
```

```csharp
public class DataMigrationService
{
    /// <summary>
    /// 跨库数据迁移
    /// </summary>
    public async Task MigrateOrders(ISqlSugarClient sourceDb, ISqlSugarClient targetDb)
    {
        var sw = Stopwatch.StartNew();
        int batchSize = 50000;
        long totalMigrated = 0;

        // 获取源表总数
        int totalCount = sourceDb.Queryable<Order>().Count();
        int totalBatches = (int)Math.Ceiling((double)totalCount / batchSize);

        Console.WriteLine($"开始迁移，总计 {totalCount} 条记录，分 {totalBatches} 批");

        // 确保目标表存在
        targetDb.CodeFirst.InitTables<Order>();

        for (int page = 1; page <= totalBatches; page++)
        {
            // 从源库读取
            var batch = sourceDb.Queryable<Order>()
                .OrderBy(o => o.Id)
                .ToPageList(page, batchSize);

            // 写入目标库
            await targetDb.Fastest<Order>()
                .SetIdentity(true)  // 保留原始 ID
                .BulkCopyAsync(batch);

            totalMigrated += batch.Count;
            var progress = (double)totalMigrated / totalCount * 100;
            Console.WriteLine($"进度：{progress:F1}%（{totalMigrated}/{totalCount}）");

            batch.Clear();
        }

        sw.Stop();
        Console.WriteLine($"迁移完成！总计 {totalMigrated} 条，耗时 {sw.Elapsed.TotalMinutes:F1} 分钟");
    }
}
```

```csharp
public class EtlService
{
    private readonly ISqlSugarClient _db;

    public EtlService(ISqlSugarClient db) => _db = db;

    /// <summary>
    /// 每日销售汇总 ETL
    /// </summary>
    public async Task DailySalesEtl(DateTime date)
    {
        Console.WriteLine($"开始执行 {date:yyyy-MM-dd} 销售汇总 ETL");

        // Extract：提取当日订单数据
        var orders = await _db.Queryable<Order>()
            .Where(o => SqlFunc.DateIsSame(o.CreateTime, date, DateType.Day))
            .Where(o => o.Status == 3)  // 已完成
            .ToListAsync();

        if (!orders.Any())
        {
            Console.WriteLine("当日无已完成订单");
            return;
        }

        // Transform：转换为汇总数据
        var summaries = orders
            .GroupBy(o => new { o.CustomerId, ProductId = 0 })
            .Select(g => new DailySalesSummary
            {
                SalesDate = date,
                CustomerId = g.Key.CustomerId,
                OrderCount = g.Count(),
                TotalAmount = g.Sum(o => o.TotalAmount),
                AvgAmount = g.Average(o => o.TotalAmount),
                MaxAmount = g.Max(o => o.TotalAmount),
                MinAmount = g.Min(o => o.TotalAmount),
                CreateTime = DateTime.Now
            })
            .ToList();

        // Load：加载到汇总表
        // 使用 BulkMerge，如果当天已有数据则更新
        await _db.Fastest<DailySalesSummary>().BulkMergeAsync(summaries);

        Console.WriteLine($"ETL 完成：处理 {orders.Count} 条订单，生成 {summaries.Count} 条汇总");
    }
}
```

```csharp
public class ReportPrecomputeService
{
    private readonly ISqlSugarClient _db;

    public ReportPrecomputeService(ISqlSugarClient db) => _db = db;

    /// <summary>
    /// 预计算月度报表数据
    /// </summary>
    public async Task PrecomputeMonthlyReport(int year, int month)
    {
        var startDate = new DateTime(year, month, 1);
        var endDate = startDate.AddMonths(1);

        // 1. 商品销售统计
        var productStats = await _db.Queryable<OrderDetail, Order>(
            (d, o) => d.OrderId == o.Id)
            .Where((d, o) => o.CreateTime >= startDate && o.CreateTime < endDate)
            .Where((d, o) => o.Status == 3)
            .GroupBy((d, o) => d.ProductId)
            .Select((d, o) => new MonthlyProductReport
            {
                Year = year,
                Month = month,
                ProductId = d.ProductId,
                SalesQuantity = SqlFunc.AggregateSum(d.Quantity),
                SalesAmount = SqlFunc.AggregateSum(d.Quantity * d.UnitPrice),
                OrderCount = SqlFunc.AggregateCount(d.OrderId),
                AvgPrice = SqlFunc.Round(
                    SqlFunc.AggregateAvg(d.UnitPrice), 2),
                CreateTime = DateTime.Now
            })
            .ToListAsync();

        // 2. 清除旧数据
        await _db.Deleteable<MonthlyProductReport>()
            .Where(r => r.Year == year && r.Month == month)
            .ExecuteCommandAsync();

        // 3. 批量写入新数据
        if (productStats.Any())
        {
            await _db.Fastest<MonthlyProductReport>().BulkCopyAsync(productStats);
        }

        Console.WriteLine($"{year}年{month}月报表预计算完成，共 {productStats.Count} 个商品");
    }
}
```

## 16. 本章小结

本章全面介绍了 SqlSugar 的大数据批量操作：

- **BulkCopy**：使用数据库原生协议的极速批量插入，是处理大数据的首选
- **BulkUpdate**：通过临时表实现高效的批量更新
- **BulkMerge**：有则更新、无则插入的合并操作
- **BulkDelete**：批量删除和软删除
- **PageSize 分批**：分批处理中等规模数据，兼容所有数据库
- **DataTable 操作**：直接操作 DataTable，适用于 Excel 导入等场景
- **性能基准**：BulkCopy 比逐条插入快 100-200 倍
- **内存优化**：分批加载、流式读取、避免大对象字段
- **流式查询**：ForEach、DataReader、IAsyncEnumerable
- **百万级处理**：分批插入、分批更新、流式导出
- **数据库差异**：不同数据库的批量操作底层实现和兼容性
- **错误处理**：异常捕获、分批重试、数据验证、重复数据处理
- **实战场景**：Excel 导入、数据迁移、ETL 处理、报表预计算

掌握批量操作是构建高性能数据处理系统的关键技能。在数据量较大的场景下，选择正确的批量操作方式可以将处理时间从数小时缩短到数分钟。
