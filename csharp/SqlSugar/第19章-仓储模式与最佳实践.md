# 第19章：仓储模式与最佳实践

## 19.1 仓储模式概述

### 19.1.1 什么是仓储模式

仓储模式（Repository Pattern）是一种设计模式，它在数据访问层和业务逻辑层之间建立抽象层，将数据的存取逻辑封装在仓储类中，使业务逻辑不直接依赖具体的数据访问技术。

### 19.1.2 仓储模式的优点

| 优点 | 说明 |
|------|------|
| 解耦 | 业务逻辑与数据访问分离 |
| 可测试性 | 容易进行单元测试（Mock仓储） |
| 统一接口 | 标准化的CRUD操作接口 |
| 可维护性 | 修改数据访问逻辑不影响业务层 |
| 代码复用 | 通用方法在基类中实现 |

## 19.2 SqlSugar内置仓储

### 19.2.1 SimpleClient

SqlSugar提供了`SimpleClient<T>`作为内置的简易仓储实现。

```csharp
// 创建仓储
var db = new SqlSugarClient(new ConnectionConfig()
{
    ConnectionString = "连接字符串",
    DbType = DbType.SqlServer,
    IsAutoCloseConnection = true
});

var userRepository = new SimpleClient<User>(db);

// 基本CRUD操作
// 插入
userRepository.Insert(new User { Name = "张三", Age = 25 });

// 查询
var user = userRepository.GetById(1);
var users = userRepository.GetList();
var filteredUsers = userRepository.GetList(u => u.Age > 18);

// 更新
user.Name = "李四";
userRepository.Update(user);

// 删除
userRepository.DeleteById(1);
```

### 19.2.2 继承SimpleClient

```csharp
public class UserRepository : SimpleClient<User>
{
    public UserRepository(ISqlSugarClient db) : base(db)
    {
    }

    // 自定义查询方法
    public List<User> GetActiveUsers()
    {
        return Context.Queryable<User>()
            .Where(u => u.IsActive && !u.IsDeleted)
            .OrderBy(u => u.CreateTime, OrderByType.Desc)
            .ToList();
    }

    public User GetByEmail(string email)
    {
        return Context.Queryable<User>()
            .Where(u => u.Email == email)
            .First();
    }

    public PageResult<User> GetPageList(int pageIndex, int pageSize, string keyword)
    {
        int totalCount = 0;
        var list = Context.Queryable<User>()
            .WhereIF(!string.IsNullOrEmpty(keyword), u => u.Name.Contains(keyword))
            .OrderBy(u => u.Id, OrderByType.Desc)
            .ToPageList(pageIndex, pageSize, ref totalCount);

        return new PageResult<User>
        {
            Items = list,
            TotalCount = totalCount,
            PageIndex = pageIndex,
            PageSize = pageSize
        };
    }
}
```

## 19.3 自定义仓储基类

### 19.3.1 定义仓储接口

```csharp
public interface IRepository<T> where T : class, new()
{
    // 查询
    T GetById(dynamic id);
    Task<T> GetByIdAsync(dynamic id);
    List<T> GetList();
    Task<List<T>> GetListAsync();
    List<T> GetList(Expression<Func<T, bool>> where);
    Task<List<T>> GetListAsync(Expression<Func<T, bool>> where);
    T GetFirst(Expression<Func<T, bool>> where);
    Task<T> GetFirstAsync(Expression<Func<T, bool>> where);
    bool Any(Expression<Func<T, bool>> where);
    int Count(Expression<Func<T, bool>> where);

    // 分页
    PageResult<T> GetPageList(Expression<Func<T, bool>> where,
        PageRequest request);
    Task<PageResult<T>> GetPageListAsync(Expression<Func<T, bool>> where,
        PageRequest request);

    // 插入
    bool Insert(T entity);
    Task<bool> InsertAsync(T entity);
    bool InsertRange(List<T> entities);
    Task<bool> InsertRangeAsync(List<T> entities);
    int InsertReturnIdentity(T entity);
    Task<int> InsertReturnIdentityAsync(T entity);

    // 更新
    bool Update(T entity);
    Task<bool> UpdateAsync(T entity);
    bool UpdateRange(List<T> entities);

    // 删除
    bool Delete(T entity);
    bool DeleteById(dynamic id);
    bool DeleteByIds(dynamic[] ids);

    // 事务
    ISqlSugarClient AsSugarClient();
}
```

### 19.3.2 实现仓储基类

```csharp
public class Repository<T> : SimpleClient<T>, IRepository<T> where T : class, new()
{
    public Repository(ISqlSugarClient db) : base(db)
    {
    }

    public async Task<T> GetFirstAsync(Expression<Func<T, bool>> where)
    {
        return await Context.Queryable<T>().Where(where).FirstAsync();
    }

    public bool Any(Expression<Func<T, bool>> where)
    {
        return Context.Queryable<T>().Where(where).Any();
    }

    public int Count(Expression<Func<T, bool>> where)
    {
        return Context.Queryable<T>().Where(where).Count();
    }

    public PageResult<T> GetPageList(Expression<Func<T, bool>> where, PageRequest request)
    {
        int totalCount = 0;
        var list = Context.Queryable<T>()
            .WhereIF(where != null, where)
            .OrderByIF(!string.IsNullOrEmpty(request.OrderBy),
                request.OrderBy + " " + (request.IsAsc ? "asc" : "desc"))
            .ToPageList(request.PageIndex, request.PageSize, ref totalCount);

        return new PageResult<T>
        {
            Items = list,
            TotalCount = totalCount,
            PageIndex = request.PageIndex,
            PageSize = request.PageSize
        };
    }

    public async Task<PageResult<T>> GetPageListAsync(Expression<Func<T, bool>> where, PageRequest request)
    {
        RefAsync<int> totalCount = 0;
        var list = await Context.Queryable<T>()
            .WhereIF(where != null, where)
            .OrderByIF(!string.IsNullOrEmpty(request.OrderBy),
                request.OrderBy + " " + (request.IsAsc ? "asc" : "desc"))
            .ToPageListAsync(request.PageIndex, request.PageSize, totalCount);

        return new PageResult<T>
        {
            Items = list,
            TotalCount = totalCount,
            PageIndex = request.PageIndex,
            PageSize = request.PageSize
        };
    }

    public ISqlSugarClient AsSugarClient()
    {
        return Context;
    }
}

// 分页请求模型
public class PageRequest
{
    public int PageIndex { get; set; } = 1;
    public int PageSize { get; set; } = 20;
    public string OrderBy { get; set; }
    public bool IsAsc { get; set; } = true;
}

// 分页结果模型
public class PageResult<T>
{
    public List<T> Items { get; set; }
    public int TotalCount { get; set; }
    public int PageIndex { get; set; }
    public int PageSize { get; set; }
    public int TotalPages => (int)Math.Ceiling((double)TotalCount / PageSize);
}
```

## 19.4 服务层模式

### 19.4.1 定义服务接口

```csharp
public interface IUserService
{
    User GetById(int id);
    List<User> GetActiveUsers();
    PageResult<User> Search(string keyword, int page, int pageSize);
    bool Create(UserCreateDto dto);
    bool Update(int id, UserUpdateDto dto);
    bool Delete(int id);
}
```

### 19.4.2 实现服务层

```csharp
public class UserService : IUserService
{
    private readonly IRepository<User> _userRepo;
    private readonly ISqlSugarClient _db;

    public UserService(IRepository<User> userRepo, ISqlSugarClient db)
    {
        _userRepo = userRepo;
        _db = db;
    }

    public User GetById(int id)
    {
        return _userRepo.GetById(id);
    }

    public List<User> GetActiveUsers()
    {
        return _userRepo.GetList(u => u.IsActive && !u.IsDeleted);
    }

    public PageResult<User> Search(string keyword, int page, int pageSize)
    {
        return _userRepo.GetPageList(
            u => (string.IsNullOrEmpty(keyword) || u.Name.Contains(keyword)),
            new PageRequest { PageIndex = page, PageSize = pageSize, OrderBy = "Id", IsAsc = false });
    }

    public bool Create(UserCreateDto dto)
    {
        var user = new User
        {
            Name = dto.Name,
            Email = dto.Email,
            Age = dto.Age,
            IsActive = true,
            CreateTime = DateTime.Now
        };

        // 检查邮箱是否已存在
        if (_userRepo.Any(u => u.Email == dto.Email))
            throw new Exception("邮箱已存在");

        return _userRepo.Insert(user);
    }

    public bool Update(int id, UserUpdateDto dto)
    {
        var user = _userRepo.GetById(id);
        if (user == null)
            throw new Exception("用户不存在");

        user.Name = dto.Name;
        user.Email = dto.Email;
        user.Age = dto.Age;
        user.UpdateTime = DateTime.Now;

        return _userRepo.Update(user);
    }

    public bool Delete(int id)
    {
        // 软删除
        var user = _userRepo.GetById(id);
        if (user == null) return false;

        user.IsDeleted = true;
        user.DeleteTime = DateTime.Now;
        return _userRepo.Update(user);
    }
}
```

### 19.4.3 在控制器中使用

```csharp
[ApiController]
[Route("api/[controller]")]
public class UserController : ControllerBase
{
    private readonly IUserService _userService;

    public UserController(IUserService userService)
    {
        _userService = userService;
    }

    [HttpGet("{id}")]
    public IActionResult GetById(int id)
    {
        var user = _userService.GetById(id);
        if (user == null) return NotFound();
        return Ok(user);
    }

    [HttpGet]
    public IActionResult Search([FromQuery] string keyword, int page = 1, int pageSize = 20)
    {
        var result = _userService.Search(keyword, page, pageSize);
        return Ok(result);
    }

    [HttpPost]
    public IActionResult Create([FromBody] UserCreateDto dto)
    {
        _userService.Create(dto);
        return Ok(new { message = "创建成功" });
    }

    [HttpPut("{id}")]
    public IActionResult Update(int id, [FromBody] UserUpdateDto dto)
    {
        _userService.Update(id, dto);
        return Ok(new { message = "更新成功" });
    }

    [HttpDelete("{id}")]
    public IActionResult Delete(int id)
    {
        _userService.Delete(id);
        return Ok(new { message = "删除成功" });
    }
}
```

## 19.6 最佳实践总结

### 19.6.1 连接管理

| 实践 | 说明 |
|------|------|
| 使用SqlSugarScope | 单例模式，线程安全，推荐在Web应用中使用 |
| IsAutoCloseConnection=true | 自动管理连接生命周期 |
| 配置连接池 | 根据并发量调整最大连接数 |
| 避免手动开关连接 | 让框架自动管理 |

### 19.6.2 编码规范

```csharp
// ✅ 推荐：使用异步方法
var users = await db.Queryable<User>().ToListAsync();

// ✅ 推荐：按需查询列
var names = await db.Queryable<User>()
    .Select(u => new { u.Id, u.Name })
    .ToListAsync();

// ✅ 推荐：使用WhereIF避免空条件
var list = await db.Queryable<User>()
    .WhereIF(!string.IsNullOrEmpty(name), u => u.Name.Contains(name))
    .WhereIF(age > 0, u => u.Age == age)
    .ToListAsync();

// ❌ 避免：在循环中单条操作
foreach (var user in users)
{
    db.Insertable(user).ExecuteCommand(); // 性能差
}
// ✅ 推荐：批量操作
db.Insertable(users).ExecuteCommand();
```

### 19.6.3 错误处理

```csharp
public class UserService : IUserService
{
    public async Task<Result<User>> CreateAsync(UserCreateDto dto)
    {
        try
        {
            // 业务验证
            if (await _userRepo.AnyAsync(u => u.Email == dto.Email))
                return Result<User>.Fail("邮箱已被注册");

            var user = MapToEntity(dto);

            var success = await _userRepo.InsertAsync(user);
            if (!success)
                return Result<User>.Fail("创建失败");

            return Result<User>.Ok(user);
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "创建用户异常");
            return Result<User>.Fail("系统异常，请稍后重试");
        }
    }
}
```

### 19.6.4 安全注意事项

```csharp
// ✅ SqlSugar默认使用参数化查询，防止SQL注入
var user = db.Queryable<User>()
    .Where(u => u.Name == userInput) // 参数化
    .First();

// ⚠️ 使用原生SQL时务必参数化
var list = db.Ado.SqlQuery<User>(
    "SELECT * FROM User WHERE Name = @name",
    new SugarParameter("@name", userInput));

// ❌ 危险：拼接SQL
var list = db.Ado.SqlQuery<User>(
    $"SELECT * FROM User WHERE Name = '{userInput}'"); // SQL注入风险！
```

## 19.7 本章小结

本章详细介绍了SqlSugar的仓储模式与最佳实践：

- **SimpleClient**：SqlSugar内置的简易仓储，满足基本CRUD需求
- **自定义仓储**：通过继承SimpleClient或自定义接口实现更灵活的仓储
- **服务层模式**：在仓储和控制器之间增加服务层，封装业务逻辑
- **项目分层**：推荐的Core/Repository/Service/WebApi分层架构
- **最佳实践**：异步操作、批量处理、按需查询、参数化安全

良好的架构设计和编码规范是构建高质量应用的基础，合理运用仓储模式可以让代码更清晰、更易维护。
