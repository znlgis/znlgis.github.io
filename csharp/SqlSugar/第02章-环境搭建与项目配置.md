## 1. NuGet包安装

### 1.1 包名说明

SqlSugar 根据目标框架提供了两个 NuGet 包：

| 包名 | 适用框架 | 说明 |
|------|---------|------|
| `SqlSugar` | .NET Framework 4.5+ | 传统 .NET Framework 项目 |
| `SqlSugarCore` | .NET Core 3.1 / .NET 5-10 | 跨平台 .NET 项目（推荐） |

> **注意**：不要同时安装两个包，根据项目目标框架选择其中一个即可。

### 1.2 使用 .NET CLI 安装

```bash
# .NET Core / .NET 5+ 项目（推荐）
dotnet add package SqlSugarCore

# 安装指定版本
dotnet add package SqlSugarCore --version 5.1.4.169

# 查看已安装的包
dotnet list package
```

### 1.3 使用 NuGet 包管理器安装

在 Visual Studio 中：

1. 右键点击项目 → **管理 NuGet 程序包**
2. 在 **浏览** 选项卡中搜索 `SqlSugarCore`
3. 选择最新稳定版本，点击 **安装**

也可以在 **程序包管理器控制台** 中执行：

```powershell
# .NET Core / .NET 5+ 项目
Install-Package SqlSugarCore

# .NET Framework 项目
Install-Package SqlSugar
```

### 1.4 数据库驱动包

SqlSugarCore 已经内置了大部分数据库的驱动依赖，安装时会自动引入。对于某些特殊数据库，可能需要额外安装驱动包：

| 数据库 | 额外驱动包 | 说明 |
|-------|-----------|------|
| MySQL | 自动引入 | MySqlConnector |
| SQL Server | 自动引入 | Microsoft.Data.SqlClient |
| PostgreSQL | 自动引入 | Npgsql |
| Oracle | 自动引入 | Oracle.ManagedDataAccess.Core |
| SQLite | `System.Data.SQLite.Core` | 部分场景需要手动安装 |
| 达梦 | `DmProvider` | 需要手动安装达梦驱动 |
| 人大金仓 | `Kdbndp` | 需要手动安装金仓驱动 |

```bash
# 示例：安装 SQLite 驱动
dotnet add package System.Data.SQLite.Core
```

## 4. ConnectionConfig详解

`ConnectionConfig` 是 SqlSugar 中最核心的配置类，用于配置数据库连接信息。

### 4.1 基础配置

```csharp
var config = new ConnectionConfig()
{
    // 数据库连接字符串（必填）
    ConnectionString = "Server=localhost;Database=MyDb;Uid=root;Pwd=123456;",

    // 数据库类型（必填）
    DbType = DbType.MySql,

    // 是否自动关闭连接（推荐设为 true）
    IsAutoCloseConnection = true,

    // 主键初始化方式
    InitKeyType = InitKeyType.Attribute
};
```

### 4.2 ConnectionString 各数据库连接字符串

不同数据库的连接字符串格式各不相同：

```csharp
// MySQL
"Server=localhost;Port=3306;Database=mydb;Uid=root;Pwd=123456;CharSet=utf8mb4;"

// SQL Server
"Server=localhost;Database=mydb;User Id=sa;Password=123456;TrustServerCertificate=true;"

// SQL Server（Windows 认证）
"Server=localhost;Database=mydb;Integrated Security=true;TrustServerCertificate=true;"

// PostgreSQL
"Host=localhost;Port=5432;Database=mydb;Username=postgres;Password=123456;"

// Oracle
"Data Source=(DESCRIPTION=(ADDRESS=(PROTOCOL=TCP)(HOST=localhost)(PORT=1521))(CONNECT_DATA=(SERVICE_NAME=orcl)));User Id=system;Password=123456;"

// SQLite
"DataSource=mydb.db;"

// 达梦
"Server=localhost;Port=5236;User Id=SYSDBA;Password=SYSDBA;"

// 人大金仓
"Server=localhost;Port=54321;User Id=system;Password=123456;Database=mydb;"
```

### 4.3 DbType 数据库类型枚举


### 4.4 IsAutoCloseConnection

```csharp
// 自动关闭连接（推荐）
IsAutoCloseConnection = true
```

| 值 | 说明 |
|----|------|
| `true` | 每次操作完成后自动关闭连接，推荐在大多数场景使用 |
| `false` | 需要手动管理连接的打开和关闭 |

> **最佳实践**：除非有特殊需求（如使用事务需要手动控制连接），否则始终设为 `true`。

### 4.5 InitKeyType 主键初始化方式

```csharp
// 使用特性标记主键（推荐）
InitKeyType = InitKeyType.Attribute

// 使用数据库中的主键信息
InitKeyType = InitKeyType.SystemTable
```

| 值 | 说明 | 适用场景 |
|----|------|---------|
| `Attribute` | 从实体类的 `[SugarColumn(IsPrimaryKey = true)]` 特性读取 | Code First 场景 |
| `SystemTable` | 从数据库系统表中读取主键信息 | Db First 场景 |

### 4.6 MoreSettings 高级配置

```csharp
var config = new ConnectionConfig()
{
    ConnectionString = "...",
    DbType = DbType.MySql,
    IsAutoCloseConnection = true,
    InitKeyType = InitKeyType.Attribute,

    // 高级设置
    MoreSettings = new ConnMoreSettings()
    {
        // 是否自动将 Pascal 命名转为驼峰命名
        IsAutoRemoveDataCache = true,

        // 禁用 Nvarchar
        IsWithNoLockQuery = false,

        // 默认使用 NOLOCK（仅 SQL Server）
        IsAutoToUpper = false,

        // 自定义错误消息
        DisableNvarchar = true,

        // PgSql 模式
        PgSqlIsAutoToLower = true,
    }
};
```

### 4.7 ConfigureExternalServices 外部服务配置

```csharp
var config = new ConnectionConfig()
{
    ConnectionString = "...",
    DbType = DbType.MySql,
    IsAutoCloseConnection = true,

    ConfigureExternalServices = new ConfigureExternalServices()
    {
        // 自定义实体服务
        EntityService = (property, column) =>
        {
            // 所有 string 类型属性默认允许为空
            if (column.IsPrimaryKey == false && property.PropertyType == typeof(string))
            {
                column.IsNullable = true;
            }
        },

        // 自定义实体名称服务
        EntityNameService = (type, entity) =>
        {
            // 自定义表名映射规则
            entity.DbTableName = "t_" + entity.DbTableName.ToLower();
        }
    }
};
```

### 4.8 完整配置示例

```csharp
var config = new ConnectionConfig()
{
    ConnectionString = "Server=localhost;Port=3306;Database=mydb;Uid=root;Pwd=123456;CharSet=utf8mb4;",
    DbType = DbType.MySql,
    IsAutoCloseConnection = true,
    InitKeyType = InitKeyType.Attribute,

    MoreSettings = new ConnMoreSettings()
    {
        IsAutoRemoveDataCache = true,
    },

    ConfigureExternalServices = new ConfigureExternalServices()
    {
        EntityService = (property, column) =>
        {
            if (column.IsPrimaryKey == false
                && new NullabilityInfoContext().Create(property).WriteState is NullabilityState.Nullable)
            {
                column.IsNullable = true;
            }
        }
    }
};
```

## 5. SqlSugarClient与SqlSugarScope

SqlSugar 提供了两种核心操作对象：`SqlSugarClient` 和 `SqlSugarScope`。理解它们的区别对于正确使用 SqlSugar 至关重要。

### 5.1 SqlSugarClient

`SqlSugarClient` 是 SqlSugar 的基础客户端类，**非线程安全**。

```csharp
// 创建 SqlSugarClient 实例
var db = new SqlSugarClient(new ConnectionConfig()
{
    ConnectionString = "Server=localhost;Database=mydb;Uid=root;Pwd=123456;",
    DbType = DbType.MySql,
    IsAutoCloseConnection = true,
    InitKeyType = InitKeyType.Attribute
});
```

**特点**：
- 每次使用需要创建新实例，或使用 `using` 语句管理生命周期
- 非线程安全，不能跨线程共享
- 适合简单场景或手动管理生命周期的场景

**使用模式**：

```csharp
// 方式1：每次创建新实例
public Student GetById(int id)
{
    using var db = new SqlSugarClient(config);
    return db.Queryable<Student>().InSingle(id);
}

// 方式2：通过工厂方法
public static SqlSugarClient CreateDb()
{
    return new SqlSugarClient(new ConnectionConfig()
    {
        ConnectionString = "...",
        DbType = DbType.MySql,
        IsAutoCloseConnection = true,
        InitKeyType = InitKeyType.Attribute
    });
}
```

### 5.2 SqlSugarScope

`SqlSugarScope` 是 SqlSugar 5.x 推出的 **线程安全** 的单例客户端，**推荐使用**。

```csharp
// 创建 SqlSugarScope 实例（全局单例）
public static readonly SqlSugarScope Db = new SqlSugarScope(new ConnectionConfig()
{
    ConnectionString = "Server=localhost;Database=mydb;Uid=root;Pwd=123456;",
    DbType = DbType.MySql,
    IsAutoCloseConnection = true,
    InitKeyType = InitKeyType.Attribute
},
db =>
{
    // 每次获取实例时的配置（AOP等）
    db.Aop.OnLogExecuting = (sql, pars) =>
    {
        Console.WriteLine(sql);
    };
});
```

**特点**：
- 线程安全，可以作为单例使用
- 内部使用 `AsyncLocal<T>` 保证每个线程/异步上下文独立
- 自动管理连接的生命周期
- **推荐在 ASP.NET Core 项目中使用**

### 5.3 两者核心区别

| 对比维度 | SqlSugarClient | SqlSugarScope |
|---------|---------------|---------------|
| 线程安全 | ❌ 不安全 | ✅ 安全 |
| 生命周期 | 每次创建或手动管理 | 单例模式 |
| 使用方式 | `new` 或 `using` | 全局静态实例 |
| 连接管理 | 手动或自动 | 自动 |
| DI 注册 | Scoped/Transient | Singleton |
| 推荐场景 | 控制台、简单应用 | Web应用、多线程 |
| AOP 配置 | 创建时配置 | 构造函数第二个参数配置 |
| 性能 | 有创建开销 | 无创建开销 |

### 5.4 SqlSugarScope的工作原理

```
SqlSugarScope（单例）
│
├── 线程1 → 内部 SqlSugarClient 实例1（AsyncLocal）
├── 线程2 → 内部 SqlSugarClient 实例2（AsyncLocal）
├── 线程3 → 内部 SqlSugarClient 实例3（AsyncLocal）
│
└── 每个线程/异步上下文自动获得独立的 Client 实例
    连接在操作完成后自动释放
```

> **要点**：`SqlSugarScope` 虽然是单例，但内部会为每个线程维护独立的连接实例，因此是线程安全的。

## 6. ASP.NET Core依赖注入

### 6.1 基本注册方式

在 ASP.NET Core 中，推荐使用依赖注入的方式注册 SqlSugar：

**方式一：注册 SqlSugarScope 为单例（推荐）**

```csharp
// Program.cs
var builder = WebApplication.CreateBuilder(args);

// 从配置文件读取连接字符串
var connectionString = builder.Configuration.GetConnectionString("DefaultConnection");

// 注册 SqlSugarScope 为单例
builder.Services.AddSingleton<ISqlSugarClient>(sp =>
{
    var sqlSugar = new SqlSugarScope(new ConnectionConfig()
    {
        ConnectionString = connectionString,
        DbType = DbType.MySql,
        IsAutoCloseConnection = true,
        InitKeyType = InitKeyType.Attribute,
    },
    db =>
    {
        // AOP：SQL 执行日志
        db.Aop.OnLogExecuting = (sql, pars) =>
        {
            var logger = sp.GetRequiredService<ILogger<Program>>();
            logger.LogInformation("SQL: {Sql}", sql);
        };

        // AOP：SQL 执行耗时
        db.Aop.OnLogExecuted = (sql, pars) =>
        {
            var logger = sp.GetRequiredService<ILogger<Program>>();
            logger.LogInformation("SQL执行耗时: {Time}ms", db.Ado.SqlExecutionTime.TotalMilliseconds);
        };

        // AOP：SQL 执行异常
        db.Aop.OnError = (exp) =>
        {
            var logger = sp.GetRequiredService<ILogger<Program>>();
            logger.LogError(exp, "SQL执行异常: {Message}", exp.Message);
        };
    });

    return sqlSugar;
});

var app = builder.Build();
```

**appsettings.json 配置**：

```json
{
  "ConnectionStrings": {
    "DefaultConnection": "Server=localhost;Port=3306;Database=mydb;Uid=root;Pwd=123456;CharSet=utf8mb4;"
  }
}
```

### 6.2 方式二：注册 SqlSugarClient 为 Scoped

```csharp
// Program.cs
builder.Services.AddScoped<ISqlSugarClient>(sp =>
{
    var sqlSugar = new SqlSugarClient(new ConnectionConfig()
    {
        ConnectionString = connectionString,
        DbType = DbType.MySql,
        IsAutoCloseConnection = true,
        InitKeyType = InitKeyType.Attribute,
    });

    // 配置 AOP
    sqlSugar.Aop.OnLogExecuting = (sql, pars) =>
    {
        Console.WriteLine(sql);
    };

    return sqlSugar;
});
```

### 6.3 在控制器中使用

```csharp
[ApiController]
[Route("api/[controller]")]
public class StudentController : ControllerBase
{
    private readonly ISqlSugarClient _db;

    public StudentController(ISqlSugarClient db)
    {
        _db = db;
    }

    [HttpGet]
    public async Task<ActionResult<List<Student>>> GetAll()
    {
        var list = await _db.Queryable<Student>().ToListAsync();
        return Ok(list);
    }

    [HttpGet("{id}")]
    public async Task<ActionResult<Student>> GetById(int id)
    {
        var student = await _db.Queryable<Student>().InSingleAsync(id);
        if (student == null)
            return NotFound();
        return Ok(student);
    }

    [HttpPost]
    public async Task<ActionResult> Create([FromBody] Student student)
    {
        await _db.Insertable(student).ExecuteCommandAsync();
        return CreatedAtAction(nameof(GetById), new { id = student.Id }, student);
    }

    [HttpPut("{id}")]
    public async Task<ActionResult> Update(int id, [FromBody] Student student)
    {
        student.Id = id;
        await _db.Updateable(student).ExecuteCommandAsync();
        return NoContent();
    }

    [HttpDelete("{id}")]
    public async Task<ActionResult> Delete(int id)
    {
        await _db.Deleteable<Student>().In(id).ExecuteCommandAsync();
        return NoContent();
    }
}
```

### 6.4 封装扩展方法

为了让注册过程更加简洁，可以封装一个扩展方法：

```csharp
public static class SqlSugarSetup
{
    public static IServiceCollection AddSqlSugar(
        this IServiceCollection services,
        IConfiguration configuration)
    {
        var connectionString = configuration.GetConnectionString("DefaultConnection")
            ?? throw new InvalidOperationException("未找到数据库连接字符串配置");

        var dbTypeStr = configuration.GetValue<string>("DbType") ?? "MySql";
        var dbType = Enum.Parse<DbType>(dbTypeStr);

        services.AddSingleton<ISqlSugarClient>(sp =>
        {
            var sqlSugar = new SqlSugarScope(new ConnectionConfig()
            {
                ConnectionString = connectionString,
                DbType = dbType,
                IsAutoCloseConnection = true,
                InitKeyType = InitKeyType.Attribute,
                ConfigureExternalServices = new ConfigureExternalServices()
                {
                    EntityService = (property, column) =>
                    {
                        if (column.IsPrimaryKey == false
                            && new NullabilityInfoContext()
                                .Create(property).WriteState is NullabilityState.Nullable)
                        {
                            column.IsNullable = true;
                        }
                    }
                }
            },
            db =>
            {
                var logger = sp.GetRequiredService<ILoggerFactory>()
                    .CreateLogger("SqlSugar");

                db.Aop.OnLogExecuting = (sql, pars) =>
                {
                    logger.LogDebug("SQL: {Sql}", sql);
                };

                db.Aop.OnError = (exp) =>
                {
                    logger.LogError(exp, "SQL执行异常");
                };
            });

            return sqlSugar;
        });

        return services;
    }
}
```

使用方式：

```csharp
// Program.cs
var builder = WebApplication.CreateBuilder(args);
builder.Services.AddSqlSugar(builder.Configuration);
```

## 7. 多数据库配置

SqlSugar 支持在同一项目中同时连接多个数据库。

### 7.1 多数据库场景

常见的多数据库场景包括：

- **读写分离**：主库写入，从库读取
- **分库**：不同业务使用不同数据库
- **异构数据库**：同时使用 MySQL 和 SQL Server
- **多租户**：每个租户使用独立数据库

### 7.2 通过ConfigId配置多库

```csharp
var db = new SqlSugarScope(new List<ConnectionConfig>()
{
    // 主库（默认）
    new ConnectionConfig()
    {
        ConfigId = "main",  // 配置标识
        ConnectionString = "Server=localhost;Database=main_db;Uid=root;Pwd=123456;",
        DbType = DbType.MySql,
        IsAutoCloseConnection = true,
        InitKeyType = InitKeyType.Attribute
    },
    // 日志库
    new ConnectionConfig()
    {
        ConfigId = "log",
        ConnectionString = "Server=localhost;Database=log_db;Uid=root;Pwd=123456;",
        DbType = DbType.MySql,
        IsAutoCloseConnection = true,
        InitKeyType = InitKeyType.Attribute
    },
    // 统计库（使用 PostgreSQL）
    new ConnectionConfig()
    {
        ConfigId = "stats",
        ConnectionString = "Host=localhost;Port=5432;Database=stats_db;Username=postgres;Password=123456;",
        DbType = DbType.PostgreSQL,
        IsAutoCloseConnection = true,
        InitKeyType = InitKeyType.Attribute
    }
});
```

### 7.3 切换数据库

```csharp
// 使用主库（默认）
var mainDb = db.GetConnection("main");
var users = mainDb.Queryable<User>().ToList();

// 切换到日志库
var logDb = db.GetConnection("log");
logDb.Insertable(new OperationLog
{
    Action = "查询用户",
    CreateTime = DateTime.Now
}).ExecuteCommand();

// 切换到统计库
var statsDb = db.GetConnection("stats");
var report = statsDb.Queryable<DailyStat>().ToList();
```

### 7.4 实体类指定数据库

通过 `[TenantAttribute]` 特性将实体绑定到特定数据库：

```csharp
// 绑定到 log 数据库
[SugarTable("OperationLog")]
[Tenant("log")]
public class OperationLog
{
    [SugarColumn(IsPrimaryKey = true, IsIdentity = true)]
    public long Id { get; set; }
    public string Action { get; set; } = string.Empty;
    public DateTime CreateTime { get; set; }
}

// 绑定到 stats 数据库
[SugarTable("DailyStat")]
[Tenant("stats")]
public class DailyStat
{
    [SugarColumn(IsPrimaryKey = true, IsIdentity = true)]
    public int Id { get; set; }
    public DateTime StatDate { get; set; }
    public int UserCount { get; set; }
}
```

### 7.5 多库依赖注入

```csharp
builder.Services.AddSingleton<ISqlSugarClient>(sp =>
{
    var configs = new List<ConnectionConfig>();

    // 从配置文件读取多个数据库配置
    var dbConfigs = builder.Configuration.GetSection("DatabaseConfigs").Get<List<DbConfig>>();

    foreach (var dbConfig in dbConfigs!)
    {
        configs.Add(new ConnectionConfig()
        {
            ConfigId = dbConfig.ConfigId,
            ConnectionString = dbConfig.ConnectionString,
            DbType = Enum.Parse<DbType>(dbConfig.DbType),
            IsAutoCloseConnection = true,
            InitKeyType = InitKeyType.Attribute
        });
    }

    return new SqlSugarScope(configs, db =>
    {
        db.Aop.OnLogExecuting = (sql, pars) =>
        {
            Console.WriteLine(sql);
        };
    });
});
```

```json
    {
```

### 7.6 跨库查询

```csharp
// 跨库联表查询（需要在同一个数据库服务器上）
var result = db.GetConnection("main")
    .Queryable<User>()
    .LeftJoin<OperationLog>((u, l) => u.Id == l.UserId)
    .Select((u, l) => new
    {
        UserName = u.Name,
        Action = l.Action,
        OperateTime = l.CreateTime
    })
    .ToList();
```

## 8. 配置最佳实践

### 8.1 连接字符串安全管理

**不要**在代码中硬编码连接字符串：

```csharp
// ❌ 不推荐：硬编码连接字符串
var config = new ConnectionConfig()
{
    ConnectionString = "Server=localhost;Uid=root;Pwd=123456;Database=mydb;"
};

// ✅ 推荐：从配置文件读取
var config = new ConnectionConfig()
{
    ConnectionString = configuration.GetConnectionString("DefaultConnection")
};
```

在生产环境中，推荐使用以下方式管理连接字符串：

```csharp
// 使用环境变量
ConnectionString = Environment.GetEnvironmentVariable("DB_CONNECTION_STRING")

// 使用 Azure Key Vault / AWS Secrets Manager 等密钥管理服务
// 使用 User Secrets（开发环境）
// dotnet user-secrets set "ConnectionStrings:DefaultConnection" "..."
```

### 8.2 AOP日志配置

```csharp
db.Aop.OnLogExecuting = (sql, pars) =>
{
    // 开发环境：输出完整 SQL
    if (env.IsDevelopment())
    {
        Console.ForegroundColor = ConsoleColor.Blue;
        Console.WriteLine($"[SQL] {sql}");
        Console.ResetColor();

        if (pars?.Any() == true)
        {
            Console.WriteLine($"[参数] {string.Join(", ", pars.Select(p => $"{p.ParameterName}={p.Value}"))}");
        }
    }
};

db.Aop.OnLogExecuted = (sql, pars) =>
{
    // 记录慢查询
    if (db.Ado.SqlExecutionTime.TotalMilliseconds > 1000)
    {
        logger.LogWarning("慢查询({Time}ms): {Sql}",
            db.Ado.SqlExecutionTime.TotalMilliseconds, sql);
    }
};

db.Aop.OnError = (exp) =>
{
    logger.LogError(exp, "SQL执行异常: {Sql}", exp.Sql);
};

// AOP：数据变更审计
db.Aop.OnDiffLogEvent = it =>
{
    // 记录数据变更日志
    var editBeforeData = it.BeforeData;   // 修改前数据
    var editAfterData = it.AfterData;     // 修改后数据
    var sql = it.Sql;
    var parameters = it.Parameters;
    // 写入审计日志...
};
```

### 8.3 初始化检查

建议在应用启动时进行数据库连接检查：

```csharp
var app = builder.Build();

// 应用启动时检查数据库连接
using (var scope = app.Services.CreateScope())
{
    var db = scope.ServiceProvider.GetRequiredService<ISqlSugarClient>();
    try
    {
        // 测试连接
        db.Ado.GetDataTable("SELECT 1");
        Console.WriteLine("✅ 数据库连接成功");

        // 自动建表（开发环境）
        if (app.Environment.IsDevelopment())
        {
            db.CodeFirst.InitTables(typeof(Student), typeof(Course));
            Console.WriteLine("✅ 数据表初始化完成");
        }
    }
    catch (Exception ex)
    {
        Console.WriteLine($"❌ 数据库连接失败: {ex.Message}");
        throw;
    }
}
```

### 8.4 生产环境配置建议

```csharp
var config = new ConnectionConfig()
{
    ConnectionString = configuration.GetConnectionString("DefaultConnection"),
    DbType = DbType.MySql,
    IsAutoCloseConnection = true,
```
