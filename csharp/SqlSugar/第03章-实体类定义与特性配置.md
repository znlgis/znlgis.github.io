## 1. 实体类基础

### 1.1 什么是实体类

在 SqlSugar 中，实体类（Entity）是 C# 类与数据库表之间的映射载体。每个实体类对应一张数据库表，类的属性对应表的列。

```csharp
// 一个最简单的实体类
public class Student
{
    public int Id { get; set; }
    public string Name { get; set; } = string.Empty;
    public int Age { get; set; }
}
```

上面的实体类将映射到名为 `Student` 的数据库表，包含 `Id`、`Name`、`Age` 三个列。

### 1.2 实体类命名约定

默认情况下，SqlSugar 使用以下约定进行映射：

| 约定 | 说明 |
|------|------|
| 类名 → 表名 | 类名直接作为表名，如 `Student` → `Student` 表 |
| 属性名 → 列名 | 属性名直接作为列名，如 `Name` → `Name` 列 |
| 属性类型 → 列类型 | C# 类型自动映射为数据库类型 |

### 1.3 类型映射规则

C# 类型与数据库类型的默认映射关系：

| C# 类型 | MySQL | SQL Server | PostgreSQL | SQLite |
|---------|-------|------------|------------|--------|
| `int` | `int` | `int` | `integer` | `INTEGER` |
| `long` | `bigint` | `bigint` | `bigint` | `INTEGER` |
| `string` | `varchar(255)` | `nvarchar(255)` | `varchar(255)` | `TEXT` |
| `bool` | `tinyint(1)` | `bit` | `boolean` | `INTEGER` |
| `DateTime` | `datetime` | `datetime` | `timestamp` | `TEXT` |
| `decimal` | `decimal(18,2)` | `decimal(18,2)` | `numeric(18,2)` | `REAL` |
| `double` | `double` | `float` | `double precision` | `REAL` |
| `float` | `float` | `real` | `real` | `REAL` |
| `Guid` | `char(36)` | `uniqueidentifier` | `uuid` | `TEXT` |
| `byte[]` | `blob` | `varbinary(max)` | `bytea` | `BLOB` |

### 1.4 可空类型

```csharp
public class Student
{
    public int Id { get; set; }

    // 不可空属性 → 数据库列 NOT NULL
    public string Name { get; set; } = string.Empty;

    // 可空属性 → 数据库列允许 NULL
    public string? Remark { get; set; }

    // 值类型可空
    public int? Score { get; set; }

    public DateTime? GraduationDate { get; set; }
}
```

> **提示**：在 C# 的 Nullable Reference Types 启用时，`string?` 表示可空，`string` 表示不可空。SqlSugar 可以通过配置自动识别可空引用类型。

## 2. SugarTable特性

`[SugarTable]` 特性用于配置实体类与数据库表之间的映射关系。

### 2.1 基本用法

```csharp
using SqlSugar;

// 指定表名
[SugarTable("t_student")]
public class Student
{
    public int Id { get; set; }
    public string Name { get; set; } = string.Empty;
}
```

### 2.2 TableName 属性

指定实体类对应的数据库表名：

```csharp
// 表名映射
[SugarTable("sys_user")]
public class User
{
    public int Id { get; set; }
    public string UserName { get; set; } = string.Empty;
}

// 运行时表名为 sys_user，而非 User
```

### 2.3 TableDescription 属性

设置表的描述/注释（在 Code First 建表时会生成表注释）：

```csharp
[SugarTable("sys_user", TableDescription = "系统用户表")]
public class User
{
    public int Id { get; set; }
    public string UserName { get; set; } = string.Empty;
}
```

### 2.4 IsDisabledDelete 属性

禁止通过 Code First 删除该表中不存在的列：

```csharp
[SugarTable("sys_user", IsDisabledDelete = true)]
public class User
{
    // 数据库中存在但实体中没有的列不会被删除
    public int Id { get; set; }
    public string UserName { get; set; } = string.Empty;
}
```

### 2.5 IsDisabledUpdateAll 属性

禁止通过 Code First 修改所有列：

```csharp
[SugarTable("sys_config", IsDisabledUpdateAll = true)]
public class SysConfig
{
    public int Id { get; set; }
    public string ConfigKey { get; set; } = string.Empty;
    public string ConfigValue { get; set; } = string.Empty;
}
```

### 2.6 多个属性组合使用

```csharp
[SugarTable(
    TableName = "t_order",
    TableDescription = "订单表",
    IsDisabledDelete = true,
    IsDisabledUpdateAll = false
)]
public class Order
{
    [SugarColumn(IsPrimaryKey = true, IsIdentity = true)]
    public long Id { get; set; }

    public string OrderNo { get; set; } = string.Empty;

    public decimal Amount { get; set; }
}
```

## 3. SugarColumn特性详解

`[SugarColumn]` 是 SqlSugar 中最重要的特性之一，用于精细配置实体属性与数据库列之间的映射。

### 3.1 所有属性一览

| 属性名 | 类型 | 默认值 | 说明 |
|-------|------|-------|------|
| `IsPrimaryKey` | bool | false | 是否为主键 |
| `IsIdentity` | bool | false | 是否为自增列 |
| `ColumnName` | string | null | 数据库列名 |
| `ColumnDescription` | string | null | 列描述/注释 |
| `IsNullable` | bool | false | 是否允许为空 |
| `Length` | int | 0 | 字符串长度 |
| `DecimalDigits` | int | 0 | 小数位数 |
| `IsIgnore` | bool | false | 完全忽略该列 |
| `IsOnlyIgnoreInsert` | bool | false | 插入时忽略 |
| `IsOnlyIgnoreUpdate` | bool | false | 更新时忽略 |
| `DefaultValue` | string | null | 默认值 |
| `ColumnDataType` | string | null | 自定义列数据类型 |
| `OldColumnName` | string | null | 旧列名（迁移用） |
| `IndexGroupNameList` | string[] | null | 索引分组名称 |
| `UniqueGroupNameList` | string[] | null | 唯一索引分组名称 |
| `IsTranscoding` | bool | false | 是否转码 |
| `SerializeDateTimeFormat` | string | null | DateTime序列化格式 |
| `IsJson` | bool | false | 是否为JSON类型 |
| `NoSerialize` | bool | false | 不序列化 |
| `IsTreeKey` | bool | false | 是否为树形主键 |
| `SqlParameterDbType` | object | null | 自定义参数类型 |

### 3.2 IsPrimaryKey - 主键

```csharp
public class Student
{
    // 标记为主键
    [SugarColumn(IsPrimaryKey = true)]
    public int Id { get; set; }

    public string Name { get; set; } = string.Empty;
}
```

**复合主键**：

```csharp
public class StudentCourse
{
    // 复合主键：学生ID
    [SugarColumn(IsPrimaryKey = true)]
    public int StudentId { get; set; }

    // 复合主键：课程ID
    [SugarColumn(IsPrimaryKey = true)]
    public int CourseId { get; set; }

    public decimal Score { get; set; }
}
```

### 3.3 IsIdentity - 自增列

```csharp
public class Student
{
    // 主键 + 自增
    [SugarColumn(IsPrimaryKey = true, IsIdentity = true)]
    public int Id { get; set; }

    public string Name { get; set; } = string.Empty;
}
```

> **注意**：自增列在 `Insert` 操作时会被自动忽略，插入成功后会自动回填自增值。

```csharp
var student = new Student { Name = "张三" };
// 插入后 student.Id 会自动回填自增值
db.Insertable(student).ExecuteReturnIdentity();
Console.WriteLine(student.Id); // 输出自增ID
```

### 3.4 ColumnName - 列名映射

```csharp
public class Student
{
    [SugarColumn(IsPrimaryKey = true, IsIdentity = true)]
    public int Id { get; set; }

    // 属性名为 Name，数据库列名为 student_name
    [SugarColumn(ColumnName = "student_name")]
    public string Name { get; set; } = string.Empty;

    // 属性名为 CreateTime，数据库列名为 create_time
    [SugarColumn(ColumnName = "create_time")]
    public DateTime CreateTime { get; set; }
}
```

### 3.5 ColumnDescription - 列描述

```csharp
public class Student
{
    [SugarColumn(IsPrimaryKey = true, IsIdentity = true, ColumnDescription = "学生ID")]
    public int Id { get; set; }

    [SugarColumn(ColumnDescription = "学生姓名")]
    public string Name { get; set; } = string.Empty;

    [SugarColumn(ColumnDescription = "年龄")]
    public int Age { get; set; }

    [SugarColumn(ColumnDescription = "创建时间")]
    public DateTime CreateTime { get; set; }
}
```

> 列描述在 Code First 建表时会生成列注释，便于数据库管理。

### 3.6 IsNullable - 允许为空

```csharp
public class Student
{
    [SugarColumn(IsPrimaryKey = true, IsIdentity = true)]
    public int Id { get; set; }

    // 不允许为空（默认）
    [SugarColumn(IsNullable = false)]
    public string Name { get; set; } = string.Empty;

    // 允许为空
    [SugarColumn(IsNullable = true)]
    public string? Remark { get; set; }

    // 值类型 int? 自动识别为可空
    [SugarColumn(IsNullable = true)]
    public int? ParentId { get; set; }
}
```

### 3.7 Length - 字符串长度

```csharp
public class User
{
    [SugarColumn(IsPrimaryKey = true, IsIdentity = true)]
    public int Id { get; set; }

    // varchar(50)
    [SugarColumn(Length = 50, IsNullable = false)]
    public string UserName { get; set; } = string.Empty;

    // varchar(100)
    [SugarColumn(Length = 100, IsNullable = true)]
    public string? Email { get; set; }

    // varchar(500)
    [SugarColumn(Length = 500, IsNullable = true)]
    public string? Address { get; set; }

    // text 类型（设置超大长度或使用 ColumnDataType）
    [SugarColumn(Length = -1)]
    public string? Content { get; set; }
}
```

> **注意**：`Length = -1` 在 SQL Server 中映射为 `nvarchar(max)`，在 MySQL 中映射为 `longtext`。

### 3.8 DecimalDigits - 小数位数

```csharp
public class Product
{
    [SugarColumn(IsPrimaryKey = true, IsIdentity = true)]
    public int Id { get; set; }

    public string ProductName { get; set; } = string.Empty;

    // decimal(18, 2) - 价格，保留2位小数
    [SugarColumn(Length = 18, DecimalDigits = 2)]
    public decimal Price { get; set; }

    // decimal(10, 4) - 重量，保留4位小数
    [SugarColumn(Length = 10, DecimalDigits = 4)]
    public decimal Weight { get; set; }

    // decimal(5, 2) - 折扣率
    [SugarColumn(Length = 5, DecimalDigits = 2)]
    public decimal DiscountRate { get; set; }
}
```

### 3.9 IsIgnore - 完全忽略

被标记为 `IsIgnore = true` 的属性不会参与任何数据库操作（不建表、不查询、不插入、不更新）：

```csharp
public class Student
{
    [SugarColumn(IsPrimaryKey = true, IsIdentity = true)]
    public int Id { get; set; }

    public string Name { get; set; } = string.Empty;

    // 完全忽略：不会映射到数据库列
    [SugarColumn(IsIgnore = true)]
    public string FullName => $"学生-{Name}";

    // 完全忽略：计算属性
    [SugarColumn(IsIgnore = true)]
    public bool IsAdult => Age >= 18;

    public int Age { get; set; }

    // 导航属性也应该忽略
    [SugarColumn(IsIgnore = true)]
    public List<Course>? Courses { get; set; }
}
```

### 3.10 IsOnlyIgnoreInsert - 仅插入时忽略

```csharp
public class Article
{
    [SugarColumn(IsPrimaryKey = true, IsIdentity = true)]
    public int Id { get; set; }

    public string Title { get; set; } = string.Empty;

    // 插入时忽略，使用数据库默认值；查询和更新正常
    [SugarColumn(IsOnlyIgnoreInsert = true)]
    public DateTime CreateTime { get; set; }

    // 浏览次数：插入时忽略（默认为0），更新和查询正常
    [SugarColumn(IsOnlyIgnoreInsert = true)]
    public int ViewCount { get; set; }
}
```

### 3.11 IsOnlyIgnoreUpdate - 仅更新时忽略

```csharp
public class Article
{
    [SugarColumn(IsPrimaryKey = true, IsIdentity = true)]
    public int Id { get; set; }

    public string Title { get; set; } = string.Empty;

    // 创建时间：更新时忽略，不会被修改
    [SugarColumn(IsOnlyIgnoreUpdate = true)]
    public DateTime CreateTime { get; set; }

    // 创建人：更新时忽略
    [SugarColumn(IsOnlyIgnoreUpdate = true)]
    public string CreatedBy { get; set; } = string.Empty;

    // 更新时间：正常参与更新
    public DateTime? UpdateTime { get; set; }
}
```

### 3.12 DefaultValue - 默认值

```csharp
public class User
{
    [SugarColumn(IsPrimaryKey = true, IsIdentity = true)]
    public int Id { get; set; }

    public string UserName { get; set; } = string.Empty;

    // 默认值为 1（启用状态）
    [SugarColumn(DefaultValue = "1")]
    public int Status { get; set; }

    // 默认值为当前时间
    [SugarColumn(DefaultValue = "GETDATE()", IsOnlyIgnoreInsert = true)]
    public DateTime CreateTime { get; set; }

    // 默认值为空字符串
    [SugarColumn(DefaultValue = "''")]
    public string Remark { get; set; } = string.Empty;

    // 默认值为 0
    [SugarColumn(DefaultValue = "0")]
    public decimal Balance { get; set; }
}
```

> **注意**：`DefaultValue` 的值是 SQL 表达式字符串，不同数据库的函数可能不同（如 SQL Server 用 `GETDATE()`，MySQL 用 `NOW()`）。

### 3.13 ColumnDataType - 自定义数据类型

```csharp
public class Article
{
    [SugarColumn(IsPrimaryKey = true, IsIdentity = true)]
    public int Id { get; set; }

    // 强制指定数据库类型为 text
    [SugarColumn(ColumnDataType = "text")]
    public string Content { get; set; } = string.Empty;

    // 指定为 ntext（SQL Server）
    [SugarColumn(ColumnDataType = "ntext")]
    public string Summary { get; set; } = string.Empty;

    // 指定为 json 类型（MySQL 5.7+）
    [SugarColumn(ColumnDataType = "json", IsJson = true)]
    public string? ExtraData { get; set; }

    // 指定为 timestamp
    [SugarColumn(ColumnDataType = "timestamp")]
    public DateTime CreateTime { get; set; }
}
```

### 3.14 OldColumnName - 旧列名（迁移用）

用于 Code First 迁移时重命名列：

```csharp
public class Student
{
    [SugarColumn(IsPrimaryKey = true, IsIdentity = true)]
    public int Id { get; set; }

    // 数据库中旧列名为 student_name，新列名为 Name
    // Code First 迁移时会自动重命名
    [SugarColumn(OldColumnName = "student_name")]
    public string Name { get; set; } = string.Empty;

    // 旧列名为 birth_date
    [SugarColumn(OldColumnName = "birth_date", IsNullable = true)]
    public DateTime? Birthday { get; set; }
}
```

### 3.15 IsJson - JSON列

```csharp
public class UserProfile
{
    [SugarColumn(IsPrimaryKey = true, IsIdentity = true)]
    public int Id { get; set; }

    public string UserName { get; set; } = string.Empty;

    // JSON 类型列，存储额外信息
    [SugarColumn(IsJson = true, IsNullable = true, ColumnDataType = "text")]
    public Dictionary<string, object>? ExtendData { get; set; }

    // JSON 类型列，存储标签列表
    [SugarColumn(IsJson = true, IsNullable = true, ColumnDataType = "text")]
    public List<string>? Tags { get; set; }

    // JSON 类型列，存储地址对象
    [SugarColumn(IsJson = true, IsNullable = true, ColumnDataType = "text")]
    public AddressInfo? Address { get; set; }
}

public class AddressInfo
{
    public string Province { get; set; } = string.Empty;
    public string City { get; set; } = string.Empty;
    public string Detail { get; set; } = string.Empty;
}
```

使用示例：

```csharp
// 插入带 JSON 的数据
var profile = new UserProfile
{
    UserName = "张三",
    Tags = new List<string> { "VIP", "活跃用户" },
    Address = new AddressInfo
    {
        Province = "北京",
        City = "北京",
        Detail = "朝阳区xxx街道"
    },
    ExtendData = new Dictionary<string, object>
    {
        { "level", 5 },
        { "score", 98.5 }
    }
};
db.Insertable(profile).ExecuteCommand();

// 查询时自动反序列化
var user = db.Queryable<UserProfile>().First(it => it.UserName == "张三");
Console.WriteLine(user.Address?.City);  // 输出：北京
Console.WriteLine(user.Tags?[0]);       // 输出：VIP
```

### 3.16 完整实体类示例

```csharp
/// <summary>
/// 系统用户表
/// </summary>
[SugarTable("sys_user", TableDescription = "系统用户表")]
public class SysUser
{
    /// <summary>
    /// 用户ID
    /// </summary>
    [SugarColumn(IsPrimaryKey = true, IsIdentity = true, ColumnDescription = "用户ID")]
    public long Id { get; set; }

    /// <summary>
    /// 用户名
    /// </summary>
    [SugarColumn(ColumnName = "user_name", Length = 50, IsNullable = false,
        ColumnDescription = "用户名")]
    public string UserName { get; set; } = string.Empty;

    /// <summary>
    /// 密码（加密存储）
    /// </summary>
    [SugarColumn(ColumnName = "password_hash", Length = 256, IsNullable = false,
        ColumnDescription = "密码哈希值")]
    public string PasswordHash { get; set; } = string.Empty;

    /// <summary>
    /// 邮箱
    /// </summary>
    [SugarColumn(Length = 100, IsNullable = true, ColumnDescription = "邮箱地址")]
    public string? Email { get; set; }

    /// <summary>
    /// 手机号
    /// </summary>
    [SugarColumn(Length = 20, IsNullable = true, ColumnDescription = "手机号码")]
    public string? Phone { get; set; }

    /// <summary>
    /// 状态（0禁用 1启用）
    /// </summary>
    [SugarColumn(DefaultValue = "1", ColumnDescription = "用户状态")]
    public int Status { get; set; }

    /// <summary>
    /// 余额
    /// </summary>
    [SugarColumn(Length = 18, DecimalDigits = 2, DefaultValue = "0",
        ColumnDescription = "账户余额")]
    public decimal Balance { get; set; }

    /// <summary>
    /// 创建时间
    /// </summary>
    [SugarColumn(IsOnlyIgnoreUpdate = true, ColumnDescription = "创建时间")]
    public DateTime CreateTime { get; set; } = DateTime.Now;

    /// <summary>
    /// 更新时间
    /// </summary>
    [SugarColumn(IsNullable = true, ColumnDescription = "更新时间")]
    public DateTime? UpdateTime { get; set; }

    /// <summary>
    /// 是否删除（软删除）
    /// </summary>
    [SugarColumn(DefaultValue = "0", ColumnDescription = "是否逻辑删除")]
    public bool IsDeleted { get; set; }

    /// <summary>
    /// 扩展数据（JSON）
    /// </summary>
    [SugarColumn(IsJson = true, IsNullable = true, ColumnDataType = "text",
        ColumnDescription = "扩展数据")]
    public Dictionary<string, object>? ExtData { get; set; }

    /// <summary>
    /// 显示名称（计算属性，不映射数据库）
    /// </summary>
    [SugarColumn(IsIgnore = true)]
    public string DisplayName => $"{UserName}({Email ?? "无邮箱"})";
}
```

## 4. 主键与自增列

### 4.1 单主键

```csharp
// 自增int主键
public class Student
{
    [SugarColumn(IsPrimaryKey = true, IsIdentity = true)]
    public int Id { get; set; }
    public string Name { get; set; } = string.Empty;
}
```

### 4.2 Guid主键

```csharp
public class Order
{
    // GUID 主键，非自增
    [SugarColumn(IsPrimaryKey = true)]
    public Guid Id { get; set; } = Guid.NewGuid();

    public string OrderNo { get; set; } = string.Empty;
    public decimal Amount { get; set; }
}
```

### 4.3 雪花ID主键

SqlSugar 内置了雪花算法（Snowflake）生成分布式唯一 ID：

```csharp
public class Order
{
    // 雪花ID主键
    [SugarColumn(IsPrimaryKey = true)]
    public long Id { get; set; }

    public string OrderNo { get; set; } = string.Empty;
}
```

配置雪花 ID：

```csharp
// 配置雪花 ID 工作机器ID（分布式环境中每个节点不同）
SnowFlakeSingle.WorkId = 1;

// 插入时自动生成雪花 ID
var order = new Order { OrderNo = "ORD-001" };
db.Insertable(order).ExecuteCommand();
// order.Id 会自动填充雪花ID
```

### 4.4 复合主键

```csharp
// 学生选课关联表
public class StudentCourse
{
    [SugarColumn(IsPrimaryKey = true)]
    public int StudentId { get; set; }

    [SugarColumn(IsPrimaryKey = true)]
    public int CourseId { get; set; }

    public decimal Score { get; set; }
    public DateTime SelectTime { get; set; } = DateTime.Now;
}

// 复合主键的操作
// 查询
var sc = db.Queryable<StudentCourse>()
    .Where(it => it.StudentId == 1 && it.CourseId == 101)
    .First();

// 更新
db.Updateable(new StudentCourse
{
    StudentId = 1,
    CourseId = 101,
    Score = 95
}).ExecuteCommand();

// 删除
db.Deleteable<StudentCourse>()
    .Where(it => it.StudentId == 1 && it.CourseId == 101)
    .ExecuteCommand();
```

## 5. 导航属性

导航属性是 SqlSugar 中用于处理实体间关联关系的核心功能。通过 `[Navigate]` 特性来定义。

### 5.1 一对多关系

```csharp
// 班级（一）
[SugarTable("Class")]
public class SchoolClass
{
    [SugarColumn(IsPrimaryKey = true, IsIdentity = true)]
    public int Id { get; set; }

    public string ClassName { get; set; } = string.Empty;

    // 导航属性：一个班级有多个学生
    [Navigate(NavigateType.OneToMany, nameof(Student.ClassId))]
    public List<Student>? Students { get; set; }
}

// 学生（多）
[SugarTable("Student")]
public class Student
{
```

## 6. 枚举映射

### 6.1 基本枚举映射

SqlSugar 默认将枚举映射为其对应的整数值：

```csharp
// 定义枚举
public enum UserStatus
{
    Disabled = 0, // 禁用
    Active = 1,   // 启用
    Locked = 2    // 锁定
}

public enum Gender
{
    Unknown = 0,  // 未知
    Male = 1,     // 男
    Female = 2    // 女
}

// 在实体中使用枚举
[SugarTable("sys_user")]
public class User
{
    [SugarColumn(IsPrimaryKey = true, IsIdentity = true)]
    public int Id { get; set; }

    public string UserName { get; set; } = string.Empty;

    // 枚举类型，数据库中存储为 int 值
    public UserStatus Status { get; set; } = UserStatus.Active;

    public Gender Gender { get; set; } = Gender.Unknown;
}
```

```csharp
// 使用枚举查询
var activeUsers = db.Queryable<User>()
    .Where(it => it.Status == UserStatus.Active)
    .ToList();

// 枚举在数据库中存储为整数
// Status = 1 (Active), Gender = 1 (Male)
```

### 6.2 枚举存储为字符串

如果希望将枚举存储为字符串而非整数，可以自定义处理：

```csharp
[SugarTable("sys_config")]
public class SysConfig
{
    [SugarColumn(IsPrimaryKey = true, IsIdentity = true)]
    public int Id { get; set; }

    // 将枚举存储为字符串
    [SugarColumn(Length = 50, ColumnDataType = "varchar(50)")]
    public string StatusStr
    {
        get => Status.ToString();
        set => Status = Enum.Parse<UserStatus>(value);
    }

    [SugarColumn(IsIgnore = true)]
    public UserStatus Status { get; set; }
}
```

### 7.2 值对象映射

通过 `IsIgnore` 和计算属性实现值对象模式：

```csharp
// 值对象

{
    public decimal Amount { get; set; }
    public string Currency { get; set; } = "CNY";

    public override string ToString() => $"{Amount} {Currency}";
}

{

    // 数据库实际存储的列

    public decimal PriceAmount { get; set; }

    [SugarColumn(Length = 10, DefaultValue = "'CNY'")]
    public string PriceCurrency { get; set; } = "CNY";

    // 值对象（不映射数据库）
    [SugarColumn(IsIgnore = true)]
    public Money Price
    {
        get => new Money { Amount = PriceAmount, Currency = PriceCurrency };
        set
        {
            PriceAmount = value.Amount;
            PriceCurrency = value.Currency;
        }
    }
}
```

## 9. 实体约定与命名规范

### 9.1 全局命名映射

通过 `ConfigureExternalServices` 实现全局命名转换：

```csharp
var db = new SqlSugarScope(new ConnectionConfig()
{
    ConnectionString = "...",
    DbType = DbType.MySql,
    IsAutoCloseConnection = true,

    ConfigureExternalServices = new ConfigureExternalServices()
    {
        // 全局实体名转换：类名 → 下划线命名
        EntityNameService = (type, entity) =>
        {
            // Student → student
            // SysUser → sys_user
            entity.DbTableName = UtilMethods.ToUnderLine(entity.DbTableName);
        },

        // 全局列名转换：属性名 → 下划线命名
        EntityService = (property, column) =>
        {
            // UserName → user_name
            // CreateTime → create_time
            column.DbColumnName = UtilMethods.ToUnderLine(column.DbColumnName);

            // 自动处理可空引用类型
            if (column.IsPrimaryKey == false
                && new NullabilityInfoContext().Create(property).WriteState
                    is NullabilityState.Nullable)
            {
                column.IsNullable = true;
            }
        }
    }
});
```

### 9.2 常见命名规范

| 命名规范 | 类名示例 | 数据库表名 | 转换方式 |
|---------|---------|-----------|---------|
| Pascal → 下划线 | `SysUser` | `sys_user` | `UtilMethods.ToUnderLine()` |
| 添加前缀 | `User` | `t_user` | `"t_" + name` |
| 添加后缀 | `User` | `user_info` | `name + "_info"` |
| 全部小写 | `SysUser` | `sysuser` | `.ToLower()` |

### 9.3 推荐的实体类编写规范

```csharp
// ✅ 推荐的写法
[SugarTable("sys_user", TableDescription = "系统用户表")]
public class SysUser
{
    /// <summary>
    /// 用户ID
    /// </summary>

    public long Id { get; set; }

    /// <summary>
    /// 用户名
    /// </summary>
    [SugarColumn(Length = 50, IsNullable = false, ColumnDescription = "用户名")]
    public string UserName { get; set; } = string.Empty;
}

// ❌ 不推荐的写法

{
    public int id { get; set; }  // 属性名应使用 PascalCase
    public string name;          // 应使用属性而非字段
}
```

## 10. Fluent API配置

除了使用特性（Attribute）配置外，SqlSugar 还支持 Fluent API 方式来配置实体映射。

### 10.1 基本用法

```csharp
var db = new SqlSugarScope(new ConnectionConfig()
{
    ConnectionString = "...",
    DbType = DbType.MySql,
    IsAutoCloseConnection = true,

    ConfigureExternalServices = new ConfigureExternalServices()
    {
        EntityService = (property, column) =>
        {
            // 通过 Fluent API 方式配置列
            var entityType = property.DeclaringType;

            if (entityType == typeof(Student))
            {
                // 配置 Student 实体
                if (property.Name == nameof(Student.Id))
                {
                    column.IsPrimaryKey = true;
                    column.IsIdentity = true;
                }
                if (property.Name == nameof(Student.Name))
                {
                    column.Length = 50;
                    column.IsNullable = false;
                    column.ColumnDescription = "学生姓名";
                }
            }
        },

        EntityNameService = (type, entity) =>
        {
            if (type == typeof(Student))
            {
                entity.DbTableName = "t_student";
            }
        }
    }
});
```

### 10.2 无特性实体类（POCO）

使用 Fluent API，实体类可以保持纯 POCO（不依赖 SqlSugar 引用）：

```csharp
// 纯 POCO 实体类（无任何 SqlSugar 特性）
public class Student
{
    public int Id { get; set; }
    public string Name { get; set; } = string.Empty;
    public int Age { get; set; }
    public int ClassId { get; set; }
    public DateTime CreateTime { get; set; }
}

// 在配置中通过 Fluent API 完成映射
ConfigureExternalServices = new ConfigureExternalServices()
{
    EntityService = (property, column) =>
    {
        if (property.DeclaringType == typeof(Student))
        {
            switch (property.Name)
            {
                case "Id":
                    column.IsPrimaryKey = true;
                    column.IsIdentity = true;
                    break;
                case "Name":
                    column.DbColumnName = "student_name";
                    column.Length = 100;
                    column.IsNullable = false;
                    break;
                case "CreateTime":
                    column.IsOnlyIgnoreUpdate = true;
                    break;
            }
        }
    },
    EntityNameService = (type, entity) =>
    {
        if (type == typeof(Student))
        {
            entity.DbTableName = "t_student";
            entity.IsDisabledDelete = true;
        }
    }
}
```

### 10.3 特性与Fluent API混合使用

在实际项目中，可以将两种方式混合使用：

```csharp
// 实体类使用基本特性
[SugarTable("t_student")]
public class Student
{
    [SugarColumn(IsPrimaryKey = true, IsIdentity = true)]
    public int Id { get; set; }

    public string Name { get; set; } = string.Empty;

    public int Age { get; set; }
}

// 全局配置中补充通用规则
ConfigureExternalServices = new ConfigureExternalServices()
{
    EntityService = (property, column) =>
    {
        // 所有未标记为主键的 string? 类型自动设为可空
        if (column.IsPrimaryKey == false
            && new NullabilityInfoContext().Create(property).WriteState is NullabilityState.Nullable)
        {
            column.IsNullable = true;
        }

        // 所有 DateTime 类型属性设置列描述
        if (property.PropertyType == typeof(DateTime) && string.IsNullOrEmpty(column.ColumnDescription))
        {
            column.ColumnDescription = "时间字段";
        }
    }
}
```

> **建议**：对于简单项目，使用特性配置更直观；对于需要保持实体类纯净（POCO）或有统一命名规范的项目，使用 Fluent API 更灵活。

## 11. 本章小结

本章详细介绍了 SqlSugar 的实体类定义与特性配置：

- **SugarTable 特性**：用于配置表名、表描述、迁移控制等表级别属性
- **SugarColumn 特性**：提供了丰富的列级别配置，包括主键、自增、列名映射、可空性、长度、默认值、忽略规则、JSON 列等
- **主键与自增列**：支持单主键、复合主键、GUID 主键和雪花 ID 主键
- **导航属性**：通过 `[Navigate]` 特性实现一对一、一对多、多对多关联关系
- **枚举映射**：默认将枚举映射为整数值存储
- **复杂类型映射**：通过 JSON 列存储复杂对象和集合
- **实体继承**：通过基类提取公共字段，减少重复代码
- **Fluent API**：可作为特性配置的替代方案，保持实体类纯净
