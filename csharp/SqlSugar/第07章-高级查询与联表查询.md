## 1. Join联表查询

### 1.1 InnerJoin - 内连接

内连接只返回两个表中匹配的行：

```csharp
// 查询学生及其班级信息（内连接）
var list = db.Queryable<Student, ClassInfo>((s, c) => new JoinQueryInfos(
        JoinType.Inner, s.ClassId == c.Id
    ))
    .Select((s, c) => new
    {
        StudentName = s.Name,
        StudentAge = s.Age,
        ClassName = c.ClassName
    })
    .ToList();
```

生成的 SQL：

```sql
SELECT s.Name AS StudentName, s.Age AS StudentAge, c.ClassName
FROM Student s
INNER JOIN ClassInfo c ON s.ClassId = c.Id
```

### 1.2 LeftJoin - 左连接

左连接返回左表的所有行，即使右表没有匹配的行：

```csharp
// 左连接：查询所有学生，包括没有班级的学生
var list = db.Queryable<Student, ClassInfo>((s, c) => new JoinQueryInfos(
        JoinType.Left, s.ClassId == c.Id
    ))
    .Select((s, c) => new
    {
        StudentName = s.Name,
        ClassName = c.ClassName ?? "未分配班级"
    })
    .ToList();
```

生成的 SQL：

```sql
SELECT s.Name AS StudentName, IFNULL(c.ClassName, '未分配班级') AS ClassName
FROM Student s
LEFT JOIN ClassInfo c ON s.ClassId = c.Id
```

### 1.3 RightJoin - 右连接

右连接返回右表的所有行：

```csharp
// 右连接：查询所有班级，包括没有学生的班级
var list = db.Queryable<Student, ClassInfo>((s, c) => new JoinQueryInfos(
        JoinType.Right, s.ClassId == c.Id
    ))
    .Select((s, c) => new
    {
        StudentName = s.Name,
        ClassName = c.ClassName
    })
    .ToList();
```

### 1.4 简化写法（推荐）

SqlSugar 提供了更简洁的联表查询写法：

```csharp
// 使用 LeftJoin 方法（推荐写法）
var list = db.Queryable<Student>()
    .LeftJoin<ClassInfo>((s, c) => s.ClassId == c.Id)
    .Select((s, c) => new
    {
        s.Id,
        s.Name,
        s.Age,
        ClassName = c.ClassName
    })
    .ToList();

// 使用 InnerJoin 方法
var list = db.Queryable<Student>()
    .InnerJoin<ClassInfo>((s, c) => s.ClassId == c.Id)
    .Select((s, c) => new
    {
        s.Id,
        s.Name,
        ClassName = c.ClassName
    })
    .ToList();
```

### 1.5 联表查询带条件和排序

```csharp
var list = db.Queryable<Student>()
    .LeftJoin<ClassInfo>((s, c) => s.ClassId == c.Id)
    .Where((s, c) => s.Age > 18)
    .Where((s, c) => c.ClassName != null)
    .OrderBy((s, c) => s.Id, OrderByType.Desc)
    .Select((s, c) => new
    {
        s.Id,
        s.Name,
        s.Age,
        ClassName = c.ClassName
    })
    .ToList();
```

## 2. 多表联查

### 2.1 三表联查

```csharp
// 学生、班级、成绩三表联查
var list = db.Queryable<Student>()
    .LeftJoin<ClassInfo>((s, c) => s.ClassId == c.Id)
    .LeftJoin<Score>((s, c, sc) => s.Id == sc.StudentId)
    .Select((s, c, sc) => new
    {
        StudentName = s.Name,
        ClassName = c.ClassName,
        ScoreValue = sc.ScoreValue,
        Subject = sc.Subject
    })
    .ToList();
```

生成的 SQL：

```sql
SELECT s.Name AS StudentName, c.ClassName, sc.ScoreValue, sc.Subject
FROM Student s
LEFT JOIN ClassInfo c ON s.ClassId = c.Id
LEFT JOIN Score sc ON s.Id = sc.StudentId
```

### 2.2 四表联查

```csharp
// 学生、班级、成绩、课程四表联查
var list = db.Queryable<Student>()
    .LeftJoin<ClassInfo>((s, c) => s.ClassId == c.Id)
    .LeftJoin<Score>((s, c, sc) => s.Id == sc.StudentId)
    .LeftJoin<Course>((s, c, sc, co) => sc.CourseId == co.Id)
    .Select((s, c, sc, co) => new
    {
        StudentName = s.Name,
        ClassName = c.ClassName,
        CourseName = co.CourseName,
        ScoreValue = sc.ScoreValue
    })
    .ToList();
```

### 2.3 自连接

```csharp
// 查询员工及其上级（自连接）
var list = db.Queryable<Employee, Employee>((e1, e2) => new JoinQueryInfos(
        JoinType.Left, e1.ManagerId == e2.Id
    ))
    .Select((e1, e2) => new
    {
        EmployeeName = e1.Name,
        ManagerName = e2.Name
    })
    .ToList();
```

生成的 SQL：

```sql
SELECT e1.Name AS EmployeeName, e2.Name AS ManagerName
FROM Employee e1
LEFT JOIN Employee e2 ON e1.ManagerId = e2.Id
```

### 2.4 联表分组聚合

```csharp
// 统计每个班级的学生人数和平均年龄
var list = db.Queryable<Student>()
    .LeftJoin<ClassInfo>((s, c) => s.ClassId == c.Id)
    .GroupBy((s, c) => c.ClassName)
    .Select((s, c) => new
    {
        ClassName = c.ClassName,
        StudentCount = SqlFunc.AggregateCount(s.Id),
        AvgAge = SqlFunc.AggregateAvg(s.Age),
        MaxAge = SqlFunc.AggregateMax(s.Age),
        MinAge = SqlFunc.AggregateMin(s.Age)
    })
    .Having((s, c) => SqlFunc.AggregateCount(s.Id) > 0)
    .OrderByDescending((s, c) => SqlFunc.AggregateCount(s.Id))
    .ToList();
```

### 2.5 联表分页

```csharp
int totalCount = 0;

var list = db.Queryable<Student>()
    .LeftJoin<ClassInfo>((s, c) => s.ClassId == c.Id)
    .Where((s, c) => s.Age > 18)
    .OrderBy((s, c) => s.Id)
    .Select((s, c) => new StudentDto
    {
        Id = s.Id,
        Name = s.Name,
        ClassName = c.ClassName
    })
    .ToPageList(1, 10, ref totalCount);
```

### 2.6 支持多达12张表的联查

SqlSugar 支持最多12张表的联查：

```csharp
// 多表联查示例（6表联查）
var list = db.Queryable<T1>()
    .LeftJoin<T2>((t1, t2) => t1.Id == t2.T1Id)
    .LeftJoin<T3>((t1, t2, t3) => t2.Id == t3.T2Id)
    .LeftJoin<T4>((t1, t2, t3, t4) => t3.Id == t4.T3Id)
    .LeftJoin<T5>((t1, t2, t3, t4, t5) => t4.Id == t5.T4Id)
    .LeftJoin<T6>((t1, t2, t3, t4, t5, t6) => t5.Id == t6.T5Id)
    .Select((t1, t2, t3, t4, t5, t6) => new
    {
        // 选择需要的字段
    })
    .ToList();
```

> **提示**：虽然 SqlSugar 支持多表联查，但实际项目中建议联表数不超过3-4张，过多的联表会影响性能和可维护性。

## 3. 子查询

### 3.1 Where中的子查询

```csharp
// 查询有考试成绩的学生
var list = db.Queryable<Student>()
    .Where(it => SqlFunc.Subqueryable<Score>()
        .Where(sc => sc.StudentId == it.Id)
        .Any())
    .ToList();
```

生成的 SQL：

```sql
SELECT * FROM Student it
WHERE EXISTS (
    SELECT 1 FROM Score sc WHERE sc.StudentId = it.Id
)
```

### 3.2 子查询获取单个值

```csharp
// 查询每个学生的最高成绩
var list = db.Queryable<Student>()
    .Select(it => new
    {
        it.Id,
        it.Name,
        MaxScore = SqlFunc.Subqueryable<Score>()
            .Where(sc => sc.StudentId == it.Id)
            .Max(sc => sc.ScoreValue)
    })
    .ToList();
```

生成的 SQL：

```sql
SELECT Id, Name,
    (SELECT MAX(ScoreValue) FROM Score sc WHERE sc.StudentId = it.Id) AS MaxScore
FROM Student it
```

### 3.3 子查询获取数量

```csharp
// 查询每个班级的学生数量
var list = db.Queryable<ClassInfo>()
    .Select(it => new
    {
        it.Id,
        it.ClassName,
        StudentCount = SqlFunc.Subqueryable<Student>()
            .Where(s => s.ClassId == it.Id)
            .Count()
    })
    .ToList();
```

### 3.4 IN子查询

```csharp
// 查询有成绩大于90分的学生
var list = db.Queryable<Student>()
    .Where(it => SqlFunc.Subqueryable<Score>()
        .Where(sc => sc.StudentId == it.Id && sc.ScoreValue > 90)
        .Any())
    .ToList();
```

### 3.5 NOT IN子查询

```csharp
// 查询没有任何成绩的学生
var list = db.Queryable<Student>()
    .Where(it => SqlFunc.Subqueryable<Score>()
        .Where(sc => sc.StudentId == it.Id)
        .NotAny())
    .ToList();
```

### 3.6 子查询作为数据源

```csharp
// 使用子查询作为 FROM 数据源
var list = db.Queryable<Student>()
    .Where(it => it.Age > 18)
    .Select(it => new { it.Id, it.Name, it.ClassId })
    .MergeTable()  // 将前面的查询作为子查询
    .LeftJoin<ClassInfo>((sub, c) => sub.ClassId == c.Id)
    .Select((sub, c) => new
    {
        sub.Id,
        sub.Name,
        ClassName = c.ClassName
    })
    .ToList();
```

生成的 SQL：

```sql
SELECT sub.Id, sub.Name, c.ClassName
FROM (
    SELECT Id, Name, ClassId FROM Student WHERE Age > 18
) sub
LEFT JOIN ClassInfo c ON sub.ClassId = c.Id
```

## 4. Union与UnionAll

### 4.1 UnionAll - 合并结果（保留重复）

```csharp
// UnionAll：合并两个查询的结果
var query1 = db.Queryable<Student>()
    .Where(it => it.ClassId == 1)
    .Select(it => new { it.Id, it.Name });

var query2 = db.Queryable<Student>()
    .Where(it => it.ClassId == 2)
    .Select(it => new { it.Id, it.Name });

var list = db.UnionAll(query1, query2).ToList();
```

生成的 SQL：

```sql
SELECT Id, Name FROM Student WHERE ClassId = 1
UNION ALL
SELECT Id, Name FROM Student WHERE ClassId = 2
```

### 4.2 Union - 合并结果（去重）

```csharp
// Union：合并结果并去除重复行
var query1 = db.Queryable<Student>()
    .Select(it => new { it.Name });

var query2 = db.Queryable<Teacher>()
    .Select(it => new { it.Name });

var list = db.Union(query1, query2).ToList();
```

### 4.3 UnionAll后继续查询

```csharp
// UnionAll 后进行分页
var query1 = db.Queryable<Student>()
    .Where(it => it.ClassId == 1)
    .Select(it => new { it.Id, it.Name, Type = "Student" });

var query2 = db.Queryable<Teacher>()
    .Select(it => new { it.Id, it.Name, Type = "Teacher" });

var list = db.UnionAll(query1, query2)
    .OrderBy(it => it.Id)
    .ToPageList(1, 10);
```

## 6. 树形查询

### 6.1 基础树形查询

SqlSugar 提供了便捷的树形查询方法，适用于菜单、部门等树形结构数据：

```csharp
// 实体类
public class Department
{
    [SugarColumn(IsPrimaryKey = true, IsIdentity = true)]
    public int Id { get; set; }
    public string Name { get; set; }
    public int ParentId { get; set; }  // 父节点ID，根节点为0

    [SugarColumn(IsIgnore = true)]
    public List<Department> Children { get; set; }
}

// 查询所有部门并组装为树形结构
var treeList = db.Queryable<Department>()
    .ToTree(it => it.Children, it => it.ParentId, 0);
    // 参数1: 子节点属性
    // 参数2: 父ID属性
    // 参数3: 根节点的父ID值
```

### 6.2 带条件的树形查询

```csharp
// 只查询启用状态的部门树
var treeList = db.Queryable<Department>()
    .Where(it => it.IsEnabled == true)
    .ToTree(it => it.Children, it => it.ParentId, 0);
```

### 6.3 查询指定节点的所有子节点

```csharp
// 查询某个部门下的所有子部门（包括子部门的子部门）
var children = db.Queryable<Department>()
    .ToChildList(it => it.ParentId, 5);  // 查询 ParentId=5 的所有后代节点
```

### 6.4 查询指定节点的所有父节点

```csharp
// 查询某个部门的所有上级部门
var parents = db.Queryable<Department>()
    .ToParentList(it => it.ParentId, 20);  // 查询 Id=20 的所有祖先节点
```

## 8. 动态查询与SqlQueryable

### 8.1 动态表名查询

```csharp
// 动态指定表名
var list = db.Queryable<Student>()
    .AS("Student_2024")  // 指定实际表名
    .ToList();
```

生成的 SQL：

```sql
SELECT * FROM Student_2024
```

### 8.2 动态条件构建

```csharp
// 使用 Expressionable 构建动态表达式
var exp = Expressionable.Create<Student>();

exp.AndIF(!string.IsNullOrEmpty(name), it => it.Name.Contains(name));
exp.AndIF(age.HasValue, it => it.Age == age.Value);
exp.AndIF(classId.HasValue, it => it.ClassId == classId.Value);
exp.OrIF(includeAll, it => true);

var list = db.Queryable<Student>()
    .Where(exp.ToExpression())
    .ToList();
```

### 8.3 FromQuery 子查询

```csharp
// 使用 FromQuery 创建子查询
var subQuery = db.Queryable<Student>()
    .Where(it => it.Age > 18)
    .Select(it => new { it.Id, it.Name, it.ClassId });

var list = db.Queryable<ClassInfo>()
    .LeftJoin(subQuery, (c, s) => c.Id == s.ClassId)
    .Select((c, s) => new
    {
        c.ClassName,
        StudentName = s.Name
    })
    .ToList();
```

### 8.4 WithTemp 临时表查询

```csharp
// 使用临时结果集
var tempData = db.Queryable<Student>()
    .Where(it => it.Age > 18)
    .Select(it => new { it.Id, it.Name, it.ClassId })
    .ToList();

// 将内存数据作为临时表使用
var list = db.Queryable<ClassInfo>()
    .LeftJoin(db.Reportable(tempData).ToQueryable(), (c, t) => c.Id == t.ClassId)
    .Select((c, t) => new
    {
        c.ClassName,
        t.Name
    })
    .ToList();
```

### 8.5 MergeTable 合并查询

```csharp
// 将前面的查询结果合并为临时表，再进行后续操作
var list = db.Queryable<Student>()
    .Select(it => new
    {
        it.Id,
        it.Name,
        AgeGroup = SqlFunc.IIF(it.Age < 18, "未成年", "成年")
    })
    .MergeTable()  // 合并为子查询
    .Where(it => it.AgeGroup == "成年")
    .OrderBy(it => it.Id)
    .ToList();
```

生成的 SQL：

```sql
SELECT * FROM (
    SELECT Id, Name,
        CASE WHEN Age < 18 THEN '未成年' ELSE '成年' END AS AgeGroup
    FROM Student
) t
WHERE t.AgeGroup = '成年'
ORDER BY t.Id
```

## 10. CASE WHEN表达式

### 10.1 简单CASE WHEN

```csharp
// 使用 SqlFunc.IIF（简单的 CASE WHEN）
var list = db.Queryable<Student>()
    .Select(it => new
    {
        it.Id,
        it.Name,
        it.Age,
        AgeCategory = SqlFunc.IIF(it.Age < 18, "未成年", "成年")
    })
    .ToList();
```

生成的 SQL：

```sql
SELECT Id, Name, Age,
    CASE WHEN Age < 18 THEN '未成年' ELSE '成年' END AS AgeCategory
FROM Student
```

### 10.2 多条件CASE WHEN

```csharp
// 嵌套 IIF 实现多条件判断
var list = db.Queryable<Student>()
    .Select(it => new
    {
        it.Id,
        it.Name,
        it.Age,
        AgeGroup = SqlFunc.IIF(it.Age < 12, "儿童",
                   SqlFunc.IIF(it.Age < 18, "少年",
                   SqlFunc.IIF(it.Age < 30, "青年",
                   SqlFunc.IIF(it.Age < 50, "中年", "老年"))))
    })
    .ToList();
```

### 10.3 在Where中使用CASE WHEN

```csharp
// 根据条件动态计算分组
var list = db.Queryable<Score>()
    .GroupBy(it => SqlFunc.IIF(it.ScoreValue >= 90, "优秀",
                  SqlFunc.IIF(it.ScoreValue >= 80, "良好",
                  SqlFunc.IIF(it.ScoreValue >= 60, "及格", "不及格"))))
    .Select(it => new
    {
        Grade = SqlFunc.IIF(it.ScoreValue >= 90, "优秀",
                SqlFunc.IIF(it.ScoreValue >= 80, "良好",
                SqlFunc.IIF(it.ScoreValue >= 60, "及格", "不及格"))),
        Count = SqlFunc.AggregateCount(it.Id)
    })
    .ToList();
```

### 10.4 在OrderBy中使用CASE WHEN

```csharp
// 自定义排序顺序
var list = db.Queryable<Student>()
    .OrderBy(it => SqlFunc.IIF(it.ClassId == 1, 1,
                   SqlFunc.IIF(it.ClassId == 3, 2,
                   SqlFunc.IIF(it.ClassId == 2, 3, 4))))
    .ToList();
```

## 11. 窗口函数

### 11.1 ROW_NUMBER - 行号

```csharp
// 按班级分组添加行号
var list = db.Queryable<Student>()
    .Select(it => new
    {
        it.Id,
        it.Name,
        it.ClassId,
        it.Age,
        RowNum = SqlFunc.RowNumber(it.Id, it.ClassId)
        // RowNumber(排序字段, 分组字段)
    })
    .ToList();
```

生成的 SQL：

```sql
SELECT Id, Name, ClassId, Age,
    ROW_NUMBER() OVER (PARTITION BY ClassId ORDER BY Id) AS RowNum
FROM Student
```

### 11.2 ROW_NUMBER 降序

```csharp
// 按年龄降序编号
var list = db.Queryable<Student>()
    .Select(it => new
    {
        it.Id,
        it.Name,
        it.Age,
        RowNum = SqlFunc.RowNumber(
            SqlFunc.Desc(it.Age))  // 降序排列
    })

```

### 11.3 RANK 和 DENSE_RANK

```csharp
// RANK函数
var list = db.Queryable<Score>()
    .Select(it => new
    {
        it.StudentId,
        it.Subject,
        it.ScoreValue,
        Rank = SqlFunc.Rank(SqlFunc.Desc(it.ScoreValue), it.Subject)
        // 按科目分组，按成绩降序排名
    })
    .ToList();

// DENSE_RANK函数
var list = db.Queryable<Score>()
    .Select(it => new
    {
        it.StudentId,
        it.Subject,
        it.ScoreValue,
        DenseRank = SqlFunc.DenseRank(SqlFunc.Desc(it.ScoreValue), it.Subject)
    })
    .ToList();
```

生成的 SQL：

```sql
-- RANK
SELECT StudentId, Subject, ScoreValue,
    RANK() OVER (PARTITION BY Subject ORDER BY ScoreValue DESC) AS Rank
FROM Score

-- DENSE_RANK
SELECT StudentId, Subject, ScoreValue,
    DENSE_RANK() OVER (PARTITION BY Subject ORDER BY ScoreValue DESC) AS DenseRank
FROM Score
```

### 11.4 聚合窗口函数

```csharp
// SUM OVER - 累计求和
var list = db.Queryable<Score>()
    .Select(it => new
    {
        it.StudentId,
        it.ScoreValue,
        TotalScore = SqlFunc.AggregateSum(it.ScoreValue)
            .Over()
            .PartitionBy(it.StudentId)
            .ToValue()
```

### 11.5 使用窗口函数实现分组取Top N

```csharp
// 每个班级取成绩最高的前3名学生
var list = db.Queryable<Student>()
    .LeftJoin<Score>((s, sc) => s.Id == sc.StudentId)
    .Select((s, sc) => new
    {
        s.Id,
        s.Name,
        s.ClassId,
        sc.ScoreValue,
        RowNum = SqlFunc.RowNumber(SqlFunc.Desc(sc.ScoreValue), s.ClassId)
    })
    .MergeTable()
    .Where(it => it.RowNum <= 3)
    .ToList();
```

生成的 SQL：

```sql
SELECT * FROM (
    SELECT s.Id, s.Name, s.ClassId, sc.ScoreValue,
        ROW_NUMBER() OVER (PARTITION BY s.ClassId ORDER BY sc.ScoreValue DESC) AS RowNum
    FROM Student s
    LEFT JOIN Score sc ON s.Id = sc.StudentId
) t
WHERE t.RowNum <= 3
```

## 12. CTE递归查询

### 12.1 基础CTE查询

```csharp
// 使用 CTE 递归查询组织架构树
var list = db.Queryable<Department>()
    .Where(it => it.Id == 1)  // 从根节点开始
    .ToTree(it => it.Children, it => it.ParentId, 0);
```

### 12.2 手动CTE递归

对于复杂的递归场景，可以使用原生 SQL：

```csharp
// 使用原生 SQL 实现 CTE 递归
string sql = @"
    WITH RECURSIVE dept_tree AS (
        -- 基础查询（锚点）
        SELECT Id, Name, ParentId, 1 AS Level
        FROM Department
        WHERE Id = @rootId

        UNION ALL

        -- 递归查询
        SELECT d.Id, d.Name, d.ParentId, dt.Level + 1
        FROM Department d
        INNER JOIN dept_tree dt ON d.ParentId = dt.Id
    )
    SELECT * FROM dept_tree ORDER BY Level, Id";

var list = db.Ado.SqlQuery<DepartmentTreeDto>(sql,
    new SugarParameter("@rootId", 1));
```

### 12.3 向上递归（查找所有父节点）

```csharp
// 查找某个部门的所有上级部门
string sql = @"
    WITH RECURSIVE parent_tree AS (
        SELECT Id, Name, ParentId, 1 AS Level
        FROM Department
        WHERE Id = @nodeId

        UNION ALL

        SELECT d.Id, d.Name, d.ParentId, pt.Level + 1
        FROM Department d
        INNER JOIN parent_tree pt ON d.Id = pt.ParentId
        WHERE d.ParentId IS NOT NULL
    )
    SELECT * FROM parent_tree ORDER BY Level DESC";

var parents = db.Ado.SqlQuery<DepartmentTreeDto>(sql,
    new SugarParameter("@nodeId", 20));
```

### 12.4 使用ToParentList和ToChildList

SqlSugar 封装了更简便的树形查询方法：

```csharp
// 查询所有子节点（向下递归）
var children = db.Queryable<Department>()
    .ToChildList(it => it.ParentId, 1);  // 查询 Id=1 的所有后代

// 查询所有父节点（向上递归）
var parents = db.Queryable<Department>()
    .ToParentList(it => it.ParentId, 20);  // 查询 Id=20 的所有祖先

// 限制递归层级
var children = db.Queryable<Department>()
    .ToChildList(it => it.ParentId, 1, 3);  // 最多递归3层
```

```sql
SELECT * FROM Student WITH (NOLOCK)
```

### 13.2 Partition 分表查询

```csharp
// 分表查询（按日期分表）
var list = db.Queryable<OrderInfo>()
    .SplitTable(tabs => tabs.InTableNames("OrderInfo_2024", "OrderInfo_2023"))
    .Where(it => it.Amount > 100)
    .ToList();
```

### 13.3 Clone 克隆查询

```csharp
// 克隆查询对象，用于分支条件查询
var baseQuery = db.Queryable<Student>()
    .Where(it => it.Age > 18);

// 分支1：查询总数
var count = baseQuery.Clone().Count();

// 分支2：查询列表
var list = baseQuery.Clone()
    .OrderBy(it => it.Id)
    .Take(10)
    .ToList();
```

### 13.4 Reportable 报表查询

```csharp
// 生成日期维度（补全缺失的日期）
var dateRange = db.Reportable(
    ReportableDateType.MonthsInLast1years)  // 最近12个月
    .ToQueryable<DateTime>();

// 与业务数据联查，实现每月统计（包含无数据的月份）
var list = db.Queryable(dateRange, db.Queryable<Order>()
    .GroupBy(it => SqlFunc.DateValue(it.CreateTime, DateType.Month))
    .Select(it => new
    {
        Month = SqlFunc.DateValue(it.CreateTime, DateType.Month),
        Total = SqlFunc.AggregateSum(it.Amount)
    })
    .MergeTable())
    .LeftJoin((d, o) => d.ColumnName == o.Month)
    .Select((d, o) => new
    {
        Month = d.ColumnName,
        Total = SqlFunc.IsNull(o.Total, 0)
    })
    .ToList();
```

### 13.5 ThenMapper 二次映射

```csharp
// 使用 ThenMapper 进行二次查询映射
var list = db.Queryable<ClassInfo>()
    .Mapper(c => c.Students, c => c.Students.First().ClassId)
    .ToList();

// 或使用 ThenMapper
var list = db.Queryable<ClassInfo>()
    .ToList();

// 手动二次查询
foreach (var c in list)
{
    c.Students = db.Queryable<Student>()
        .Where(s => s.ClassId == c.Id)
        .ToList();
}
```

## 14. 本章小结

本章全面介绍了 SqlSugar 的高级查询功能：

- **Join 联表查询**：`InnerJoin`、`LeftJoin`、`RightJoin`，支持简化写法
- **多表联查**：支持最多12张表的联查，包括自连接、联表分组聚合、联表分页
- **子查询**：`Subqueryable` 实现 WHERE 子查询、SELECT 子查询、IN 子查询
- **Union/UnionAll**：合并多个查询结果，支持后续查询操作
- **原生 SQL**：`SqlQueryable`、`Ado` 原生查询、存储过程调用
- **树形查询**：`ToTree`、`ToChildList`、`ToParentList` 处理树形结构
- **跨数据库查询**：多库配置、跨库联查、数据库上下文切换
- **动态查询**：动态表名、`Expressionable` 条件构建、`MergeTable` 合并查询
- **EXISTS**：`Any()` 和 `NotAny()` 实现 EXISTS/NOT EXISTS
- **CASE WHEN**：`SqlFunc.IIF` 实现条件表达式
- **窗口函数**：`ROW_NUMBER`、`RANK`、`DENSE_RANK`，分组取 Top N
- **CTE 递归查询**：递归查询组织架构、向上/向下递归

掌握这些高级查询功能后，你可以应对绝大多数复杂的业务查询场景。
