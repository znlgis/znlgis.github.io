# Clipper1 C# 开发使用教程

## 教程简介

本教程是 Clipper1（ClipperLib）的完整中文开发使用教程，专注于 C# 语言版本。Clipper1 是一个强大的开源多边形裁剪和偏移库，广泛应用于 GIS、CAD、游戏开发、制造业等领域。

3. **完成练习**：尝试完成每章末尾的练习题
