## 🎯 推荐学习路线

### 🏗️ CAD 开发入门
1. [FreeCAD 教程](FreeCAD/) — 参数化建模入门
2. [CadQuery 教程](cadquery/) — Python 参数化 CAD
3. [OpenSCAD 教程](openscad/) — 脚本化设计
4. [OCCT 教程](occt/) — 几何内核深入

1. [IFoxCAD 教程](IFoxCAD/) — .NET 开发框架
