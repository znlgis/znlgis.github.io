# CAD 教程

本栏目收录 CAD（计算机辅助设计）开发相关的完整教程，涵盖参数化建模、几何内核、BIM、EDA、CAM 和三维可视化等领域。

## 🎯 推荐学习路线

### 🏗️ CAD 开发入门
1. [FreeCAD 教程](https://znlgis.github.io/cad/FreeCAD/) — 参数化建模入门
2. [CadQuery 教程](https://znlgis.github.io/cad/cadquery/) — Python 参数化 CAD
3. [OpenSCAD 教程](https://znlgis.github.io/cad/openscad/) — 脚本化设计
4. [OCCT 教程](https://znlgis.github.io/cad/occt/) — 几何内核深入

### 🔌 AutoCAD 二次开发
1. [IFoxCAD 教程](https://znlgis.github.io/cad/IFoxCAD/) — .NET 开发框架
2. [TongWen 教程](https://znlgis.github.io/cad/TongWen/) — CAD 图纸无损翻译
3. [LibreDWG 教程](https://znlgis.github.io/cad/libredwg/) — DWG 文件格式

### 📐 BIM 开发
1. [Xbim 教程](https://znlgis.github.io/cad/Xbim/) — IFC 标准与 BIM
2. [Astral3D 教程](https://znlgis.github.io/cad/Astral3D/) — BIM 轻量化

### ⚡ EDA 电子设计
1. [KiCad 教程](https://znlgis.github.io/cad/KiCad/) — 完整 PCB 设计流程
