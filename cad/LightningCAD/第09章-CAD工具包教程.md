# 第9章 CAD工具包教程

本章将详细介绍 LightningCAD 附带的 **CAD 工具包（Kit）** 中的各项辅助工具。这些工具覆盖了从轴网生成、视口导航到图纸管理、快捷键配置等日常 CAD 深化设计工作中高频使用的通用功能，旨在帮助您提升绘图效率、规范图纸管理，并获得更流畅的操作体验。

## 9.1 CAD工具包概述

### 9.1.1 什么是 CAD 工具包（Kit）

CAD 工具包（以下简称"Kit"）是 LightningCAD 产品体系中一组**通用 CAD 辅助工具**的集合。它独立于围护业务的核心排布逻辑，专注于为 CAD 深化设计师提供跨场景、跨项目的基础效率工具。

Kit 中包含的工具涵盖以下领域：

| 工具模块 | 功能简述 |
|----------|----------|
| **操作向导（OperateWizard）** | 侧面停靠面板，按分类组织所有命令，支持搜索与主题切换 |
| **轴网生成（AxisGrid）** | 自动生成与手动绘制建筑轴网 |
| **视口导航（ViewportNavigation）** | 快速定位图纸区域，保存/恢复视口位置 |
| **属性面板（PropertyPalette）** | 统一查看与编辑选中实体的属性信息 |
| **图纸管理（DrawingManage）** | 集中管理图层、文字样式、标注样式等图纸基础设置 |
| **快捷键管理（ShortcutSettings）** | 自定义快捷键与简化命令，支持导入/导出 |
| **备份管理（BackupSettings）** | 自动与手动备份 DWG 文件，防止数据丢失 |
| **用户反馈（Feedback）** | 快速提交问题反馈与查询处理进度 |

### 9.1.2 工具包与核心插件的关系

LightningCAD 的整体架构分为**核心业务层**与**工具包层**两个部分：

- **核心业务层**：负责板材排布、节点线管理、收边处理、图纸输出等围护结构深化设计的专属业务逻辑。
- **工具包层（Kit）**：提供通用的 CAD 辅助功能，不依赖于特定的围护业务场景。

两者通过**依赖注入（DI）**机制协同工作。Kit 层定义了一套配置接口 `IKitAppConfig`，由宿主产品（如 LightningCAD 主程序）在启动时注入路径、面板标识等配置信息。这意味着 Kit 层的工具可以灵活适配不同的宿主产品，而不需要修改 Kit 自身的代码。

### 9.1.3 可以独立使用还是依赖核心功能

Kit 中的大部分工具**可以独立使用**，无需先执行核心业务操作。例如：

- **轴网生成**、**视口导航**、**图层管理**等工具可在任何 DWG 图纸中直接使用。
- **属性面板**在选中 CAD 实体后即可展示属性信息，无论该实体是否由 LightningCAD 创建。
- **快捷键管理**、**备份管理**属于全局设置，在插件加载后即生效。

部分工具在与核心业务配合使用时可获得更丰富的功能。例如，属性面板在选中 LightningCAD 创建的板材、节点线等围护实体时，会展示专属的业务属性（如板材型号、节点编号等），而在选中普通 CAD 实体时则显示通用几何属性。

## 9.2 操作向导（OperateWizard）

### 9.2.1 操作向导的作用

操作向导是 LightningCAD 在 CAD 界面右侧停靠的**命令导航面板**。它将所有可用命令按照业务分类进行组织，让用户无需记忆命令名称，即可通过直观的分组列表快速找到并执行所需功能。

操作向导的核心价值：

- **分类导航**：所有命令按功能分组（如柱梁、墙面、屋面等），支持两级分类切换。
- **快速搜索**：内置搜索框，可按命令名称、命令别名或提示信息快速过滤。
- **Ribbon 同步**：操作向导的分类切换会与 CAD 顶部的 Ribbon 工具栏联动，保持一致的功能上下文。
- **主题适配**：支持浅色与深色两种主题模式，适配不同的工作环境偏好。

### 9.2.2 向导界面说明

操作向导面板从上到下由以下区域组成：

#### 顶部工具栏

| 按钮 | 功能 |
|------|------|
| 🔍 **放大** | 增大命令列表的行高和字体（最大 40px 行高 / 20px 字体） |
| 🔍 **缩小** | 减小命令列表的行高和字体（最小 28px 行高 / 12px 字体） |
| 📋 **Fs 特性面板** | 打开/关闭属性面板（详见 9.5） |
| ☁ **备份设置** | 打开备份设置对话框（详见 9.8） |
| 🌓 **主题切换** | 在浅色/深色主题之间切换 |

#### 分类下拉框

位于工具栏右侧，用于选择当前显示的命令分类。分类采用两级结构：

- **一级分类**（如"详图"、"预算"等）
- **二级分类**（如"墙面"、"屋面"、"雨棚"等）

切换分类后，下方的命令分组列表和 CAD Ribbon 工具栏将同步更新。

#### 搜索框

位于分类下拉框下方，支持以下操作：

1. 在搜索框中输入关键词。
2. 按 **Enter** 键或点击搜索图标 🔍 执行搜索。
3. 搜索结果将过滤命令列表，仅显示名称、别名或提示信息中包含关键词的命令。
4. 点击清除按钮 ✕ 可恢复显示全部命令。

#### 命令分组列表（GroupBar）

面板主体区域采用可折叠的分组列表展示命令。每个分组包含：

- **分组标题**：点击可展开或折叠该分组。
- **命令按钮**：每个按钮显示命令图标、中文名称和快捷键提示（如已设置）。鼠标悬停时显示命令的详细提示信息。

单击命令按钮即可执行对应的 CAD 命令。

### 9.2.3 使用场景

| 场景 | 说明 |
|------|------|
| **新用户入门** | 不熟悉命令名称时，通过分类浏览快速找到所需功能 |
| **日常操作** | 替代传统的命令行输入，通过面板点击完成高频操作 |
| **命令查找** | 输入关键词搜索不常用的命令，避免在菜单中逐级查找 |
| **切换工作上下文** | 通过分类下拉框快速切换墙面/屋面等不同工作场景的命令集 |

### 9.2.4 打开与关闭操作向导

- **打开**：在 CAD 命令行输入操作向导的命令名称，或通过 LightningCAD 菜单入口打开。
- **关闭**：再次执行同一命令即可关闭面板（切换式开关）。
- **停靠**：面板默认停靠在 CAD 界面右侧，可拖动到左侧或其他位置。

## 9.3 轴网生成

### 9.3.1 轴网（Axis Grid）的概念与作用

轴网是建筑设计中用于定位结构构件（柱、梁、墙等）的基准参考线系统。在围护结构深化设计中，轴网是板材排布、节点定位的重要参照。

LightningCAD 的轴网工具提供以下能力：

- **自动生成轴网**：通过参数化对话框批量生成规则轴网。
- **手动绘制轴线**：交互式逐条绘制轴线，支持轴号自动递增。
- **定义轴线**：将已有的 CAD 线段定义为轴线并赋予轴号。

### 9.3.2 自动生成轴网

自动生成轴网是快速创建规则轴网的首选方式。操作流程如下：

#### 步骤一：启动命令

在操作向导中找到"生成轴网"命令并点击，或在命令行输入对应命令名称。

#### 步骤二：指定基点

命令启动后，CAD 命令行会提示您在图纸上**点击指定轴网的基点**（即轴网左下角的起始位置）。

#### 步骤三：设置轴网参数

指定基点后，系统将弹出"生成轴网"配置对话框。对话框分为三个区域：

**X 方向（水平方向，竖向轴线）**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| **启用/禁用** | 勾选复选框控制是否生成 X 方向的轴线 | 启用 |
| **间距序列** | 逗号分隔的间距值（单位与图纸一致）。例如 `3000,3000,3000,3000,3000` 表示 5 个等间距 3000 的开间 | `3000,3000,3000,3000,3000` |
| **编号方式** | 数字（1, 2, 3…）或字母（A, B, C…） | 数字 |
| **起始编号** | 编号的起始值。数字模式填 `1`，字母模式填 `A` | `1` |
| **轴号位置** | 轴号标注在轴线的哪一端：左侧 / 右侧 / 两侧都有 | 左侧 |

**Y 方向（垂直方向，横向轴线）**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| **启用/禁用** | 勾选复选框控制是否生成 Y 方向的轴线 | 启用 |
| **间距序列** | 逗号分隔的间距值 | `3000,3000,3000` |
| **编号方式** | 数字或字母 | 字母 |
| **起始编号** | 编号起始值 | `A` |
| **轴号位置** | 底部 / 顶部 / 两端都有 | 底部 |

**通用参数**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| **轴线超出长度** | 轴线超出网格边界的延伸长度（图纸单位） | `1000` |

#### 步骤四：确认生成

设置完参数后，点击**确认**按钮，系统将根据参数在图纸上批量生成轴网线及轴号标注。点击**取消**或按 **Esc** 键可放弃生成。

> **提示**：
> - 间距序列支持不等间距。例如 `6000,3600,6000` 表示三个开间，中间开间较窄。
> - 对话框中的参数会自动保存，下次打开时将恢复上次的设置。
> - 如果只需要生成单方向的轴线（如仅竖向），可取消勾选另一方向的复选框。

### 9.3.3 绘制轴线（手动绘制）

手动绘制适用于需要在已有图纸上补充少量轴线的场景。

#### 操作流程

1. **启动命令**：在操作向导中点击"绘制轴线"命令。
2. **输入轴号**：命令行提示输入轴号（如 `1` 或 `A`），输入后按 Enter 确认。
3. **指定起点**：在图纸上点击确定轴线的起点。
4. **实时预览**：移动鼠标时，系统会通过 Jig 技术实时预览轴线的位置和方向。
5. **指定终点**：点击确定轴线的终点，系统将自动创建轴线（Line 实体）及轴号标注块。
6. **连续绘制**：完成一条轴线后，系统自动进入下一条轴线的绘制状态，**轴号自动递增**（如 `1→2→3` 或 `A→B→C`）。
7. **退出**：按 **Esc** 键退出绘制模式。

#### 轴号自动递增规则

系统会智能识别您输入的起始轴号格式：

- **数字序列**：`1` → `2` → `3` → …
- **字母序列**：`A` → `B` → `C` → …

如果无法识别为规律序列，则后续轴线将沿用同一轴号。

### 9.3.4 定义轴线

"定义轴线"命令用于将图纸中已有的线段转换为带有轴号标注的轴线。

#### 操作流程

1. **启动命令**：点击"定义轴线"命令。
2. **选择轴号**：命令行提示输入或选择轴号。
3. **选择线段**：选择图纸中需要定义为轴线的线段。
4. **确认**：系统将所选线段转换为轴线，并在端点处生成轴号标注块。

### 9.3.5 编辑轴网

对于已生成的轴网，您可以通过以下方式编辑：

- **修改间距**：使用 CAD 的移动（Move）或拉伸（Stretch）命令调整轴线位置。
- **添加轴线**：使用"绘制轴线"命令在现有轴网中补充新的轴线。
- **删除轴线**：直接选中轴线实体后按 Delete 键删除。轴号标注块需单独删除。
- **修改轴号**：选中轴号标注块，通过属性面板（详见 9.5）修改轴号文字。在 Debug 模式下，属性面板中轴号字段可直接编辑；在 Release 模式下，轴号字段为只读。

## 9.4 视口导航

### 9.4.1 视口导航的作用

在大型围护结构项目中，一张 DWG 图纸通常包含多个大样图、整理图框和详图区域。设计师需要频繁在不同区域之间切换视角。视口导航工具帮助您：

- **快速定位到图框区域**：一键飞行到图纸中所有大样/图框的总体范围。
- **保存工作位置**：自动记录跳转前的视口位置，方便返回。
- **手动书签**：将常用的视口位置保存为命名书签，随时恢复。

### 9.4.2 导航面板说明

通过操作向导或命令启动视口导航后，将弹出"视口导航"对话框。面板分为以下区域：

#### 核心导航按钮（顶部）

| 按钮 | 功能 | 说明 |
|------|------|------|
| **查看图框** | 自动保存当前视口位置，然后缩放到所有图框的总体范围 | 如果图纸中没有大样或整理图框，将提示"当前图纸中没有大样或整理图框" |
| **返回画图点** | 跳回最近一次自动保存的工作视口位置 | 相当于"后退"按钮 |

#### 手动书签操作区

- **输入名称**：在文本框中输入书签名称。
- **保存视口**：点击按钮将当前视口位置保存为命名书签。书签保存在 DWG 文件中，与图纸一起持久化。

#### 手动收藏书签列表

以列表形式展示所有已保存的手动书签：

- **跳转**：双击书签名称即可恢复到保存时的视口位置。
- **删除**：点击书签右侧的删除按钮 ❌ 可移除该书签。

#### 自动历史足迹

系统会在每次执行"查看图框"操作前，自动保存当前视口位置到历史记录中：

- 最多保留 **5 条**历史记录。
- 双击任意历史记录可跳转到对应视口位置。
- 历史记录以时间戳命名（格式：`yyyy/MM/dd HH:mm:ss`）。

> **提示**：自动历史仅在视口位于图框区域之外时才会保存。如果您已经在图框区域内操作，系统不会重复记录，避免历史被无意义的记录覆盖。

### 9.4.3 使用场景

| 场景 | 操作 |
|------|------|
| **从详图区返回工作区** | 点击"查看图框"定位到图框，完成后点击"返回画图点"回到之前的工作位置 |
| **在多个大样之间切换** | 将每个大样的视口保存为手动书签（如"大样A"、"大样B"），通过双击书签快速切换 |
| **检查全局后恢复** | 缩放查看全局后，通过自动历史足迹返回之前的编辑位置 |

## 9.5 属性面板（PropertyPalette）

### 9.5.1 属性面板的作用

属性面板是 LightningCAD 提供的**统一实体属性编辑器**，以停靠面板的形式常驻在 CAD 界面左侧。当您在图纸中选中实体时，属性面板会自动显示该实体的属性信息，并允许您直接编辑。

与 CAD 原生的属性面板相比，LightningCAD 属性面板具有以下优势：

- **围护业务感知**：能识别 LightningCAD 创建的板材、节点线、收边、洞口等围护实体，展示业务专属属性。
- **批量编辑**：选中多个同类实体时，可一次性修改公共属性。
- **即时应用**：修改后点击"应用"按钮即可生效，无需关闭面板。

### 9.5.2 支持的实体类型

属性面板根据选中实体的类型自动切换显示内容：

| 实体类型 | 图标 | 说明 |
|----------|------|------|
| **板材（Panel）** | 🟦 | 显示板材型号、长度、颜色、图层等属性 |
| **边界（Boundary）** | 🟧 | 显示排布边界的几何属性 |
| **洞口（Opening）** | 🟨 | 显示洞口的尺寸、位置等属性 |
| **多边形洞口（PolyOpening）** | 🟨 | 显示多边形洞口的顶点与尺寸信息 |
| **分隔线（DivisionLine）** | 🟩 | 显示分隔线的位置与关联属性 |
| **节点线（JieDianLine）** | 🟪 | 显示节点编号、收边信息等，并提供"编辑节点线"快捷按钮 |
| **轴线（AxisLine）** | ⬜ | 显示轴号（支持编辑，详见 9.3.5） |
| **多选（Multi）** | 🔲 | 选中多个实体时，显示公共属性并支持批量编辑 |

### 9.5.3 属性面板布局说明

属性面板从上到下包含以下区域：

1. **工作状态栏**（顶部）：当面板正在加载实体属性时，显示进度提示和进度条。
2. **消息栏**：显示操作过程中的错误或提示信息。
3. **实体类型选择器**：下拉框显示当前选中实体的类型图标和名称。多选时，可在此切换查看不同实体类型的属性。
4. **属性编辑区**（主体）：以"属性名 - 属性值"的两列表格形式展示实体属性。属性按分组（如"基本信息"）组织。
   - 只读属性旁显示锁定图标 🔒。
   - 已修改的属性旁显示红色圆点标记。
5. **操作按钮栏**（底部）：
   - **应用**：将修改后的属性值写入实体。
   - **重置**：放弃未保存的修改，重新加载实体的当前属性。

### 9.5.4 属性编辑操作

1. **选中实体**：在 CAD 图纸中单击选中一个实体（或使用框选选中多个实体）。
2. **查看属性**：属性面板自动加载并显示选中实体的属性。
3. **修改属性**：单击属性值单元格，进入编辑状态。根据属性类型，编辑器可能是文本框、下拉框或数值输入框。
4. **应用修改**：点击底部的**应用**按钮，系统将修改写入 CAD 实体。如果修改涉及关联实体（如轴号标注），系统会同步更新。
5. **重置**：如果修改有误，点击**重置**按钮可恢复到修改前的状态。

### 9.5.5 多选批量编辑

选中多个实体时，属性面板的行为如下：

- 如果选中的是**同类型实体**（如多块板材），面板显示所有实体的公共属性。修改公共属性后点击"应用"，所有选中实体将同步更新。
- 如果选中的是**不同类型实体**，面板通过实体类型选择器下拉框让您切换查看不同类型的属性。
- 对于节点线的多选场景，面板还提供"批量编辑节点线"按钮，可一次性打开多条节点线的编辑界面。

### 9.5.6 节点线专属功能

当选中节点线实体时，属性面板除了显示基本属性外，还会展示**收边信息区域**：

- 列出与该节点线关联的所有收边（含收边名称和编号）。
- 点击某个收边后，下方显示该收边的详细属性，支持编辑。

## 9.7 快捷键管理

### 9.7.1 功能概述

LightningCAD 提供完善的快捷键管理系统，支持为所有命令设置键盘快捷键和简化命令（别名）。快捷键系统采用全局键盘钩子技术，在 CAD 应用程序处于前台时实时监听键盘输入，实现快速命令触发。

### 9.7.2 打开快捷键设置

在操作向导中找到"快捷键设置"命令并点击，系统将弹出"快捷键设置"对话框（尺寸 900×600）。

### 9.7.3 界面布局

快捷键设置对话框分为四个区域：

#### 顶部工具栏

- **搜索框**：输入命令名称、别名或快捷键进行搜索过滤。
- **分组下拉框**：按命令分组（如"柱梁"、"板材"等）过滤显示。默认为"全部"。

#### 命令列表

以表格形式展示所有可用命令：

| 列名 | 说明 |
|------|------|
| **分组** | 命令所属的功能分组 |
| **命令名称** | 命令的内部全局名称（如 `FsLtShengChengZhouWang`） |
| **显示名称** | 命令的中文名称（如"生成轴网"） |
| **简化命令** | 命令的简化别名（如 `SCZW`），可在 CAD 命令行直接输入触发。双击单元格可直接编辑 |
| **快捷键** | 命令的键盘快捷键（如 `Ctrl+Shift+A`），以彩色标签形式展示 |

#### 快捷键操作区

| 按钮/控件 | 功能 |
|-----------|------|
| **设置快捷键** | 选中命令后点击此按钮，进入录制模式。按下期望的组合键即可完成设置 |
| **清除快捷键** | 清除选中命令的快捷键 |
| **启用快捷键** | 全局开关，启用或禁用所有快捷键功能 |
| **导出** | 将快捷键配置导出为 JSON 文件 |
| **导入** | 从 JSON 文件导入快捷键配置 |
| **清除全部** | 清除所有命令的简化命令和快捷键 |

#### 底部操作区

- **保存**：保存所有修改并关闭对话框。
- **取消**：放弃修改并关闭对话框。

### 9.7.4 自定义快捷键

#### 设置快捷键

1. 在命令列表中选中目标命令。
2. 点击"设置快捷键"按钮，界面进入录制模式，显示"请按下快捷键..."提示。
3. 按下期望的组合键（如 `Ctrl+Shift+G`）。系统自动识别修饰键（Ctrl / Alt / Shift）和主键。
4. 如果快捷键未被占用，设置立即生效。
5. 如果快捷键已被其他命令占用，系统弹出冲突提示，询问是否覆盖。确认后，原命令的快捷键将被清除。
6. 按"取消"按钮可退出录制模式。

#### 设置简化命令

简化命令（别名）是可以在 CAD 命令行直接输入的短字符串。例如，将"生成轴网"的简化命令设为 `SCZW`，之后在命令行输入 `SCZW` 即可执行该命令。

设置方法：双击命令列表中"简化命令"列的单元格，直接输入别名文本。

### 9.7.5 快捷键冲突检测

系统在以下环节自动检测冲突：

- **设置快捷键时**：如果新设置的快捷键与其他命令重复，弹出确认对话框。
- **保存时**：检查所有简化命令是否存在重复。如果存在重复，保存将被阻止，并显示详细的冲突信息。

### 9.7.6 导入/导出快捷键配置

#### 导出

1. 点击"导出"按钮。
2. 在弹出的保存对话框中选择保存位置和文件名（默认 `LtShortcuts.json`）。
3. 系统将当前所有已设置的快捷键和简化命令导出为 JSON 文件。

导出的 JSON 格式示例：
```json
{
  "FsLtShengChengZhouWang": {
    "alias": "SCZW",
    "shortcut": "Ctrl+Shift+G"
  },
  "FsLtHuiZhiZhouXian": {
    "shortcut": "Ctrl+Alt+A"
  }
}
```

#### 导入

1. 点击"导入"按钮。
2. 选择之前导出的 JSON 配置文件。
3. 系统解析文件内容，将匹配的快捷键和简化命令应用到当前命令列表中。
4. 导入完成后显示成功导入的配置数量。

> **提示**：导入操作采用合并策略——仅更新 JSON 文件中存在的配置项，未在文件中出现的命令配置保持不变。

### 9.7.7 快捷键工作原理

LightningCAD 的快捷键系统具有以下技术特性：

- **全局键盘钩子**：通过 Windows 低级键盘钩子（WH_KEYBOARD_LL）监听键盘事件，确保快捷键在 CAD 的各种操作状态下均可响应。
- **前台窗口检测**：仅当 CAD 应用程序为前台活动窗口时才触发快捷键，避免干扰其他应用程序的操作。
- **防重复触发**：按键按住时不会重复触发命令，防止误操作。
- **命令发送**：快捷键触发时，系统通过 `SendStringToExecute` 向 CAD 发送命令字符串，确保命令在 CAD 的命令执行环境中正确运行。

## 9.8 备份管理

### 9.8.1 功能概述

备份管理工具为 DWG 文件提供自动备份保护机制。在意外崩溃、误操作或文件损坏时，您可以从备份文件中恢复图纸数据，最大限度减少工作损失。

### 9.8.2 打开备份设置

通过以下方式打开备份设置对话框：

- 在操作向导的顶部工具栏中点击 ☁ **备份设置**按钮。
- 或通过命令启动备份设置。

### 9.8.3 自动备份机制

LightningCAD 的自动备份在以下两个时机触发：

| 触发时机 | 说明 |
|----------|------|
| **手动保存前（BeginSave）** | 在您按 Ctrl+S 或点击保存时，系统先将磁盘上的当前文件（保存前的版本）备份一份，然后再执行实际保存 |
| **自动保存后（SaveComplete）** | CAD 的自动保存（.sv$ 临时文件）完成后，系统将临时文件复制为 .dwg 格式的备份文件 |

> **注意**：自动备份功能需要启用后才会生效。默认情况下备份功能处于关闭状态，建议开启。

### 9.8.4 备份策略设置

打开备份设置对话框后，可配置以下参数：

#### 基本设置

| 参数 | 说明 | 范围 | 默认值 |
|------|------|------|--------|
| **启用自动备份** | 总开关，控制是否启用自动备份功能 | 开/关 | 关闭 |
| **备份间隔** | 两次备份之间的最小时间间隔 | 1-60 分钟 | 15 分钟 |
| **保留数量** | 最多保留的备份文件个数。超出后自动删除最旧的备份 | 1-10 个 | 5 个 |

#### 备份路径

| 选项 | 说明 |
|------|------|
| **在当前文件目录下创建文件同名的 _Backup 文件夹**（默认） | 备份文件保存在 DWG 文件所在目录下，以 `文件名.dwg_Backup` 命名的子文件夹中 |
| **使用自定义文件夹** | 选择任意目录作为备份存储位置。点击"..."按钮浏览选择文件夹 |

### 9.8.5 备份文件命名规则

备份文件按照以下格式命名：

```
原文件名 yyyy-MM-dd HH_mm_ss.dwg
```

例如，原文件 `厂房墙面.dwg` 在 2026年6月4日 14:30:15 生成的备份文件名为：

```
厂房墙面 2026-06-04 14_30_15.dwg
```

### 9.8.6 备份文件管理

#### 查看备份文件

备份文件存储在 `_Backup` 文件夹中（或您指定的自定义路径）。您可以直接在 Windows 资源管理器中打开该文件夹查看备份文件。

备份目录路径示例（使用默认路径模式）：
```
D:\Projects\厂房A\厂房墙面.dwg_Backup\
├── 厂房墙面 2026-06-04 14_30_15.dwg
├── 厂房墙面 2026-06-04 14_15_08.dwg
├── 厂房墙面 2026-06-04 14_00_02.dwg
├── 厂房墙面 2026-06-04 13_45_00.dwg
└── 厂房墙面 2026-06-04 13_30_00.dwg
```

#### 恢复备份

1. 在资源管理器中找到目标备份文件。
2. 将备份文件复制到工作目录，并重命名为所需的文件名。
3. 在 CAD 中打开恢复的文件。

> **提示**：恢复前建议先比对备份文件与当前文件的大小和修改时间，确认选择的是正确的版本。

#### 清理备份

- **自动清理**：系统会在每次备份后自动检查备份数量，超出"保留数量"设置的旧备份将被自动删除。
- **手动清理**：您可以在资源管理器中手动删除不再需要的备份文件。

### 9.8.7 设置生效说明

备份设置的修改在保存后**需要重启 CAD 才能生效**。保存时系统会提示"备份设置已保存，重启CAD后生效"。

## 9.10 常见问题与技巧

### 9.10.1 轴网生成与实际尺寸不匹配

**问题**：生成的轴网尺寸与预期的实际建筑尺寸不一致。

**原因与解决**：

1. **间距单位错误**：轴网间距使用的单位与图纸单位一致（通常为毫米）。请确认输入的间距值是正确的毫米数值，而非米值。例如，6 米开间应输入 `6000` 而非 `6`。
2. **基点位置不当**：轴网从指定的基点开始向右上方展开。如果基点选择不当，轴网可能偏离预期位置。可使用 CAD 的移动命令将轴网整体移动到正确位置。
3. **不等间距输入错误**：使用不等间距时，确保逗号分隔的数值正确。例如 `6000,3600,6000` 表示三段间距，总长度为 15600。

### 9.10.2 图层管理误操作恢复

**问题**：在图层管理中误操作导致图层配置被覆盖或修改。

**解决方案**：

1. **恢复默认**：在图层管理界面中点击"恢复默认"按钮，可将配置恢复为 LightningCAD 的出厂默认值。
2. **重新加载配置**：如果之前保存过自定义配置，可以重新编辑并"保存配置"。
3. **CAD 原生图层管理器**：对于已创建在图纸中的图层属性变更，需要使用 CAD 原生的 LAYER 命令或图层管理器来修改。图纸管理中的修改仅影响配置定义，不会自动更新已有图层。

> **建议**：在进行大批量图层配置修改前，先点击"保存配置"保存当前状态作为备份。

### 9.10.3 备份文件占用空间清理

**问题**：长期使用后，备份文件占用了大量磁盘空间。

**解决方案**：

1. **调整保留数量**：在备份设置中减小"保留数量"参数（如从 5 改为 3），系统将自动清理多余的旧备份。
2. **手动清理**：打开备份文件夹（`_Backup` 目录），手动删除不再需要的旧备份文件。
3. **调整备份间隔**：增大"备份间隔"时间（如从 15 分钟改为 30 分钟），减少备份频率。
4. **使用自定义路径**：将备份路径指向空间充裕的磁盘分区。

> **提示**：备份文件与原始 DWG 文件大小相同。如果磁盘空间紧张，建议定期清理旧备份。

### 9.10.4 快捷键冲突解决

**问题**：设置的快捷键无法触发命令，或触发了错误的命令。

**排查步骤**：

1. **检查快捷键启用状态**：确认快捷键设置界面中的"启用快捷键"复选框已勾选。
2. **检查冲突**：在快捷键设置界面中，搜索该快捷键，查看是否有多个命令绑定了相同的快捷键。如有冲突，保留一个并清除其他。
3. **检查 CAD 原生快捷键**：某些组合键可能被 CAD 自身或其他插件占用。尝试使用不同的组合键。
4. **检查简化命令冲突**：如果简化命令与 CAD 内置命令重名（如 `L` 对应 LINE 命令），CAD 内置命令优先。建议使用至少 2-3 个字符的别名。
5. **重启 CAD**：快捷键设置的变更可能需要重启 CAD 才能完全生效。

### 9.10.5 属性面板不显示属性

**问题**：选中实体后，属性面板为空白或不显示预期的属性。

**排查步骤**：

1. **确认面板已加载**：检查面板顶部是否显示加载进度条。如果正在加载，请等待完成。
2. **检查实体类型**：属性面板仅对 LightningCAD 识别的实体类型显示业务属性。普通 CAD 线段、圆弧等基础实体可能不在支持范围内。
3. **重新选中实体**：取消选择后重新选中实体，触发面板刷新。
4. **检查错误信息**：面板顶部的消息栏可能显示加载错误信息，根据提示排查。

### 9.10.6 操作向导命令列表为空

**问题**：操作向导面板中不显示任何命令。

**排查步骤**：

1. **检查配置文件**：操作向导的命令列表从 CSV 配置文件（`CmdsMenu.csv`）中读取。确认该文件存在于安装目录的 Config 子目录中。
2. **检查分类选择**：确认顶部的分类下拉框已选择有效的分类。
3. **清除搜索**：如果搜索框中有文本，点击清除按钮 ✕ 恢复全部命令显示。
4. **重启插件**：关闭并重新加载 LightningCAD 插件。

### 9.10.7 视口导航"查看图框"无反应

**问题**：点击"查看图框"按钮后提示"当前图纸中没有大样或整理图框"。

**原因**：当前 DWG 图纸中没有 LightningCAD 识别的图框实体（大样图框或整理图框）。

**解决方案**：

1. 确认图纸中已使用 LightningCAD 创建了图框。
2. 如果图框是由其他工具创建的，可能不在 LightningCAD 的识别范围内。此时可使用手动书签功能手动保存和恢复视口位置。

### 9.10.8 实用技巧汇总

| 技巧 | 说明 |
|------|------|
| **轴网参数复用** | 生成轴网对话框的参数会自动保存。如果多个项目使用相同的轴网参数，无需每次重新输入 |
| **视口书签命名规范** | 为手动书签使用有意义的名称（如"南立面大样"、"A区屋面详图"），方便快速识别 |
| **属性面板保持打开** | 将属性面板常驻在 CAD 界面侧边，选中实体即可自动显示属性，无需反复开关 |
| **快捷键导出备份** | 定期将快捷键配置导出为 JSON 文件备份。重装系统或更换电脑后可快速恢复 |
| **图层配置共享** | 团队中一人配置好图层后，可通过"保存配置"导出配置文件，其他成员导入即可获得统一的图层标准 |
| **操作向导搜索** | 搜索支持模糊匹配命令名称、别名和提示信息。不确定命令名称时，输入功能关键词即可（如"轴网"、"板材"） |
| **主题切换** | 长时间工作时切换到深色主题可减轻眼睛疲劳。主题偏好会自动保存 |
