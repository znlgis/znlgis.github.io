## 6.1 收边概述

### 6.1.1 什么是收边

在围护结构工程中，**收边**（ShouBian）是指围护板材边缘的收口处理构件。收边是围护系统不可或缺的组成部分，它安装于板材的边缘、转角、洞口等位置，起到封闭板材断面、引导排水、美化外观的作用。

在 LightningCAD 中，收边以**图块（Block）**的形式定义在图纸中，每个收边图块包含完整的属性信息（如编号、名称、分类、截面参数等），并与**节点线**（JieDianLine）建立关联关系，从而实现从设计到出图、从算量到加工的全流程数字化管理。

### 6.1.2 收边的作用

收边在围护系统中承担着多重功能：

| 功能 | 说明 |
|------|------|
| **防水密封** | 封闭板材边缘，防止雨水渗入围护结构内部 |
| **结构收口** | 对板材切割边缘进行包封，保证结构完整性 |
| **美观装饰** | 提供整洁、统一的外观效果，隐藏板材断面 |
| **导向排水** | 通过特定的截面形状引导雨水沿指定方向排出 |
| **保护板材** | 防止板材边缘受到外力损伤或腐蚀 |

### 6.1.3 收边的类型

LightningCAD 支持多种收边类型，通过**收边分类**（ShouBianCategory）字段进行区分。常见的收边类型包括：

| 分类 | 说明 | 典型应用场景 |
|------|------|-------------|
| **檐口收边** | 屋面檐口处的收边构件 | 屋面板下端边缘 |
| **山墙收边** | 山墙面与屋面交接处的收边 | 山墙顶部和侧面 |
| **墙角收边** | 墙面转角位置的收边 | 墙面阴阳角 |
| **洞口收边** | 门窗等洞口周围的收边 | 门窗框四周 |
| **屋脊收边** | 屋脊位置的收边构件 | 双坡屋面脊线处 |
| **泛水收边** | 防水泛水处理处的收边 | 屋面与墙面交接处 |
| **包角收边** | 包角位置的收边构件 | 板材转角包角 |

### 6.1.4 收边的数据结构

在 LightningCAD 中，每个收边包含以下核心数据：

- **基本信息**：收边编号（ShouBianNumber）、收边名称（ShouBianName）、产品系统（ProductSystem）、收边分类（ShouBianCategory）、厚度（ShouBianThickness）、材质（Material）、颜色（Color）
- **横截面信息**：展宽（ZhanKuan）、边长数组（Lengths）、角度数组（Angles）、折弯道数（ZheWan）、抿边形式（MinBian：无/单抿/双抿）
- **分割规则**：布置模式（长度模式/点状模式）、分段参数、搭接参数等

## 6.2 收边创建

LightningCAD 提供了多种创建收边的方式，您可以根据实际工程需要选择最合适的方法。

### 6.2.1 从收边库插入收边

这是最常用的收边创建方式，通过收边库浏览器选择预定义的收边模板并插入到当前图纸中。

**操作流程：**

1. 在功能区或命令行中执行**收边库**命令（`FsShouBianKuWeiHu`）
2. 系统打开**收边库浏览器**窗口
3. 在浏览器中选择需要的收边模板（详见 6.4 收边库浏览器）
4. 单击**插入到图纸**按钮
5. 如果是首次插入，系统提示您选择插入点；如果图纸中已有收边，系统将自动检测下一个可用插入点，避免重叠
6. 收边图块将按设定的比例插入到图纸中，并自动执行整理排列

> **提示**：您也可以勾选多个收边后执行**批量插入**，系统将一次性插入所有勾选的收边，并自动按行排列。

### 6.2.2 基于节点线关联收边

收边通常与节点线配合使用。当您在节点线上定义收边编号后，系统会自动建立关联关系。

**操作流程：**

1. 在图纸中绘制或选择已有的节点线
2. 选中节点线，打开**属性面板**
3. 在属性面板的收边信息区域中，设置关联的收边编号
4. 系统将根据收边编号从图纸中已加载的收边图块中匹配数据
5. 收边信息将自动填充到节点线的收边数据中

> **注意**：节点线上记录的收边编号列表是从节点图框上读取的。确保对应的收边图框已加载到图纸中，否则系统可能无法获取完整的收边信息。

### 6.2.3 插入收边定义模板

如果您需要创建一个全新的自定义收边，可以先插入收边定义模板，然后手动编辑属性。

**操作流程：**

1. 执行**插入收边定义模板**命令（`FsChaRuShouBianTiQuKuang`）
2. 系统提示"选择收边定义模板插入点"，在图纸中点击指定位置
3. 系统插入一个空的收边定义模板图块
4. 双击图块，打开属性编辑对话框
5. 填写收边编号、名称、分类、截面参数等属性
6. 确认保存

> **提示**：模板文件名为 `ShouBian_DingYi_Template.dwg`，位于安装目录的 Template 文件夹中。

### 6.2.4 收边的缩放比例

从收边库插入收边时，系统会根据模板中的定义框自动计算缩放比例。您可以在收边库浏览器中设置：

- **使用自定义长度**：勾选此选项后，可指定目标框架长度（默认 2000mm），系统将据此计算缩放比例
- **使用原始尺寸**：取消勾选后，收边将按原始尺寸插入

## 6.3 收边编辑

### 6.3.1 收边属性面板

选中图纸中的节点线后，LightningCAD 的**属性面板**（Property Palette）将显示该节点线关联的所有收边信息。属性面板是编辑收边属性的主要入口。

属性面板中的收边信息按以下三个分组展示：

#### 基本信息（只读）

基本信息从收边图框中同步获取，在属性面板中为只读状态：

| 属性 | 说明 |
|------|------|
| 收边编号 | 收边的唯一标识编号 |
| 收边名称 | 收边的名称描述 |
| 产品系统 | 所属产品系统名称 |
| 分类 | 收边分类（如檐口、山墙等） |
| 厚度 | 收边板材厚度 |
| 材质 | 收边材质 |
| 颜色 | 收边颜色 |

#### 横截面信息（只读）

横截面信息描述收边的截面几何特征：

| 属性 | 说明 |
|------|------|
| 展宽 | 收边展开后的总宽度（mm） |
| 折弯道数 | 截面的折弯次数 |
| 抿边形式 | 无 / 单抿 / 双抿 |

#### 分割规则（可编辑）

分割规则用于控制收边的分段方式，是属性面板中**可编辑**的部分：

| 属性 | 说明 | 适用模式 |
|------|------|---------|
| 布置模式 | 长度模式 / 点状模式 | 通用 |
| 首尾延伸长度 | 收边首尾两端的延伸距离（mm） | 通用 |
| 分割算法 | 均分 / 定尺 | 长度模式 |
| 最大分段长度 | 每段收边的最大允许长度（mm） | 长度模式 |
| 搭接长度 | 相邻两段收边的搭接长度（mm） | 长度模式 |
| 单件长度 | 点状布置时每件的长度（mm） | 点状模式 |
| 单件间隔 | 点状布置时相邻件的中心距（mm） | 点状模式 |

> **提示**：切换布置模式后，属性面板会自动刷新，显示对应模式下的可编辑字段。

### 6.3.2 编辑收边图块属性

如果需要修改收边的基本信息（如编号、名称、分类等），可以直接编辑收边图块：

1. 在图纸中双击收边图块
2. 系统打开**增强属性编辑器**
3. 修改需要的属性值
4. 单击"确定"保存

> **注意**：修改收边图块属性后，需要重新同步节点线数据，确保节点线上的收边信息与图框保持一致。系统在执行收边分段等操作时会自动执行属性同步。

### 6.3.3 批量编辑

当多条节点线关联了相同属性的收边时，LightningCAD 支持批量编辑：

1. 在属性面板中选择一条节点线
2. 修改收边的分割规则参数
3. 使用"应用到其他"功能，将修改同步到其他具有相同属性的收边

## 6.4 收边库浏览器

收边库浏览器是 LightningCAD 中管理收边模板的核心工具，提供浏览、搜索、插入、删除等完整的收边库管理功能。

### 6.4.1 打开收边库浏览器

执行**收边库**命令（`FsShouBianKuWeiHu`），系统将打开收边库浏览器窗口。

### 6.4.2 界面布局

收边库浏览器界面包含以下区域：

- **系统名称筛选区**：按产品系统名称过滤收边列表，支持搜索
- **分类搜索区**：按收边分类进行过滤
- **名称/编号搜索区**：按收边名称或编号进行模糊搜索
- **收边列表区**：以分组视图展示所有收边，按收边分类进行分组
- **预览区**：显示当前选中收边的 DWG 预览图
- **操作按钮区**：插入到图纸、打开文件夹、删除等

### 6.4.3 浏览与搜索

收边库浏览器提供多维度的搜索与过滤功能：

**按产品系统筛选：**
1. 在"系统名称"下拉列表中选择一个产品系统
2. 列表将仅显示属于该系统的收边
3. 选择"全部"可显示所有收边

**按分类搜索：**
1. 在"分类搜索"输入框中输入关键字
2. 列表将实时过滤，仅显示分类名称包含关键字的收边

**按名称/编号搜索：**
1. 在"名称搜索"输入框中输入关键字
2. 列表将实时过滤，匹配收边名称或编号中包含关键字的项

> **提示**：三种搜索条件可以组合使用，实现精确筛选。例如，先选择产品系统，再输入分类关键字，可以快速定位目标收边。

### 6.4.4 收边分类

收边库中的收边按**收边分类**字段自动分组显示。常见的分组包括：

- 檐口收边
- 山墙收边
- 墙角收边
- 洞口收边
- 屋脊收边
- 泛水收边
- 未分类（未设置分类的收边）

### 6.4.5 插入收边到图纸

**单个插入：**
1. 在列表中选中一个收边
2. 单击**插入到图纸**按钮
3. 根据提示选择插入点（首次插入）或系统自动检测插入点（后续插入）
4. 收边图块将插入到当前图纸中

**批量插入：**
1. 在列表中勾选多个收边的复选框
2. 单击**插入到图纸**按钮
3. 系统将一次性插入所有勾选的收边，按行自动排列
4. 插入完成后自动取消勾选

### 6.4.6 管理收边库

**删除单个收边：**
1. 选中要删除的收边
2. 单击**删除**按钮
3. 确认删除操作
4. 系统将同时删除 DWG 文件和 Excel 中的记录

**批量删除：**
1. 勾选要删除的多个收边
2. 单击**批量删除**按钮
3. 确认删除操作

**打开文件位置：**
1. 选中一个收边
2. 单击**打开文件夹**按钮
3. 系统将在 Windows 资源管理器中打开收边 DWG 文件所在的文件夹，并选中该文件

### 6.4.7 收边库数据源

收边库的数据来源于两部分：

- **Excel 文件**：存储收边的属性数据（编号、名称、分类、截面参数等），路径由公共库配置决定
- **DWG 文件**：存储收边的图形定义（截面形状、尺寸标注等），存放在收边库文件夹中，文件名与收边编号一致

> **注意**：如果收边的 DWG 文件不存在，该收边将不会在列表中显示。系统会在日志中记录跳过的收边信息。

## 6.5 收边分段

### 6.5.1 为什么需要分段

在实际工程中，收边构件需要进行分段处理，主要原因包括：

| 原因 | 说明 |
|------|------|
| **运输限制** | 超长收边不便于运输，需要分段后到现场组装 |
| **加工限制** | 工厂设备的加工长度有限，超长收边需要分段加工 |
| **安装便利** | 分段后的收边更便于现场安装和搬运 |
| **材料优化** | 合理的分段可以减少材料浪费 |
| **板缝对齐** | 收边分段位置与板材拼缝对齐，保证防水效果 |

### 6.5.2 布置模式

LightningCAD 支持两种收边布置模式：

#### 长度模式（Length）

适用于沿节点线全长连续布置的收边。在长度模式下，收边将覆盖整条节点线，并根据设定的参数进行分段。

**长度模式参数：**

| 参数 | 说明 |
|------|------|
| 分割算法 | **均分**（Average）：根据最大分段长度自动计算等分方案，每段长度相等；**定尺**（Fixed）：按固定长度逐段布置，最后一段为余长 |
| 最大分段长度 | 每段收边允许的最大长度（mm） |
| 搭接长度 | 相邻两段收边之间的搭接长度（mm） |
| 首尾延伸长度 | 收边在节点线首尾两端的延伸距离（mm） |
| 是否断于板缝 | 勾选后，分段位置将优先对齐板材拼缝位置 |

#### 点状模式（Dot）

适用于沿节点线间隔布置的收边件，如固定件、连接件等。

**点状模式参数：**

| 参数 | 说明 |
|------|------|
| 单件长度 | 每个收边件的长度（mm） |
| 单件间隔 | 相邻收边件的中心距（mm） |
| 智能加一 | 勾选后，当末端剩余长度超过 3 倍单件长度时，自动在末端增加一段 |

### 6.5.3 分段操作流程

**步骤 1：选择节点线**

1. 执行**收边分段**命令（`FsShouBianFenDuan`）
2. 系统提示"请选择需要进行收边分段的节点线"
3. 在图纸中选择一条或多条节点线
4. 按回车确认选择

> **注意**：系统会自动检查所选节点线关联的节点图框和收边图框是否已加载到图纸中。如果有缺失，系统将列出缺失的图框编号，请先加载后再执行分段操作。

**步骤 2：设置分段参数**

系统弹出**收边分段**窗口，显示所选节点线关联的所有收边。收边按布置模式分为两个标签页：

- **长度模式标签页**：显示布置模式为"长度"的收边
- **点状模式标签页**：显示布置模式为"点状"的收边

对于**长度模式**的收边，可设置：

| 参数 | 说明 |
|------|------|
| 颜色 | 标注颜色 |
| 目标长度 | 最大分段长度（mm） |
| 搭接长度 | 相邻段搭接长度（mm） |
| 外延长度 | 首尾延伸长度（mm） |
| 均分/定尺 | 选择分割算法 |
| 断于板缝 | 是否对齐板缝 |

对于**点状模式**的收边，可设置：

| 参数 | 说明 |
|------|------|
| 颜色 | 标注颜色 |
| 单件长度 | 每件收边的长度（mm） |
| 中心距 | 相邻件的中心间距（mm） |
| 智能加一 | 是否启用末端自动加段 |

**步骤 3：选择要分段的收边**

- 勾选需要执行分段的收边项
- 使用**全选** / **全不选**按钮快速操作
- 同一属性组合的收边会被自动合并为一组，修改参数将同时应用于组内所有收边

**步骤 4：同改功能（批量同步参数）**

当选中多个收边项时，修改其中一项的参数，可以同步到所有选中的项：
- 修改任意参数（如目标长度、搭接长度、颜色等）
- 系统将自动把修改值同步到其他选中的收边项

**步骤 5：执行分段**

1. 参数设置完成后，单击**确定**按钮
2. 系统根据设置的参数对每条节点线上的收边执行分段计算
3. 分段结果将保存到节点线的收边数据中
4. 命令行将显示每条收边的分段结果，例如：`收边 SB-001 (节点线 xxx, 长度 6000.0) 分段完成，共 3 段`

### 6.5.4 分段算法详解

#### 均分模式

均分模式会根据最大分段长度自动计算最优的等分方案：

1. 计算实际总长度 = 节点线长度 + 首尾延伸长度 × 2
2. 估算需要的段数 = ⌈实际总长度 / 最大分段长度⌉
3. 计算每段长度 = (实际总长度 + (段数 - 1) × 搭接长度) / 段数
4. 如果计算出的段长超过最大分段长度，增加段数重新计算
5. 按计算结果布置各段，相邻段之间减去搭接长度

**示例**：节点线长度 6000mm，最大分段长度 3000mm，搭接长度 100mm，无延伸
- 实际总长度 = 6000mm
- 估算段数 = ⌈6000 / 3000⌉ = 2
- 每段长度 = (6000 + 1 × 100) / 2 = 3050mm
- 3050 > 3000，增加段数到 3
- 每段长度 = (6000 + 2 × 100) / 3 = 2066.7mm ✓

#### 定尺模式

定尺模式按固定长度逐段布置：

1. 从起始位置开始，按目标长度逐段布置
2. 每段之间减去搭接长度
3. 最后一段为剩余长度（可能短于目标长度）

#### 断于板缝

勾选"断于板缝"后，分段位置将优先对齐板材拼缝：

1. 系统自动检测节点线附近的板材边缘位置
2. 将板缝位置作为优先的分段断点
3. 在板缝间距超过最大分段长度时，在区间内插入额外的分段点
4. 自动过滤首尾段中长度小于板宽的板缝位置，避免产生过短的分段

> **提示**：断于板缝功能需要图纸中已布置板材实体（AecPanelMgd），系统通过检测板材边缘与节点线的距离来确定板缝位置。板材内缩值从节点线数据中获取。

### 6.5.5 分段结果

分段完成后，每条收边的分段信息将保存为 `SegmentInfo` 列表，每个分段包含：

| 字段 | 说明 |
|------|------|
| 起始位置 | 该段在节点线上的起始距离（mm） |
| 结束位置 | 该段在节点线上的结束距离（mm） |
| 长度 | 该段的实际长度 = 结束位置 - 起始位置 |
| 颜色 | 该段的标注颜色 |

## 6.6 批量标注

### 6.6.1 功能说明

**批量标注收边线**功能用于从节点线上提取收边分段信息，并在图纸中自动创建文字标注。标注内容包括收边编号、分段长度、颜色等信息，方便施工人员读图。

### 6.6.2 操作流程

**步骤 1：执行命令**

在功能区或向导面板中点击**批量标注收边线**命令（`FsPiLiangBiaoZhuShouBianXian`）。

**步骤 2：设置标注参数**

系统弹出**标注设置**窗口，可配置以下参数：

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 分段标记 | 勾选后按分段逐段标注；取消后集中标注 | 勾选（分段标记） |
| 展示颜色 | 是否在标注中显示颜色信息 | 不勾选 |
| 文字样式 | 选择标注使用的 CAD 文字样式 | _Standard |
| 字高 | 标注文字的高度 | 100 |
| 宽度因子 | 文字的宽度比例因子 | 0.7 |
| 文字距收边线 | 标注文字与收边线的距离倍数 | 0.4 |
| 行间距 | 多行标注文字的行间距倍数 | 0.25 |

> **提示**：标注设置会自动保存，下次使用时将自动加载上次的配置。

**步骤 3：选择节点线**

1. 设置完成后单击"确定"
2. 系统提示"请框选需要批量标注的节点线"
3. 在图纸中框选需要标注的节点线
4. 按回车确认选择

**步骤 4：自动标注**

系统将自动完成以下操作：
1. 读取每条节点线上的收边分段数据
2. 根据设置的标注参数计算标注位置
3. 在收边线图层上创建文字标注
4. 标注文字放置在专用的收边文字图层上

### 6.6.3 标注图层

批量标注涉及以下图层：

| 图层 | 说明 |
|------|------|
| 收边文字图层 | 存放标注文字，默认名称为"收边文字" |
| 收边线图层 | 存放收边线段，默认名称为"收边线" |

图层的名称和颜色可在结构线图层配置中自定义。

## 6.7 BOM 导出

### 6.7.1 什么是 BOM

**BOM**（Bill of Materials，材料清单）是围护工程中用于统计材料用量的重要文档。LightningCAD 支持将收边数据导出为 BOM 表格，便于材料采购、加工下单和工程预算。

### 6.7.2 收边明细表

**收边明细表**是 LightningCAD 提供的收边统计功能，可以汇总当前图纸中所有收边的信息。

**操作流程：**

1. 执行**收边明细表**命令（`FsShouBianMingXiBiao`）
2. 系统提示选择节点线，框选需要统计的节点线
3. 系统弹出**收边明细表**窗口，显示统计数据

**明细表包含以下字段：**

| 字段 | 说明 |
|------|------|
| 序号 | 自动编号 |
| 收边编号 | 收边的唯一标识 |
| 收边名称 | 收边名称描述 |
| 厚度 | 收边板材厚度（mm） |
| 颜色 | 收边颜色 |
| 展宽 | 收边展开宽度（mm） |
| 产地 | 可编辑的产地信息 |
| 单长 | 单段长度（m，保留 3 位小数） |
| 数量 | 该规格收边的数量 |
| 备注 | 备注信息 |

窗口底部显示**合计数量**，即所有收边的总数量。

### 6.7.3 导出到 DWG

将收边明细表导出为 DWG 表格，直接插入到图纸中：

1. 在收边明细表窗口中单击**导出到 DWG** 按钮
2. 系统关闭窗口并提示"请选择收边 BOM 表格插入点"
3. 在图纸中点击指定表格插入位置
4. 系统自动创建 BOM 表格图块

**导出规则：**

- 数据按**收边编号**分组，同一编号的数据共用一个小表格
- 每个小表格最多显示 9 行长度/数量数据
- 小表格按每行 2 个并排排列
- 表格使用预定义的模板文件（`ShouBian_BOM_Definition_Lt.dwg` 和 `ShouBian_BOM_Frame_Lt.dwg`）
- BOM 锚点放置在专用隐藏图层（`ZZZ_FsHidden_ShouBianBOM`）上，不参与打印

### 6.7.4 导出到 Excel

将已生成的 DWG BOM 表格导出为 Excel 文件：

1. 执行**收边 BOM 导出 Excel** 命令（`FsShouBianBomDaoExcel`）
2. 系统提示框选收边 BOM 表格
3. 选择已插入到图纸中的 BOM 表格图块
4. 系统读取表格数据并导出为 Excel 文件

### 6.7.5 BOM 模板自定义

LightningCAD 的收边 BOM 表格使用 DWG 模板文件生成，您可以通过修改模板来自定义表格样式：

| 模板文件 | 说明 |
|---------|------|
| `ShouBian_BOM_Definition_Lt.dwg` | 小表格定义模板，包含单元格布局和锚点 |
| `ShouBian_BOM_Frame_Lt.dwg` | 外框模板，定义表格的整体边框样式 |

模板文件位于安装目录的 `Template` 文件夹中。修改模板时请注意：
- 不要修改锚点图层名称（`ZZZ_FsHidden_ShouBianBOM`）
- 不要修改图块名称
- 保持锚点标记的位置正确

## 6.9 常见问题与技巧

### 6.9.1 分段后收边编号规则

**问：收边分段后，每一段的编号如何确定？**

答：分段后的各段收边保持与原始收边相同的编号。分段信息以 `SegmentInfo` 列表的形式存储在节点线的收边数据中，每段通过起始位置和结束位置来区分，不会生成新的编号。在 BOM 统计中，同一编号的收边会汇总在一起。

### 6.9.2 收边与节点线的关联关系

**问：收边和节点线是如何关联的？**

答：收边与节点线的关联通过以下机制实现：

1. **节点线数据**：每条节点线的 `JieDianData` 中包含 `ShouBianInfos` 字段，记录了该节点线关联的收边编号列表（`ShouBianNumbers`）和收边详细信息列表（`Items`）
2. **图框同步**：系统在执行分段等操作时，会自动从图纸中已加载的节点图框和收边图框中同步属性数据到节点线
3. **双向关联**：修改节点线上的收边属性后，数据会回写到节点线的存储中；修改收边图框后，需要重新同步

> **注意**：如果节点线关联的收边图框未加载到图纸中，系统将无法获取完整的收边信息。请确保所有相关的收边图框已加载。

### 6.9.3 BOM 导出数据不完整

**问：为什么导出的 BOM 数据不完整？**

答：可能的原因和解决方法：

| 问题 | 原因 | 解决方法 |
|------|------|---------|
| 部分收边未统计 | 节点线未被选中 | 确保框选了所有需要统计的节点线 |
| 收边信息缺失 | 收边图框未加载 | 先加载收边图框再执行统计 |
| 分段数据为空 | 未执行分段操作 | 先执行收边分段再导出 BOM |
| 属性不同步 | 图框属性被修改但未同步 | 执行分段操作时系统会自动同步 |

### 6.9.4 批量标注性能优化

**问：大量节点线标注时性能较慢，如何优化？**

答：以下建议可以帮助提升批量标注的性能：

1. **分批标注**：将大量节点线分成几个批次进行标注，避免一次性处理过多数据
2. **关闭不必要的图层**：标注前关闭不需要显示的图层，减少图形刷新负担
3. **合理设置标注参数**：避免过小的字高和过密的行间距，减少文字重叠
4. **使用分段标记模式**：分段标记模式比集中标记模式计算量更小

### 6.9.5 收边图框与属性面板数据不一致

**问：属性面板显示的收边信息与图框中的不一致怎么办？**

答：这种情况通常发生在手动修改了图框属性但未同步到节点线时。解决方法：

1. 执行**收边分段**命令，系统会在分段前自动执行属性同步
2. 或重新从收边库插入正确的收边图框

### 6.9.6 断于板缝功能不生效

**问：勾选了"断于板缝"但分段结果没有对齐板缝？**

答：请检查以下条件：

1. 图纸中是否已布置板材实体（AecPanelMgd）
2. 板材是否与节点线相邻（距离不超过板材内缩值 + 1mm 容差）
3. 节点线数据中的板材内缩值是否正确设置
4. 板材边缘是否平行于节点线方向

> **提示**：系统通过检测板材顶点到节点线的距离来确定板缝位置。如果板材与节点线的距离过大，系统将无法识别板缝。

### 6.9.7 实用技巧

**技巧 1：利用"同改"功能快速设置参数**

在收边分段窗口中，勾选多个收边项后，修改其中一项的参数，其他选中项将自动同步。这在处理大量相同规格的收边时非常高效。

**技巧 2：善用收边库的批量插入**

当需要在图纸中布置多种收边时，可以在收边库浏览器中一次性勾选所有需要的收边，然后批量插入。系统会自动排列并整理，避免手动逐个插入的繁琐操作。

**技巧 3：合理选择均分与定尺**

- **均分模式**适合需要每段长度一致的场景，如外观要求较高的工程
- **定尺模式**适合按标准长度加工的场景，可以减少加工调整

**技巧 4：利用智能加一优化点状布置**

在点状模式下，勾选"智能加一"后，当末端剩余长度超过 3 倍单件长度时，系统会自动在末端增加一段，避免末端出现过长的无覆盖区域。

**技巧 5：标注设置自动记忆**

批量标注的参数设置会自动保存（通过 PersistenceManager），下次使用时将自动加载上次的配置，无需重复设置。
