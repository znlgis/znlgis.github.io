## 10.1 公共库策略

### 10.1.1 什么是公共库

**公共库**是 LightningCAD 中用于集中存储和管理围护结构共享数据的资源中心。它将板型定义、节点模板、收边模板等跨项目复用的数据统一存放在一个独立的目录中，供所有 DWG 工程文件共享引用。

公共库的核心价值在于**一次定义、多处复用**——您只需在公共库中维护一套标准化的板型、节点和收边数据，即可在所有项目中直接调用，避免重复定义和数据不一致的问题。

公共库包含以下三个核心子库：

| 子库名称 | 文件夹标识 | 存储内容 |
|----------|-----------|---------|
| **板材库** | `PanelLibrary` | 板材规格定义数据（板型名称、排板板宽、材料板宽、厚度等），存储在 Excel 文件中 |
| **节点库** | `JieDianLibrary` | 节点详图定义（节点 DWG 文件 + 属性索引 Excel 文件），每个节点对应一个独立的 DWG 文件 |
| **收边库** | `ShouBianLibrary` | 收边截面定义（收边 DWG 文件 + 属性索引 Excel 文件），每个收边对应一个独立的 DWG 文件 |

### 10.1.2 安装包自带标准公共库

LightningCAD 安装包中自带了一套**标准公共库**（位于安装目录的 `Resources/StandardLibraries/` 下），包含行业常用的板型、节点和收边数据。

安装时，标准公共库将随安装程序自动部署到安装目录中：

```
LightningCAD/
└── Resources/
    └── StandardLibraries/      # 标准公共库（安装时自动部署）
        ├── PanelLibrary/       # 标准板材库
        │   └── PanelLibrary.xlsx
        ├── JieDianLibrary/     # 标准节点库
        │   ├── JieDianLibrary.xlsx
        │   ├── JD-001.dwg
        │   ├── JD-002.dwg
        │   └── ...
        └── ShouBianLibrary/    # 标准收边库
            ├── ShouBianLibrary.xlsx
            ├── SB-001.dwg
            ├── SB-002.dwg
            └── ...
```

> **提示**：标准公共库提供的是基础数据集，旨在帮助您快速上手。在实际生产中，建议基于标准库创建自定义公共库，添加企业特有的板型、节点和收边数据。

### 10.1.3 自定义公共库路径

在实际使用中，您通常需要指定一个自定义的公共库路径，以便管理企业自有的标准化数据。

#### 设置步骤

1. **打开公共库设置窗口**
   - 在 CAD 中，通过 LightningCAD 功能区点击**公共库设置**按钮。
   - 或在命令行输入公共库设置命令。

2. **选择公共库根目录**
   - 在公共库设置窗口中，点击**浏览**按钮。
   - 选择一个目录作为公共库的根目录。
   - 系统会实时检测所选目录的状态：
     - **首次设置**：目录为空或不含子库文件夹，系统将复制标准库文件到此目录。
     - **部分存在**：目录中已有部分子库文件夹，系统将补全缺失的子库。
     - **已构建**：目录中已包含所有子库文件夹，系统将直接使用该目录。

3. **应用设置**
   - 点击**应用设置**按钮。
   - 系统将根据目录状态执行相应操作（复制/补全/直接使用）。
   - 配置信息保存到 `CommonLibraryConfig.json` 文件中。

4. **打开文件夹验证**
   - 点击**打开文件夹**按钮，在资源管理器中查看公共库目录结构。

#### 启动时自动检测与补全

LightningCAD 在每次启动时会**自动检测**公共库配置状态：

- **情况 1：公共库未配置**——系统弹出提示"需要进行公共库路径设置才能使用插件"，引导您进入公共库设置窗口。
- **情况 2：公共库根目录存在但子库不完整**——系统自动从安装包的标准库中补全缺失的子库文件夹，无需手动操作。
- **情况 3：公共库配置完整**——系统正常加载，不弹出任何提示。

> **提示**：自动补全机制确保即使公共库目录被意外损坏或部分删除，系统也能在下次启动时自动修复，无需重新安装。

### 10.1.4 库的目录结构说明

一个完整的公共库目录结构如下：

```
<公共库根目录>/
├── PanelLibrary/                    # 板材库
│   └── PanelLibrary.xlsx            # 板材规格索引表（按安装位置分 Sheet）
│
├── JieDianLibrary/                  # 节点库
│   ├── JieDianLibrary.xlsx          # 节点属性索引表
│   ├── JieDian_DingYi_Template.dwg  # 节点定义模板
│   ├── JieDianFrameTemplate.dwg     # 节点框模板
│   ├── JD-001.dwg                   # 节点详图文件（编号即文件名）
│   ├── JD-002.dwg
│   └── ...
│
└── ShouBianLibrary/                 # 收边库
    ├── ShouBianLibrary.xlsx         # 收边属性索引表
    ├── ShouBian_DingYi_Template.dwg # 收边定义模板
    ├── SB-001.dwg                   # 收边截面文件（编号即文件名）
    ├── SB-002.dwg
    └── ...
```

**关键规则**：

- 节点和收边的 DWG 文件名必须与其编号一致（如编号 `JD-001` 对应文件 `JD-001.dwg`）。
- Excel 索引表中的每一行记录对应一个 DWG 文件，系统通过编号进行关联。
- 如果 Excel 中记录的某个编号对应的 DWG 文件不存在，该条目将在库浏览器中被跳过，系统会在日志中记录警告信息。

### 10.1.5 团队共享公共库（网络路径/云同步）

在团队协作场景中，多个设计师需要共享同一套公共库数据，以确保项目间的数据一致性。LightningCAD 支持以下共享方式：

#### 方式一：网络共享路径

将公共库目录放置在局域网共享路径上，所有团队成员指向同一个网络路径：

```
\\Server\SharedLib\LightningCAD_Library\
├── PanelLibrary/
├── JieDianLibrary/
└── ShouBianLibrary/
```

**配置方法**：在每位成员的公共库设置中，将根目录指向网络共享路径即可。

**注意事项**：
- 确保网络路径稳定可靠，网络中断将导致库功能不可用。
- 建议对共享目录设置适当的读写权限：普通用户只读，库管理员可写。
- 网络延迟可能影响库浏览器的加载速度，建议在网络条件较好的环境中使用。

#### 方式二：云同步工具

使用云同步工具（如坚果云、OneDrive、企业私有云盘等）将公共库目录同步到每位成员的本地计算机：

```
C:\Users\<用户名>\CloudSync\LightningCAD_Library\
├── PanelLibrary/
├── JieDianLibrary/
└── ShouBianLibrary/
```

**优势**：本地访问速度快，离线时仍可使用最近同步的版本。

**注意事项**：
- 确保同步工具不会在 DWG 文件上产生冲突副本。
- 建议由专人负责库的更新和同步，避免多人同时修改导致冲突。

### 10.1.6 库版本管理与更新

公共库中的数据会随着项目积累不断优化和扩充。建议采用以下策略管理库版本：

| 策略 | 说明 |
|------|------|
| **版本标记** | 在公共库根目录下维护一个 `CHANGELOG.md` 或 `版本说明.txt` 文件，记录每次更新的内容和时间 |
| **定期备份** | 每周或每月对公共库目录进行完整备份，保留历史版本 |
| **变更审批** | 对公共库的修改（新增/删除/修改板型、节点、收边）应经过技术负责人审批 |
| **增量更新** | 更新时仅替换变更的文件，避免全量覆盖导致自定义数据丢失 |
| **兼容性检查** | 更新前确认新增的数据格式与当前 LightningCAD 版本兼容 |

> **提示**：通过 LightningCAD 的节点库浏览器和收边库浏览器，您可以直接在界面中完成节点和收边的新增、编辑和删除操作，修改将自动同步到 Excel 索引表和 DWG 文件中。

## 10.2 自定义配置详解

### 10.2.1 用户配置文件说明

LightningCAD 使用 **JSON 文件**作为用户配置的持久化机制。所有用户偏好设置、默认参数和工作状态都保存在用户配置目录下的 JSON 文件中，实现了跨会话的配置保持。

**配置文件存储位置**：

```
%AppData%\FsLt\
├── UserProfiles\                          # 用户配置目录
│   ├── CommonLibraryConfig.json           # 公共库路径配置
│   ├── Scripts\                           # CAD 启动脚本
│   └── CUI\                               # 用户级 CUI 菜单文件
├── Logs\                                  # 运行日志
└── Cache\                                 # 临时缓存
```

此外，每个 DWG 工程文件还有一个关联的 `.cfg/` 配置目录（与 DWG 文件同级），存储该工程特有的排布配置方案：

```
<工程目录>/
├── MyProject.dwg
└── MyProject.cfg/
    └── Configs/
        ├── WallOutPanelLayout.configs.json    # 墙面外板排布配置
        ├── WallInnerPanelLayout.configs.json  # 墙面内板排布配置
        ├── RoofOutPanelLayout.configs.json    # 屋面外板排布配置
        ├── RoofInnerPanelLayout.configs.json  # 屋面内板排布配置
        └── FloorPanelLayout.configs.json      # 楼承板排布配置
```

### 10.2.2 可自定义的配置项

LightningCAD 提供了丰富的可自定义配置项，覆盖从排布参数到界面偏好的各个方面。

#### 默认板型参数

在排布参数设置窗口中，您可以将常用的板型配置保存为配置方案，下次使用时直接加载：

- 板材名称（板型）、板类型、厚度、排板板宽
- 颜色、CAD 颜色、正反压
- 填充图案、填充颜色、填充比例

**操作方式**：在排布窗口中配置好板型参数后，点击**保存**按钮将当前配置方案持久化到 `.cfg/` 目录。

#### 默认搭接参数

收边的搭接参数可在收边分段窗口中设置并自动记忆：

- 最大分段长度
- 搭接长度
- 首尾延伸长度
- 分割算法（均分/定尺）

#### 默认节点线样式

通过节点线图层配置窗口，可以自定义节点线的默认显示样式：

- 节点中心线图层名称
- 节点线文字图层名称
- 节点线边界框图层名称
- 收边文字图层名称
- 收边线图层名称
- 各元素的 CAD 颜色索引

#### 默认收边样式

收边的默认样式通过收边库和属性面板进行配置：

- 布置模式（长度模式/点状模式）
- 分割算法参数
- 标注参数（字高、宽度因子、行间距等）

#### 默认图层配置

LightningCAD 的图层配置采用统一管理方式，各功能模块的图层名称均可自定义：

- 板材图层
- 节点线各元素图层
- 收边线/收边文字图层
- 洞口图层
- 标注图层

#### 编号规则配置

板材编号支持 5 个自定义前缀字段和 1 个后缀字段，可根据企业编号规范灵活配置：

- 自定义前缀 1~5（如合同号、楼层号、区域号、板类型代码等）
- 编号流水号（自动递增）
- 自定义后缀

#### 单位设置

LightningCAD 默认使用**毫米（mm）**作为长度单位，与 CAD 图纸的绘图单位保持一致。所有排布参数、板材尺寸、收边参数等均以毫米为单位输入和显示。

> **提示**：在导出统计表和 BOM 表时，部分字段会自动转换为米（m）或平方米（m²）以符合工程惯例。

### 10.2.3 配置导出/导入（迁移到另一台电脑）

当您需要将 LightningCAD 的工作环境迁移到另一台电脑时，可以通过复制配置文件实现快速迁移。

#### 导出配置

将以下目录完整复制到移动存储设备或云盘中：

1. **用户配置目录**：`%AppData%\FsLt\UserProfiles\`
   - 包含公共库配置、CAD 启动脚本、CUI 菜单文件等。

2. **工程配置目录**：各 DWG 文件同级的 `.cfg/` 目录
   - 包含排布配置方案等工程级配置。

3. **公共库目录**（可选）：您指定的公共库根目录
   - 如果使用网络共享路径或云同步，则无需单独复制。

#### 导入配置

在新电脑上完成 LightningCAD 安装后：

1. 将 `UserProfiles` 目录复制到新电脑的 `%AppData%\FsLt\` 下。
2. 在公共库设置中重新指定公共库路径（如果路径发生变化）。
3. 在客户端的 CAD 管理页面重新注册 CAD 插件。
4. 打开工程文件时，`.cfg/` 目录中的配置将自动加载。

### 10.2.4 配置重置

如果配置出现异常或希望恢复到初始状态，可以执行配置重置：

1. **重置公共库配置**：删除 `%AppData%\FsLt\UserProfiles\CommonLibraryConfig.json` 文件，重启 CAD 后系统将提示重新设置公共库路径。

2. **重置排布配置**：删除 DWG 文件同级的 `.cfg/` 目录，排布配置方案将恢复为空白状态。

3. **完全重置**：删除整个 `%AppData%\FsLt\` 目录，所有用户配置将恢复为出厂默认值。

> **注意**：配置重置操作不可撤销。建议在重置前备份相关配置文件。

## 10.3 最佳实践

### 10.3.1 项目准备阶段

良好的项目准备是高效设计的基础。在开始围护深化设计之前，请按照以下建议进行准备工作。

#### 图纸标准化建议

**图层规划**：

在开始设计前，建议预先规划好图层体系。LightningCAD 会自动创建所需的图层，但您可以提前统一命名规范：

| 图层类别 | 建议命名 | 用途 |
|----------|---------|------|
| 围护边界 | `AEC-BOUNDARY` | 围护结构边界线 |
| 板材 | `AEC-PANEL` | 排布生成的板材实体 |
| 节点线 | `AEC-NODE` | 节点线中心线 |
| 节点文字 | `AEC-NODE-TEXT` | 节点编号文字 |
| 收边线 | `AEC-SHOUBIAN` | 收边线段 |
| 收边文字 | `AEC-SHOUBIAN-TEXT` | 收边标注文字 |
| 洞口 | `AEC-OPENING` | 门窗洞口 |
| 轴线 | `AEC-AXIS` | 定位轴线 |

**单位设置**：

- 确保 CAD 图纸的绘图单位为**毫米（mm）**，这是 LightningCAD 的默认工作单位。
- 检查 `UNITS` 命令中的插入比例是否为毫米。

**坐标系**：

- 建议使用世界坐标系（WCS）作为基准。
- 如果项目使用自定义坐标系（UCS），请确保在排布前切换到正确的 UCS。
- 多楼层项目建议每层使用独立的 DWG 文件，通过外部参照（XREF）进行定位。

#### 边界线的绘制规范

围护边界线是排布的基础，其绘制质量直接影响排布结果的准确性。

**绘制要求**：

1. **必须闭合**：边界线必须是闭合的多段线（Polyline），使用 `PEDIT` 命令的 `Close` 选项确保闭合。
2. **避免自交**：边界线不应存在自交或交叉的情况。
3. **简化顶点**：尽量减少不必要的顶点，避免在同一直线段上存在多个冗余顶点。
4. **方向一致**：建议统一按顺时针或逆时针方向绘制边界线。
5. **精确尺寸**：使用精确坐标输入或对象捕捉（OSNAP）确保边界尺寸准确。

**常见错误**：

| 错误类型 | 后果 | 解决方法 |
|---------|------|---------|
| 边界不闭合 | 排布命令拒绝执行 | 使用 `PEDIT → Close` 闭合 |
| 存在零长度线段 | 排布计算异常 | 使用 `OVERKILL` 命令清理 |
| 顶点不精确对齐 | 排布出现微小缝隙 | 使用对象捕捉确保顶点精确 |
| 边界包含圆弧段 | 楼承板排布可能异常 | 系统会自动处理，但建议检查 |

### 10.3.2 板材排布阶段

#### 批量处理策略

对于包含多个墙面或屋面区域的大型项目，合理的批量处理策略可以显著提高效率：

1. **多轮廓同时排布**：外墙板排布支持一次选择多个围护边界，系统将逐一在每个边界内执行排布。建议将同一立面、同一板型的多个区域一次选中排布。

2. **配置方案复用**：为常见的排布参数组合创建配置方案并保存。例如：
   - "外墙-海蓝-横排-从下到上"
   - "屋面-白灰-竖排-每开间重排"
   
   下次遇到类似场景时直接加载方案，无需重新设置参数。

3. **善用预排板**：在正式生成板材前，务必使用**预排板**功能预览效果。预览阶段可以随时修改参数并重新预览，避免生成后反复撤销。

#### 复杂形状边界的处理技巧

1. **异形边界**：对于非矩形的围护边界（如 L 形、T 形），系统会自动沿边界轮廓排布并裁切边缘板材。建议先进行预排板检查裁切效果。

2. **多洞口场景**：当边界内包含大量洞口时，确保所有洞口都已正确创建并被选中。系统会自动在洞口周围裁切板材。

3. **节点线辅助分割**：在需要板材分割的位置预先添加节点线（搭接线），排布后系统会自动在搭接线位置进行二次分割（搭接线补刀）。

4. **最小板尺寸过滤**：合理设置**最小板长度**和**最小板宽度**参数，自动过滤掉边缘处过小的裁切板材，避免产生不合理的碎片板。

#### 多区域排布的工作流

对于包含多个独立区域的项目（如多栋建筑、多个立面），建议按以下顺序排布：

```
外墙板（所有立面）→ 内墙板 → 屋面外板 → 屋面内板 → 楼承板
```

每个区域排布完成后，立即执行碰撞检查，确认无误后再进入下一区域。

### 10.3.3 节点与收边阶段

#### 先节点后收边的工作顺序

**强烈建议**按照以下顺序处理节点线和收边：

```
配置规则映射 → 自动生成节点线 → 手动补充节点线 → 收边关联 → 收边分段 → 批量标注
```

**原因**：
- 收边依赖于节点线的关联关系。收边的分段计算和标注都需要从节点线上读取收边信息。
- 如果先处理收边再修改节点线，可能导致收边数据与节点线不一致。

#### 利用规则映射提高效率

规则映射是自动生成节点线的核心机制，合理配置可以大幅减少手动工作量：

1. **首次配置投入时间**：花时间仔细配置规则映射表，为每种安装位置指定正确的节点类型和缩进值。

2. **善用智能匹配**：点击**智能匹配节点**按钮，系统会自动按安装位置名称匹配图纸中已有的节点图块，减少手动选择的工作量。

3. **保存配置方案**：将配置好的规则映射保存为方案，相似项目可以直接复用。

4. **复制配置微调**：对于相似但不完全相同的项目，复制现有配置方案后仅修改差异部分。

### 10.3.4 校验与输出阶段

#### 何时执行校验

建议在以下时间节点执行图纸校验：

| 时机 | 校验重点 | 说明 |
|------|---------|------|
| **排布完成后** | 碰撞检查、板材编号检查 | 确认排布结果无冲突 |
| **节点线生成后** | 节点缺失检查 | 确认所有应标注节点的位置都已标注 |
| **收边处理完成后** | 收边缺失检查 | 确认所有边缘位置都已设置收边 |
| **出图前** | 全面审核 | 执行所有校验项目，生成完整校验报告 |

#### 分阶段校验策略

对于大型项目，建议采用**分阶段校验**策略，而非等到最后才一次性校验：

1. **第一阶段（排布校验）**：每完成一个区域的排布，立即执行碰撞检查和板材编号检查。
2. **第二阶段（节点校验）**：节点线生成后，执行节点缺失检查和属性不匹配检查。
3. **第三阶段（收边校验）**：收边处理完成后，执行收边缺失检查和 ID 重复检查。
4. **第四阶段（全面校验）**：所有工作完成后，执行全面审核，确保无遗漏。

分阶段校验的好处是**问题发现越早，修复成本越低**。在排布阶段发现的碰撞问题只需调整排布参数，而在出图前发现则可能需要返工大量节点线和收边。

### 10.3.5 团队协作

#### 公共库共享策略

团队协作的基础是统一的公共库。建议采取以下策略：

1. **指定库管理员**：指定一名技术负责人作为公共库管理员，负责库数据的更新和维护。
2. **统一库路径**：所有团队成员的公共库指向同一个网络共享路径或云同步目录。
3. **变更通知**：库数据更新后，及时通知所有团队成员。
4. **只读保护**：普通成员对公共库目录设置为只读权限，防止意外修改。

#### 配置统一化

为确保团队成员输出一致的图纸风格，建议统一以下配置：

- **图层命名规范**：统一图层名称，确保打印样式一致。
- **文字样式**：统一板材标注、节点标注、收边标注使用的文字样式。
- **编号规则**：统一编号前缀的含义和格式。
- **颜色映射**：统一板材颜色名称与 CAD 颜色的映射关系。

#### 图纸拆分与合并

对于大型项目，单个 DWG 文件可能包含过多实体，影响性能。建议按以下维度拆分图纸：

| 拆分维度 | 说明 |
|---------|------|
| **按单体建筑** | 每栋建筑使用独立的 DWG 文件 |
| **按立面方向** | 每个立面（东/南/西/北）使用独立的 DWG 文件 |
| **按楼层** | 多层建筑按楼层拆分 |
| **按功能模块** | 排布图、节点详图、统计表分别使用独立文件 |

拆分后的图纸可通过**外部参照（XREF）**进行定位和组合查看。

## 10.4 性能优化建议

### 10.4.1 大型项目（100+ 板材）的性能注意事项

当项目中的板材数量超过 100 块时，以下操作可能出现明显的延迟：

| 操作 | 性能影响 | 优化建议 |
|------|---------|---------|
| 排布计算 | 板材数量越多，计算时间越长 | 合理设置最小板尺寸，过滤碎片板 |
| 碰撞检查 | 需要逐对检测板材间的碰撞关系 | 分区域检查，避免全图一次检查 |
| 批量修改属性 | 修改大量板材属性时需要逐一写入 | 分批修改，每批不超过 50 块 |
| 统计表生成 | 需要遍历所有板材并汇总数据 | 确保不需要统计的板材不在选择范围内 |
| 节点线自动生成 | 需要分析所有边界和洞口 | 分区域生成 |

### 10.4.2 避免不必要的重绘

CAD 的图形重绘（Regen）是性能消耗的主要来源。以下操作会触发重绘：

- 创建或删除实体
- 修改实体的几何属性
- 图层开关状态变化
- 缩放或平移视图

**优化建议**：

1. **批量操作优于逐一操作**：一次批量修改 50 块板材的属性，比逐一修改 50 次只触发一次最终重绘。
2. **合理使用预排板**：预排板阶段在临时图层上显示，确认后再正式生成，避免反复创建和删除。
3. **关闭不需要的图层**：在操作某个功能模块时，冻结其他不相关的图层，减少重绘范围。

### 10.4.3 合理使用图层过滤

图层过滤是管理复杂图纸显示的有效手段：

1. **按工作阶段设置图层状态**：
   - 排布阶段：冻结节点线、收边线图层
   - 节点阶段：冻结板材填充、收边线图层
   - 收边阶段：冻结板材填充图层
   - 出图阶段：解冻所有图层

2. **使用图层隔离**：在 CAD 中使用 `LAYISO` 命令临时隔离当前正在编辑的图层，隐藏其他所有图层。

3. **保存图层状态**：使用 CAD 的图层状态管理器（`LAYERSTATE`）保存常用的图层组合，一键切换。

### 10.4.4 备份策略优化

LightningCAD 内置了文件自动备份功能，但对于大型项目，建议额外采取以下备份策略：

| 备份类型 | 频率 | 说明 |
|---------|------|------|
| **CAD 自动保存** | 每 10-15 分钟 | CAD 内置的自动保存功能（`SAVETIME` 系统变量） |
| **LightningCAD 备份** | 按软件设定 | 插件内置的定时备份 |
| **手动备份** | 每完成一个工作阶段 | 在关键节点手动保存副本 |
| **版本备份** | 每天工作结束时 | 将 DWG 文件复制为带日期后缀的备份文件 |

**备份文件命名建议**：

```
项目名_立面_日期_版本.dwg
例如：A厂房_南立面_20260604_v3.dwg
```

> **提示**：`.cfg/` 配置目录也应纳入备份范围。如果只备份了 DWG 文件而丢失了 `.cfg/` 目录，排布配置方案将需要重新创建。

## 10.5 工作流建议

### 10.5.1 完整的围护设计工作流

以下是一个典型的围护结构深化设计完整工作流，适用于大多数工业厂房和钢结构建筑项目：

#### 阶段 1：项目初始化

**目标**：建立标准化的工作环境。

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1.1 | 确认公共库已配置 | 启动 CAD，确认公共库路径正确、子库完整 |
| 1.2 | 创建/打开 DWG 文件 | 使用标准模板创建新图纸，或打开已有底图 |
| 1.3 | 设置图层 | 确认图层命名和颜色符合项目规范 |
| 1.4 | 设置单位和坐标系 | 确认绘图单位为毫米，坐标系正确 |
| 1.5 | 执行单体初始化 | 使用 `FsInitBuilding` 命令创建 `.cfg/` 配置目录 |
| 1.6 | 加载公共库数据 | 从板材库、节点库、收边库中加载项目需要的数据 |

#### 阶段 2：边界绘制

**目标**：在图纸中建立完整的围护结构边界。

| 步骤 | 操作 | 说明 |
|------|------|------|
| 2.1 | 绘制墙面边界 | 根据建筑图纸绘制各立面的围护边界线（闭合多段线） |
| 2.2 | 绘制屋面边界 | 绘制屋面围护边界线 |
| 2.3 | 绘制楼板边界 | 绘制楼承板围护边界线（如有） |
| 2.4 | 创建洞口 | 在边界内创建门窗洞口（矩形/异形） |
| 2.5 | 定义轴线 | 创建定位轴线系统 |
| 2.6 | 定义屋面坡度 | 如为坡屋面，使用屋面坡度定义命令设置坡度参数 |

#### 阶段 3：板材排布

**目标**：在所有边界内完成板材的自动排布。

| 步骤 | 操作 | 说明 |
|------|------|------|
| 3.1 | 外墙板排布 | 选择边界和洞口，配置板型和排布参数，预排板确认后生成 |
| 3.2 | 内墙板排布 | 同外墙板流程 |
| 3.3 | 屋面外板排布 | 选择屋面边界，考虑坡度和开间参数 |
| 3.4 | 屋面内板排布 | 同屋面外板流程 |
| 3.5 | 楼承板排布 | 选择楼板边界和排布方向 |
| 3.6 | 碰撞检查 | 对每个区域执行碰撞检查，修复冲突 |
| 3.7 | 板材调整 | 使用合并、长度调整等功能优化排布结果 |

#### 阶段 4：节点线生成

**目标**：在所有需要的位置标注节点线。

| 步骤 | 操作 | 说明 |
|------|------|------|
| 4.1 | 插入节点图块 | 从节点库浏览器中将项目需要的节点图块插入到图纸中 |
| 4.2 | 配置规则映射 | 为墙面和屋面分别配置节点线规则映射 |
| 4.3 | 自动生成节点线 | 选择边界和洞口，执行自动生成 |
| 4.4 | 手动补充 | 在自动生成未覆盖的位置手动创建节点线 |
| 4.5 | 节点线编辑 | 调整节点线属性、缩进值等 |

#### 阶段 5：收边处理

**目标**：完成所有收边的关联、分段和标注。

| 步骤 | 操作 | 说明 |
|------|------|------|
| 5.1 | 加载收边图块 | 从收边库浏览器中将需要的收边图块插入到图纸中 |
| 5.2 | 关联收边到节点线 | 在节点线上设置关联的收边编号 |
| 5.3 | 收边分段 | 对节点线上的收边执行分段计算 |
| 5.4 | 批量标注 | 执行批量标注收边线命令 |

#### 阶段 6：整体校验

**目标**：确保图纸质量满足交付标准。

| 步骤 | 操作 | 说明 |
|------|------|------|
| 6.1 | 执行全面校验 | 一键执行所有校验项目 |
| 6.2 | 查看校验报告 | 逐项检查校验结果 |
| 6.3 | 定位并修复问题 | 点击问题条目定位到图纸位置，修复问题 |
| 6.4 | 重新校验 | 修复后再次执行校验，确认所有问题已消除 |

#### 阶段 7：输出检查

**目标**：确认图纸表达清晰、信息完整。

| 步骤 | 操作 | 说明 |
|------|------|------|
| 7.1 | 检查图层显示 | 确认所有应显示的图层已解冻，不需要的图层已冻结 |
| 7.2 | 检查标注完整性 | 确认板材编号、节点标注、收边标注齐全 |
| 7.3 | 检查图面布局 | 调整图面布局，确保图纸清晰可读 |

#### 阶段 8：统计表与 BOM 导出

**目标**：生成材料统计清单。

| 步骤 | 操作 | 说明 |
|------|------|------|
| 8.1 | 板材统计表 | 生成板材统计表，导出 DWG 表格和 Excel 文件 |
| 8.2 | 收边明细表 | 生成收边明细表，导出 DWG BOM 和 Excel 文件 |
| 8.3 | 归并长度计算 | 对板材执行归并长度计算，生成标准化下料清单 |

#### 阶段 9：图纸交付

**目标**：完成最终交付文件。

| 步骤 | 操作 | 说明 |
|------|------|------|
| 9.1 | 最终保存 | 保存 DWG 文件 |
| 9.2 | 备份文件 | 创建带日期后缀的备份副本 |
| 9.3 | 打印/发布 | 使用打印样式输出 PDF 或纸质图纸 |

### 10.5.2 各阶段的耗时参考

以下是一个中等规模工业厂房项目（约 200 块板材、50 条节点线、30 条收边）的各阶段耗时参考：

| 阶段 | 耗时参考 | 说明 |
|------|---------|------|
| 项目初始化 | 15-30 分钟 | 含环境检查和参数设置 |
| 边界绘制 | 1-3 小时 | 取决于建筑复杂程度 |
| 板材排布 | 2-4 小时 | 含参数调试和碰撞修复 |
| 节点线生成 | 1-2 小时 | 自动生成 + 手动补充 |
| 收边处理 | 1-2 小时 | 含分段和标注 |
| 整体校验 | 30-60 分钟 | 含问题修复 |
| 统计表导出 | 15-30 分钟 | 含数据核对 |
| **合计** | **约 1-2 个工作日** | 熟练操作后可进一步缩短 |

> **提示**：以上耗时为参考值，实际时间取决于项目复杂度、个人熟练程度和设计要求的变化频率。使用 LightningCAD 相比纯手工绘图，通常可提升 **3-5 倍**的工作效率。

### 10.5.3 常见返工点与避免方法

| 常见返工点 | 原因 | 避免方法 |
|-----------|------|---------|
| 排布方案需要推翻重做 | 板型选择错误或排布方向不合理 | 充分使用预排板功能，确认效果后再生成 |
| 节点线位置不对 | 规则映射配置错误或缩进值不合理 | 自动生成后立即检查关键位置，及时修正 |
| 收边分段结果不合理 | 分段参数设置不当 | 先对少量节点线试分段，确认参数正确后再批量执行 |
| 板材编号混乱 | 未及时编号或编号规则不统一 | 排布完成后立即执行编号，统一编号规则 |
| 统计结果不准确 | 板材属性不完整或有重复实体 | 出图前执行全面校验，检查 ID 重复和属性不匹配 |
| 洞口周围板材处理不当 | 洞口创建时机不对或未被选中 | 确保在排布前创建好所有洞口，排布时全部选中 |

## 10.6 快捷键与效率技巧

### 10.6.1 常用 CAD 命令配合使用

LightningCAD 作为 CAD 插件运行，许多原生 CAD 命令可以与围护设计功能配合使用，提高效率：

| CAD 命令 | 用途 | 配合场景 |
|---------|------|---------|
| `PEDIT` | 编辑多段线 | 确保围护边界闭合（`Close` 选项） |
| `OVERKILL` | 删除重复实体 | 清理边界线上的重复顶点和零长度线段 |
| `LAYISO` | 图层隔离 | 临时只显示当前编辑的图层 |
| `LAYUNISO` | 取消图层隔离 | 恢复所有图层的显示 |
| `MATCHPROP` | 特性匹配 | 快速将一个实体的属性复制到其他实体 |
| `STRETCH` | 拉伸 | 调整节点线或板材的位置 |
| `ARRAY` | 阵列 | 快速复制节点线等实体 |
| `HATCH` | 填充 | 为板材添加自定义填充图案 |
| `TABLE` | 表格 | 查看和编辑导出的统计表 |
| `LAYERSTATE` | 图层状态管理 | 保存和恢复常用的图层组合 |
| `XREF` | 外部参照 | 引用其他图纸作为底图参考 |
| `SECURELOAD` | 安全加载控制 | 设置为 0 以允许加载任意位置的插件 |

### 10.6.3 鼠标操作技巧

#### 双击编辑

LightningCAD 支持双击快捷编辑功能：

- **双击板材实体**：打开板材属性编辑面板，可直接修改板材的各项属性。
- **双击节点线**：打开节点线编辑对话框，修改节点类型、缩进值等参数。
- **双击收边图块**：打开增强属性编辑器，修改收边的基本属性。

> **提示**：双击编辑功能通过 LightningCAD 的双击拦截器（`AcadDoubleClickInterceptor`）实现，它会在 CAD 的原生双击事件之前拦截并处理 LightningCAD 自定义实体的双击操作。

#### 右键菜单

选中 LightningCAD 的自定义实体后，右键菜单中可能包含特定的操作选项（取决于 CAD 平台和配置）。

### 10.6.4 Ribbon 面板的高效使用

LightningCAD 在 CAD 的 Ribbon 界面中提供了专用的**"闪电围护"**选项卡，将常用功能以按钮形式组织：

**高效使用建议**：

1. **熟悉按钮位置**：花时间熟悉各功能按钮在 Ribbon 中的位置，形成肌肉记忆。
2. **使用工具提示**：将鼠标悬停在按钮上可查看功能说明和命令名称。
3. **结合命令行**：对于频繁使用的功能，直接输入命令名比点击 Ribbon 按钮更快。
4. **自定义快速访问工具栏**：将最常用的功能添加到 CAD 的快速访问工具栏（QAT），一键调用。

## 10.7 与外部软件的配合

### 10.7.1 与 Excel 的数据交换

LightningCAD 与 Microsoft Excel 之间有着紧密的数据交互，覆盖了参数导入和结果导出两个方向。

#### BOM 导出到 Excel

LightningCAD 支持将统计结果导出为 Excel 文件，便于后续的材料采购和工程管理：

**板材统计表导出**：
- 导出格式：`.xlsx`
- 分组方式：按板型和规格自动分组
- 包含字段：序号、名称、板型、编号、长度、宽度、厚度、颜色、块数、轴线位置等
- 自动计算：总长、面积、总重等字段使用 Excel 公式，修改数据后自动更新
- 按板材类型分别导出：墙面板导出"压型板"和"复合板"两个文件；楼承板导出"单板"和"钢筋桁架板"两个文件

**收边 BOM 导出**：
- 执行 `FsShouBianBomDaoExcel` 命令
- 选择图纸中已插入的 BOM 表格图块
- 系统读取表格数据并导出为 Excel 文件

#### 参数从 Excel 导入

LightningCAD 的公共库数据本身就存储在 Excel 文件中：

- **板材库**：`PanelLibrary.xlsx`——按安装位置分 Sheet 管理板型数据
- **节点库**：`JieDianLibrary.xlsx`——管理节点属性索引
- **收边库**：`ShouBianLibrary.xlsx`——管理收边属性索引

您可以直接在 Excel 中编辑这些数据文件，然后通过库浏览器的**重新加载**功能刷新数据。

**编辑注意事项**：
- 不要修改 Excel 文件的列标题和 Sheet 名称，系统依赖这些名称进行数据解析。
- 确保编号字段的唯一性，重复编号可能导致数据加载异常。
- 编辑完成后保存文件，然后在库浏览器中点击**重新加载**。

### 10.7.2 与 Tekla/Revit 的数据交互规划

LightningCAD 的产品路线图中已规划了与主流 BIM 软件的数据交互能力：

#### Revit 集成（规划中）

客户端已展示了 Revit 平台的入口卡片，未来计划支持：

- **二三维联动引擎**：在 CAD 二维图纸和 Revit 三维模型之间建立数据关联
- **BIM 围护建模**：基于 LightningCAD 的排布数据在 Revit 中自动生成围护结构三维模型
- **碰撞检测**：利用 Revit 的碰撞检测能力验证围护结构与主体结构之间的空间关系

#### 当前可用的数据交换方式

在 BIM 集成实现之前，您可以通过以下方式与 Tekla/Revit 进行数据交换：

| 交换方式 | 说明 |
|---------|------|
| **DWG 文件导入** | 将 LightningCAD 生成的 DWG 文件作为底图导入到 Tekla/Revit 中 |
| **Excel 数据导入** | 将 LightningCAD 导出的 Excel 统计表导入到 BIM 软件的材料管理系统中 |
| **DXF 格式** | 如有需要，可将 DWG 文件另存为 DXF 格式，提高跨平台兼容性 |

### 10.7.3 生成加工数据

LightningCAD 的统计数据可以直接用于围护板材和收边件的加工生产：

#### 板材加工数据

通过板材统计表和归并长度计算，可以生成以下加工数据：

- **下料清单**：包含每块板材的归并长度、板宽、厚度等信息，直接用于切割机编程。
- **板材编号图**：在 CAD 图纸中标注每块板材的编号和位置，指导现场安装。
- **材料汇总表**：按规格汇总板材数量和总面积，用于材料采购。

#### 收边加工数据

通过收边 BOM 表和分段信息，可以生成以下加工数据：

- **收边下料单**：包含每段收边的长度、数量、折弯参数等，用于折弯机编程。
- **收边截面图**：从收边库中导出的 DWG 截面图，包含完整的尺寸标注，用于模具设计。
- **收边汇总表**：按规格汇总收边数量和总长度，用于材料采购。

#### 数据格式

| 数据类型 | 格式 | 用途 |
|---------|------|------|
| 统计表 | DWG 表格 + Excel | 图纸展示 + 数据处理 |
| BOM 表 | DWG 表格 + Excel | 图纸展示 + 采购下单 |
| 归并长度 | 板材属性数据 | 切割机编程 |
| 收边分段 | 节点线属性数据 | 折弯机编程 |

> **提示**：导出的 Excel 文件使用预定义的模板格式，包含完整的表头、分组标题和计算公式。如果您的加工系统需要特定格式的数据，可以在 Excel 中进行二次加工处理。
