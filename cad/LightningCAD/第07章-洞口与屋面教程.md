# 第7章 洞口与屋面教程

> 本章将系统介绍 LightningCAD（闪电围护）中**洞口**与**屋面坡度**功能的完整使用方法。洞口是围护结构深化设计中不可或缺的关键环节——在墙面、屋面或楼承板上开设洞口，用于预留门窗位置、设备通道和采光通风口。屋面坡度定义则是屋面板排布的前置步骤，直接影响板材长度计算和排布方向。通过本章的学习，您将掌握从创建各类洞口到定义屋面坡度的完整工作流程。
>

## 7.1 洞口概述

### 7.1.1 什么是洞口

在围护结构工程中，**洞口**（Opening）是指在墙面、屋面或楼承板等围护板材铺设区域内开设的各类开口。这些开口对应建筑物中的门窗、设备管线通道、采光通风设施等功能需求。

在 LightningCAD 中，洞口以**独立的 CAD 自定义实体**形式存在于图纸中，分为两种基本类型：

| 类型 | 实体类 | 说明 |
|------|--------|------|
| **矩形洞口** | `AecRectOpeningMgd` | 标准的矩形门窗开口，由基点（左下角）、宽度和高度定义 |
| **多边形洞口（异形窗）** | `AecPolyOpeningMgd` | 非标准形状的开口，由闭合多段线定义，支持弧线段 |

每个洞口实体不仅包含几何信息，还承载了丰富的属性数据，包括洞口类型（门洞/窗洞）、标签内容、文字高度、颜色等，为后续的板材排布和节点线自动生成提供基础数据。

### 7.1.2 洞口的作用

洞口在围护系统设计中承担着多重关键作用：

| 作用 | 说明 |
|------|------|
| **预留门窗位置** | 在墙面板排布时自动绕开门窗区域，确保板材不覆盖门窗开口 |
| **设备管线通道** | 为暖通管道、电缆桥架等设备预留穿越围护结构的通道 |
| **采光通风** | 为屋面天窗、采光板、通风器等设施预留开口位置 |
| **板材自动裁剪** | 排布时系统自动使用洞口进行板材裁剪（布尔差集运算），生成精确的板材形状 |
| **节点线关联** | 洞口边缘可自动生成对应的节点线（如门上、窗侧等位置），关联收边配件 |

### 7.1.3 洞口类型

LightningCAD 支持两大类洞口形状：

#### 矩形洞口

矩形洞口是最常用的洞口类型，适用于绝大多数标准门窗。矩形洞口由以下参数定义：

- **基点（BasePt）**：洞口的左下角锚点坐标
- **宽度（Width）**：洞口水平方向尺寸（mm）
- **高度（Height）**：洞口垂直方向尺寸（mm）
- **标签内容（LabelContent）**：洞口类型名称（如"窗洞"、"人行门"等）

#### 多边形洞口（异形窗）

多边形洞口用于非标准形状的开口，如弧形窗、三角形窗、不规则造型窗等。多边形洞口由闭合多段线定义，支持直线段和弧线段（凸度 Bulge）。

### 7.1.4 洞口位置分类

根据洞口所在的围护结构位置，LightningCAD 将洞口分为三大类：

| 位置分类 | 说明 | 可用洞口类型 |
|---------|------|-------------|
| **墙面洞口** | 位于墙面围护边界内的洞口 | 窗洞、百叶窗、玻璃幕墙、人行门、推拉门、提升门、卷帘门 |
| **屋面洞口** | 位于屋面围护边界内的洞口 | 排烟洞口、气楼、天窗、通风器、采光板、其他 |
| **楼承板洞口** | 位于楼承板围护边界内的洞口 | 楼承板洞口 |

每种洞口类型都有预定义的**颜色索引**，创建洞口时系统将自动应用对应颜色，方便在图纸中通过颜色区分不同类型的洞口。

## 7.2 创建墙面洞口

墙面洞口是 LightningCAD 中最常用的功能之一，支持创建矩形洞口（门窗洞）和多边形洞口（异形窗）两种形式。

### 7.2.1 创建矩形洞口

#### 操作流程概览

```
启动命令 → 选择洞口类型和创建方式 → 绘制/拾取洞口 → 系统创建洞口实体
```

#### 详细操作步骤

**第一步：启动墙面矩形洞口命令**

在 LightningCAD 功能区（Ribbon）的"门窗洞口"面板中，点击**"定义矩形洞口"**按钮，或在命令行输入 `FsCreateWallRectOpening`。

**第二步：选择洞口类型和创建方式**

系统将弹出**"定义门窗洞"**对话框，包含以下设置：

1. **洞口类型选择**：从下拉列表中选择洞口类型。墙面洞口按"窗洞类型"和"门洞类型"分组显示：
   - 窗洞类型：窗洞、百叶窗、玻璃幕墙
   - 门洞类型：人行门、推拉门、提升门、卷帘门

2. **创建方式选择**：LightningCAD 提供四种创建矩形洞口的方式：

| 创建方式 | 说明 | 适用场景 |
|---------|------|---------|
| **绘制洞口（Sketch）** | 通过指定两个对角点手动绘制矩形洞口 | 精确控制洞口位置和尺寸 |
| **拾取矩形（Pick）** | 选择图纸中已有的矩形多段线，自动转换为洞口 | 已有建筑图纸中的门窗位置 |
| **拾取小实体（PickSmallEntities）** | 选择多个零散实体，系统按间距自动分组并生成包围盒洞口 | 从设备图元快速生成洞口 |
| **拾取图块（PickBlockReference）** | 选择图纸中的图块参照，以图块包围盒创建洞口 | 基于门窗图块快速生成洞口 |

3. **附加选项**：
   - **清理源图元（CleanSource）**：勾选后，创建洞口时将自动删除原始的多段线、小实体或图块参照。默认勾选。
   - **零散实体分组容差**：当使用"拾取小实体"方式时，间距小于此值（默认 50mm）的实体将被合并为同一组，生成一个洞口。
   - **直角容差**：当使用"拾取矩形"方式时，判断多段线是否为矩形时允许的直角偏差角度（默认 0.5°）。

4. 点击对应的操作按钮确认选择，对话框关闭后进入图纸交互阶段。

> **提示**：系统会记住您上次选择的洞口类型和创建方式，下次启动命令时自动恢复，无需重复设置。

**第三步：在图纸中创建洞口**

根据所选的创建方式，执行不同的交互操作：

**方式一：绘制洞口（Sketch）**

1. 命令行提示"绘制洞口起点"，在图纸中点击指定洞口的**左下角点**（基点）。
2. 系统启动实时拖拽预览（Jig），显示矩形洞口的动态轮廓。
3. 移动鼠标到目标位置，点击指定洞口的**右上角点**（终点）。
4. 系统根据两个对角点计算洞口的宽度和高度，创建矩形洞口实体。

**方式二：拾取矩形（Pick）**

1. 命令行提示"选择多个矩形作为洞口"。
2. 在图纸中框选或逐个点选已有的闭合矩形多段线。
3. 按回车确认选择。
4. 系统逐一验证所选多段线是否为矩形：
   - 检查顶点数量（必须为 4 个有效顶点）。
   - 检查各边是否为直线段。
   - 检查相邻边是否垂直（在直角容差范围内）。
5. 对于近似矩形（偏差在容差范围内），系统将自动纠偏并创建洞口。
6. 非矩形的多段线将被跳过，命令行提示"跳过 X 个多段线，其不是矩形，请使用异形窗功能定义！"。

> **注意**：如果选择了位置重复的多段线，系统会自动去重。当启用了"清理源图元"选项时，重复的多段线将被自动删除。

**方式三：拾取小实体（PickSmallEntities）**

1. 命令行提示"选择一些需要包含的实体来生成一个洞口"。
2. 在图纸中选择需要包围在洞口内的零散实体（如线条、文字、标注等）。
3. 按回车确认选择。
4. 系统根据实体的图面位置自动分组：
   - 间距小于"分组容差"（默认 50mm）的实体归为同一组。
   - 每组实体生成一个包围盒，作为洞口的范围。
5. 系统在每个分组位置创建矩形洞口。

**方式四：拾取图块（PickBlockReference）**

1. 命令行提示"选择一个或多个图块作为洞口"。
2. 在图纸中选择门窗图块参照。
3. 系统计算每个图块的包围盒（包含嵌套实体），以此创建矩形洞口。

**第四步：创建结果**

创建完成后，命令行将显示结果统计信息：

```
成功创建 X 个洞口实体
```

如果使用"拾取矩形"方式，还会显示详细的处理统计：

```
多段线处理统计:
总选择数量：N
成功创建洞口：X
清理了 Y 个原始实体
```

### 7.2.2 创建多边形洞口（异形窗）

对于非矩形的洞口（如弧形窗、三角形窗、异形造型窗等），需要使用**异形窗**功能创建多边形洞口。

#### 操作流程

**第一步：绘制闭合多段线**

在图纸中使用 CAD 的 `PLINE` 命令绘制洞口轮廓的闭合多段线：

- 多段线必须闭合（使用 `C` 选项闭合或首尾点重合）。
- 支持直线段和弧线段（圆弧凸度）。
- 多段线的形状即为洞口的最终形状。

**第二步：启动异形窗转换命令**

在功能区点击**"多段线转异形窗"**按钮，或在命令行输入对应命令。

**第三步：选择多段线**

命令行提示"请选择一个多段线用来转换为异形窗"，在图纸中选择已绘制好的闭合多段线。

> **注意**：如果选择的多段线未闭合，系统将提示"选择的多段线未闭合！"并拒绝转换。

**第四步：系统创建异形窗**

系统将执行以下操作：

1. 读取多段线的顶点坐标和凸度信息。
2. 创建 `AecPolyOpeningMgd` 异形窗实体。
3. 将异形窗放置在专用的洞口图层上。
4. 自动检测并处理异形窗与中缝/伸缩缝的关系——异形窗可以打断中缝和伸缩缝。
5. 删除原始的多段线。

**第五步：设置异形窗标签**

创建完成后，异形窗将显示标题标签（默认为"异形窗"）。您可以通过属性面板修改标签内容、文字高度等参数。

异形窗还支持**分段标签**功能，可以为异形窗的每条边分别设置标签信息，用于标注各边的尺寸或节点信息。

### 7.2.3 洞口与板材的关系

#### 自动裁剪板材

在板材排布过程中，洞口将作为裁剪条件自动参与板材的裁剪计算：

1. **布尔差集运算**：系统将洞口区域从板材中减去（板轮廓 - 洞口 = 实际板材形状）。
2. **贯穿洞口处理**：当洞口的长或宽与板材的长或宽相等时（即洞口贯穿整块板），系统将板材在洞口位置打断，生成多块独立的板材。
3. **洞口嵌套校验**：系统会检查洞口之间是否存在嵌套或重叠关系，如果发现异常将提示警告。

#### 洞口避让规则

- 板材排布时自动绕洞口口区域，不会在洞口位置生成板材。
- 洞口边缘的板材将根据排布参数进行裁切处理（如果启用了"是否处理特殊板"选项）。
- 洞口周围的裁切板材将参与裁板面积统计。

#### 洞口周围板材处理

在排布参数设置窗口中，勾选**"是否处理特殊板"**选项后，系统将对洞口边缘的板材进行特殊处理：

- 洞口边缘的异形板材将被正确识别和标记。
- 系统将对异形板材进行"分条-相交-合并"的拆分处理，确保每块板材的形状合理。

### 7.2.4 洞口属性编辑

创建洞口后，可以通过以下方式编辑洞口属性：

#### 通过属性面板编辑

1. 在图纸中选中矩形洞口实体。
2. 打开 CAD 属性面板（Property Palette）。
3. 属性面板将显示洞口的完整属性信息，分为以下分组：

| 分组 | 可编辑属性 |
|------|-----------|
| **基本信息** | 洞口类型（标签内容）、宽度、高度 |
| **标签设置** | 文字高度、文字样式、标签偏移位置 |
| **显示设置** | 颜色、图层 |

#### 通过批量编辑命令

当需要同时修改多个洞口的属性时，可使用批量编辑功能：

1. 启动**"编辑矩形洞口"**命令。
2. 在图纸中选择需要编辑的矩形洞口（支持预选和框选）。
3. 系统弹出**"编辑矩形洞口"**对话框，显示以下可编辑参数：

| 参数 | 说明 |
|------|------|
| **宽度** | 洞口宽度（mm），修改后所有选中洞口统一调整 |
| **高度** | 洞口高度（mm），修改后所有选中洞口统一调整 |
| **洞口类型** | 从下拉列表中选择新的洞口类型。如果选中洞口的类型不一致，显示"多种" |
| **基准点** | 调整尺寸时的锚点位置（9 种基准点可选） |

4. 对话框底部显示已选中的洞口数量。
5. 修改完成后点击"确定"，系统将修改应用到所有选中的洞口。

#### 基准点说明

编辑洞口尺寸时，**基准点**决定了尺寸变化的锚定方向。系统提供 9 种基准点位置：

| 基准点 | 位置说明 |
|--------|---------|
| 左下角 | 左下角固定，向右上方扩展 |
| 下中 | 下边中点固定，向两侧和上方扩展 |
| 右下角 | 右下角固定，向左上方扩展 |
| 左中 | 左边中点固定，向上下和右方扩展 |
| 中心 | 中心点固定，向四周均匀扩展 |
| 右中 | 右边中点固定，向上下和左方扩展 |
| 左上角 | 左上角固定，向右下方扩展 |
| 上中 | 上边中点固定，向两侧和下方扩展 |
| 右上角 | 右上角固定，向左下方扩展 |

## 7.3 创建屋面洞口

### 7.3.1 屋面洞口特点

屋面洞口与墙面洞口在操作流程上基本一致，但具有以下特点：

1. **洞口类型不同**：屋面洞口的类型列表与墙面不同，包括排烟洞口、气楼、天窗、通风器、采光板等屋面专用类型。
2. **坡度影响**：屋面通常具有排水坡度，洞口在排布时需要考虑坡度对板材长度和裁剪的影响。
3. **节点线位置不同**：屋面洞口的各边对应的节点线安装位置类型与墙面不同（如洞口侧、洞口上、洞口下等），具体取决于洞口边与屋脊线的平行/垂直关系。

### 7.3.2 操作流程

**第一步：启动屋面洞口命令**

在功能区点击**"定义屋面洞口"**按钮，或在命令行输入 `FsDingYiWuMianDongKou`。

**第二步：选择洞口类型和创建方式**

系统弹出**"定义屋面洞口"**对话框：

1. **洞口类型选择**：从下拉列表中选择屋面洞口类型：
   - 排烟洞口
   - 气楼
   - 天窗
   - 通风器
   - 采光板
   - 其他

2. **创建方式选择**：与墙面洞口相同，支持四种方式：
   - 绘制洞口（Sketch）
   - 拾取矩形（Pick）
   - 拾取小实体（PickSmallEntities）
   - 拾取图块（PickBlockReference）

3. 点击对应的操作按钮确认。

**第三步：在图纸中创建洞口**

操作方式与墙面矩形洞口完全一致，请参见 7.2.1 节的详细说明。

**第四步：创建结果**

系统创建屋面矩形洞口实体，命令行显示创建结果统计。

### 7.3.3 与墙面洞口的区别

| 对比项 | 墙面洞口 | 屋面洞口 |
|--------|---------|---------|
| **命令名称** | 定义矩形洞口 | 定义屋面洞口 |
| **洞口类型列表** | 窗洞、百叶窗、玻璃幕墙、人行门、推拉门、提升门、卷帘门 | 排烟洞口、气楼、天窗、通风器、采光板、其他 |
| **洞口类型分组** | 按"窗洞类型"和"门洞类型"分组 | 统一为"窗洞类型" |
| **节点线位置识别** | 基于包围盒上下左右位置判断（门上/门下/门侧/窗上等） | 基于与屋脊线的平行/垂直关系判断（洞口侧/洞口上/洞口下） |
| **坡度考虑** | 无 | 排布时需考虑屋面坡度对板材的影响 |

## 7.4 创建楼承板洞口

### 7.4.1 楼承板洞口特点

楼承板洞口用于在楼面围护区域内创建设备洞口、管线通道等开口。楼承板洞口具有以下特点：

1. **洞口类型简单**：楼承板仅有一种洞口类型——"楼承板洞口"。
2. **无门洞分类**：楼承板不涉及门窗，因此不存在门洞/窗洞的分类。
3. **排布方向灵活**：楼承板排布支持任意方向，洞口裁剪将适应排布方向。

### 7.4.2 操作流程

**第一步：启动楼承板洞口命令**

在功能区点击**"定义楼承板洞口"**按钮，或在命令行输入 `FsDingYiLouChengBanDongKou`。

**第二步：选择创建方式**

系统弹出**"定义楼承板洞口"**对话框：

1. **洞口类型**：默认为"楼承板洞口"，已自动选中。
2. **创建方式**：选择绘制洞口、拾取矩形、拾取小实体或拾取图块。
3. 点击对应的操作按钮确认。

**第三步：在图纸中创建洞口**

操作方式与墙面、屋面洞口完全一致。

### 7.4.3 注意事项

1. **洞口位置**：楼承板洞口应位于楼承板围护边界线内部。如果洞口超出边界范围，排布时可能不会正确裁剪。

2. **洞口与节点线**：楼承板洞口同样支持在洞口边缘自动生成节点线，用于标注洞口周边的收边做法。

3. **多个洞口间距**：当多个楼承板洞口间距较小时，洞口之间的板材可能过窄。建议在排布参数中设置合理的**最小板宽度**，过滤掉不合理的窄板。

4. **贯穿洞口**：如果楼承板洞口的宽度或高度恰好等于排布区域的宽度或高度，系统将识别为贯穿洞口，在洞口位置将板材打断。

## 7.5 编辑矩形洞口

### 7.5.1 编辑洞口尺寸

LightningCAD 提供多种方式编辑已有洞口的尺寸：

#### 方式一：批量编辑命令（推荐）

1. 启动**"编辑矩形洞口"**命令。
2. 选择需要编辑的洞口实体。
3. 在弹出的编辑对话框中修改宽度和高度值。
4. 选择基准点位置，确定尺寸变化的锚定方向。
5. 点击"确定"应用修改。

> **提示**：批量编辑支持同时修改多个洞口。如果选中的多个洞口尺寸不一致，对话框中将显示第一个洞口的尺寸值，修改后所有洞口将统一为新尺寸。

#### 方式二：属性面板编辑

1. 选中单个洞口实体。
2. 在属性面板中直接修改宽度和高度数值。
3. 修改即时生效，无需额外确认。

#### 方式三：夹点拖拽

1. 选中洞口实体，洞口将显示夹点（Grip）。
2. 拖拽洞口的角点夹点可以调整洞口的宽度和高度。
3. 拖拽边中点夹点可以单独调整宽度或高度。

> **注意**：夹点拖拽修改的是洞口的几何图形，不会自动更新洞口实体内部存储的宽度和高度属性值。建议优先使用批量编辑命令或属性面板进行精确修改。

### 7.5.2 编辑洞口位置

#### 移动洞口

1. 选中洞口实体。
2. 使用 CAD 的 `MOVE` 命令或拖拽基点夹点移动洞口到新位置。
3. 移动操作不改变洞口的尺寸和属性。

> **提示**：移动洞口后，如果图纸中已有排布好的板材，需要重新执行排布操作才能使板材正确裁剪。

#### 精确定位

在属性面板中，可以修改洞口的基点坐标（BasePt）实现精确定位。

### 7.5.3 编辑洞口属性

#### 修改洞口类型

1. 选中洞口实体，打开属性面板。
2. 在"标签内容"字段中修改洞口类型名称。
3. 系统将自动更新洞口的颜色为对应类型的预定义颜色。

#### 修改标签样式

在属性面板中，可以修改洞口标签的以下样式参数：

| 参数 | 说明 |
|------|------|
| **文字高度** | 标签文字的高度（默认 300mm） |
| **文字样式** | 关联的 CAD 文字样式 |
| **标签偏移** | 标签相对于洞口基点的偏移位置 |
| **文字方向** | 标签文字的排列方向 |

### 7.5.4 复制洞口

使用 CAD 的标准复制命令可以快速复制洞口：

1. 选中需要复制的洞口实体。
2. 使用 `COPY` 命令或 `Ctrl+C` / `Ctrl+V` 复制洞口。
3. 复制后的洞口保留原始的所有属性信息（类型、标签样式等）。
4. 系统会自动检测重复洞口——如果复制后的洞口与已有洞口位置和尺寸完全相同（容差 10mm 内），将提示"跳过重复洞口"。

### 7.5.5 镜像洞口

使用 CAD 的 `MIRROR` 命令可以镜像洞口：

1. 选中需要镜像的洞口实体。
2. 指定镜像线的起点和终点。
3. 选择是否保留原始洞口。
4. 镜像后的洞口将正确更新基点位置和尺寸方向。

### 7.5.6 删除洞口

使用 CAD 的 `ERASE` 命令或按 `Delete` 键删除洞口：

1. 选中需要删除的洞口实体。
2. 执行删除操作。

> **重要说明**：删除洞口后，如果图纸中已有排布好的板材，板材不会自动恢复为未裁剪状态。您需要重新执行板材排布操作，使板材在没有洞口的情况下重新排列。

## 7.6 屋面概述

### 7.6.1 屋面在围护结构中的角色

屋面（屋面）是建筑围护结构的重要组成部分，承担着防水、保温、隔热、排水等关键功能。在 LightningCAD 的围护深化设计流程中，屋面板的排布是核心工作之一，而**屋面坡度**的定义则是屋面板排布的前置条件。

屋面系统的设计流程通常为：

```
定义屋面围护边界 → 定义屋面坡度 → 排布屋面外板 → 排布屋面内板 → 生成节点线 → 收边处理
```

### 7.6.2 屋面类型

LightningCAD 支持以下常见的屋面形式：

| 屋面形式 | 说明 | 坡度特征 |
|---------|------|---------|
| **单坡屋面** | 屋面向一个方向倾斜 | 单一坡度方向 |
| **双坡屋面** | 屋面从屋脊向两侧倾斜 | 左右两个坡度，由屋脊线分隔 |
| **多坡屋面** | 包含多个坡面和屋脊 | 多个坡度方向组合 |

### 7.6.3 与板材排布的关系

屋面坡度直接影响板材排布的以下方面：

1. **板材长度计算**：屋面板的实际展开长度需要考虑坡度的影响。坡度越大，板材的斜面长度越长。

2. **排布方向**：屋面板默认沿坡度方向（垂直于屋脊线）排布，板材的长度方向与坡度方向一致。

3. **坡度信息写入**：排布完成后，坡度信息将自动写入每块板材的属性数据中（`PanelBasicInfo.SlopeInputRaw` 和 `SlopeAngleRadians`），用于后续的材料统计和加工下单。

4. **搭接参数**：坡度影响板材之间的搭接方式和搭接长度。

## 7.7 定义屋面坡度

### 7.7.1 什么是屋面坡度

**屋面坡度**是指屋面相对于水平面的倾斜程度。坡度的定义是屋面板排布的关键前置参数，它决定了：

- 屋面板的实际展开长度
- 排水方向和排水效率
- 板材的搭接方式
- 收边件的选择和安装方式

在 LightningCAD 中，屋面坡度以**坡度属性块**（`FsRoofSlope`）的形式插入到图纸中。每个坡度属性块包含一个坡度值属性（`SLOPE`），系统在屋面板排布时会自动读取这些坡度信息。

### 7.7.2 坡度定义方式

LightningCAD 的坡度输入采用**比例方式**（ Slope 格式），使用 `a/b` 的分数形式表示坡度。

#### 比例方式（Slope）

这是 LightningCAD 定义屋面坡度的标准方式，格式为 `分子/分母`：

- **输入格式**：`a/b`，其中 `a` 为垂直升高值，`b` 为水平距离值。
- **示例**：
  - `5/100`：表示每 100 单位水平距离升高 5 单位（常见屋面坡度）
  - `1/10`：表示每 10 单位水平距离升高 1 单位（较陡的屋面）
  - `1/3`：表示每 3 单位水平距离升高 1 单位（陡坡屋面）

系统内部会将比例值转换为弧度值进行计算：`弧度 = arctan(a/b)`

#### 系统内部支持的坡度格式

虽然屋面坡度定义对话框使用比例方式输入，但 LightningCAD 的坡度系统内部支持三种格式的存储和解析：

| 格式 | 前缀 | 示例 | 说明 |
|------|------|------|------|
| **比例格式** | `Slope:` | `Slope:5/100` | 分数形式，屋面坡度定义对话框使用此格式 |
| **小数比例** | `Slope:` | `Slope:0.33` | 小数形式，系统自动转换为 `arctan(0.33)` |
| **弧度格式** | `Radian:` | `Radian:0.5` | 弧度值（0 ~ π/2），用于精确的数学计算 |
| **角度格式** | `Degree:` | `Degree:30` | 角度值（0° ~ 90°），用于直观的角度表达 |

> **提示**：在板材属性面板中编辑坡度时，您可以使用上述任意格式输入。系统将自动解析并规范化存储。

### 7.7.3 操作流程

#### 第一步：启动定义屋面坡度命令

在功能区的"屋面"面板中点击**"定义屋面坡度"**按钮，或在命令行输入 `FsDingYiWuMianPoDu`。

#### 第二步：输入坡度值

系统弹出**"定义屋面坡度"**对话框：

1. 在**坡度值**输入框中，以 `a/b` 的格式输入坡度比例。
   - 例如：输入 `5/100` 表示 5% 的屋面坡度。
   - 例如：输入 `1/10` 表示 10% 的屋面坡度。

2. 系统将实时验证输入的格式：
   - 格式必须为 `数字/数字`（如 `5/100`、`1/10`）。
   - 分母不能为 0。
   - 分子和分母均支持小数（如 `2.5/100`）。

3. 如果输入格式正确，"确定"按钮将变为可用状态。如果格式错误，对话框将显示验证提示："格式错误，请输入 a/b 格式（如 5/100）"。

4. 点击**"确定"**确认坡度值。

#### 第三步：指定坡度标注插入点

确认坡度值后，命令行提示"指定坡度标注插入点（回车或 ESC 结束）"：

1. 在图纸中点击指定坡度属性块的插入位置。
2. 系统立即在该位置插入坡度标注块，标注文字显示您输入的坡度值（如 `5/100`）。
3. 插入后图形立即可见，您可以继续指定下一个插入点。
4. 可以在不同位置插入多个坡度标注，适用于多坡屋面（如双坡屋面的左右两侧分别标注不同的坡度）。
5. 按**回车**或 **ESC** 键结束插入。

#### 第四步：坡度标注与屋面边界的关联

坡度标注块插入后，在进行屋面排布时需要选择屋面围护边界。系统将自动读取边界范围内的坡度属性块，获取坡度信息并应用到排布计算中。

### 7.7.4 坡度对排板的影响

#### 屋面板长度计算

屋面坡度会影响板材的实际展开长度。当屋面存在坡度时：

- **水平投影长度**：板材在水平面上的投影长度。
- **斜面展开长度**：板材沿屋面的实际长度 = 水平投影长度 / cos(坡度角)。

例如：坡度为 `5/100` 时，坡度角约为 2.86°，cos(2.86°) ≈ 0.9988，展开长度约为投影长度的 1.001 倍。对于小坡度屋面，差异较小；对于大坡度屋面，差异显著。

#### 排板方向自动调整

屋面板排布时：

- 排布方向默认垂直于屋脊线（即沿坡度方向排布）。
- 板材的长度方向与坡度方向一致。
- 系统从起铺点向两个方向（正向和反向）分别排布板材。

#### 搭接参数变化

坡度对搭接的影响：

- 坡度方向上的搭接缝需要考虑排水方向，通常上板压下板。
- 坡度较大时，搭接长度可能需要适当增加以确保防水效果。
- 排布配置方案中的搭接线位置将参考坡度方向进行计算。

### 7.7.5 修改已有坡度

如果需要修改已插入的坡度标注：

1. 在图纸中双击坡度属性块。
2. 系统打开**增强属性编辑器**。
3. 修改 `SLOPE` 属性的值（格式为 `a/b`，如 `10/100`）。
4. 点击"确定"保存修改。

> **注意**：修改坡度标注后，如果已经完成了屋面板排布，需要重新执行排布操作才能使新的坡度值生效。

### 7.7.6 设置板材坡度

除了通过"定义屋面坡度"命令在图纸中插入坡度标注外，您还可以直接修改已排布板材的坡度属性：

1. 选中已排布的屋面板材。
2. 在属性面板中找到**"坡度"**属性。
3. 输入坡度值，支持以下格式：
   - `Slope:5/100`（比例格式）
   - `Radian:0.05`（弧度格式）
   - `Degree:3`（角度格式）
4. 系统将自动解析输入值并更新板材的坡度数据。
5. 清空坡度值将移除板材的坡度信息。

> **提示**：通常不需要手动设置单块板材的坡度。在屋面排布时，系统会自动从坡度标注块中读取坡度值并写入每块板材。

## 7.8 常见问题与技巧

### 7.8.1 洞口创建后板材未自动裁剪

**问题描述**：创建洞口后，已排布的板材没有在洞口位置自动裁剪，板材仍然覆盖洞口区域。

**原因分析**：洞口创建和板材排布是两个独立的操作。创建洞口后，已有的板材不会自动更新裁剪状态。

**解决方法**：

1. 创建洞口后，需要**重新执行板材排布**操作。
2. 在排布时选择围护边界和洞口对象，系统将在排布过程中自动裁剪板材。
3. 排布参数中勾选**"是否处理特殊板"**，确保洞口边缘的板材得到正确处理。

### 7.8.2 洞口位置偏差

**问题描述**：创建的洞口位置与设计图纸中的门窗位置存在偏差。

**原因分析**：

- 使用"绘制洞口"方式时，起点和终点拾取不够精确。
- 使用"拾取矩形"方式时，原始多段线的位置本身存在偏差。

**解决方法**：

1. **使用精确坐标**：在属性面板中直接修改洞口的基点坐标（BasePt），实现精确定位。
2. **使用对象捕捉**：绘制洞口时启用 CAD 的对象捕捉（OSNAP），精确捕捉已有图元的关键点。
3. **批量编辑**：使用编辑矩形洞口命令，统一调整多个洞口的位置和尺寸。

### 7.8.3 屋面坡度与排板方向不一致

**问题描述**：屋面板排布方向与预期的坡度方向不一致。

**原因分析**：

- 屋面排布时未正确选择高檐口或屋脊节点线作为方向参考。
- 坡度标注块的位置不在屋面围护边界范围内。

**解决方法**：

1. 确保坡度标注块位于屋面围护边界内部。
2. 在屋面排布时，正确选择高檐口或屋脊节点线，系统将据此确定排布方向。
3. 排布方向默认垂直于屋脊线（沿坡度方向），检查屋脊线的方向是否正确。

### 7.8.4 多个洞口重叠处理

**问题描述**：多个洞口之间存在重叠或间距过小的情况。

**系统行为**：

- 系统在排布时会进行**洞口嵌套校验**，检测洞口之间是否存在嵌套或重叠。
- 如果发现洞口嵌套，系统可能抛出异常并提示错误。
- 间距过小的洞口可能导致洞口之间的板材过窄。

**解决方法**：

1. **合并洞口**：将相邻的重叠洞口合并为一个更大的洞口。
2. **调整间距**：使用编辑命令调整洞口位置，确保洞口之间有足够的间距。
3. **设置最小板宽度**：在排布参数中设置合理的最小板宽度，自动过滤掉洞口之间过窄的板材。
4. **重复洞口检测**：系统在创建洞口时会自动检测重复洞口（位置和尺寸容差 10mm 内），跳过重复的洞口并输出提示。

### 7.8.5 拾取矩形时提示"不是矩形"

**问题描述**：使用"拾取矩形"方式创建洞口时，系统提示所选多段线"不是矩形"。

**原因分析**：

- 多段线的顶点数量不是 4 个。
- 多段线的某些边不是直线段（包含弧线段）。
- 多段线的相邻边不垂直（角度偏差超过直角容差）。
- 多段线未闭合。

**解决方法**：

1. **检查顶点数**：使用 `LIST` 命令查看多段线的顶点数量，确保恰好为 4 个有效顶点。
2. **检查闭合性**：使用 `PEDIT` 命令的 `Close` 选项确保多段线已闭合。
3. **调整直角容差**：在创建对话框中增大"直角容差"值（最大 5°），允许更大的角度偏差。系统对近似矩形会自动纠偏。
4. **使用异形窗**：如果多段线确实不是矩形（如梯形、平行四边形），请使用异形窗功能创建多边形洞口。

### 7.8.6 异形窗创建失败

**问题描述**：使用"多段线转异形窗"命令时创建失败。

**原因分析**：

- 选择的多段线未闭合。
- 选择的多段线自相交。

**解决方法**：

1. 确保多段线已闭合（使用 `PEDIT` → `Close` 或确保首尾点重合）。
2. 检查多段线是否存在自相交的情况，如有则修正。
3. 确保选择的是 `LWPOLYLINE`（轻量多段线）类型。

### 7.8.7 屋面坡度输入格式错误

**问题描述**：在"定义屋面坡度"对话框中输入坡度值后，"确定"按钮始终不可用。

**原因分析**：输入的格式不符合 `a/b` 的要求。

**解决方法**：

1. 确保输入格式为 `数字/数字`，如 `5/100`、`1/10`。
2. 分子和分母均支持整数和小数，如 `2.5/100`。
3. 分母不能为 0。
4. 不要输入百分号（%）或度数符号（°），屋面坡度定义仅支持比例格式。
5. 不要输入 `Slope:` 等前缀，对话框会自动添加前缀。

### 7.8.8 编辑技巧与快捷键

**技巧 1：善用预选功能**

在启动编辑矩形洞口命令之前，可以先在图纸中选中需要编辑的洞口实体，然后启动命令。系统将自动识别预选的洞口，跳过选择步骤直接进入编辑对话框。

**技巧 2：属性面板快速切换**

选中洞口后，属性面板会自动显示洞口的所有属性。您可以通过 Tab 键在各属性字段之间快速切换，提高编辑效率。

**技巧 3：批量创建洞口**

使用"拾取矩形"方式可以一次性将图纸中的多个矩形多段线批量转换为洞口，非常适合从建筑专业图纸中快速提取门窗位置。操作步骤：

1. 从建筑图纸中复制门窗的矩形轮廓线到当前图纸。
2. 启动创建洞口命令，选择"拾取矩形"方式。
3. 框选所有门窗矩形。
4. 系统自动验证、去重并批量创建洞口。

**技巧 4：利用图块包围盒创建洞口**

当建筑图纸中的门窗以图块形式存在时，可以使用"拾取图块"方式快速创建洞口：

1. 启动创建洞口命令，选择"拾取图块"方式。
2. 选择门窗图块。
3. 系统自动计算图块的包围盒并创建洞口。
4. 勾选"清理源图元"可自动删除原始图块。

**技巧 5：零散实体分组创建洞口**

当门窗位置由多个零散实体（如线条、文字标注等）表示时，可以使用"拾取小实体"方式：

1. 启动创建洞口命令，选择"拾取小实体"方式。
2. 框选门窗区域的所有相关实体。
3. 系统根据实体间距自动分组（默认容差 50mm），每组生成一个洞口。
4. 如果分组结果不理想，可以调整"分组容差"值后重试。

**技巧 6：洞口类型持久化**

系统会记住您在每种位置（墙面/屋面/楼承板）上次选择的洞口类型。下次启动对应位置的洞口命令时，对话框将自动选中上次的洞口类型，无需重复选择。

**技巧 7：坡度标注的连续插入**

定义屋面坡度时，确认坡度值后可以连续在多个位置插入坡度标注。这对于双坡屋面特别有用——您可以在屋脊两侧分别插入相同坡度值的标注，无需重复输入。
