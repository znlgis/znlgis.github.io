# 第3章 客户端使用指南

本章将带您从零开始，全面了解闪电围护（LightningCAD）客户端的各项功能。无论您是首次接触还是希望深入了解某个具体模块，都可以按照章节顺序逐步阅读。

> **产品官网**：[https://shandianweihu.com/](https://shandianweihu.com/) — 获取最新产品信息、版本更新和下载安装包。

## 3.1 客户端主界面概览

启动闪电围护客户端后，您将看到一个采用现代圆角卡片风格设计的主窗口。窗口默认居中显示，尺寸为 820×600 像素，整体风格基于 **Syncfusion Windows11** 主题，支持亮色与暗色两种外观。

### 3.1.1 主窗口布局

主窗口从上到下分为三个区域：

| 区域 | 说明 |
|------|------|
| **标题栏**（顶部） | 左侧显示产品 Logo 和名称"闪电围护"及当前版本号；右侧显示服务器连接状态指示灯、最小化按钮和关闭按钮 |
| **功能标签页**（中部） | 以水平标签页（Tab）组织各功能模块，点击标签即可切换 |
| **状态栏**（底部） | 左侧显示服务器连接状态和授权信息提示；右侧显示版本更新状态和检查更新入口 |

### 3.1.2 功能标签页

主窗口中部包含以下标签页：

| 标签页 | 说明 |
|--------|------|
| **▷ 软件启动**（默认页） | 展示可用的 CAD 平台卡片（AutoCAD / Revit / Rhinoceros），可一键启动 CAD 并自动加载插件 |
| **🕑 最近项目** | 快速访问近期打开的工程项目（功能开发中） |
| **📁 公共库** | 团队共享的围护构件公共库管理（功能开发中） |
| **⚙ 设置** | 基础设置、主题外观、关闭行为、CAD 插件注册管理、运维工具入口 |
| **👤 个人中心** | 查看和修改个人资料、修改密码、换绑邮箱（仅邮箱登录时显示） |

### 3.1.3 标题栏

- **Logo 与版本号**：标题栏左侧展示闪电围护的品牌 Logo 和当前客户端版本号（如 `v1.2.3`）。
- **服务器状态指示灯**：标题栏右侧有一个小圆点指示灯：
  - 🟢 **绿色**：服务器已连接，网络正常。
  - 🔴 **红色**：服务器未连接，请检查网络。
- **最小化按钮**（`—`）：将窗口最小化到任务栏。
- **关闭按钮**（`✕`）：根据您在"设置"中配置的"关闭按钮行为"执行对应操作（详见 3.1.5）。

> **提示**：标题栏支持鼠标拖拽移动窗口。双击标题栏不会触发最大化（窗口已固定为可最小化模式）。

### 3.1.4 系统托盘图标

客户端启动后，系统托盘（屏幕右下角通知区域）会出现闪电围护的图标。将鼠标悬停在图标上，会显示"闪电围护 LightningCAD"的提示文字。

**托盘右键菜单**包含以下选项：

| 菜单项 | 功能 |
|--------|------|
| **显示主界面** | 恢复并激活主窗口（如果窗口被隐藏或最小化） |
| **退出** | 完全退出闪电围护客户端 |

**快捷操作**：双击托盘图标也可以直接显示/激活主窗口。

### 3.1.5 最小化行为

您可以在"设置"页面中配置点击关闭按钮（`✕`）时的行为：

| 选项 | 说明 |
|------|------|
| **最小化到托盘**（默认） | 点击关闭按钮后，窗口隐藏到系统托盘，程序继续在后台运行。您可以通过托盘图标重新打开主界面。 |
| **直接退出** | 点击关闭按钮后，程序完全退出。 |

> **提示**：无论选择哪种模式，最小化按钮（`—`）始终只是将窗口最小化到任务栏，不会隐藏到托盘。

## 3.2 用户注册

如果您还没有闪电围护账号，可以通过邮箱注册一个新账号。

### 3.2.1 注册流程

1. **打开注册窗口**
   - 在登录窗口中，找到并点击注册入口，系统将弹出"注册新账号"窗口。

2. **输入邮箱地址**
   - 在"邮箱"输入框中，填写您的有效邮箱地址。
   - 系统会自动验证邮箱格式是否正确（需包含 `@` 符号和有效的域名）。

3. **发送验证码**
   - 点击邮箱输入框右侧的 **"发送验证码"** 按钮。
   - 系统会向您的邮箱发送一封包含验证码的邮件。
   - 点击发送后，按钮将进入 **60 秒倒计时**（显示为"60s 后重发"、"59s 后重发"...），倒计时结束前无法重复发送。
   - 倒计时结束后，按钮文字变为 **"重新发送"**，您可以再次点击发送新的验证码。

4. **输入验证码**
   - 登录您的邮箱，查收闪电围护发送的验证码邮件。
   - 将收到的验证码填入"邮箱验证码"输入框。

5. **设置密码**
   - 在"密码"输入框中设置您的登录密码。
   - 在"确认密码"输入框中再次输入相同的密码，确保两次输入一致。
   - **密码要求**：长度不得少于 **6 位**。
   - **安全说明**：您的密码在传输过程中采用 **SM2 国密算法** 加密，确保通信安全。

6. **设置昵称（可选）**
   - 在"昵称"输入框中填写您希望展示的名称。此项为选填，注册后也可以在个人中心修改。

7. **完成注册**
   - 点击 **"注 册"** 按钮提交注册信息。
   - 注册成功后，系统会显示绿色提示"注册成功！即将返回登录页。"，并在 1.5 秒后自动关闭注册窗口，返回登录界面。

### 3.2.2 注意事项

- **验证码有效期**：邮箱验证码具有一定的时效性，请在有效期内完成注册。如果验证码过期，请重新发送。
- **邮箱准确性**：请确保填写的邮箱地址正确且可正常接收邮件，否则将无法收到验证码。
- **密码安全**：建议使用包含字母和数字的组合密码，提高账号安全性。
- **注册失败排查**：如果注册失败，系统会在窗口中显示红色错误提示信息，请根据提示检查并修正输入内容后重试。

## 3.3 用户登录

闪电围护提供两种登录方式：**邮箱登录**和 **QQ 群登录**。启动客户端后，如果之前没有保存有效的登录凭据，系统将自动显示登录窗口。

### 3.3.1 邮箱登录

这是最常用的登录方式，适用于通过邮箱注册的用户。

#### 登录步骤

1. **输入账号（邮箱）**
   - 在"邮箱"输入框中输入您注册时使用的邮箱地址。

2. **输入密码**
   - 在"密码"输入框中输入您的登录密码。
   - 点击密码框右侧的 **眼睛图标** 可以切换密码的显示/隐藏状态，方便确认输入内容。

3. **输入图形验证码**
   - 验证码区域会显示一张 GIF 动画验证码图片。
   - 在左侧输入框中输入您在图片中看到的字符。
   - 如果验证码看不清楚，**点击验证码图片**即可刷新获取新的验证码。

4. **点击登录**
   - 点击 **"登 录"** 按钮。
   - 登录过程中，右侧区域会显示半透明遮罩和"登录中..."的进度提示。
   - 登录成功后，系统将自动打开主窗口。

#### 记住账号功能

- 勾选登录表单中的 **"记住账号"** 复选框后，系统将保存您的邮箱和加密密码。
- 下次启动客户端时，系统会自动填充已保存的账号和密码，无需手动输入。
- **安全机制**：保存的密码经过双重加密保护：
  - 第一层：SM2 国密算法加密密码内容。
  - 第二层：Windows DPAPI（数据保护接口）加密存储，确保仅在当前计算机的当前用户下才能解密读取。
- 如果不勾选"记住账号"，则每次启动都需要手动输入账号和密码。

#### Token 自动管理

- 登录成功后，服务器会返回 AccessToken 和 RefreshToken。
- 客户端会在本地保存这些令牌（Token），下次启动时自动尝试刷新 Token。
- 如果 Token 刷新成功，将直接进入主窗口，无需再次输入账号密码。
- 如果 Token 已过期或刷新失败，系统会自动跳转到登录窗口，请重新登录。

#### 忘记密码

如果您忘记了登录密码，可以通过"重置密码"功能找回：

1. 在登录窗口中进入"重置密码"窗口。
2. 输入您的注册邮箱。
3. 点击"发送验证码"，查收邮箱中的验证码并填入。
4. 设置新密码（不少于 6 位）并确认。
5. 点击"重 置 密 码"按钮完成重置。
6. 重置成功后将自动返回登录页面，使用新密码登录即可。

### 3.3.2 QQ 群登录

QQ 群登录是面向特定授权 QQ 群成员的便捷登录方式，无需注册邮箱账号。

#### 登录步骤

1. **点击 QQ 群登录**
   - 在登录窗口的"其他登录方式"区域，点击 **"QQ群登录"** 按钮。
   - 系统将弹出"QQ群登录"窗口。

2. **WebView2 扫码登录**
   - 窗口中会加载 QQ 登录页面（基于 WebView2 控件）。
   - 请使用 **手机 QQ 扫描页面上的二维码**，或在页面中直接输入 QQ 账号密码完成登录。
   - 页面状态提示："请使用手机 QQ 扫码登录，或输入 QQ 账号密码"。

3. **验证群成员身份**
   - QQ 登录完成后，系统会自动提取登录凭据并验证您的群成员身份。
   - **重要**：您必须是闪电围护授权的 QQ 群成员才能通过验证。如果您不在授权群内，验证将失败并显示错误提示。

4. **登录成功**
   - 验证通过后，系统将记录您的 QQ 群号和群名称信息。
   - 自动打开主窗口，登录窗口和 QQ 登录窗口将自动关闭。

#### QQ 群登录的特殊说明

- QQ 群登录不使用传统的 AccessToken，而是通过群成员身份进行授权。
- 客户端会每 **60 秒** 定期刷新登录状态凭证，以向 CAD 插件表明客户端处于在线状态。
- QQ 群登录时，"个人中心"标签页将自动隐藏（因为 QQ 登录不涉及邮箱账号的个人资料管理）。
- 退出客户端时，系统会自动清除 QQ 登录的共享凭证文件。

#### 登录失败处理

- 如果验证失败，窗口底部会显示红色错误信息。
- 您可以点击 **"重新登录"** 按钮重新加载 QQ 登录页面。
- 点击 **"取消"** 按钮可关闭 QQ 登录窗口，返回邮箱登录界面。

## 3.4 个人中心

个人中心提供了账号信息管理功能，包括查看和修改个人资料、修改密码、换绑邮箱等。

> **注意**：个人中心仅在 **邮箱登录** 模式下可见。如果您是通过 QQ 群登录的，此标签页将自动隐藏。

个人中心采用左侧导航 + 右侧内容的布局方式，左侧导航栏包含三个功能页签以及底部的操作按钮。

### 3.4.1 基本资料

进入"个人中心"后，默认显示"基本资料"页面。

#### 查看资料

- **邮箱**：以脱敏方式显示当前绑定的邮箱地址（如 `u***@example.com`）。
- **昵称**：显示当前设置的昵称，可直接在输入框中修改。

#### 上传头像

- 点击左侧的 **圆形头像区域**，系统将弹出文件选择对话框。
- 支持的图片格式：`JPG`、`JPEG`、`PNG`。
- 选择图片后，系统将自动上传并更新头像显示。
- 上传成功后会显示"头像上传成功"的绿色提示。

#### 保存资料

- 修改昵称后，点击 **"保存资料"** 按钮提交更改。
- 保存成功后，按钮右侧会显示绿色的"保存成功"提示。

### 3.4.2 修改密码

点击左侧导航栏的"修改密码"进入密码修改页面。

#### 操作步骤

1. 在"当前密码"输入框中输入您正在使用的密码。
2. 在"新密码"输入框中输入新的密码（不少于 **6 位**）。
3. 在"确认新密码"输入框中再次输入新密码，确保两次输入一致。
4. 点击 **"修改密码"** 按钮。

#### 安全说明

- 修改密码时，旧密码和新密码均采用 **SM2 国密算法** 加密后传输至服务器，确保传输过程安全。
- 密码修改成功后，系统会显示"密码修改成功，即将跳转到登录页"的提示，并在 1.2 秒后自动跳转到登录窗口。
- 您需要使用新密码重新登录。

### 3.4.3 修改邮箱（换绑邮箱）

点击左侧导航栏的"修改邮箱"进入邮箱换绑页面。

#### 操作步骤

1. **身份验证**：在"当前密码（身份验证）"输入框中输入当前密码，用于确认您的身份。
2. **输入新邮箱**：在"新邮箱"输入框中填写您希望绑定的新邮箱地址。
3. **发送验证码**：点击"发送验证码"按钮，系统将向新邮箱发送验证码。按钮同样有 60 秒倒计时。
4. **输入验证码**：查收新邮箱中的验证码并填入"验证码"输入框。
5. **确认更换**：点击 **"确认更换"** 按钮完成邮箱换绑。

#### 注意事项

- 换绑邮箱需要同时验证当前密码和新邮箱的验证码，双重保障账号安全。
- 换绑成功后，系统会自动将"记住账号"中保存的邮箱地址更新为新邮箱。
- 邮箱修改成功后，系统将自动跳转到登录窗口，请使用新邮箱地址登录。

### 3.4.4 注销登录

在个人中心左侧导航栏的底部，点击 **"注销登录"** 按钮：

- 系统会弹出确认对话框："确定要注销登录吗？"
- 点击"是"后，系统将清除当前的登录凭据（AccessToken 和 RefreshToken），并跳转到登录窗口。
- 如果是 QQ 群登录状态，还会同时清除 QQ 登录的共享凭证文件。

### 3.4.5 退出系统

在个人中心左侧导航栏的底部，点击红色的 **"退出系统"** 按钮：

- 系统会弹出确认对话框："确定要退出系统吗？"
- 点击"是"后，客户端将完全退出。

> **注意**："注销登录"只是退出当前账号并返回登录页面，程序仍在运行；"退出系统"则是完全关闭客户端程序。

## 3.5 CAD 管理

闪电围护客户端的核心功能之一是管理和启动 CAD 软件，并自动加载围护设计插件。

### 3.5.1 CAD 版本检测

客户端启动时会自动扫描 Windows 注册表，检测您计算机上已安装的 CAD 软件。

**当前支持的 CAD 平台**：

| CAD 平台 | 支持版本 |
|----------|----------|
| **AutoCAD** | 2019、2021、2025、2027（版本号 R23.x ~ R25.x） |
| **中望 CAD（ZWCAD）** | 2022 及以上版本 |

检测完成后，所有发现的 CAD 版本将显示在 **"⚙ 设置"** 标签页的"插件启动设置"区域中。每个 CAD 版本以独立卡片的形式展示，包含以下信息：

- **显示名称**：如"AutoCAD 2019"或"中望 CAD 2022"。
- **安装路径**：CAD 可执行文件的完整路径（过长时自动截断，鼠标悬停可查看完整路径）。
- **自启动开关**：控制是否为该 CAD 版本注册插件。
- **设为主页**：选择哪个 CAD 版本作为主页默认启动项。

> **提示**：如果未检测到任何已安装的 CAD 版本，设置页面会显示"未检测到支持的 CAD 版本"的提示。在"软件启动"页面也会显示相应的红色警告信息。

### 3.5.2 插件注册开关

在每个 CAD 版本卡片的右侧，有一个 **开关按钮（Toggle）**：

- **开启（勾选）**：系统将向对应 CAD 的注册表中写入插件注册信息，使 CAD 在启动时能够自动识别和加载闪电围护插件。注册过程包括：
  - 在 CAD 的 `Applications` 注册表项中创建 `LtLauncher` 子项。
  - 配置插件 DLL 加载路径（`LOADER`）。
  - 设置加载控制参数（`LOADCTRLS`、`MANAGED`）。
  - 将插件目录添加到 CAD 的搜索路径和信任路径中。
  - 添加字体文件和打印样式文件路径。
  - 复制 CUI 菜单文件到用户配置目录。

- **关闭（取消勾选）**：系统将从注册表中移除插件注册信息，CAD 启动时将不再自动加载闪电围护插件。

**插件状态指示**：

- 开关为 **开启状态**（绿色/选中）：表示插件已注册到该 CAD 版本，可以正常使用。
- 开关为 **关闭状态**（灰色/未选中）：表示插件尚未注册，CAD 启动后不会加载围护设计功能。

### 3.5.3 设置主页 CAD

如果您安装了多个 CAD 版本，可以通过每个卡片上的 **"设为主页"** 单选按钮来选择哪个版本作为主页默认显示的 CAD。

- 被设为主页的 CAD 版本将显示在"软件启动"标签页的顶部卡片中。
- 主页 CAD 卡片展示的信息包括：CAD 名称、功能标签（围护设计、参数化制图、公共库、工程量统计）以及"启动"按钮。

### 3.5.4 启动 CAD

在"软件启动"标签页中，找到主页 CAD 卡片，点击右侧的 **"▶ 启动"** 按钮即可启动 CAD。

#### 启动流程

点击启动按钮后，系统将按以下步骤执行：

1. **验证 CAD 可执行文件**
   - 检查注册表中记录的 CAD 安装路径是否存在。
   - 如果文件不存在，将弹出错误提示。

2. **确保 CAD 路径配置**
   - 自动检查并修复 CAD 注册表中的搜索路径、信任路径、字体路径和打印样式路径。
   - 确保 CUI 菜单文件已正确部署到用户配置目录。

3. **生成插件加载脚本（.scr）**
   - 系统会在用户配置目录下创建一个 `.scr` 脚本文件（如 `Lt_AutoCAD_R23_0_Loader.scr`）。
   - 脚本内容为 `netload "插件DLL路径"`，用于在 CAD 启动后自动执行 .NET 程序集加载。

4. **启动 CAD 进程**
   - 使用命令行参数启动 CAD：
     ```
     /product AutoCAD /language "zh-CN" /b "脚本路径.scr"
     ```
   - CAD 启动后会自动执行脚本中的 `netload` 命令，加载闪电围护插件。

5. **CUI 菜单自动注入**
   - 插件加载成功后，CAD 界面中将自动出现闪电围护的自定义菜单和工具栏（通过 CUI 文件实现）。

> **提示**：如果脚本创建失败，系统会弹出警告提示，CAD 将在不加载插件的情况下启动。您可以稍后在 CAD 中手动使用 `NETLOAD` 命令加载插件。

### 3.5.5 未来支持的 CAD 平台

在"软件启动"页面中还展示了以下即将支持的平台（按钮显示"敬请期待"）：

| 平台 | 定位 | 核心能力 |

## 3.7 自动更新

闪电围护内置了自动更新机制，通过独立的更新宿主进程（`Fs.Lt.UpdateHost`）实现全自动静默更新，确保您始终使用最新版本的客户端。

### 3.7.1 启动时自动检测

- 每次启动客户端时，系统会自动在后台检查是否有新版本。
- 更新配置由更新通道服务管理，检查过程快速且不影响正常使用。
- 如果当前已是最新版本，不会有任何弹窗打扰。

### 3.7.2 发现新版本

当检测到新版本时，根据更新类型的不同，处理方式有所区别：

| 更新类型 | 行为 |
|----------|------|
| **可选更新** | 弹出对话框询问"检测到闪电围护新版本，是否开始更新？"，您可以选择"确定"开始更新或"取消"跳过。同时支持"稍后提醒"和"跳过此版本"选项。 |
| **强制更新** | 弹出提示"检测到闪电围护重要更新，系统将自动开始更新。"，不提供跳过或稍后选项，必须更新后才能继续使用。 |

### 3.7.3 CAD 进程检测

- 在开始下载更新之前，系统会检测是否有 CAD 进程（AutoCAD / 中望 CAD）正在运行。
- 如果检测到 CAD 正在运行：
  - **可选更新**：提示"检测到 CAD 正在运行，请关闭后再点击确定继续更新"，您可以选择取消更新。
  - **强制更新**：提示"本次为强制更新，必须关闭 CAD 才能继续"，请保存工作并关闭 CAD 后点击确定。

### 3.7.4 更新流程

确认更新后，系统将启动独立的 `Fs.Lt.UpdateHost` 更新宿主进程，按以下步骤自动执行：

1. **读取更新请求**：验证发布描述（Release Descriptor）的完整性和合法性。
2. **等待客户端退出**：更新宿主等待闪电围护客户端进程完全退出。
3. **下载 MSI 安装包**：根据当前版本自动选择差异包或全量包，最大化减少下载量。
4. **执行安装**：静默调用 MSI 安装程序，完成文件替换和注册表更新。
5. **完整性验证**：安装完成后，验证关键文件哈希值，确保安装包未被篡改或损坏。
6. **自动重启**：更新完成后自动重启闪电围护客户端。

### 3.7.5 状态栏版本信息

状态栏会实时显示当前的版本和更新状态：

| 显示内容 | 含义 |
|----------|------|
| `已是最新 v1.2.3` | 当前版本已是最新，无需更新 |
| `发现新版本 v1.3.0` + `立即更新` | 有新版本可用，点击可开始更新 |

## 3.8 心跳检测与在线状态

闪电围护客户端内置了心跳检测服务，用于持续监控与服务端的连接状态。

### 3.8.1 工作原理

- **检测频率**：每 **5 分钟** 自动向服务端发送一次心跳请求。
- **首次启动**：客户端启动后会立即执行一次心跳检测，无需等待 5 分钟。
- **防重叠机制**：如果上一次心跳请求尚未完成，新的请求会被自动跳过，避免网络拥堵。

### 3.8.2 在线状态指示

心跳检测的结果会实时反映在界面上：

- **标题栏状态灯**：
  - 🟢 绿色圆点 + "服务器已连接"：心跳检测成功，Token 有效，网络连通。
  - 🔴 红色圆点 + "服务器未连接"：心跳检测失败，可能是网络中断、服务端不可达或 Token 已失效。

- **底部状态栏**：同样显示服务器连接状态文字。

### 3.8.3 网络连通性检测

心跳检测同时验证了以下两个方面：

1. **网络连通性**：客户端能否正常访问服务端接口。
2. **Token 有效性**：当前保存的 AccessToken 是否仍然有效（未过期、未被吊销）。

当检测到离线状态时，请检查：
- 计算机的网络连接是否正常。
- 防火墙或安全软件是否阻止了客户端的网络访问。
- 如果网络正常但仍显示离线，可能是 Token 已失效，请尝试注销后重新登录。

## 3.12 常见问题与故障排除

### Q1：启动客户端后显示"服务器未连接"

**可能原因**：
- 网络连接异常。
- 防火墙或安全软件阻止了客户端的网络访问。
- 服务端暂时不可用。

**解决方法**：
1. 检查计算机的网络连接是否正常。
2. 检查防火墙设置，确保闪电围护客户端被允许访问网络。
4. 等待几分钟后观察状态是否恢复（心跳检测会每 5 分钟自动重试）。

### Q2：CAD 启动后没有加载围护设计插件

**可能原因**：
- 对应 CAD 版本的插件注册开关未开启。
- 插件 DLL 文件缺失或损坏。
- CAD 的信任路径未正确配置。

**解决方法**：
1. 进入"设置"页面，确认对应 CAD 版本的"自启动"开关已开启。
2. 关闭 CAD，重新从客户端的"软件启动"页面启动 CAD。
3. 如果问题仍然存在，可以在 CAD 命令行中手动输入 `NETLOAD`，手动加载插件 DLL 文件。

### Q3：登录时提示"验证码错误"

**解决方法**：
1. 点击验证码图片刷新获取新的验证码。
2. 仔细辨认验证码中的字符（注意区分大小写、数字 0 和字母 O 等）。
3. 确保在验证码有效期内提交登录。

### Q4：QQ 群登录提示"验证失败"

**可能原因**：
- 您不是授权 QQ 群的成员。
- QQ 登录页面未完全加载就进行了验证。
- 登录信息不完整（缺少 skey Cookie）。

**解决方法**：
1. 确认您的 QQ 账号已加入闪电围护授权的 QQ 群。
2. 确保在 WebView2 页面中已完全完成 QQ 登录（能看到 QQ 空间/群页面）。
3. 点击"重新登录"按钮重试。

### Q5：更新时提示"CAD 正在运行"

**解决方法**：
1. 保存当前 CAD 中的所有工作。
2. 关闭所有正在运行的 CAD 窗口。
3. 在更新对话框中点击"确定"继续更新。
