# 第十二章：PCB布局设计进阶

## 12.1 多层板设计

原理图确定了电气连接，PCB 决定这些连接在物理上怎么落地。这一章处理多层板、电源、信号、散热、机械配合这几类问题。它们的共同点是在单面板或低频小板上可以忽略，到了高速、大电流或小体积的场合，任何一项做错都只能通过改板解决。下面的顺序按设计流程走：先定层叠，再谈电源与信号，最后落到布线与复审。

### 12.1.1 层叠结构

```
四层板典型叠层：
Layer 1 - F.Cu    : 信号/元器件
Layer 2 - In1.Cu  : 地平面 (GND)
Layer 3 - In2.Cu  : 电源平面 (VCC)
Layer 4 - B.Cu    : 信号/元器件

六层板典型叠层：
Layer 1 - F.Cu    : 信号
Layer 2 - In1.Cu  : 地平面
Layer 3 - In2.Cu  : 信号
Layer 4 - In3.Cu  : 信号
Layer 5 - In4.Cu  : 电源平面
Layer 6 - B.Cu    : 信号
```

四层板的经典叠层是「信号—地—电源—信号」：两个内层构成完整参考平面，两个外层信号都能找到相邻的参考层，回流路径短。层叠一旦定下，阻抗计算、过孔结构、制造成本都跟着定，改层叠等于改板，所以这一步要在布局开始前冻结。六层板把两个信号层放到内层，是为了让高速信号在两层地/电源之间获得更好的屏蔽，代价是内层走线要打过孔换层，过孔带来的阻抗不连续和损耗都要计入。需要说明的是，KiCad 里的层序只是逻辑顺序，真正的物理叠层和介质厚度由板厂按阻抗要求实现，所以叠层与阻抗要求必须写进制板说明，不能只在工程文件里设一下。

### 12.1.2 配置多层板

```
Board Setup → Board Stackup：

1. 设置铜层数量
2. 配置各层属性：
   - 层名称
   - 层类型（信号/电源/混合）
   - 铜厚度
3. 配置绝缘层：
   - 材料类型
   - 厚度
   - 介电常数
```

Board Setup 的 Board Stackup 面板里可以增减铜层、给每层选类型、填写铜厚与介质参数。三个容易出错的点：介电常数和介质厚度直接决定阻抗，填之前先问板厂要标准叠层表，直接用他们的参数比自算可靠；层类型用于标明这一层的用途，生成制造文件时会带上对应信息，但不要指望它自动禁止走线——布线约束仍然要靠设计规则实现；各层厚度相加要等于目标板厚，常见是 1.6mm，填完在面板上核对一遍总厚度。层数改变后，原有的设计规则、覆铜和布线不会自动迁移，改之前先提交一次版本。

### 12.1.3 层分配策略

```
信号层分配原则：
- 高速信号相邻参考平面
- 敏感信号与干扰源分层
- 差分对使用同一层

电源层设计：
- 完整的地平面
- 分割电源区域
- 避免大面积开窗
```

信号层分配的原则可以概括成一句话：让每条重要走线都有完整、连续的参考平面，并且换层时回流有路可走。高速信号贴着参考平面走，换层处要在信号过孔旁边补地过孔，否则回流被迫绕行，形成环路天线；差分对在同一层内成对走，不要各自换层。电源层被分成多块时，分割缝不能从高速信号正下方穿过，因为跨缝等于参考平面断开。层分配阶段还要考虑制造：内层信号越多，板厂的对位与阻抗控制要求越高，报价也越高。

## 12.2 电源完整性设计

电源完整性问题表现为芯片端的电压跌落和噪声，根源是电源分布网络（PDN）的阻抗。目标只有一个：在芯片工作频段内，从稳压器到芯片引脚看到的阻抗足够低。

### 12.2.1 电源分布网络

```
PDN设计要点：
1. 低阻抗路径
2. 充足的去耦电容
3. 合理的过孔密度
4. 避免形成天线

去耦电容放置：
- 靠近IC电源引脚
- 多容值组合
- 短而宽的连接
```

PDN 的四个要点各有对应做法。低阻抗路径靠铜厚、线宽和并联层数，大电流支路要按载流计算线宽，不按信号线习惯给 0.2mm。去耦电容分频段工作：10uF 级管低频和中频，0.1uF 级管高频，MLCC 的等效串联电感决定了它在高频段还能不能起作用，所以电容要靠近引脚、回路面积要小，引线越长效果越差。过孔密度说的是电源过孔的电感，单孔约 1nH 量级，电流突变时压降就出在这里，多个并联才压得下来。避免形成天线指的是长而细的铜带，它既是电感也是辐射体。还有一个常被忽略的因素是电容的直流偏压特性：X5R、X7R 在接近额定电压时容量下降明显，选型时要按实际工作电压看曲线，不能只看标称值。

### 12.2.2 电源覆铜设计

```
覆铜策略：
1. 使用覆铜而非走线
2. 避免细长的铜带
3. 添加足够的过孔
4. 保持参考完整

过孔阵列：
- 电源过孔密集布置
- 减小回路电感
- 改善热传导
```

电源用铜皮而不是走线，是因为铜皮截面大、阻抗低，还能顺带散热。要避免的是细长铜带：它电感大，电流变化时压降明显，形状上又接近天线。过孔阵列的作用是把多层铜皮并联起来，同时降低回路电感、改善导热，电源入口和芯片电源区都值得布置。覆铜与地平面要配合看：电源铜皮把地平面切碎，等于人为制造回流断点。最后用 DRC 的最小宽度、最小间距规则去检查孤岛和细颈，手工铺铜很容易在这些地方留下隐患。

## 12.3 信号完整性设计

信号完整性讨论的是走线上的波形失真与串扰。多数设计里，只要做到参考平面完整、阻抗受控、关键信号等长，问题就能控制住；真正需要仿真的是少数高速接口。

### 12.3.1 传输线设计

```
微带线（Microstrip）：
- 单层走线
- 参考下方地平面
- 计算阻抗

带状线（Stripline）：
- 内层走线
- 上下均有参考平面
- 更好的屏蔽效果
```

什么时候必须按传输线处理？经验判据是走线长度超过信号上升沿有效长度的六分之一左右。FR-4 中信号传播速度约 15cm/ns，上升沿 1ns 对应的临界长度大致在 2.5cm 量级，超过这个长度就该考虑端接和阻抗。微带线在外层，下方是地平面，阻抗随线宽增大而减小、随介质厚度增大而增大，制造简单、方便探测，缺点是损耗和辐射比内层大。带状线夹在两个参考平面之间，屏蔽好、损耗低，代价是需要更多层、过孔更多。两者都要求参考平面连续，跨分割的走线等于阻抗突变。

### 12.3.2 阻抗控制

```
阻抗计算参数：
- 走线宽度
- 铜厚度
- 介质厚度
- 介电常数

常见阻抗要求：
- USB: 90Ω差分
- HDMI: 100Ω差分
- DDR: 50Ω单端
```

阻抗由四个量共同决定：走线宽度、铜厚、介质厚度、介电常数。前三个是几何量，第四个是材料量，都在板厂的工艺控制范围内，所以阻抗不是画图时算完就结束，而是要写进制板说明由板厂调整。常见目标值：USB 2.0 差分 90Ω，HDMI 差分 100Ω，DDR 单端 50Ω。KiCad 里的做法是在 Board Setup 的 Net Classes 里定义线宽与间距，用 Custom Rules 给特定网络加约束，布线时按网络类生效，最后用 DRC 的阻抗/线宽规则复核。注意规则里填的线宽是设计值，板厂可能为了阻抗微调，最终以他们的工程确认单为准。

### 12.3.3 等长布线

```
等长布线应用：
- DDR数据/地址总线
- 并行总线
- 差分对

KiCad等长工具：
1. 选择需要等长的网络
2. 使用蛇形布线
3. 调整至目标长度
```

等长的目的是控制时序偏移。并行总线的数据与选通信号之间、差分对内部两根线之间，长度差会直接变成采样窗口的损失。DDR 的等长容差通常按单位间隔的百分比给出，具体数值看器件手册，不要凭经验套。KiCad 的操作路径是：先把需要等长的网络归到一个带长度约束的网络类，交互布线时用等长/蛇形工具调整，界面上会实时显示当前长度与目标容差。补长度用的蛇形段要均匀，折返间距至少三倍线宽，否则相邻段之间的耦合会让等长的收益打折；补长度应加在受扰小的位置，不要贴着连接器或晶振。

## 12.4 差分对布线

差分信号传的是两根线之间的电压差，共模噪声在接收端被抵消，所以抗干扰能力比单端强。代价是布线空间翻倍、间距和长度都要受控，走不好反而比单端更差。

### 12.4.1 差分对设计

```
差分对特点：
- 两根线承载互补信号
- 抗共模噪声
- 用于高速信号

设计要点：
- 保持线间距一致
- 等长布线
- 避免stub
```

差分对的三个要点：间距一致、等长、无 stub。间距变化会带来阻抗不连续，反射就在这些位置产生；长度不一致会把差分信号变成共模分量，既降低抗扰度也增加辐射；stub 包括过孔残桩、测试点、分叉，高速时都要避免。差分对并不需要一条专用的「回流线」，它需要的是完整的参考平面，参考平面一旦断开，两条线的回流都受影响，共模电流会找别的路径。

### 12.4.2 差分对布线操作

```
布线步骤：
1. 定义差分对
   Board Setup → Design Rules → Differential Pairs
   
2. 设置参数
   - 间距
   - 线宽
   - 最大非耦合长度
   
3. 使用差分对布线工具
   Route → Route Differential Pair
```

KiCad 里差分对在 Board Setup 的 Design Rules 中定义，网络名按固定后缀配对（常见的是 +/− 或 _P/_N），也可以在网络类里统一设定线宽与间距。布线时切到差分对模式，工具会一次带出两根线，转弯处自动保持间距。三个参数要设对：间距（gap）决定差分阻抗，线宽与单端阻抗相关，最大非耦合长度限制进出焊盘、过孔附近允许分开的距离。换层时两根线成对打孔，并在旁边补地过孔提供回流；进出连接器时保持两线对称，不要一根绕远一根走直。差分对内部的等长优先于对外部总线的等长。

## 12.5 散热设计

散热不是高速板才要考虑的问题。线性稳压器、功率 MOS、LED 驱动、电机驱动这类器件，热量如果出不去，结温会迅速逼近上限，表现为效率下降、保护动作甚至损坏。

### 12.5.1 热设计考虑

```
热管理策略：
1. 热焊盘设计
2. 散热过孔阵列
3. 铜皮散热
4. 外部散热器

热焊盘设计：
- 连接到内层或底层铜皮
- 多个散热过孔
- 与地平面连接
```

估算从功耗开始：线性稳压器的功耗是压降乘电流，开关器件的功耗主要是导通损耗与开关损耗。结温等于环境温度加上热阻乘功耗，热阻由封装、焊盘、铜皮、散热器串联构成，任何一环变大都会抬高结温。热焊盘的做法是把器件底部的散热焊盘通过多个过孔连到内层或底层铜皮，再与地平面相连，兼顾电气与散热。要提醒的是回流焊工艺：大面积散热焊盘吸热快，钢网开窗通常要分格处理，否则容易出现虚焊，具体开窗方式按板厂建议执行。

### 12.5.2 散热过孔

```
散热过孔设计：
- 孔径: 0.3-0.5mm
- 密度: 1-2mm间距
- 填充: 可选树脂填充
- 阵列: 均匀分布
```

散热过孔的常用参数是孔径 0.3-0.5mm、间距 1-2mm、均匀分布。数量比孔径更重要，因为单孔的热阻远大于铜皮本身，靠的是并联。有回流焊要求的板子通常选树脂填充或盖油塞孔，防止焊锡沿过孔流到底面造成漏焊；不填充时至少保证过孔不落在焊盘正中央。过孔阵列还应避开信号过孔和器件引脚，避免破坏焊盘周围的阻焊与铜平衡。

## 12.6 高级覆铜技术

覆铜在 KiCad 里是填充操作，不是电气连接：网络相同的铜皮连通，不同网络的铜皮按规则自动避让。覆铜的边界、优先级、避让间距都会影响最终效果，复杂板子上这部分需要专门管理。

### 12.6.1 覆铜优先级

```
多覆铜区域管理：
- 设置优先级数值
- 高优先级覆盖低优先级
- 用于电源岛设计
```

多个覆铜区域重叠时按优先级决定填充顺序，高优先级区域先铺，低优先级的自动避让。电源岛设计常用这个机制：先铺完整地平面，再铺各电源区域，让窄缝处的归属可预期。优先级设置不当的典型现象是某块铜皮被另一块挤掉，或者窄缝里的铜皮时有时无，导出 Gerber 前后看起来不一致。建议在覆铜完成后单独检查一遍铜皮连通性，用高亮网络的方式确认没有孤立铜岛。

### 12.6.2 隔离区域

```
使用规则区域（Rule Area）：
- 禁止走线区域
- 禁止覆铜区域
- 禁止过孔区域

应用场景：
- 天线区域隔离
- 机械避让
- EMI敏感区域
```

规则区域（Rule Area）可以设置禁止走线、禁止过孔、禁止覆铜、禁止元件，用途比名字听起来广：天线净空区、机械避让区、隔离电源的爬电距离、EMI 敏感区都能用它划出来。要记住规则区域只是设计约束，不提供电气隔离，也不等于屏蔽罩；安规要求的爬电距离和电气间隙要按工作电压查表确定数值，再用规则区域约束布局。规则区域画完之后用 DRC 验证一遍，确认禁止项确实生效。

## 12.7 机械集成

PCB 最终要装进外壳、固定在设备里。机械问题在电气设计阶段看不出来，等到装配才发现孔位不对、连接器被挡住、电容顶到上盖，返工成本很高。所以机械约束要在布局开始前就拿到。

### 12.7.1 安装孔设计

```
安装孔类型：
- 电镀孔（接地）
- 非电镀孔（绝缘）

设计要点：
- 合适的孔径
- 适当的焊盘/禁区
- 考虑公差
```

安装孔分两类：电镀孔通常接地，作用是屏蔽、泄放静电、结构接地；非电镀孔用于需要绝缘的安装位置，孔壁不导电。孔径要按螺钉规格留间隙，M3 螺钉的过孔一般在 3.2mm 左右，具体取决于装配方式和公差；焊盘或禁布区要覆盖螺钉头或垫圈直径，避免装配时压到走线。金属外壳的场合还要注意安装孔附近不要有裸露铜箔，防止螺钉或工具造成短路。

### 12.7.2 外壳配合

```
外壳集成考虑：
1. 板子外形与外壳匹配
2. 连接器位置
3. 高度限制
4. 通风散热
5. 装配工艺
```

外壳配合要确认五件事：板框（Edge.Cuts）与外壳内腔匹配，连接器开口位置对准，高度方向上电容和散热器不顶盖，通风孔与发热器件位置对应，装配顺序可行（螺丝能否伸进去、板子能否装进去）。可行的流程是先拿到外壳的关键尺寸或 3D 模型，再定板框与连接器位置，最后用 KiCad 的 3D 查看器把板子与外壳模型叠起来检查干涉。没有外壳模型时，至少把限高区域在板框层标注出来并和结构工程师确认。

## 12.8 设计复审

复审是投板前的最后一道关口。多层板打样一次的成本和周期都不低，复审清单的作用是把能提前发现的问题挡在投板之前。

### 12.8.1 复审清单

```
布局复审：
□ 元器件摆放合理
□ 信号流向清晰
□ 热管理考虑
□ 机械配合

布线复审：
□ 关键信号处理
□ 电源完整性
□ 等长/阻抗控制
□ 过孔使用合理

制造复审：
□ 符合制造规则
□ 丝印清晰
□ 测试点充足
□ 文件完整
```

清单按三个阶段分组。布局阶段看摆放与流向：信号是否从输入到输出单向流动、功率器件与敏感器件是否分开、发热器件是否靠近板边或散热结构、连接器是否便于插拔。布线阶段看关键信号与完整性：高速与差分对是否按规则走完、参考平面是否连续、电源路径是否满足载流、过孔是否合理、等长与阻抗是否达标。制造阶段看可生产性：DRC 全绿、丝印不压焊盘、测试点可探、Gerber 与钻孔文件齐全。检查方法上，DRC 只能覆盖规则能表达的问题，铺铜孤岛、丝印遮挡、装配干涉仍然要靠人眼和 3D 视图过一遍，导出 Gerber 后用独立查看器再核对一次层数和钻孔。

## 12.9 本章小结

本章介绍了PCB布局设计的进阶内容：

1. **多层板设计**：掌握了多层板叠层和配置。
2. **电源完整性**：了解了PDN设计和去耦策略。
3. **信号完整性**：学会了传输线和阻抗控制。
4. **差分对布线**：掌握了差分对设计技术。
5. **散热设计**：了解了热管理方法。
6. **高级覆铜**：学会了复杂覆铜设计。
7. **机械集成**：了解了与机械设计的配合。

通过本章学习，读者可以设计更复杂的多层PCB。

多层板设计的核心是权衡：层数换信号质量与成本，铜皮换阻抗与散热，规则换可制造性。这些权衡没有统一答案，取决于产品定位、批量与预算。把每次改板的原因记下来，下一版就能少走一段弯路。
