# 第五章：基础绘图工具

## 5.1 绘图基础概念

### 5.1.1 实体类型

QCAD支持多种基本几何实体：

| 实体类型 | 说明 | 应用场景 |
|----------|------|----------|
| 点 (Point) | 几何点 | 参考点、定位标记 |
| 直线 (Line) | 两点间的直线段 | 边界、轮廓 |
| 圆弧 (Arc) | 圆的一部分 | 圆角、曲线连接 |
| 圆 (Circle) | 完整的圆 | 孔、圆柱截面 |
| 椭圆 (Ellipse) | 椭圆或椭圆弧 | 特殊形状 |
| 多段线 (Polyline) | 连续的线段和弧段 | 复杂轮廓 |
| 样条曲线 (Spline) | 光滑曲线 | 自由曲线 |
| 矩形 (Rectangle) | 四边形 | 门窗、设备 |
| 多边形 (Polygon) | 正多边形 | 螺母、特殊形状 |

### 5.1.2 绘图流程

标准绘图流程：

1. **选择工具**：从工具栏或菜单选择绘图工具
2. **设置选项**：在选项栏设置相关参数
3. **指定点位**：通过点击或输入坐标确定关键点
4. **确认完成**：按Enter或右键确认

### 5.1.3 坐标输入方法

**绝对坐标**：
```
格式: x,y
示例: 100,50
说明: 相对于原点的坐标
```

**相对坐标**：
```
格式: @dx,dy
示例: @50,30
说明: 相对于上一点的偏移
```

**极坐标**：
```
格式: 距离<角度
示例: 100<45
说明: 从原点出发，距离100，角度45°
```

**相对极坐标**：
```
格式: @距离<角度
示例: @50<90
说明: 从上一点出发，距离50，角度90°
```

## 5.2 点工具

### 5.2.1 单点绘制

**菜单路径**：绘图 → 点 → 单点

**操作步骤**：
1. 选择"单点"工具
2. 点击或输入坐标指定点位置
3. 继续放置更多点或按Esc结束

**命令行示例**：
```
命令: point
指定点: 100,50
指定点: @50,0
指定点: Enter (结束)
```

### 5.2.2 点样式设置

通过"格式" → "点样式"设置点的显示方式：

| 样式 | 描述 |
|------|------|
| · | 小点（默认） |
| + | 十字 |
| × | 斜十字 |
| ○ | 空心圆 |
| ● | 实心圆 |
| □ | 空心方块 |
| ■ | 实心方块 |

### 5.2.3 等分点

**菜单路径**：绘图 → 点 → 等分点

**功能**：在选定对象上创建等分点

**操作步骤**：
1. 选择"等分点"工具
2. 选择要等分的对象（直线、圆弧等）
3. 输入等分数量
4. 自动在对象上创建等分点

**示例**：
```
命令: divide
选择对象: (选择一条直线)
输入等分数 <2>: 5
(在直线上创建5个等分点)
```

### 5.2.4 定距等分点

**功能**：按指定距离在对象上放置点

**操作步骤**：
1. 选择"定距等分"工具
2. 选择对象
3. 输入间距
4. 按指定间距放置点

## 5.3 直线工具

### 5.3.1 两点直线

**菜单路径**：绘图 → 直线 → 两点直线

**操作步骤**：
1. 选择"两点直线"工具
2. 指定起点
3. 指定终点
4. 可继续绘制下一段线或按Enter结束

**命令行示例**：
```
命令: line
指定第一点: 0,0
指定下一点或 [撤销(U)]: 100,0
指定下一点或 [撤销(U)/闭合(C)]: 100,50
指定下一点或 [撤销(U)/闭合(C)]: 0,50
指定下一点或 [撤销(U)/闭合(C)]: C (闭合)
```

**选项说明**：
- **U (撤销)**：撤销上一点
- **C (闭合)**：闭合到起点

### 5.3.2 角度直线

**菜单路径**：绘图 → 直线 → 角度直线

**功能**：绘制指定角度的直线

**操作步骤**：
1. 选择"角度直线"工具
2. 输入角度值
3. 指定起点
4. 指定长度或终点

**选项栏设置**：
- 角度：直线与X轴的夹角
- 长度：直线长度（可选）
- 参考：选择参考方向

### 5.3.3 水平直线

**功能**：绘制水平直线（角度为0°或180°）

**快捷用法**：
1. 选择"水平直线"工具
2. 指定起点
3. 移动鼠标确定长度和方向
4. 点击或输入长度值

### 5.3.4 垂直直线

**功能**：绘制垂直直线（角度为90°或270°）

### 5.3.5 平行线

**菜单路径**：绘图 → 直线 → 平行线

**功能**：绘制与现有直线平行的线

**操作步骤**：
1. 选择"平行线"工具
2. 选择参考直线
3. 输入偏移距离
4. 指定方向（哪一侧）
5. 指定起点和终点

**选项说明**：
- **距离**：与参考线的平行距离
- **数量**：一次创建的平行线数量
- **通过点**：通过指定点创建平行线

### 5.3.6 垂线

**菜单路径**：绘图 → 直线 → 垂线

**功能**：绘制与现有直线垂直的线

**操作步骤**：
1. 选择"垂线"工具
2. 选择参考直线
3. 指定垂线的起点（在参考线上或外部）
4. 指定终点

### 5.3.7 切线

**功能**：绘制与圆或圆弧相切的直线

**类型**：
- **点到圆的切线**：从外部点到圆的切线
- **两圆的公切线**：两个圆的公切线

**操作步骤**（点到圆切线）：
1. 选择"切线"工具
2. 指定外部点
3. 选择圆
4. 选择切点位置（可能有两个切点）

### 5.3.8 构造线和射线

**构造线（XLine）**：
- 双向无限延伸的直线
- 用作辅助参考
- 不会打印输出

**射线（Ray）**：
- 从一点单向无限延伸
- 用于角度参考

## 5.4 圆弧工具

### 5.4.1 三点圆弧

**菜单路径**：绘图 → 圆弧 → 三点

**功能**：通过三个点绘制圆弧

**操作步骤**：
1. 选择"三点圆弧"工具
2. 指定起点
3. 指定圆弧上的一点
4. 指定终点

**命令行示例**：
```
命令: arc
指定圆弧起点: 0,0
指定圆弧上的点: 50,25
指定圆弧终点: 100,0
```

### 5.4.2 圆心起点终点圆弧

**功能**：指定圆心、起点和终点绘制圆弧

**操作步骤**：
1. 指定圆心
2. 指定起点（确定半径和起始角度）
3. 指定终点（确定终止角度）

**注意**：终点不一定在圆弧上，系统使用终点方向确定终止角度

### 5.4.3 圆心起点角度圆弧

**功能**：指定圆心、起点和圆心角

**参数**：
- 圆心位置
- 起点位置
- 圆心角（正值逆时针，负值顺时针）

### 5.4.4 起点终点半径圆弧

**功能**：指定起点、终点和半径

**注意**：
- 给定两点和半径，可能有四个解
- 需要选择弧的方向和大小弧

### 5.4.5 相切圆弧

**功能**：绘制与现有对象相切的圆弧

**类型**：
- **切点起点**：从上一线段终点相切延伸
- **三切点**：与三个对象都相切的圆弧

### 5.4.6 连续圆弧

**功能**：绘制与上一条线段平滑连接的圆弧

**应用**：创建光滑的曲线路径

## 5.5 圆工具

### 5.5.1 圆心半径

**菜单路径**：绘图 → 圆 → 圆心半径

**操作步骤**：
1. 指定圆心
2. 输入半径或指定圆上一点

**命令行示例**：
```
命令: circle
指定圆心: 100,100
指定半径或 [直径(D)]: 50
```

### 5.5.2 圆心直径

**功能**：用圆心和直径定义圆

**操作步骤**：
1. 指定圆心
2. 输入D选择直径模式
3. 输入直径值

### 5.5.3 两点圆

**功能**：通过两个点确定圆（两点为直径端点）

**操作步骤**：
1. 指定第一个直径端点
2. 指定第二个直径端点

**特点**：两点连线即为直径

### 5.5.4 三点圆

**功能**：通过三个不共线的点确定圆

**操作步骤**：
1. 指定第一点
2. 指定第二点
3. 指定第三点

**应用**：当已知圆上三点时使用

### 5.5.5 相切圆

**两切点一半径**：
1. 选择第一个切线对象
2. 选择第二个切线对象
3. 输入半径
4. 选择圆的位置（可能有多个解）

**三切点**：
1. 选择三个切线对象
2. 系统计算与三者都相切的圆

### 5.5.6 同心圆

**功能**：创建与现有圆同心的圆

**操作步骤**：
1. 选择参考圆
2. 输入新圆半径或偏移距离

## 5.6 椭圆工具

### 5.6.1 中心和两个半径

**功能**：指定中心和两个半轴长度

**操作步骤**：
1. 指定椭圆中心
2. 指定长轴端点（确定长轴方向和长度）
3. 指定短轴长度

### 5.6.2 椭圆弧

**功能**：绘制椭圆的一部分

**操作步骤**：
1. 定义完整椭圆（同上）
2. 指定起始角度
3. 指定终止角度

### 5.6.3 焦点定义椭圆

**功能**：通过两个焦点和椭圆上一点定义

**操作步骤**：
1. 指定第一个焦点
2. 指定第二个焦点
3. 指定椭圆上一点

## 5.7 矩形和多边形

### 5.7.1 矩形（两角点）

**菜单路径**：绘图 → 形状 → 矩形（两角点）

**操作步骤**：
1. 指定第一个角点
2. 指定对角点

**选项**：
- **尺寸输入**：输入宽度和高度
- **圆角**：指定圆角半径
- **倒角**：指定倒角距离

### 5.7.2 矩形（中心和尺寸）

**功能**：从中心开始绘制矩形

**操作步骤**：
1. 指定矩形中心
2. 输入宽度和高度
3. 指定旋转角度（可选）

### 5.7.3 矩形（三点）

**功能**：通过三个点定义矩形

**操作步骤**：
1. 指定第一个角点
2. 指定同一边的第二个角点
3. 指定宽度方向

### 5.7.4 正多边形（内接）

**功能**：绘制内接于圆的正多边形

**操作步骤**：
1. 输入边数
2. 指定中心
3. 指定半径（到顶点的距离）

**命令行示例**：
```
命令: polygon
输入边数 <6>: 6
指定中心: 100,100
指定半径: 50
```

### 5.7.5 正多边形（外切）

**功能**：绘制外切于圆的正多边形

**特点**：半径为中心到边的距离

### 5.7.6 正多边形（边长）

**功能**：通过指定一条边定义正多边形

**操作步骤**：
1. 输入边数
2. 指定边的起点
3. 指定边的终点

## 5.8 多段线工具

### 5.8.1 绘制多段线

**菜单路径**：绘图 → 多段线 → 绘制多段线

**功能**：绘制由直线段和圆弧段组成的连续曲线

**操作步骤**：
1. 指定起点
2. 指定下一点（默认直线）
3. 输入选项切换到圆弧模式
4. 继续添加顶点
5. 按Enter或C闭合结束

**选项**：
- **A (弧段)**：切换到圆弧模式
- **L (直线)**：切换回直线模式
- **W (宽度)**：设置线宽
- **U (撤销)**：撤销上一点
- **C (闭合)**：闭合多段线

**圆弧模式选项**：
- **角度**：指定圆心角
- **圆心**：指定圆弧圆心
- **方向**：指定切线方向
- **半径**：指定圆弧半径
- **第二点**：通过三点定义弧

### 5.8.2 多段线属性

| 属性 | 说明 |
|------|------|
| 闭合 | 是否首尾相连 |
| 宽度 | 全局或逐段宽度 |
| 顶点 | 顶点坐标列表 |
| 凸度 | 圆弧段的弯曲程度 |

### 5.8.3 编辑多段线

**添加顶点**：
1. 选择多段线
2. "修改" → "多段线" → "添加顶点"
3. 指定新顶点位置

**删除顶点**：
1. 选择多段线
2. "修改" → "多段线" → "删除顶点"
3. 选择要删除的顶点

**转换段类型**：
在直线段和圆弧段之间转换

## 5.9 样条曲线工具

### 5.9.1 控制点样条

**功能**：通过控制点定义样条曲线（曲线不一定通过控制点）

**操作步骤**：
1. 指定第一个控制点
2. 继续指定控制点
3. 按Enter结束

**特点**：
- 控制点影响曲线形状
- 曲线光滑通过控制多边形
- 适合自由形态设计

### 5.9.2 拟合点样条

**功能**：通过指定点绘制光滑曲线（曲线通过所有点）

**操作步骤**：
1. 指定第一个拟合点
2. 继续指定拟合点
3. 按Enter结束

**特点**：
- 曲线精确通过所有指定点
- 自动计算光滑连接
- 适合描绘已知轮廓

### 5.9.3 样条曲线选项

**阶数**：
- 控制曲线的光滑程度
- 默认为3次（三阶）样条
- 阶数越高曲线越光滑

**闭合样条**：
- 首尾相连形成闭合曲线
- 连接处光滑过渡

## 5.10 绘图辅助功能

### 5.10.1 对象捕捉

对象捕捉帮助精确定位关键点：

| 捕捉类型 | 说明 | 快捷键 |
|----------|------|--------|
| 端点 | 线段端点 | END |
| 中点 | 线段中点 | MID |
| 圆心 | 圆/弧的圆心 | CEN |
| 节点 | 点对象 | NOD |
| 象限点 | 圆的四个象限点 | QUA |
| 交点 | 对象交点 | INT |
| 垂足 | 垂直投影点 | PER |
| 切点 | 切线切点 | TAN |
| 最近点 | 对象上最近点 | NEA |
| 插入点 | 块的插入点 | INS |

**使用方法**：
1. 启用需要的捕捉模式（工具栏或F3）
2. 移动光标靠近目标
3. 出现捕捉标记时点击

### 5.10.2 正交模式

**功能**：限制光标只能水平或垂直移动

**启用**：按F8或点击状态栏"正交"按钮

**应用**：
- 绘制水平/垂直线
- 移动对象保持方向

### 5.10.3 极轴追踪

**功能**：按指定角度追踪光标

**设置**：
1. 右键点击状态栏"极轴"按钮
2. 设置追踪角度（如15°, 30°, 45°）
3. 启用极轴追踪

**使用**：当光标接近设定角度时显示追踪线

### 5.10.4 对象追踪

**功能**：从捕捉点延伸追踪线

**使用方法**：
1. 启用对象追踪（F11）
2. 悬停在捕捉点上获取追踪基点
3. 沿追踪线移动定位

### 5.10.5 动态输入

**功能**：在光标附近显示输入字段

**包含**：
- 坐标/距离输入
- 角度输入
- 命令选项

**启用**：按F12切换

## 5.11 本章小结

本章详细介绍了QCAD的基础绘图工具：

1. **点工具**：单点、等分点、定距点
2. **直线工具**：两点线、角度线、平行线、垂线、切线
3. **圆弧工具**：三点弧、圆心弧、相切弧
4. **圆工具**：圆心半径、两点圆、三点圆、相切圆
5. **椭圆工具**：椭圆和椭圆弧
6. **矩形和多边形**：各种定义方式
7. **多段线**：复合曲线绘制
8. **样条曲线**：光滑曲线绘制
9. **辅助功能**：捕捉、追踪、正交

掌握这些基础工具是进行CAD绘图的基础，建议通过大量实践熟悉各个工具的使用。
