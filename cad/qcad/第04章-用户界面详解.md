# 第四章：用户界面详解

## 4.1 界面概述

QCAD采用现代化的用户界面设计，将功能合理组织，为用户提供高效直观的操作体验。界面主要由以下几个部分组成：

### 4.1.1 主界面布局

```
┌────────────────────────────────────────────────────────────────────┐
│                          菜单栏 (Menu Bar)                          │
├────────────────────────────────────────────────────────────────────┤
│  工具栏 (Toolbars)                                                  │
│  ┌─────┐┌─────┐┌─────┐┌─────┐┌─────┐┌─────┐                       │
│  │文件 ││编辑 ││视图 ││绘图 ││修改 ││标注 │ ...                    │
│  └─────┘└─────┘└─────┘└─────┘└─────┘└─────┘                       │
├─────────┬──────────────────────────────────────────────┬───────────┤
│ 属性    │                                              │ 图层管理  │
│ 面板    │              绘图区域                         │ 面板      │
│ (Property│           (Drawing Area)                    │ (Layer    │
│  Panel) │                                              │  Panel)   │
│         │                                              │           │
│         │                                              ├───────────┤
│         │                                              │ 块面板    │
│         │                                              │ (Block    │
│         │                                              │  Panel)   │
├─────────┴──────────────────────────────────────────────┴───────────┤
│  CAD工具栏 (CAD Toolbar)                                            │
│  ┌─────┐┌─────┐┌─────┐┌─────┐┌─────┐┌─────┐                       │
│  │直线 ││圆弧 ││圆   ││矩形 ││多边形││文本 │ ...                    │
│  └─────┘└─────┘└─────┘└─────┘└─────┘└─────┘                       │
├────────────────────────────────────────────────────────────────────┤
│  命令行 / 状态栏 (Command Line / Status Bar)                        │
└────────────────────────────────────────────────────────────────────┘
```

### 4.1.2 界面特点

1. **可定制性**：工具栏、面板位置可自由调整
2. **上下文敏感**：根据操作显示相关选项
3. **快捷访问**：支持键盘快捷键和命令行
4. **多语言支持**：完整的国际化界面

绘图区是主要的工作空间，提供以下功能：

4. **选择操作**：选择和编辑对象
5. **网格显示**：显示辅助网格

### 4.4.2 视图导航

### 4.4.3 坐标系统

QCAD使用笛卡尔坐标系统：

**世界坐标系（WCS）**：
- 固定的绝对坐标系
- 原点(0, 0)为固定参考点
- X轴正方向向右
- Y轴正方向向上

**用户坐标系（UCS）**：
- 可自定义的相对坐标系
- 可设置自定义原点和方向
- 便于特定角度的绘图

**坐标输入方式**：

1. **绝对坐标**：`x,y` 或 `@x,y`
   - 例：`100,50` 表示点(100, 50)

2. **相对坐标**：`@dx,dy`
   - 例：`@50,30` 表示从当前点偏移(50, 30)

3. **极坐标**：`距离<角度`
   - 例：`100<45` 表示距离100，角度45°

4. **相对极坐标**：`@距离<角度`
   - 例：`@50<90` 表示相对偏移距离50，角度90°

### 4.4.4 网格系统

**网格设置**：
1. 菜单 "编辑" → "当前绘图首选项"
2. 选择 "网格" 选项卡
3. 设置网格参数：
   - 网格间距X/Y
   - 元网格（主网格）间距
   - 网格起点

**网格显示选项**：
- 显示/隐藏网格：快捷键 G
- 网格颜色设置
- 网格线型设置

### 4.4.5 十字光标

十字光标显示当前鼠标位置，包括：

1. **十字线**：显示水平和垂直参考线
2. **坐标显示**：显示当前位置坐标
3. **捕捉标记**：显示捕捉点类型

**光标设置**：
- 光标大小
- 光标颜色
- 十字线长度（可设为全屏）

| 对象类型 | 几何属性 |

### 4.5.3 属性编辑

**修改属性**：
1. 选中一个或多个对象
2. 在属性面板中修改相应值
3. 按Enter确认或点击其他位置

**批量修改**：
- 选中多个对象
- 修改共同属性
- 所有选中对象同时更新

**使用"匹配属性"**：
1. 选择源对象
2. 执行"匹配属性"命令
3. 选择目标对象
4. 属性被复制

### 4.6.1 图层面板布局

```
┌────────────────────────────────────────────┐
│ 图层管理                           [+][-] │
├────────────────────────────────────────────┤
│ ☑ 💡🔓 ■ 0                                │
│ ☑ 💡🔓 ■ 墙体                              │

💡 - 打印状态
🔓/🔒 - 解锁/锁定
■ - 图层颜色
```

### 4.6.2 图层操作

**新建图层**：
1. 点击 [+] 按钮或右键菜单
2. 输入图层名称
3. 设置图层属性

**删除图层**：
1. 选择图层
2. 点击 [-] 按钮
3. 确认删除（图层上的对象将移到0图层）

**图层属性**：
- **名称**：图层唯一标识
- **可见性**：控制图层显示
- **锁定**：防止编辑图层对象
- **打印**：控制是否打印
- **颜色**：图层默认颜色
- **线型**：图层默认线型
- **线宽**：图层默认线宽

### 4.6.3 图层使用技巧

1. **按功能分层**：将不同功能的图形放在不同图层
2. **合理命名**：使用有意义的图层名称
3. **颜色区分**：不同图层使用不同颜色便于识别
4. **锁定辅助图层**：防止误修改辅助线
5. **使用图层快捷操作**：双击设为当前图层

## 4.8 命令行与状态栏

### 4.8.1 命令行功能

命令行位于界面底部，提供：

1. **命令输入**：直接输入命令名称
2. **参数输入**：输入命令参数（坐标、距离等）
3. **提示信息**：显示当前操作提示
4. **历史记录**：查看命令历史

**命令行使用**：
```
命令: line                    ← 输入命令
指定第一点:                   ← 提示输入
100,50                        ← 输入坐标
指定下一点或 [撤销(U)]:       ← 提示下一步
@100<45                       ← 相对极坐标输入
指定下一点或 [撤销(U)/闭合(C)]:
Enter                         ← 确认结束
```

### 4.8.2 常用命令

| 命令 | 功能 | 命令 | 功能 |
|------|------|------|------|
| line | 绘制直线 | circle | 绘制圆 |
| arc | 绘制圆弧 | rect | 绘制矩形 |
| move | 移动对象 | copy | 复制对象 |
| rotate | 旋转对象 | mirror | 镜像对象 |
| trim | 修剪 | extend | 延伸 |
| fillet | 圆角 | chamfer | 倒角 |
| offset | 偏移 | scale | 缩放 |
| erase | 删除 | undo | 撤销 |

### 4.8.3 状态栏

状态栏显示当前状态信息：

```
┌──────────────────────────────────────────────────────────────────┐
│ 坐标: X=150.00 Y=75.00 │ 捕捉: 端点 中点 │ 网格: 10 │ 正交: 关 │
└──────────────────────────────────────────────────────────────────┘
```

**状态栏信息**：
- **坐标显示**：当前光标位置
- **捕捉模式**：当前启用的捕捉
- **网格状态**：网格开关和间距
- **正交模式**：正交开关状态
- **极轴追踪**：追踪角度

### 4.8.4 动态输入

启用动态输入后，在光标附近显示输入框：

- 坐标输入框
- 长度输入框
- 角度输入框
- 命令选项

**启用动态输入**：
- 状态栏点击"动态输入"按钮
- 或快捷键 F12

## 4.9 首选项设置

### 4.9.1 应用程序首选项

"编辑" → "应用程序首选项" 打开全局设置：

**常规选项**：
- 语言设置
- 自动保存间隔
- 最近文件数量
- 启动行为

**图形视图**：
- 背景颜色
- 网格颜色
- 光标样式
- 抗锯齿设置

**文件**：
- 默认文件路径
- 备份设置
- 自动恢复

**键盘**：
- 快捷键定义
- 命令别名

### 4.9.2 绘图首选项

"编辑" → "当前绘图首选项" 打开文档设置：

**单位**：
- 绘图单位（mm/cm/m/英寸等）
- 角度单位（度/弧度等）
- 精度设置

**网格**：
- 网格间距
- 元网格设置
- 网格显示选项

**尺寸**：
- 标注样式
- 箭头类型
- 文字设置

**打印**：
- 页面大小
- 打印比例
- 打印样式

本章详细介绍了QCAD的用户界面：
