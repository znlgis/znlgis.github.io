# 第六章：高级绘图功能

## 6.1 文本工具

### 6.1.1 单行文本

**菜单路径**：绘图 → 文本 → 单行文本

**功能**：创建简单的单行文本标注

**操作步骤**：
1. 选择"单行文本"工具
2. 指定文本插入点
3. 在对话框中输入文本内容
4. 设置文本属性
5. 确认创建

**文本属性设置**：

| 属性 | 说明 |
|------|------|
| 内容 | 文本字符串 |
| 字体 | 字体名称（如宋体、Arial） |
| 高度 | 文本高度 |
| 角度 | 文本旋转角度 |
| 对齐 | 水平和垂直对齐方式 |
| 宽度因子 | 字符宽度比例 |
| 倾斜角 | 字符倾斜角度 |

**对齐选项**：

水平对齐：
- 左对齐（Left）
- 居中（Center）
- 右对齐（Right）
- 对齐（Align）
- 适合（Fit）

垂直对齐：
- 基线（Baseline）
- 底部（Bottom）
- 中间（Middle）
- 顶部（Top）

### 6.1.2 多行文本

**菜单路径**：绘图 → 文本 → 多行文本

**功能**：创建带格式的多行文本块

**操作步骤**：
1. 选择"多行文本"工具
2. 指定文本框的第一个角点
3. 指定对角点确定文本区域
4. 在编辑器中输入和格式化文本
5. 确认创建

**格式化选项**：
- 字体选择
- 字号设置
- 粗体、斜体、下划线
- 颜色设置
- 段落对齐
- 行间距
- 列表（项目符号、编号）

### 6.1.3 特殊字符

在文本中插入特殊字符：

| 代码 | 字符 | 说明 |
|------|------|------|
| %%d | ° | 度数符号 |
| %%p | ± | 正负号 |
| %%c | Ø | 直径符号 |
| %%% | % | 百分号 |
| %%o | | 上划线开关 |
| %%u | | 下划线开关 |

### 6.1.4 文本样式

**创建文本样式**：
1. 菜单"格式" → "文本样式"
2. 点击"新建"
3. 输入样式名称
4. 设置字体、高度等属性
5. 保存样式

**应用文本样式**：
- 在文本属性中选择已定义的样式
- 或设置为当前样式后创建文本

## 6.2 尺寸标注

### 6.2.1 线性标注

**菜单路径**：绘图 → 标注 → 线性

**功能**：标注水平或垂直距离

**操作步骤**：
1. 指定第一个延伸线起点
2. 指定第二个延伸线起点
3. 指定标注线位置

**标注方向**：
- 移动光标决定标注方向（水平/垂直）
- 或使用专门的水平/垂直标注命令

### 6.2.2 对齐标注

**功能**：沿两点连线方向标注距离

**操作步骤**：
1. 指定第一点
2. 指定第二点
3. 指定标注位置

**特点**：标注线平行于被标注线段

### 6.2.3 角度标注

**功能**：标注两条线之间的夹角

**操作步骤**：
1. 选择第一条线
2. 选择第二条线
3. 指定标注弧位置

**或者**：
1. 指定角度顶点
2. 指定第一条边上的点
3. 指定第二条边上的点
4. 指定标注位置

### 6.2.4 半径标注

**功能**：标注圆或圆弧的半径

**操作步骤**：
1. 选择圆或圆弧
2. 指定标注位置

**样式选项**：
- 标注线放置（内部/外部）
- 箭头样式
- 文字位置

### 6.2.5 直径标注

**功能**：标注圆的直径

**操作步骤**：
1. 选择圆
2. 指定标注位置

**显示格式**：
- 自动添加直径符号Ø
- 可设置公差显示

### 6.2.6 弧长标注

**功能**：标注圆弧的弧长

**操作步骤**：
1. 选择圆弧
2. 指定标注位置

### 6.2.7 坐标标注

**功能**：标注点的X或Y坐标值

**类型**：
- X坐标标注
- Y坐标标注

**操作步骤**：
1. 选择"坐标标注"工具
2. 指定要标注的点
3. 指定引出方向
4. 指定文字位置

### 6.2.8 引线标注

**功能**：创建带引线的注释

**操作步骤**：
1. 指定引线起点（箭头位置）
2. 指定引线中间点（可选）
3. 指定引线终点
4. 输入标注文本

**引线类型**：
- 直线引线
- 样条引线
- 无引线（仅文本）

### 6.2.9 标注样式

**创建标注样式**：
1. 菜单"格式" → "标注样式"
2. 点击"新建"
3. 设置样式参数

**样式参数**：

| 类别 | 参数 |
|------|------|
| 线 | 标注线颜色、延伸线、偏移 |
| 箭头 | 箭头类型、大小 |
| 文字 | 字体、高度、位置、对齐 |
| 主单位 | 单位格式、精度、前缀后缀 |
| 换算单位 | 是否显示换算值 |
| 公差 | 公差格式和值 |

**常用箭头类型**：
- 实心闭合箭头
- 空心箭头
- 斜线
- 圆点
- 无箭头

## 6.3 图案填充

### 6.3.1 图案填充基础

**菜单路径**：绘图 → 填充 → 图案填充

**功能**：为封闭区域添加图案填充

**操作步骤**：
1. 选择"图案填充"工具
2. 在填充对话框中选择图案
3. 设置填充参数
4. 点击封闭区域内部
5. 预览并确认

### 6.3.2 预定义图案

QCAD提供多种预定义填充图案：

| 类别 | 图案示例 |
|------|----------|
| 常规 | SOLID（实心）、ANSI31-38 |
| ISO | ISO等间距线、ISO砖块 |
| 建筑 | AR-CONC（混凝土）、AR-SAND（沙） |
| 特殊 | GRASS（草地）、EARTH（土壤） |

### 6.3.3 填充参数

| 参数 | 说明 |
|------|------|
| 图案 | 选择图案类型 |
| 比例 | 图案缩放比例 |
| 角度 | 图案旋转角度 |
| 颜色 | 图案线条颜色 |
| 背景 | 背景填充颜色 |
| 原点 | 图案起始点 |

### 6.3.4 边界选择

**拾取点方式**：
- 点击封闭区域内部
- 自动检测边界

**选择对象方式**：
- 手动选择边界对象
- 适用于复杂情况

**边界保留**：
- 选择是否保留边界对象
- 创建新的边界多段线

### 6.3.5 填充孤岛检测

**孤岛**：填充区域内的封闭区域

**检测模式**：
- **普通**：交替填充孤岛
- **外部**：仅填充最外层
- **忽略**：忽略所有孤岛

### 6.3.6 渐变填充

**功能**：创建颜色渐变填充

**渐变类型**：
- 线性渐变
- 径向渐变

**参数**：
- 起始颜色
- 结束颜色
- 渐变角度
- 居中/偏移

### 6.3.7 自定义图案

创建自定义填充图案：

1. **编辑.pat文件**：
```
*CUSTOM,自定义图案描述
角度, X原点, Y原点, X偏移, Y偏移, 线长1, 间隔1, 线长2, 间隔2, ...
```

2. **示例**：
```
*MYBRICK,自定义砖块
0, 0, 0, 0, 25, 75, -25
90, 0, 0, 0, 75, 25, -75
```

3. **保存到patterns目录**

## 6.4 块和符号

### 6.4.1 创建块

**菜单路径**：块 → 从选择创建块

**操作步骤**：
1. 选择要创建为块的对象
2. 执行"创建块"命令
3. 输入块名称
4. 指定基点（插入点）
5. 选择处理方式（保留/转换/删除原对象）

### 6.4.2 插入块

**操作步骤**：
1. 执行"插入块"命令
2. 选择要插入的块
3. 指定插入点
4. 设置缩放因子和旋转角度
5. 确认插入

**插入参数**：

| 参数 | 说明 |
|------|------|
| X比例 | X方向缩放 |
| Y比例 | Y方向缩放 |
| 角度 | 旋转角度 |
| 阵列行数 | 多行插入 |
| 阵列列数 | 多列插入 |
| 行间距 | 行间距离 |
| 列间距 | 列间距离 |

### 6.4.3 块编辑

**在位编辑**：
1. 双击块参照
2. 进入块编辑模式
3. 修改块内容
4. 保存并关闭编辑器
5. 所有块参照自动更新

**块编辑器**：
1. 选择"块" → "编辑块"
2. 选择要编辑的块
3. 在独立窗口中编辑
4. 保存更改

### 6.4.4 块属性

**属性定义**：
为块添加可编辑的文本属性

**创建带属性的块**：
1. 创建块的图形内容
2. 添加属性定义
3. 设置属性标签、提示和默认值
4. 创建块

**属性参数**：
- 标签（Tag）：属性标识
- 提示（Prompt）：插入时的提示
- 默认值（Default）：默认文本
- 可见性（Visible）：是否显示

### 6.4.5 块库

**访问块库**：
1. 菜单"视图" → "库浏览器"
2. 浏览可用的符号库
3. 拖放插入到图形中

**添加到库**：
1. 创建块
2. 保存为.dxf文件
3. 复制到库目录

### 6.4.6 外部参照

**功能**：引用外部文件作为参照

**与块的区别**：
- 外部参照链接到外部文件
- 修改源文件自动更新
- 适合大型项目协作

**操作**：
1. "插入" → "外部参照"
2. 选择外部文件
3. 指定插入参数
4. 可卸载、重载、绑定

## 6.5 高级绘图技巧

### 6.5.1 构造几何

**构造线和射线**：
用于辅助绘图，通常不打印

**使用技巧**：
1. 绘制构造线建立参考框架
2. 基于构造线精确定位
3. 完成后删除或移到不打印图层

### 6.5.2 使用参考点

**临时参考点**：
1. 使用"点"工具放置参考点
2. 利用"节点"捕捉精确定位
3. 完成后删除参考点

**永久参考点**：
- 放在专用图层
- 设置图层不打印

### 6.5.3 边界创建

**从现有对象创建边界**：
1. 菜单"绘图" → "边界"
2. 点击封闭区域内部
3. 创建多段线边界

**用途**：
- 计算面积
- 创建填充边界
- 导出区域

### 6.5.4 区域功能

**创建区域**：
从封闭边界创建面域对象

**区域运算**：
- 并集：合并两个区域
- 差集：从一个区域减去另一个
- 交集：提取重叠部分

### 6.5.5 使用图层组织

**图层策略**：
```
图层结构示例：
├── 0 (默认图层)
├── 边界
│   ├── 外墙
│   └── 内墙
├── 门窗
│   ├── 门
│   └── 窗
├── 家具
├── 标注
│   ├── 尺寸
│   └── 文字
├── 辅助
└── 不打印
```

**颜色编码**：
- 不同图层使用不同颜色
- 便于视觉识别
- 按颜色打印控制

### 6.5.6 使用模板

**创建模板**：
1. 设置好图层、样式、单位等
2. 另存为模板文件
3. 新建文档时使用模板

**模板内容**：
- 图层定义
- 文本样式
- 标注样式
- 线型加载
- 页面设置
- 常用块

## 6.6 本章小结

本章介绍了QCAD的高级绘图功能：

1. **文本工具**：
   - 单行和多行文本
   - 特殊字符
   - 文本样式

2. **尺寸标注**：
   - 线性、角度、半径等标注
   - 引线和注释
   - 标注样式

3. **图案填充**：
   - 预定义图案
   - 渐变填充
   - 自定义图案

4. **块和符号**：
   - 块创建和插入
   - 块属性
   - 块库和外部参照

5. **高级技巧**：
   - 构造几何
   - 区域功能
   - 图层组织

这些功能使您能够创建专业级的技术图纸。继续练习以熟练掌握。
