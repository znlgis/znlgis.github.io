# 第二章：安装与环境配置

## 2.1 系统要求

### 2.1.1 硬件要求

QCAD对硬件要求相对较低，能够在大多数现代计算机上流畅运行：

**最低配置**：
- **处理器**：1 GHz 或更快的处理器
- **内存**：512 MB RAM
- **硬盘空间**：200 MB 可用空间
- **显示器**：1024 x 768 分辨率
- **显卡**：支持OpenGL的显卡（可选，用于加速渲染）

**推荐配置**：
- **处理器**：2 GHz 双核或更高
- **内存**：4 GB RAM 或更多
- **硬盘空间**：500 MB 可用空间（包含模板和库文件）
- **显示器**：1920 x 1080 分辨率或更高
- **显卡**：独立显卡，支持OpenGL 2.0以上

### 2.1.2 操作系统要求

QCAD支持以下操作系统：

**Windows**：
- Windows 10（32位和64位）
- Windows 11（64位）
- Windows 8/8.1（32位和64位）
- Windows 7 SP1（32位和64位）

**macOS**：
- macOS 10.14 Mojave 或更高版本
- 支持Intel和Apple Silicon（M1/M2）处理器

**Linux**：
- Ubuntu 18.04 LTS 或更高版本
- Debian 9 或更高版本
- Fedora 28 或更高版本
- 其他支持Qt 5的Linux发行版

### 2.1.3 依赖组件

QCAD运行需要以下组件（通常随安装包提供）：

- **Qt框架**：Qt 5.12 或更高版本
- **OpenGL**：用于图形渲染加速
- **字体**：系统基本字体
- **打印机驱动**：用于打印输出（可选）

## 2.2 Windows平台安装

### 2.2.1 下载安装包

1. 访问QCAD官方网站：https://www.qcad.org
2. 点击"Download"或"下载"链接
3. 选择Windows版本（32位或64位）
4. 下载安装程序（.exe文件）

### 2.2.2 安装步骤

**标准安装流程**：

1. **运行安装程序**：
   - 双击下载的安装文件
   - 如果出现安全提示，选择"运行"

2. **选择安装语言**：
   - 从下拉列表选择中文或其他语言
   - 点击"确定"继续

3. **接受许可协议**：
   - 阅读并同意许可条款
   - 选择"我接受"继续

4. **选择安装位置**：
   - 默认安装路径：`C:\Program Files\QCAD`
   - 可以自定义安装目录
   - 点击"下一步"继续

5. **选择组件**：
   - 核心程序（必选）
   - 示例文件（推荐）
   - 符号库（推荐）
   - 字体文件（推荐）

6. **创建快捷方式**：
   - 桌面快捷方式（推荐）
   - 开始菜单快捷方式

7. **完成安装**：
   - 点击"安装"开始复制文件
   - 等待安装完成
   - 点击"完成"退出安装程序

### 2.2.3 便携版安装

QCAD也提供便携版（Portable），适合U盘携带：

1. 下载便携版压缩包（.zip文件）
2. 解压到目标目录
3. 运行`qcad.exe`启动程序
4. 所有设置保存在程序目录中

### 2.2.4 静默安装

企业部署可使用静默安装：

```batch
qcad-3.x.x-setup.exe /S /D=C:\QCAD
```

参数说明：
- `/S`：静默安装
- `/D=path`：指定安装目录

## 2.3 macOS平台安装

### 2.3.1 下载安装包

1. 访问QCAD官方网站
2. 选择macOS版本下载
3. 下载.dmg磁盘镜像文件

### 2.3.2 安装步骤

1. **打开DMG文件**：
   - 双击下载的.dmg文件
   - 等待磁盘镜像挂载

2. **拖动安装**：
   - 将QCAD图标拖动到Applications文件夹
   - 等待复制完成

3. **首次运行**：
   - 打开应用程序文件夹
   - 右键点击QCAD，选择"打开"
   - 在安全提示中确认运行

4. **授予权限**：
   - 如需要，在"系统偏好设置"→"安全性与隐私"中允许运行

### 2.3.3 Apple Silicon支持

对于M1/M2 Mac用户：

- QCAD提供原生Apple Silicon版本
- 下载时选择正确的架构版本
- 原生版本性能更佳

### 2.3.4 Homebrew安装

也可以通过Homebrew安装：

```bash
# 安装QCAD
brew install --cask qcad

# 更新QCAD
brew upgrade --cask qcad

# 卸载QCAD
brew uninstall --cask qcad
```

## 2.4 Linux平台安装

### 2.4.1 通用二进制包

1. **下载**：
   - 从官网下载Linux版本（.tar.gz）
   - 选择适合的架构（x86_64）

2. **解压安装**：
```bash
# 解压到/opt目录
sudo tar -xzf qcad-3.x.x-linux-x86_64.tar.gz -C /opt/

# 创建符号链接
sudo ln -s /opt/qcad-3.x.x/qcad /usr/local/bin/qcad

# 运行QCAD
qcad
```

3. **创建桌面快捷方式**：
```bash
# 创建.desktop文件
cat > ~/.local/share/applications/qcad.desktop << EOF
[Desktop Entry]
Name=QCAD
Comment=2D CAD Application
Exec=/opt/qcad-3.x.x/qcad
Icon=/opt/qcad-3.x.x/scripts/qcad_icon.png
Terminal=false
Type=Application
Categories=Graphics;Engineering;
EOF
```

### 2.4.2 Ubuntu/Debian安装

**使用AppImage**：

```bash
# 下载AppImage
wget https://qcad.org/download/qcad-3.x.x-linux-x86_64.AppImage

# 添加执行权限
chmod +x qcad-3.x.x-linux-x86_64.AppImage

# 运行
./qcad-3.x.x-linux-x86_64.AppImage
```

**安装依赖**（如需从源码编译）：

```bash
sudo apt update
sudo apt install build-essential qt5-qmake qtbase5-dev \
    libqt5svg5-dev libqt5script5 libqt5scripttools5 \
    libglu1-mesa-dev libfreetype6-dev libfontconfig1-dev \
    libssl-dev libdbus-1-dev libsm-dev libx11-dev
```

### 2.4.3 Fedora/Red Hat安装

```bash
# 安装依赖
sudo dnf install qt5-qtbase-devel qt5-qtscript-devel \
    qt5-qtsvg-devel mesa-libGLU-devel freetype-devel \
    fontconfig-devel openssl-devel dbus-devel

# 解压并运行
tar -xzf qcad-3.x.x-linux-x86_64.tar.gz
cd qcad-3.x.x
./qcad
```

### 2.4.4 Arch Linux安装

```bash
# 使用AUR安装
yay -S qcad

# 或从官方仓库
pacman -S qcad
```

## 2.5 从源码编译安装

### 2.5.1 准备工作

从源码编译QCAD需要以下准备：

**必需工具**：
- Git 2.0+
- Qt 5.12+ 或 Qt 6.x
- C++ 编译器（GCC 7+, Clang 10+, MSVC 2017+）
- CMake 3.10+ 或 QMake

### 2.5.2 获取源码

```bash
# 创建工作目录
mkdir qcad-build && cd qcad-build

# 克隆主仓库
git clone https://github.com/qcad/qcad.git qcad

# 对于Qt 6，还需要额外模块
git clone https://github.com/qcad/qtjsapi.git qtjsapi
git clone https://github.com/qcad/qcadjsapi.git qcadjsapi
```

### 2.5.3 Windows编译

**使用Visual Studio**：

1. 安装Visual Studio 2019/2022
2. 安装Qt（与VS版本匹配）
3. 打开VS Developer Command Prompt

```batch
:: 设置Qt路径
set PATH=C:\Qt\5.15.2\msvc2019_64\bin;%PATH%

:: 进入源码目录
cd qcad

:: 使用qmake配置
qmake -r CONFIG+=ractivated

:: 编译
nmake release
```

**使用CMake**：

```batch
:: 创建构建目录
mkdir build && cd build

:: 配置
cmake .. -DCMAKE_PREFIX_PATH="C:/Qt/5.15.2/msvc2019_64/lib/cmake"

:: 编译
cmake --build . --config Release
```

### 2.5.4 Linux编译

```bash
# 安装依赖（Ubuntu）
sudo apt install build-essential qt5-qmake qtbase5-dev \
    qtscript5-dev libqt5svg5-dev

# 设置Qt路径（如果使用自定义Qt）
export PATH="/opt/Qt/5.15.2/gcc_64/bin:$PATH"

# 进入源码目录
cd qcad

# 使用qmake配置
qmake -r CONFIG+=ractivated

# 编译（使用所有CPU核心）
make -j$(nproc) release

# 运行
./release/qcad
```

### 2.5.5 macOS编译

```bash
# 安装Xcode命令行工具
xcode-select --install

# 使用Homebrew安装Qt
brew install qt@5

# 设置Qt路径
export PATH="/usr/local/opt/qt@5/bin:$PATH"

# 进入源码目录
cd qcad

# 配置
qmake -r CONFIG+=ractivated

# 编译
make -j$(sysctl -n hw.ncpu) release

# 运行
open release/QCAD.app
```

### 2.5.6 编译问题排查

**常见问题及解决方案**：

1. **找不到Qt**：
   - 检查PATH是否包含Qt的bin目录
   - 验证：`qmake --version`

2. **编译器不匹配**：
   - 确保Qt版本与编译器版本兼容
   - 例如：Qt MSVC版本需要使用MSVC编译

3. **缺少依赖**：
   - 根据错误信息安装缺失的开发包
   - Linux常见：`libGL-dev`, `libfreetype-dev`

4. **内存不足**：
   - 减少并行编译数：`make -j2`
   - 增加swap空间

## 2.6 初始配置

### 2.6.1 首次运行设置

首次运行QCAD时，进行以下基本设置：

**语言设置**：
1. 菜单 "Edit" → "Application Preferences"
2. 选择 "Language" 选项
3. 从列表选择 "Chinese (Simplified)"
4. 重启QCAD使设置生效

**单位设置**：
1. 菜单 "Edit" → "Application Preferences"
2. 选择 "Graphics View" → "Units"
3. 设置默认单位（毫米、厘米、米等）

### 2.6.2 界面自定义

**工具栏配置**：
- 右键点击工具栏区域
- 选择要显示/隐藏的工具栏
- 拖动调整工具栏位置

**面板配置**：
- 菜单 "View" → "Widgets"
- 选择要显示的面板
- 拖动调整面板位置

**颜色方案**：
1. "Edit" → "Application Preferences"
2. "Graphics View" → "Colors"
3. 选择预设方案或自定义颜色

### 2.6.3 快捷键设置

QCAD支持自定义快捷键：

1. 菜单 "Edit" → "Application Preferences"
2. 选择 "Keyboard"
3. 在命令列表中找到要设置的命令
4. 双击快捷键列
5. 按下新的快捷键组合
6. 点击"确定"保存

**常用默认快捷键**：

| 功能 | 快捷键 |
|------|--------|
| 新建 | Ctrl+N |
| 打开 | Ctrl+O |
| 保存 | Ctrl+S |
| 撤销 | Ctrl+Z |
| 重做 | Ctrl+Y |
| 复制 | Ctrl+C |
| 粘贴 | Ctrl+V |
| 删除 | Delete |
| 全选 | Ctrl+A |
| 缩放全图 | Home |
| 缩放窗口 | Z, W |

### 2.6.4 默认模板设置

设置新文档的默认模板：

1. 创建标准模板文件（包含常用图层、样式等）
2. 保存为.dxf文件
3. "Edit" → "Application Preferences"
4. "Template" → "Default Template"
5. 选择模板文件路径

### 2.6.5 打印设置

配置默认打印选项：

1. "Edit" → "Application Preferences"
2. "Printing" 选项卡
3. 设置默认打印机
4. 配置页面边距
5. 设置默认比例

## 2.7 许可证激活

### 2.7.1 社区版

QCAD社区版无需许可证，可以免费使用全部基本功能。

### 2.7.2 专业版激活

购买QCAD专业版后：

1. 启动QCAD
2. 菜单 "Help" → "Register"
3. 输入许可证密钥
4. 点击"Activate"
5. 等待在线验证
6. 完成激活

**离线激活**：
1. 选择"离线激活"选项
2. 记录机器ID
3. 访问激活网站输入机器ID
4. 获取激活码
5. 在QCAD中输入激活码

### 2.7.3 试用版

专业版功能可以免费试用：
- 试用期限：通常30天
- 功能完整
- 试用期结束后降级为社区版功能

## 2.8 卸载QCAD

### 2.8.1 Windows卸载

**方法1：控制面板**：
1. 打开"控制面板"
2. 选择"程序和功能"
3. 找到QCAD
4. 点击"卸载"

**方法2：使用卸载程序**：
1. 进入QCAD安装目录
2. 运行`uninstall.exe`
3. 按提示完成卸载

**清理残留**：
- 删除配置文件：`%APPDATA%\QCAD`
- 删除缓存：`%LOCALAPPDATA%\QCAD`

### 2.8.2 macOS卸载

1. 将QCAD从应用程序文件夹移到废纸篓
2. 清理配置文件：
```bash
rm -rf ~/Library/Application\ Support/QCAD
rm -rf ~/Library/Preferences/com.qcad.*
rm -rf ~/Library/Caches/QCAD
```

### 2.8.3 Linux卸载

**删除程序文件**：
```bash
# 删除程序目录
sudo rm -rf /opt/qcad-3.x.x

# 删除符号链接
sudo rm /usr/local/bin/qcad

# 删除桌面文件
rm ~/.local/share/applications/qcad.desktop
```

**清理配置**：
```bash
rm -rf ~/.config/QCAD
rm -rf ~/.local/share/QCAD
```

## 2.9 常见安装问题

### 2.9.1 Windows问题

**问题**：启动时提示缺少DLL
**解决**：
- 安装Visual C++ Redistributable
- 重新安装QCAD

**问题**：界面显示异常
**解决**：
- 更新显卡驱动
- 在"Edit" → "Preferences"中禁用OpenGL加速

### 2.9.2 macOS问题

**问题**：无法打开，提示"已损坏"
**解决**：
```bash
xattr -cr /Applications/QCAD.app
```

**问题**：Retina显示模糊
**解决**：
- 检查系统显示设置
- 更新到最新版本

### 2.9.3 Linux问题

**问题**：缺少libqt5script
**解决**：
```bash
# Ubuntu
sudo apt install libqt5script5

# Fedora
sudo dnf install qt5-qtscript
```

**问题**：字体显示不正常
**解决**：
- 安装字体包：`sudo apt install fonts-liberation`
- 配置fontconfig
