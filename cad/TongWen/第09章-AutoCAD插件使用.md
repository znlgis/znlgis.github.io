## 1. 插件概述

### 1.1 什么是 AutoCAD 插件？

同文 AutoCAD 插件是一个直接嵌入在 AutoCAD 软件内部的功能模块，让你无需离开 AutoCAD 环境就能完成图纸文字的提取、翻译和回写操作。插件以侧边面板的形式固定在 AutoCAD 主窗口的左侧，宽度为 268 像素，随时可用、不遮挡绘图区域。

### 1.2 插件与 Studio 的关系

同文由两部分组成：

- **同文 Studio**（桌面应用程序）：进行翻译项目管理、术语表维护、质量控制等全局操作
- **同文 AutoCAD 插件**（CAD 内嵌模块）：在 AutoCAD 内部完成图纸文字的提取与回写

两者各司其职、紧密配合：插件负责"对图纸做什么"（提取、回写），Studio 负责"翻译本身"（术语管理、翻译任务调度、质量审核）。插件提取到的文字会提交到项目中进行翻译；Studio 中的翻译结果需要通过插件回写到图纸中。

> **类比理解**：Studio 好比翻译公司，负责管理翻译任务、维护术语库、把控翻译质量；AutoCAD 插件好比驻场工程师，负责在客户现场（DWG 文件）取走需要翻译的材料，翻译完成后再放回原位。

### 1.3 两种工作方式的适用场景

你可以在两种方式之间灵活切换：

| 工作方式 | 适用场景 | 优点 |
|----------|----------|------|
| **纯插件操作** | 简单图纸、少量文字、快速翻译 | 无需切换窗口，效率高 |
| **插件 + Studio 协同** | 大型项目、多张图纸、需要术语统一和质量控制 | 数据集中管理，支持多人协作、审批流程 |

大多数实际项目采用的是协同方式：在插件端完成提取和回写，在 Studio 端完成翻译、术语管理和审核。

## 2. 安装与启动

### 2.1 安装

AutoCAD 插件随同文 Studio 一同安装。安装 Studio 时，安装程序会自动将插件注册到 AutoCAD 中。安装完成后，重新启动 AutoCAD 即可看到插件面板。

> **注意**：插件支持 AutoCAD 2016 及以上版本（含 AutoCAD Mechanical、AutoCAD Architecture 等垂直产品）。

### 2.2 启动

启动 AutoCAD 后，插件会自动加载。如果侧边面板没有显示，可以使用以下方法之一：

- **命令行**：输入 `TW_SHOW_PANEL` 并回车
- **功能面板上的自定义按钮**（如果已配置）

### 2.3 连接 Studio

插件需要连接到本地运行的 Studio 才能正常工作。Studio 启动后会自动监听，插件启动后也会自动尝试连接。连接成功时，插件底部的状态栏会显示连接状态。

如果自动连接失败，可以使用命令 `TW_CONNECT` 手动连接。

## 3. 侧边面板详解

### 3.1 整体布局

侧边面板固定在 AutoCAD 左侧，宽度为 268px，从上到下依次为：

```
┌──────────────────────────────┐
│     顶部状态横幅              │
├──────────────────────────────┤
│  第1区：项目关联（可折叠）     │
├──────────────────────────────┤
│  第2区：文字提取（可折叠）     │
├──────────────────────────────┤
│  第3区：翻译工作区            │
├──────────────────────────────┤
│  第4区：便捷命令              │
├──────────────────────────────┤
│     底部状态栏                │
└──────────────────────────────┘
```

### 3.2 顶部状态横幅解读

状态横幅会随当前图纸与项目的关联状态而变化，是判断当前工作状态的首要依据：

| 外观 | 状态 | 含义 | 下一步操作 |
|------|------|------|------------|
| 🟡 黄色背景，文字"当前图纸未关联项目" | **未关联** | 当前打开的 DWG 文件尚未与任何项目建立关联 | 进入第1区进行项目关联 |
| 🟢 绿色背景，文字"已关联：项目名" | **已关联** | 图纸已成功关联到指定项目，可以开始提取和翻译 | 进入第2区开始文字提取 |
| 🟢 绿色背景，文字"已提取 · 项目名" | **已提取** | 图纸已关联项目，且已经执行过文字提取操作 | 进入第3区打开翻译工作台 |
| 🔵 蓝色文字"▸ 还有 N 个项目也包含此图纸" | **多匹配** | 当前图纸的文件名在多个项目中都有记录 | 在展开的候选列表中选择正确的项目 |

### 3.3 第1区：项目关联

项目关联是使用插件的第一步，告诉同文"这张图纸属于哪个翻译项目"。

#### 未关联状态

当图纸尚未关联任何项目时，该区域显示两个按钮：

- **🔗 "关联已有"按钮**：将当前图纸关联到一个已存在的项目。点击后弹出项目选择对话框（参见[10.1 关联已有项目对话框](#101-关联已有项目对话框)）。
- **＋ "新建"按钮**：新建一个项目并将当前图纸关联到新项目。点击后弹出新建项目对话框（参见[10.2 新建项目对话框](#102-新建项目对话框)）。

> **重要**：如果当前 DWG 文件尚未保存（即新建图纸尚未存盘），两个按钮均处于禁用状态。请先保存图纸再操作。

#### 已关联状态

当图纸已关联项目时，该区域显示：
- 项目名称（绿色文字）
- "切换"按钮：点击可关联到其他项目
- "解除关联"按钮：断开图纸与当前项目的关联关系

#### 多匹配状态

当同名 DWG 文件出现在多个项目中时，项目名称右侧会显示蓝色提示"▸ 还有 N 个项目也包含此图纸"。点击可展开候选项目列表，从中选择正确的项目来完成关联切换。

### 3.4 第2区：文字提取

文字提取是将 DWG 图纸中的所有可翻译文字识别并提交到项目的操作。

#### 三个操作按钮

| 按钮 | 功能 | 说明 |
|------|------|------|
| ▣ **整图提取** | 提取整个图纸中所有文字实体 | 适用于首次处理整张图纸 |
| ⬜ **框选提取** | 在 AutoCAD 中框选一个矩形区域，只提取该区域内的文字 | 适用于只需处理图纸局部 |
| ☑ **不提取图框文字** | 勾选后，自动跳过图框（BlockReference）内的属性文字 | 避免把图纸编号、比例尺等非翻译内容混入翻译任务 |

#### 提取进度显示

点击提取按钮后，侧边面板会实时显示提取进度：

- 当前步骤文字（如"正在读取实体…"、"正在分析图框…"、"正在提交到项目…"）
- 每步耗时（秒）

#### 提取完成

提取完成后，会弹出一个 MessageBox，显示本次提取的统计信息：

- **实体数**：图纸中识别到的文字实体总数
- **继承数**：从之前批次继承过来的翻译条目（已在项目中翻译过的相同文字）
- **新增数**：本次新提交的待翻译条目
- **批次**：当前提取对应的批次编号
- **耗时**：从点击提取按钮到完成提取的总时间

点击"确定"后，系统会自动打开翻译工作台（WorkspaceWindow），进入翻译阶段。

### 3.5 第3区：翻译工作区

该区域只有一个按钮：

- **📄 "打开翻译工作区"按钮**：点击后打开独立的 WPF 翻译工作台窗口（900×620px），进行翻译操作。

该窗口的详细使用方法请参见[第6章：翻译工作台窗口详解](#6-翻译工作台窗口详解)。

### 3.6 第4区：便捷命令

提供两个快速切换图层可见性的按钮：

| 按钮 | 功能 |
|------|------|
| 👁 **隐藏/显示原文图层** | 切换源语言文字所在图层的可见性，便于查看翻译效果 |
| 👁 **隐藏/显示译文图层** | 切换翻译后文字所在图层的可见性 |

关于图层控制的更多用法，参见[第8章：图层可见性控制](#8-图层可见性控制)。

### 3.7 底部状态栏

面板最底部是一条深蓝色的状态栏，实时显示当前操作状态和提示信息。例如：
- 连接状态（"已连接到 Studio" / "未连接到 Studio"）
- 操作结果（"提取完成，共找到 128 个文字实体"）
- 错误提示（"图纸未保存，无法关联项目"）

## 4. 项目关联操作

### 4.1 关联已有项目

**适用场景**：你已经通过 Studio 创建了项目，现在要把当前图纸加入该项目。

**操作步骤**：

1. 确保当前 DWG 图纸已经保存（快捷键 `Ctrl+S`）
2. 在侧边面板第1区，点击 **🔗 "关联已有"** 按钮
3. 在弹出的"关联已有项目"对话框中，从列表中选择目标项目
4. 点击"确定"
5. 观察顶部状态横幅，确认变为绿色并显示正确的项目名称

### 4.2 新建项目

**适用场景**：你还没有创建项目，需要在关联图纸的同时创建一个新项目。

**操作步骤**：

1. 确保当前 DWG 图纸已经保存
2. 在侧边面板第1区，点击 **＋ "新建"** 按钮
3. 在弹出的"新建项目"对话框中填写项目信息：
   - 项目名称（必填）
   - 源语言和目标语言
   - 其他可选信息
4. 点击"确定"
5. 系统会自动创建项目并将当前图纸关联到新项目
6. 观察顶部状态横幅，确认变为绿色并显示新项目名称

### 4.3 切换项目

如果当前图纸需要关联到另一个项目：

1. 在第1区，点击"切换"按钮
2. 在弹出的项目选择对话框中选择目标项目
3. 点击"确定"

### 4.4 解除关联

如果不再需要当前图纸与项目的关联关系：

1. 在第1区，点击"解除关联"按钮
2. 确认解除关联操作
3. 顶部状态横幅将变为黄色"未关联"状态

> **注意**：解除关联不会删除已提取的数据，但会使当前图纸无法再执行提取和回写操作，直到重新关联。

## 5. 文字提取操作

### 5.1 整图提取

整图提取会扫描当前 DWG 文件的所有文字实体（TEXT、MTEXT、DIMENSION、ATTRIBUTE 等），将需要进行翻译的文字提交到项目。

**操作步骤**：

1. 确保图纸已关联项目（顶部状态横幅为绿色）
2. 根据需要决定是否勾选 **☑ "不提取图框文字"**
3. 点击 **▣ "整图提取"** 按钮
4. 观察进度显示，等待提取完成
5. 弹出的 MessageBox 会显示提取统计信息
6. 点击"确定"，翻译工作台窗口自动打开

### 5.2 框选提取

框选提取允许你仅对图纸的某个区域进行文字提取，适用于以下场景：
- 只翻译图纸中的某个图块或局部区域
- 图纸较大，测试性提取少量文字
- 补充提取之前遗漏的区域

**操作步骤**：

1. 确保图纸已关联项目
2. 根据需要决定是否勾选 **☑ "不提取图框文字"**
3. 点击 **⬜ "框选提取"** 按钮
4. AutoCAD 命令行会提示你指定选择区域，使用鼠标在图纸中框选一个矩形
5. 按回车确认选择
6. 观察进度显示，等待提取完成

### 5.3 图框文字过滤

图框（Title Block）通常包含图纸编号、项目名称、比例尺、设计人等非翻译内容。勾选 **☑ "不提取图框文字"** 后，插件会自动识别并跳过 BlockReference（图块引用）内的属性文字，避免这些内容被提交到翻译任务中。

> **建议**：在处理正式施工图纸时，建议勾选此项。仅在确定需要翻译图框内容时才取消勾选。

### 5.4 进度解读

提取过程中，进度信息会逐步更新。常见的步骤包括：

| 步骤 | 说明 | 参考耗时 |
|------|------|----------|
| 正在读取实体… | 扫描 DWG 数据库中的所有文字图元 | 视图纸复杂度而定，通常数秒 |
| 正在分析图框… | 识别并标记图框引用，用于后续过滤 | 1-3 秒 |
| 正在提交到项目… | 将文字数据通过网络发送到 Studio 项目 | 视文字数量而定 |
| 提取完成 | 所有步骤已完成 | — |

如果在某一步骤停滞时间过长，请检查 Studio 是否正常运行，以及网络连接是否正常。

## 6. 翻译工作台窗口详解

翻译工作台窗口（WorkspaceWindow）是一个独立的 WPF 窗口，尺寸为 900×620 像素，是你完成翻译操作的核心界面。

### 6.1 与 Studio 翻译工作区的异同

| 对比维度 | 插件翻译工作台 | Studio 翻译工作区 |
|----------|---------------|-------------------|
| **打开方式** | 在 AutoCAD 内点击"打开翻译工作区" | 在 Studio 主界面中打开 |
| **定位功能** | ✅ 有（可直接在 CAD 中定位实体） | ❌ 无 |
| **回写功能** | ✅ 有（直接回写到图纸） | ❌ 无 |
| **术语表** | ✅ 有（抽屉式侧边栏） | ✅ 有 |
| **审批流程** | ✅ 有（批准/退回所选） | ✅ 有 |
| **批量操作** | ✅ 支持 | ✅ 支持 |
| **外观定位** | 独立窗口，可自由移动 | 内嵌在 Studio 主窗口中 |

简单来说：**插件翻译工作台侧重于单张图纸的精准翻译和定位，Studio 翻译工作区侧重于多图纸的全局管理和质量控制。**

### 6.2 窗口布局

翻译工作台窗口布局如下：

```
┌──────────────────────────────────────────────────────────┐
│  📄 翻译工作台 — DWG文件名                        [×]   │
├──────────────────────────────────────────────────────────┤
│  [源语言→目标语言]  [专业选择▾]                          │
│  [🆕翻译当前批次]  [▶️翻译全部未翻项]                   │
│  [💾保存]  [📗术语表]  [🔍搜索...]                       │
│                                                          │
│  [全部 待翻译 已翻译 已审批 已回写 失败]                  │
│  [☐跳过非译内容]                                         │
│                                                          │
│  回写模式：[下拉框▾]  [☐合并图层]  [💾回写到图纸]       │
│                                                          │
│ ┌──────────────────────────────────────────────────────┐ │
│ │  数据表格（Syncfusion SfDataGrid）                   │ │
│ │  ────────┬──────┬──────┬──────┬──────┬──────         │ │
│ │  序号    │原文   │译文   │状态   │位置   │操作        │ │
│ │  ────────┼──────┼──────┼──────┼──────┼──────         │ │
│ │   1      │...   │...   │待翻译│...   │🎯定位       │ │
│ │   2      │...   │...   │已翻译│...   │🎯定位       │ │
│ │  ...     │...   │...   │...   │...   │...           │ │
│ └──────────────────────────────────────────────────────┘ │
│                                                          │
│  已选择N条  [✅批准所选]  [↩退回所选]  [✓✓全部批准]      │
│  [🗑清空所选]                                            │
└──────────────────────────────────────────────────────────┘
```

### 6.3 顶部工具栏

#### 语言对选择

位于窗口左上角，显示当前翻译项目的语言对方向，如"简体中文 → English"。该信息在项目创建时确定，翻译工作台内通常不需要修改。

#### 专业选择下拉框

选择翻译所使用的专业领域，影响术语表匹配和翻译结果的专业性。例如：
- 机械工程
- 土木建筑
- 电气工程
- 化工流程
- 暖通空调

选择合适的专业可以提高翻译准确性。

#### 翻译按钮

| 按钮 | 功能 | 使用场景 |
|------|------|----------|
| 🆕 **翻译当前批次** | 只翻译本次提取的当前批次文字 | 新提取了一批文字，快速翻译 |
| ▶️ **翻译全部未翻项**（蓝色） | 翻译当前图纸所有尚未翻译的条目 | 补充翻译之前遗漏的条目 |

### 6.4 状态筛选与搜索

#### 状态筛选 Chips

表格上方有一排状态筛选标签（Chips），点击即可快速过滤显示对应状态的条目：

| 筛选标签 | 说明 |
|----------|------|
| **全部** | 显示所有条目 |
| **待翻译** | 仅显示尚未翻译的条目 |
| **已翻译** | 仅显示已有译文的条目 |
| **已审批** | 仅显示译文已通过审批的条目 |
| **已回写** | 仅显示已经回写到图纸的条目 |
| **失败** | 仅显示翻译失败或回写失败的条目 |

#### 搜索框

输入关键词，实时过滤表格中的条目，支持在原文和译文中搜索。

#### ☐ "跳过非译内容"

勾选后，标记为非译内容（如数字编号、纯符号等）的条目将不参与翻译操作。

### 6.5 数据表格

数据表格使用 Syncfusion SfDataGrid 控件，具有以下特性：
- **列排序**：点击列标题可按该列升序/降序排列
- **列筛选**：部分列支持下拉筛选条件
- **多选**：支持按住 `Ctrl` 或 `Shift` 进行多项选择
- **行状态颜色**：不同状态的条目用不同颜色标识，一目了然

### 6.6 💾 保存与术语表

#### 💾 保存按钮

将当前翻译工作台所做的修改（译文、审批状态等）保存到项目数据库中。建议定期保存，以免意外关闭窗口导致数据丢失。

#### 📗 术语表按钮

点击后，窗口右侧滑出一个术语表抽屉面板。该面板列出当前项目关联的所有术语，你可以：
- 浏览术语列表
- 搜索特定术语
- 对照术语翻译，确保译文符合项目统一的术语规范

### 6.7 回写操作

回写是将翻译完成的译文写回到 DWG 图纸中的操作。

#### 回写模式

| 模式 | 说明 |
|------|------|
| **覆盖原文** | 译文直接覆盖原文字，原文不再保留 |
| **新建图层** | 译文写入新的独立图层，原文保持不变 |
| **附加到原文** | 译文添加到原文旁边（如"原文 / 译文"格式） |

#### ☐ 合并图层

勾选此选项后，所有译文字将回写到同一个图层中（而非每个实体各自一个图层），便于统一管理译文图层。

#### 💾 "回写到图纸"按钮

点击后，插件会根据当前选择的回写模式和图层设置，将翻译好的文字写入到 DWG 图纸的对应位置。回写完成后，可以在 AutoCAD 绘图区域查看效果。

### 6.8 详情抽屉

在表格中点击某一行，窗口右侧会滑出一个详情抽屉面板，显示该条目的详细信息：

- **对象上下文**：该文字实体在图纸中的位置信息（坐标、图层、所属图块等）
- **QA（质量保证）信息**：如有质量问题标记，会在此显示

### 6.9 🎯 定位按钮

表格中每一行都有一个 **🎯 定位** 按钮。点击后，AutoCAD 会缩放到该文字实体所在的位置并在屏幕中心高亮显示，方便你在图纸中看到该文字的实际上下文。

详见[第7章：定位功能详解](#7-定位功能详解)。

### 6.10 底部操作栏

| 操作 | 功能 |
|------|------|
| **已选择N条** | 实时显示当前表格中选中的条目数量 |
| ✅ **批准所选** | 将当前选中的条目标记为"已审批"，表示翻译质量合格 |
| ↩ **退回所选** | 将当前选中的条目标记为"待翻译"，表示翻译需要重新处理 |
| ✓✓ **全部批准** | 一键批准当前视图中所有条目的译文 |
| 🗑 **清空所选** | 清空当前表格中的多选状态 |

## 7. 定位功能详解

定位功能是插件翻译工作台区别于 Studio 翻译工作区的核心特色之一。它允许你在翻译过程中随时在 AutoCAD 中查看某个文字的实际位置和上下文。

### 7.1 功能说明

当你在翻译工作台的表格中看到一条待翻译的文字（比如"底座"），可能不确定它在图纸中的具体位置和含义（是机械零件的底座，还是电气设备的底座？）。点击 **🎯 定位** 按钮后，AutoCAD 绘图窗口会自动执行以下操作：

1. **缩放视图**：将视图缩放到该文字实体所在位置
2. **居中显示**：将该实体置于屏幕中心
3. **高亮标记**：短暂高亮显示该实体，便于视觉识别

### 7.2 操作步骤

1. 在翻译工作台的表格中找到需要定位的条目
2. 点击该行右侧的 **🎯 定位** 按钮
3. 切换到 AutoCAD 绘图窗口（或翻译工作台窗口会自动将焦点交给 AutoCAD）
4. 在 AutoCAD 中查看该文字实体的位置和周围上下文
5. 确认理解后，返回翻译工作台进行翻译

### 7.3 实用技巧

- **不确定含义时优先定位**：遇到术语或缩写时，先定位查看图纸上下文再翻译，避免望文生义。
- **批量定位**：可以依次点击多条条目的定位按钮，在 AutoCAD 中查看它们的位置关系。
- **定位 + 图层隐藏**：结合使用图层可见性控制（参见[第8章](#8-图层可见性控制)），隐藏干扰图层后，定位效果更加清晰。

## 8. 图层可见性控制

翻译过程中，经常需要对比查看原文和译文的效果。图层可见性控制提供了便捷的切换方式。

### 8.1 侧边面板便捷按钮

位于侧边面板第4区，提供两个快速切换按钮：

| 按钮 | 功能 | 典型用法 |
|------|------|----------|
| 👁 **隐藏/显示原文图层** | 切换源语言文字所在图层的可见性 | 翻译回写后，隐藏原文图层，只查看译文效果 |
| 👁 **隐藏/显示译文图层** | 切换翻译后文字所在图层的可见性 | 回顾原文时，隐藏译文图层，避免干扰 |

这两个按钮是**切换开关**：点击一次隐藏，再点击一次恢复显示。

### 8.2 TWLAYERVIS 命令

`TWLAYERVIS` 是一个交互式图层可见性控制命令，提供更灵活的图层操作方式。

**操作方法**：

1. 在 AutoCAD 命令行输入 `TWLAYERVIS` 并回车
2. 命令行提示选择操作：
   - **Show**：显示指定类型的图层
   - **Hide**：隐藏指定类型的图层
   - **All**：显示所有图层（恢复默认）
3. 根据提示完成操作

**典型场景**：

- 回写完成后，想只看翻译效果 → 使用 `TWLAYERVIS` → Hide → 原文图层
- 只查看原文布局 → 使用 `TWLAYERVIS` → Hide → 译文图层
- 恢复到完整视图 → 使用 `TWLAYERVIS` → All

## 11. 插件端 vs Studio 端对比

理解两者的分工，有助于你选择正确的工具完成对应的任务。

| 操作 | 插件端 | Studio 端 | 推荐 |
|------|--------|-----------|------|
| 创建项目 | ✅ | ✅ | Studio（功能更完整） |
| 关联图纸 | ✅ | ✅ | 插件（操作更直接） |
| 提取文字 | ✅ | ❌ | 插件（唯一方式） |
| 逐条翻译 | ✅ | ✅ | Studio（界面更宽敞） |
| 批量翻译 | ✅ | ✅ | 均适合 |
| 术语管理 | ❌ | ✅ | Studio（唯一方式） |
| 质量审核 | ✅ | ✅ | Studio（审批流程更完整） |
| 回写到图纸 | ✅ | ❌ | 插件（唯一方式） |
| 定位实体 | ✅ | ❌ | 插件（唯一方式） |
| 图层控制 | ✅ | ❌ | 插件（唯一方式） |
| 全局报告 | ❌ | ✅ | Studio（唯一方式） |

### 11.1 什么时候用插件？

- 需要在图纸中查看文字的实际位置
- 需要执行提取或回写操作（这两个操作只能在插件端完成）
- 处理单张图纸的快速翻译
- 只有 AutoCAD 环境，不方便同时打开 Studio

### 11.2 什么时候用 Studio？

- 管理多个项目和图纸
- 维护术语表，进行术语统一
- 需要完整的审批流程和质量控制
- 多人协作翻译同一个项目
- 生成全局翻译进度报告

### 11.3 最佳实践

**推荐的协同工作流程**：
1. 在 **插件端** 打开 DWG → 关联项目 → 整图提取
2. 在 **Studio 端** 打开同一项目 → 集中翻译 → 术语审核 → 质量把关
3. 在 **插件端** 审批结果 → 回写到图纸 → 检查最终效果
4. 如发现问题，在 **Studio 端** 修改译文 → 再次在 **插件端** 回写

## 12. 插件工作流完整示例

下面以一个典型的施工图纸翻译场景为例，展示从打开 DWG 到完成翻译回写的全流程。

### 场景设定

- 图纸：`XX电厂-管道布置图.dwg`
- 源语言：简体中文
- 目标语言：English
- 要求：只翻译图纸中的技术标注文字，图框内容不翻译

### 步骤 1：打开图纸并保存

1. 启动 AutoCAD
2. 打开 `XX电厂-管道布置图.dwg`
3. 确认侧边面板已显示（如未显示，输入 `TW_SHOW_PANEL`）
4. 如果图纸有修改，按 `Ctrl+S` 保存

### 步骤 2：检查连接状态

1. 查看侧边面板底部状态栏
2. 如果显示"未连接到 Studio"，请先打开 Studio，然后输入 `TW_CONNECT` 手动连接
3. 连接成功后，状态栏变为"已连接到 Studio"

### 步骤 3：创建项目并关联图纸

1. 查看顶部状态横幅，应为黄色"当前图纸未关联项目"
2. 点击第1区的 **＋ "新建"** 按钮
3. 在新建项目对话框中填写：
   - 项目名称：`XX电厂管道施工图`
   - 源语言：`简体中文`
   - 目标语言：`English`
4. 点击"确定"
5. 确认顶部状态横幅变为 🟢 绿色："已关联：XX电厂管道施工图"

### 步骤 4：整图提取文字

1. 在第2区，勾选 **☑ "不提取图框文字"**（排除图纸编号、比例尺等内容）
2. 点击 **▣ "整图提取"** 按钮
3. 观察进度显示，等待提取完成
4. 弹出 MessageBox，显示提取统计信息（例如：实体数 256，新增数 198）——记下这些数字
5. 点击"确定"
6. 翻译工作台窗口自动打开

### 步骤 5：逐条审核并翻译

1. 在翻译工作台中，将状态筛选设为"待翻译"
2. 浏览待翻译条目，对每条文字进行翻译：
   - 如果对某条文字的含义不确定，点击 **🎯 定位** 按钮，在 AutoCAD 中查看其位置和上下文
   - 确定了含义后，在译文中输入对应的英文
3. 对于专业术语（如"法兰"、"蝶阀"等），点击 **📗 术语表** 查看标准译法
4. 对于数字编号、纯符号等不需要翻译的内容，可手动标记为"非译内容"
5. 翻译完成一条后，将状态标记为"已翻译"
6. 重复以上步骤，处理所有待翻译条目

### 步骤 6：质量审核

1. 将状态筛选设为"已翻译"，检查所有已翻译条目的译文质量
2. 发现翻译不当的条目，直接修改译文
3. 选中检查通过的条目（按 `Ctrl` 多选或按 `Shift` 范围选择）
4. 点击底部 **✅ "批准所选"** 按钮进行审批
5. 如果需要全部通过，点击 **✓✓ "全部批准"**

### 步骤 7：回写到图纸

1. 确认所有需要回写的条目都已被审批
2. 在回写区域设置回写模式：选择"新建图层"（保留原文以便对比）
3. 勾选 **☐ "合并图层"**（便于统一管理译文）
4. 点击 **💾 "回写到图纸"** 按钮
5. 等待回写进度完成

### 步骤 8：检查回写结果

1. 返回 AutoCAD 绘图窗口
2. 使用侧边面板第4区的 **👁 "隐藏/显示原文图层"** 按钮，隐藏原文图层
3. 查看译文在图纸中的显示效果，确认文字位置、大小、颜色等是否正确
4. 再次点击 **👁 "隐藏/显示原文图层"** 恢复显示原文
5. 如果需要修改，可以使用 `TWLAYERVIS` 命令进行图层切换，方便对比检查

### 步骤 9：最终确认

1. 确认所有译文位置正确、格式一致
2. 在翻译工作台中将状态筛选设为"已回写"，确认所有应该回写的条目都已处理
3. 如需调整，返回 Studio 修改译文，然后再次回写
4. 完成后，在 AutoCAD 中保存图纸（`Ctrl+S`）

### 全流程总结

```
打开DWG → 保存 → 检查连接 → 创建/关联项目 → 整图提取
    → 翻译工作台：逐条翻译 + 术语查证 + 定位确认
    → 审批通过 → 回写到图纸 → 图层检查 → 保存 → 完成
```

## 13. 注意事项与技巧

### 13.1 图纸要求

- **图纸必须已保存**：新建未保存的图纸无法进行项目关联和文字提取。这是因为同文需要根据文件路径来建立图纸与项目的对应关系。
- **文件路径不要包含特殊字符**：某些特殊字符可能导致关联信息存储失败。建议使用英文路径和文件名。
- **大图纸提取可能较慢**：包含数千个文字实体的复杂图纸，提取时间可能超过 1 分钟，请耐心等待。

### 13.2 连接问题排查

- **"未连接到 Studio"**：先检查 Studio 是否已启动。如果已启动但仍未连接，使用 `TW_DISCONNECT` 断开后，再用 `TW_CONNECT` 重新连接。
- **连接频繁断开**：检查防火墙设置，确保 Studio 的网络端口未被阻止。
- **Studio 版本不匹配**：确保插件版本与 Studio 版本一致。版本不一致可能导致功能异常。

### 13.3 翻译质量相关

- **优先使用术语表**：项目中应提前维护好术语表，确保同一术语在整个项目中翻译一致。尤其对于专业图纸，术语统一至关重要。
- **善用定位功能**：不确定含义的文字，一定要先用定位功能在图纸中确认上下文，避免脱离图纸凭想象翻译。
- **逐条审核**：不要急于"全部批准"。至少对关键条目逐一审核，特别是技术参数、材料规格等不得有误的内容。
- **"不提取图框文字"的时机**：处理正规施工图时勾选；处理无图框的概念图、示意图时可取消勾选。

### 13.4 回写相关

- **首次回写前备份**：第一次使用回写功能前，建议先备份 DWG 文件（另存为副本），以防回写设置不当覆盖了重要内容。
- **推荐使用"新建图层"模式**：这样原文和译文分别在不同的图层中，方便后期对比和独立修改。
- **回写后检查**：回写完成后，务必用图层可见性控制检查译文在图纸中的位置、文字大小和颜色是否正确。

### 13.5 效率提升技巧

- **自定义快捷键**：将 `TW_EXTRACT_ALL`（整图提取）、`TW_WORKSPACE`（打开工作台）、`TW_WRITEBACK_FILE`（回写）绑定到 AutoCAD 快捷键，大幅提高操作效率。
- **批量操作**：在翻译工作台中使用多选（`Ctrl` / `Shift`）+ 底部操作按钮，一次性审批/退回多条条目。
- **常看状态横幅**：顶部状态横幅是一切的起点，任何时候不确定当前状态，先看横幅颜色。
- **使用 `TW_STATUS`**：这是你的"帮助"命令，任何时候不确定可用命令或插件状态时使用。

### 13.6 数据安全

- **定期保存**：翻译工作台中的修改记得点击 💾 保存按钮；AutoCAD 中的图纸修改记得 `Ctrl+S` 保存。
- **不要直接关闭 AutoCAD**：如果有未完成的操作（如提取进行中、回写进行中），直接关闭可能导致数据不完整。先完成当前操作再退出。
- **图纸备份**：对于重要的生产图纸，建议在操作前先创建备份副本。

### 13.7 常见问题

| 问题 | 可能原因 | 解决方法 |
|------|----------|----------|
| "关联已有"按钮灰色不可点击 | 图纸未保存 | 先保存图纸（`Ctrl+S`） |
| 提取后翻译工作台为空 | 提取过程中出现错误 | 检查 Studio 连接状态，使用 `TW_CHECK_META` 诊断 |
| 回写后图纸没有变化 | 图层被隐藏 | 使用 `TWLAYERVIS` → All 显示所有图层 |
| 定位按钮点击无反应 | 翻译工作台与图纸失去同步 | 关闭翻译工作台后重新打开 |
| 提取的条目比预期少 | 图框过滤被勾选 | 检查 ☑"不提取图框文字"是否误勾 |
| Studio 中看不到提取的数据 | 网络连接或项目同步问题 | 使用 `TW_STATUS` 检查连接，确认项目关联正确 |
