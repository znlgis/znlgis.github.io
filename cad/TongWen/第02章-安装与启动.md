# 第02章：安装与启动

> **产品官网**：[https://shandianweihu.com/](https://shandianweihu.com/)

本章详细介绍同文（Tongwen）的安装流程与首次启动配置。阅读完本章后，您将能够独立完成从下载安装包、运行安装程序、配置AutoCAD插件到验证产品正常运行的全过程。

---

## 2.1 安装前的准备工作

在动手安装之前，请逐一确认以下条件是否满足，以避免安装过程中出现不必要的错误或中断。

### 2.1.1 操作系统要求

同文仅支持 64 位 Windows 操作系统。具体版本要求如下：

| 操作系统 | 最低版本 | 推荐版本 |
|----------|----------|----------|
| Windows 10 | 版本 1809（Build 17763） | 版本 22H2 或更高 |
| Windows 11 | 版本 21H2 | 版本 23H2 或更高 |

> **注意**：不支持 Windows 7、Windows 8/8.1 以及任何 32 位操作系统。在非 Windows 平台上（如 macOS、Linux）目前没有原生支持。

**如何查看操作系统版本：**
1. 按 `Win + R` 打开"运行"对话框，输入 `winver` 后回车。
2. 在弹出的"关于 Windows"窗口中查看版本号和操作系统位数。
3. 确认显示为"64 位操作系统"。

### 2.1.2 AutoCAD 版本确认

同文以 AutoCAD 插件形式运行翻译功能，因此需要本机已安装受支持的 AutoCAD 版本。

**当前支持的 AutoCAD 版本：**

| AutoCAD 版本 | 年份标识 | 插件框架 |
|--------------|----------|----------|
| AutoCAD 2019 | 2019 | .NET Framework 4.7+ |
| AutoCAD 2021 | 2021 | .NET 6.0 |
| AutoCAD 2025 | 2025 | .NET 8.0 |
| AutoCAD 2026 | 2026 | .NET 8.0 |

> **说明**：您只需安装上述版本中的至少一个即可使用同文。如果安装了多个版本，同文的启动器会自动检测，并允许您选择启动哪个版本。

**关于AutoCAD LT：** 同文的核心功能依赖 AutoCAD 完整的 .NET API，AutoCAD LT 不提供此 API 接口，因此完全不支持在任何版本的 AutoCAD LT 上加载和运行。

**如何查看已安装的 AutoCAD 版本：**
1. 打开 AutoCAD，点击左上角的大"A"图标（或应用程序菜单）。
2. 选择"关于 AutoCAD"（或直接执行 `ABOUT` 命令）。
3. 在弹出窗口中查看产品名称和版本号。例如"AutoCAD 2025"即表示安装了 2025 版本。

如果尚未安装 AutoCAD，请先从 Autodesk 官方网站获取并安装，再继续同文的安装。

### 2.1.3 .NET 运行时环境检查

同文的不同组件依赖不同的 .NET 运行时，这些运行时必须预先安装在系统中。

**各组件对应运行时依赖：**

| 组件 | 所需运行时 | 说明 |
|------|-----------|------|
| AutoCAD 2019 插件 | .NET Framework 4.7.2 或更高 | Windows 10/11 通常已内置 |
| AutoCAD 2021 插件 | .NET 6.0（桌面运行时） | 需单独安装 |
| AutoCAD 2025/2026 插件 | .NET 8.0（桌面运行时） | 需单独安装 |
| Studio 主程序 | .NET 8.0（桌面运行时） | 需单独安装 |

**检查 .NET Framework 版本：**
1. 按 `Win + R`，输入 `regedit` 打开注册表编辑器。
2. 导航至 `HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\NET Framework Setup\NDP\v4\Full`。
3. 查看 `Release` 项的数值。如果该值大于或等于 461808，则表示已安装 .NET Framework 4.7.2 或更高版本。

**检查 .NET 6.0 / .NET 8.0 桌面运行时：**
1. 打开命令提示符（cmd）或 PowerShell。
2. 输入命令 `dotnet --list-runtimes`。
3. 在输出中查找是否包含 `Microsoft.NETCore.App 6.0.x` 和 `Microsoft.NETCore.App 8.0.x`，同时确认对应的 `Microsoft.WindowsDesktop.App` 条目存在。

**下载运行时：**
如果缺少必要的运行时，请从微软官方网站下载安装：

- .NET 6.0 桌面运行时：[https://dotnet.microsoft.com/download/dotnet/6.0](https://dotnet.microsoft.com/download/dotnet/6.0)
  - 下载页中选择 "Windows" → "Desktop Runtime" → "x64" 安装包
- .NET 8.0 桌面运行时：[https://dotnet.microsoft.com/download/dotnet/8.0](https://dotnet.microsoft.com/download/dotnet/8.0)
  - 下载页中选择 "Windows" → "Desktop Runtime" → "x64" 安装包

> **提示**：如果您同时安装了 AutoCAD 2021 和 2025/2026，则需要同时安装 .NET 6.0 和 .NET 8.0 两种桌面运行时。安装顺序不限。

### 2.1.4 用户权限

安装同文需要本地管理员权限。请确保您使用的 Windows 账户属于 "Administrators" 组。如果您使用的是公司配发的电脑且有 IT 管理策略限制，可能需要联系 IT 部门协助完成安装。

## 2.2 获取安装包

### 2.2.1 官网下载（推荐）

推荐从同文产品官网获取最新版安装包：

1. 在浏览器中打开产品官网：[https://shandianweihu.com/](https://shandianweihu.com/)
2. 导航至"下载"或"产品下载"页面。
3. 找到同文（Tongwen）最新版本的 MSI 安装包，点击下载。
4. 下载文件通常命名为 `Tongwen_Setup_vX.X.X.msi`（其中 `X.X.X` 为具体版本号）。

### 2.2.2 安装包校验（可选）

为了确保下载的安装包没有被篡改或损坏，建议对下载的 MSI 文件进行校验：

1. 在官网下载页面找到对应版本的 SHA256 校验值。
2. 在 PowerShell 中执行以下命令计算文件哈希：

   ```powershell
   Get-FileHash -Path "下载文件路径\Tongwen_Setup_vX.X.X.msi" -Algorithm SHA256
   ```

3. 将输出的 Hash 值与官网公布的 SHA256 值对比，确认一致。

## 2.3 MSI 安装步骤详解

同文使用 WixSharp 构建的 MSI 安装包进行分发。MSI（Microsoft Installer）是 Windows 平台标准的安装格式，支持静默安装、日志记录和企业批量部署。

### 2.3.1 启动安装向导

1. 在文件资源管理器中找到下载好的 MSI 文件。
2. 右键点击文件，选择"以管理员身份运行"（或直接双击，系统会弹出 UAC 提示，点击"是"确认）。
3. 安装向导启动，首先显示欢迎页面。

### 2.3.2 阅读并接受许可协议

1. 安装向导第二页显示《最终用户许可协议》（EULA）。
2. 请仔细阅读协议条款。
3. 勾选"我接受许可协议中的条款"复选框。
4. 点击"下一步"继续。

**如果无法接受许可协议：** 点击"取消"退出安装。不接受许可协议将无法继续使用本产品。

### 2.3.3 选择安装路径

1. 在"目标文件夹"页面选择安装目录。
2. 默认路径为：`C:\Program Files\Tongwen\`
3. 若要更改路径，点击"更改"（或"浏览"）按钮，选择其他磁盘或目录。

> **建议**：
> - 如果系统盘（C盘）空间充足（剩余 2 GB 以上），使用默认路径即可。
> - 如果系统盘空间紧张，可以改到其他分区如 `D:\Program Files\Tongwen\`。
> - 安装路径中不要包含中文、空格或特殊字符，以确保组件能正常注册和加载。

### 2.3.4 选择安装组件

自定义安装页面列出可供安装的组件。您可以根据实际安装的 AutoCAD 版本选择性安装：

| 组件名称 | 说明 | 是否需要 |
|----------|------|----------|
| Studio 主程序 | 桌面WPF程序，用于术语库管理、翻译配置、项目设置 | 必选 |
| AutoCAD 2019 插件 | 适用于 AutoCAD 2019 的插件（DLL/ARX） | 若安装了 AutoCAD 2019 则勾选 |
| AutoCAD 2021 插件 | 适用于 AutoCAD 2021 的插件（DLL/ARX） | 若安装了 AutoCAD 2021 则勾选 |
| AutoCAD 2025 插件 | 适用于 AutoCAD 2025 的插件（DLL/ARX） | 若安装了 AutoCAD 2025 则勾选 |
| AutoCAD 2026 插件 | 适用于 AutoCAD 2026 的插件（DLL/ARX） | 若安装了 AutoCAD 2026 则勾选 |

> **提示**：如果不确定以后是否会用到某个 AutoCAD 版本，可以全部勾选——插件占用空间极小（每个版本约 5–15 MB），全部安装也不会造成负担。

### 2.3.5 确认安装

1. 点击"安装"按钮开始正式安装过程。
2. 安装程序将文件复制到目标目录、注册COM组件、写入注册表信息。
3. 进度条显示安装进度，整个过程通常在一分钟内完成。
4. 安装完成后，点击"完成"退出向导。

> **勾选"启动同文 Studio"复选框**：安装完成页通常会有一个"启动同文 Studio"的选项，勾选后点击完成即可立即启动程序。建议勾选以进入首次配置向导。

### 2.3.6 静默安装（高级用户）

如果需要在多台机器上批量部署，可以使用 MSI 静默安装模式：

```powershell
# 基本静默安装（使用默认选项）
msiexec /i "Tongwen_Setup_vX.X.X.msi" /quiet /norestart

# 指定安装路径
msiexec /i "Tongwen_Setup_vX.X.X.msi" /quiet INSTALLDIR="D:\Tools\Tongwen" /norestart

# 生成安装日志（方便排查问题）
msiexec /i "Tongwen_Setup_vX.X.X.msi" /quiet /log "C:\Temp\tongwen_install.log" /norestart
```

## 2.5 首次启动向导

首次启动同文时，您需要完成一些必要的初始配置。以下是详细的步骤指引。

### 2.5.1 启动 Studio 主程序

有三种方式可以启动同文 Studio：

1. **桌面快捷方式**：安装程序通常会在桌面创建"同文 Studio"快捷方式，双击即可启动。
2. **开始菜单**：点击"开始"→ 找到"Tongwen" 或 "同文"程序组 → 点击"同文 Studio"。
3. **安装目录直接启动**：进入安装目录，双击 `Tongwen.Studio.exe`。

首次启动时，如果系统提示 Windows Defender 防火墙警告，请选择"允许访问"，以确保 Studio 能与本地 AutoCAD 进程正常通信。

### 2.5.2 启动器界面概览

同文启动器（`Tongwen.Launcher.exe`）是一款小巧的工具程序，负责检测系统中已安装的 AutoCAD 版本并启动对应的 AutoCAD 进程。

启动器打开后，您会看到：

- **欢迎标题与版本号**（如"同文启动器 v2.1.0"）
- **已检测到的 AutoCAD 版本列表**：启动器自动扫描 Windows 注册表，列出所有已安装的 AutoCAD 版本。每个版本条目显示版本号（如"AutoCAD 2025"）和安装路径。
- **配置按钮**：进入启动器设置，可调整默认行为。
- **启动按钮**：选中某个 AutoCAD 版本后，点击按钮启动该版本并尝试加载同文插件。

### 2.5.3 AutoCAD 版本检测原理与手动刷新

启动器通过读取 Windows 注册表中的 AutoCAD 安装信息来检测已安装的版本。具体检测路径如下：

- `HKEY_LOCAL_MACHINE\SOFTWARE\Autodesk\AutoCAD\R23.1` → AutoCAD 2019
- `HKEY_LOCAL_MACHINE\SOFTWARE\Autodesk\AutoCAD\R24.0` → AutoCAD 2021
- `HKEY_LOCAL_MACHINE\SOFTWARE\Autodesk\AutoCAD\R24.2` → AutoCAD 2025
- `HKEY_LOCAL_MACHINE\SOFTWARE\Autodesk\AutoCAD\R24.3` → AutoCAD 2026

**如果启动器未检测到已安装的 AutoCAD 版本：**
1. 确认 AutoCAD 确实已正常安装（能独立启动运行）。
2. 在启动器中点击"刷新"按钮，重新扫描注册表。
3. 如果仍然未检测到，可能是注册表信息不完整，尝试启动一次 AutoCAD 并正常关闭，使系统补全注册表信息。
4. 如果问题依旧，请参考本章 [2.9 常见安装问题](#29-常见安装问题)。

### 2.5.4 选择默认 AutoCAD 版本

如果您的电脑上安装了多个受支持的 AutoCAD 版本，启动器会全部列出。您需要选择一个作为"默认版本"：

1. 在版本列表中，点击您最常用的 AutoCAD 版本。
2. 点击"设为默认"按钮（或从右键菜单中选择"设为默认版本"）。
3. 此后启动器打开时将自动选中该版本，您可以直接点击"启动"进入。

> **提示**：您随时可以在启动器中更改默认版本。此设置保存在 `launcher.json` 配置文件中。

## 2.6 AutoCAD 插件注册

为了让同文插件在 AutoCAD 启动时自动加载，需要将其信息写入 Windows 注册表。同文提供了自动注册和手动注册两种方式。

### 2.6.1 自动注册（推荐）

启动器内置了一键注册功能，操作方法如下：

1. 打开同文启动器。
2. 在版本列表中选择目标 AutoCAD 版本。
3. 点击"注册插件"按钮。
4. 系统可能弹出 UAC 提示（因为注册表写入需要管理员权限），点击"是"确认。
5. 提示"插件注册成功"后，完成注册。

自动注册会向以下注册表位置写入信息：

```
HKEY_CURRENT_USER\SOFTWARE\Autodesk\AutoCAD\<版本号>\ACAD-xxxx:xxx\Applications\Tongwen
```

> **说明**：写入的是当前用户（HKCU）的注册表，不需要管理员权限。如果希望通过 HKEY_LOCAL_MACHINE（HKLM）为所有用户注册，则需要以管理员身份运行启动器。

### 2.6.2 注册表自启动原理

注册后，AutoCAD 在启动时会自动扫描注册表中的 `Applications` 键，加载注册在此处的插件程序集。这意味着：

- 每次启动 AutoCAD，同文插件会自动加载，无需手动操作。
- 您可以在 AutoCAD 命令行中输入同文命令，直接使用翻译功能。

### 2.6.3 取消注册

如果需要临时禁用同文插件的自动加载：

1. 打开启动器。
2. 选择已注册的 AutoCAD 版本。
3. 点击"取消注册"按钮。
4. 注册表相关条目将被移除，下次启动 AutoCAD 时插件不再自动加载。

## 2.7 启动 AutoCAD 并加载插件

同文插件支持三种加载方式。根据使用场景选择最合适的方式。

### 2.7.1 方式一：通过启动器启动（推荐）

这是最便捷、最推荐的启动方式：

1. 打开同文启动器（`Tongwen.Launcher.exe`）。
2. 确认默认版本正确，或手动选择目标 AutoCAD 版本。
3. 点击"启动"按钮。
4. 启动器会自动启动对应版本的 AutoCAD，并确保插件被正确加载。
5. AutoCAD 启动后，在命令行中输入 `TW_STATUS` 并回车，如果显示"同文插件已就绪"则表示加载成功。

> **启动器启动的优势**：
> - 自动处理不同 AutoCAD 版本的命令行参数差异
> - 支持"新建空白图纸"或"打开最近项目"两种启动模式
> - 记录插件加载日志，方便问题排查

### 2.7.2 方式二：SCR脚本 NETLOAD（无需注册表）

如果不想修改注册表，或者需要临时加载插件，可以使用脚本方式：

1. 先用通常方式启动 AutoCAD。
2. 在命令行中输入 `NETLOAD` 并回车。
3. 在弹出的文件选择对话框中，浏览到安装目录下的 `Plugins\AutoCAD20XX\Tongwen.Cad20XX.dll` 文件。
4. 选中 DLL 文件，点击"打开"。
5. 加载成功后命令行会显示提示信息。

**批量加载脚本：**

如果需要频繁手动加载，可以创建一个 SCR 脚本文件来简化操作：

1. 新建一个文本文件，命名为 `LoadTongwen.scr`。
2. 文件内容如下（请根据实际路径修改）：

   ```
   NETLOAD
   "C:\Program Files\Tongwen\Plugins\AutoCAD2025\Tongwen.Cad2025.dll"
   ```

3. 在 AutoCAD 命令行中输入 `SCRIPT`，选择此文件执行。

### 2.7.3 方式三：手动 NETLOAD

每次需要使用时手动加载插件：

1. 启动 AutoCAD。
2. 在命令行输入 `NETLOAD`。
3. 浏览并选择对应版本的插件 DLL。
4. 点击"打开"完成加载。

> **适用场景**：适用于偶尔使用同文功能、不愿修改系统配置的用户，或用于临时加载非默认版本的插件。

## 2.8 启动验证

完成以上步骤后，需要验证插件是否成功加载并能正常工作。

### 2.8.1 检查插件加载状态

在 AutoCAD 命令行中输入以下命令来检查插件状态：

```
TW_STATUS
```

**可能的输出及含义：**

| 输出信息 | 含义 | 处理建议 |
|----------|------|----------|
| 同文插件已就绪 | 插件加载成功，所有功能正常 | 可以开始使用 |
| 未找到插件 | 插件未加载 | 检查注册表或手动 NETLOAD 加载 |
| 插件版本不匹配 | 插件 DLL 版本与当前 AutoCAD 版本不兼容 | 确认加载了正确版本的插件 DLL |
| API Key 未配置 | 插件加载成功但未设置翻译 API Key | 在 Studio 中配置 DeepSeek API Key |
| 连接 Studio 失败 | 插件无法与 Studio 主程序通信 | 确认 Studio 正在运行 |

### 2.8.2 验证翻译功能

1. 在 AutoCAD 中绘制或打开一张包含文字（TEXT、MTEXT）的图纸。
2. 在命令行输入翻译命令（具体命令名称请参考后续章节）。
3. 如果弹出了翻译预览窗口或直接在图纸上显示了翻译结果，表示功能正常工作。

### 2.8.3 验证 Studio 连接

1. 确保同文 Studio 主程序正在运行。
2. 在 Studio 主界面中查看状态栏，确认显示"已连接"状态。
3. 在 Studio 中打开术语库管理页面，确认能够正常浏览和编辑术语条目。

### 2.8.4 检查日志文件

如果任何步骤未按预期工作，可以查看日志文件定位问题。日志文件位置：

```
%LocalAppData%\Tongwen\Logs\
```

- `studio.log` — Studio 主程序日志
- `launcher.log` — 启动器日志
- `cad2025.log`（或其他版本号）— CAD 插件日志

使用记事本或其他文本编辑器打开日志文件，查找 `ERROR` 或 `WARN` 关键词以快速定位问题行。

## 2.9 常见安装问题

以下是安装与启动过程中常见的问题及解决方法。

### 问题 1：安装时提示"无法写入注册表"

**现象**：安装过程中弹出错误提示，内容包含"无法写入注册表"或"拒绝访问"。

**原因**：当前用户缺少管理员权限。

**解决方法**：
1. 关闭安装向导。
2. 右键点击 MSI 安装文件，选择"以管理员身份运行"。
3. 输入管理员凭据后重新安装。

### 问题 2：安装完成后启动 Studio 提示缺少 .NET 运行时

**现象**：双击 `Tongwen.Studio.exe` 后弹出错误窗口，提示"需要安装 .NET 8.0"或"找不到指定的框架"。

**原因**：系统中未安装 .NET 8.0 桌面运行时。

**解决方法**：
1. 访问 [https://dotnet.microsoft.com/download/dotnet/8.0](https://dotnet.microsoft.com/download/dotnet/8.0)
2. 下载并安装 "Windows x64 Desktop Runtime"。
3. 重启电脑后再次尝试启动 Studio。

### 问题 3：启动器提示"未检测到 AutoCAD"

**现象**：启动器中版本列表为空，显示"未检测到支持的 AutoCAD 版本"。

**原因**：
- 系统中确实未安装受支持的 AutoCAD 版本（2019/2021/2025/2026）。
- 注册表中缺少 AutoCAD 安装信息。
- 安装了不受支持的 AutoCAD LT 版本。

**解决方法**：
1. 确认已安装 AutoCAD 2019、2021、2025 或 2026 的标准版（非 LT 版）。
2. 尝试手动启动一次 AutoCAD，正常打开并关闭。
3. 在启动器中点击"刷新"按钮。
4. 如果问题依旧，打开命令提示符（以管理员身份），运行以下命令检查注册表：

   ```cmd
   reg query "HKLM\SOFTWARE\Autodesk\AutoCAD" /s | findstr "R23.1 R24.0 R24.2 R24.3"
   ```

   如果没有输出，说明 AutoCAD 的注册表信息缺失，建议重新安装 AutoCAD。

### 问题 4：插件加载后 AutoCAD 崩溃或闪退

**现象**：启动 AutoCAD 后加载同文插件时，AutoCAD 直接关闭或无响应。

**原因**：
- .NET 运行时版本不匹配（如加载 2025 插件但没有安装 .NET 8.0）。
- 插件 DLL 文件损坏。
- 与其他 AutoCAD 插件冲突。

**解决方法**：
1. 确认对应版本的 .NET 运行时已正确安装（见 [2.1.3 节](#213-net-运行时环境检查)）。
2. 尝试重新安装同文以修复可能损坏的插件文件。
3. 临时禁用其他 AutoCAD 插件，逐个排查冲突来源。
4. 查看日志文件 `%LocalAppData%\Tongwen\Logs\cad20XX.log` 获取崩溃前的错误信息。

### 问题 5：翻译功能提示"API Key 未配置"

**现象**：在 AutoCAD 中执行翻译命令时，提示"API Key 未配置"或"翻译服务不可用"。

**原因**：尚未在 Studio 中配置 DeepSeek API Key。

**解决方法**：
1. 打开同文 Studio 主程序。
2. 点击左栏的"设置"（或齿轮图标），进入设置页面。
3. 找到"翻译服务"或"API 设置"部分。
4. 在 "DeepSeek API Key" 输入框中输入您的 API Key。
5. 点击"测试连接"确认 Key 有效。
6. 点击"保存"使配置生效。
7. 回到 AutoCAD 中重新尝试翻译功能。

> **获取 DeepSeek API Key**：请访问 DeepSeek 平台官网注册并获取 API Key。API Key 是使用翻译功能的必要条件。

### 问题 6：Studio 无法连接 AutoCAD 插件

**现象**：Studio 状态栏显示"未连接"，翻译功能无法从 AutoCAD 中调用。

**原因**：
- Studio 主程序未启动。
- 防火墙阻止了 Studio 与 AutoCAD 之间的本地通信。
- 插件加载未成功。

**解决方法**：
1. 确保 Studio 主程序正在运行。
2. 在 AutoCAD 命令行中输入 `TW_STATUS` 确认插件状态。
3. 检查 Windows 防火墙设置，确保 `Tongwen.Studio.exe` 被允许通过专用网络通信。
4. 尝试重启 Studio 并以管理员身份运行。

### 问题 7：同时安装了多个 AutoCAD 版本，插件加载了错误版本

**现象**：使用 AutoCAD 2025，但加载的却是 2019 版本插件，导致功能异常。

**原因**：注册表中为不同版本写入了错误的插件路径。

**解决方法**：
1. 打开启动器。
2. 对 **所有** 已注册的 AutoCAD 版本执行"取消注册"操作。
3. 仅为您实际使用的 AutoCAD 版本执行"注册插件"。
4. 重新通过启动器启动 AutoCAD。

## 2.10 卸载步骤

如果不再需要使用同文，可以按照以下步骤完整卸载。

### 2.10.1 通过 Windows 设置卸载（推荐）

1. 按 `Win + I` 打开 Windows 设置。
2. 点击"应用"（或"应用和功能"）。
3. 在应用列表中找到"同文" 或 "Tongwen"。
4. 点击该项，选择"卸载"。
5. 按照卸载向导提示完成操作。

### 2.10.2 通过安装目录卸载

1. 打开安装目录（默认为 `C:\Program Files\Tongwen\`）。
2. 双击 `uninstall.exe`。
3. 按照提示完成卸载。

### 2.10.3 清理残留数据

卸载程序不会自动删除用户数据文件。如果您希望彻底清除所有同文相关数据，请手动删除以下目录：

| 路径 | 内容 | 是否建议删除 |
|------|------|-------------|
| `文档\Tongwen\` | 项目文件、术语库 | 若不再使用可删除，建议先备份 |
| `%LocalAppData%\Tongwen\` | 日志、临时文件、缓存 | 可直接删除 |
| `%AppData%\Tongwen\` | 用户配置（如果存在） | 建议删除以完全清除配置 |

**路径说明：**
- `文档\Tongwen\` 即 `C:\Users\<用户名>\Documents\Tongwen\`
- `%LocalAppData%\Tongwen\` 即 `C:\Users\<用户名>\AppData\Local\Tongwen\`
- `%AppData%\Tongwen\` 即 `C:\Users\<用户名>\AppData\Roaming\Tongwen\`

### 2.10.4 清理注册表残留（高级操作）

如果卸载后发现有注册表残留（通常不会影响系统），可通过以下方式彻底清理：

1. 按 `Win + R`，输入 `regedit` 打开注册表编辑器。
2. 导航至 `HKEY_CURRENT_USER\SOFTWARE\Tongwen`，删除该键。
3. 导航至 `HKEY_CURRENT_USER\SOFTWARE\Autodesk\AutoCAD\<版本>\Applications\Tongwen`，删除该键。
4. 导航至 `HKEY_LOCAL_MACHINE\SOFTWARE\Tongwen`（如果存在），删除该键。

> **警告**：操作注册表编辑器前请务必备份注册表。删除错误的键可能影响系统或其他软件的正常运行。如果您不熟悉注册表操作，建议跳过此步骤。

## 2.11 数据目录说明

同文的所有用户数据都存储在用户目录中，不会写入安装目录。这样的设计便于重装系统时备份和迁移数据。

### 目录总览

| 目录路径 | 存储内容 | 说明 |
|----------|----------|------|
| `文档\Tongwen\Projects\` | 翻译项目文件 | 每个翻译任务保存为一个项目 |
| `文档\Tongwen\Glossaries\` | 术语库文件 | 用户自定义的翻译术语映射表 |
| `文档\Tongwen\Export\` | 导出文件 | 翻译结果导出为 DWG/DXF 等格式 |
| `%LocalAppData%\Tongwen\Logs\` | 日志文件 | 程序运行日志，用于排查问题 |
| `%LocalAppData%\Tongwen\Cache\` | 缓存文件 | API 翻译结果缓存，提升响应速度 |
| `%LocalAppData%\Tongwen\Temp\` | 临时文件 | 处理过程中的临时数据 |
| 安装目录 `\tongwen.p1.json` | 全局配置 | API Key、界面语言、翻译偏好等 |
| 安装目录 `\launcher.json` | 启动器配置 | 默认版本、窗口尺寸等 |

### 2.11.1 备份建议

如果您需要定期备份同文数据，建议重点备份以下内容：

1. **`文档\Tongwen\Projects\`** — 翻译项目是最有价值的数据，建议定期备份到云盘或外部硬盘。
2. **`文档\Tongwen\Glossaries\`** — 术语库是长期积累的翻译知识资产，丢失后难以重建。
3. **`tongwen.p1.json`** — 全局配置备份可以免除重新配置的麻烦。注意该文件包含 API Key，请妥善保管。

### 2.11.2 迁移到新电脑

更换电脑时，可按以下步骤迁移数据：

1. 在新电脑上安装同文（按本章 [2.3 节](#23-msi-安装步骤详解) 操作）。
2. 将旧电脑的 `文档\Tongwen\` 整个文件夹复制到新电脑的 `文档\` 目录下。
3. 将旧电脑的 `tongwen.p1.json` 文件复制到新电脑的安装目录，覆盖新生成的文件。
4. 启动同文 Studio，检查项目列表和术语库是否正常显示。
