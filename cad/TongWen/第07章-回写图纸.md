# 第07章：回写图纸

> **产品官网**：[https://shandianweihu.com/](https://shandianweihu.com/)

---

## 7.1 本章概述

回写图纸是同文（Tongwen）翻译工作流中承上启下的关键环节。如果说前面的章节解决了"如何提取文字""如何翻译文字""如何审校译文"，那么本章要回答的问题是：**如何将翻译好的文字安全、精确、可控地写回 DWG 图纸，生成完整的译文图纸。**

回写不是简单的"把翻译结果粘贴进图纸"。它需要解决一系列技术挑战：原文是否保留？译文放在哪一层？字体样式是否继承？坐标位置是否对准？如果某个翻译单元质量不合格（QA 阻断），是否还能被回写？如果一次翻译不完美，第二次回写会怎样？

同文通过三种回写策略、灵活的合并图层选项和可控的输出位置配置，为上述问题提供了完整的答案。本章将从概念到操作，逐一展开。

**本章阅读建议**：如果您是第一次使用回写功能，请务必从 7.2 节（回写概述）开始，建立对回写机制的整体认知。如果您只关心"怎么操作"，可以直接跳至 7.4 节（回写操作步骤）。如果您遇到了具体的问题，可以查阅 7.10 节（常见问题与排查）。

## 7.2 回写概述

### 7.2.1 什么是回写

在同文的翻译工作流中，"回写"是指将翻译工作台中已完成翻译（且通过审批）的译文内容，按照指定的策略写回到原始 DWG 图纸中的过程。回写的输出是一个新的 DWG 文件——**原始图纸不会被修改**，所有翻译改动都发生在新的输出文件中。

这意味着回写操作是**非破坏性**的：原始图纸始终保持不变，您可以反复尝试不同的回写策略，而无需担心"改坏了原图"。

### 7.2.2 为什么需要回写策略

在实际工程图纸翻译中，不同场景对译文"如何出现在图纸上"有着完全不同的需求。举几个典型的场景：

- **场景 A**：国内某设计院需要将一套建筑平面图翻译为英文，同时保留中文版存档。交付给海外业主的是英文版，但内部后续还要基于中文版做设计变更。这种情况下，译文和原文需要物理分离——原文留在原图层，译文写入新图层，方便随时对比和切换。

- **场景 B**：某海外施工项目，施工队只懂英文，图纸本身就是纯英文版。翻译公司收到中文版后直接翻译为英文即可，不需要保留中文原文。这种情况下，译文直接覆盖原文是最简单高效的做法。

- **场景 C**：某中外合资项目，监理方要求图纸同时显示中文和英文，方便中方施工队和外方监理同时使用同一张图纸进行现场核查。这种情况下，译文和原文需要同时出现在图纸上。

同文针对这三种典型场景，分别设计了三种回写策略。

### 7.2.3 回写在翻译流程中的位置

在完整的同文翻译工作流中，回写处于流程的末尾环节：

```
创建项目 → 新建翻译会话 → 提取图纸文字 → (可选)配置术语库
    → 机器翻译/人工翻译 → 条目审校 → QA 质量检查 → ★回写图纸 → 验证输出
```

理解这一位置很重要：回写依赖前面的所有环节。如果提取漏掉了文字，翻译时就会有缺失；如果 QA 审校尚未通过，对应翻译单元就会被阻止回写。回写的质量直接取决于前序步骤的质量。

## 7.3 三种回写策略详解

同文提供三种回写策略，在创建翻译会话时即可在回写配置中进行选择。下面逐一详解每种策略的工作原理、输出效果、优点、局限和典型适用场景。

### 7.3.1 策略一：创建新图层（isolatedlayer）

**这是同文的默认回写策略，也是推荐的首选模式。**

#### 工作原理

回写时，同文会为每个包含原文的图层创建一个对应的译文图层。新图层的命名规则为：**`原图层名` + `后缀`**（后缀可在设置中配置，默认为 `_EN` 或 `_T`，取决于目标语言）。例如：

| 原文图层 | 译文图层（后缀为 `_EN`） |
|----------|-------------------------|
| 建筑-文字 | 建筑-文字_EN |
| 结构-注释 | 结构-注释_EN |
| ELEC-TEXT | ELEC-TEXT_EN |

原文文字实体保持完全不动，译文文字实体被创建在对应的新图层中。原文和译文在空间上完全重叠（坐标、旋转角度、对齐方式均与原文一致），但分属不同图层。

#### 输出文件

输出文件命名为：**`{原始文件名}_translated.dwg`**

例如原始文件为 `二层平面图.dwg`，则输出文件为 `二层平面图_translated.dwg`。

原始文件不会被修改，输出文件与原始文件位于同一目录（或您配置的输出目录，详见 7.6 节）。

#### 输出效果

打开输出的 DWG 文件后，在 AutoCAD 图层管理器中，您将看到：

- 原始图层（如 `建筑-文字`）：原文存在，译文不存在
- 译文图层（如 `建筑-文字_EN`）：译文存在，原文不存在

由于两个图层默认都是打开状态，您在图纸上同时看到原文和译文叠在一起。但通过 **冻结** 或 **关闭** 某一组图层，您可以立即切换显示：

- 冻结所有 `_EN` 图层 → 只显示原文版本
- 冻结所有非 `_EN` 的文字图层 → 只显示译文版本

（同文的 AutoCAD 插件提供一键切换图层可见性的按钮，详见 7.8 节。）

#### 优点

1. **完全非破坏性**：原文毫发无损，任何时候都可以关闭译文图层恢复原始图纸样式。
2. **可对比**：原文和译文同时存在，方便人工逐条对照检查翻译质量。
3. **可回退**：如果对翻译结果不满意，修改翻译后再回写一次即可，不会产生任何"不可逆"的后果。
4. **适合协作**：图纸交付后，接收方可以自主选择显示哪种语言版本。
5. **图层结构清晰**：每个专业的文字都独立成层，便于后续的图层管理和打印样式设置。

#### 局限

1. 输出图纸的文件大小会比原文略大（因为同时包含了原文和译文两套文字实体）。
2. 如果原文本身已经有很多图层，译文图层会让图层列表翻倍——图层管理可能变得冗长（可通过"合并图层"选项缓解，详见 7.4 节）。

#### 适用场景

- **推荐给所有用户作为默认选择**。除非您有特殊理由选择其他模式，否则始终选择此模式。
- 需要保留原文对照的图纸交付。
- 翻译质量需要人工复核的场合。
- 同一图纸将来可能需要再次修改和重新翻译。
- 多语种版本归档（先回写英文版，再回写日语版，每个语种的译文都在独立的图层中）。

---

### 7.3.2 策略二：原位替换（inplace）

**此为破坏性策略，使用前请确认您确实不再需要原文。**

#### 工作原理

回写时，同文直接修改原始文字实体的文本内容——将原文替换为译文。整个过程中不创建新图层，不添加新文字实体，所有文字实体保持在原有的图层上不变。

这意味着：原文内容被**永久替换**，在输出的 DWG 文件中无法恢复原文。

#### 输出文件

输出文件同样命名为：**`{原始文件名}_translated.dwg`**，原始文件不会被修改。

但由于输出文件中原文已不存在，如果再次用这个输出文件作为源文件进行新的翻译会话，原文提取将无从谈起。

#### 输出效果

打开输出的 DWG 文件后，图纸外观与原始图纸完全一致——同样的图层、同样的文字数量、同样的布局结构。唯一的区别是：每条文字的内容变成了翻译后的语言。

#### 优点

1. **图纸结构保持不变**：不增加新图层，图层列表与原始图纸完全一致。适合需要"一张纯净图纸"的场合。
2. **文件大小不增加**：文字实体数量不变，只是内容发生了替换，文件体积基本不变。
3. **无需管理图层**：接收方打开图纸后看到的就是最终译文，无需任何图层切换操作。

#### 局限

1. **破坏性**：原文永久丢失。如果翻译有误，需要重新从原始图纸开始整个提取→翻译→回写流程。
2. **不可对比**：无法在同一张图纸上看到原文和译文的对比。
3. **不可回退**：一旦回写完成，输出文件中不存在原文的任何痕迹（除非您重新从原始图纸提取）。
4. **协作局限**：交付给外方后，中方的工程师如果需要参考图纸，必须返回查看原始文件。

#### 适用场景

> ⚠️ **警告**：此模式适合以下场景，但即使符合条件，也建议先用"创建新图层"模式生成一个对照版，确认无误后再改用"原位替换"生成交付版。

- **纯外文出图**：图纸本身就是全外文设计，翻译为中文后直接存档，不再需要对照原文。
- **最终交付版本**：经过多轮审校确认翻译无误后，用此模式生成"纯净"的最终交付版。
- **图纸图层已经非常多**：不希望再增加一倍图层时。但更好的替代方案是使用"创建新图层"模式并启用"合并图层"选项（详见 7.4 节）。
- **特殊输出需求**：某些下游软件（如特定的数控机床读取 DWG 时）对图层数量有限制，此时必须保持图层数量不变。

### 7.3.3 策略三：双语追加（bilingualappend）

**此策略适合需要原文和译文同时展示在同一位置的场景。**

#### 工作原理

回写时，同文不创建新图层，而是**直接修改原文文字实体的内容**，将其格式调整为：**`{原文} / {译文}`**（分隔符可在设置中配置，默认为空格加斜杠加空格）。

例如，原文为"混凝土强度等级"，译文为"Concrete Strength Grade"，则回写后该文字实体的内容变为：

```
混凝土强度等级 / Concrete Strength Grade
```

文字实体保持在原始图层上不变。整个过程不创建新图层。

#### 输出文件

输出文件命名为：**`{原始文件名}_translated.dwg`**。

#### 输出效果

打开输出的 DWG 文件后，图纸中的每条文字都变成了双语格式。原文在前，译文在后，中间以分隔符连接。接收方无需任何操作即可同时看到两种语言。

#### 注意：文字变长问题

双语追加会导致每个文字实体的内容长度显著增加。原文和译文的长度都是不可控的，拼接后可能变成原文的数倍长度。这可能导致以下问题：

- **文字超出预留空间**：原文文字可能位于狭窄的标注空间内，追加译文后文字串会溢出原有包围盒。
- **对齐方式偏差**：如果原文是居中对齐或右对齐，文字变长后对齐效果可能不符合预期。
- **MText 排版混乱**：多行文字（MText）在追加译文后，换行位置和段落排版可能被破坏。

对于这些问题，同文的处理方式是：**尽力保持原文的文字样式和定位参数不变**，但对于溢出和排版问题，建议回写后在 AutoCAD 中手动微调。

#### 优点

1. **一目了然**：原文和译文同时出现，适合施工现场对照检查。
2. **图层不增加**：图层结构与原始图纸完全一致。
3. **无需图层切换**：任何人打开图纸都能看到双语版本。

#### 局限

1. **破坏性**：原文内容被修改（与策略二类似），原始文字内容不可恢复。
2. **文字变长**：可能导致排版问题，需要人工微调。
3. **不适合密集标注**：如果原文文字已经占据全部预留空间，追加译文后会严重溢出。
4. **审校困难**：如果译文中存在错误，修改后需要重新回写整个文件——因为译文已经和原文混在一起。

#### 适用场景

- **施工对照图**：中方施工队和外方监理需要在同一张图上同时看到两种语言。
- **审校参考**：翻译审校人员可以直观地逐条比对原文和译文（但需要注意，此模式下审校的是"最终效果"，而非翻译工作台中的对照模式）。
- **培训教学**：用于培训新工程师熟悉专业术语的双语对照。
- **竣工归档**：当项目要求竣工图必须包含中英双语时。

### 7.3.4 三种策略对比总览

| 对比维度 | 创建新图层 (isolatedlayer) | 原位替换 (inplace) | 双语追加 (bilingualappend) |
|----------|---------------------------|-------------------|---------------------------|
| **破坏性** | 无（原文完整保留） | 有（原文被替换） | 有（原文被修改为双语） |
| **新图层** | 创建译文图层 | 不创建 | 不创建 |
| **文件大小** | 略大（双倍文字实体） | 基本不变 | 基本不变 |
| **原文可恢复** | 是（关闭译文图层即可） | 否 | 否 |
| **对比查看** | 支持（通过图层切换） | 不支持 | 支持（同位置显示） |
| **排版风险** | 低（译文独立，不影响原文排版） | 中（译文长度可能不匹配原文空间） | 高（双语拼接后长度显著增加） |
| **图层数量** | 翻倍（可通过"合并图层"缓解） | 不变 | 不变 |
| **推荐程度** | ★★★★★（默认推荐） | ★★★（仅限特定场景） | ★★（谨慎使用） |

## 7.4 合并图层选项

### 7.4.1 选项说明

在使用"创建新图层"回写策略时，翻译工作台的回写配置面板中会出现一个复选框选项——**"合并图层"**。

该选项控制译文的图层组织方式：

| 选项状态 | 行为 |
|----------|------|
| **不勾选（默认）** | 为每个原文图层创建对应的译文图层（如 `建筑-文字_EN`、`结构-注释_EN`、`ELEC-TEXT_EN` 等）。译文图层数量 = 原文中含文字的图层数量。 |
| **勾选** | 所有译文文字实体统一写入**同一个译文图层**（层名可在设置中配置，默认为 `TEXT_TRANSLATED` 或 `TONGWEN_LAYER`）。译文图层数量 = 1。 |

### 7.4.2 勾选与不勾选的区别

以一张包含三个文字图层的图纸为例：

```
原文图层：建筑-文字、结构-注释、ELEC-TEXT
```

- **不勾选（默认）**：输出图纸包含 6 个文字图层（3 个原文 + 3 个译文）
  - `建筑-文字`（原文）
  - `建筑-文字_EN`（译文）
  - `结构-注释`（原文）
  - `结构-注释_EN`（译文）
  - `ELEC-TEXT`（原文）
  - `ELEC-TEXT_EN`（译文）

- **勾选**：输出图纸包含 4 个文字图层（3 个原文 + 1 个译文）
  - `建筑-文字`（原文）
  - `结构-注释`（原文）
  - `ELEC-TEXT`（原文）
  - `TEXT_TRANSLATED`（所有译文在此层）

### 7.4.3 优点与局限

| | 不勾选（默认） | 勾选 |
|---|---------------|------|
| **图层可管理性** | 译文按原文图层分类，可以精确控制某个专业图层的译文可见性 | 所有译文在一个图层中，一键切换全部译文的可见性 |
| **图层数量** | 图层数量翻倍，大型图纸的图层列表可能变得冗长 | 仅增加一个图层，保持图层列表简洁 |
| **灵活性** | 高。可以只显示"建筑文字"的英文而隐藏"结构注释"的英文 | 低。无法区分不同原文图层来源的译文 |
| **适用场景** | 需要按专业/图层精细控制译文显示时 | 不需要区分译文来源，只需要全局切换中英文时 |

### 7.4.4 使用建议

- **一般图纸（50 层以下）**：不勾选。图层列表在可管理范围内，按图层分类的译文更有条理。
- **大型图纸（100 层以上）**：考虑勾选。避免图层管理器变得臃肿难用。
- **仅需快速切换中英版本**：勾选。只增加一个译文图层，切换操作最简单。
- **需要按专业控制**（如建筑显示英文、结构保留中文）：不勾选。这是精细控制的前提。

## 7.5 回写操作步骤

本节以 **同文 Studio 桌面工作台** 为主要操作环境，详细描述回写的完整操作步骤。如果您使用的是 AutoCAD 插件端，操作界面略有不同但核心流程一致。

### 7.5.1 前置条件检查

在点击回写按钮之前，请确认以下条件已满足：

1. **翻译会话已打开**：您已创建翻译会话并完成了图纸文字提取（参见第 04 章）。
2. **翻译工作已完成**：所有需要翻译的文本条目已有译文（不一定要全部翻译完，但未翻译的条目将不会被回写）。
3. **核心条目的 QA 已通过**：无阻断（Blocker）级别的 QA 问题待处理（详见 7.7 节）。
4. **原始 DWG 文件可访问**：原始图纸文件的路径没有发生变动（如果移动了原始图纸，需要在项目设置中更新路径）。
5. **目标输出目录有写入权限**：如果配置了固定输出目录，确保该目录存在且可写入。

### 7.5.2 步骤一：打开回写配置面板

在翻译工作台界面中：

1. 确认当前位于需要回写的翻译会话中。
2. 在工具栏或侧边菜单中，找到 **"回写"** 按钮（通常图标为向下箭头或文件输出图标）。
3. 点击 **"回写"** 按钮，弹出回写配置对话框。

### 7.5.3 步骤二：选择回写模式

在回写配置对话框中，**"回写策略"** 下拉列表包含三个选项：

- **创建新图层（推荐）** — 默认选中
- **原位替换（谨慎使用）**
- **双语追加**

根据您的实际需求选择对应的策略（选择建议参见 7.9 节）。

如果您选择了"原位替换"或"双语追加"，对话框底部会显示一条警告提示：

> ⚠️ 此策略为破坏性操作。原文内容将在输出文件中被修改且不可恢复。建议先使用"创建新图层"模式验证翻译质量。

### 7.5.4 步骤三：配置合并图层选项

如果您选择了 **"创建新图层"** 策略，对话框中将显示 **"合并图层"** 复选框：

- **不勾选**（默认）：译文按原文图层名+后缀创建对应的翻译图层。
- **勾选**：所有译文合并到同一个图层中。

如果您选择了"原位替换"或"双语追加"，此选项将**不可用**（灰色显示），因为这两个策略不创建新图层。

### 7.5.5 步骤四：配置译文图层后缀（可选）

在同一面板中，您可以自定义译文图层名的后缀。默认后缀通常根据目标语言自动确定：

| 目标语言 | 默认后缀 | 示例 |
|----------|---------|------|
| 英语 | `_EN` | `建筑-文字_EN` |
| 日语 | `_JP` | `建築-文字_JP` |
| 韩语 | `_KO` | `건축-문자_KO` |

您也可以手动修改为任意后缀（如 `_译文`、`_T` 等）。修改后缀后需要确保图层名不超过 AutoCAD 的字符限制（通常 255 字符以内）。

### 7.5.6 步骤五：确认输出位置

回写配置对话框底部会显示当前输出文件的保存路径。路径格式类似于：

```
D:\项目\建筑图纸\二层平面图_translated.dwg
```

如果输出位置需要更改（例如保存到不同的文件夹），您可以在设置中修改输出位置策略（详见 7.6 节），而非在每次回写时临时更改。

### 7.5.7 步骤六：点击"开始回写"

确认所有配置无误后：

1. 点击 **"开始回写"** 按钮。
2. 同文开始处理回写任务。进度条显示当前进度（如"正在处理 45/200 个文字实体…"）。
3. 根据图纸大小和文字数量，回写可能需要几秒到几十秒不等。大型图纸（文字实体上千条）可能需要一到两分钟。

### 7.5.8 步骤七：等待完成

回写过程中请勿关闭翻译会话或同文 Studio。处理完成后，对话框将显示：

- ✅ **回写成功**：共处理 X 条文字实体，其中回写成功 Y 条，受阻 Z 条。
- 点击 **"查看文件"** 可直接打开输出文件所在的文件夹。
- 点击 **"在 CAD 中打开"**（如果 AutoCAD 已安装并注册了文件关联）可直接用 AutoCAD 打开输出文件。

### 7.5.9 步骤八：查看结果

用 AutoCAD 打开输出文件 `{原始文件名}_translated.dwg`：

1. 打开图层管理器（命令行输入 `LAYER` 或在功能区点击图层图标）。
2. 检查译文图层是否已创建（"创建新图层"模式下），或译文是否已写入对应位置（"原位替换"和"双语追加"模式下）。
3. 随机抽查 5-10 处译文，确认翻译内容正确、文字样式正常、位置准确。
4. 如果发现问题，返回翻译工作台修改译文，然后重新执行回写。

## 7.6 输出位置配置

同文提供三种输出位置策略，在 **设置 → 回写** 面板中进行配置。

### 7.6.1 策略一：与原文件同目录（默认）

**行为**：回写的输出文件始终保存到原始 DWG 文件所在的同一目录中。

**示例**：
- 原始文件：`D:\项目\建筑\二层平面图.dwg`
- 输出文件：`D:\项目\建筑\二层平面图_translated.dwg`

**优点**：
- 简单直观，无需额外配置。
- 原始文件和译文文件始终在同一处，方便管理。
- 不会因目录变动导致"找不到输出文件"的困惑。

**注意事项**：
- 确保原始文件所在目录有写入权限（通常都没有问题）。
- 如果原始文件在只读介质上（如光盘、只读网络共享），回写会失败。此时需要切换到策略二或策略三。

### 7.6.2 策略二：每次询问保存位置

**行为**：每次执行回写时，弹出文件保存对话框，让您手动选择输出目录和文件名。

**适用场景**：
- 您希望将译文文件与原文文件分开存放（如原文在归档目录、译文在工作目录）。
- 不同批次的翻译需要保存到不同目录。
- 您希望在保存前自定义输出文件名。

**注意事项**：
- 每次都需要手动选择，批量处理时可能比较繁琐。
- 选错目录后译文文件可能散落在不同的文件夹中，不利于后续管理。

### 7.6.3 策略三：保存到固定目录

**行为**：所有回写输出文件统一保存到您预设的固定目录中。

**配置方法**：
1. 打开 **设置 → 回写**。
2. 在"输出位置"选项中，选择"保存到固定目录"。
3. 点击 **"浏览"** 按钮，选择目标文件夹（如 `D:\翻译输出`）。
4. 点击"保存"以确认配置。

**优点**：
- 适合批量处理场景：多张图纸翻译后，所有译文文件集中在一个文件夹中。
- 适合团队协作：配置为共享网络文件夹后，审校人员可以直接从统一位置获取译文文件。

**注意事项**：
- 如果多张不同项目的图纸恰好同名（如都叫 `平面图.dwg`），后回写的文件会覆盖先回写的文件。因为同文在固定目录策略下保持原始文件名（仅添加 `_translated` 后缀）。建议不同项目的图纸确保文件名唯一，或按项目分别配置不同的固定目录。
- 确保固定目录具有写入权限，且磁盘空间充足。

### 7.6.4 三种策略对比

| 策略 | 配置复杂度 | 适用场景 | 注意事项 |
|------|-----------|---------|---------|
| 与原文件同目录 | 最低（默认） | 日常使用 | 原文目录需有写入权限 |
| 每次询问 | 低 | 需要灵活控制输出位置 | 批量处理时操作繁琐 |
| 固定目录 | 中 | 批量处理、团队协作 | 同名文件会覆盖，需注意磁盘空间 |

## 7.7 回写前检查

回写不是"无条件地把所有翻译都写进图纸"。同文设计了质量控制机制，确保只有达到质量标准的翻译才会被回写。

### 7.7.1 审批状态要求

在翻译工作台中，每个翻译单元都有一个审批状态（Review Status）：

| 状态 | 含义 | 能否被回写 |
|------|------|:--------:|
| **Draft（草稿）** | 机器翻译自动生成的译文，未经人工确认 | ❌ |
| **Translated（已翻译）** | 翻译已完成，但尚未经过审校 | ❌（部分配置下可通过） |
| **Approved（已批准）** | 翻译经过人工审校并确认通过 | ✅ |
| **Rejected（已驳回）** | 审校人员驳回了该译文，需要重新翻译 | ❌ |

**只有状态为 Approved（已批准）的翻译单元才会被回写。** 这是同文的质量底线——确保写进图纸的每一处译文都经过了人工确认。

> 📌 **特殊情况**：在某些团队配置中，管理员可以将"Translated（已翻译）"状态也纳入可回写范围。这通常用于"翻译质量要求不高、追求速度"的场景。但生产环境强烈建议保持默认的"仅 Approved 可回写"设置。

### 7.7.2 QA 阻断处理

同文的 QA（质量检查）系统会对每一条译文进行四级风险评估（参见相关 QA 章节）：

| 风险级别 | 英文标识 | 含义 | 对回写的影响 |
|----------|---------|------|:----------:|
| **阻断** | Blocker | 严重错误：可能涉及安全、合规或根本性误译 | **阻止回写** |
| 高 | High | 高风险：可能影响工程理解的错误 | 警告但不阻止 |
| 中 | Medium | 中等风险：术语不统一、风格不一致等 | 警告但不阻止 |
| 低 | Low | 低风险：标点、空格等格式问题 | 不阻止，无警告 |

**阻断（Blocker）级别的 QA 发现会阻止对应翻译单元被回写。** 这意味着：

- 如果图纸中有 200 条文字实体，其中 10 条的译文被 QA 标记为 Blocker，那么回写时这 10 条**不会被写入图纸**。输出图纸中对应的位置将保持原文（或为空，取决于回写策略）。
- 只有解决了这 10 条的 Blocker 问题（修正译文 → 重新提交审校 → 状态变为 Approved），再次回写时它们才会被写入。

### 7.7.3 回写前的自检清单

在执行回写之前，建议您按照以下清单逐项检查：

- [ ] 所有需要交付的翻译单元状态是否为 **Approved**？
- [ ] 是否存在 **Blocker** 级别的 QA 问题未处理？
- [ ] 打开 QA 面板，筛选 Blocker 级别，确保列表为空或全部已解决。
- [ ] 随机抽取 20 条译文进行人工快速审阅，确保翻译质量符合预期。
- [ ] 确认术语库中的关键术语已正确应用到译文中。
- [ ] 原始 DWG 文件是否存在于预期位置？（在项目设置中验证路径）
- [ ] 回写策略是否选择了正确的模式？
- [ ] 输出位置是否正确配置？

## 7.8 回写后验证

回写完成后，建议执行以下验证步骤，确保译文已经正确写入图纸。

### 7.8.1 基本验证

1. **确认文件已生成**：在输出目录中确认 `{原始文件名}_translated.dwg` 文件已存在，且文件大小合理（通常不小于原始文件，且明显大于空文件）。

2. **用 AutoCAD 打开输出文件**：确认文件可以正常打开，没有因回写错误导致的文件损坏。

3. **快速浏览全图**：在 AutoCAD 中 `ZOOM EXTENTS`（缩放至范围），快速浏览全图，确认图纸整体外观正常，没有大面积的空白或明显的文字错位。

### 7.8.2 译文内容验证

1. **随机抽取检查点**：在图纸上随机选择 10-20 个位置，使用 `ZOOM WINDOW` 放大查看，逐条核对译文内容是否与翻译工作台中的 Approved 译文一致。

2. **重点检查区域**：
   - **图框/标题栏**：项目名称、图号、日期、设计人等信息是否正确翻译。
   - **图例/说明**：技术说明段落是否完整，有无遗漏或截断。
   - **标注文字**：尺寸标注旁边的文字注释是否翻译正确。
   - **材料表/设备表**：表格中的文字是否完整翻译且位置正确。

3. **检查遗漏**：如果在翻译工作台中有某条文字的译文，但图纸中对应位置仍然是原文（或为空），可能是因为：
   - 该翻译单元的状态不是 Approved。
   - 该翻译单元被 QA 标记为 Blocker 且未解决。
   - 该文字实体在回写时遇到了无法处理的异常（查看回写报告日志确认）。

### 7.8.3 图层验证（仅"创建新图层"策略）

1. 在 AutoCAD 中打开图层管理器（命令行输入 `LAYER` 后回车，或快捷键 `LA`）。
2. 检查是否存在带后缀的译文图层（如 `建筑-文字_EN`）。
3. 选择一个译文图层，冻结所有其他图层（或在图层管理器中关闭其他图层的灯泡图标），确认：
   - 该译文图层中确实有译文文字。
   - 文字样式（字体、颜色、高度）与原文一致。
4. 逐层检查，确保所有预期的译文图层都已创建并包含正确的译文。

### 7.8.4 样式与格式验证

1. **字体验证**：随机选择几处译文文字，在 AutoCAD 中按 `Ctrl+1` 打开属性面板，检查下列属性是否与原文一致：
   - 文字样式（Text Style）
   - 字体高度（Height）
   - 旋转角度（Rotation）
   - 对齐方式（Justify）
   - 图层归属（Layer）

2. **MText 格式验证**：对于多行文字（MText），双击进入编辑模式，检查：
   - 换行位置是否合理。
   - 内嵌格式（如加粗、颜色标记）是否保留。
   - 段落间距是否正常。

3. **块属性验证**：对于图框中的文字（块属性），检查：
   - 属性值是否已正确更新为译文。
   - 属性位置是否仍然在图框内的正确位置。

### 7.8.5 发现问题的处理流程

如果在验证中发现译文内容错误、遗漏或格式问题：

1. **返回翻译工作台**：修正对应的翻译条目。
2. **重新提交审校**：如果需要，将修正后的译文提交流程重新审核。
3. **确保状态变为 Approved**。
4. **重新执行回写**：使用相同的配置再次回写。同文会覆盖之前的输出文件（相同文件名），更新后的译文将生效。

## 7.9 图层管理工具

在"创建新图层"回写策略下，管理原文和译文的图层可见性是一个常见的操作需求。同文为此提供了两种图层管理方式。

### 7.9.1 AutoCAD 插件面板的图层控制按钮

如果您安装了同文的 AutoCAD 插件，在侧边面板的顶部或工具栏区域，会提供一组图层可见性控制按钮。

#### 按钮列表

| 按钮名称 | 图标示意 | 功能 |
|----------|---------|------|
| **隐藏原文图层** | 眼睛+斜线（原文色） | 一键关闭所有原始文字图层。图纸中只显示译文，相当于"纯译文版"。 |
| **显示原文图层** | 眼睛（原文色） | 一键打开所有原始文字图层。恢复原文显示（此前被"隐藏原文图层"关闭的图层重新打开）。 |
| **隐藏译文图层** | 眼睛+斜线（译文色） | 一键关闭所有译文图层（带后缀的图层）。图纸中只显示原文（可能叠加了译文，取决于当前状态）。 |
| **显示译文图层** | 眼睛（译文色） | 一键打开所有译文图层。 |
| **仅显示译文** | 切换开关 | 快捷键：同时"隐藏原文图层"+"显示译文图层"，一步切换到纯译文视图。 |
| **仅显示原文** | 切换开关 | 快捷键：同时"显示原文图层"+"隐藏译文图层"，一步切换到纯原文视图。 |
| **全部显示** | 两个眼睛 | 一键打开所有文字相关图层。原文和译文同时显示（通常用于对照检查）。 |

#### 操作示例

**场景：交图前快速复查译文版**

1. 在 AutoCAD 中打开 `二层平面图_translated.dwg`。
2. 在同文插件面板中，点击 **"仅显示译文"** 按钮。
3. 此时图纸中只显示译文文字（所有带 `_EN` 后缀的图层被打开，原文图层被关闭）。
4. 逐区域检查译文排版和内容。
5. 检查完成后，点击 **"全部显示"** 恢复原始状态。

**场景：外方监理要求只看英文版**

1. 打开译文图纸。
2. 点击 **"仅显示译文"**，此时图纸是纯净的英文版。
3. 打印或导出 PDF。打印输出将只包含英文文字，中文文字不可见且不被打印。

### 7.9.2 TWLAYERVIS 命令行命令

`TWLAYERVIS` 是同文 AutoCAD 插件提供的一个命令行命令，用于交互式地控制图层可见性。该命令不要求打开插件面板，适合习惯键盘操作的 AutoCAD 用户。

#### 基本用法

在 AutoCAD 命令行中输入：

```
TWLAYERVIS
```

回车后，命令行会输出一组选项提示：

```
[显示全部(S)/仅原文(O)/仅译文(T)/切换(Toggle)]:
```

输入对应的字母即可切换模式：

| 输入 | 效果 |
|------|------|
| `S` | 显示全部文字图层（原文 + 译文） |
| `O` | 仅显示原文文字图层，隐藏所有译文图层 |
| `T` | 仅显示译文文字图层，隐藏所有原文图层 |
| `Toggle` | 在"仅原文"和"仅译文"之间来回切换 |

#### 支持脚本化调用

`TWLAYERVIS` 命令支持带参数字符串调用，适合建快捷键或编写 AutoLISP 宏：

```
TWLAYERVIS S    // 显示全部
TWLAYERVIS O    // 仅原文
TWLAYERVIS T    // 仅译文
TWLAYERVIS G    // 切换 (Toggle)
```

#### 支持空间过滤

在某些大型图纸中，文字可能同时存在于模型空间（Model Space）和多个布局空间（Layout/Paper Space）中。`TWLAYERVIS` 命令可以通过子选项指定作用范围：

```
TWLAYERVIS
[显示全部(S)/仅原文(O)/仅译文(T)/切换(Toggle)]: T
[应用到当前空间(C)/所有空间(A)]: A
```

- **当前空间**：只切换当前活动视口中文字图层的可见性。
- **所有空间**：切换模型空间和所有布局中文字图层的可见性。

### 7.9.3 图层可见性与打印

在 AutoCAD 中，图层的打印设置（是否可打印）与可见性设置是独立的。同文回写生成的译文图层默认是**可打印**的。

如果您希望在打印英文版时自动隐藏中文原文，有两种方式：

1. **使用插件按钮**：在打印前点击"仅显示译文"，然后执行打印。关闭的图层不会被打印。
2. **预先配置打印样式**：在 AutoCAD 的图层管理器中，手动将原文图层的"打印"属性设置为"不打印"。同文的插件面板不会修改图层的打印属性，只修改可见性。

> 📌 建议：生成最终交付 PDF 前，务必先"仅显示译文"再打印预览，确认输出的确实是译文版本。

## 7.10 回写注意事项

### 7.10.1 非破坏性 vs 破坏性

| 策略 | 破坏性 | 原文保留 | 建议 |
|------|:------:|:------:|------|
| 创建新图层 | ❌ | ✅ | 首选，随时可恢复原文 |
| 原位替换 | ✅ | ❌ | 最终交付版，确认无误后使用 |
| 双语追加 | ✅ | 部分（内容被修改） | 施工对照图，需接受排版调整 |

**核心原则**：在不确定翻译质量的情况下，始终优先使用"创建新图层"模式。即使翻译质量已经过审校，也建议先用"创建新图层"模式生成对照版进行人工复核，确认无误后再用"原位替换"生成最终交付版（如果您的场景确实需要纯净译文版的话）。

### 7.10.2 文件命名规则

同文回写的输出文件命名遵循以下规则：

- **固定前缀**：原始文件名（不含扩展名部分）。
- **固定后缀**：`_translated`（可配置，在设置 → 回写 → 输出文件名中进行调整）。
- **扩展名**：`.dwg`。

完整格式：

```
{原始文件名}_translated.dwg
```

例如：

| 原始文件 | 输出文件 |
|----------|---------|
| `一层平面图.dwg` | `一层平面图_translated.dwg` |
| `HVAC_LAYOUT.dwg` | `HVAC_LAYOUT_translated.dwg` |
| `结构-03-配筋图.dwg` | `结构-03-配筋图_translated.dwg` |

**注意事项**：
- 如果输出目录中已经存在同名文件，回写会**覆盖**它。每次回写都会生成全新的文件内容，之前的输出文件会被替换。
- 如果您需要保留多个版本的回写结果，请在每次回写后手动重命名输出文件，或改用"每次询问保存位置"策略并在对话框中选择不同的文件名。

### 7.10.3 反复回写

您可以对同一翻译会话执行多次回写。这在以下场景中很常见：

- **场景**：第一次回写后发现有几处译文需要修改。修改译文 → 确认状态为 Approved → 再次点击回写。新的 `_translated.dwg` 文件将包含最新的译文。

每次回写都是**全量重写**——同文不会做增量更新，而是基于当前翻译会话中的全部 Approved 译文重新生成整个输出文件。这意味着：

- ✅ 已存在的译文图层会被清空并重新填充，确保内容是最新的。
- ✅ 已解决 Blocker 的新翻译单元会在本次回写中被写入。
- ✅ 回写是幂等的——相同的输入始终产生相同的输出。

**重要提示**：如果您在两次回写之间手动修改了 `_translated.dwg` 文件（例如在 AutoCAD 中调整了文字位置或样式），第二次回写会**覆盖这些手动修改**。建议将手动调整只应用于最终版本，或者在调整前先复制一份译文文件。

### 7.10.4 文字样式与字体

同文在回写时会尽最大努力保留原文的文字样式：

- 对于"创建新图层"策略：译文文字实体继承原文的样式（字体、高度、颜色、对齐方式、旋转角度、宽度因子等），但文字内容是译文。
- 对于"原位替换"策略：原文的文字实体被直接修改，只改变文字内容，其他属性保持不变。
- 对于"双语追加"策略：原文的文字实体被修改为双语格式，但文字样式保持一致。

**字体回退说明**：如果原文使用了中文字体（如 `宋体`、`仿宋`），而译文是英文，AutoCAD 在渲染时可能自动回退到字体文件中的默认英文字形。反之亦然——如果译文是中文但原文使用的是不支持中文的字体（如 `Simplex.shx`），译文中的中文字符可能显示为问号（`?`）。

**解决方法**：在回写前，在翻译工作台的设置中为译文指定目标字体样式。同文支持将译文文字实体关联到一个您预先在 DWG 中定义好的、支持目标语言文字的字型（Text Style）。

### 7.10.5 块属性回写的特殊性

对于图框中的文字（AttributeReference / 块属性），回写的行为与普通文字略有不同：

- 块属性是块定义（Block Definition）的一部分，不能简单地"换一个图层"。
- 在"创建新图层"策略下，块属性值的修改是直接发生在原属性上的（因为属性不能脱离块而独立存在于另一个图层）。但同文会同时创建一个非属性的文字副本来承载译文，放置在与块属性相同的位置。这个副本位于译文图层中。
- 在"原位替换"策略下，属性值直接被替换为译文。
- 在"双语追加"策略下，属性值被修改为"原文 / 译文"格式。

**这意味着**：在"创建新图层"模式下，如果您"仅显示译文"，图框中的块属性位置会显示译文文字副本（非属性文本），同时原文块属性因原文图层被关闭而不可见。图框的整体外观是正确的，但这些文字副本不是块属性——如果后续在图框属性中编辑字段，副本不会自动更新。

### 7.10.6 大图纸的注意事项

对于包含数千条甚至上万条文字实体的超大型图纸（如全套施工图合并文件），回写可能需要较长时间。建议：

- 在回写前关闭不必要的应用程序，释放系统内存。
- 确保磁盘有足够的可用空间（输出文件通常比原始文件大 20%-50% 甚至更多）。
- 如果回写失败（超时或内存不足），可以尝试将大型图纸拆分为多个较小的文件分别翻译和回写。
- 对于超大项目，建议使用同文的批量处理模式（通过项目配置一次性处理多张图纸），这样每张图纸单独回写，不容易因单文件过大而失败。

## 7.11 回写模式选择指南

本节针对不同的使用场景，给出明确的回写模式推荐。您可以根据自己的实际情况对照选择。

### 7.11.1 按使用场景选择

| 使用场景 | 推荐策略 | 合并图层 | 说明 |
|----------|---------|:--------:|------|
| **初次使用，不确定效果** | 创建新图层 | 不勾选 | 安全第一，原文保留，随时可恢复 |
| **日常图纸翻译** | 创建新图层 | 不勾选 | 默认推荐配置，适用于 90% 的场景 |
| **最终交付纯净译文版** | 原位替换 | 不适用 | 前提：已经用"创建新图层"模式验证过翻译质量并确认无误 |
| **施工现场对照用图** | 双语追加 | 不适用 | 原文和译文同时出现在图纸上，方便中外双方核对 |
| **给外方监理的英文版** | 创建新图层 | 勾选 | 只需一个译文图层，外方打开后一键切换到纯英文 |
| **图层已经很多（100+）** | 创建新图层 | 勾选 | 避免图层数量翻倍，保持图层管理器可用 |
| **需要按专业控制双语** | 创建新图层 | 不勾选 | 例如：建筑图层显示英文、结构图层保留中文 |
| **竣工图多语种归档** | 创建新图层 | 不勾选 | 每个语种的译文在独立图层上，一份图纸包含所有语种 |
| **翻译质量不确定，需多次迭代** | 创建新图层 | 任意 | 方便反复修改和回写，原文始终安全 |
| **批量处理几百张图纸** | 创建新图层 | 勾选 | 减少每张图纸的图层数量，保持输出文件整洁 |

### 7.11.2 决策流程图

以下决策流程可以帮助您快速做出选择：

```
开始
  │
  ├─ 是否需要保留原文？ ─── 否 ──→ 原位替换
  │
  └─ 是
       │
       ├─ 原文和译文是否需要同时可见？ ─── 是 ──→ 双语追加
       │
       └─ 否
            │
            ├─ 图层数量是否已经很多（100+）？ ─── 是 ──→ 创建新图层 + 合并图层
            │
            └─ 否 ──→ 创建新图层 + 不合并图层
```

### 7.11.3 推荐的工作流

对于大多数用户，推荐以下"双轮验证"工作流：

**第一轮（验证轮）**：

- 策略：**创建新图层**（不合并图层）
- 目的：生成对照版图纸，逐条对比原文和译文。
- 操作：在 AutoCAD 中打开输出文件，使用"仅显示译文"和"仅显示原文"切换，快速定位翻译问题。
- 修正：发现问题后返回翻译工作台修改，重新回写。

**第二轮（交付轮）**：

- 确认第一轮的翻译质量已无问题后：
  - 如果交付方需要纯净译文版 → 使用**原位替换**生成交付版。
  - 如果交付方需要双语版 → 使用**双语追加**生成交付版。
  - 如果交付方需要可切换的中英版 → 继续使用**创建新图层**模式，直接交付第一轮生成的文件（或在确认无误后再回写一次生成最终版）。

## 7.12 常见问题与排查

### 问题 1：回写后某些位置仍然是原文，没有变成译文

**可能原因**：

1. **该翻译单元的状态不是 Approved**。检查翻译工作台，看对应条目的审批状态。只有 Approved 状态的条目才会被回写。
2. **该翻译单元被 QA 标记为 Blocker**。打开 QA 面板，查看是否有 Blocker 级别的发现问题尚未解决。解决 Blocker 问题并将状态变更为 Approved 后，重新回写。
3. **原文实体类型特殊**。某些特殊的文字实体（如自定义对象中的文字、代理实体中的文字）可能无法被同文识别和回写。查看回写日志确认是否有"跳过"的条目。
4. **原始图纸文件发生了变更**。如果原始 DWG 文件在提取后发生了修改（文字被删除、移动或句柄变化），回写时可能无法定位到对应的原文实体。此时需要重新提取文字。

**排查步骤**：

```
1. 翻译工作台 → 筛选该文字 → 查看状态是否为 Approved
2. 翻译工作台 → QA 面板 → 筛选 Blocker → 确认无阻断
3. 检查回写报告日志 → 查看是否有报错或跳过的条目
4. 确认原始 DWG 文件未在提取后被修改过
```

### 问题 2：译文图层已创建但图层中没有文字

**可能原因**：

1. **合并图层选项导致**：如果您勾选了"合并图层"，所有译文都在统一的译文图层中，而非分散到各个 `_EN` 图层。检查是否存在 `TEXT_TRANSLATED` 或其他统一译文图层。
2. **图层被冻结或关闭**：在 AutoCAD 中检查图层的可见性状态。某些图层可能在视口（Viewport）中被特定冻结。
3. **文字颜色与背景色相同**：如果译文的颜色与图纸背景色非常接近（如白色文字在白色背景上），可能"看不见"。尝试切换 AutoCAD 的背景色或调整文字颜色。

**排查步骤**：

```
1. LAYER → 检查所有图层的"开/关"和"冻结/解冻"状态
2. LAYER → 按名称排序，查找带译文后缀或统一译文名称的图层
3. CTRL+A 全选 → 检查是否有不可见但实际存在的文字实体
4. 切换到模型空间（而非布局空间）查看
```

### 问题 3：MText 译文格式错乱

**可能原因**：

MText（多行文字）内部包含格式码（如字体切换、颜色标记、堆叠文字、段落缩进等），翻译后如果译文长度与原文差异较大，原有格式可能被打乱。

**解决方法**：

1. 在翻译工作台中，MText 条目会有格式标记。翻译时注意不要删除或修改格式标记（同文会用占位符保护它们）。
2. 如果译文格式已经混乱，在 AutoCAD 中双击进入 MText 编辑器，手动调整排版。
3. 如果类似问题频繁出现，联系技术支持，可能需要在术语库或翻译记忆中针对特定 MText 格式做特殊处理。

### 问题 4：译文字体显示为问号（?）

**可能原因**：

译文语言需要的字形（Glyph）在原文使用的字体文件中不存在。例如：
- 原文使用 `Simplex.shx` 字体（仅含英文字形），但译文包含中文字符——中文无法渲染，显示为 `?`。
- 原文使用中文字体，但译文的某些特殊字符（如带重音符号的法语字母 `é`、`è`）不在该字体中。

**解决方法**：

1. **方法一（推荐）**：在翻译工作台的设置中，为目标语言指定一个包含所需字形的 AutoCAD Text Style。回写时译文将使用该字体。
2. **方法二**：在 AutoCAD 中手动修改译文图层或译文文字实体的字体属性。
3. **方法三**：在 AutoCAD 中将缺失的字形字体文件（如 `Simplex.shx`）替换为支持目标语言的字体文件。

### 问题 5：双语追加后文字严重溢出

**可能原因**：

双语追加模式下，每条文字实体的内容变为 `原文 / 译文`。如果原文已经接近或填满了预留空间，追加译文后必然溢出。

**解决方法**：

1. **调整字号**：在 AutoCAD 中手动减小溢出文字的字高，使其适配预留空间。
2. **换行处理**：对于 MText，同文会尝试在追加译文前插入换行符。如果仍然溢出，手动编辑 MText 调整换行位置。
3. **优化译文**：如果译文本身过于冗长，考虑使用更简洁的译文（在翻译工作台的术语库或翻译记忆中优化）。
4. **改用"创建新图层"模式**：如果溢出问题普遍且严重影响图纸可用性，放弃双语追加模式，改用"创建新图层"模式。原文和译文分开显示，各自使用独立空间。

### 问题 6：回写后图纸文件大小增加很多

**可能原因**：

在"创建新图层"模式下，原文和译文两套文字实体同时存储在 DWG 文件中，文件大小自然会增加——通常增加 30%-80%，取决于文字实体数量。

**解决方法**：

1. 这是"创建新图层"策略的正常现象，不是错误。
2. 如果您需要减小文件大小，可以使用"原位替换"策略（前提是确认不再需要原文），或使用 AutoCAD 的 `PURGE` 命令清理未使用的样式等冗余数据。
3. 如果文件大小增加超过 100%，检查是否有异常——可能是因为字体嵌入、冗余样式等原因导致的非正常膨胀。

### 问题 7：回写失败，报错"无法访问原文件"或"文件被占用"

**可能原因**：

1. 原始 DWG 文件正在被 AutoCAD 或其他程序打开（文件被锁定）。
2. 原始文件所在目录无写入权限（如网络共享目录权限不足）。
3. 原始文件路径发生了变更（文件被移动、重命名或删除）。
4. 磁盘空间不足，无法创建输出文件。

**解决方法**：

1. 关闭所有打开了原始 DWG 文件的程序（包括 AutoCAD），然后重试。
2. 确认输出目录有写入权限，尝试以管理员身份运行同文 Studio。
3. 在项目设置中更新原始文件的路径，确保路径指向正确的位置。
4. 清理磁盘空间后重试。

### 问题 8：TWLAYERVIS 命令无效

**可能原因**：

1. 同文 AutoCAD 插件未正确加载。
2. 当前 DWG 文件不是同文回写生成的文件（不包含带同文译文后缀的图层）。
3. AutoCAD 的命令识别环境有问题。

**解决方法**：

1. 在 AutoCAD 命令行中输入 `APPLOAD`，检查同文插件（通常为 `Tongwen.dll` 或 `Tongwen.arx`）是否已加载。
2. 确认当前 DWG 文件是通过同文回写生成的（包含 `_EN`、`_T` 或自定义后缀的译文图层）。
3. 如果插件已加载但命令仍无效，尝试重新加载插件：`APPLOAD` → 卸载 → 重新加载。
4. 如果以上步骤均无效，可以使用 AutoCAD 原生的 `LAYER` 命令手动控制图层的可见性（虽然不如 `TWLAYERVIS` 方便，但效果相同）。

## 7.13 最佳实践总结

### 7.13.1 日常工作的推荐配置

以下配置适合大多数用户的日常翻译工作：

| 配置项 | 推荐值 | 说明 |
|--------|-------|------|
| 回写策略 | 创建新图层 | 安全、可控、可恢复 |
| 合并图层 | 不勾选 | 保留按原文图层分类的组织结构 |
| 输出位置 | 与原文件同目录 | 简单直观 |
| 译文图层后缀 | `_EN`（根据目标语言自动确定） | 可识别，不与现有图层冲突 |

### 7.13.2 大型项目 / 批量处理的推荐配置

| 配置项 | 推荐值 | 说明 |
|--------|-------|------|
| 回写策略 | 创建新图层 | 安全第一 |
| 合并图层 | 勾选 | 避免大量图纸叠加后图层数量过多 |
| 输出位置 | 固定目录 | 所有译文文件集中存放，便于统一审查 |
| QA 阻断处理 | 严格模式（Blocker 必须解决） | 批量处理中质量不能放松 |

### 7.13.3 安全准则

1. **永远不要直接用"原位替换"或"双语追加"作为第一次回写**。先使用"创建新图层"验证内容，满意后再考虑其他策略。
2. **原始 DWG 文件妥善备份**。虽然同文不会修改原始文件，但在任何批量操作前做好备份都是良好的工程习惯。
3. **回写后务必抽查验证**。不要因为"自动化"而放弃人工检查。随机抽取 10-20 处译文比对原文，是成本最低的保险措施。
4. **Blocker 零容忍**。任何 Blocker 级别的 QA 发现都必须在回写前解决，不要抱有"先回写再说"的心态。
