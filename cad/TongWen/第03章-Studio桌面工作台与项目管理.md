# 第03章：Studio 桌面工作台与项目管理

> **产品官网**：[https://shandianweihu.com/](https://shandianweihu.com/) — 获取最新产品信息、版本更新和下载安装包。

---

同文（Tongwen）的 Studio 桌面工作台是您日常使用翻译功能的核心入口。它将项目组织、翻译执行、术语管理和系统设置集成在一个统一界面中，让您无需在多个工具之间来回切换即可完成从 CAD 图纸提取到翻译交付的完整工作流。

本章将从零开始，逐一介绍 Studio 工作台的界面布局、各功能页面的操作方式以及项目管理的完整流程。

## 3.1 Studio 主界面概览

### 3.1.1 启动 Studio

在 Windows 系统中，您可以通过以下方式启动 Studio 桌面工作台：

- **开始菜单**：点击"开始 → 同文 → Studio"，或直接在搜索框中输入"Studio"后回车。
- **桌面快捷方式**：安装完成后桌面会自动生成 Studio 快捷方式，双击即可启动。
- **命令行启动**（高级用户）：在命令行中执行 Studio 的可执行文件路径。

启动后的片刻内，Studio 主窗口将显示在屏幕上。

### 3.1.2 整体布局

Studio 主窗口采用经典的**左右分区**布局，由三个核心区域构成：

| 区域 | 位置 | 说明 |
|------|------|------|
| **左侧导航栏** | 窗口左侧，纵向排列 | 以图标 + 文字的形式列出五个功能页面入口。点击即可切换到对应页面。当前所处页面会高亮显示。 |
| **主内容区** | 窗口中央，占据主要面积 | 显示当前所选页面的完整内容。不同页面之间的内容完全独立，切换时保留各自的状态。 |
| **底部状态栏** | 窗口最底部 | 显示 IPC 管道连接状态、当前 CAD 版本信息、网络状态等关键运行状态。 |

窗口支持拖拽调整大小，最小化、最大化以及关闭按钮均位于窗口右上角的标题栏中。

### 3.1.3 左侧导航栏

左侧导航栏中包含五个页面入口，从上到下依次排列：

| 图标 | 页面名称 | 功能概要 |
|------|----------|----------|
| 🚀 | **启动器** | AutoCAD 版本检测与启动、插件注册状态查看、默认 CAD 版本设置 |
| 🏠 | **项目管理** | 项目卡片列表浏览、新建/删除项目、新建翻译任务、提取模式选择 |
| 📄 | **翻译工作区** | 翻译表格编辑、语言与专业选择、翻译/审批流程操作、数据导入导出 |
| 📚 | **术语库** | 术语表文件管理、CSV/Excel 导入导出、术语内容浏览与编辑 |
| ⚙️ | **设置** | AutoCAD 检测路径、输出目录配置、翻译引擎选择、本地文件目录管理 |

### 3.1.4 页面切换

页面切换有三种方式：

1. **鼠标点击**：直接点击左侧导航栏中的目标页面图标。
2. **键盘快捷键**：通过快捷键快速跳转（具体快捷键组合请参考设置页面中的快捷键配置）。
3. **程序触发**：某些操作完成后（例如新建翻译任务成功后），系统会自动跳转到翻译工作区页面。

切换页面时，前一个页面的运行状态会被保留。例如，您在翻译工作区中编辑到一半的译文，切换到项目管理页面后再切回来，之前的内容不会丢失。

## 3.2 启动器页面（🚀）

启动器是 Studio 的默认首页，也是您每次工作的起点。它负责管理与 AutoCAD 程序的连接和启动。

### 3.2.1 页面布局

启动器页面从上到下包含以下几个功能区块：

| 区块 | 说明 |
|------|------|
| **版本检测面板** | 自动扫描系统中已安装的 AutoCAD 版本，以列表形式展示 |
| **插件注册状态** | 显示同文插件在各 AutoCAD 版本中的注册/加载状态 |
| **默认版本设置** | 指定一个默认的 AutoCAD 版本，用于"一键启动" |
| **快速启动按钮** | 一键启动默认版本或指定版本的 AutoCAD，并自动加载同文插件 |

### 3.2.2 AutoCAD 版本检测

当您首次打开启动器页面或点击"重新检测"按钮后，Studio 会自动扫描系统注册表和常用安装路径，查找已安装的 AutoCAD 版本。

检测到的 AutoCAD 版本会以列表形式展示，每条记录包含以下信息：

| 字段 | 说明 |
|------|------|
| **版本名称** | 例如"AutoCAD 2021"、"AutoCAD 2025"、"中望CAD 2023"等 |
| **安装路径** | AutoCAD 主程序（acad.exe 或 zwcad.exe）所在的完整路径 |
| **产品类型** | 标识为 AutoCAD 或中望 CAD（ZWCAD） |
| **插件状态** | 该版本中是否已注册同文插件（见下一节详述） |

> **提示**：如果检测不到某个已安装的 AutoCAD 版本，可能是该版本安装在非标准路径下。您可以前往"设置 → AutoCAD 检测"页面手动添加安装路径。

### 3.2.3 插件注册状态

每个检测到的 AutoCAD 版本旁边会显示一个插件状态指示器：

| 状态 | 含义 |
|------|------|
| ✅ **已注册** | 同文插件已成功注册到该 AutoCAD 版本中，启动 CAD 后将自动加载 |
| ⚠️ **未注册** | 插件尚未注册，需要点击"注册插件"按钮执行注册操作 |
| 🔄 **注册中** | 插件注册操作正在进行中，请稍候 |
| ❌ **注册失败** | 插件注册过程中出现错误，请检查权限或查看日志 |

**注册插件的步骤**：

1. 在版本列表中找到目标 AutoCAD 版本。
2. 如果状态显示"未注册"，点击该行右侧的"注册插件"按钮。
3. 系统会弹出确认对话框，点击"确认"开始注册。
4. 注册过程通常只需几秒，完成后状态将更新为"已注册"。

> **注意**：注册插件操作需要管理员权限。如果注册失败，请尝试以管理员身份运行 Studio。

### 3.2.4 启动 AutoCAD

在启动器页面中，您可以通过以下方式启动 AutoCAD：

**方式一：一键启动（使用默认版本）**

1. 确保您已在"默认版本设置"中指定了一个默认 CAD 版本。
2. 点击页面顶部醒目的 **"启动默认 CAD"** 按钮。
3. AutoCAD 将自动启动，并在加载完成后显示同文插件的工具栏或功能区面板。

**方式二：选择版本启动**

1. 在版本列表中，找到您想要启动的 AutoCAD 版本所在行。
2. 点击该行右侧的 **"启动"** 按钮。
3. 系统将启动该特定版本的 AutoCAD 并加载同文插件。

> **启动顺序**：启动 CAD 后，请稍等片刻直到软件完全加载（通常 10~30 秒，取决于计算机性能）。待工具栏中出现同文插件的入口后，即可开始使用。

### 3.2.5 设置默认版本

设置默认版本可以让您每次都通过"一键启动"快速打开最常用的 AutoCAD 版本。

**操作步骤**：

1. 在版本列表中找到您希望设为默认的 AutoCAD 版本。
2. 点击该行右侧的 **"设为默认"** 按钮（或右键点击该行，在上下文菜单中选择"设为默认版本"）。
3. 设置成功后，该版本行会出现一个星标（⭐）或"默认"标签，同时顶部的一键启动按钮也会更新为该版本的名称。

> **提示**：默认版本设置会保存在本地配置文件中，下次启动 Studio 时自动生效，无需重新设置。

## 3.3 项目管理页面（🏠）

项目管理是同文 Studio 的核心组织功能。您的每一个翻译任务都归属于一个项目，项目之间相互独立、互不干扰。

### 3.3.1 项目卡片列表

进入项目管理页面后，主区域会以**卡片网格**的形式展示您创建的所有项目。每个项目以一张独立卡片的形态呈现，包含以下信息：

| 卡片元素 | 说明 |
|----------|------|
| **项目名称** | 卡片的标题，以较大的字体显示在顶部 |
| **项目描述** | 一段简短的文字，用于说明该项目的用途或备注信息 |
| **语言对** | 显示该项目的源语言和目标语言，例如"中文 → 英文" |
| **术语表数量** | 显示该项目已关联的术语表文件个数 |
| **图纸数量** | 显示该项目中已创建的翻译任务（图纸）总数 |
| **审批进度条** | 一条可视化进度条，展示该项目下所有翻译条目的审批完成比例（已审批数 / 总数） |
| **操作按钮** | 卡片底部或悬停时显示：新建任务、项目设置、删除项目等 |

> **空状态**：如果您还没有创建任何项目，页面中央会显示空状态引导文字"暂无项目，点击下方按钮创建第一个项目"以及一个醒目的 **"新建项目"** 按钮。

### 3.3.2 新建项目

创建项目是使用同文翻译功能的第一步。一个项目可以理解为一个"文件夹"，里面可以放入多个翻译任务（图纸）。

#### 新建项目对话框

点击项目管理页面中的 **"新建项目"** 按钮，将弹出新建项目对话框。对话框中包含以下配置项：

| 字段 | 类型 | 说明 | 是否必填 |
|------|------|------|----------|
| **项目名称** | 文本输入框 | 项目的唯一标识名称，建议使用具有辨识度的名称，例如"XX项目-厂房图纸翻译" | ✅ 必填 |
| **项目描述** | 多行文本框 | 项目的补充说明信息，可留空。描述会在项目卡片上显示。 | 可选 |
| **源语言** | 下拉选择框 | 选择图纸中原文的语言，例如"中文" | ✅ 必填 |
| **目标语言** | 下拉选择框 | 选择翻译的目标语言，例如"英文"、"日文"、"韩文"等 | ✅ 必填 |
| **术语表引用** | 多选选择器 | 从术语库中选择一个或多个术语表关联到该项目。关联后，翻译过程中会自动应用术语表中的规范译法。 | 可选 |

#### 操作步骤

1. 点击项目管理页面中的 **"+ 新建项目"** 按钮。
2. 在弹出的对话框中，输入**项目名称**（必填）。
3. （可选）输入**项目描述**，帮助自己和团队成员了解项目背景。
4. 从**源语言**下拉列表中选择原文语言（例如"中文"）。
5. 从**目标语言**下拉列表中选择您需要翻译成的语言（例如"英文"）。
6. （可选但强烈推荐）点击**术语表引用**区域，在弹出的术语表选择器中勾选您希望关联的术语表文件。关于术语表选择器的详细操作，请参考第 3.5.2 节。
7. 确认所有信息无误后，点击 **"确定"** 按钮。
8. 如果创建成功，对话框将自动关闭，项目卡片列表中会出现您刚创建的项目卡片。

> **注意事项**：
> - 项目名称在系统中允许多个项目同名，但建议使用有区分度的名称以避免混淆。
> - 创建项目后，语言对不可修改。如需更改，请删除该项目后重新创建（操作前请确认项目中是否有已完成的翻译数据）。

### 3.3.3 新建翻译任务

有了项目之后，就可以创建翻译任务了。一个翻译任务对应一张或多张 DWG/DXF 图纸。

#### 新建翻译任务对话框

在目标项目的卡片上点击 **"新建任务"** 按钮，将弹出新建翻译任务对话框。对话框包含以下配置：

| 字段/区域 | 类型 | 说明 |
|-----------|------|------|
| **选择文件** | 文件浏览/拖拽区 | 点击"浏览"按钮或直接拖拽 DWG/DXF 文件到该区域，支持多选 |
| **已选文件列表** | 列表展示 | 显示您已添加的文件名称、路径和文件大小。可以在此列表中移除不需要的文件 |
| **提取模式** | 单选按钮组 | 选择图纸内容的提取模式。当前唯一可选：**Core Console 模式** |
| **提取设置** | 折叠面板 | Core Console 模式下的高级参数设置（通常保持默认即可） |

#### Core Console 提取模式说明

Core Console 是同文当前唯一的图纸内容提取模式。它利用 AutoCAD 的 Core Console（核心控制台）功能，在后台以静默方式打开 DWG/DXF 文件并提取其中需要翻译的文本内容。

**Core Console 模式的特点**：

- **无需打开 AutoCAD 界面**：提取过程在后台完成，不会弹出 AutoCAD 图形窗口，不干扰您正在进行的工作。
- **速度快**：相比交互式提取，Console 模式的处理速度更快，适合批量图纸处理。
- **要求 CAD 已安装**：需要系统中至少安装了一个版本的 AutoCAD 或中望 CAD 来提供 Core Console 组件。
- **支持格式**：DWG（2010 及以上版本）、DXF（ASCII 和 Binary 格式）。

#### 操作步骤

1. 在项目管理页面中，找到目标项目卡片，点击卡片上的 **"新建任务"** 按钮。
2. 在弹出对话框中，点击 **"浏览文件"** 按钮或直接将 DWG/DXF 文件拖入文件选择区域。
3. 在文件选择窗口中，定位到您的图纸所在文件夹，选中一个或多个文件（按住 Ctrl 键可多选），点击"打开"。
4. 回到对话框后，在**已选文件列表**中确认文件列表是否正确。如需移除某个文件，点击该文件右侧的删除图标。
5. 确认**提取模式**为"Core Console"（当前唯一可选模式）。
6. （可选）展开"提取设置"，根据需要进行调整。对于绝大多数场景，默认设置即可胜任。
7. 点击 **"确定"** 按钮，系统将开始提取过程。
8. 提取过程中，系统会显示进度条和当前处理的文件名。提取完成后，Studio 将自动跳转到**翻译工作区**页面，所有提取到的文本内容将显示在翻译表格中。

> **注意**：
> - 提取过程中请勿关闭 Studio 或强制结束 AutoCAD Core Console 进程。
> - 如果提取失败，请检查：① AutoCAD 是否已正确安装；② 图纸文件是否损坏；③ 设置页面中 AutoCAD 检测路径是否正确。

### 3.3.4 项目设置

对于已创建的项目，您可以随时修改其基本信息和配置。

#### 项目设置抽屉面板

点击项目卡片上的 **"项目设置"** 按钮（通常是一个齿轮图标），页面右侧会滑出一个**抽屉面板**。抽屉面板从右向左滑入，覆盖部分主内容区域，关闭时反向滑出。

抽屉面板中包含以下可修改的配置：

| 字段 | 类型 | 说明 |
|------|------|------|
| **项目名称** | 文本输入框 | 修改项目名称，修改后项目卡片和列表中的名称会同步更新 |
| **项目描述** | 多行文本框 | 修改项目的描述信息 |
| **语言对** | 下拉选择框（只读） | 显示当前语言对，**创建后不可修改**。如需更改请删除项目重建 |
| **术语表引用** | 多选选择器 | 添加或移除关联的术语表文件。取消关联不会删除术语表文件本身 |

#### 操作步骤

1. 在项目管理页面中，找到目标项目卡片。
2. 点击卡片上的 **"⚙ 项目设置"** 按钮。
3. 右侧滑出设置抽屉面板，显示当前项目的配置信息。
4. 修改需要调整的字段（如项目名称、描述或术语表引用）。
5. 修改完成后，点击抽屉面板底部的 **"保存"** 按钮。
6. 如果放弃修改，点击 **"取消"** 按钮或点击抽屉面板外的空白区域即可关闭。

### 3.3.5 删除项目

删除项目将永久移除该项目及其包含的所有翻译任务、翻译数据和进度记录。**此操作不可撤销**，请在操作前仔细确认。

#### 操作步骤

1. 在项目管理页面中，找到目标项目卡片。
2. 点击卡片上的 **"删除项目"** 按钮（通常为一个垃圾桶图标，可能位于卡片底部或悬停状态下显示）。
3. 系统将弹出一个**确认对话框**，其中会明确列出将被删除的数据：
   - 项目名称
   - 关联的翻译任务数量
   - 已翻译/未翻译的条目数量
4. 确认对话框会要求您**二次确认**（例如输入项目名称或点击"确认删除"按钮）。
5. 点击 **"确认删除"** 按钮后，系统执行删除操作。
6. 删除完成后，项目卡片从列表中消失，页面恢复为删除前的状态。

> **警告**：删除操作立即生效且无法恢复。如果项目中包含大量已完成翻译的数据，建议在删除前先通过翻译工作区的"导出"功能备份数据。

## 3.4 管道服务（Pipe Service）

同文 Studio 使用 IPC（Inter-Process Communication，进程间通信）管道来与 AutoCAD 进程进行实时通信。管道的运行状态直接影响提取和翻译功能能否正常工作。

### 3.4.1 管道状态指示

管道服务的运行状态可以在两个位置查看：

| 位置 | 显示方式 |
|------|----------|
| **底部状态栏** | 状态栏左侧有一个管道状态指示灯和文字说明 |
| **启动器页面** | 启动器页面顶部可能有专用的管道状态面板 |

管道状态有以下几种：

| 状态 | 指示灯颜色 | 含义 |
|------|------------|------|
| **运行中** | 🟢 绿色 | 管道服务正常运行，可以执行提取和翻译操作 |
| **已停止** | 🔴 红色 | 管道服务未启动，提取和翻译功能不可用 |
| **启动中** | 🟡 黄色 | 管道服务正在启动过程中，请稍候 |
| **连接断开** | ⚪ 灰色 | 管道服务正在运行但与 CAD 的连接已断开，需要重新连接 |

### 3.4.2 启动管道服务

通常情况下，管道服务会在 Studio 启动时自动启动。如果因故未启动或您手动停止了它，可以通过以下方式重新启动：

1. 查看底部状态栏或启动器页面中的管道状态指示。
2. 如果状态显示"已停止"，点击旁边的 **"启动管道"** 按钮。
3. 系统将在后台启动管道服务，状态指示灯将先变为黄色（启动中），然后变为绿色（运行中）。
4. 启动完成后，提取和翻译功能恢复正常。

### 3.4.3 停止管道服务

在以下场景中，您可能需要手动停止管道服务：

- Studio 长时间不使用时，释放系统资源。
- 管道服务出现异常（如响应缓慢），需要重启。
- 安装更新或修改 CAD 插件配置前。

**操作步骤**：

1. 点击状态栏或启动器页面中的 **"停止管道"** 按钮。
2. 管道服务将在几秒内安全关闭，状态指示灯变为红色。
3. 如需重新启动，参考上一节的步骤。

### 3.4.4 何时需要管道服务

管道服务并非在所有操作中都必需。以下是各功能对管道服务的依赖情况：

| 操作 | 是否需要管道 | 说明 |
|------|-------------|------|
| 启动 AutoCAD | ✅ 需要 | 通过管道服务通知 CAD 加载插件 |
| 新建翻译任务（提取内容） | ✅ 需要 | 通过管道调用 Core Console 进行提取 |
| 翻译工作区编辑 | ❌ 不需要 | 翻译编辑在 Studio 本地完成 |
| 术语库管理 | ❌ 不需要 | 术语管理独立于 CAD 管道 |
| 项目创建/删除 | ❌ 不需要 | 项目管理完全在 Studio 内部完成 |
| 设置修改 | ❌ 不需要 | 配置修改只涉及本地文件 |

## 3.5 界面交互规范

同文 Studio 遵循一套统一的交互模式。了解这些模式可以帮助您更高效地操作。

### 3.5.1 导航切换

左侧导航栏是页面跳转的唯一入口。切换规则如下：

- **点击切换**：鼠标左键单击导航项即可切换页面。当前所在页面的导航项会高亮显示（通常以不同的背景色或左侧色条标识）。
- **页面独立性**：五个页面的状态各自独立维护。在翻译工作区编辑的内容不会因切换到启动器再切回而丢失。
- **切换不触发保存**：页面切换本身不会触发数据保存操作。翻译工作区中的数据需要手动保存（点击"保存"按钮或使用快捷键）。

### 3.5.2 术语表选择器

术语表选择器是一个在多个场景中出现的通用组件，用于从术语库中选择一个或多个术语表文件。

**出现场景**：
- 新建项目 → 术语表引用
- 项目设置 → 术语表引用
- 翻译工作区 → 关联术语表

**操作方式**：

1. 点击术语表引用字段，或点击字段旁的 **"选择"** 按钮。
2. 弹出一个术语表选择器窗口，列出术语库中所有可用的术语表文件。
3. 每条术语表记录显示：**文件名称**、**语言对**、**条目数量**、**最后修改时间**。
4. 通过复选框勾选您需要关联的术语表（支持多选）。
5. 点击 **"确定"** 完成选择，或点击 **"取消"** 放弃。

> **提示**：您也可以在选择器窗口中点击 **"新建术语表"** 来快速创建一个空的术语表，而无需先离开当前操作场景去术语库页面。

### 3.5.3 抽屉面板

抽屉面板（Drawer）是一种从窗口边缘滑出的面板，用于在不离开当前页面的情况下完成辅助操作或查看详细信息。

**出现场景**：
- 项目设置抽屉
- 术语表详情抽屉

**交互行为**：

| 行为 | 说明 |
|------|------|
| **打开** | 点击触发按钮（如"项目设置"）后，抽屉从右侧平滑滑入 |
| **遮罩层** | 抽屉打开时，其左侧的主内容区会覆盖一层半透明遮罩，提示用户当前焦点在抽屉上 |
| **关闭方式** | ① 点击抽屉内的"取消"按钮；② 点击抽屉外的遮罩区域；③ 按键盘 Esc 键 |
| **保存** | 点击抽屉内的"保存"按钮提交修改并关闭抽屉 |
| **宽度** | 抽屉通常占据窗口宽度的约 30%~40%，可根据内容自适应调整 |

**术语表详情抽屉**：

在术语库页面中，点击某个术语表文件，右侧会滑出详情抽屉，显示该术语表的完整内容预览：

- 术语条目的原文与译文对照列表
- 条目总数和已审核数量
- 最后修改时间和修改人
- 导出和编辑入口按钮

### 3.5.4 对话框操作

Studio 中有多种类型的对话框，用于收集用户输入或请求确认。

**通用对话框行为**：

| 类型 | 示例 | 行为 |
|------|------|------|
| **表单对话框** | 新建项目、新建翻译任务 | 包含多个输入字段和"确定/取消"按钮。按 Enter 键通常等同于点击"确定"，按 Esc 键等同于"取消" |
| **确认对话框** | 删除项目确认 | 显示警告信息和确认/取消按钮，通常要求显式点击确认按钮 |
| **输入对话框** | 重命名、快速搜索 | 包含单个文本输入框，输入内容后按 Enter 确认 |
| **文件选择对话框** | 添加图纸文件 | 调用系统的标准文件选择窗口，支持多选和文件类型过滤 |

**输入对话框**：

输入对话框用于需要用户输入简短文本的场景。它包含：
- 一个提示标签（说明要输入什么）
- 一个文本输入框
- "确定"和"取消"按钮

操作时，直接在输入框中输入文本，按 Enter 或点击"确定"提交，按 Esc 或点击"取消"放弃。

## 3.6 底部状态栏

状态栏位于 Studio 窗口的最底部，是一条始终可见的横条。它实时反映系统的运行状况供您快速了解当前环境。

### 3.6.1 状态栏布局

状态栏从左到右包含以下信息区域：

| 位置 | 显示内容 | 说明 |
|------|----------|------|
| 最左侧 | 🟢/🔴 **管道状态** | 以彩色圆点和文字（"管道运行中"/"管道已停止"）显示 IPC 管道状态 |
| 左侧中部 | **CAD 版本** | 显示当前默认的 AutoCAD 版本，如"CAD 2025"。如果没有设置默认版本，显示"未设置" |
| 中部 | **网络状态** | 显示网络连接状态，例如"在线"或"离线" |
| 右侧中部 | **进程信息** | 可能显示当前正在进行的后台任务信息，如"提取中：厂房图纸.dwg" |
| 最右侧 | **版本号** | 显示 Studio 的当前版本号，如"v1.2.0" |

### 3.6.2 快速操作

点击状态栏中的某些区域可以触发快速操作：

| 点击目标 | 触发操作 |
|----------|----------|
| 管道状态区域 | 打开管道控制菜单（启动/停止/重启） |
| CAD 版本区域 | 跳转到启动器页面 |
| 进程信息区域 | 打开任务进度详情窗口 |

> **提示**：将鼠标悬停在状态栏各区域上停留片刻，通常会显示更详细的工具提示信息。例如悬停在管道状态上，会显示管道的详细运行参数。

## 3.7 常见操作场景演练

### 3.7.1 场景一：首次使用完整流程

以下是首次使用同文进行图纸翻译的完整操作路径：

1. **启动 Studio** → 自动进入启动器页面。
2. **检测 CAD 版本** → 在启动器中点击"重新检测"，确认 CAD 版本列表中出现您安装的 AutoCAD。
3. **注册插件** → 如果插件状态为"未注册"，点击"注册插件"完成注册。
4. **设置默认版本** → 选择一个常用版本，点击"设为默认"。
5. **创建项目** → 切换到项目管理页面（🏠），点击"新建项目"。
6. **填写项目信息** → 输入名称、选择语言对、关联术语表（如有），点击"确定"。
7. **新建翻译任务** → 在新创建的项目卡片上点击"新建任务"。
8. **选择图纸文件** → 浏览并选择需要翻译的 DWG/DXF 文件，点击"确定"。
9. **等待提取完成** → 系统自动提取文本并跳转到翻译工作区。
10. **开始翻译** → 在翻译工作区中逐条编辑译文（详见下一章）。

### 3.7.2 场景二：日常翻译工作

如果您已经创建过项目和任务，日常的翻译工作流程更加简洁：

1. **启动 Studio** → 管道服务和默认 CAD 设置自动加载。
2. **进入项目管理** → 在项目卡片列表中找到正在进行的项目。
3. **新建任务** → 如果有新的图纸需要翻译，点击"新建任务"添加。
4. **进入翻译工作区** → 点击已有任务进入翻译工作区继续翻译（详见第 04 章）。
5. **导出译文** → 翻译完成后，在翻译工作区中导出成果。

### 3.7.3 场景三：项目归档与清理

当某个项目翻译全部完成后：

1. 进入**翻译工作区**，确认所有条目均已审批通过（可通过审批进度条判断）。
2. 使用"导出"功能将译稿保存为 DWG/DXF 或其它格式。
3. 回到**项目管理页面**，确认该项目数据已备份完毕。
4. （可选）点击"删除项目"，清理本地数据以释放空间。
