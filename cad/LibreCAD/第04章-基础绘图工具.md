# 第四章 基础绘图工具

## 4.1 绘图准备

### 4.1.1 图形设置

在开始绘图之前，建议先进行以下设置：

**设置图纸参数**

1. 打开"编辑" > "当前图形首选项"
2. 在"图纸"标签页设置：
   - 图纸格式：A4、A3、A2等
   - 图纸方向：横向或纵向
   - 页边距：根据需要设置

**设置单位**

1. 在"单位"标签页设置：
   - 主单位：毫米、厘米、米、英寸等
   - 长度格式：十进制、分数、科学计数
   - 精度：小数位数

**设置网格**

1. 在"网格"标签页设置：
   - 显示网格：开启/关闭
   - X间距：网格横向间距
   - Y间距：网格纵向间距
   - 元网格：主网格线间隔

### 4.1.2 图层准备

良好的图层组织是高效绘图的基础：

**建议的图层结构**

| 图层名称 | 颜色 | 线型 | 线宽 | 用途 |
|---------|------|------|------|------|
| 0 | 白色 | 实线 | 默认 | 默认图层 |
| 轮廓线 | 黑色 | 实线 | 0.35 | 主要轮廓 |
| 中心线 | 红色 | 点划线 | 0.18 | 中心线 |
| 虚线 | 蓝色 | 虚线 | 0.25 | 隐藏线 |
| 尺寸 | 绿色 | 实线 | 0.18 | 尺寸标注 |
| 文字 | 青色 | 实线 | 0.25 | 文字注释 |
| 辅助 | 灰色 | 实线 | 0.13 | 辅助线 |

**创建图层**

1. 在图层面板点击"+"按钮
2. 输入图层名称
3. 设置图层颜色、线型、线宽
4. 点击确定

### 4.1.3 捕捉设置

开启必要的捕捉模式：

```
推荐开启的捕捉：
☑ 端点捕捉
☑ 中点捕捉
☑ 圆心捕捉
☑ 交点捕捉
☑ 垂足捕捉
```

## 4.2 点工具

### 4.2.1 单点绘制

**命令**：`point` 或菜单 "绘图" > "点" > "单点"

**操作步骤**：
1. 启动点命令
2. 在绘图区域点击或输入坐标
3. 右键或按Enter结束

**命令行示例**：
```
命令: point
指定点位置: 100,50↵
命令: _
```

### 4.2.2 点样式设置

LibreCAD支持多种点样式：

```
编辑 > 当前图形首选项 > 点
├── 点样式：
│   ├── 点（默认）
│   ├── 加号
│   ├── 叉号
│   ├── 圆点
│   └── 方点
└── 点大小：相对或绝对
```

### 4.2.3 定距等分点

在直线或曲线上创建等距离的点：

**操作步骤**：
1. 选择"绘图" > "点" > "等分"
2. 选择要等分的对象
3. 输入等分数量或距离
4. 点自动创建在等分位置

## 4.3 直线工具

### 4.3.1 两点直线

**命令**：`line` 或 `l`

**操作步骤**：
1. 启动直线命令
2. 指定第一点
3. 指定第二点
4. 继续指定下一点或按Enter结束

**命令行示例**：
```
命令: line
指定第一点: 0,0↵
指定下一点或 [撤销(U)]: 100,0↵
指定下一点或 [撤销(U)/闭合(C)]: 100,50↵
指定下一点或 [撤销(U)/闭合(C)]: C↵  (闭合)
命令: _
```

**选项说明**：
- U（撤销）：撤销上一个点
- C（闭合）：连接到第一点形成闭合图形

### 4.3.2 角度直线

从一点出发绘制指定角度的直线：

**命令**：菜单 "绘图" > "直线" > "角度"

**操作步骤**：
1. 启动角度直线命令
2. 指定起点
3. 输入角度值
4. 输入长度或点击终点

**命令行示例**：
```
命令: lineangle
指定起点: 50,50↵
指定角度 <0>: 45↵
指定长度: 100↵
```

### 4.3.3 水平线和垂直线

**水平线**：菜单 "绘图" > "直线" > "水平"
**垂直线**：菜单 "绘图" > "直线" > "垂直"

这两个命令会自动限制直线为水平或垂直方向。

### 4.3.4 平行线

在指定距离处绘制与现有直线平行的线：

**命令**：菜单 "绘图" > "直线" > "平行"

**操作步骤**：
1. 启动平行线命令
2. 输入偏移距离
3. 选择参考直线
4. 点击指定平行线位置（参考线的哪一侧）

### 4.3.5 正交直线

绘制与选定直线垂直的直线：

**命令**：菜单 "绘图" > "直线" > "正交"

**操作步骤**：
1. 启动正交直线命令
2. 选择参考直线
3. 指定垂直线通过的点
4. 指定长度或另一端点

### 4.3.6 切线

**从点到圆的切线**：

**操作步骤**：
1. 选择"绘图" > "直线" > "切线" > "点到圆"
2. 指定点
3. 选择圆或圆弧
4. 选择切点位置（可能有两个）

**两圆公切线**：

**操作步骤**：
1. 选择"绘图" > "直线" > "切线" > "圆到圆"
2. 选择第一个圆
3. 选择第二个圆
4. 选择切线类型（外切/内切）

### 4.3.7 矩形

**命令**：`rectangle` 或 `rec`

**操作步骤**：
1. 启动矩形命令
2. 指定第一个角点
3. 指定对角点

**命令行示例**：
```
命令: rectangle
指定第一个角点: 0,0↵
指定对角点: 100,50↵
```

**使用尺寸绘制矩形**：
```
命令: rectangle
指定第一个角点: 0,0↵
指定对角点: @100,50↵  (使用相对坐标指定尺寸)
```

### 4.3.8 多边形

绘制正多边形：

**命令**：`polygon`

**操作步骤**：
1. 启动多边形命令
2. 输入边数
3. 选择内接或外切
4. 指定中心点
5. 指定半径

**命令行示例**：
```
命令: polygon
输入边数 <4>: 6↵
内接于圆(I)/外切于圆(C) <I>: I↵
指定中心点: 100,100↵
指定半径: 50↵
```

## 4.4 圆工具

### 4.4.1 圆心-半径绘圆

**命令**：`circle` 或 `c`

**操作步骤**：
1. 启动圆命令
2. 指定圆心
3. 输入半径或指定圆上一点

**命令行示例**：
```
命令: circle
指定圆心或 [三点(3P)/两点(2P)/相切(T)]: 100,100↵
指定半径或 [直径(D)]: 50↵
```

### 4.4.2 圆心-直径绘圆

**操作步骤**：
1. 启动圆命令
2. 指定圆心
3. 输入D选择直径模式
4. 输入直径值

**命令行示例**：
```
命令: circle
指定圆心或 [三点(3P)/两点(2P)/相切(T)]: 100,100↵
指定半径或 [直径(D)]: D↵
指定直径: 100↵
```

### 4.4.3 两点绘圆

通过指定直径的两个端点绘制圆：

**操作步骤**：
1. 启动圆命令
2. 输入2P选择两点模式
3. 指定直径的第一个端点
4. 指定直径的第二个端点

**命令行示例**：
```
命令: circle
指定圆心或 [三点(3P)/两点(2P)/相切(T)]: 2P↵
指定直径的第一点: 50,50↵
指定直径的第二点: 150,50↵
```

### 4.4.4 三点绘圆

通过三点绘制经过这三点的圆：

**命令行示例**：
```
命令: circle
指定圆心或 [三点(3P)/两点(2P)/相切(T)]: 3P↵
指定第一点: 0,0↵
指定第二点: 100,0↵
指定第三点: 50,50↵
```

### 4.4.5 相切圆

**两切点一半径**：

绘制与两个对象相切且具有指定半径的圆：

**操作步骤**：
1. 选择"绘图" > "圆" > "两点切圆"
2. 选择第一个相切对象
3. 选择第二个相切对象
4. 输入半径

**三切圆**：

绘制与三个对象都相切的圆：

**操作步骤**：
1. 选择"绘图" > "圆" > "三切圆"
2. 依次选择三个相切对象
3. 系统自动计算并绘制相切圆

### 4.4.6 同心圆

绘制与现有圆同心的圆：

**操作步骤**：
1. 选择"绘图" > "圆" > "同心圆"
2. 选择参考圆
3. 输入新圆的半径

## 4.5 圆弧工具

### 4.5.1 三点圆弧

**命令**：`arc` 或 `a`

**操作步骤**：
1. 启动圆弧命令
2. 指定起点
3. 指定圆弧上的一点
4. 指定终点

**命令行示例**：
```
命令: arc
指定起点或 [圆心(C)]: 0,0↵
指定第二点或 [圆心(C)/端点(E)]: 50,25↵
指定端点: 100,0↵
```

### 4.5.2 圆心-起点-角度

**操作步骤**：
1. 选择"绘图" > "圆弧" > "圆心-起点-角度"
2. 指定圆心
3. 指定起点
4. 输入圆心角

**命令行示例**：
```
命令: arc
指定起点或 [圆心(C)]: C↵
指定圆心: 50,50↵
指定起点: 100,50↵
指定端点或 [角度(A)/弦长(L)]: A↵
指定包含角: 90↵
```

### 4.5.3 圆心-起点-终点

**操作步骤**：
1. 选择圆心起点终点模式
2. 指定圆心
3. 指定起点（确定半径和起始角度）
4. 指定终点（确定终止角度）

### 4.5.4 起点-终点-半径

**操作步骤**：
1. 指定起点
2. 指定终点
3. 输入半径
4. 选择弧的方向（凸向）

### 4.5.5 切线圆弧

从上一个绘制对象的终点继续绘制相切的圆弧：

**操作步骤**：
1. 绘制一条直线或圆弧
2. 选择"绘图" > "圆弧" > "切线"
3. 指定圆弧的终点
4. 系统自动计算相切圆弧

### 4.5.6 续接圆弧

在现有圆弧的端点处继续绘制圆弧：

**操作步骤**：
1. 选择"绘图" > "圆弧" > "续接"
2. 选择现有圆弧
3. 指定续接方式
4. 指定新圆弧参数

## 4.7 样条曲线

### 4.7.1 控制点样条

通过控制点定义的B样条曲线：

**命令**：`spline`

**操作步骤**：
1. 启动样条命令
2. 依次指定控制点
3. 按Enter结束
4. 指定起始切向（可选）
5. 指定终止切向（可选）

**命令行示例**：
```
命令: spline
指定第一点或 [拟合(F)]: 0,0↵
指定下一点: 50,100↵
指定下一点或 [闭合(C)/拟合公差(F)]: 100,50↵
指定下一点或 [闭合(C)/拟合公差(F)]: 150,100↵
指定下一点或 [闭合(C)/拟合公差(F)]: ↵
指定起点切向: ↵
指定端点切向: ↵
```

### 4.7.2 拟合点样条

曲线经过指定的点：

**操作步骤**：
1. 启动样条命令
2. 输入F选择拟合模式
3. 指定拟合点
4. 设置拟合公差

### 4.7.3 样条属性

样条曲线的可编辑属性：
- 控制点位置
- 节点权重
- 闭合/开放状态
- 阶数

## 4.8 折线（多段线）

### 4.8.1 基本折线

**命令**：`polyline` 或 `pl`

**操作步骤**：
1. 启动折线命令
2. 指定起点
3. 依次指定其他顶点
4. 按Enter结束或输入C闭合

**命令行示例**：
```
命令: polyline
指定起点: 0,0↵
指定下一点或 [圆弧(A)/闭合(C)/撤销(U)]: 100,0↵
指定下一点或 [圆弧(A)/闭合(C)/撤销(U)]: 100,50↵
指定下一点或 [圆弧(A)/闭合(C)/撤销(U)]: 0,50↵
指定下一点或 [圆弧(A)/闭合(C)/撤销(U)]: C↵
```

### 4.8.2 折线选项

**圆弧段（A）**：
在折线中插入圆弧段
```
指定下一点或 [圆弧(A)/闭合(C)/撤销(U)]: A↵
指定圆弧的端点或 [角度(A)/圆心(CE)/直线(L)/半径(R)]: 
```

**撤销（U）**：
撤销上一个顶点

**闭合（C）**：
连接到起点形成闭合折线

### 4.8.3 折线与线段的区别

| 特性 | 折线 | 普通线段 |
|------|------|----------|
| 对象数量 | 一个整体 | 多个独立对象 |
| 选择 | 整体选择 | 单独选择 |
| 面积计算 | 支持 | 不支持 |
| 填充 | 支持 | 不支持 |
| 偏移 | 整体偏移 | 单独偏移 |
| 编辑 | 编辑顶点 | 编辑端点 |

### 4.8.4 编辑折线

**编辑折线顶点**：
1. 选择折线
2. 双击或选择"修改" > "编辑折线"
3. 可进行以下操作：
   - 移动顶点
   - 添加顶点
   - 删除顶点
   - 转换为圆弧段

## 4.9 文字工具

### 4.9.1 单行文字

**命令**：`text`

**操作步骤**：
1. 启动文字命令
2. 指定文字插入点

**命令**：`mtext`

1. 启动多行文字命令

5. 点击确定

### 4.9.3 文字样式设置

**设置文字样式**：
1. 格式 > 文字样式

## 4.10 填充图案

### 4.10.1 创建填充

**命令**：`hatch`

**操作步骤**：
1. 启动填充命令
2. 选择填充图案
3. 设置比例和角度
4. 选择边界（点击封闭区域内部）
5. 确认创建

### 4.10.2 填充图案类型

LibreCAD提供多种预定义填充图案：

| 图案名称 | 说明 |
|---------|------|
| SOLID | 实体填充 |
| ANSI31 | 45度斜线 |
| ANSI32 | 密集斜线 |
| ANSI33 | 交叉线 |
| ANSI34 | 点阵 |
| BRICK | 砖墙图案 |
| CONCRETE | 混凝土图案 |
| GRASS | 草地图案 |

### 4.10.3 填充设置

**图案参数**：
- 比例：控制图案大小
- 角度：图案旋转角度
- 原点：图案起始位置

**边界设置**：
- 拾取点：在封闭区域内点击
- 选择对象：选择边界对象
- 边界保留：是否保留边界对象

### 4.10.4 编辑填充

**修改填充属性**：
1. 选择填充对象
2. 打开属性面板或双击
3. 修改图案、比例、角度等

## 4.12 绘图技巧

### 4.12.1 精确绘图技巧

**使用对象捕捉**：
- 开启端点、中点、交点等捕捉
- 绘图时自动吸附到特征点

**使用正交模式**：
- 按F8开启正交
- 限制光标为水平或垂直方向

**使用极轴追踪**：
- 设置常用角度（15°、30°、45°等）
- 光标自动沿设定角度方向

### 4.12.2 快速绘图技巧

**使用命令行**：
- 输入命令比点击菜单更快
- 使用命令别名（l代替line）
- 使用坐标输入精确定位

**复制和镜像**：
- 绘制对称图形的一半
- 使用镜像完成另一半

**利用阵列**：
- 绘制一个重复单元
- 使用阵列创建多个副本

### 4.12.3 常见问题处理

**线段无法连接**：
- 检查坐标精度
- 使用对象捕捉确保连接
- 使用"修复"功能修复小间隙

**填充失败**：
- 确保区域完全封闭
- 检查是否有交叉或重叠线
- 尝试减小填充比例

**对象无法选择**：
- 检查图层是否锁定
- 检查是否在正确的视图
- 尝试使用框选

## 4.13 本章小结

本章详细介绍了LibreCAD的基础绘图工具：

1. **点工具**：单点、多点、等分点
2. **直线工具**：两点线、角度线、平行线、垂直线、切线、矩形、多边形
3. **圆工具**：圆心半径、两点圆、三点圆、相切圆、同心圆
4. **圆弧工具**：三点弧、圆心角度弧、切线弧
5. **椭圆工具**：椭圆、椭圆弧
6. **样条曲线**：控制点样条、拟合点样条
7. **折线**：连续折线、圆弧折线
8. **文字工具**：单行文字、多行文字
9. **填充图案**：各种预定义图案
10. **图像插入**：光栅图像
