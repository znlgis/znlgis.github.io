# 第八章 尺寸标注与文字

## 8.1 尺寸标注概述

### 8.1.1 尺寸标注的重要性

尺寸标注是工程图纸中不可或缺的组成部分，它传达了图形的实际尺寸信息，是制造和施工的依据。

**标注的作用**：
- 表达对象的真实尺寸
- 指导加工制造和施工
- 便于图纸检查和审核
- 记录设计意图

### 8.1.2 尺寸标注的组成

一个完整的尺寸标注包括：

```
            尺寸文字
               │
         ←───3.50───→
         │           │
    延伸线         延伸线
         │           │
    ─────●───────────●─────
         起点       终点
              尺寸线
```

**组成要素**：
- **尺寸线**：带箭头的测量线
- **延伸线**：从对象延伸出来的线
- **尺寸文字**：显示的数值
- **箭头/终端符号**：尺寸线端点的标记

### 8.1.3 尺寸标注类型

LibreCAD支持以下标注类型：

| 类型 | 用途 |
|------|------|
| 线性标注 | 水平和垂直距离 |
| 对齐标注 | 沿对象方向的距离 |
| 半径标注 | 圆弧的半径 |
| 直径标注 | 圆的直径 |
| 角度标注 | 两线之间的角度 |
| 弧长标注 | 圆弧的长度 |
| 坐标标注 | 点的坐标值 |
| 引线标注 | 带指引线的注释 |

## 8.2 尺寸样式设置

### 8.2.1 尺寸样式管理

**打开尺寸样式设置**：
编辑 > 当前图形首选项 > 尺寸

### 8.2.2 尺寸线设置

```
尺寸样式 > 尺寸线
├── 颜色：ByBlock
├── 线宽：ByBlock
├── 超出量：0（箭头外延伸长度）
├── 基线间距：3.75（连续标注间距）
└── 抑制：第一条/第二条（是否显示）
```

### 8.2.3 延伸线设置

```
尺寸样式 > 延伸线
├── 颜色：ByBlock
├── 线宽：ByBlock
├── 超出尺寸线：1.25
├── 起点偏移：0.625
└── 抑制：第一条/第二条
```

### 8.2.4 箭头设置

```
尺寸样式 > 箭头
├── 第一个箭头：实心闭合
├── 第二个箭头：实心闭合
├── 引线箭头：实心闭合
└── 箭头大小：2.5
```

**箭头类型**：
- 实心闭合：最常用的箭头
- 空心闭合：轮廓箭头
- 点：小圆点
- 斜线：短斜线
- 建筑标记：45度短线

### 8.2.5 文字设置

```
尺寸样式 > 文字
├── 文字样式：Standard
├── 文字颜色：ByBlock
├── 文字高度：2.5
├── 从尺寸线偏移：0.625
├── 文字位置：居中
└── 文字对齐：与尺寸线对齐
```

### 8.2.6 主单位设置

```
尺寸样式 > 主单位
├── 单位格式：十进制
├── 精度：0.00（2位小数）
├── 前缀：（如⌀）
├── 后缀：（如mm）
├── 比例因子：1.0
└── 零抑制：前导/后续
```

## 8.3 线性标注

### 8.3.1 对齐标注

沿两点连线方向测量距离：

**命令**：`dimaligned` 或菜单 尺寸 > 对齐

**操作步骤**：
1. 启动对齐标注命令
2. 指定第一个延伸线起点
3. 指定第二个延伸线起点
4. 指定尺寸线位置

**命令行示例**：
```
命令: dimaligned
指定第一条延伸线原点或 <选择对象>: 0,0↵
指定第二条延伸线原点: 100,50↵
指定尺寸线位置: (点击确定位置)
尺寸文字 = 111.80
```

### 8.3.2 水平标注

测量水平方向的距离：

**命令**：`dimhorizontal` 或菜单 尺寸 > 线性 > 水平

**操作步骤**：
1. 启动水平标注命令
2. 指定第一个延伸线起点
3. 指定第二个延伸线起点
4. 指定尺寸线位置

### 8.3.3 垂直标注

测量垂直方向的距离：

**命令**：`dimvertical` 或菜单 尺寸 > 线性 > 垂直

**操作步骤**：
1. 启动垂直标注命令
2. 指定第一个延伸线起点
3. 指定第二个延伸线起点
4. 指定尺寸线位置

### 8.3.4 连续标注

创建连续的标注链：

**命令**：`dimcontinue`

**操作步骤**：
1. 创建第一个线性标注
2. 启动连续标注命令
3. 指定下一个延伸线起点
4. 重复直到完成
5. 按Enter结束

### 8.3.5 基线标注

从同一基线出发创建多个标注：

**命令**：`dimbaseline`

**操作步骤**：
1. 创建第一个线性标注
2. 启动基线标注命令
3. 指定下一个延伸线起点
4. 重复直到完成

## 8.4 半径和直径标注

### 8.4.1 半径标注

标注圆或圆弧的半径：

**命令**：`dimradius` 或菜单 尺寸 > 半径

**操作步骤**：
1. 启动半径标注命令
2. 选择圆或圆弧
3. 指定尺寸线位置

**命令行示例**：
```
命令: dimradius
选择圆弧或圆: (点击圆)
指定尺寸线位置: (点击确定位置)
尺寸文字 = R25.00
```

### 8.4.2 直径标注

标注圆的直径：

**命令**：`dimdiameter` 或菜单 尺寸 > 直径

**操作步骤**：
1. 启动直径标注命令
2. 选择圆
3. 指定尺寸线位置

**命令行示例**：
```
命令: dimdiameter
选择圆弧或圆: (点击圆)
指定尺寸线位置: (点击确定位置)
尺寸文字 = ⌀50.00
```

### 8.4.3 弧长标注

标注圆弧的长度：

**操作步骤**：
1. 选择弧长标注命令
2. 选择圆弧
3. 指定尺寸位置

## 8.5 角度标注

### 8.5.1 两线角度

标注两条直线之间的夹角：

**命令**：`dimangular` 或菜单 尺寸 > 角度

**操作步骤**：
1. 启动角度标注命令
2. 选择第一条线
3. 选择第二条线
4. 指定尺寸弧位置

**命令行示例**：
```
命令: dimangular
选择圆弧、圆、线或 <指定顶点>: (选择第一条线)
选择第二条线: (选择第二条线)
指定尺寸弧线位置: (点击确定位置)
尺寸文字 = 45°
```

### 8.5.2 三点角度

通过三点定义角度：

**操作步骤**：
1. 启动角度标注命令
2. 按Enter选择指定顶点模式
3. 指定角度顶点
4. 指定第一条边上的点
5. 指定第二条边上的点
6. 指定尺寸弧位置

### 8.5.3 圆弧角度

标注圆弧的圆心角：

**操作步骤**：
1. 启动角度标注命令
2. 选择圆弧
3. 指定尺寸弧位置

## 8.6 引线标注

### 8.6.1 创建引线

**命令**：`leader` 或菜单 尺寸 > 引线

**操作步骤**：
1. 启动引线命令
2. 指定引线起点（箭头位置）
3. 指定引线拐点（可多个）
4. 指定引线终点
5. 按Enter结束引线
6. 输入注释文字

**命令行示例**：
```
命令: leader
指定引线起点: (点击箭头位置)
指定下一点: (点击拐点)
指定下一点或 [注释(A)/格式(F)/撤销(U)] <注释>: ↵
输入注释文字: 表面粗糙度 Ra3.2↵
```

### 8.6.2 引线样式

引线可以设置不同的样式：

- **箭头类型**：实心、空心、点等
- **引线类型**：直线、样条曲线
- **落地线**：引线末端的水平线

### 8.6.3 多重引线

创建多个箭头指向同一注释：

**操作步骤**：
1. 创建第一个引线
2. 添加附加的引线起点
3. 连接到同一文字

## 8.7 坐标标注

### 8.7.1 X坐标标注

**命令**：菜单 尺寸 > 坐标 > X坐标

**操作步骤**：
1. 启动X坐标标注
2. 指定要标注的点
3. 指定引线终点位置

### 8.7.2 Y坐标标注

**命令**：菜单 尺寸 > 坐标 > Y坐标

**操作步骤**：
1. 启动Y坐标标注
2. 指定要标注的点
3. 指定引线终点位置

### 8.7.3 坐标标注的应用

坐标标注适用于：
- 孔位坐标标注
- 加工中心编程
- 数控加工图纸

## 8.8 编辑尺寸标注

### 8.8.1 修改尺寸文字

**双击编辑**：
1. 双击尺寸标注
2. 修改文字内容
3. 确认

**命令行编辑**：
```
命令: dimedit
选择标注: (选择尺寸)
输入新的尺寸文字: 50.00↵
```

### 8.8.2 覆盖尺寸值

可以输入与测量值不同的文字：

**特殊符号**：
- `<>`：代表实际测量值
- `<>mm`：在测量值后加单位
- `2x<>`：显示为"2x50.00"形式

### 8.8.3 移动尺寸文字

1. 选择尺寸标注
2. 拖动文字控制点
3. 移动到新位置

### 8.8.4 调整尺寸位置

**移动整个尺寸**：
1. 选择尺寸标注
2. 使用移动命令
3. 指定新位置

**调整尺寸线位置**：
1. 选择尺寸标注
2. 拖动尺寸线控制点

### 8.8.5 更新尺寸

当对象修改后，更新相关尺寸：

**自动更新**：
关联尺寸自动随对象更新

**手动更新**：
```
命令: dimregen
选择标注: (选择要更新的尺寸)
```

## 8.9 文字工具详解

### 8.9.1 单行文字

**命令**：`text`

**操作步骤**：
1. 启动文字命令
2. 指定文字起点
3. 输入文字高度
4. 输入旋转角度
5. 输入文字内容
6. 按Enter确认

**命令行示例**：
```
命令: text
指定文字起点或 [对正(J)/样式(S)]: 100,100↵
指定高度 <5>: 5↵
指定旋转角度 <0>: 0↵
输入文字: LibreCAD教程↵
```

### 8.9.2 文字对正

文字对正决定了文字相对于插入点的位置：

| 对正方式 | 说明 |
|---------|------|
| 左 | 左对齐（默认） |
| 中 | 水平居中 |
| 右 | 右对齐 |
| 左上 | 左上角对齐 |
| 中上 | 顶部居中 |
| 右上 | 右上角对齐 |
| 中间 | 完全居中 |

### 8.9.3 多行文字

**命令**：`mtext`

**操作步骤**：
1. 启动多行文字命令
2. 指定第一个角点
3. 指定对角点
4. 在编辑器中输入文字
5. 确定

**多行文字编辑器功能**：
- 字体设置
- 文字大小
- 粗体/斜体
- 文字颜色
- 段落对齐
- 行距设置

### 8.9.4 文字样式

**创建文字样式**：
1. 格式 > 文字样式
2. 新建样式
3. 设置字体、高度、宽度因子等
4. 保存

**样式参数**：
```
文字样式
├── 样式名称
├── 字体名称
├── 字体大小：0=使用时指定
├── 宽度因子：1.0=正常
├── 倾斜角度：0=不倾斜
└── 文字生成标志
```

### 8.9.5 特殊字符

**使用特殊字符**：

| 代码 | 显示 | 说明 |
|------|------|------|
| %%c | ⌀ | 直径符号 |
| %%d | ° | 度数符号 |
| %%p | ± | 正负符号 |
| %%% | % | 百分号 |
| %%o | 上划线 | 切换上划线 |
| %%u | 下划线 | 切换下划线 |

### 8.9.6 编辑文字

**双击编辑**：
双击文字对象进入编辑模式

**属性编辑**：
在属性面板中修改文字属性

**命令编辑**：
```
命令: ddedit
选择注释对象: (选择文字)
```

## 8.10 标注最佳实践

### 8.10.1 标注原则

**清晰性**：
- 尺寸应易于阅读
- 避免标注重叠
- 使用适当的文字大小

**完整性**：
- 标注所有必要的尺寸
- 避免重复标注
- 包含基准尺寸

**一致性**：
- 使用统一的标注样式
- 保持相同的精度
- 遵循行业标准

### 8.10.2 标注布局

**尺寸链**：
连续标注相邻的尺寸

**基线标注**：
从同一基准出发标注

**坐标标注**：
用于数控加工的坐标方式

### 8.10.3 常见问题

**尺寸太小看不清**：
- 增加文字高度
- 调整箭头大小
- 检查图形比例

**尺寸与对象重叠**：
- 移动尺寸位置
- 使用打断点
- 调整延伸线偏移
