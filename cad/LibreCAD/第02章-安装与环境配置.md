# 第二章 安装与环境配置

## 2.1 系统要求

### 2.1.1 硬件要求

LibreCAD对硬件要求相对较低，以下是推荐配置：

**最低配置**
- **处理器**：1.0 GHz 或更快的处理器
- **内存**：512 MB RAM
- **存储空间**：200 MB 可用硬盘空间
- **显示器**：1024 x 768 分辨率

**推荐配置**
- **处理器**：2.0 GHz 或更快的多核处理器
- **内存**：2 GB RAM 或更多
- **存储空间**：500 MB 可用硬盘空间
- **显示器**：1920 x 1080 分辨率或更高
- **显卡**：支持OpenGL的显卡（可选，用于硬件加速）

### 2.1.2 软件要求

**操作系统支持**

| 操作系统 | 版本要求 | 支持状态 |
|---------|---------|---------|
| Windows | Windows 7 SP1 或更高 | 完全支持 |
| macOS | 10.14 (Mojave) 或更高 | 完全支持 |
| Linux | 主流发行版 | 完全支持 |

**Linux发行版支持**
- Ubuntu 18.04 LTS 或更高
- Debian 10 或更高
- Fedora 30 或更高
- CentOS/RHEL 7 或更高
- Arch Linux
- openSUSE
- 其他支持Qt的发行版

## 2.2 Windows系统安装

### 2.2.1 从官方下载安装

**步骤一：下载安装包**

1. 访问LibreCAD官方下载页面：https://github.com/LibreCAD/LibreCAD/releases
2. 找到最新的稳定版本（通常标记为Latest）
3. 下载适合您系统的安装包：
   - `LibreCAD-Installer-x.x.x-win64.exe`（64位系统推荐）
   - `LibreCAD-Installer-x.x.x-win32.exe`（32位系统）

**步骤二：运行安装程序**

1. 双击下载的安装程序
2. 如果出现用户账户控制提示，点击"是"允许安装
3. 选择安装语言（可选择"简体中文"）

**步骤三：安装向导**

1. **欢迎页面**：点击"下一步"继续

2. **许可协议**：
   - 阅读GNU通用公共许可证第2版
   - 选择"我接受协议"
   - 点击"下一步"

3. **选择目标位置**：
   - 默认安装路径：`C:\Program Files\LibreCAD`
   - 可点击"浏览"更改安装位置
   - 点击"下一步"

4. **选择开始菜单文件夹**：
   - 使用默认设置或自定义文件夹名称
   - 点击"下一步"

5. **选择附加任务**：
   - ☑ 创建桌面快捷方式（推荐）
   - ☑ 创建快速启动栏图标
   - 点击"下一步"

6. **准备安装**：
   - 确认安装设置
   - 点击"安装"开始安装

7. **完成安装**：
   - 安装完成后点击"完成"
   - 可勾选"运行LibreCAD"立即启动

### 2.2.2 便携版安装

LibreCAD也提供便携版，无需安装即可使用：

1. 下载便携版压缩包：`LibreCAD-x.x.x-win64-portable.zip`
2. 解压到任意目录（如：`D:\PortableApps\LibreCAD`）
3. 运行目录中的`librecad.exe`即可启动

便携版优点：
- 无需管理员权限
- 可放在U盘中随身携带
- 不会修改系统注册表
- 卸载时直接删除文件夹即可

### 2.2.3 通过包管理器安装

**使用Chocolatey安装**

如果已安装Chocolatey包管理器，可使用以下命令：

```powershell
# 以管理员身份运行PowerShell
choco install librecad
```

**使用Scoop安装**

```powershell
# 添加extras bucket
scoop bucket add extras

# 安装LibreCAD
scoop install librecad
```

## 2.3 macOS系统安装

### 2.3.1 从官方下载安装

**步骤一：下载DMG文件**

1. 访问：https://github.com/LibreCAD/LibreCAD/releases
2. 下载macOS版本：
   - `LibreCAD-x.x.x-macOS-arm64.dmg`（Apple Silicon芯片）
   - `LibreCAD-x.x.x-macOS-x86_64.dmg`（Intel芯片）

**步骤二：安装应用**

1. 双击下载的DMG文件挂载磁盘映像
2. 将LibreCAD图标拖拽到Applications文件夹
3. 等待复制完成后弹出磁盘映像

**步骤三：处理安全提示（Apple Silicon/macOS 12+）**

由于LibreCAD未进行Apple签名，首次运行可能遇到"已损坏"提示：

```bash
# 打开终端，执行以下命令
xattr -rc /Applications/LibreCAD.app
sudo codesign --force --deep --sign - /Applications/LibreCAD.app
```

或者：
1. 打开"系统偏好设置" > "安全性与隐私"
2. 点击"仍然打开"允许运行LibreCAD

### 2.3.2 通过Homebrew安装

推荐使用Homebrew进行安装和更新：

```bash
# 安装Homebrew（如果尚未安装）
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 安装LibreCAD
brew install --cask librecad

# 更新LibreCAD
brew upgrade --cask librecad
```

### 2.3.3 macOS特定设置

**Retina显示屏优化**

LibreCAD支持Retina显示屏的高DPI渲染：
1. 打开LibreCAD
2. 进入"编辑" > "当前图形首选项" > "显示"
3. 调整适合的缩放比例

**触控板手势**

macOS版本支持以下触控板手势：
- 双指捏合：缩放视图
- 双指滑动：平移视图
- 双指轻点：右键菜单

## 2.4 Linux系统安装

### 2.4.1 Ubuntu/Debian系统

**方法一：使用APT安装（推荐）**

```bash
# 更新软件包列表
sudo apt update

# 安装LibreCAD
sudo apt install librecad

# 安装中文语言包（可选）
sudo apt install librecad-data
```

**方法二：添加PPA获取最新版本**

官方仓库的版本可能不是最新的，可通过PPA获取：

```bash
# 添加LibreCAD PPA
sudo add-apt-repository ppa:librecad-dev/librecad-stable
sudo apt update

# 安装最新版本
sudo apt install librecad
```

**方法三：从源码编译**

参见后续章节"源码编译与开发环境搭建"。

### 2.4.2 Fedora/RHEL/CentOS

**Fedora系统**

```bash
# 使用DNF安装
sudo dnf install librecad
```

**RHEL/CentOS系统**

```bash
# 首先启用EPEL仓库
sudo dnf install epel-release

# 安装LibreCAD
sudo dnf install librecad
```

### 2.4.3 Arch Linux

```bash
# 使用Pacman安装
sudo pacman -S librecad

# 或从AUR安装开发版本
yay -S librecad-git
```

### 2.4.4 openSUSE

```bash
# 使用Zypper安装
sudo zypper install librecad
```

### 2.4.5 通过Flatpak安装（通用方法）

Flatpak是一种跨发行版的包格式：

```bash
# 安装Flatpak（如果尚未安装）
# Ubuntu/Debian:
sudo apt install flatpak

# 添加Flathub仓库
flatpak remote-add --if-not-exists flathub https://flathub.org/repo/flathub.flatpakrepo

# 安装LibreCAD
flatpak install flathub org.librecad.librecad

# 运行LibreCAD
flatpak run org.librecad.librecad
```

### 2.4.6 通过Snap安装

```bash
# 安装LibreCAD
sudo snap install librecad

# 运行LibreCAD
librecad
```

## 2.5 首次启动与基本配置

### 2.5.1 初始化向导

首次启动LibreCAD时，会显示欢迎界面：

1. **语言选择**：
   - 从下拉列表选择"简体中文"或其他语言
   - 确认后界面会切换为所选语言

2. **单位设置**：
   - 选择默认工作单位（毫米/厘米/米/英寸等）
   - 设置默认图纸尺寸

3. **界面主题**：
   - 选择亮色或暗色主题
   - 可稍后在设置中更改

### 2.5.2 应用程序首选项

点击"编辑" > "应用程序首选项"打开设置面板：

**外观设置**

```
应用程序首选项 > 外观
├── 语言：简体中文
├── 工具栏图标大小：中等(24x24)
├── 字体：系统默认
├── 显示网格：是
└── 背景颜色：白色（可自定义）
```

**路径设置**

```
应用程序首选项 > 路径
├── 转换：/usr/share/librecad/translations
├── 填充图案：/usr/share/librecad/patterns
├── 字体：/usr/share/librecad/fonts
├── 库目录：/usr/share/librecad/library
└── 模板目录：/usr/share/librecad/templates
```

**默认设置**

```
应用程序首选项 > 默认
├── 单位：毫米
├── 图纸尺寸：A4
├── 颜色深度：24位
├── 自动保存间隔：5分钟
└── 备份文件数量：3
```

### 2.5.3 当前图形首选项

点击"编辑" > "当前图形首选项"设置当前图形参数：

**图纸设置**

```
当前图形首选项 > 图纸
├── 图纸格式：A4
├── 图纸方向：横向/纵向
├── 页边距：10mm
└── 页数：单页
```

**单位设置**

```
当前图形首选项 > 单位
├── 主单位：毫米
├── 格式：十进制
├── 精度：0.00 (2位小数)
└── 比例：1:1
```

**网格设置**

```
当前图形首选项 > 网格
├── 显示网格：是
├── 正交网格：是
├── X间距：10
├── Y间距：10
└── 元网格：5
```

**尺寸设置**

```
当前图形首选项 > 尺寸
├── 尺寸文字高度：2.5
├── 箭头大小：2.5
├── 延伸线长度：2.0
├── 尺寸线间距：10.0
└── 精度：0.00
```

### 2.5.4 自定义快捷键

LibreCAD支持自定义键盘快捷键：

1. 进入"编辑" > "应用程序首选项" > "快捷键"
2. 在命令列表中找到要修改的命令
3. 双击当前快捷键列
4. 按下新的快捷键组合
5. 点击"确定"保存

**常用默认快捷键**

| 功能 | 快捷键 | 说明 |
|------|--------|------|
| 新建 | Ctrl+N | 新建图形 |
| 打开 | Ctrl+O | 打开文件 |
| 保存 | Ctrl+S | 保存文件 |
| 撤销 | Ctrl+Z | 撤销操作 |
| 重做 | Ctrl+Y | 重做操作 |
| 复制 | Ctrl+C | 复制选中 |
| 粘贴 | Ctrl+V | 粘贴 |
| 删除 | Delete | 删除选中 |
| 全选 | Ctrl+A | 选择全部 |
| 放大 | +/= | 放大视图 |
| 缩小 | - | 缩小视图 |
| 适应窗口 | V | 自动缩放 |

## 2.6 工作环境优化

### 2.6.1 显示设置优化

**高DPI显示器配置**

对于4K或Retina显示器：

1. 打开"编辑" > "应用程序首选项"
2. 进入"外观"选项卡
3. 调整"工具栏图标大小"为"大(32x32)"
4. 如果文字过小，可在操作系统层面设置缩放

**Windows系统DPI设置**
```
右键桌面 > 显示设置 > 缩放与布局 > 更改文本、应用等项目的大小
```

**Linux系统DPI设置**（以GNOME为例）
```bash
gsettings set org.gnome.desktop.interface text-scaling-factor 1.25
```

### 2.6.2 性能优化

**大文件处理优化**

```
应用程序首选项 > 外观
├── 显示文字：仅标题模式（大文件时）
├── 显示填充：简化显示（大文件时）
└── 选择轮廓宽度：1（减少渲染负担）
```

**自动保存设置**

```
应用程序首选项 > 默认
├── 自动保存：启用
├── 自动保存间隔：5分钟（根据需要调整）
└── 备份数量：3
```

### 2.6.3 工作区布局

**停靠面板管理**

LibreCAD允许自定义停靠面板布局：

1. **显示/隐藏面板**：
   - 视图 > 停靠区域 > 选择要显示的面板

2. **调整面板位置**：
   - 拖动面板标题栏到新位置
   - 可停靠在左/右/上/下边

3. **浮动面板**：
   - 双击面板标题栏使其浮动
   - 再次双击返回停靠状态

**保存工作区布局**

目前LibreCAD会自动保存上次的窗口布局，下次启动时恢复。

### 2.6.4 模板配置

**创建自定义模板**

1. 新建一个空白图形
2. 设置好默认的：
   - 图层结构
   - 尺寸样式
   - 文字样式
   - 线型定义
3. 另存为模板文件：`文件 > 另存为` > 选择路径
4. 将文件保存到模板目录

**设置默认模板**

```
应用程序首选项 > 路径 > 模板
设置模板目录路径，LibreCAD会在新建时显示可用模板
```

## 2.7 多语言配置

### 2.7.1 界面语言切换

1. 打开"编辑" > "应用程序首选项"
2. 在"外观"标签页找到"语言"选项
3. 从下拉列表选择语言：
   - 简体中文
   - 繁体中文
   - English
   - 其他语言
4. 点击"确定"
5. 重启LibreCAD使更改生效

### 2.7.2 字体配置

**中文字体支持**

LibreCAD使用LFF格式字体文件，要正确显示中文需要：

1. 下载中文字体文件（如：`simsun.lff`）
2. 将字体文件复制到LibreCAD字体目录：
   - Windows: `C:\Program Files\LibreCAD\resources\fonts`
   - Linux: `/usr/share/librecad/fonts`
   - macOS: `/Applications/LibreCAD.app/Contents/Resources/fonts`

3. 重启LibreCAD
4. 在文字样式中选择中文字体

**从TTF转换字体**

LibreCAD提供了字体转换工具：

```bash
# 使用ttf2lff工具转换
ttf2lff input.ttf output.lff
```

### 2.7.3 命令别名本地化

可以为常用命令创建中文别名：

1. 找到命令别名文件（通常在配置目录）
2. 添加中文别名：

```
# 命令别名示例
直线=line
圆=circle
圆弧=arc
移动=move
复制=copy
```

### 2.8.3 备份与迁移

**备份配置**

建议定期备份以下内容：
- 用户配置目录
- 自定义字体文件
- 自定义图块库
- 模板文件

**迁移到新系统**

1. 复制旧系统的配置目录
2. 在新系统安装LibreCAD
3. 将配置目录内容复制到新系统对应位置
4. 重启LibreCAD

## 2.9 常见安装问题

### 2.9.1 Windows常见问题

**问题1：提示缺少DLL文件**

解决方案：
1. 安装Visual C++ Redistributable
2. 下载地址：https://aka.ms/vs/17/release/vc_redist.x64.exe

**问题2：程序无法启动**

解决方案：
1. 以管理员身份运行
2. 检查防病毒软件是否拦截
3. 重新安装程序

**问题3：中文显示乱码**

解决方案：
1. 确保系统安装了中文字体
2. 在LibreCAD中安装中文LFF字体
3. 检查文件编码是否为UTF-8

### 2.9.2 macOS常见问题

**问题1："已损坏，无法打开"**

解决方案：
```bash
xattr -rc /Applications/LibreCAD.app
sudo codesign --force --deep --sign - /Applications/LibreCAD.app
```

**问题2：Retina显示模糊**

解决方案：
1. 检查显示设置中的缩放选项
2. 尝试不同的分辨率设置

### 2.9.3 Linux常见问题

**问题1：Qt版本不兼容**

解决方案：
```bash
# Ubuntu/Debian
sudo apt install libqt5-dev

# 或使用Flatpak版本避免依赖问题
flatpak install flathub org.librecad.librecad
```

**问题2：启动时崩溃**

解决方案：
1. 删除配置文件重新生成：
```bash
rm -rf ~/.config/LibreCAD
```
2. 检查显卡驱动是否正确安装
3. 尝试使用软件渲染：
```bash
LIBGL_ALWAYS_SOFTWARE=1 librecad
```

**问题3：菜单无法显示**

解决方案（针对Wayland）：
```bash
# 使用XWayland运行
QT_QPA_PLATFORM=xcb librecad
```
