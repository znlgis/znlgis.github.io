# 第十章 打印与输出

## 10.1 打印基础

### 10.1.1 打印概述

在CAD工作流程中，将数字图纸转换为物理输出或电子文档是最终交付的重要环节。LibreCAD提供了完整的打印和输出功能。

**输出方式**：
- 打印机输出：物理纸张
- PDF输出：电子文档
- 图像输出：栅格图像

### 10.1.2 打印与导出的区别

| 特性 | 打印 | 导出 |
|------|------|------|
| 输出设备 | 打印机/PDF打印机 | 文件 |
| 格式 | 打印机支持的格式 | SVG/PDF/图像 |
| 交互 | 打印对话框 | 导出对话框 |
| 用途 | 最终输出 | 中间格式交换 |

## 10.2 页面设置

### 10.2.1 图纸设置

在打印前，需要设置图纸参数：

**设置方法**：
编辑 > 当前图形首选项 > 图纸

**图纸参数**：
```
图纸设置
├── 图纸格式：A4/A3/A2/A1/A0/自定义
├── 方向：纵向/横向
├── 页边距：上/下/左/右
└── 页数：单页/多页
```

### 10.2.2 标准图纸尺寸

| 格式 | 尺寸(mm) | 用途 |
|------|---------|------|
| A0 | 841 × 1189 | 大型图纸 |
| A1 | 594 × 841 | 详图、大型零件 |
| A2 | 420 × 594 | 装配图 |
| A3 | 297 × 420 | 零件图 |
| A4 | 210 × 297 | 文档、小型零件 |

### 10.2.3 自定义图纸尺寸

**设置自定义尺寸**：
1. 在图纸格式选择"自定义"
2. 输入宽度和高度
3. 设置单位（mm/inch）

### 10.3.1 进入打印预览

**方法**：
- 文件 > 打印预览
- 工具栏打印预览按钮

### 10.3.3 预览操作

**视图控制**：
- 滚轮：缩放
- 中键拖动：平移

**打印设置**：

## 10.4 打印设置

### 10.4.1 打开打印对话框

**方法**：
- 文件 > 打印
- 快捷键：Ctrl+P
- 打印预览中的打印按钮

### 10.4.2 打印机选择

```
打印设置
├── 打印机：选择打印机
├── 状态：就绪/离线
├── 类型：激光/喷墨/PDF
└── 位置：本地/网络
```

### 10.4.3 打印范围

**范围选项**：
| 选项 | 说明 |
|------|------|
| 范围 | 打印绘图范围内的内容 |
| 窗口 | 打印指定窗口区域 |
| 当前视图 | 打印当前显示区域 |

### 10.4.4 比例设置

**比例选项**：
```
比例设置
├── 适应纸张：自动缩放适应
├── 1:1：实际大小
├── 1:2：缩小一半
├── 2:1：放大一倍
└── 自定义：任意比例
```

**比例计算**：
```
打印比例 = 图纸单位 : 打印单位

例如：
1:100 表示图纸上1mm等于实际100mm
1:50  表示图纸上1mm等于实际50mm
```

### 10.4.5 打印偏移

调整图形在纸张上的位置：

```
偏移设置
├── 居中：自动居中
├── X偏移：水平偏移量
└── Y偏移：垂直偏移量
```

### 10.4.6 打印选项

```
打印选项
├── 打印线宽：使用设置的线宽
├── 打印黑白：所有颜色转为黑色
├── 打印填充：打印填充图案
└── 打印线型：使用设置的线型
```

## 10.5 打印样式

### 10.5.1 颜色模式

**彩色打印**：
- 保持原有颜色
- 适用于彩色打印机
- 用于演示或展示

**灰度打印**：
- 颜色转换为灰度
- 减少墨水使用
- 适用于普通打印

**黑白打印**：
- 所有颜色转为黑色
- 最常用的工程图打印方式
- 确保清晰度

### 10.5.2 线宽打印

**使用对象线宽**：
按照对象设置的线宽打印

**使用图层线宽**：
按照图层设置的线宽打印

**统一线宽**：
所有线条使用相同线宽

### 10.5.3 打印预设

可以保存常用的打印设置：

1. 配置好打印设置
2. 保存为预设
3. 下次直接调用

## 10.6 打印到PDF

### 10.6.1 使用PDF打印机

**Windows系统**：
1. 安装PDF打印机（如Microsoft Print to PDF）
2. 打印时选择PDF打印机
3. 选择保存位置

**Linux系统**：
1. 使用CUPS-PDF
2. 打印时选择PDF打印机

**macOS系统**：
1. 打印对话框左下角选择"PDF"
2. 选择"存储为PDF"

### 10.6.2 使用导出功能

**操作步骤**：
1. 文件 > 导出 > PDF
2. 设置导出选项
3. 选择保存位置
4. 导出

**PDF导出设置**：
```
PDF导出设置
├── 纸张大小：A4/A3/自定义
├── 方向：纵向/横向
├── 分辨率：72/150/300 DPI
├── 颜色：彩色/灰度/黑白
├── 比例：适应/1:1/自定义
└── 范围：全部/窗口
```

### 10.6.3 PDF质量设置

| 用途 | 分辨率 | 文件大小 |
|------|--------|---------|
| 屏幕预览 | 72 DPI | 小 |
| 普通打印 | 150 DPI | 中等 |
| 高质量打印 | 300 DPI | 较大 |
| 专业出版 | 600 DPI | 大 |

## 10.7 批量打印

### 10.7.1 使用命令行打印

```bash
# 转换单个文件
librecad dxf2pdf input.dxf output.pdf

# 批量转换
for file in *.dxf; do
    librecad dxf2pdf "$file" "${file%.dxf}.pdf"
done
```

### 10.7.2 Windows批量打印脚本

```batch
@echo off
setlocal enabledelayedexpansion

for %%f in (*.dxf) do (
    set "name=%%~nf"
    librecad dxf2pdf "%%f" "!name!.pdf"
    echo Converted: %%f
)

pause
```

### 10.7.3 打印队列管理

对于大量文件打印：
1. 先全部转换为PDF
2. 使用PDF阅读器的批量打印
3. 或使用系统打印队列

## 10.8 打印问题排除

### 10.8.1 常见问题

**问题1：打印结果空白**

可能原因：
- 打印范围设置错误
- 图形在打印区域外
- 比例设置过小

解决方案：
- 检查打印范围设置
- 使用"适应纸张"选项
- 在打印预览中确认

**问题2：打印不完整**

可能原因：
- 部分内容超出纸张
- 分辨率设置不足
- 内存不足

解决方案：
- 调整比例使内容完全在纸张内
- 提高分辨率设置
- 关闭其他程序释放内存

**问题3：线条太细或看不见**

可能原因：
- 线宽设置太小
- 打印分辨率太低
- 颜色与纸张接近

解决方案：
- 增加线宽设置
- 使用黑白打印模式
- 检查颜色设置

**问题4：文字显示问题**

可能原因：
- 字体不可用
- 字体大小太小
- 字符编码问题

解决方案：
- 安装所需字体
- 增大文字高度
- 使用系统通用字体

### 10.8.2 打印优化

**提高打印质量**：
- 使用300 DPI或更高分辨率
- 选择适当的线宽
- 检查所有图层的打印设置

**减小文件大小**：
- 使用较低分辨率（用于预览）
- 删除不需要的图层
- 简化复杂图形

### 10.8.3 打印机设置检查

**Windows**：
1. 控制面板 > 设备和打印机
2. 右键打印机 > 打印机属性
3. 检查打印质量设置

**Linux**：
1. 系统设置 > 打印机
2. 选择打印机配置
3. 检查选项设置

**使用模板**：
文件 > 从模板新建 > 选择模板

## 10.10 出图规范

### 10.10.1 工程制图标准

**国家标准**：
- GB/T 14689-2008 技术制图 图纸幅面和格式
- GB/T 14690-1993 技术制图 比例
- GB/T 14691-1993 技术制图 字体
- GB/T 4458.4-2003 机械制图 图样画法

**线宽规定**：
| 线型 | 线宽 | 用途 |
|------|------|------|
| 粗实线 | 0.5-0.7 | 可见轮廓线 |
| 细实线 | 0.25-0.35 | 尺寸线、引出线 |
| 虚线 | 0.25-0.35 | 不可见轮廓线 |
| 点划线 | 0.25-0.35 | 中心线、对称线 |
| 双点划线 | 0.25-0.35 | 相邻零件轮廓 |

### 10.10.2 打印检查清单

**打印前检查**：
- [ ] 图层设置正确
- [ ] 线宽设置适当
- [ ] 尺寸标注完整
- [ ] 文字清晰可读
- [ ] 图框和标题栏完整
- [ ] 比例设置正确
- [ ] 打印范围正确

### 10.10.3 文档归档

**归档要求**：
