# 第六章 图层与属性管理

## 6.1 图层基础

### 6.1.1 图层的概念

图层是CAD绘图中最重要的组织工具之一。可以将图层想象成透明的绘图纸，每一张纸上绘制不同类别的内容，然后叠加在一起形成完整的图形。

**图层的作用**：
- 组织和分类图形对象
- 控制对象的显示和隐藏
- 批量控制对象的颜色、线型、线宽
- 简化复杂图形的管理
- 控制对象的打印输出

### 6.1.2 图层属性

每个图层具有以下属性：

| 属性 | 说明 | 默认值 |
|------|------|--------|
| 名称 | 图层的唯一标识 | "0" |
| 可见性 | 控制图层是否显示 | 可见 |
| 锁定状态 | 控制图层是否可编辑 | 未锁定 |
| 颜色 | 图层默认颜色 | 白色 |
| 线型 | 图层默认线型 | 实线 |
| 线宽 | 图层默认线宽 | 默认 |
| 打印 | 控制图层是否打印 | 可打印 |

### 6.1.3 图层0

图层0是LibreCAD的默认图层，具有特殊性质：
- 不能删除
- 不能重命名
- 始终存在于每个图形中
- 新建图形时自动创建

## 6.2 图层管理面板

### 6.2.1 面板界面

图层管理面板通常位于界面右侧：

```
┌─────────────────────────────────────┐
│ 图层                        [+][-][≡]│
├─────────────────────────────────────┤
│ ☑ 🔓 ⚫ 0         ─────  默认      │
│ ☑ 🔓 🔴 轮廓线    ═════  0.35      │
│ ☑ 🔓 🔵 中心线    ─ ─ ─  0.18      │
│ ☐ 🔓 🟢 辅助线    ·····  0.13      │
│ ☑ 🔒 🟡 尺寸      ─────  0.25      │
└─────────────────────────────────────┘
```

**列说明**：
1. 复选框：可见性开关
2. 锁图标：锁定状态
3. 颜色块：图层颜色
4. 图层名：图层名称
5. 线型示意：图层线型
6. 线宽值：图层线宽

### 6.2.2 面板操作

**工具栏按钮**：
- [+] 添加新图层
- [-] 删除选中图层
- [≡] 图层选项菜单

**右键菜单**：
- 添加图层
- 删除图层
- 重命名图层
- 设为当前图层
- 编辑图层属性
- 全部显示/隐藏
- 全部锁定/解锁

## 6.3 图层操作

### 6.3.1 创建图层

**方法一：使用面板**
1. 点击图层面板的"+"按钮
2. 输入图层名称
3. 设置图层属性
4. 点击确定

**方法二：使用命令**
```
命令: layer
?/创建(C)/删除(D)/冻结(F)/解冻(T)/设置(S)/锁定(L)/解锁(U): C↵
新图层名称: 轮廓线↵
```

### 6.3.2 删除图层

**操作步骤**：
1. 在图层面板选择要删除的图层
2. 点击"-"按钮或右键选择"删除"

**注意**：
- 不能删除图层0
- 不能删除当前图层
- 不能删除包含对象的图层（需先移动或删除对象）

### 6.3.3 重命名图层

**操作步骤**：
1. 双击图层名称
2. 输入新名称
3. 按Enter确认

或：
1. 右键点击图层
2. 选择"重命名"
3. 输入新名称

### 6.3.4 设置当前图层

**方法一**：双击要设置的图层
**方法二**：右键点击图层，选择"设为当前"
**方法三**：使用命令
```
命令: layer
?/创建(C)/删除(D)/冻结(F)/解冻(T)/设置(S)/锁定(L)/解锁(U): S↵
要设为当前的图层名: 轮廓线↵
```

新绘制的对象将放置在当前图层上。

### 6.3.5 切换可见性

**单个图层**：
- 点击图层前的复选框
- 勾选=可见，取消勾选=隐藏

**批量操作**：
- 右键菜单 > 全部显示
- 右键菜单 > 全部隐藏
- 右键菜单 > 反选显示

### 6.3.6 锁定图层

锁定的图层上的对象可见但不能编辑。

**锁定/解锁**：
- 点击图层的锁图标
- 右键菜单 > 锁定/解锁

**用途**：
- 保护已完成的图形不被误改
- 参考图层内容而不影响它

## 6.4 图层属性设置

### 6.4.1 修改图层颜色

**操作步骤**：
1. 双击图层的颜色块
2. 在颜色选择器中选择颜色
3. 点击确定

**颜色选择方式**：
- 标准颜色：预定义的常用颜色
- 自定义颜色：RGB或HSL指定
- 索引颜色：AutoCAD兼容的256色

### 6.4.2 修改图层线型

**操作步骤**：
1. 双击图层的线型示意
2. 在线型列表中选择
3. 点击确定

**常用线型**：
| 线型名称 | 用途 | 图示 |
|---------|------|------|
| Continuous | 实线/轮廓线 | ───── |
| Dashed | 虚线/隐藏线 | - - - - |
| Dot | 点线 | · · · · |
| DashDot | 点划线/中心线 | ─ · ─ · |
| DashDotDot | 双点划线 | ─ · · ─ |
| Divide | 分隔线 | ─ · · ─ |
| Border | 边界线 | ─ ─ · |

### 6.4.3 修改图层线宽

**操作步骤**：
1. 双击图层的线宽值
2. 选择预定义线宽或输入自定义值
3. 点击确定

**标准线宽（mm）**：
- 0.00 - 默认
- 0.13 - 细线
- 0.18 - 细线
- 0.25 - 中等
- 0.35 - 粗线
- 0.50 - 粗线
- 0.70 - 特粗
- 1.00 - 特粗

### 6.4.4 设置打印属性

控制图层是否在打印输出时显示：

**操作步骤**：
1. 右键点击图层
2. 选择"设置打印"
3. 勾选或取消"可打印"

**用途**：
- 辅助线图层不打印
- 参考图层不打印
- 构造线图层不打印

## 6.5 图层组织策略

### 6.5.1 按功能分层

适用于通用工程制图：

```
图层结构：
├── 0          # 默认图层
├── 轮廓       # 主要轮廓线
├── 中心线     # 对称线、中心线
├── 隐藏线     # 不可见轮廓
├── 虚线       # 虚线表示
├── 尺寸       # 尺寸标注
├── 文字       # 文字注释
├── 填充       # 剖面填充
├── 辅助       # 辅助线、构造线
└── 图框       # 图框和标题栏
```

### 6.5.2 按专业分层

适用于建筑设计：

```
图层结构：
├── A-Wall     # 墙体
├── A-Door     # 门
├── A-Window   # 窗户
├── A-Furn     # 家具
├── A-Text     # 建筑文字
├── S-Column   # 结构柱
├── S-Beam     # 梁
├── E-Outlet   # 电气插座
├── E-Light    # 灯具
├── E-Wire     # 电线
├── P-Pipe     # 给排水管道
└── P-Fixture  # 洁具
```

### 6.5.3 按状态分层

适用于项目管理：

```
图层结构：
├── EXIST      # 现有状况
├── NEW        # 新建内容
├── DEMO       # 待拆除内容
├── REVISION   # 修改内容
└── TEMP       # 临时内容
```

### 6.5.4 图层命名规范

**建议的命名规则**：
- 使用有意义的名称
- 采用一致的命名约定
- 避免使用特殊字符
- 可使用前缀分类

**命名示例**：
```
好的命名：
✓ 轮廓线
✓ A-Wall-Ext  (建筑-墙体-外墙)
✓ E_LIGHT_01  (电气_灯具_一层)

不好的命名：
✗ Layer1
✗ 新建图层
✗ temp123
```

## 6.6 对象属性管理

### 6.6.1 ByLayer属性

对象可以使用"ByLayer"属性，这意味着对象继承其所在图层的属性：

**ByLayer颜色**：对象使用图层颜色
**ByLayer线型**：对象使用图层线型
**ByLayer线宽**：对象使用图层线宽

**优点**：
- 便于批量修改：只需修改图层属性
- 保持一致性：同一图层对象外观一致
- 简化管理：减少单独设置

### 6.6.2 修改对象属性

**使用属性面板**：
1. 选择对象
2. 在属性面板中修改属性
3. 更改立即生效

**使用命令**：
```
命令: properties
选择对象: (选择对象)
```

### 6.6.3 属性匹配

将一个对象的属性应用到其他对象：

**命令**：`matchprop` 或 `ma`

**操作步骤**：
1. 启动属性匹配命令
2. 选择源对象（作为模板）
3. 选择目标对象
4. 目标对象属性被更改

**可匹配的属性**：
- 图层
- 颜色
- 线型
- 线宽

### 6.6.4 更改对象图层

**方法一：使用属性面板**
1. 选择对象
2. 在属性面板的图层下拉框中选择新图层

**方法二：使用图层面板**
1. 选择对象
2. 在图层面板中点击目标图层

**方法三：使用命令**
```
命令: chprop
选择对象: (选择对象)
输入要更改的属性 [颜色(C)/高程(E)/图层(LA)/线型(LT)/线型比例(S)/线宽(LW)/厚度(T)]: LA↵
输入新图层名 <当前>: 轮廓线↵
```

## 6.7 线型管理

### 6.7.1 线型概念

线型定义了线条的显示样式，由重复的图案单元组成。

**线型文件**：
- LibreCAD使用.lin格式的线型文件
- 位于安装目录的resources/patterns目录

### 6.7.2 加载线型

**操作步骤**：
1. 格式 > 线型...
2. 点击"加载"按钮
3. 选择线型文件
4. 选择要加载的线型
5. 点击确定

### 6.7.3 线型比例

线型比例影响线型图案的大小：

**全局线型比例**：
- 应用于整个图形
- 编辑 > 当前图形首选项 > 显示

**对象线型比例**：
- 应用于单个对象
- 在属性面板中设置

**比例计算**：
```
显示比例 = 全局比例 × 对象比例
```

### 6.7.4 自定义线型

线型定义格式：
```
*线型名称,描述
A,图案定义
```

**图案元素**：
- 正数：线段长度
- 负数：间隙长度
- 0：点

**示例**：
```
*DASHED,虚线 __ __ __
A,12.7,-6.35

*DASHDOT,点划线 __.__.__
A,12.7,-6.35,0,-6.35
```

## 6.8 颜色管理

### 6.8.1 颜色系统

LibreCAD支持多种颜色系统：

**索引颜色**：
- 256色索引（ACI - AutoCAD Color Index）
- 与AutoCAD兼容
- 索引1-7为标准颜色

**真彩色**：
- RGB值指定
- 1670万种颜色
- 格式：R,G,B

### 6.8.2 标准颜色

| 索引 | 颜色名 | RGB值 |
|------|--------|-------|
| 1 | 红色 | 255,0,0 |
| 2 | 黄色 | 255,255,0 |
| 3 | 绿色 | 0,255,0 |
| 4 | 青色 | 0,255,255 |
| 5 | 蓝色 | 0,0,255 |
| 6 | 品红 | 255,0,255 |
| 7 | 白色/黑色 | 255,255,255 |

### 6.8.3 选择颜色

**颜色选择器**：
1. 点击颜色按钮
2. 选择颜色方式：
   - 标准颜色
   - 索引颜色
   - 自定义颜色
3. 确定选择

## 6.9 线宽管理

### 6.9.1 线宽设置

**显示线宽**：
- 视图 > 显示线宽
- 或状态栏线宽按钮

**线宽单位**：
- 毫米（mm）
- 打印时按实际宽度输出

### 6.9.2 标准线宽

CAD标准推荐的线宽：

| 线宽(mm) | 用途 |
|----------|------|
| 0.13 | 辅助线、参考线 |
| 0.18 | 尺寸线、引出线 |
| 0.25 | 可见轮廓、一般线条 |
| 0.35 | 粗实线、主要轮廓 |
| 0.50 | 剖切线、特粗轮廓 |
| 0.70 | 图框边线 |
| 1.00 | 特殊强调 |

### 6.9.3 线宽比例

**打印线宽**：
- 打印时使用实际线宽
- 屏幕显示可能与打印不同

**线宽显示设置**：
```
编辑 > 应用程序首选项 > 外观
├── 显示线宽：开/关
└── 线宽显示比例：调整屏幕显示
```

## 6.10 图层过滤与搜索

### 6.10.1 图层过滤

当图形包含大量图层时，可使用过滤功能：

**按名称过滤**：
1. 在图层面板的搜索框中输入关键字
2. 只显示匹配的图层

**按状态过滤**：
- 只显示可见图层
- 只显示锁定图层
- 只显示包含对象的图层

### 6.10.2 图层状态管理

保存和恢复图层状态设置：

**保存状态**：
记录当前所有图层的可见性、锁定、颜色等设置

**恢复状态**：
一键恢复到之前保存的图层配置

**用途**：
- 不同工作阶段快速切换
- 不同打印输出配置
- 项目检查点

## 6.11 本章小结

本章详细介绍了LibreCAD的图层与属性管理：

1. **图层基础**：图层概念、属性、图层0
2. **图层管理**：创建、删除、重命名、可见性、锁定
3. **图层属性**：颜色、线型、线宽、打印设置
4. **组织策略**：按功能、按专业、按状态分层
5. **对象属性**：ByLayer、属性修改、属性匹配
6. **线型管理**：加载线型、线型比例、自定义线型
7. **颜色管理**：索引颜色、真彩色、颜色选择
8. **线宽管理**：标准线宽、线宽显示、打印线宽

良好的图层管理是高效CAD工作的基础。合理组织图层可以大大提高绘图效率和图形质量。
