# Xbim 教程目录

本教程结合 [xBimTeam/XbimEssentials](https://github.com/xBimTeam/XbimEssentials) 与 [xBimTeam/XbimGeometry](https://github.com/xBimTeam/XbimGeometry) 两大核心仓库的源码结构、模块划分与官方文档，面向中文读者系统介绍 Xbim 工具集（xBIM Toolkit）的学习、使用与二次开发。教程围绕 IFC（Industry Foundation Classes）数据模型、EXPRESS 元模型、几何引擎（基于 Open CASCADE）、可视化（WindowsUI / WebUI）以及 COBie、IDS、BCF 等 Open BIM 生态展开，并补充工程实战与综合案例。
