# 第07章：高级建模技巧

## 7.1 参数化设计

### 7.1.1 参数化设计概述

参数化设计是CadQuery的核心优势之一。通过将尺寸和几何关系定义为参数，可以轻松生成不同规格的模型。

**参数化设计的优点：**
- 快速生成变体模型
- 易于修改和维护
- 支持批量生产
- 便于设计优化

### 7.1.2 基本参数化

```python
import cadquery as cq

# 定义参数
length = 80.0
width = 60.0
height = 20.0
hole_diameter = 15.0
fillet_radius = 3.0
wall_thickness = 3.0

# 使用参数创建模型
result = (
    cq.Workplane("XY")
    .box(length, width, height)
    .faces(">Z")
    .shell(-wall_thickness)
    .faces(">Z")
    .workplane()
    .hole(hole_diameter)
    .edges("|Z")
    .fillet(fillet_radius)
)

cq.exporters.export(result, "parametric_box.step")
```

### 7.1.3 参数化函数

```python
import cadquery as cq

def make_enclosure(length, width, height, wall=2.0, corner_radius=3.0):
    """
    创建参数化外壳
    
    Args:
        length: 长度
        width: 宽度
        height: 高度
        wall: 壁厚
        corner_radius: 圆角半径
    """
    result = (
        cq.Workplane("XY")
        .box(length, width, height)
        .edges("|Z")
        .fillet(corner_radius)
        .faces(">Z")
        .shell(-wall)
    )
    return result

# 生成不同尺寸的外壳
small = make_enclosure(50, 30, 20)
medium = make_enclosure(80, 50, 30, wall=3.0)
large = make_enclosure(120, 80, 40, wall=4.0, corner_radius=5.0)

cq.exporters.export(small, "enclosure_small.step")
cq.exporters.export(medium, "enclosure_medium.step")
cq.exporters.export(large, "enclosure_large.step")
```

### 7.1.5 配置驱动设计

import cadquery as cq

# 配置字典
configs = {
    "M6": {
        "thread_diameter": 6,
        "head_diameter": 10,
        "head_height": 4,
        "length": 20
    },
    "M8": {
        "thread_diameter": 8,
        "head_diameter": 13,
        "head_height": 5,
        "length": 25
    },
    "M10": {
        "thread_diameter": 10,
        "head_diameter": 16,
        "head_height": 6.4,
        "length": 30
    }
}

def make_hex_bolt(config):
    """根据配置创建六角螺栓"""
    td = config["thread_diameter"]
    hd = config["head_diameter"]
    hh = config["head_height"]
    length = config["length"]
    
    return (
        cq.Workplane("XY")
        .polygon(6, hd)
        .extrude(hh)
        .faces("<Z")
        .workplane()
        .circle(td / 2)
        .extrude(-length)
        .edges(">Z")
        .chamfer(hh * 0.1)
    )

# 生成不同规格的螺栓
for name, config in configs.items():
    bolt = make_hex_bolt(config)
    cq.exporters.export(bolt, f"bolt_{name}.step")

### 7.2.2 旋转曲面

```python
import cadquery as cq
import math

def vase_profile(height, base_radius, neck_radius, belly_radius):
    """创建花瓶轮廓"""
    points = []
    segments = 50
    
    for i in range(segments + 1):
        t = i / segments
        h = t * height
        
        # 使用正弦函数创建曲线轮廓
        if t < 0.3:
            r = base_radius + (belly_radius - base_radius) * math.sin(t / 0.3 * math.pi / 2)
        elif t < 0.7:
            r = belly_radius * (1 + 0.1 * math.sin((t - 0.3) / 0.4 * 2 * math.pi))
        else:
            r = belly_radius + (neck_radius - belly_radius) * math.sin((t - 0.7) / 0.3 * math.pi / 2)
        
        points.append((r, h))
    
    return points

# 创建花瓶
profile = vase_profile(100, 15, 10, 30)
vase = (
    cq.Workplane("XZ")
    .moveTo(0, 0)
    .spline(profile)
    .lineTo(0, 100)
    .close()
    .revolve(360, (0, 0, 0), (0, 1, 0))
    .shell(-2)  # 创建空心
)

cq.exporters.export(vase, "vase.step")
```

### 7.2.3 扫略曲面

```python
import cadquery as cq
import math

# 创建螺旋路径
def helix_path(radius, pitch, turns):
    points = []
    segments = int(turns * 36)
    
    for i in range(segments + 1):
        angle = 2 * math.pi * i / 36
        x = radius * math.cos(angle)
        y = radius * math.sin(angle)
        z = pitch * i / 36
        points.append((x, y, z))
    
    return points

# 使用内置的螺旋线
helix = cq.Wire.makeHelix(pitch=10, height=80, radius=25)

# 创建截面
# 异形截面
profile = (
    cq.Workplane("XY")
    .ellipse(5, 3)
)

# 沿螺旋线扫略
result = profile.sweep(helix, isFrenet=True)

cq.exporters.export(result, "helix_sweep.step")
```

## 7.9 自由函数API形状操作

第1章介绍了自由函数（Free Function）API 的基本概念和 `cq.cut`、`cq.fuse`、`cq.intersect` 等基础操作。本节进一步介绍 v2.6+ 引入的形状级操作方法，以及更丰富的自由函数应用场景。

### 7.9.1 自由函数布尔运算

与 Workplane 方法链不同，自由函数直接操作 Shape 对象，适合在非 Workplane 上下文中组合已有实体：

```python
import cadquery as cq

# 创建两个独立形状
box = cq.Workplane("XY").box(30, 30, 20).val()
cyl = cq.Workplane("XY").cylinder(12, 25).val()

# 自由函数版布尔运算
union = cq.fuse(box, cyl)       # 并集
diff = cq.cut(box, cyl)          # 差集（box减去cyl）
inter = cq.intersect(box, cyl)   # 交集

# 将结果包装回 Workplane 以便导出
cq.exporters.export(cq.Workplane("XY").newObject([union]), "ff_union.step")
cq.exporters.export(cq.Workplane("XY").newObject([diff]), "ff_diff.step")
```

| 方法链 | 自由函数 | 说明 |
|--------|----------|------|
| `wp1.union(wp2)` | `cq.fuse(shape1, shape2)` | 布尔并集 |
| `wp1.cut(wp2)` | `cq.cut(shape1, shape2)` | 布尔差集 |
| `wp1.intersect(wp2)` | `cq.intersect(shape1, shape2)` | 布尔交集 |

### 7.9.2 形状级移除：Shape.remove()

v2.6+ 引入的 `Shape.remove()` 方法直接在形状层面执行切除操作，无需 Workplane 上下文：

```python
import cadquery as cq

# 创建底板
plate = cq.Workplane("XY").box(50, 40, 10).val()

# 在形状级别切除孔洞
hole = cq.Workplane("XY").workplane(offset=15).cylinder(4, 15).val()
result = plate.remove(hole)

cq.exporters.export(cq.Workplane("XY").newObject([result]), "shape_remove.step")
```

### 7.9.3 面沿法向拉伸：Face.extend()

`Face.extend(amount)` 将单个面沿其法线方向拉伸指定距离，返回拉伸后的实体。这一操作在需要对面进行局部增厚时非常有用：

```python
import cadquery as cq

# 创建基础块并提取顶面
block = cq.Workplane("XY").box(30, 30, 10)
top_face = block.faces(">Z").val()

# 将顶面沿法向（Z轴正方向）拉伸5mm
extended = top_face.extend(5)

# 与原块合并
result = block.union(cq.Workplane("XY").newObject([extended]))

cq.exporters.export(result, "face_extend.step")
```

### 7.9.4 实体内部挖腔：Solid.addCavity()

`Solid.addCavity(cavity)` 从一个实体内挖去另一个实体，形成空腔结构：

```python
import cadquery as cq

# 创建外壳实体
outer = cq.Workplane("XY").box(40, 40, 30).val()

# 创建内部空腔形状
inner = cq.Workplane("XY").box(30, 30, 25).val()

# 挖腔
hollow = outer.addCavity(inner)

cq.exporters.export(cq.Workplane("XY").newObject([hollow]), "cavity.step")
```

### 7.9.5 缝合操作：cq.stitch()

`cq.stitch()` 将一组共边的面缝合为壳体（Shell）或实体（Solid）。适用于从零散面片构建模型或修复非流形几何：

```python
import cadquery as cq

# 创建盒子的六个面
box = cq.Workplane("XY").box(30, 30, 20)
faces = box.faces().vals()

# 将所有面重新缝合为壳
shell = cq.stitch(faces)

# 从壳生成实体
solid = cq.Workplane("XY").newObject([cq.Solid.makeSolid(shell)])

cq.exporters.export(solid, "stitched.step")
```

## 7.10 选择器与形状集合操作

v2.5+ 版本增强了选择器返回的形状集合，使其支持类似 Python 列表的函数式遍历操作。这些操作让筛选和批量处理形状变得简洁高效。

### 7.10.1 按索引访问：`[]`

形状集合支持下标索引访问，可以直接获取第N个形状：

```python
import cadquery as cq

model = cq.Workplane("XY").box(50, 30, 20)
faces = model.faces().vals()

# 直接访问第0个面
first_face = faces[0]
print(f"第0个面面积: {first_face.Area():.2f} mm²")

# 访问前三个面
first_three = faces[:3]
print(f"前三个面总面积: {sum(f.Area() for f in first_three):.2f} mm²")
```

### 7.10.2 按条件筛选：filter()

使用列表推导式按自定义条件筛选形状，返回满足条件的新集合：

```python
import cadquery as cq

model = cq.Workplane("XY").box(50, 30, 20)

# 筛选面积大于500的面
large_faces = [f for f in model.faces().vals() if f.Area() > 500]

print("大面积面:")
for f in large_faces:
    print(f"  面积: {f.Area():.2f} mm²")

# 筛选长度大于30的边
long_edges = [e for e in model.edges().vals() if e.Length() > 30]
print(f"长度>30mm的边: {len(long_edges)} 条")
```

### 7.10.3 映射操作：map()

对形状集合中的每个元素应用操作，返回结果集合：

```python
import cadquery as cq

model = cq.Workplane("XY").box(50, 30, 20)

# 获取所有面的中心点坐标
centers = [f.Center() for f in model.faces().vals()]

for i, c in enumerate(centers):
    print(f"面{i} 中心: ({c.x:.1f}, {c.y:.1f}, {c.z:.1f})")
```

### 7.10.4 排序操作：sort()

按指定属性对形状集合排序：

```python
import cadquery as cq

model = cq.Workplane("XY").box(50, 30, 20)

# 按面积从小到大排序
faces = model.faces().vals()
sorted_faces = sorted(faces, key=lambda f: f.Area())

print("面按面积升序:")
for f in sorted_faces:
    print(f"  {f.Area():.2f} mm²")
```

### 7.10.5 批量操作：apply()

对集合中的每个形状应用选择器操作，实现批量特征提取：

```python
import cadquery as cq

model = (
    cq.Workplane("XY")
    .box(50, 30, 20)
    .faces(">Z")
    .workplane()
    .rect(30, 15)
    .cutBlind(-10)
)

# 获取每个面中的所有边
all_faces = model.faces().vals()
for i, face in enumerate(all_faces):
    edges = face.Edges()
    print(f"面{i} 包含 {len(edges)} 条边")
```

### 7.10.6 方法调用：invoke()

在形状集合的每个元素上直接调用方法：

```python
import cadquery as cq

model = cq.Workplane("XY").box(50, 30, 20)

# 获取所有面的类型信息
for face in model.faces().vals():
    surf_type = type(face).__name__
    print(f"面类型: {surf_type}, 面积: {face.Area():.2f} mm²")
```
