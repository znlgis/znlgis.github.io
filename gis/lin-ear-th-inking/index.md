# Lin.ear th.inking 博客翻译

这是 [Lin.ear th.inking](https://lin-ear-th-inking.blogspot.com/) 博客的中文翻译系列。该博客由 Martin Davis 撰写，他是 JTS Topology Suite（Java 拓扑套件）的原始创建者和主要维护者，也是计算几何领域的权威专家。

## 关于原作者

**Martin Davis** 是 JTS（Java Topology Suite）的创始人，该库是许多重要空间数据处理库的基础，包括：
- **GEOS** - C++ 版本的 JTS
- **Shapely** - Python 空间分析库
- **NetTopologySuite** - .NET 版本的 JTS
- **PostGIS** - PostgreSQL 空间扩展

他的博客 "Lin.ear th.inking" 深入探讨了计算几何、空间算法和 JTS/GEOS 的最新发展。
