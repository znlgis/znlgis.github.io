# 三维 GIS 技术与业务全景教程

> **所属合集**：[GIS 业务全景（BPC）](https://znlgis.github.io/gis/bpc/) — 按业务领域组织的 GIS 解读教程合集。

三维 GIS 已经完成身份转变：从“可视化附属品”变成“时空数据基础设施”。判断依据不是厂商宣传，而是标准格局——3D Tiles 把摄影测量、BIM、点云、矢量与时态数据纳入同一个空间分块体系；引擎从 WebGL 单极走向 WebGL/WebGPU 双栈与“哪一层用谁”的组合；3D 高斯泼溅（3DGS）从论文走进工程管线。本教程由《三维 + GIS 技术与业务全景分析报告》（v1.0）改写，按“整体图景—技术层—业务层—合规—前景—行动”的顺序，把标准与格式、引擎与调度、重建路线、行业场景、四条合规硬线与 2026—2030 年的技术主线串成一条可以从头读到尾的线。

> **说明**：本教程正文保持原报告的论述、依据与表格口径，标准文档号、产品版本、政策文号与资料截止日期均按原文保留；各章新增的导读、学习目标、本章小结与思考练习为教程化改写，方便自学、培训与检索。原报告正文中的“本报告”自称予以保留，阅读时按“本教程”理解即可。凡涉及具体项目，仍应以现行有效的标准文本、项目所在地的实施细则与合同约定为准。
