# 附录B 术语与缩略语

> **本篇导读**
>
> 房产测绘里最难沟通的往往不是技术，而是词：同一个“面积”在不同环节指的不是一件事，“共有建筑面积分摊”在口语里叫“公摊”，“户”在成果里是权属单元而不是住户。本附录把正文反复使用、彼此又容易混的术语收成一张表，逐条给出正文采用的含义。它是一份词表，不是名词解释汇编：查到词以后，回到对应章节看它怎么用，比背定义有用。

## 使用说明

- **用途**：统一说法。写成果说明、做培训材料、对外沟通时先对一遍本表，避免同一概念在不同文档里换名字。
- **口径**：词条含义按本教程口径写，服务于全书用法一致，不是规范的权威定义；需要引用定义时，回到标准或规章原文。
- **边界**：表题已限定为“本报告涉及的主要术语”，只收主要词条，不追求收全；未收录的词按其正文语境理解。
- **缩略语**：表 B-1 按术语列出；缩写、标准号与编号另见表 B-2。本教程正文统一使用表中写法，不混用同义缩写。

**表B-1 本报告涉及的主要术语**

| 术语 | 含义 |
| --- | --- |
| 房产测绘 | 以房屋及其用地为对象，测量其坐落、界址、形状、面积、结构、层数等自然状况，并据以核定权属单元的专业活动 |
| 幢 | 独立成栋的房屋建筑单元，是房产测绘与不动产登记的基本空间单位之一；幢界一经确定，即成为全幢面积测算与分摊的基础 |
| 层与层次 | 房屋在竖向的划分单位，按自然层编立；夹层、设备层、半地下空间的处理方式因规范与地方细则而异 |
| 户（权属单元） | 房屋中权属独立、可单独登记的最小单元；分户界址线即为户的边界，是面积测算与分摊的最小计算对象 |
| 套内建筑面积 | 由套内使用面积、套内墙体面积与套内阳台建筑面积三部分组成的面积，反映权利人独占使用的空间规模 |
| 共有建筑面积 | 整幢建筑物的建筑面积扣除各套内建筑面积之和后，剩余由相关权利人共同使用的建筑面积 |
| 分摊系数 | 共有建筑面积与参与分摊的套内建筑面积之比，用于将该部分面积按比例分配至各户；多级分摊时按层级逐级计算 |
| 功能区 | 按使用性质或服务范围划分的区域，如商业区、住宅区、办公区；功能区划分直接决定共有面积的分摊范围 |
| 预测面积与实测面积 | 预测面积依据设计图纸计算，用于预售与合同约定；实测面积依据房屋竣工后的实际状况测量，用于最终结算与登记 |
| 多测合一 | 在同一工程建设项目中，对时间相近、内容相似、出资主体相同的多个测绘事项优化整合，执行统一技术标准，实现同一标的物只测一次、同一测绘成果只提交一次的测绘服务模式 |
| 不动产单元代码 | 按统一规则设定的不动产单元唯一标识，是不动产登记与成果关联的空间索引 |
| 数字房产图 | 以数字化形式表达房屋空间位置、权属界线与属性的图件与数据库，支撑查询、统计、共享与业务协同 |
| 实景三维 | 对真实场景进行时序化、三维化表达的地理空间数据成果，为城市建设与治理提供统一的空间定位框架 |
| 可追溯性 | 成果中的每个数字与每项判断都能追溯到原始记录、规则依据与判断责任人的属性，是可复核的基础 |

上述术语在正文中保持一致用法。需要说明的是，“共有建筑面积分摊”在口语场合常被称为“公摊”，本报告统一使用前者，以强调其作为法定计算过程而非估算行为的性质。

## 使用提示

- 口语与文本分开：读者说“公摊”，你写“共有建筑面积分摊”，第一次出现时点一句对应关系，后面就不必反复解释。
- 别拿本表去争辩定义：与地方细则或受理机构表述不一致时，登记口径以受理机构的用法为准，本表只保证本教程内部一致。
- 术语要连着算法理解：“分摊系数”“功能区”“共有建筑面积”三个词互为前提，单看其中一条容易算错范围。
- 词表随正文更新，本表未收的新词以正文首次出现处的用法为准，不要自行另造同义词。
