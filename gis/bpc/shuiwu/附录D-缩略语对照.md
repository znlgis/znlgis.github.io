# 附录D 缩略语对照

本附录给出全书出现的英文缩略语与中文对照，按缩略语字母排列。同一缩写在不同行业可能有不同含义（例如 CIM 在城市规划语境指城市信息模型，在计算机集成制造语境指另一概念），本教程采用水务与城市空间治理语境下的含义。

**表D-1 缩略语对照表**

| 缩略语 | 全称 | 中文 |
| --- | --- | --- |
| GIS | Geographic Information System | 地理信息系统 |
| BIM | Building Information Modeling | 建筑信息模型 |
| CIM | City Information Modeling | 城市信息模型 |
| DMA | District Metered Area | 独立计量区 |
| SCADA | Supervisory Control and Data Acquisition | 监控与数据采集 |
| MNF | Minimum Night Flow | 夜间最小流量 |
| RS | Remote Sensing | 遥感 |
| InSAR | Interferometric Synthetic Aperture Radar | 合成孔径雷达干涉测量 |
| LiDAR | Light Detection and Ranging | 激光雷达 |
| DEM | Digital Elevation Model | 数字高程模型 |
| DOM | Digital Orthophoto Map | 数字正射影像 |
| DSM | Digital Surface Model | 数字表面模型 |
| OGC | Open Geospatial Consortium | 开放地理空间信息联盟 |
| WMS | Web Map Service | 网络地图服务 |
| WFS | Web Feature Service | 网络要素服务 |
| WMTS | Web Map Tile Service | 网络地图瓦片服务 |
| MVT | Mapbox Vector Tile | 矢量瓦片 |
| POI | Point of Interest | 兴趣点 |
| API | Application Programming Interface | 应用程序接口 |
| TCO | Total Cost of Ownership | 总拥有成本 |
