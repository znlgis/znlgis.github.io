# 附录B 主要标准规范

本附录汇总全书引用的主要标准规范，按标准号排列。使用时注意两点：一是标准存在局部修订与版本更替（如《城镇供水管网漏损控制及评定标准》CJJ 92-2016 已有局部修订），引用前应核对现行有效版本；二是不同标准对同一指标的口径可能不同，跨标准引用时须写明依据的具体条次。

**表B-1 报告中引用的主要标准**

| 标准号 | 名称 | 适用领域 |
| --- | --- | --- |
| GB 5749-2022 | 生活饮用水卫生标准 | 供水水质 |
| GB 50013-2018 | 室外给水设计标准 | 供水工程设计 |
| GB 50014-2021 | 室外排水设计标准 | 排水工程设计 |
| GB 51222-2017 | 城镇内涝防治技术规范 | 内涝防治 |
| CJJ 92-2016 | 城镇供水管网漏损控制及评定标准（含局部修订） | 漏损控制 |
| CJJ 181-2012 | 城镇排水管道检测与评估技术规程 | 排水管道检测 |
| CJJ 61-2017 | 城市地下管线探测技术规程 | 管线探测 |
| CJJ/T 8-2011 | 城市测量规范 | 城市测绘 |
| CJJ/T 315-2022 | 城市信息模型基础平台技术标准 | CIM 平台 |
| GB/T 35636-2017 | 地下管线要素分类、代码与图示表达 | 管线数据标准 |
| GB 18918-2002 | 城镇污水处理厂污染物排放标准（2026 年修改单） | 污水排放 |
