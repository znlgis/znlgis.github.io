# 附录A 术语表

术语定义采用行业通行口径，涉及具体标准条文的（如漏损率、内涝防治标准），以文中标注的标准号为准。阅读正文遇到不确定的缩写，可先查本表，再查[附录 D 缩略语对照](https://znlgis.github.io/gis/bpc/shuiwu/附录D-缩略语对照/)。

本表收录报告中出现的关键术语，按业务与技术两类排列，供非专业读者查阅。

**表A-1 关键术语解释**

| 术语 | 英文/缩写 | 含义 |
| --- | --- | --- |
| 地理信息科学 | GIS | 研究地理空间数据的采集、管理、分析与可视化的学科与技术体系 |
| 空间参考 | Spatial Reference | 定义地理坐标与高程起算方式的基准体系，包括平面基准与高程基准 |
| 2000国家大地坐标系 | CGCS2000 | 我国现行国家大地坐标系，地心坐标系，2008年起启用 |
| 拓扑关系 | Topology | 空间对象之间的连接、邻接、包含等关系，是网络分析的基础 |
| 连通性分析 | Connectivity Analysis | 依据管网拓扑判断两点之间是否存在通路及其路径 |
| 关阀分析 | Valve Isolation Analysis | 从事故点出发沿管网搜索，确定需关闭的阀门与受影响范围 |
| 独立计量区 | DMA | 通过关闭边界阀门、安装流量计形成的独立计量区域，用于漏损控制 |
| 夜间最小流量 | MNF | 凌晨时段的最小用水流量，近似反映该区域背景漏损水平 |
| 产销差率 | Non-Revenue Water Ratio | 供水量与售水量之差占供水量的比例 |
| 漏损率 | Leakage Rate | 漏损水量占供水总量的比例，按 CJJ 92-2016 评定 |
| 水力模型 | Hydraulic Model | 描述管网中压力、流量分布的数学模型，常用 EPANET 等求解 |
| 汇水区 | Catchment | 降雨径流汇入某一排水系统或河道的区域 |
| 雨污混接 | Illicit Connection | 雨水管与污水管错误连通的现象，是排水系统的主要缺陷之一 |
| 内涝 | Urban Waterlogging | 因排水能力不足或外水顶托导致的地面积水现象 |
| 数字孪生 | Digital Twin | 物理实体在数字空间中的动态映射，支持仿真与推演 |
| 数据底板 | Data Baseboard | 数字孪生体系中的基础数据集，含地形、影像、模型、监测等 |
| 实景三维 | 3D Real Scene | 以倾斜摄影、激光点云等技术构建的实景三维模型 |
| 城市信息模型 | CIM | 融合 BIM、GIS 与物联网的城市三维空间信息模型 |
| 建筑信息模型 | BIM | 建筑工程的三维数字化表达，含几何与属性信息 |
| 遥感 | RS | 通过卫星或航空平台获取地表信息的技术 |
| 合成孔径雷达干涉 | InSAR | 利用雷达相位差测量地表微小形变的技术 |
| 激光雷达 | LiDAR | 通过激光测距获取高精度三维点云的技术 |
| 数字高程模型 | DEM | 表达地表高程的栅格数据 |
| 正射影像 | DOM | 经几何校正的航空或卫星影像 |
| 兴趣点 | POI | 具有地理位置的设施或服务点，用于地址匹配与空间分析 |
| 空间插值 | Spatial Interpolation | 由离散采样点估计连续表面的方法 |
| 热点分析 | Hotspot Analysis | 识别空间上统计显著的高值或低值聚集区域 |
| 元数据 | Metadata | 描述数据的数据，包括来源、精度、时相、责任人等 |
| 主数据 | Master Data | 跨系统共享的核心实体数据，如管网、客户、组织 |
| 数据治理 | Data Governance | 围绕数据质量、标准、安全与责任的制度与技术体系 |
| 开放地理空间信息联盟 | OGC | 制定地理空间互操作标准的国际组织 |
| 三维瓦片 | 3D Tiles | 大规模三维模型流式传输的开放标准 |
| 低功耗广域网 | NB-IoT | 面向物联网的低功耗广域通信技术，常用于智能水表 |
| 监控与数据采集 | SCADA | 对厂站设备进行远程监视与控制的系统 |
| 智能体 | Agent | 能感知环境并自主采取行动以实现目标的人工智能程序 |
