# 附录A 术语表

> **本篇导读**
>
> 本篇是全教程的统一术语口径。应急管理 GIS 的讨论里，“承灾体”“危险性”“暴露度”“脆弱性”这四个词经常被混用，而它们对应完全不同的数据与算法；“一张图”“数字孪生”“实景三维”这类词在不同部门的含义也不一致。本篇给出 30 条术语的定义，凡是正文中出现的核心概念，都能在这里找到一句可以拿去对齐口径的话。建议的用法：读正文前扫一遍，遇到定义与你所在单位的既有用法不一致时，以本篇为准并记录下来——口径不一致往往不是理解问题，而是协同问题，早发现比晚发现便宜。

## 使用说明

- **以本教程采用的定义为界**：部分术语有多个学派或行业定义，本篇给出的是本教程采用的那一种，用于内部一致，不主张替代标准文本；表中释义保留原报告的表述。
- **术语与附录 D 的分工**：本篇解释“是什么”，[附录 D 缩略语对照](https://znlgis.github.io/gis/bpc/yingji/附录D-缩略语对照/)只给“怎么缩写”。两者配合使用。
- **遇到分歧先记下来**：与主管部门或既有系统口径不一致时，不要自行统一，先记录差异与出处，作为后续对齐的输入。

**表A-1  本报告主要术语**

| 术语 | 英文/缩写 | 释义 |
| --- | --- | --- |
| 地理信息科学 | Geographic Information Science, GIS | 研究地理空间数据的获取、存储、管理、分析、可视化与应用的学科，本报告泛指以空间数据为核心的技术与能力体系 |
| 地理信息系统 | Geographic Information System, GIS | 支持空间数据采集、管理、分析与表达的技术系统 |
| 应急管理 | Emergency Management | 为预防和减少突发事件发生、控制与减轻危害、应对与处置、恢复与重建所开展的活动 |
| 突发事件 | Emergency | 突然发生，造成或者可能造成严重社会危害，需要采取应急处置措施予以应对的自然灾害、事故灾难、公共卫生事件和社会安全事件 |
| 一张图 | — | 汇聚基础地理、专题要素、实时数据与应用能力的统一空间界面，本报告强调其本质是统一的数据与规则而非单一界面 |
| 承灾体 | Hazard-bearing Body | 可能受到灾害影响的人口、房屋建筑、基础设施、资源与环境要素 |
| 致灾因子 | Hazard | 可能引发灾害的自然或人为因素，如降雨、地震动、火源 |
| 危险性 | Hazard | 致灾因子在特定时空范围内造成破坏的可能性与强度 |
| 暴露度 | Exposure | 承灾体处于致灾因子影响范围内的程度 |
| 脆弱性 | Vulnerability | 承灾体在给定致灾强度下受损的可能程度 |
| 减灾能力 | Mitigation Capacity | 区域在灾害发生前后减轻损失的能力 |
| 风险区划 | Risk Zoning | 依据风险等级在空间上划分区域并表达于图件 |
| 数字孪生 | Digital Twin | 对物理实体或过程建立的可计算、可同步、可推演的虚拟映射 |
| 实景三维 | 3D Real Scene | 对地表及地上地下空间要素的三维化、实体化、时序化表达 |
| 应急测绘 | Emergency Surveying and Mapping | 突发事件应对中快速获取、处理与提供测绘地理信息成果的活动 |
| 应急标绘 | Emergency Plotting | 在应急指挥地图上按规范标注事件、力量、资源与处置要素 |
| 避难场所 | Emergency Shelter | 灾害发生时供人员紧急疏散、临时安置的场所 |
| 叫应 | Call-and-Respond | 预警发布后对责任人进行点对点通知并要求确认反馈的机制 |
| 三断 | — | 断路、断网、断电的极端条件 |
| 空间可达性 | Accessibility | 从某一位置到达目标位置的时间、距离或成本度量 |
| 淹没分析 | Inundation Analysis | 给定水文条件计算淹没范围与水深的空间分析方法 |
| 数据分类分级 | Data Classification and Grading | 按数据的敏感程度与影响范围划分保护等级的制度安排 |
| 重要数据 | Important Data | 一旦遭到篡改、破坏、泄露或非法利用，可能危害国家安全、经济运行、社会稳定、公共健康和安全的数据 |
| 底图 | Base Map | 用于叠加专题内容的统一空间参考底图 |
| 主数据 | Master Data | 在多个系统间共享、需保持唯一与权威的基础数据 |
| 拓扑 | Topology | 空间要素之间的邻接、连通、包含等关系 |
| 分辨率 | Resolution | 空间数据可分辨的最小单元尺寸 |
| 精度 | Accuracy | 空间数据与真实位置或属性的接近程度 |
