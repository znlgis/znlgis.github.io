# 附录A 术语表

> **本篇导读**
>
> 术语表是整套教程的“度量衡”。这个领域的返工与争议，大多不是技术做不出来，而是双方对同一个词的理解不同：“一张图”到底指门户、指数据集、还是指那套裁决机制；地理实体码与不动产单元代码是不是一回事；统一底图与地理底图差在哪一层。本附录按拼音顺序收录正文使用的核心术语，每条给出释义与备注，凡涉及法定定义者标注依据。建议在项目启动会上用这张表统一口径，再谈建设范围与验收标准。

本表按拼音顺序排列，只收录本报告正文使用的术语。凡涉及法定定义者标注依据。

**表A-1 术语与释义**

| 术语 | 释义 | 备注 |
| --- | --- | --- |
| “一张图” | 自然资源管理和国土空间规划“一张图”的简称，指以统一底图为基础、以统一门户为入口、以业务场景为出口的自然资源空间治理基础设施 | 2026 年表述升级后的正式称法 |
| 国土空间基础信息平台 | 承载与发布国土空间数据的服务载体，“一张图”门户融合其能力 | 与“一张图”为吸纳关系 |
| 实施监督系统 | 国土空间规划“一张图”实施监督信息系统，依据 GB/T 39972—2021 建设 | 覆盖规划条线 |
| 统一底图 | 由地理底图、现状、规划、管理四层数据按统一坐标系、统一分类、统一时点整合而成的空间数据集 | “一张图”的数据基础 |
| 统一门户 | 整合各已建平台服务资源形成的统一入口，含国家级节点与省级节点 | 国家级节点为全国总枢纽与总入口 |
| 共享工具箱与应用池 | “一张图”融合既有平台能力后的能力供给形态，提供地图服务、数据服务、时空分析服务、智能体、工具组件、通用服务 | 平台融合的产物 |
| 地理底图 | 以国家测绘地理信息成果为基础的统一地理框架数据 | 含地形、影像、地名等 |
| 基准影像 | 用于统一影像位置精度的参照影像；首版全国几何基准影像于 2026 年 8 月 27 日发布，全国空间分辨率整体达 0.5 米 | 用作“底图模板” |
| 地理实体码 | 为地理实体分配的唯一标识，用于关联实景三维数据与行业专题数据 | 部 2026 年提出 |
| 不动产单元代码 | 按 GB/T 37346 为不动产单元设定的唯一代码 | “一码管地”的基础 |
| 在地（落位）上图分析 | 把项目的空间范围叠加到统一底图上，比对永久基本农田、生态保护红线、城镇开发边界等要素，判断是否压占 | 2026 年常用功能 |
| 三区三线 | 三区为生态空间、农业空间、城镇空间；三线为生态保护红线、永久基本农田、城镇开发边界 | 国土空间规划核心管控工具 |
| 五级三类 | 国土空间规划分级分类：五级为国家、省、市、县、乡镇；三类为总体规划、详细规划、相关专项规划 | 规划体系框架 |
| 1+N+1 | 城市层面规划体系：总体规划 + N 个专项规划 + 详细规划 | 体现空间唯一性 |
| 两统一 | 统一行使全民所有自然资源资产所有者职责、统一行使所有国土空间用途管制和生态保护修复职责 | 自然资源部核心职责 |
| 四个融合 | 司局融合、部局融合、部门融合、部省融合 | “一张图”的组织目标 |
| 四统一 | 统一底图、统一标准、统一规划、统一平台 | 顶层依据 |
| 统一调查 | 以统一分类标准、统一步骤组织的自然资源调查监测 | 8 大任务之一 |
| 统一产权底板 | 以宗地为基本单元、权属清晰的产权空间底板 | 8 大任务之一 |
| 统一用途管制 | 以统一规则、统一底图实施的国土空间用途管制 | 8 大任务之一 |
| 一体化督察和协同执法 | 督察与执法的一体化，依托“一张图”开展图斑判定与协同处置 | 8 大任务之一 |
| 国土变更调查 | 每年开展的国土利用现状变更调查，2026 年起转向日常调查监测机制 | 依据自然资办函〔2026〕1038 号 |
| 日常调查监测机制 | 替代年度集中调查的常态化调查监测机制 | 2026 年制度变化 |
| 实景三维中国 | 国家层面的三维空间数据与支撑环境建设，分地形级、城市级、部件级 | 依据自然资办发〔2022〕7 号 |
| 数字空间基准 | 包含坐标框架、高程基准、重力基准、地球定向参数等在内的国家空间基准体系 | “十五五”国土测绘重点 |
| 基准站“一张网” | 全国卫星导航定位基准站的统筹整合网络，站点 7569 座（国家级 420、省级 3293、协同 3856） | 2026 年 9 月授权运营落地 |
| 地理实体 | 现实世界中具有独立身份、可被识别与描述的空间对象 | 三维与专题数据的关联锚点 |
| 空间参照系 | 用于定位空间对象的坐标系、高程基准、投影与时点的组合 | 全部叠加分析的前提 |
| 时相 | 空间数据所反映的时间状态 | 版本回溯的基础 |
| 冲突裁决 | 当同一空间对象在不同数据源中呈现不同结论时，按既定规则确定唯一官方说法的机制 | 本报告核心概念 |
| 短板定级 | 成熟度评估中取最低维度等级作为整体等级的方法 | 见第14章 |

## 使用提示

- **怎么用**：立项文件、需求规格、验收方案里出现本表词条时，先对齐释义再动笔；两方理解不一致时，以本表“释义”列为讨论起点，最终以所引标准原文为准。
- **本表不收什么**：地方标准术语、厂商产品名、项目专有名词一律不收。遇到这类词，回到本地细则或合同文本确认，不要套用本表的解释。
- **易混三组**：“一张图”与统一底图（前者是含规则与责任的整体，后者是四层数据的集合）；地理实体码与不动产单元代码（前者关联三维与专题，后者对应权利单元）；统一门户与共享工具箱（前者是入口，后者是能力供给形态）。
- **维护建议**：项目启动会上把本表打印成签字确认件，新增术语走同样流程；跨年度项目建议每次续期时复核一次。
