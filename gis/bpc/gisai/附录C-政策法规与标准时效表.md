# 附录C 政策法规与标准时效表

> **本篇导读**
>
> 标准与法规的现行状态，决定一份方案能不能写、一句话能不能引。本附录把与 GeoAI 直接相关的依据收成两张表：C.1 列 13 项法规与制度，标出施行日期、有效期与关键条款；C.2 列 17 项标准，逐一标注现行、修订中、在编或即将实施。它与第 12、13 章配套：第 12 章讲测绘与影像的硬要求，第 13 章讲数据出境、标准时效与红线清单，本附录是两章引用时的底表。

### C.1 法规与制度（现行状态）

| 名称 | 状态 / 关键时点 | 与本主题的关系 |
| --- | --- | --- |
| 中华人民共和国测绘法 | **2017-04-27 修订、2017-07-01 施行，至今未再修订** | 根本依据；第 2 条把“处理和提供”定义为测绘活动 → AI 自动提取建模后交付属测绘活动，须持资质 |
| 地图管理条例 | 现行 | 地图编制、审核、发布规则；第 15、22、24、49、54 条为关键条款 |
| 地图审核管理规定 | 现行 | 审图号有效期 2 年（第 28 条）；公开内容与审核内容一致性（第 32 条） |
| 公开地图内容表示规范（自然资规〔2023〕2 号） | **2023-02-14 发布，有效期 5 年**（约 2028 年初到期） | 公开地图可表示与不得表示的内容；本轮窗口最需关注的一次换版 |
| 遥感影像公开使用管理规定（试行）（国测成发〔2011〕9 号） | 现行 | **位置精度不得高于 50 米、地面分辨率不得优于 0.5 米**；>10 米影像销售须客户登记与半年备案 |
| 数据安全法 | 2021-09-01 施行 | 数据分类分级、重要数据目录、安全评估 |
| 个人信息保护法 | 2021-11-01 施行 | 位置等个人信息；行踪轨迹属敏感个人信息需单独同意 |
| 网络安全法 / 关键信息基础设施安全保护条例 | 现行 | 关基运营者义务 |
| 促进和规范数据跨境流动规定（网信办令 16 号） | **2024-03-22 施行** | 评估有效期 3 年可延 3 年；100 万/1 万/10 万人阈值；自贸区负面清单 |
| 生成式人工智能服务管理暂行办法 | 2023-08-15 施行 | 训练数据来源、备案、标注规则说明等义务 |
| **人工智能生成合成内容标识办法** | **2025-09-01 施行** | AI 生成内容必须标识；**已有 2026-04 处罚案例** |
| 科技伦理审查办法（试行） | 2023 年施行 | 高风险 AI 科技活动立项即触发伦理审查 |
| 公共数据资源授权运营实施规范（试行） | **2025-03-01 施行，有效期 5 年** | 时空数据授权运营的制度基础 |

### C.2 标准（含状态判定）

| 标准编号 | 名称/领域 | 状态 | 对 AI 成果的意义 |
| --- | --- | --- | --- |
| GB/T 24356-2023 | 测绘成果质量检查与验收 | **现行**（2023-05-23 实施） | 成果验收主标准，AI 成果最终按此判定 |
| GB/T 18316 | 数字测绘成果质量要求/检查与验收 | **修订中（在编）** | 修订完成前不可作为已发布标准引用 |
| GB/T 17941-2008 | 数字测绘成果质量要求 | 现行 | 与 2023 版体系存在代际差 |
| GB/T 45667-2025 | 测绘地理信息标准一致性测试规范 | **2025-09-01 实施** | 填补标准间一致性测试空白 |
| GB/T 18578-2025 | 城市地理信息系统设计规范 | 2025-09-01 实施（修订） | 城市 GIS 设计的现行依据 |
| GB/T 21740-2025 | 基础地理信息城市数据库建设规范 | 2025-09-01 实施（修订） | 城市数据库建设依据 |
| CH/T 6012-2025 等 9 项 | 城市地下空间测绘成果质量检验技术要求等 | 2025 年公告发布，**2025-12-01 实施** | 行业标准批次更新 |
| **GB 45438-2025** | 网络安全技术 人工智能生成合成内容标识方法 | **强制性，2025-02-28 发布 / 2025-09-01 实施** | AI 生成内容标识的技术依据 |
| GB/T 45654-2025 | 网络安全技术 生成式人工智能服务安全基本要求 | 2025-04-25 发布 / **2025-11-01 实施** | 训练数据安全、模型安全与安全措施 |
| GB/T 45288.2-2025 | 人工智能 大模型 第 2 部分：评测指标与方法 | 2025-02-28 发布 | 模型能力评测的指标与方法 |
| **GB 48319-2026** | 智能网联汽车时空数据安全处理基本要求 | **2026-09-28 发布，2027-10-01 实施（即将实施，非现行）** | 时空数据收集、存储、传输的安全要求 |
| CH/T 9015/9016/9017-2012 | 三维地理信息模型产品/生产/数据库 | 现行 | 三维 AI 成果依据（覆盖传统 Mesh） |
| CH/T 9024-2014 | 三维地理信息模型数据产品质量检查与验收 | 现行 | 同上；地理实体成果存在空窗 |
| ISO 19157-1:2023 | 地理信息 数据质量 | 现行 | 国际质量评价口径 |
| **ISO 19178-1:2025** | 地理信息 人工智能样本标记语言（概念模型） | 已发布（**我国牵头首项地理信息 AI 国际标准**） | 管训练样本标记，样本层标准化的国际依据 |
| **openEO** | 地球观测数据开放接口 | **2026-05-19 成为 OGC Community Standard** | 管 EO 数据如何被 AI 调用 |
| **3D Tiles 2.0** | 三维数据承载格式 | 预计 2026 年内批准 | 管三维成果的承载与交换 |

> **时效纪律**：上表中标记为“在编/修订中/即将实施”的标准，在正式生效前**不得作为合规依据引用**。本报告对其只作趋势参考。实际项目引用标准时，应以全国标准信息公共服务平台或发布公告的当前状态为准。

## 使用提醒

- 时效纪律优先：标为“在编/修订中/即将实施”的标准，正式生效前不得作为合规依据引用，本表只作趋势参考。
- 具体项目引用时，以全国标准信息公共服务平台或发布公告的当前状态为准；本表基准日是 2026 年 11 月。
- GB 48319-2026 是典型易错项：2026-09-28 发布、2027-10-01 实施，2026 年内只能写“即将实施”。
- 地方性 AI+测绘政策不在本表覆盖范围，按项目所在省市单独核查，并记录核查日期。
