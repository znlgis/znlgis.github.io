# 第01章 导论：研究范围、方法口径与五条核心结论

> **本章导读**
>
> 先立口径，再谈技术。本章对应原报告摘要与 1.1—1.3 节：摘要用四组事实把“演示可行”与“工程可交付”分开，并给出五条核心结论；正文三节分别界定范围、说明研究方法、给出时效性口径——法规看施行日期、标准看实施状态、统计看统计年度与发布主体。它放在全教程开篇，是后面十三章与五个附录共用的引用规则，遇到数字疑问可回这里核对。最该带走一句：2025—2026 年 GIS×AI 的能力边界已被公开基准标定，与合同里 90% 的门槛之间存在结构性错配，“AI 初筛 + 人工终判”是长期形态，不是过渡期权宜之计。

## 学习目标

读完本章，你应当能够：

- 复述五条核心结论，并指出其中哪几条属于技术判断、哪几条属于制度约束；
- 用 1.1 节的范围界定判断一个具体需求是否属于本报告讨论范围，并引用对应的排除项说明理由；
- 用 1.3 节的时效性口径判断一条待引用的政策、标准或统计数字能否作为依据（含 GB 48319-2026 这类已发布未实施的情形）；
- 用 1.2 节研究方法对照自己单位的技术方案，写出一份数据来源核验清单，标出哪些数字只有单一来源；
- 区分“演示可行”与“工程可交付”在验收条款上的差别，并写出正文中已合同化的那个例子（结果正确率不低于 90%、符合 GB/T 24356）；
- 说清为什么参数规模不是地观测模型的决定性变量，并写出选型该问的三个问题：模态覆盖、时间跨度、位置编码。

## 摘要

GIS 与 AI 的结合，在 2025—2026 年已跨过“演示可行”阶段，进入“工程可交付”阶段。这个判断不是修辞，而是由四组可公开验证的事实同时支撑。

**第一，产业的钱和定位都变了，但收入尚未兑现。** 2025 年我国地理信息产业总产值 **9005 亿元、同比增长 5.9%**，从业单位约 **26.9 万家、同比增长 11.1%**（增速接近产值增速两倍），从业人员约 **400 万人**，新登记企业约 **4.5 万户、同比增长 19.7%**；内地 79 家上市地信企业中 75 家 2025 年末总市值约 **9920.2 亿元、同比 +43.8%**（《中国地理信息产业发展报告（2026）》，2026-10-15）。**估值大幅上行与头部企业收入停滞同时发生**——超图营收仅 +0.75%，说明资本市场买的是结构转换的预期，而非当期业绩。政策侧同步给出了明确抓手：自然资源部提出“十五五”促进地理信息与人工智能深度融合、**力争年均产业总产值突破万亿元**，并在 2026 年 10 月的产业大会上提出实施**“时空智能+”行动**。

**第二，技术侧的变化发生在三个层次同时，且可用具体数字度量。**
- **数据层**：实景三维中国于 **2025-12-30** 宣布初步建成——5 米、10 米格网覆盖全国陆地国土，1:1 万数据覆盖 70%，300 余城市完成三维模型生产；同期民用遥感卫星累计发射 **694 颗**。观测供给已过剩，瓶颈转为“把影像变成结论”。
- **模型层**：地理空间基础模型进入批量发布期。Prithvi-EO-2.0 基于 **420 万条** HLS 时序训练（3 亿/6 亿参数，GEO-Bench 提升 8%，80×A100 约 11 天）；TerraMind 以 **5000 亿 token** 做任意到任意多模态预训练，是 PANGAEA 上唯一以冻结编码器超过任务专用 U-Net 的基础模型（领先 ≥3 个百分点）；Ai2 于 **2026-10-22** 发布 OlmoEarth v1.3，把全球 10 米网格年度观测压缩为 **128 维向量**并开放预计算特征，训练 GPU 时间降至 v1 的 **18%**。
- **应用层**：空间智能体成为产品主线。超图 **SuperMap GIS 2026**（2026-05-26）以“智能体原生”为核心，推出 AgentX 与 Skill Hub；Esri 在 2026 年推出 Agentic GIS 与 MCP Beta；Google 于 2025-10 发布 Earth AI，2026-10 扩展为地理空间推理智能体（GRA）。

**第三，价值的量化已出现，但分布极不均衡。** 公开工程数字给出量级：中国测绘科学研究院 ACID 系统在全国 500 区县测试，数据维度压缩 **97.79%**、单区县处理 **17 分钟**、疑似新增建/构筑物任务效率提升约 **34%**；面向建设用地变化的检测方法平均查全率 **97.3%**、**人工排查工作量降低 41.9%**；湖南“天空地网”单县质检由 **2—3 小时缩短至 30—40 分钟**。更关键的是**验收标准已经合同化**：惠州市自然资源局 2025-12 询价公告明确要求 AI 变化检测“**结果正确率不低于 90%**、符合 GB/T 24356”。**变化检测是唯一同时满足高频、可量化、可验收、有国标兜底四条件的场景。**

**第四，能力的真实边界被公开基准清晰标定，且与合同要求存在结构性错配。** GEOBench-VLM（ICCV 2025）显示最佳模型单选准确率仅 **41.7%**，GPT-4o 约为随机猜测 2 倍；ACL 2026 Findings 实测显示**零样本 LLM Agent 调用 Earth Engine API 准确率仅 40.0%，44% 以上情况代码无法运行**，头部模型约 60%。这与合同中 90% 的门槛形成“能力—合同错配”——**这正是“AI 初筛 + 人工终判”成为主流形态的根本原因，而不是过渡期权宜之计。**

**本报告的核心结论可压缩为五条：**

1. **技术竞争的主战场已从“模型精度”转向“任务闭环”。** 变化检测在 LEVIR-CD 上的 F1 已在 91%—92.5% 区间收敛，方法间差异小于标注噪声——**精度已进入饱和区**；真正的差异转向“能否把模型、工具、数据、知识组织成可交付的任务执行系统”，以及能否在真实生产约束下稳定运行。
2. **参数规模不是决定性变量。** 在地观测领域，约 3 亿参数的 TerraMind 在统一协议下超过 20.6 亿参数的通用模型。**选型应问“预训练数据的模态覆盖、时间跨度与位置编码”，而不是“多少参数”。**
3. **智能体是最真实的产品形态变化，但边界必须讲清。** 自然语言下达任务、自动编排 Skill、输出地图/图表/报告已可交付；但公开基准显示零样本 Agent 仅 40%，且厂商开放的 MCP 能力仅限“云端轻量服务”，不开放私有数据与复杂分析。**“智能体”≠“自动化”。**
4. **合规已成为产品设计的前置约束。** 《测绘法》第二条把“处理和提供”也定义为测绘活动——**AI 自动提取建模后对外交付属测绘活动，须持资质**；地图审图号有效期 **2 年**、每 **6 个月**备案新增标注、未审核地图服务可罚 **20 万元以下**；遥感影像公开使用有 **50 米/0.5 米**两条硬阈值（超分模型必须先过分辨率闸门）；标识义务自 **2025-09-01** 施行且**已有实际处罚案例**（2026-04 剪映/猫箱/即梦 AI）。
5. **2026—2030 年的主赛道是“时空智能”与数据要素化的叠加。** 2026-09 全国卫星导航定位基准站网服务数据完成**国家层面首次时空信息基础设施领域的公共数据授权运营**；“全国一张网”整合 **7000 座**基准站。“十五五”深化时空智能科技攻关、支撑智能驾驶与低空经济——这是 AI 能力变现的主要出口。

## 1.1 报告范围

本报告讨论的“GIS 与 AI 结合”，指**人工智能技术在地理空间数据的生产、治理、分析、表达与决策支持全链路中的应用**，以及由此带来的产业组织结构变化。范围界定如下：

- **技术侧**：地理空间基础模型、遥感与点云/三维视觉模型、大语言模型与多模态模型、空间智能体、空间推理与知识图谱、AI 与 GIS 平台/数据库/制图工具的集成、推理加速与工程化
- **业务侧**：市场规模、厂商格局、行业场景（自然资源、应急、水利、电力、交通、保险、城市治理、低空经济）、商业与计价模式、采购与生态
- **制度侧**：与 GeoAI 直接相关的测绘地理信息法规、数据与 AI 治理制度、标准体系与时效状态
- **不包含**：通用大模型本身的架构与训练细节（仅在涉及空间能力时提及）、非空间属性的业务系统功能测评、任何涉密或未公开的地理信息内容

## 1.2 研究方法

| 方法 | 说明 | 局限 |
| --- | --- | --- |
| 公开文献与标准检索 | 政府公告、全国标准信息公共服务平台、OGC/ISO 公开文件、期刊与预印本 | 部分标准需付费获取全文，正文只能依据公开摘要与解读 |
| 厂商公开信息比对 | 官网新闻稿、产品文档、开发者博客、发布会公开材料 | 厂商数据存在选择性披露，仅用于判断方向与节奏，不用于横向排名 |
| 统计与财报核验 | 同一数字在至少两个独立来源出现方采用；上市公司数据取公开财报 | 协会口径与商业机构口径不可直接比较，须分别标注 |
| 案例量化提取 | 优先采用带明确测试范围、指标定义与对照基线的公开结果 | 不同研究的测试集不同，数字不可直接横比 |
| 反向证据核查 | 主动检索与厂商叙事相反的证据（基准实测、财报、处罚通报） | 反向证据往往分散，需专项检索 |

## 1.3 时效性口径（本报告最重要的方法约束）

“最新”在地理信息与 AI 这两个变化极快的领域，是一个必须被量化的词。本报告采用如下口径：

| 对象 | 时效判定标准 | 本报告的处理方式 |
| --- | --- | --- |
| 法规 | 是否现行有效、最近一次修订/施行日期 | 给出施行日期；已废止或被替代的明确标注，不作引用依据 |
| 标准 | 标准号 + 版本年 + 实施状态（现行/在编/征求意见/即将实施） | 在编或“即将实施”的标准只作趋势参考，**不作为合规依据** |
| 统计数据 | 统计年度 + 发布日期 + 发布主体 | 全部标注，避免“2026 年报告引用 2023 年数据”的错配 |
| 产品版本 | 版本号 + 发布月份 | 标注发布月份，过期版本注明已被迭代 |
| 论文与预印本 | 是否同行评审、发布时间 | 预印本标注“未经同行评审” |
| 机构预测 | 预测机构 + 预测区间 + 发布时点 | 明确标注为预测，不与既成事实混排 |

**三个必须遵守的技术性纪律**，它们对应本报告发现的最常见引用错误：

1. **跨规划期数据不可混排。** 大量中文材料把“十四五”末的数据与“十五五”初的政策混在同一句里，导致读者误判时效。本报告凡出现“十五五”目标，均标注其为**目标值而非实现值**。
2. **“已发布”≠“已实施”。** 例如 GB 48319-2026 于 2026-09-28 发布，但要到 **2027-10-01** 才实施，2026 年内属“即将实施”，不能按已生效引用。
3. **产品有“时间锚点”。** 空天·灵眸 3.0 发布于 2024-09，SenseEarth 3.0 发布于 2023-05，按本报告规则引用时必须显式标注年份——**把它们当作“2026 年最新进展”是最常见的引用错误之一**。

## 本章小结

- 2025—2026 年 GIS×AI 已跨过“演示可行”进入“工程可交付”，由四组事实同时支撑：产业规模与估值、技术三层变化、价值量化、以及被基准标定的能力边界。
- 产业侧的信号是估值与收入的背离：内地 79 家上市地信企业 2025 年末总市值约 9920.2 亿元、同比 +43.8%，而超图营收仅 +0.75%，本报告判断资本市场买的是结构转换预期而非当期业绩。
- 变化检测是唯一同时满足高频、可量化、可验收、有国标兜底四条件的场景，但 LEVIR-CD 上 F1 已收敛在 91%—92.5%，方法间差异小于标注噪声，继续优化模型结构的边际价值极低。
- 能力与合同存在结构性错配：GEOBench-VLM 最佳模型单选准确率仅 41.7%，零样本 LLM Agent 调用 Earth Engine API 准确率仅 40.0%、44% 以上代码无法运行，而合同门槛是 90%。
- 合规是前置约束不是事后补办：《测绘法》第二条把“处理和提供”也定义为测绘活动，地图审图号有效期 2 年、每 6 个月备案新增标注、未审核地图服务可罚 20 万元以下，影像公开使用有 50 米与 0.5 米两条硬阈值。
- 引用纪律上“已发布”不等于“已实施”：GB 48319-2026 于 2026-09-28 发布、2027-10-01 才实施；空天·灵眸 3.0（2024-09）与 SenseEarth 3.0（2023-05）引用时必须显式标注年份。
- 2026—2030 年的主赛道是“时空智能”与数据要素化的叠加：2026-09 国家层面首次在时空信息基础设施领域开展公共数据授权运营，“全国一张网”整合 7000 座基准站。

## 思考与练习

1. 用 1.1 节范围界定，判断“给通用大模型补地理常识”是否属于本报告讨论范围，写出你依据的是哪一条排除项。
2. 取你单位一份对外技术方案，按 1.3 节六类对象列出其中的政策、标准、统计与产品版本引用，标出哪几条缺时效标注。
3. 有人说“2026 年遥感解译已全面达到 90% 可用”。用摘要第四条的基准数字反驳，并说明正文里的 90% 究竟指什么。
4. 辨析：甲方认为“精度再提 3 个点就能替代人工”，乙方认为“人工终判是长期形态”。分别用摘要第一条与第四条的证据支撑两方，再给结论。
5. 应用题：某区县要做变化检测采购，按正文线索写出三项合同条款（正确率门槛、标准依据、复核机制），并注明每项依据出自哪节。
6. 结合你所在行业，把五条核心结论各改写为一句适用于你业务的判断；写不出来的那条，说明缺哪一类公开证据。
