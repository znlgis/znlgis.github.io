# 附录E 成果质检规则清单（建议）

> **本篇导读**
>
> 附录 E 是一份可以直接灌进规则库的初始清单，按第 9 章的六要素结构组织，分七组：完整性、几何、属性、拓扑、逻辑与计算、一致性与有效性、程序与合规，共 43 条规则，每条给出编号、名称、判定式与处置或级别；编号按前缀分组（QC-CMP、QC-GEO、QC-ATT、QC-TOP、QC-LGC、QC-CON、QC-PRC），看前缀就知道规则维度。它要回答的是“成果一致性怎么变成可执行的检查”：第 9 章讲了四个层面，这里把每个层面的典型违反写成可判定的表达式。两处容易做错：一是把表里的严重级别当成定论，说明部分写明严重级别为建议值，各地应结合本地规程调整；二是只做几何与属性检查，跳过表 E-6 与表 E-7——跨事项匹配与时点有效性恰恰是“一套成果”能否成立的地方，签章、资质与检查记录则是合规证据。读完你会明白，规则库的门槛不在写规则，而在把容差、分级与处置一并定下来。

## 使用提示

- **用途**：作为规则库的第一版内容。先按前缀把七组规则分给不同责任人，再逐条补齐适用范围、判定表达式与容差，就能跑起来。
- **口径读法**：判定式里的“容差”“阈值”本清单未给数值，必须与本地规程的精度要求匹配后再填；严重级别是建议值，错误、警告、提示三级如何处置（阻断、修复、仅报告）要由本地质量制度决定。
- **边界**：清单是建议性的，不构成验收标准；规则覆盖的是可自动判定的部分，需要人判断的规则适用与责任认定不在其列，不能以规则全部通过替代两级检查。
- **配合使用**：与第 09 章（9.3 节规则库设计、9.4 节自动化实现要点）配合读，理解六要素为何这样排；与附录 D 配合，规则判定的对象正是那张数据字典定义的图层与字段。

**说明**：本清单按第 9 章的六要素结构组织，可直接作为规则库的初始内容。**严重级别为建议值，各地应结合本地规程调整。**

**表 E-1　完整性规则（级别：错误）**

| 规则编号 | 规则名称 | 判定 | 处置 |
| --- | --- | --- | --- |
| QC-CMP-001 | 必填属性非空 | 所有必填字段值不为空 | 阻断 |
| QC-CMP-002 | 图层齐全 | 实际图层集合 ⊇ 数据字典要求的图层集合 | 阻断 |
| QC-CMP-003 | 元数据齐全 | 元数据最小集（附录 D）各项均存在 | 阻断 |
| QC-CMP-004 | 成果清单完整 | 提交文件列表覆盖成果要求清单 | 阻断 |
| QC-CMP-005 | 要素数量合理 | 各图层要素数 > 0（除允许为空的图层） | 警告 |

**表 E-2　几何规则（级别：错误/警告）**

| 规则编号 | 规则名称 | 判定 | 级别 |
| --- | --- | --- | --- |
| QC-GEO-001 | 面要素闭合 | 面环首尾节点重合（容差内） | 错误 |
| QC-GEO-002 | 几何有效 | 无自相交、无悬挂节点（按要素类型） | 错误 |
| QC-GEO-003 | 无零长度线 | 线要素长度 > 0 | 错误 |
| QC-GEO-004 | 无重复要素 | 几何完全相同或近似相同的要素不存在 | 错误 |
| QC-GEO-005 | 无微小碎面 | 面要素面积 ≥ 阈值 | 警告 |
| QC-GEO-006 | 无狭长面 | 面积/周长² 比例 ≥ 阈值 | 提示 |
| QC-GEO-007 | 节点密度合理 | 单位长度节点数 ≤ 阈值 | 提示 |

**表 E-3　属性规则（级别：错误）**

| 规则编号 | 规则名称 | 判定 |
| --- | --- | --- |
| QC-ATT-001 | 枚举值合法 | 值 ∈ 字典取值范围 |
| QC-ATT-002 | 数值域合法 | 面积 > 0、层数 ≥ 1、高度 > 0 等 |
| QC-ATT-003 | 编码格式合法 | 宗地代码、不动产单元代码符合编码规则 |
| QC-ATT-004 | 日期合法 | 日期可解析且不在未来（除计划类字段） |
| QC-ATT-005 | 字段长度合法 | 字符串长度 ≤ 定义长度 |

**表 E-4　拓扑规则（级别：错误/警告）**

| 规则编号 | 规则名称 | 判定 | 级别 |
| --- | --- | --- | --- |
| QC-TOP-001 | 宗地不重叠 | 任意两宗地面交集面积 = 0 | 错误 |
| QC-TOP-002 | 相邻宗地共线 | 相邻界址线重合度 = 100% | 错误 |
| QC-TOP-003 | 界址点在线端 | 界址点位于界址线端点 | 错误 |
| QC-TOP-004 | 建筑不越界 | 建筑基底 ⊆ 宗地（或符合允许越界规则） | 警告 |
| QC-TOP-005 | 房屋分户不重叠 | 同一层内分户面交集 = 0 | 错误 |
| QC-TOP-006 | 分户覆盖整层 | 分户面并集 = 楼层平面（容差内） | 错误 |
| QC-TOP-007 | 绿地不与建筑重叠 | 绿地面 ∩ 建筑基底面 = 空 | 警告 |
| QC-TOP-008 | 控制点不冲突 | 同一点号不出现两个坐标 | 错误 |

**表 E-5　逻辑与计算规则（级别：错误）**

| 规则编号 | 规则名称 | 判定 |
| --- | --- | --- |
| QC-LGC-001 | 面积字段与几何一致 | ABS(面积字段 − 几何计算面积) ≤ 面积限差 |
| QC-LGC-002 | 分户面积之和 = 幢面积 | ABS(Σ 分户 − 幢) ≤ 限差 |
| QC-LGC-003 | 绿地率计算正确 | 认定绿地面积 ÷ 计算基数 = 绿地率（在容差内） |
| QC-LGC-004 | 容积率计算正确 | 计容建筑面积 ÷ 用地面积 = 容积率（在容差内） |
| QC-LGC-005 | 基底面积计算正确 | 按基底面积规则重算与填报值一致 |
| QC-LGC-006 | 层数与分层轮廓一致 | 分层轮廓数量 = 地上层数（若按层建模） |

**表 E-6　一致性与有效性规则（级别：错误/警告）**

| 规则编号 | 规则名称 | 判定 | 级别 |
| --- | --- | --- | --- |
| QC-CON-001 | 坐标系声明正确 | 元数据坐标系 = CGCS2000 或经批准的联系坐标系 | 错误 |
| QC-CON-002 | 高程基准正确 | 元数据高程基准 = 1985 国家高程基准 | 错误 |
| QC-CON-003 | 范围在辖区内 | 数据范围在行政区划范围内（容差内） | 警告 |
| QC-CON-004 | 与既有宗地套合 | 新建宗地与地籍库既有宗地界址重合度 ≥ 阈值 | 警告 |
| QC-CON-005 | 跨事项对象匹配 | 规划核实的建筑与房产测绘的幢可一一对应 | 警告 |
| QC-CON-006 | 时点有效性 | 测绘时点在有效期内 | 警告 |
| QC-CON-007 | 不动产单元代码可关联 | 房屋单元的代码在登记库中存在或符合编码规则 | 警告 |

**表 E-7　程序与合规规则（级别：错误）**

| 规则编号 | 规则名称 | 判定 |
| --- | --- | --- |
| QC-PRC-001 | 签章完备 | 成果报告、图件均有有效电子签章 |
| QC-PRC-002 | 资质匹配 | 承接单位资质类别覆盖全部委托事项 |
| QC-PRC-003 | 检查记录完整 | 过程检查、最终检查记录均存在 |
| QC-PRC-004 | 密级已标注 | 成果密级字段非空 |
| QC-PRC-005 | 人员资格 | 项目负责人具备相应资格 |
