# 前言

> **本篇导读**
>
> 这份前言回答三个问题：这套教程讲什么、为什么值得现在读、以及怎么读最省时间。如果只用一句话概括全教程的结论：CAD 图纸翻模今天已经不是“能不能做”的问题，而是“用什么口径做、由谁复核、交给谁使用”的工程管理问题——把它当成一次性建模外包，几乎注定失败；把它当成一条带标准、带质检、带版本的生产线，才可能稳定交付。

## 教程定位

CAD 图纸翻模（Drawing-based 3D Reconstruction / CAD-to-BIM），指以二维 CAD 图纸（通常是 DWG/DXF 格式的施工图、方案图或竣工图）作为几何与信息的主要依据，在三维环境中重建建筑、结构、机电等构件的几何形体，并附加构件类别、材质、尺寸、编号等属性，形成可编辑三维模型的过程。它是既有建筑数字化最常用的入口之一，也是城市级三维底座、BIM 智能辅助审查、运维数据底座等下游应用的共同前提。

教程不到“软件怎么点”的层面，而是按“认知—标准—技术—交付—治理”的顺序，把一门工程作业拆开讲清楚：它依赖哪些外部约束，哪条技术路线适合哪类项目，产线怎么组织，验收和合同怎么写，成本与人才怎么算。它适合需要判断与决策的人，也适合希望把翻模做成稳定业务而不是接一单算一单的人。

## 主要判断

综合全文，本教程形成五条基本判断。

**第一，翻模的产出是“数据资产”，不是“模型文件”。** 几何只是载体；能被检索、能被算量、能进审查、能被运维接手，靠的是语义、属性、坐标与可核查性这四层信息。缺少这四层的模型，无论画得多精细，都停留在展示品层面。

**第二，选型比努力更重要，而路线几乎总是混合的。** 图纸规则化半自动、参数化 BIM 重建、点云/实景逆向、AI 端到端四条路线没有绝对优劣，只有场景匹配。真实项目里，主体结构用脚本批量生成、复杂节点手工重建、改造部位用点云校核、AI 用于批量属性与文字提取，是更常见的组合。

**第三，决定成败的是五个口径，而不是建模技巧。** 精度口径（几何偏差怎么量）、信息口径（每个构件带哪些属性）、命名与编码口径（怎么分类追溯）、坐标与单位口径（CGCS2000 还是地方坐标、米还是毫米）、交付口径（原生、IFC、轻量化各自的作用与验收方式）。这五项在项目启动时没有书面锁定，后期返工几乎不可避免。

**第四，主要风险在上游，后果由下游承担。** 最贵的错误通常不是模型画错，而是图纸版本混乱、精度口径反复、属性造假、涉密与数据合规失控。它们的共同特征是：发生在上游、暴露在下游、由翻模方承担后果。因此合同中的验收标准、变更计价与数据条款，重要性不低于建模能力本身。

**第五，合规与时效是硬门槛，不是加分项。** 三维成果正从“加分项”变成“交付项”：报建要 IFC、审查要图模一致、入库要坐标与编码、AI 使用要评估数据能否出门。同时政策与标准处在高频更新期，超期未复核的状态结论不宜直接写进合同。教程因此在第 3 章与附录 D 给出了核验方法与复核周期。

## 如何使用本教程

原报告按“认知—标准—技术—交付—治理”的顺序组织，读者可按角色取舍：

**表 1  按角色的阅读路径**

| 角色 | 建议重点章节 | 读完后应能回答的问题 |
| --- | --- | --- |
| 业主 / 建设单位 | 第 1、3、8、9 章，附录 A | 我需要什么精度的模型？预算与验收标准怎么定？ |
| 测绘 / 地理信息单位 | 第 3、4、5 章，附录 B | 我已有的测绘能力如何迁移到翻模业务？ |
| BIM 咨询 / 翻模服务商 | 第 4、5、7、8、9 章 | 我的产线怎么搭、报价怎么算、质量怎么保证？ |
| 设计院 / 施工总包 | 第 2、4、6 章 | 翻模如何嵌入现有设计与施工流程？ |
| 政府 / 平台公司 | 第 3、10、11 章 | 如何用模型支撑审批、运维与城市级底座？ |

注：章节编号与正文一致。

**按篇阅读**：入门先读第一、二篇建立“什么值得做、走哪条路”的判断；一线生产与项目管理重点读第三篇与附录 B；管理与决策重点读第 3、9、10、13 章。目录页另给了三条推荐路线（入门、生产与交付、管理与决策）。

**按问题检索**：第 14 章按“输入、建模、质检与交付、组织与管理”整理了高频问题与处置；附录 B 是可勾选的质检清单，附录 C 是交付文档的模板要点。

**每章结构**：章首导读说明本章回答什么问题；学习目标给出可检验的阅读要求；正文保留原报告的论述、表格与依据；章末小结提炼关键判断，思考与练习用于自测或培训讨论；页末给出上一章、下一章与目录的导航。

## 使用边界

本教程面向翻模项目的组织与管理，供建设单位、翻模服务商、设计院与施工方、测绘与地理信息单位、政府与平台公司在立项、招标、生产与验收时参考。文中的分级、排序与路线建议均为基于公开资料与作业实践的定性判断，不构成对任何主体经营决策、投资决策或法律适用的建议。

政策、标准与产品信息均有核验日期，会随时间变化。引用前请以官方最新文本为准，并按[附录D · 核验方法与复核安排](https://znlgis.github.io/gis/bpc/cadfm/附录D-主要资料来源/)执行：交付类文件每 90 天、投标类文件每次投标前复核一次，记录“核验日 + 来源 + 结论”。
