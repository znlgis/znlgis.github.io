# 附录A 合规检查清单

> **本篇导读**
>
> 本附录把第 10、11 章讲过的规则压成一张可直接勾选的清单，按立项、开发、发布、运营四个节点组织，与 5.7 节的检查项一一对应。用法有三种：立项评审前当核对表用，结项时当合规证据归档，跨部门交接时当共识底稿。与正文的配合方式是：先用第 10 章判断“这件事能不能做”，再用本章清单确认“这一步有没有按规则做”——判断与执行分开，才不容易漏项。

**立项**
- [ ] 数据来源合法性与授权链完整（含用途、期限、再分发权）
- [ ] 是否构成测绘活动的判定（涉及采集则先确认资质）
- [ ] 涉密判定（依据自然资发〔2020〕95 号，形成书面结论）
- [ ] 数据分类分级与处理规则（谁能看、存多久、能否出境、能否训练）
- [ ] 个人信息影响评估（含位置轨迹、人脸、车牌）

**开发**
- [ ] 坐标系统一至 CGCS2000，明确各环节转换与精度损失
- [ ] 高程基准声明（1985 国家高程基准/大地高/正高）
- [ ] 去标识化与最小必要（位置、影像中的人脸与车牌）
- [ ] 访问控制、审计日志、密钥管理
- [ ] 出境评估（如有跨境处理或境外云服务）

**发布**
- [ ] 地图审核或自查（国界、行政区划、重要地物表示）
- [ ] 成果形态复核（矢量可反推精度，风险高于栅格）
- [ ] 精度与要素的公开合规性
- [ ] 第三方数据与图源的版权与署名

**运营**
- [ ] 数据更新机制与过期数据销毁
- [ ] 安全事件响应预案（2026 年起按新修订《网络安全法》执行）
- [ ] 授权运营边界复核（如涉及公共数据）
- [ ] 第三方共享的合同约束与责任划分
- [ ] 模型版本与训练数据变更的再评估

## 使用提醒

- 清单是检查框架，不是法律意见；具体判断以现行法律法规文本与主管部门解释为准，与附录 D 的报告说明口径一致。
- 各勾选项在不同行业权重不同：涉密判定与地图审核在公开成果中不可省，数据出境在纯内网项目中可标注“不适用”并写明理由。
- 每次结项把清单归档，作为合规证据的一部分；法规更新后（如 2026 年 1 月 1 日起施行的新修订《网络安全法》）要修订清单版本并注明生效日期。
- 与附录 B 配合使用：凡因资料不足无法勾选的条目，转入附录 B 的跟踪清单，不要默认通过。
