# 第04章 分析方法体系：从描述到预测

> **本章导读**
>
> 方法清单很容易写，难的是匹配。本章对应原报告 3.5 节（3.5.1—3.5.4）：按“回答什么问题”把方法分成描述型、解释型、预测型三类，再给出一张业务问题与首选方法的对照表，逐行标出常见误用。它处在技术层中间：前面几章决定方法能不能算得动、算得对，后面两章在这套方法之上做增量。要带走的判断是，最基础的空间查询与叠加占了实际分析工作量的一半以上，误用几乎都发生在跳过业务规则校验、用静态结果代替动态过程这两步。读完你应当能拿到一个需求，先问它要回答哪一类问题。

## 学习目标

读完本章，你应当能够：

- 把 3.5.1—3.5.3 的方法按描述型、解释型、预测型归类，并各举两个适用业务问题；
- 用 3.5.4 节匹配表为选址、违建识别、洪涝风险、交通拥堵四类问题选首选方法，并各说一个常见误用；
- 解释“显著不等于因果”，说明空间回归中带宽选择为什么是主要技术门槛；
- 区分风险建模中的动态水动力模型与静态淹没面，说明前者为什么必须做敏感性分析；
- 说明空间聚合的边界处理（点在面归属、跨界面要素的面积分摊）如何改变汇总结论；
- 为一个你熟悉的需求写出“问题—方法—误用”三栏对照，并标明可交付物。

把方法按“回答什么问题”分类，比按算法名分类更实用。

## 3.5.1 描述型：现状是什么

- **空间查询与叠加**：相交、包含、邻接、缓冲区、裁剪、合并。最基础也最常用，占实际分析工作量的一半以上。
- **空间聚合**：按行政区、网格、商圈汇总。难点在边界处理（点在面归属、跨界面要素的面积分摊）。
- **密度与可达性**：核密度估计、最近设施点、等时圈（isochrone）。等时圈是选址与公共服务评估的核心工具，依赖路网数据质量与实时交通。

## 3.5.2 解释型：为什么是这样

- **空间自相关**：全局/局部 Moran's I、Getis-Ord Gi*，用于识别集聚与热点。注意：显著不等于因果。
- **空间回归**：GWR/MGWR 处理空间异质性（同一因素在不同区位影响不同），空间计量模型处理空间依赖。参数估计与带宽选择是主要技术门槛。
- **地理探测器**：用于探测空间分异的驱动因子及其交互作用，在规划与社科研究中应用广泛。

## 3.5.3 预测型：未来会怎样

- **时空预测**：时空自回归、图神经网络、时空 Transformer。交通流量、空气质量、房价是典型场景。
- **选址优化**：p-median、最大覆盖、区位-分配模型，本质是组合优化而非统计推断。
- **路径与调度**：VRP（车辆路径）、TSP、多目标路径规划。难点在约束建模（时间窗、载重、限行）而非算法本身。
- **风险建模**：洪水淹没（水动力或简化水文）、火灾蔓延（元胞自动机）、滑坡易发性（逻辑回归/随机森林）。这类模型对输入数据精度极度敏感，务必做敏感性分析。

## 3.5.4 方法与问题的匹配表

| 业务问题 | 首选方法 | 常见误用 |
|---|---|---|
| 门店选址 | 最大覆盖 + 等时圈 + 客群叠加 | 只用缓冲区，忽略路网与实际出行 |
| 违建识别 | 影像变化检测 + 审批数据比对 | 只做影像分类，不做业务规则校验 |
| 洪涝风险 | 水动力模型 + DEM + 管网 | 用静态淹没面代替动态演进 |
| 交通拥堵 | OD 分析 + 时空聚类 + 仿真 | 只做热力图不做因果分解 |
| 耕地保护 | 变化检测 + 地块比对 + 规则引擎 | 依赖单一时相影像 |
| 网络规划 | 覆盖优化 + 传播模型 + 人口栅格 | 用行政中心点代替真实人口分布 |

## 本章小结

- 按“回答什么问题”给方法分类比按算法名分类实用：描述型答现状、解释型答成因、预测型答未来。
- 空间查询与叠加是最基础也最常用的部分，占实际分析工作量一半以上；难点不在算法而在边界处理——点在面归属、跨界面要素的面积分摊都会改变汇总结果。
- 密度与可达性分析（核密度、最近设施点、等时圈）是选址与公共服务评估的核心工具，结论质量直接取决于路网数据质量与实时交通。
- 空间自相关显著不等于因果；GWR/MGWR 处理空间异质性，空间计量模型处理空间依赖，参数估计与带宽选择是主要门槛。
- 选址优化（p-median、最大覆盖、区位-分配）本质是组合优化而非统计推断；路径与调度的难点在约束建模（时间窗、载重、限行）而非算法本身。
- 风险建模对输入数据精度极度敏感，务必做敏感性分析；洪水淹没用静态淹没面代替动态演进是典型误用。

## 思考与练习

1. 取你单位近一年做过的三次分析，按描述型/解释型/预测型归类，看哪一类被过度使用、为什么。
2. 用一个真实的选址问题比较“缓冲区”与“等时圈”的候选点差异，并说明差异来自哪一项数据。
3. 辨析：报告写“热点显著，因此该区域的问题由某因素导致”。用 3.5.2 节判断这句话的问题，并改写为可接受的表述。
4. 应用：为县域耕地保护监测从 3.5.4 节匹配表出发写一组方法，并列出两条入库前的检查项。
5. 你的路网数据缺失或不完整。说明这会如何影响可达性分析，并给出替代方案与结论应如何降级表述。
6. 为洪涝风险项目列出敏感性分析要变的三个输入，说明每个变化会改写哪一条结论。
