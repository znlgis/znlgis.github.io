# 第13章 前景（下）：政策主线、技术主线与不确定性

> **本章导读**
>
> 上一章给出的是区间，本章要回答区间靠什么实现——政策、技术、商业模式三支力量。本章对应原报告 6.3—6.6 节：先看政策语义从“基础保障”切换到“时空智能基础设施”之后，四条任务线各自把钱投向哪里（6.3），再看技术演进的六条主线与各自的真实约束（6.4），然后是商业模式迁移（6.5）与三个关键不确定性（6.6）。最实用的一条写在 6.4 节：标准批准滞后厂商实现约 6—18 个月，采购文件因此宜写“支持 3D Tiles 1.1 及后续兼容版本”。

## 学习目标

读完本章，你应当能够：

- 复述 2025 年底“十四五收官”与 2026 年“十五五开局”两个政策口径的差异，并说出“建设智能、融合、安全、优质的时空信息新型基础设施”这条主线；
- 列出 6.3 节四条任务线（国家数字空间基准、实景三维中国、遥感影像统筹、数据要素），各写一条对应的预算投向判断；
- 解释“应用就绪型服务”这一提法对供给方的要求，说明它为什么意味着分析能力要前置到数据产品里；
- 复述 6.4 节六条技术主线，指出哪一条的瓶颈在工具契约而非模型能力，并说明工具契约包含哪些要素；
- 用“标准批准滞后 6—18 个月”这一判断，把一份招标文件里“支持 3D Tiles 2.0”的写法改成更稳妥的表述并说明理由；
- 说出 6.6 节三个不确定性的类型，为每一类举出一个可跟踪的观察对象。

## 6.3 政策主线：从“基础保障”到“时空智能基础设施”

政策语义在 2025—2026 年发生了明显切换。2025 年底的口径是“十四五收官”：实景三维中国初步建成、“全国卫星导航定位基准站一张网”建成运行（整合全国 7000 座基准站，构建“1+32”国家级和省级北斗应用与基准服务中心，日均专业服务超千万次）〔来源：央视新闻／光明网，2025-12-30〕。

2026 年的口径切换到“十五五开局”，主线是**建设智能、融合、安全、优质的时空信息新型基础设施**，加快测绘地理信息数智化转型。四条任务线值得记住：

1. **国家数字空间基准**：新一代毫米级国家坐标框架、全国厘米级似大地水准面模型、基于北斗的坐标与速度场产品、卫星导航信号完好性与地表沉降监测产品。
2. **实景三维中国**：由“初步建成”转向“全面建成”，重点是时序化增量更新、应用生态构建、国地融合形成全国覆盖二三维一体基础数据集。
3. **遥感影像统筹**：公益与商业卫星协同、卫星/航空/无人机多源联动、全国统一基准影像、“应用就绪型服务”。
4. **数据要素**：公共数据授权运营、全国地理信息数据资源“一本账”、“天地图”商业化运营、以地理实体码关联实景三维与行业专题数据。

〔来源：中国自然资源报，2026-08-31（转述自然资源部 2026-08-27 例行新闻发布会）〕

**对分析从业者的含义**：政策重心从“建库”转向“用库”，意味着未来的预算会更多流向“基于已有数据的分析与服务”，而不是“再采集一遍”。同时“应用就绪型服务”这个提法值得注意——它明确要求供给方把数据加工到“可以直接用”的程度，这本质上是把分析能力前置到数据产品里。

## 6.4 技术演进的六条主线

1. **GeoAI 从“模型可用”走向“轻量化可用”**。竞争点从参数量转向少样本适配能力与推理成本。公开研究已出现“小模型在特定任务上优于大模型”的证据（如洪水淹没制图的少样本基准），但适用边界严格，不能外推。
2. **Agent 化空间分析**。真实瓶颈不在模型能力，而在**工具契约**是否机器可读——数据目录、坐标基准、权限、版本。谁先做好“空间数据资产目录 + 可审计工具接口”，谁的 Agent 才可用。
3. **云原生与湖仓一体**。从“上云”到“数据不动算力动”：算法下沉到数据侧（服务端计算）、格式统一到 GeoParquet + Iceberg/Delta + STAC、接口统一到 OGC API。
4. **实时孪生与三维格式收敛**。标准批准滞后于厂商实现约 6—18 个月，形成“标准化慢、工程化快”的双速状态。采购文件写“支持 3D Tiles 2.0”存在合规风险，稳妥写法是“支持 3D Tiles 1.1 及后续兼容版本”。
5. **边缘与星上处理**。高重访星座让“获取”变成常态，“下传—处理—分发”的时延成为瓶颈，星上预处理从概念转向工程，约束是算力与功耗。
6. **隐私计算与空间数据流通**。制度路径是“数据产权登记 + 授权运营 + 禁止出境/禁止转售”；技术路径（联邦学习、可信执行环境、差分隐私）在空间数据上的成熟度低于金融与医疗，**根本卡点是空间数据的价值高度依赖精度**——加噪后往往直接失去分析价值。

## 6.5 商业模式的迁移

| 模式 | 成熟度 | 关键约束 |
|---|---|---|
| 数据即服务（DaaS） | 高 | 授权边界、更新时效承诺 |
| API/用量计费 | 高 | 免费额度策略、跨云出口成本 |
| 行业 SaaS | 中 | 项目制惯性、定制化侵蚀毛利、验收标准缺失 |
| 分析即服务（AaaS） | 低—中 | 结果可信度举证、责任划分、模型漂移 |

**最可能的变化**：Agent 化会把“按调用计费”推向“按任务计费”——客户不再为瓦片付费，而为“一次完成的变化检测任务”付费。计价单位从技术指标转为业务结果，这对收入确认、SLA 设计与责任保险都提出新要求。

## 6.6 三个关键不确定性

1. **口径不确定性**：低空经济与地理信息产业的统计边界是否被统一，直接决定所有规模叙事的可信度。
2. **技术路线不确定性**：3DGS 与 Mesh 的工程取舍、3D Tiles 2.0 的批准时点、地理基础模型“大而全 vs 小而专”的路线之争。
3. **制度不确定性**：数据出境规则与国际数据法的交互，会影响跨国项目的可行边界。

## 本章小结

- 政策重心从“建库”转向“用库”：预算会更多流向基于已有数据的分析与服务，而不是再采集一遍。
- 四条任务线里，数据要素对分析服务商最直接：公共数据授权运营、数据资源“一本账”、“天地图”商业化运营，意味着供给方式在变。
- 技术演进六条主线中，Agent 化的真实瓶颈是工具契约（数据目录、坐标基准、权限、版本）是否机器可读，而不是模型能力。
- 三维格式处于“标准化慢、工程化快”的双速状态：标准批准滞后厂商实现约 6—18 个月，采购文件写“支持 3D Tiles 2.0”存在合规风险，宜写“支持 3D Tiles 1.1 及后续兼容版本”。
- 隐私计算在空间数据上的成熟度低于金融与医疗，根本卡点是空间数据的价值高度依赖精度，加噪后往往直接失去分析价值。
- Agent 化可能把计价单位从技术指标（瓦片、调用次数）推向业务结果（一次完成的变化检测任务），这对收入确认、SLA 与责任保险都提出新要求。

## 思考与练习

1. 找一份所在地区或行业最近发布的空间信息政策文件，用 6.3 节四条任务线归类，指出它属于哪一条、对应哪类预算。
2. 辨析：某招标文件写“必须支持 3D Tiles 2.0”。用 6.4 节判断说明该要求的风险，并写出替代表述。
3. 应用题：为一个城市实景三维项目设计“从建成到用起来”的两项考核指标，写清统计口径与数据来源。
4. 取一个正在评估的 AI 分析工具，按 6.4 节第 2 条检查它的工具契约完备度，写出缺项。
5. 按 6.6 节三个不确定性各列一个可跟踪的公开信息源，并说明多久复核一次。
6. 用 6.5 节迁移表，判断你单位未来两年最该补哪一种模式的哪种能力，并写出一个季度的验证动作。
