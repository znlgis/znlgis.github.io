# 附录B 未核实与待跟踪清单

> **本篇导读**
>
> 本附录汇总正文写作时在公开渠道未取得一手确认的八类条目，正文没有把它们当作事实使用。用途有两个：引用相关数字前先查这里，避免把推算当披露；给后续跟踪留一份带方法的地图——每条都写了当前状态与跟踪方式。它与第 12、13 章的口径讨论配套，凡涉及市场规模、标准批准时点、技术收益倍数的引用，都应回到这里确认证据等级。

以下条目在公开渠道未取得一手确认，正文未作为事实使用，列出供后续跟踪：

| 条目 | 当前状态 | 跟踪方式 |
|---|---|---|
| 3D Tiles 2.0 的正式批准时点 | 2026 年内处于提案/征求意见与定稿过渡期，OGC 标准页截至 2026-11-03 仅列 1.0/1.1 | 定期查 OGC 标准页与 3d-tiles 仓库 |
| 低空经济市场规模口径 | 同一数字在“预测”与“统计”表述间摇摆，未见官方统一口径 | 跟踪民航局与统计部门正式发布 |
| 中国 GIS 企业湖仓/GeoParquet 采用率 | 无公开统计数据 | 关注行业协会调研与厂商披露 |
| 星上处理与边缘推理的量化效益 | 公开可核对比稀少 | 跟踪卫星运营商技术披露 |
| GPU 加速空间分析的收益倍数 | 常用加速库 cuSpatial 已归档（2025-07），社区流传的“10—20 倍”缺少可复现基准 | 以 Sedona SpatialBench 等公开基准为准，不引用二手倍数 |
| 各机构市场预测的基期值 | Grand View 未披露基期，按其终点值与 CAGR 反推约 1170 亿美元，属推算非披露 | 引用时注明“推算”或只引终点值与 CAGR |
| 地理基础模型的空间推理基准 | 已有 GeoBenchX 等公开基准，但尚未形成行业公认的评测共识 | 跟踪学术会议与期刊，注意基准覆盖的任务类型 |
| 各机构全球市场规模预测的基期与边界 | 四家机构 2025—2026 基期值离散约 14%，口径未收敛 | 引用时必带机构、报告名、时间 |

## 使用提醒

- 本清单是“未核实”而非“已否定”：条目可能随时被一手来源证实或修正，正式引用前须重新核对。
- 引用市场预测必须同时带机构、报告名、发布时间与预测期；只有终点值与 CAGR 的，注明是推算而非披露。
- 部分条目状态带时间点（如加速库 cuSpatial 于 2025-07 归档），跨期引用要复核该状态是否仍然成立。
- 与附录 C 配合：清单条目的可跟踪来源在附录 C 中列出，找到一手来源后应同时更新两处，避免一边更正、一边仍引旧说法。
