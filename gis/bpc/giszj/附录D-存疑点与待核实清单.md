# 附录D 存疑点与待核实清单

> **本篇导读**
>
> 这份清单是教程的诚实性附件：正文里无法取得原文确认的条目，都按最保守口径表述，不确定点集中到这里，供正式引用前复核。共十四项，覆盖错漏分值表、样本量分档、修订进度、采标程度、标准编号、吞吐指标等；多数不是查不到，而是只查到二手转载，未见标准正文或公告。后半部分另列五条已核实并修正的条目，便于追溯。

以下条目在公开渠道无法取得原文确认，正文中已按最保守口径表述，建议在正式引用前复核：

1. **GB/T 24356-2023 的错漏分值表**（A 类 / B 类的具体扣分值）——正文只描述“分级扣分”机制，未引用具体数字；公开流传的 42 分 / 12÷t 分口径未核到标准正文表格。
2. **GB/T 24356-2023 表 1 的样本量分档数值**——仅确认“按批量分档”，未取得完整表格，正文未给具体数字。
3. **GB/T 18316 修订稿的报批与预计发布时间**——当前仅确认为征求意见阶段（2025-10 立项）。
4. **GB/T 21336.1-2023 的采标程度代码**（等同 / 修改 / 非等效）——官方页面标注“采用国际标准”，未显示程度代码。
5. **ISO 19157-1:2023 的“第六类质量要素”** ——公开目次仅列五类（8.3.2—8.3.6），正文按“五类 + 扩展机制”表述，未采纳“六类”说法。
6. **ASPRS Edition 2, Version 2（2024）的具体条款号与置信度报告要求**——口径变化方向已确认（USGS 采纳说明与产品页），条款级细节未读原文。
7. **CH/T 9015/9016/9017-2012 是否已有 2023—2025 年替代版本**——未见自然资源部标准发布公告原文。
8. **CJJ 61 的现行版本号与实施日期**——公开报道称修订版 2025-03-01 实施，但来源为企业解读文章，未取得住建部公告原文；正文只称“CJJ 61 体系”。
9. **《城市信息模型数据加工技术标准》的标准编号**——确认住建部 2023 年第 134 号公告与 2024-01-01 实施日期，但标准编号（可能为 CJJ/T 系列）未核。
10. **“8000 万要素 / 日”吞吐指标**——单位公开报道口径，无可复现基准，正文按量级参考处理。
11. **自动质检替代率的量化统计**——无权威公开数据，正文按规则类型分层表述，未给单一百分比。
12. **不动产登记库间一致率数据的统计口径**——数字来自省级通报转载，全库比对的样本范围与计算方式未公开。
13. **低空空域实景三维国标项目的立项编号与进度**——仅确认进入制定流程，未取得计划号。
14. **部分 2026 年条目的页面日期可信度**——若干检索结果的时间戳晚于常规发稿节奏，正文引用时优先采用官方发布会口径与标准发布页。

**已在编制过程中核实并修正的条目**（保留记录以便追溯）：

- GB/T 24356-2023：国家标准全文公开系统确认**发布日期与实施日期均为 2023-05-23**，正文口径正确。
- GB/T 39612-2020：确认标准中文名为《**低空数字航摄与数据处理规范**》（TC230 归口，2020-12-14 发布），早期草稿误写为“低空数字航空摄影规范”，已改正。
- CH/T 9015-2012：确认**发布 2012-10-26、实施 2013-01-01**，正文“2012”标注成立。
- ISO 19157-1 的“第六类质量要素”：按公开目次仅列五类，正文统一为“五类 + 扩展机制”，不采用“六类”表述。
- GB/T 21336.1-2023：确认**2023-11-27 发布并实施**（非 2024 年），正文已按此口径。

## 使用提醒

- 清单条目的含义是“未取得原文”，不是“原文有错”；对外引用时保留不确定性表述，不要自行补一个确定值。
- 凡涉及标准具体数值（错漏分值、样本量分档）的场合，一律以标准正文为准，本教程与附录 C 都不提供替代口径。
- 后半部分“已核实并修正”的条目用于追溯正文可信度，不要与前半部分的存疑项混读成同一类风险。
- 各条目的核实状态有时点，会随标准发布与公告更新而变化；超过一定周期应重新查证，而不是沿用旧结论。
- 若某条存疑直接影响合同条款或验收结论，建议按原文允许的最保守解释执行，并留下书面记录。
