# 附录A 检查项算子清单（精简版）

> **本篇导读**
>
> 这份清单把正文散在第 3—4 章、第 6 章与第 10 章的检查项，按对象类型收成七组算子：矢量几何、拓扑、属性与逻辑、三维、点云、栅格、元数据与合规，每组只给判定与典型阈值，不给实现代码。用法是当规则库骨架：先按成果类型选组，再回正文确定阈值口径，最后把每条算子与标准条款挂上映射。它回答一条检查怎么写成可判定的原子，不回答阈值取多少才对。

**A.1 矢量几何（可直接实现）**

| 算子 | 判定 | 典型阈值 |
| --- | --- | --- |
| 自相交检测 | ST_IsValid = false 且 reason 含 Self-intersection | 0 容忍 |
| 环未闭合 | 首尾节点坐标不等 | 0 容忍 |
| 重复点 | 相邻顶点距离 < ε | ε 按精度等级设定 |
| 极小面积 | ST_Area < 阈值 | 按比例尺（如 1:500 取 0.5 m²） |
| 坐标超范围 | 超出图幅或行政区缓冲 | 按项目 |
| 空几何 / 类型不符 | GeometryType 与图层定义不一致 | 0 容忍 |
| 环方向 | 外壳顺时针、内环逆时针（按规范） | 0 容忍 |

**A.2 拓扑**

| 算子 | 判定 |
| --- | --- |
| 悬挂节点 | 线端点未与任何线/面接触（按图层语义允许的除外） |
| 过头 | 线端点超出应终止的线/面 |
| 缝隙 / 重叠 | 相邻面之间 gap 或 overlap 面积 > 阈值 |
| 覆盖一致性 | 面层并集与范围面差异 > 阈值 |
| 未打断相交 | 线线相交处无节点 |
| 网络连通 | 起点到终点不可达（按网络语义） |

**A.3 属性与逻辑**

必填空值、值域越界、字典编码非法、字段长度超限、唯一性重复、正则格式不符、跨字段条件约束、编码—名称映射不一致、日期逻辑倒挂、层级归属错误、面积/长度汇总守恒偏差超限。

**A.4 三维（3D Tiles / Mesh）**

tileset.json 结构合法、boundingVolume 与内容一致、geometricError 随层级递减、refine 策略匹配、空洞率超限、悬浮物体积超限、纹理分辨率低于下限、UV 越界、瓦片接缝错位超限、LOD 层级缺失、根变换与 CRS 一致。

**A.5 点云**

点密度低于下限、高程中误差超限、粗差率超限、噪声点比例超限、拼接错位超限、分类混淆矩阵各类精度低于阈值、覆盖空洞面积超限。

**A.6 栅格**

COG 结构合法、概览层级缺失、NoData 不一致、无效值比例超限、云量与云影比例超限、接边色差超限、DEM 中误差超限与粗差（尖峰/漏斗）、格网间距不符。

**A.7 元数据与合规**

元数据必填项缺失、CRS 声明与实际不符、密级标注缺失或矛盾、审图号缺失或版本错配、公开分辨率优于 0.5 米、位置字段未最小化、对外提供未审批。

## 使用提醒

- 这是精简版，只列常用算子，不等于检查项全集；正式规则库应按对应标准逐条补齐，不宜把本附录直接当验收依据。
- 阈值一列多为占位写法（如“按比例尺”“按项目”“按精度等级设定”），引用时必须替换为项目适用标准或合同约定的具体数值。
- 每条算子应能回溯到具体标准条款编号，否则争议时无法举证“这条检查项从何而来”。
- A.7 组含合规判定项，其中密级标注、审图号版本、公开分辨率、对外提供审批属阻断级；建议与质量规则分开管理层级与签署责任，不要只统计命中数量。
- 算子随标准换版调整，规则库需记录版本号与生效日期，保证历史结论可回放。
