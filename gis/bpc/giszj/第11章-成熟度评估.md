# 第11章 成熟度评估：不同环节处在什么阶段

> **本章导读**
>
> 这一章只有一张表，作用是把“我们到底处在什么阶段”这个笼统问题变成可以对照的坐标。原报告第 7 节的五级成熟度以 L1 起步、L2 试点、L3 可规模化应用、L4 已工程化标定主级，整数级之间再以 .5 标注过渡，给十一类环节逐一标出位置：同一时刻，二维几何与拓扑已在 L4，三维语义与表征质量仍在 L2，两者的落差就是投入方向。用法很直接：听到“我们的质检已经全面智能化”，先问它在说哪一行，多数宣称落在 L3 与 L2，L4 只在二维与拓扑层面成立。表后还有三处最值得投入的升级，那是本章的行动部分。

## 学习目标

读完本章，你应当能够：

- 用一句话说明成熟度表解决什么问题，并举出表中两个相差至少一级的环节说明差距在哪；
- 复述 L1 起步、L2 试点、L3 可规模化应用、L4 已工程化四个主级的判据差别（有无成熟算法、规则能否配置、结果能否复现）；
- 对照表格判断“质检已经全面智能化”这类宣称通常落在哪一级，并指出最常见的错位；
- 按表后提示写出三维语义质量从 L2 升到 L3 需转成可计算指标的三项（空洞率、悬浮物体积阈值、纹理分辨率下限）；
- 取你所在单位一项具体质检环节，用表的三列（环节、成熟度、判断依据）为它定位并写出理由。

用五级成熟度给质检体系的各个环节定位，可以避免“整体先进/整体落后”这类无信息量的判断。

| 环节 | 成熟度 | 判断依据 |
| --- | --- | --- |
| 二维几何与属性检查 | **L4 已工程化** | 有成熟算法与工具库，规则可配置，结果可复现 |
| 拓扑与接边检查 | **L4 已工程化** | 空间数据库与拓扑扩展支持，需注意分块边界假阳性 |
| 影像与栅格检查 | **L3.5 接近工程化** | 元数据、NoData、云量、色差可自动；匀色与接缝仍需人工确认 |
| 三维 Mesh 结构检查 | **L3 可规模化应用** | 3D Tiles 结构、LOD 单调性、瓦片索引可全自动；表面缺陷半自动 |
| 三维语义与表征质量 | **L2 试点** | “悬浮物/纹理真实感”缺量化判据，依赖人机交互 |
| 点云分类正确性 | **L2.5 部分可用** | 混淆矩阵可评估，但跨区域模型泛化差 |
| BIM 语义映射质量 | **L1.5 起步** | 缺通用标准，依赖项目约定 |
| 时序与实时质检 | **L2 试点** | 需与可观测性体系融合，尚无通用规范 |
| AI 疑似缺陷发现 | **L3 可规模化应用（限召回）** | 已在大规模业务中产生可测增益，但不能独立判定 |
| AI 独立验收判定 | **L1 不具备条件** | 技术与制度双重约束 |
| 合规自动化检查 | **L2.5 部分可用** | 密级与审图号可机检，语义级合规仍需人判 |

**这张表的用法**：如果有人说“我们的质检已经全面智能化”，对照上表就能定位他在说哪一行。多数宣称对应的是 L3（可规模化应用）与 L2（试点），而 L4 只在二维与拓扑层面成立。

**最值得投入的三处升级**：

1. **三维语义与表征质量（L2 → L3）**：把已经存在的团标要求转成可计算指标（空洞率、悬浮物体积阈值、纹理分辨率下限），能显著降低人工判读量。
2. **点云分类正确性（L2.5 → L3.5）**：把“已知地物检查区 + 混淆矩阵”标准化为常规检测项，并在 DEM 成果上做二次校验。
3. **合规自动化（L2.5 → L3.5）**：审图号版本一致性、密级标注、0.5 米分辨率、脱敏字段这类判断规则明确，最适合做成阻断级门禁。

## 本章小结

- 成熟度表的第一用途是定位而不是评价：先确定讨论的是哪一行，再谈智能化才有意义；否则“先进”与“落后”都是无信息量的判断。
- 当前工程化程度最高的是二维几何与属性检查、拓扑与接边检查，均在 L4；这两项的共同点是规则可配置、结果可复现。
- 三维结构检查已达 L3，三维语义与表征质量仍在 L2——“悬浮物”“纹理真实感”缺少量化判据，只能依赖人机交互。
- AI 的两个用途必须分开评级：疑似缺陷发现处于 L3（限召回、不能独立判定），独立验收判定处于 L1（技术与制度双重约束）。
- 最值得投入的三处升级是三维语义与表征质量、点云分类正确性、合规自动化，共同点是把已有标准要求转成可计算阈值。
- 合规自动化最适合做成阻断级门禁，因为审图号版本一致性、密级标注、0.5 米分辨率、脱敏字段这几类判断规则明确、后果严重。

## 思考与练习

1. 从表中任选两个相差至少一级的环节，写出它们差在哪一列上，并说明升级的关键动作。
2. 辨析：有人说“AI 已经能判缺陷，所以人工复核可以取消”。用表中 AI 两行的评级说明这句话混淆了哪两件事。
3. 取你所在单位一项三维或点云质检环节，按表中“判断依据”一列的写法补一条自己的判据。
4. 应用题：某单位要把合规自动化从 L2.5 提升到 L3.5，按表后第 3 条列出至少四项必须先固定的规则及其阈值来源。
5. 用表格为所在单位最弱的一个环节定位，并写出若要在两年内升一级，需要补齐的三项能力。
