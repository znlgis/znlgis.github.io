# 第04章：空间参考系统

## 4.1 空间参考系统概述

### 4.1.1 什么是空间参考系统

空间参考系统（Spatial Reference System，SRS）也称为坐标参考系统（Coordinate Reference System，CRS），是用于确定地理位置的数学框架。它定义了如何将地球表面的位置（三维）映射到平面坐标系统（二维）或保持为地理坐标（经纬度）。

空间参考系统包含以下核心要素：

```
┌─────────────────────────────────────────────────────────────┐
│                   空间参考系统组成                           │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 大地基准面 (Datum)                                       │
│     ├── 参考椭球体 (Ellipsoid)                              │
│     │   ├── 长半轴 (a)                                      │
│     │   └── 扁率 (f) 或 短半轴 (b)                          │
│     └── 基准点和方向定义                                     │
│                                                             │
│  2. 坐标系统 (Coordinate System)                            │
│     ├── 地理坐标系 (Geographic CRS)                         │
│     │   ├── 经度 (Longitude)                                │
│     │   └── 纬度 (Latitude)                                 │
│     └── 投影坐标系 (Projected CRS)                          │
│         ├── 投影方法                                        │
│         ├── 投影参数                                        │
│         └── 单位 (米/英尺等)                                │
│                                                             │
│  3. 坐标轴 (Axes)                                           │
│     ├── 轴方向                                              │
│     └── 轴顺序                                              │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 4.1.2 SRID 详解

SRID（Spatial Reference System Identifier）是空间参考系统的唯一标识符。在 PostGIS 中，SRID 存储在 `spatial_ref_sys` 表中。

```sql
-- 查看 spatial_ref_sys 表结构
\d spatial_ref_sys

-- 查询常用的 SRID
SELECT srid, auth_name, auth_srid, 
       substring(srtext, 1, 100) AS srtext_preview
FROM spatial_ref_sys
WHERE srid IN (4326, 3857, 4490, 4527, 4528, 4549)
ORDER BY srid;

-- SRID 字段说明
-- srid: PostGIS 内部使用的标识符
-- auth_name: 权威机构名称（如 EPSG）
-- auth_srid: 权威机构定义的标识符
-- srtext: WKT 格式的完整定义
-- proj4text: PROJ 格式的定义
```

### 4.1.3 常用 SRID

| SRID | 名称 | 类型 | 适用范围 | 单位 |
|------|------|------|----------|------|
| 4326 | WGS 84 | 地理坐标系 | 全球 | 度 |
| 3857 | Web Mercator | 投影坐标系 | 全球网络地图 | 米 |
| 4490 | CGCS2000 | 地理坐标系 | 中国 | 度 |
| 4527 | CGCS2000 Zone 39 | 投影坐标系 | 中国（114°-120°） | 米 |
| 4528 | CGCS2000 Zone 40 | 投影坐标系 | 中国（120°-126°） | 米 |
| 2436 | Beijing 1954 Zone 18 | 投影坐标系 | 中国（102°-108°） | 米 |
| 32650 | UTM Zone 50N | 投影坐标系 | 114°E-120°E | 米 |

## 4.2 地理坐标系

### 4.2.1 WGS 84 (EPSG:4326)

WGS 84（World Geodetic System 1984）是目前最广泛使用的全球地理坐标系，也是 GPS 系统使用的坐标系。

```sql
-- 查看 WGS 84 定义
SELECT srtext, proj4text
FROM spatial_ref_sys
WHERE srid = 4326;

-- WGS 84 参数
-- 椭球体: WGS 84
-- 长半轴: 6378137.0 米
-- 扁率: 1/298.257223563
-- 本初子午线: 格林威治

-- 创建使用 WGS 84 的表
CREATE TABLE wgs84_points (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100),
    geom GEOMETRY(POINT, 4326)
);

-- 插入数据（注意：经度在前，纬度在后）
INSERT INTO wgs84_points (name, geom) VALUES
    ('北京', ST_SetSRID(ST_MakePoint(116.4074, 39.9042), 4326)),
    ('伦敦', ST_SetSRID(ST_MakePoint(-0.1276, 51.5074), 4326)),
    ('东京', ST_SetSRID(ST_MakePoint(139.6917, 35.6895), 4326));

-- WGS 84 的坐标范围
-- 经度: -180 到 180
-- 纬度: -90 到 90
```

### 4.2.2 CGCS2000 (EPSG:4490)

CGCS2000（China Geodetic Coordinate System 2000）是中国国家大地坐标系。

```sql
-- 查看 CGCS2000 定义
SELECT srtext, proj4text
FROM spatial_ref_sys
WHERE srid = 4490;

-- 如果没有 4490，需要手动添加
INSERT INTO spatial_ref_sys (srid, auth_name, auth_srid, srtext, proj4text) VALUES
(4490, 'EPSG', 4490,
'GEOGCS["China Geodetic Coordinate System 2000",
    DATUM["China_2000",
        SPHEROID["CGCS2000",6378137,298.257222101,
            AUTHORITY["EPSG","1024"]],
        AUTHORITY["EPSG","1043"]],
    PRIMEM["Greenwich",0,
        AUTHORITY["EPSG","8901"]],
    UNIT["degree",0.0174532925199433,
        AUTHORITY["EPSG","9122"]],
    AUTHORITY["EPSG","4490"]]',
'+proj=longlat +ellps=GRS80 +no_defs')
ON CONFLICT (srid) DO NOTHING;

-- CGCS2000 参数
-- 椭球体: CGCS2000 (GRS80)
-- 长半轴: 6378137.0 米
-- 扁率: 1/298.257222101

-- 创建使用 CGCS2000 的表
CREATE TABLE cgcs2000_points (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100),
    geom GEOMETRY(POINT, 4490)
);
```

### 4.2.3 WGS 84 与 CGCS2000 的关系

WGS 84 和 CGCS2000 使用非常相似的椭球体参数，在大多数应用场景下可以认为是一致的：

| 参数 | WGS 84 | CGCS2000 |
|------|--------|----------|
| 长半轴 (a) | 6378137.0 m | 6378137.0 m |
| 扁率 (1/f) | 298.257223563 | 298.257222101 |
| 差异 | - | 约 0.1mm 级别 |

```sql
-- 实际应用中的转换（几乎无差异）
SELECT 
    ST_AsText(ST_Transform(
        ST_SetSRID(ST_MakePoint(116.4, 39.9), 4326),
        4490
    )) AS cgcs2000_point;

-- 注意：虽然理论上存在差异，但在实际应用中
-- 可以直接将 SRID 从 4326 改为 4490 而不进行坐标转换
```

### 4.3.2 Web 墨卡托 (EPSG:3857)

Web 墨卡托是网络地图的标准投影，被 Google Maps、OpenStreetMap、高德、百度等广泛使用。

```sql
-- 查看 Web 墨卡托定义
SELECT srtext, proj4text
FROM spatial_ref_sys
WHERE srid = 3857;

-- Web 墨卡托特点
-- 投影方法: 伪墨卡托 (Pseudo-Mercator)
-- 适用范围: 纬度 -85.06° 到 85.06°
-- 单位: 米
-- 坐标范围: -20037508.34 到 20037508.34

-- 将 WGS 84 坐标转换为 Web 墨卡托
SELECT ST_AsText(ST_Transform(
    ST_SetSRID(ST_MakePoint(116.4074, 39.9042), 4326),
    3857
)) AS web_mercator;
-- 结果: POINT(12958456.8 4852386.6)

-- 创建 Web 墨卡托表
CREATE TABLE web_mercator_features (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100),
    geom GEOMETRY(GEOMETRY, 3857)
);

-- 计算面积（Web 墨卡托会产生面积变形）
-- 不推荐直接用于面积计算
SELECT 
    ST_Area(ST_Transform(geom, 3857)) AS area_mercator_m2,
    ST_Area(geom::geography) AS area_geodetic_m2
FROM districts LIMIT 1;
```

### 4.3.3 UTM 投影

UTM（Universal Transverse Mercator）是将地球分为 60 个带的投影系统。

```sql
-- UTM 带号计算
-- 带号 = floor((经度 + 180) / 6) + 1

-- 北京 (116.4°E) 在 UTM Zone 50N
SELECT floor((116.4 + 180) / 6) + 1 AS utm_zone;
-- 结果: 50

-- UTM Zone 50N 的 SRID: 32650
SELECT srtext FROM spatial_ref_sys WHERE srid = 32650;

-- 转换到 UTM
SELECT ST_AsText(ST_Transform(
    ST_SetSRID(ST_MakePoint(116.4074, 39.9042), 4326),
    32650
)) AS utm_coords;
-- 结果: POINT(453578.7 4417735.5)

-- UTM 坐标说明
-- X (Easting): 相对于中央经线向东的距离，假东偏移 500000 米
-- Y (Northing): 相对于赤道向北的距离
```

### 4.3.4 高斯-克吕格投影

中国常用的高斯-克吕格（Gauss-Kruger）投影：

```sql
-- CGCS2000 3度带投影
-- 带号 = floor(经度 / 3)
-- 中央经线 = 带号 * 3

-- 北京 (116.4°E) 在 39 带（中央经线 117°E）
SELECT floor(116.4 / 3) AS zone_num;
-- 结果: 38，实际使用 39 带

-- CGCS2000 3度带 Zone 39 (SRID: 4527)
SELECT srtext FROM spatial_ref_sys WHERE srid = 4527;

-- 如果不存在，添加定义
INSERT INTO spatial_ref_sys (srid, auth_name, auth_srid, srtext, proj4text) VALUES
(4527, 'EPSG', 4527,
'PROJCS["CGCS2000 / 3-degree Gauss-Kruger zone 39",
    GEOGCS["China Geodetic Coordinate System 2000",
        DATUM["China_2000",
            SPHEROID["CGCS2000",6378137,298.257222101]],
        PRIMEM["Greenwich",0],
        UNIT["degree",0.0174532925199433]],
    PROJECTION["Transverse_Mercator"],
    PARAMETER["latitude_of_origin",0],
    PARAMETER["central_meridian",117],
    PARAMETER["scale_factor",1],
    PARAMETER["false_easting",39500000],
    PARAMETER["false_northing",0],
    UNIT["metre",1]]',
'+proj=tmerc +lat_0=0 +lon_0=117 +k=1 +x_0=39500000 +y_0=0 +ellps=GRS80 +units=m +no_defs')
ON CONFLICT (srid) DO NOTHING;

-- 转换示例
SELECT ST_AsText(ST_Transform(
    ST_SetSRID(ST_MakePoint(116.4074, 39.9042), 4326),
    4527
)) AS gauss_kruger_coords;
```

## 4.4 坐标转换

### 4.4.1 ST_Transform 函数

```sql
-- 基本语法
ST_Transform(geometry, target_srid)
ST_Transform(geometry, from_proj4, to_proj4)
ST_Transform(geometry, from_proj4, to_srid)

-- WGS 84 转 Web 墨卡托
SELECT ST_Transform(
    ST_SetSRID(ST_MakePoint(116.4074, 39.9042), 4326),
    3857
);

-- Web 墨卡托 转 WGS 84
SELECT ST_Transform(
    ST_SetSRID(ST_MakePoint(12958456.8, 4852386.6), 3857),
    4326
);

-- 使用 PROJ 字符串转换
SELECT ST_Transform(
    ST_SetSRID(ST_MakePoint(116.4074, 39.9042), 4326),
    '+proj=longlat +datum=WGS84 +no_defs',
    '+proj=merc +a=6378137 +b=6378137 +lat_ts=0.0 +lon_0=0.0 +x_0=0.0 +y_0=0 +k=1.0 +units=m +no_defs'
);
```

### 4.4.2 批量坐标转换

```sql
-- 创建转换后的表
CREATE TABLE poi_3857 AS
SELECT 
    id,
    name,
    ST_Transform(geom, 3857) AS geom
FROM poi;

-- 添加索引
CREATE INDEX idx_poi_3857_geom ON poi_3857 USING GIST (geom);

-- 更新现有表的 SRID
UPDATE poi 
SET geom = ST_Transform(geom, 4490)
WHERE ST_SRID(geom) = 4326;

-- 使用 ALTER TABLE 改变 SRID（仅改变元数据，不转换坐标）
-- 警告：这只改变 SRID 标记，不会转换实际坐标！
-- 仅在 CGCS2000 和 WGS84 等兼容坐标系之间使用
ALTER TABLE poi
ALTER COLUMN geom TYPE GEOMETRY(POINT, 4490)
USING ST_SetSRID(geom, 4490);
```

### 4.4.3 坐标转换性能优化

```sql
-- 对于大量数据，使用批量处理
-- 方法1：使用 COPY 和临时表
CREATE TEMP TABLE temp_transformed AS
SELECT id, ST_Transform(geom, 3857) AS geom
FROM large_table;

-- 方法2：分批更新
DO $$
DECLARE
    batch_size INT := 10000;
    offset_val INT := 0;
    row_count INT;
BEGIN
    LOOP
        UPDATE large_table t
        SET geom = ST_Transform(t.geom, 3857)
        FROM (
            SELECT id FROM large_table
            ORDER BY id
            LIMIT batch_size OFFSET offset_val
        ) sub
        WHERE t.id = sub.id AND ST_SRID(t.geom) != 3857;
        
        GET DIAGNOSTICS row_count = ROW_COUNT;
        EXIT WHEN row_count = 0;
        
        offset_val := offset_val + batch_size;
        COMMIT;
        RAISE NOTICE 'Processed % rows', offset_val;
    END LOOP;
END $$;

-- 方法3：并行处理（PostgreSQL 11+）
SET max_parallel_workers_per_gather = 4;
SELECT ST_Transform(geom, 3857) FROM large_table;
```

### 4.4.4 七参数转换

在中国，北京54、西安80、CGCS2000 之间的转换需要使用七参数转换：

```sql
-- 七参数 (Helmert/Bursa-Wolf 转换)
-- 参数: ΔX, ΔY, ΔZ (平移)
--       Rx, Ry, Rz (旋转，弧度)
--       S (尺度因子)

-- 使用 PROJ 字符串进行七参数转换
-- 示例：Beijing 1954 到 WGS 84 (参数需根据实际区域确定)
SELECT ST_Transform(
    ST_SetSRID(ST_MakePoint(500000, 4400000), 2436),
    '+proj=tmerc +lat_0=0 +lon_0=105 +k=1 +x_0=18500000 +y_0=0 +ellps=krass +towgs84=11,-97.4,-119.6,0,0,0,0 +units=m +no_defs',
    4326
);

-- 注意：七参数转换精度取决于：
-- 1. 转换参数的准确性
-- 2. 数据的原始精度
-- 3. 适用范围

-- 推荐使用中国测绘部门提供的官方转换参数
```

### 4.5.3 火星坐标系 (GCJ-02)

GCJ-02 是中国国家测绘局制定的坐标加密标准，高德、腾讯地图使用此坐标系。

```sql
-- 注意：GCJ-02 是非线性加密，不能使用标准的坐标转换
-- 需要使用专门的算法进行转换

-- 创建 WGS84 转 GCJ-02 函数
CREATE OR REPLACE FUNCTION wgs84_to_gcj02(lon NUMERIC, lat NUMERIC)
RETURNS TABLE(gcj_lon NUMERIC, gcj_lat NUMERIC) AS $$
DECLARE
    a NUMERIC := 6378245.0;
    ee NUMERIC := 0.00669342162296594323;
    pi NUMERIC := 3.14159265358979324;
    dLat NUMERIC;
    dLon NUMERIC;
    radLat NUMERIC;
    magic NUMERIC;
    sqrtMagic NUMERIC;
BEGIN
    IF lon < 72.004 OR lon > 137.8347 OR lat < 0.8293 OR lat > 55.8271 THEN
        -- 中国范围外，直接返回原坐标
        RETURN QUERY SELECT lon, lat;
        RETURN;
    END IF;
    
    dLat := transform_lat(lon - 105.0, lat - 35.0);
    dLon := transform_lon(lon - 105.0, lat - 35.0);
    radLat := lat / 180.0 * pi;
    magic := sin(radLat);
    magic := 1 - ee * magic * magic;
    sqrtMagic := sqrt(magic);
    dLat := (dLat * 180.0) / ((a * (1 - ee)) / (magic * sqrtMagic) * pi);
    dLon := (dLon * 180.0) / (a / sqrtMagic * cos(radLat) * pi);
    
    RETURN QUERY SELECT lon + dLon, lat + dLat;
END;
$$ LANGUAGE plpgsql;

-- 辅助函数
CREATE OR REPLACE FUNCTION transform_lat(x NUMERIC, y NUMERIC)
RETURNS NUMERIC AS $$
DECLARE
    pi NUMERIC := 3.14159265358979324;
    ret NUMERIC;
BEGIN
    ret := -100.0 + 2.0 * x + 3.0 * y + 0.2 * y * y + 0.1 * x * y + 0.2 * sqrt(abs(x));
    ret := ret + (20.0 * sin(6.0 * x * pi) + 20.0 * sin(2.0 * x * pi)) * 2.0 / 3.0;
    ret := ret + (20.0 * sin(y * pi) + 40.0 * sin(y / 3.0 * pi)) * 2.0 / 3.0;
    ret := ret + (160.0 * sin(y / 12.0 * pi) + 320 * sin(y * pi / 30.0)) * 2.0 / 3.0;
    RETURN ret;
END;
$$ LANGUAGE plpgsql;

CREATE OR REPLACE FUNCTION transform_lon(x NUMERIC, y NUMERIC)
RETURNS NUMERIC AS $$
DECLARE
    pi NUMERIC := 3.14159265358979324;
    ret NUMERIC;
BEGIN
    ret := 300.0 + x + 2.0 * y + 0.1 * x * x + 0.1 * x * y + 0.1 * sqrt(abs(x));
    ret := ret + (20.0 * sin(6.0 * x * pi) + 20.0 * sin(2.0 * x * pi)) * 2.0 / 3.0;
    ret := ret + (20.0 * sin(x * pi) + 40.0 * sin(x / 3.0 * pi)) * 2.0 / 3.0;
    ret := ret + (150.0 * sin(x / 12.0 * pi) + 300.0 * sin(x / 30.0 * pi)) * 2.0 / 3.0;
    RETURN ret;
END;
$$ LANGUAGE plpgsql;

-- 使用示例
SELECT * FROM wgs84_to_gcj02(116.4074, 39.9042);
```

### 4.5.4 百度坐标系 (BD-09)

```sql
-- BD-09 是在 GCJ-02 基础上再次加密的坐标系
CREATE OR REPLACE FUNCTION gcj02_to_bd09(lon NUMERIC, lat NUMERIC)
RETURNS TABLE(bd_lon NUMERIC, bd_lat NUMERIC) AS $$
DECLARE
    x_pi NUMERIC := 3.14159265358979324 * 3000.0 / 180.0;
    z NUMERIC;
    theta NUMERIC;
BEGIN
    z := sqrt(lon * lon + lat * lat) + 0.00002 * sin(lat * x_pi);
    theta := atan2(lat, lon) + 0.000003 * cos(lon * x_pi);
    RETURN QUERY SELECT z * cos(theta) + 0.0065, z * sin(theta) + 0.006;
END;
$$ LANGUAGE plpgsql;

-- WGS84 直接转 BD-09
CREATE OR REPLACE FUNCTION wgs84_to_bd09(lon NUMERIC, lat NUMERIC)
RETURNS TABLE(bd_lon NUMERIC, bd_lat NUMERIC) AS $$
BEGIN
    RETURN QUERY
    SELECT g.gcj_lon, g.gcj_lat
    FROM wgs84_to_gcj02(lon, lat) g
    CROSS JOIN LATERAL gcj02_to_bd09(g.gcj_lon, g.gcj_lat);
END;
$$ LANGUAGE plpgsql;
```

## 4.6 坐标系管理最佳实践

### 4.6.1 数据存储建议

```sql
-- 1. 原始数据使用地理坐标系存储
CREATE TABLE spatial_data (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100),
    geom GEOMETRY(GEOMETRY, 4326)  -- 或 4490 (CGCS2000)
);

-- 2. 为高性能查询创建投影视图
CREATE MATERIALIZED VIEW spatial_data_mercator AS
SELECT id, name, ST_Transform(geom, 3857) AS geom
FROM spatial_data;

CREATE INDEX idx_spatial_data_mercator_geom 
ON spatial_data_mercator USING GIST (geom);

-- 3. 刷新物化视图
REFRESH MATERIALIZED VIEW spatial_data_mercator;

-- 4. 创建自动刷新触发器
CREATE OR REPLACE FUNCTION refresh_mercator_view()
RETURNS TRIGGER AS $$
BEGIN
    REFRESH MATERIALIZED VIEW CONCURRENTLY spatial_data_mercator;
    RETURN NULL;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER trigger_refresh_mercator
AFTER INSERT OR UPDATE OR DELETE ON spatial_data
FOR EACH STATEMENT EXECUTE FUNCTION refresh_mercator_view();
```

### 4.6.2 坐标验证

```sql
-- 验证坐标是否在有效范围内
CREATE OR REPLACE FUNCTION validate_coordinates(
    lon NUMERIC, 
    lat NUMERIC, 
    srid INT DEFAULT 4326
)
RETURNS BOOLEAN AS $$
BEGIN
    CASE srid
        WHEN 4326, 4490 THEN
            -- WGS84 / CGCS2000
            RETURN lon >= -180 AND lon <= 180 AND lat >= -90 AND lat <= 90;
        WHEN 3857 THEN
            -- Web Mercator
            RETURN lon >= -20037508.34 AND lon <= 20037508.34 
               AND lat >= -20037508.34 AND lat <= 20037508.34;
        ELSE
            RETURN TRUE;
    END CASE;
END;
$$ LANGUAGE plpgsql;

-- 检查中国范围
CREATE OR REPLACE FUNCTION is_in_china(lon NUMERIC, lat NUMERIC)
RETURNS BOOLEAN AS $$
BEGIN
    RETURN lon >= 73.5 AND lon <= 135.0 
       AND lat >= 3.8 AND lat <= 53.5;
END;
$$ LANGUAGE plpgsql;

-- 创建约束
ALTER TABLE spatial_data ADD CONSTRAINT check_coordinates
CHECK (validate_coordinates(ST_X(geom), ST_Y(geom), ST_SRID(geom)));
```

### 4.6.3 SRID 自动检测和转换

```sql
-- 根据坐标值自动检测可能的 SRID
CREATE OR REPLACE FUNCTION detect_srid(x NUMERIC, y NUMERIC)
RETURNS INT AS $$
BEGIN
    -- 经纬度范围 (WGS84/CGCS2000)
    IF x >= -180 AND x <= 180 AND y >= -90 AND y <= 90 THEN
        RETURN 4326;
    END IF;
    
    -- Web Mercator 范围
    IF x >= -20037508.34 AND x <= 20037508.34 
       AND y >= -20037508.34 AND y <= 20037508.34 
       AND (abs(x) > 180 OR abs(y) > 90) THEN
        RETURN 3857;
    END IF;
    
    -- CGCS2000 投影坐标（带号 + 500000）
    IF x > 13000000 AND x < 46000000 AND y > 0 AND y < 10000000 THEN
        -- 3度带，返回大概的 SRID
        RETURN 4513 + floor(x / 1000000) - 13;
    END IF;
    
    RETURN 0;  -- 未知
END;
$$ LANGUAGE plpgsql;

-- 自动转换函数
CREATE OR REPLACE FUNCTION auto_transform_to_wgs84(geom GEOMETRY)
RETURNS GEOMETRY AS $$
DECLARE
    srid INT;
BEGIN
    srid := ST_SRID(geom);
    IF srid = 0 THEN
        srid := detect_srid(ST_X(ST_Centroid(geom)), ST_Y(ST_Centroid(geom)));
        geom := ST_SetSRID(geom, srid);
    END IF;
    
    IF srid != 4326 AND srid != 0 THEN
        RETURN ST_Transform(geom, 4326);
    END IF;
    
    RETURN geom;
END;
$$ LANGUAGE plpgsql;
```
