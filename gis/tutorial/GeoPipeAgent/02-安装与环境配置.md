# 第二章：安装与环境配置

## 2.1 系统要求

在开始安装 GeoPipeAgent 之前，请确保满足以下基本要求：

| 要求项 | 最低版本 | 推荐版本 |
|--------|----------|----------|
| Python | 3.10 | 3.11 / 3.12 |
| pip | 22.0+ | 最新版 |
| 操作系统 | Windows 10 / macOS 10.15 / Ubuntu 20.04 | 最新 LTS 版本 |

GeoPipeAgent 的核心库（native_python 后端）依赖 GeoPandas、Shapely、rasterio 等纯 Python 空间计算库，安装相对简单。如果需要使用 GDAL CLI 后端、QGIS 后端，还需要在系统中额外安装对应工具。

## 2.2 创建虚拟环境（推荐）

强烈建议使用虚拟环境隔离项目依赖，避免与系统其他包冲突。

### 使用 venv（Python 内置）

```bash
# 创建虚拟环境
python -m venv .venv

# 激活虚拟环境（Linux / macOS）
source .venv/bin/activate

# 激活虚拟环境（Windows CMD）
.venv\Scripts\activate.bat

# 激活虚拟环境（Windows PowerShell）
.venv\Scripts\Activate.ps1
```

### 使用 conda（推荐用于 GIS 开发）

conda 生态对地理空间依赖（GDAL、Fiona、Proj 等）支持更好，推荐 GIS 开发者使用：

```bash
# 创建 conda 环境
conda create -n geopipe python=3.11 -y
conda activate geopipe

# 使用 conda-forge 安装 GDAL（可选，用于 gdal_python 后端）
conda install -c conda-forge gdal -y
```

## 2.3 安装 GeoPipeAgent

### 2.3.1 基础安装

从源码安装（开发模式）：

```bash
# 克隆仓库
git clone https://github.com/znlgis/GeoPipeAgent.git
cd GeoPipeAgent

# 基础安装（仅核心功能）
pip install -e .
```

基础安装包含的核心依赖：
- `geopandas`：矢量数据处理
- `rasterio`：栅格数据处理
- `shapely`：几何计算
- `pyproj`：坐标参考系转换
- `pyyaml`：YAML 解析
- `click`：CLI 框架
- `pydantic`：数据模型验证

### 2.3.2 安装可选依赖

GeoPipeAgent 将部分功能性依赖设计为可选组，根据需要按需安装：

```bash
# 安装全部可选依赖（推荐开发和学习时使用）
pip install -e ".[dev,analysis,network,web]"
```

各可选依赖组说明：

| 依赖组 | 安装命令 | 包含的包 | 解锁的功能 |
|--------|----------|----------|-----------|
| `dev` | `pip install -e ".[dev]"` | pytest, pytest-cov | 开发调试、运行测试 |
| `analysis` | `pip install -e ".[analysis]"` | scipy, scikit-learn, matplotlib | 空间分析步骤（泰森多边形、热力图、插值、聚类） |
| `network` | `pip install -e ".[network]"` | networkx, geopy | 网络分析步骤（最短路径、服务区、地理编码） |
| `web` | `pip install -e ".[web]"` | fastapi, uvicorn, openai, sse-starlette | Web UI 后端服务 |

### 2.3.3 验证安装

安装完成后，通过以下命令验证：

```bash
# 检查 CLI 工具是否可用
geopipe-agent --version

# 列出所有内置步骤
geopipe-agent list-steps

# 查看可用后端
geopipe-agent backends
```

正常输出示例：

```
$ geopipe-agent list-steps
io.read_vector          读取矢量数据
io.write_vector         写入矢量数据
io.read_raster          读取栅格数据
io.write_raster         写入栅格数据
vector.buffer           缓冲区分析
vector.clip             矢量裁剪
...（共 33 个步骤）
```

## 2.4 各后端的额外配置

### 2.4.1 native_python 后端（默认，开箱即用）

默认后端，依赖 GeoPandas + Shapely，随基础安装自动就绪，无需额外配置。

```bash
# 验证默认后端是否正常
python -c "import geopandas; print(geopandas.__version__)"
python -c "import rasterio; print(rasterio.__version__)"
```

### 2.4.2 gdal_cli 后端

`gdal_cli` 后端调用系统中安装的 GDAL CLI 工具（`ogr2ogr`、`gdal_translate` 等）。

**Linux（Ubuntu/Debian）安装 GDAL**：

```bash
sudo apt-get update
sudo apt-get install gdal-bin -y

# 验证
ogr2ogr --version
```

**macOS 使用 Homebrew 安装**：

```bash
brew install gdal

# 验证
ogr2ogr --version
```

**Windows 推荐使用 OSGeo4W**：

访问 [https://trac.osgeo.org/osgeo4w/](https://trac.osgeo.org/osgeo4w/) 下载 OSGeo4W 安装器，选择 GDAL 组件安装。安装后将 GDAL bin 目录添加到 `PATH` 环境变量中。

**验证 gdal_cli 后端**：

```bash
geopipe-agent backends
# 应看到 gdal_cli 状态为 available
```

### 2.4.3 gdal_python 后端

`gdal_python` 后端使用 GDAL 的 Python 绑定（`osgeo.gdal`、`osgeo.ogr`）。

**推荐通过 conda-forge 安装**：

```bash
conda install -c conda-forge gdal python-gdal -y
# 或
pip install gdal==$(gdal-config --version)
```

**验证**：

```bash
python -c "from osgeo import gdal, ogr; print(gdal.__version__)"
```

### 2.4.4 qgis_process 和 pyqgis 后端

这两个后端需要在系统中安装 QGIS。

**Linux 安装 QGIS**：

```bash
sudo apt-get install qgis -y
```

**macOS 下载 QGIS**：访问 [https://www.qgis.org/](https://www.qgis.org/) 下载安装包。

安装完成后，检查 `qgis_process` 命令是否在 PATH 中：

```bash
qgis_process --version
```

对于 `pyqgis` 后端，还需要将 PyQGIS 的路径添加到 Python 的 `sys.path`，具体路径因操作系统和安装方式而异。

### 2.4.5 generic_cli 后端

`generic_cli` 后端允许调用任意系统命令行工具，无需额外安装，通过 YAML 中的 `command` 参数指定要执行的命令。

### 2.4.6 curl_api 后端

`curl_api` 后端通过 `curl` 命令发起 HTTP 请求调用远程 API。确保系统安装了 `curl`：

```bash
curl --version
```

大多数 Linux/macOS 系统默认已安装 `curl`；Windows 可通过 `winget install curl` 或下载安装包获取。

## 2.5 Web UI 配置

如果需要使用 Web 可视化界面，需要额外配置以下组件：

### 2.5.1 安装 Web 依赖

```bash
# 安装 Python Web 后端依赖
pip install -e ".[web]"

# 安装 Web 后端额外依赖（包含 Redis RQ 等）
pip install -r web/backend/requirements.txt
```

### 2.5.2 配置环境变量

复制 `.env.example` 为 `.env` 并编辑：

```bash
cp .env.example .env
```

`.env` 文件内容示例：

```bash
# LLM 配置（使用 OpenAI 兼容 API）
LLM_API_KEY=your-api-key-here
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_MODEL=deepseek-reasoner

# 端口配置
FRONTEND_PORT=3000
BACKEND_PORT=8000
REDIS_PORT=6379
```

支持的 LLM 服务（任何 OpenAI 兼容 API 均可）：
- OpenAI（`https://api.openai.com/v1`）
- DeepSeek（`https://api.deepseek.com/v1`）
- 通义千问、文心一言等本地/云端 API
- Ollama 本地部署（`http://localhost:11434/v1`）

### 2.5.3 安装 Redis（任务队列）

Web UI 的后台任务功能依赖 Redis：

**Linux**：

```bash
sudo apt-get install redis-server -y
sudo systemctl start redis
```

**macOS**：

```bash
brew install redis
brew services start redis
```

**Windows**：下载 Redis Windows 版本或使用 WSL 安装。

### 2.5.4 安装前端依赖

```bash
cd web/frontend
npm install
```

## 2.6 使用 Docker 快速部署（推荐生产环境）

最简单的完整部署方式是使用 Docker Compose，一键启动所有服务：

```bash
# 1. 复制环境配置文件
cp .env.example .env

# 2. 编辑 .env，填写 LLM API Key 等配置
vim .env

# 3. 启动所有服务
docker compose up -d

# 查看服务状态
docker compose ps
```

启动后可访问：
- **前端 UI**：http://localhost:3000
- **后端 API**：http://localhost:8000
- **API 文档**：http://localhost:8000/docs

Docker Compose 会自动启动四个服务：`frontend`（Nginx）、`backend`（FastAPI+GDAL）、`redis`、`worker`（RQ 后台工作进程）。

## 2.7 常见安装问题排查

### 问题 1：`geopandas` 安装失败（缺少系统依赖）

GeoPandas 依赖 GDAL、PROJ、GEOS 等 C 库。如果 pip 安装失败，建议：

```bash
# 方法 1：使用 conda-forge（推荐）
conda install -c conda-forge geopandas

# 方法 2：Linux 先安装系统依赖
sudo apt-get install libgdal-dev libproj-dev libgeos-dev -y
pip install geopandas
```

### 问题 2：`rasterio` 安装报错

```bash
# 使用预编译二进制包
pip install rasterio --only-binary=rasterio

# 或通过 conda
conda install -c conda-forge rasterio
```

### 问题 3：`geopipe-agent` 命令未找到

如果 pip 安装后找不到命令，可能是 `pip` 安装路径不在 `PATH` 中：

```bash
# 检查安装路径
python -m geopipe_agent.cli --version

# 或重新安装确保 scripts 在 PATH 中
pip install -e . --force-reinstall
```

### 问题 4：Windows 环境下 GDAL 兼容性问题

Windows 上安装 GIS 相关包容易遇到编译问题，建议：
1. 使用 conda-forge 安装所有 GIS 相关包。
2. 或者使用 WSL2（Windows Subsystem for Linux）运行 Ubuntu 环境。
3. 或者直接使用 Docker 部署方式。

## 2.8 开发环境推荐配置

对于希望深入学习或参与开发的用户，推荐以下开发环境：

```bash
# 安装所有依赖（含开发工具）
pip install -e ".[dev,analysis,network,web]"

# 安装 Web 后端额外依赖
pip install -r web/backend/requirements.txt

# 安装前端依赖
cd web/frontend && npm install && cd ../..

# 运行全部测试验证环境
python -m pytest tests/ -v

# 运行 Web 后端测试
pytest web/backend/tests/ -v

# 运行前端单元测试
cd web/frontend && npm run test
```

## 2.9 小结

本章介绍了 GeoPipeAgent 的安装步骤和环境配置要点：

- 核心库仅需 `pip install -e .` 即可完成基础安装。
- 可选依赖组（`analysis`、`network`、`web`）按需安装，避免不必要的依赖。
- 不同后端有不同的系统依赖，使用前需确认相应工具已安装。
- Web UI 需要 Redis 支持，并需要配置 LLM API Key。
- 生产环境推荐使用 Docker Compose 一键部署。

完成安装后，下一章我们将通过一个完整的示例快速体验 GeoPipeAgent 的核心工作流。
