# 第二章：安装与环境配置

## 2.1 系统要求

### 2.1.1 Python 版本

GeoPipeAgent 要求 **Python 3.10 或更高版本**。这是因为框架广泛使用了 Python 3.10 引入的新语法特性，包括：

- `match/case` 语句
- `X | Y` 联合类型语法（如 `str | None`）
- 改进的错误消息

可以通过以下命令检查 Python 版本：

```bash
python --version
# 或
python3 --version
```

### 2.1.2 操作系统支持

GeoPipeAgent 支持以下操作系统：

| 操作系统 | 支持状态 | 说明 |
|----------|----------|------|
| Linux（Ubuntu/Debian/CentOS） | ✅ 完全支持 | 推荐的开发和生产环境 |
| macOS（10.15+） | ✅ 完全支持 | 本地开发环境 |
| Windows 10/11 | ✅ 完全支持 | 建议使用 WSL2 或 Anaconda |

### 2.1.3 GDAL 安装（可选）

如果需要使用 `gdal_cli` 或 `gdal_python` 后端，需要安装 GDAL：

**Ubuntu/Debian：**

```bash
sudo apt-get update
sudo apt-get install gdal-bin libgdal-dev python3-gdal
```

**macOS（Homebrew）：**

```bash
brew install gdal
```

**Windows（OSGeo4W）：**

推荐通过 [OSGeo4W](https://trac.osgeo.org/osgeo4w/) 安装包来安装 GDAL 及相关工具。

### 2.1.4 QGIS 安装（可选）

如果需要使用 `qgis_process` 或 `pyqgis` 后端，需要安装 QGIS：

```bash
# Ubuntu
sudo apt-get install qgis qgis-plugin-grass

# macOS
brew install --cask qgis

# Windows
# 从 https://qgis.org/download/ 下载安装包
```

## 2.2 基础安装

### 2.2.1 从源码安装

```bash
# 克隆仓库
git clone https://github.com/znlgis/GeoPipeAgent.git
cd GeoPipeAgent

# 基础安装（仅包含核心依赖）
pip install -e .
```

基础安装将安装以下核心依赖：

| 包 | 版本 | 用途 |
|----|------|------|
| click | ≥ 8.0 | CLI 命令行框架 |
| pyyaml | ≥ 6.0 | YAML 解析 |
| geopandas | ≥ 0.14 | 矢量数据处理（默认后端） |
| shapely | ≥ 2.0 | 几何运算 |
| fiona | ≥ 1.9 | 矢量数据 I/O |
| rasterio | ≥ 1.3 | 栅格数据处理 |

### 2.2.2 安装全部依赖

```bash
# 安装全部可选依赖（空间分析 + 网络分析 + 开发工具）
pip install -e ".[dev,analysis,network]"
```

### 2.2.3 分组安装

可以根据需要选择性安装可选依赖：

```bash
# 仅安装空间分析依赖
pip install -e ".[analysis]"

# 仅安装网络分析依赖
pip install -e ".[network]"

# 仅安装开发依赖
pip install -e ".[dev]"

# 组合安装
pip install -e ".[analysis,network]"
```

## 2.3 可选依赖详解

### 2.3.1 analysis 依赖组

安装后可使用空间分析步骤（`analysis.*`）：

| 包 | 版本 | 用于步骤 |
|----|------|---------|
| scipy | ≥ 1.10 | `analysis.voronoi`（泰森多边形）、`analysis.interpolate`（空间插值） |
| scikit-learn | ≥ 1.2 | `analysis.cluster`（空间聚类，DBSCAN/KMeans） |
| matplotlib | ≥ 3.7 | `analysis.heatmap`（热力图/核密度估计） |

### 2.3.2 network 依赖组

安装后可使用网络分析步骤（`network.*`）：

| 包 | 版本 | 用于步骤 |
|----|------|---------|
| networkx | ≥ 3.0 | `network.shortest_path`（最短路径）、`network.service_area`（服务区） |
| geopy | ≥ 2.3 | `network.geocode`（地理编码） |

### 2.3.3 dev 依赖组

开发和测试工具：

| 包 | 版本 | 用途 |
|----|------|------|
| pytest | ≥ 7.0 | 单元测试框架 |
| pytest-cov | ≥ 4.0 | 测试覆盖率统计 |

## 2.4 验证安装

### 2.4.1 验证命令行工具

安装成功后，可以通过 CLI 命令验证：

```bash
# 查看版本
geopipe-agent --version

# 查看帮助
geopipe-agent --help

# 列出所有可用步骤
geopipe-agent list-steps

# 查看可用后端
geopipe-agent backends
```

### 2.4.2 验证步骤注册

```bash
# 列出所有步骤（表格格式）
geopipe-agent list-steps

# 输出示例：
# ID                             Name                 Category     Backends
# --------------------------------------------------------------------------------
# io.read_vector                 读取矢量数据           io           -
# io.write_vector                写入矢量数据           io           -
# vector.buffer                  矢量缓冲区分析         vector       native_python, qgis_process
# ...
# Total: 33 steps
```

```bash
# 按类别筛选，以 JSON 格式输出
geopipe-agent list-steps --category vector --format json
```

### 2.4.3 验证后端可用性

```bash
geopipe-agent backends

# 输出示例：
# [
#   {"name": "native_python", "available": true},
#   {"name": "gdal_cli", "available": false},
#   {"name": "qgis_process", "available": false},
#   {"name": "gdal_python", "available": false},
#   {"name": "pyqgis", "available": false}
# ]
```

### 2.4.4 运行测试

```bash
# 安装开发依赖
pip install -e ".[dev,analysis,network]"

# 运行全部测试
python -m pytest tests/ -v

# 运行带覆盖率报告的测试
python -m pytest tests/ -v --cov=geopipe_agent
```

## 2.5 使用虚拟环境（推荐）

### 2.5.1 使用 venv

```bash
# 创建虚拟环境
python -m venv .venv

# 激活虚拟环境
# Linux/macOS
source .venv/bin/activate
# Windows
.venv\Scripts\activate

# 安装 GeoPipeAgent
pip install -e ".[dev,analysis,network]"
```

### 2.5.2 使用 Conda

```bash
# 创建 Conda 环境
conda create -n geopipe python=3.10

# 激活环境
conda activate geopipe

# 安装 GDAL（如需使用 GDAL 后端）
conda install -c conda-forge gdal

# 安装 GeoPipeAgent
pip install -e ".[dev,analysis,network]"
```

### 2.5.3 使用 Poetry

```bash
# 如果使用 Poetry 管理依赖
poetry install
poetry install --extras "dev analysis network"
```

## 2.6 pyproject.toml 配置解析

GeoPipeAgent 使用现代的 `pyproject.toml` 进行项目配置：

```toml
[build-system]
requires = ["setuptools>=68.0", "wheel"]
build-backend = "setuptools.build_meta"

[project]
name = "geopipe-agent"
version = "0.1.0"
description = "AI-Native GIS Analysis Pipeline Framework"
readme = "README.md"
license = {text = "MIT"}
requires-python = ">=3.10"
dependencies = [
    "click>=8.0",
    "pyyaml>=6.0",
    "geopandas>=0.14",
    "shapely>=2.0",
    "fiona>=1.9",
    "rasterio>=1.3",
]

[project.scripts]
geopipe-agent = "geopipe_agent.cli:main"
```

关键配置项说明：

- **`[project.scripts]`**：定义了 CLI 入口点 `geopipe-agent`，指向 `src/geopipe_agent/cli.py` 中的 `main` 函数
- **`[tool.setuptools.packages.find]`**：配置了 `where = ["src"]`，表示包源码在 `src/` 目录下
- **`[tool.pytest.ini_options]`**：配置了测试路径和 Python 路径

## 2.7 IDE 配置建议

### 2.7.1 VS Code

推荐安装以下扩展：

- **Python**（ms-python.python）：Python 语言支持
- **YAML**（redhat.vscode-yaml）：YAML 语法高亮和验证
- **Pylance**：Python 类型检查

`.vscode/settings.json` 推荐配置：

```json
{
    "python.analysis.extraPaths": ["src"],
    "python.testing.pytestEnabled": true,
    "python.testing.pytestArgs": ["tests/"]
}
```

### 2.7.2 PyCharm

1. 将 `src/` 目录标记为 Sources Root
2. 配置 pytest 为默认测试运行器
3. 添加 Run Configuration：
   - **Script path**：`src/geopipe_agent/cli.py`
   - **Parameters**：`run my-pipeline.yaml`

## 2.8 常见安装问题

### 2.8.1 GDAL 安装失败

问题：`pip install gdal` 编译失败

解决方案：
```bash
# Ubuntu - 先安装系统级 GDAL 开发库
sudo apt-get install libgdal-dev
export CPLUS_INCLUDE_PATH=/usr/include/gdal
export C_INCLUDE_PATH=/usr/include/gdal
pip install GDAL==$(gdal-config --version)

# macOS - 使用 Homebrew
brew install gdal
pip install gdal
```

### 2.8.2 Fiona 安装失败

问题：Fiona 依赖 GDAL 库

解决方案：
```bash
# 使用 Conda 安装（推荐，自动解决依赖）
conda install -c conda-forge fiona

# 或先安装 GDAL 再安装 Fiona
pip install fiona
```

### 2.8.3 GeoPandas 版本冲突

问题：GeoPandas 与其他包存在版本冲突

解决方案：
```bash
# 使用 Conda 安装全部地理空间依赖
conda install -c conda-forge geopandas shapely fiona rasterio
```

## 2.9 本章小结

本章详细介绍了 GeoPipeAgent 的安装方法和环境配置。核心安装只需 `pip install -e .` 即可完成，安装后通过 `geopipe-agent --version` 验证。对于空间分析和网络分析功能，需要额外安装对应的可选依赖组。建议使用虚拟环境（venv 或 Conda）来隔离项目依赖。下一章将深入介绍 GeoPipeAgent 的核心架构与模块设计。
