# 第二章：安装与环境配置

## 2.1 系统要求

在安装 GeoPipeAgent 之前，请确认您的系统满足以下要求：

| 要求项 | 最低版本 | 推荐版本 |
|--------|----------|----------|
| Python | 3.10 | 3.11+ |
| pip | 22.0 | 最新版 |
| 操作系统 | Windows 10 / macOS 11 / Ubuntu 20.04 | Linux (Ubuntu 22.04) |
| 内存 | 4 GB RAM | 8 GB+ RAM |
| 磁盘空间 | 2 GB（含依赖） | 5 GB+（含数据） |

### Python 版本检查

```bash
python --version
# Python 3.11.5

python -c "import sys; print(sys.version_info >= (3, 10))"
# True
```

---

## 2.2 创建虚拟环境（强烈推荐）

强烈建议在虚拟环境中安装 GeoPipeAgent，以避免与其他项目的依赖冲突。

### 方法一：使用 venv（标准库）

```bash
# 创建虚拟环境
python -m venv geopipe-env

# 激活虚拟环境
# Linux / macOS
source geopipe-env/bin/activate

# Windows (Command Prompt)
geopipe-env\Scripts\activate.bat

# Windows (PowerShell)
geopipe-env\Scripts\Activate.ps1

# 验证激活
which python
# /path/to/geopipe-env/bin/python
```

### 方法二：使用 conda（推荐 GIS 开发环境）

conda 能更好地处理 GDAL 等复杂 C 依赖：

```bash
# 创建 conda 环境
conda create -n geopipe python=3.11 -y

# 激活环境
conda activate geopipe

# 预先安装 GDAL（可选，但推荐）
conda install -c conda-forge gdal geopandas -y
```

### 方法三：使用 uv（现代 Python 包管理器）

```bash
# 安装 uv
pip install uv

# 创建虚拟环境
uv venv geopipe-env

# 激活
source geopipe-env/bin/activate
```

# 方式一：克隆 GitHub 仓库
git clone https://github.com/your-org/geopipe-agent.git

## 2.4 安装方式详解

GeoPipeAgent 提供多种安装配置，根据使用场景选择合适的安装命令。

### 2.4.1 最小安装（仅核心功能）

```bash
pip install -e .
```

**包含内容**：
- 核心引擎（parser、validator、executor、reporter）
- IO 步骤（读写矢量/栅格）
- 矢量分析步骤（buffer、clip、reproject、dissolve 等）
- 栅格分析步骤（reproject、clip、calc、stats、contour）
- 数据质检步骤（10 个 QC 步骤）
- CLI 工具（`geopipe-agent` 命令）

**依赖包**：
- `geopandas`：矢量数据处理
- `shapely`：几何操作
- `rasterio`：栅格数据处理
- `pyproj`：坐标投影
- `pyyaml`：YAML 解析
- `click`：CLI 框架
- `rich`：终端美化输出

### 2.4.2 开发安装（含测试工具）

```bash
pip install -e ".[dev]"
```

**额外包含**：
- `pytest`：单元测试框架
- `pytest-cov`：测试覆盖率

### 2.4.3 空间分析安装（含高级分析）

```bash
pip install -e ".[analysis]"
```

**额外包含**：
- `scipy`：科学计算（插值、聚类）
- `scikit-learn`：机器学习（DBSCAN、KMeans 聚类）
- `matplotlib`：可视化（热力图渲染）

**解锁步骤**：
- `analysis.voronoi`：泰森多边形
- `analysis.heatmap`：热力图（KDE 核密度估计）
- `analysis.interpolate`：空间插值（griddata/IDW）
- `analysis.cluster`：空间聚类（DBSCAN/KMeans）

### 2.4.4 网络分析安装

```bash
pip install -e ".[network]"
```

**额外包含**：
- `networkx`：图论与网络分析
- `geopy`：地理编码服务

**解锁步骤**：
- `network.shortest_path`：最短路径分析
- `network.service_area`：服务区分析
- `network.geocode`：地理编码（Nominatim）

### 2.4.5 Web 界面安装（可选）

```bash
pip install -e ".[web]"
```

**额外包含**：
- `fastapi`：Web 框架
- `uvicorn`：ASGI 服务器
- `openai`：OpenAI API 客户端
- `sse-starlette`：服务端推送事件
- `python-multipart`：文件上传

### 2.4.6 全量安装（推荐开发使用）

```bash
pip install -e ".[dev,analysis,network]"
```

### 2.4.7 包含 Web 的完整安装

```bash
pip install -e ".[dev,analysis,network,web]"
```

## 2.5 验证安装

安装完成后，运行以下命令验证：

### 验证 CLI 工具

```bash
# 查看版本信息
geopipe-agent --version
# GeoPipeAgent version 0.1.0

# 查看帮助信息
geopipe-agent --help

# 列出所有可用步骤
geopipe-agent list-steps
```

### 验证已安装的步骤

```bash
# 列出所有步骤（表格格式）
geopipe-agent list-steps --format table

# 仅列出 IO 步骤
geopipe-agent list-steps --category io

# 仅列出矢量步骤
geopipe-agent list-steps --category vector

# 仅列出质检步骤
geopipe-agent list-steps --category qc
```

### 验证后端可用性

```bash
# 查看当前可用的执行后端
geopipe-agent backends
```

输出示例：
```
可用后端:
  ✓ native_python  — GeoPandas + Shapely（默认）
  ✓ gdal_cli       — ogr2ogr 命令行（GDAL 已安装）
  ✗ qgis_process   — QGIS Processing CLI（未安装）
  ✗ pyqgis         — PyQGIS Python API（未安装）
```

### 运行一个简单测试

创建测试文件 `test_pipeline.yaml`：

```yaml
pipeline:
  name: "安装测试"
  description: "测试 GeoPipeAgent 是否正确安装"
  steps:
    - id: check
      use: io.read_vector
      params:
        path: "test_data.geojson"
      on_error: skip
```

```bash
# 校验流水线格式（不需要真实数据文件）
geopipe-agent validate test_pipeline.yaml
# ✓ 流水线格式有效
```

## 2.6 GDAL 安装指南（可选但推荐）

GDAL 是 GIS 领域最重要的开源库，GeoPipeAgent 的多个步骤可以使用 GDAL 后端。

### Linux（Ubuntu/Debian）

```bash
# 安装 GDAL 系统库
sudo apt-get update
sudo apt-get install -y gdal-bin libgdal-dev python3-gdal

# 验证
gdal-config --version
ogr2ogr --version
```

### macOS（Homebrew）

```bash
# 安装 GDAL
brew install gdal

# 安装 Python GDAL 绑定
pip install gdal==$(gdal-config --version)
```

### Windows

建议使用 conda 安装，避免复杂的编译问题：

```bash
conda install -c conda-forge gdal
```

## 2.7 可选：安装 QGIS

如果需要使用 QGIS 后端（`qgis_process` 或 `pyqgis`），需要单独安装 QGIS：

### Ubuntu/Debian

```bash
# 添加 QGIS 软件源
sudo apt-get install -y gnupg software-properties-common
wget -qO - https://qgis.org/downloads/qgis-2022.gpg.key | sudo gpg --no-default-keyring --keyring gnupg-ring:/etc/apt/trusted.gpg.d/qgis-archive.gpg --import

# 安装 QGIS
sudo apt-get update
sudo apt-get install -y qgis python3-qgis
```

### 验证 QGIS 后端

```bash
qgis_process list
# 列出所有 QGIS Processing 算法
```

## 2.10 常见安装问题

### 问题一：GDAL 安装失败

**症状**：`pip install geopandas` 时报 `ERROR: Failed building wheel for GDAL`

**解决方案**：
```bash
# 方案 A：使用 conda 安装
conda install -c conda-forge geopandas

# 方案 B：使用预编译的 wheel
pip install --find-links https://girder.github.io/large_image_wheels GDAL

# 方案 C：先安装系统 GDAL
sudo apt-get install libgdal-dev
export GDAL_CONFIG=/usr/bin/gdal-config
pip install gdal==$(gdal-config --version)
```

### 问题二：Shapely 版本冲突

**症状**：导入时报 `ImportError: cannot import name 'geometry' from 'shapely'`

**解决方案**：
```bash
# 确保安装 Shapely 2.x
pip install "shapely>=2.0"
```

### 问题三：Windows 下路径问题

**症状**：YAML 中的路径 `data\roads.shp` 无法识别

**解决方案**：Windows 路径应使用正斜杠或原始字符串：
```yaml
# 推荐：使用正斜杠
path: "data/roads.shp"

# 或：使用双反斜杠
path: "data\\roads.shp"
```

### 问题四：`geopipe-agent` 命令不存在

**症状**：运行 `geopipe-agent` 时提示 `command not found`

**解决方案**：
```bash
# 检查虚拟环境是否激活
which python

# 重新安装
pip install -e .

# 检查 PATH
echo $PATH

# 手动运行
python -m geopipe_agent.cli.main
```

### 问题五：Python 3.10 以下版本报错

**症状**：`SyntaxError: cannot use starred expression here` 或类型注解报错

**解决方案**：升级 Python 到 3.10+
```bash
# 使用 pyenv 管理多版本
pyenv install 3.11.5
pyenv local 3.11.5
```
