# 第十章：空间分析步骤详解

## 10.1 概述

空间分析步骤（`analysis.*`）提供 **4 个高级 GIS 分析功能**，依赖 `analysis` 可选包组。使用前需安装：

```bash
pip install -e ".[analysis]"
```

安装内容：
- `scipy`：科学计算（插值、KDE 核密度）
- `scikit-learn`：机器学习（DBSCAN、KMeans 聚类）
- `matplotlib`：可视化（热力图渲染）

| 步骤 ID | 功能 | 依赖 |
|---------|------|------|
| `analysis.voronoi` | 泰森多边形（Voronoi 图） | scipy |
| `analysis.heatmap` | 热力图（KDE 核密度估计） | scipy, matplotlib |
| `analysis.interpolate` | 空间插值 | scipy |
| `analysis.cluster` | 空间聚类 | scikit-learn |

---

## 10.2 `analysis.voronoi`：泰森多边形

泰森多边形（Voronoi Diagram）将平面分割为若干区域，每个区域内的任意点距该区域的"种子点"最近。常用于服务范围划分、自然邻域插值。

### 10.2.1 参数说明

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| `input` | GeoDataFrame | **是** | - | 种子点数据（点类型） |

### 10.2.2 使用示例

```yaml
pipeline:
  name: "泰森多边形分析"
  description: "根据医院位置生成服务范围泰森多边形"

  variables:
    hospitals_path: "data/hospitals.geojson"
    boundary_path: "data/city_boundary.geojson"

  steps:
    # 加载医院点数据
    - id: load-hospitals
      use: io.read_vector
      params:
        path: "${hospitals_path}"

    # 加载城市边界
    - id: load-boundary
      use: io.read_vector
      params:
        path: "${boundary_path}"

    # 投影到米制坐标系
    - id: reproject-hospitals
      use: vector.reproject
      params:
        input: "$load-hospitals"
        target_crs: "EPSG:3857"

    - id: reproject-boundary
      use: vector.reproject
      params:
        input: "$load-boundary"
        target_crs: "EPSG:3857"

    # 生成泰森多边形（使用投影后的点）
    - id: voronoi
      use: analysis.voronoi
      params:
        input: "$reproject-hospitals"

    # 裁剪到城市边界（泰森多边形通常超出研究区）
    - id: clip-voronoi
      use: vector.clip
      params:
        input: "$voronoi"
        clip: "$reproject-boundary"

    # 转回 WGS84 保存
    - id: reproject-back
      use: vector.reproject
      params:
        input: "$clip-voronoi"
        target_crs: "EPSG:4326"

    - id: save
      use: io.write_vector
      params:
        input: "$reproject-back"
        path: "output/hospital_service_areas.geojson"
        format: "GeoJSON"

  outputs:
    service_area_count: "$voronoi.stats.feature_count"
    result: "$save"
```

### 10.2.3 应用场景

- **医疗设施服务范围**：医院、诊所的覆盖区域划分
- **零售选址分析**：店铺的最近客户区域
- **邮政分区**：邮政局服务范围
- **气象站数据**：用于自然邻域插值
- **电信基站覆盖**：信号覆盖区域分析

## 10.3 `analysis.heatmap`：热力图（KDE 核密度估计）

使用核密度估计（Kernel Density Estimation）生成连续的密度栅格，直观展示点数据的空间聚集程度。

### 10.3.1 参数说明

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| `input` | GeoDataFrame | **是** | - | 输入点数据 |
| `bandwidth` | float | **是** | - | 核宽带（带宽），控制平滑程度 |
| `resolution` | float | 否 | 自动 | 输出栅格分辨率 |
| `weight_field` | string | 否 | `null` | 权重字段（加权 KDE） |

**带宽选择指南**：
- 带宽越大，平滑程度越高，细节越少
- 带宽越小，噪声越多，局部聚集越明显
- 建议值：研究区范围的 1/100 到 1/50

### 10.3.2 使用示例

```yaml
pipeline:
  name: "犯罪热力图分析"
  description: "根据犯罪事件点数据生成核密度热力图"

  variables:
    events_path: "data/crime_events.geojson"
    bandwidth: 0.005        # 约 500 米带宽（度单位）
    output_resolution: 0.001

  steps:
    - id: load-events
      use: io.read_vector
      params:
        path: "${events_path}"

    # 生成热力图（基本用法）
    - id: heatmap-basic
      use: analysis.heatmap
      params:
        input: "$load-events"
        bandwidth: "${bandwidth}"
        resolution: "${output_resolution}"

    # 加权热力图（按案件严重程度加权）
    - id: heatmap-weighted
      use: analysis.heatmap
      params:
        input: "$load-events"
        bandwidth: "${bandwidth}"
        resolution: "${output_resolution}"
        weight_field: "severity_score"    # 严重程度字段

    - id: save-heatmap
      use: io.write_raster
      params:
        input: "$heatmap-basic"
        path: "output/crime_heatmap.tif"

    - id: save-weighted-heatmap
      use: io.write_raster
      params:
        input: "$heatmap-weighted"
        path: "output/crime_heatmap_weighted.tif"

  outputs:
    heatmap_stats: "$heatmap-basic.stats"
```

### 10.3.3 热力图的典型应用场景

| 应用领域 | 数据类型 | 分析目标 |
|----------|----------|----------|
| 公共安全 | 犯罪事件点 | 高危区域识别 |
| 交通分析 | 事故点数据 | 事故黑点分析 |
| 商业分析 | 用户签到数据 | 商业活跃区域 |
| 流行病学 | 病例位置 | 疾病传播热点 |
| 生态学 | 物种观测点 | 栖息地密度分布 |
| 旅游分析 | 游客打卡点 | 旅游热点区域 |

## 10.4 `analysis.interpolate`：空间插值

根据已知采样点的属性值，推算空间中未采样位置的属性值，生成连续栅格面。

### 10.4.1 参数说明

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| `input` | GeoDataFrame | **是** | - | 带属性值的采样点 |
| `value_field` | string | **是** | - | 要插值的属性字段名 |
| `method` | string | 否 | `griddata` | 插值方法：`griddata`/`idw` |
| `resolution` | float | 否 | 自动 | 输出栅格分辨率 |
| `power` | float | 否 | `2.0` | IDW 的幂次（仅 IDW 方法） |

### 10.4.2 插值方法对比

| 方法 | 全称 | 特点 | 适用场景 |
|------|------|------|----------|
| `griddata` | 三角剖分插值（scipy） | 精确通过已知点，不外推 | 密集均匀采样 |
| `idw` | 反距离权重插值 | 距离越近权重越大 | 稀疏不均匀采样 |

### 10.4.3 使用示例

```yaml
pipeline:
  name: "气温空间插值"
  description: "根据气象站观测数据插值生成温度面数据"

  variables:
    stations_path: "data/weather_stations.geojson"
    temp_field: "temperature_celsius"
    resolution: 0.01            # 约 1km 分辨率

  steps:
    - id: load-stations
      use: io.read_vector
      params:
        path: "${stations_path}"

    # 属性查询：过滤掉缺值的站点
    - id: valid-stations
      use: vector.query
      params:
        input: "$load-stations"
        expression: "temperature_celsius.notna() and temperature_celsius > -100"

    # IDW 插值（适合气象数据，采样点稀疏）
    - id: interpolate-idw
      use: analysis.interpolate
      params:
        input: "$valid-stations"
        value_field: "${temp_field}"
        method: "idw"
        resolution: "${resolution}"
        power: 2.0

    # griddata 插值（比较用）
    - id: interpolate-grid
      use: analysis.interpolate
      params:
        input: "$valid-stations"
        value_field: "${temp_field}"
        method: "griddata"
        resolution: "${resolution}"

    # 裁剪到研究区（去除外推区域的边缘效应）
    - id: load-boundary
      use: io.read_vector
      params:
        path: "data/study_boundary.geojson"

    - id: clip-result
      use: raster.clip
      params:
        input: "$interpolate-idw"
        mask: "$load-boundary"

    # 提取等温线（5℃ 间隔）
    - id: isotherms
      use: raster.contour
      params:
        input: "$clip-result"
        interval: 5
        attribute_name: "temperature"

    - id: save-raster
      use: io.write_raster
      params:
        input: "$clip-result"
        path: "output/temperature_interpolated.tif"

    - id: save-isotherms
      use: io.write_vector
      params:
        input: "$isotherms"
        path: "output/isotherms_5c.geojson"
        format: "GeoJSON"

  outputs:
    interpolation_stats: "$interpolate-idw.stats"
    isotherm_count: "$isotherms.stats.feature_count"
```

### 10.4.4 插值的注意事项

1. **采样点分布**：采样点应尽量均匀分布，覆盖研究区
2. **外推问题**：插值结果在采样点范围外（外推区域）误差较大
3. **数据去异常**：插值前应清除明显错误值（如 -9999）
4. **分辨率选择**：分辨率不应高于采样点间距

## 10.5 `analysis.cluster`：空间聚类

识别空间中的点群，将相互临近的点归为同一类别，发现空间分布模式。

### 10.5.1 参数说明

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| `input` | GeoDataFrame | **是** | - | 输入点数据 |
| `algorithm` | string | 否 | `dbscan` | 聚类算法：`dbscan`/`kmeans` |
| `eps` | float | 否 | `0.01` | DBSCAN 的邻域半径（度） |
| `min_samples` | int | 否 | `5` | DBSCAN 的最少点数 |
| `n_clusters` | int | 否 | `8` | KMeans 的聚类数 |

### 10.5.2 两种聚类算法对比

| 特性 | DBSCAN | KMeans |
|------|--------|--------|
| 聚类数量 | 自动确定 | 需要预设 |
| 形状 | 任意形状 | 球形/凸形 |
| 噪声处理 | 自动标记噪声点 | 所有点都归类 |
| 参数敏感度 | eps 和 min_samples | n_clusters |
| 适用场景 | 形状不规则、有噪声 | 形状规则、数量已知 |

### 10.5.3 使用示例

```yaml
pipeline:
  name: "POI 空间聚类分析"
  description: "对城市 POI 数据进行空间聚类，识别商业聚集区"

  variables:
    pois_path: "data/pois_restaurants.geojson"

  steps:
    - id: load-pois
      use: io.read_vector
      params:
        path: "${pois_path}"

    # DBSCAN 聚类（自动确定聚类数）
    # eps: 邻域半径（以度为单位，约 0.005° = 500m）
    - id: cluster-dbscan
      use: analysis.cluster
      params:
        input: "$load-pois"
        algorithm: "dbscan"
        eps: 0.005           # 约 500 米邻域
        min_samples: 10      # 最少 10 个点形成一个簇

    # KMeans 聚类（预设 5 个商业区）
    - id: cluster-kmeans
      use: analysis.cluster
      params:
        input: "$load-pois"
        algorithm: "kmeans"
        n_clusters: 5

    # 过滤掉 DBSCAN 中的噪声点（cluster_id = -1）
    - id: filter-noise
      use: vector.query
      params:
        input: "$cluster-dbscan"
        expression: "cluster_id >= 0"

    # 保存聚类结果
    - id: save-dbscan
      use: io.write_vector
      params:
        input: "$cluster-dbscan"
        path: "output/poi_clusters_dbscan.geojson"
        format: "GeoJSON"

    - id: save-kmeans
      use: io.write_vector
      params:
        input: "$cluster-kmeans"
        path: "output/poi_clusters_kmeans.geojson"
        format: "GeoJSON"

  outputs:
    dbscan_cluster_count: "$cluster-dbscan.stats.n_clusters"
    dbscan_noise_count: "$cluster-dbscan.stats.n_noise"
    valid_poi_count: "$filter-noise.stats.feature_count"
```

### 10.5.4 聚类结果字段

聚类步骤会在原始数据中添加 `cluster_id` 字段：
- DBSCAN：`-1` 表示噪声点，`0, 1, 2, ...` 表示各聚类
- KMeans：`0, 1, 2, ...` 表示各聚类中心对应的类别

## 10.6 空间分析综合案例

### 案例：城市设施公平性分析

分析城市各区域的公共设施（医院、学校、公园）的空间分布公平性。

```yaml
pipeline:
  name: "城市设施公平性分析"
  description: "综合泰森多边形、热力图、聚类分析城市公共设施分布"

  variables:
    facilities_path: "data/public_facilities.geojson"
    population_path: "data/population_grid.geojson"
    boundary_path: "data/city_boundary.geojson"

  steps:
    # 数据加载
    - id: load-facilities
      use: io.read_vector
      params:
        path: "${facilities_path}"

    - id: load-boundary
      use: io.read_vector
      params:
        path: "${boundary_path}"

    # 分类：医院
    - id: hospitals
      use: vector.query
      params:
        input: "$load-facilities"
        expression: "facility_type == 'hospital'"

    # 分类：学校
    - id: schools
      use: vector.query
      params:
        input: "$load-facilities"
        expression: "facility_type == 'school'"

    # 投影转换
    - id: reproject-facilities
      use: vector.reproject
      params:
        input: "$load-facilities"
        target_crs: "EPSG:3857"

    - id: reproject-hospitals
      use: vector.reproject
      params:
        input: "$hospitals"
        target_crs: "EPSG:3857"

    - id: reproject-boundary
      use: vector.reproject
      params:
        input: "$load-boundary"
        target_crs: "EPSG:3857"

    # 泰森多边形：医院服务范围划分
    - id: hospital-voronoi
      use: analysis.voronoi
      params:
        input: "$reproject-hospitals"

    - id: clip-voronoi
      use: vector.clip
      params:
        input: "$hospital-voronoi"
        clip: "$reproject-boundary"

    # 热力图：设施密度分布
    - id: facility-heatmap
      use: analysis.heatmap
      params:
        input: "$reproject-facilities"
        bandwidth: 500         # 500 米带宽（米制坐标系）
        resolution: 100        # 100 米分辨率

    # 聚类：识别设施聚集区
    - id: facility-cluster
      use: analysis.cluster
      params:
        input: "$reproject-facilities"
        algorithm: "dbscan"
        eps: 300              # 300 米邻域半径
        min_samples: 3

    # 保存结果
    - id: save-voronoi
      use: io.write_vector
      params:
        input: "$clip-voronoi"
        path: "output/hospital_service_zones.geojson"
        format: "GeoJSON"

    - id: save-heatmap
      use: io.write_raster
      params:
        input: "$facility-heatmap"
        path: "output/facility_density.tif"

    - id: save-clusters
      use: io.write_vector
      params:
        input: "$facility-cluster"
        path: "output/facility_clusters.geojson"
        format: "GeoJSON"

  outputs:
    hospital_service_zones: "$clip-voronoi.stats.feature_count"
    facility_clusters: "$facility-cluster.stats.n_clusters"
    heatmap_stats: "$facility-heatmap.stats"
```

## 10.7 常见问题

### 问题一：`analysis` 模块未安装

```
StepNotFoundError: 步骤 'analysis.voronoi' 未找到。
提示：空间分析步骤需要安装 analysis 依赖，请运行：pip install -e ".[analysis]"
```

解决：
```bash
pip install -e ".[analysis]"
```

### 问题二：泰森多边形覆盖范围超出研究区

这是正常现象。泰森多边形算法会生成覆盖整个平面的区域，需要使用 `vector.clip` 裁剪到研究区：

```yaml
- id: voronoi
  use: analysis.voronoi
  params:
    input: "$seed-points"

- id: clip-to-boundary
  use: vector.clip
  params:
    input: "$voronoi"
    clip: "$study-area"   # 必须裁剪！
```

### 问题三：KDE 带宽选择

带宽是热力图质量的关键参数：
- 太小 → 热力图"颗粒感"强，看不出趋势
- 太大 → 过度平滑，丢失局部细节

建议使用研究区范围的 1% 作为初始带宽，再根据结果调整。

## 10.8 本章小结

本章介绍了 4 个空间分析步骤（需要 `analysis` 依赖包）：

1. **`analysis.voronoi`**：泰森多边形，用于服务范围划分，注意裁剪到研究区
2. **`analysis.heatmap`**：KDE 核密度估计，带宽是关键参数
3. **`analysis.interpolate`**：空间插值（IDW/griddata），用于连续面的生成
4. **`analysis.cluster`**：空间聚类（DBSCAN/KMeans），识别空间分布模式

这四个步骤覆盖了 GIS 高级分析中最常用的统计与机器学习方法。
