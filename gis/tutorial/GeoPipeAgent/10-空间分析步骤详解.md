# 第十章：空间分析步骤详解

## 10.1 概述

空间分析步骤提供了高级的空间分析功能，包括泰森多边形、热力图、空间插值和空间聚类。这些步骤需要安装 `[analysis]` 可选依赖组。

```bash
pip install -e ".[analysis]"
```

安装的依赖：

| 包 | 版本 | 用于步骤 |
|----|------|---------|
| scipy | ≥ 1.10 | `analysis.voronoi`、`analysis.interpolate` |
| scikit-learn | ≥ 1.2 | `analysis.cluster` |
| matplotlib | ≥ 3.7 | `analysis.heatmap` |

## 10.2 analysis.voronoi — 泰森多边形

### 10.2.1 功能说明

根据输入的点数据生成泰森多边形（Voronoi 图）。泰森多边形将平面划分为若干区域，每个区域内的点离对应的输入点最近。

### 10.2.2 实现原理

使用 `scipy.spatial.Voronoi` 计算 Voronoi 图，然后用 `shapely` 构建多边形几何。

### 10.2.3 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | GeoDataFrame | ✅ | — | 输入点数据 |
| `boundary` | GeoDataFrame | ❌ | — | 裁剪边界（可选） |

### 10.2.4 使用示例

```yaml
- id: voronoi
  use: analysis.voronoi
  params:
    input: "$stations"
    boundary: "$study-area"
```

### 10.2.5 应用场景

- 气象站的服务范围划分
- 商店的市场覆盖区域分析
- 水源地的影响范围分析

## 10.3 analysis.heatmap — 热力图

### 10.3.1 功能说明

基于核密度估计（KDE）生成热力图栅格。输入点数据，输出密度栅格。

### 10.3.2 实现原理

使用 `scipy.stats.gaussian_kde` 进行核密度估计，生成密度网格。

### 10.3.3 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | GeoDataFrame | ✅ | — | 输入点数据 |
| `resolution` | number | ❌ | 100 | 输出栅格分辨率 |
| `bandwidth` | number | ❌ | 自动 | KDE 带宽 |
| `weight_field` | string | ❌ | — | 权重字段名 |

### 10.3.4 使用示例

```yaml
- id: heatmap
  use: analysis.heatmap
  params:
    input: "$crime-points"
    resolution: 50
    weight_field: "severity"
```

### 10.3.5 应用场景

- 犯罪热点分析
- 人口密度可视化
- 交通事故密度分析
- 商业选址分析

## 10.4 analysis.interpolate — 空间插值

### 10.4.1 功能说明

对离散点数据进行空间插值，生成连续的栅格表面。支持 griddata 和 IDW（反距离加权）两种插值方法。

### 10.4.2 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | GeoDataFrame | ✅ | — | 输入点数据 |
| `value_field` | string | ✅ | — | 用于插值的数值字段 |
| `method` | string | ❌ | "linear" | 插值方法 |
| `resolution` | number | ❌ | 100 | 输出栅格分辨率 |
| `power` | number | ❌ | 2 | IDW 权重指数 |

### 10.4.3 插值方法

| 方法 | 说明 | 适用场景 |
|------|------|----------|
| `linear` | 线性插值（scipy griddata） | 数据分布均匀时 |
| `nearest` | 最近邻插值 | 分类数据 |
| `cubic` | 三次插值 | 需要平滑曲面 |
| `idw` | 反距离加权插值 | 经典的空间插值方法 |

### 10.4.4 使用示例

```yaml
# IDW 插值
- id: interpolate-temp
  use: analysis.interpolate
  params:
    input: "$weather-stations"
    value_field: "temperature"
    method: "idw"
    resolution: 500
    power: 2

# 线性插值
- id: interpolate-elevation
  use: analysis.interpolate
  params:
    input: "$survey-points"
    value_field: "elevation"
    method: "linear"
    resolution: 30
```

### 10.4.5 应用场景

- 气温/降水空间分布
- 地下水位插值
- 土壤属性空间化
- 空气质量分布

## 10.5 analysis.cluster — 空间聚类

### 10.5.1 功能说明

对点数据进行空间聚类分析。支持 DBSCAN（基于密度）和 KMeans（基于距离）两种算法。

### 10.5.2 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | GeoDataFrame | ✅ | — | 输入点数据 |
| `algorithm` | string | ❌ | "dbscan" | 聚类算法 |
| `eps` | number | ❌ | 0.5 | DBSCAN 邻域半径 |
| `min_samples` | number | ❌ | 5 | DBSCAN 最小样本数 |
| `n_clusters` | number | ❌ | 5 | KMeans 聚类数 |

### 10.5.3 聚类算法

**DBSCAN**：
- 基于密度的聚类，不需要预先指定聚类数量
- `eps`：两个点被视为邻居的最大距离
- `min_samples`：形成密集区域的最小点数
- 能识别噪声点（标记为 -1）

**KMeans**：
- 基于距离的聚类，需要预先指定聚类数量 `n_clusters`
- 将所有点划分为 K 个聚类
- 不识别噪声点

### 10.5.4 使用示例

```yaml
# DBSCAN 聚类
- id: cluster-dbscan
  use: analysis.cluster
  params:
    input: "$poi-points"
    algorithm: "dbscan"
    eps: 500
    min_samples: 10

# KMeans 聚类
- id: cluster-kmeans
  use: analysis.cluster
  params:
    input: "$customer-locations"
    algorithm: "kmeans"
    n_clusters: 8
```

### 10.5.5 输出

聚类结果会在 GeoDataFrame 中添加 `cluster` 列，表示每个点所属的聚类编号。DBSCAN 中 `-1` 表示噪声点。

### 10.5.6 应用场景

- POI（兴趣点）聚类分析
- 犯罪热点区域识别
- 客户群体空间分布分析
- 设施选址的覆盖分析

## 10.6 典型空间分析流程

### 10.6.1 气象站分析流程

```yaml
pipeline:
  name: "气象站空间分析"
  description: "泰森多边形 + 温度插值 + 聚类分析"

  steps:
    - id: read-stations
      use: io.read_vector
      params:
        path: "data/weather_stations.shp"

    - id: read-boundary
      use: io.read_vector
      params:
        path: "data/study_area.shp"

    - id: voronoi
      use: analysis.voronoi
      params:
        input: "$read-stations"
        boundary: "$read-boundary"

    - id: interpolate
      use: analysis.interpolate
      params:
        input: "$read-stations"
        value_field: "temperature"
        method: "idw"
        resolution: 1000

    - id: cluster
      use: analysis.cluster
      params:
        input: "$read-stations"
        algorithm: "dbscan"
        eps: 50000
        min_samples: 3

    - id: save-voronoi
      use: io.write_vector
      params:
        input: "$voronoi"
        path: "output/voronoi.geojson"

    - id: save-clusters
      use: io.write_vector
      params:
        input: "$cluster"
        path: "output/clusters.geojson"

  outputs:
    voronoi: "$save-voronoi"
    clusters: "$save-clusters"
```

## 10.7 本章小结

本章详细介绍了 GeoPipeAgent 的 4 个空间分析步骤。`analysis.voronoi` 生成泰森多边形，`analysis.heatmap` 生成核密度热力图，`analysis.interpolate` 执行空间插值（支持 griddata 和 IDW），`analysis.cluster` 进行空间聚类（支持 DBSCAN 和 KMeans）。这些步骤需要安装 `[analysis]` 可选依赖组。
