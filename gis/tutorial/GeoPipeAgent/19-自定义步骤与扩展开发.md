# 第十九章：自定义步骤与扩展开发

## 19.1 概述

GeoPipeAgent 提供完整的步骤扩展机制，允许开发者编写自定义步骤并无缝集成到框架中。自定义步骤与内置步骤完全等价，可以：
- 在 YAML 流水线中用 `use:` 引用
- 通过 `geopipe-agent list-steps` 列出
- 被 `geopipe-agent describe` 查询详情
- 被 AI Skill 文档包含

---

## 19.2 步骤注册系统

### 19.2.1 `@step` 装饰器

自定义步骤通过 `@step` 装饰器注册到全局步骤注册表：

```python
from geopipe_agent.steps.registry import step
from geopipe_agent.engine.context import StepContext
from geopipe_agent.models.result import StepResult

@step(
    id="category.step_name",    # 必填：步骤唯一 ID（格式：category.action）
    name="步骤显示名称",          # 必填：人类可读名称
    description="步骤功能描述",   # 必填：详细描述
    category="category",         # 必填：步骤类别
    params={                     # 必填：参数规范
        "param_name": {
            "type": "参数类型",
            "required": True,    # 是否必填
            "description": "参数描述",
            "default": None,     # 默认值（可选）
        }
    },
    outputs={                    # 必填：输出规范
        "output": {
            "type": "输出类型",
            "description": "主输出描述"
        }
    },
)
def my_step(ctx: StepContext) -> StepResult:
    # 步骤实现
    ...
```

### 19.2.2 步骤自动发现机制

框架使用 `pkgutil.walk_packages` 扫描 `src/geopipe_agent/steps/` 目录下的所有子模块，自动导入并注册所有 `@step` 装饰的函数。

**步骤文件放置规则**：
- 内置步骤：`src/geopipe_agent/steps/{category}/{name}.py`
- 自定义步骤：任意 Python 包，需在安装时被扫描到

## 19.3 编写第一个自定义步骤

### 19.3.1 简单矢量步骤示例

```python
# src/geopipe_agent/steps/vector/centroid.py
"""
自定义步骤：计算多边形质心点
"""
import geopandas as gpd
from geopipe_agent.steps.registry import step
from geopipe_agent.engine.context import StepContext
from geopipe_agent.models.result import StepResult


@step(
    id="vector.centroid",
    name="计算质心",
    description="将多边形要素转换为质心点",
    category="vector",
    params={
        "input": {
            "type": "geodataframe",
            "required": True,
            "description": "输入多边形数据",
        },
        "keep_attributes": {
            "type": "boolean",
            "required": False,
            "default": True,
            "description": "是否保留原始属性字段",
        },
    },
    outputs={
        "output": {
            "type": "geodataframe",
            "description": "质心点 GeoDataFrame",
        }
    },
)
def vector_centroid(ctx: StepContext) -> StepResult:
    # 获取参数（自动解析变量和引用）
    gdf = ctx.require_param("input")
    keep_attributes = ctx.param("keep_attributes", default=True)

    # 计算质心
    gdf_centroid = gdf.copy()
    gdf_centroid.geometry = gdf.geometry.centroid

    # 可选：去掉属性，只保留几何
    if not keep_attributes:
        gdf_centroid = gdf_centroid[["geometry"]]

    # 构建统计信息
    stats = {
        "feature_count": len(gdf_centroid),
        "crs": str(gdf_centroid.crs),
        "geometry_type": "Point",
        "source_geometry_type": gdf.geometry.geom_type.unique().tolist(),
    }

    return StepResult(
        output=gdf_centroid,
        stats=stats,
    )
```

### 19.3.2 在流水线中使用自定义步骤

```yaml
pipeline:
  name: "使用自定义质心步骤"
  steps:
    - id: load-polygons
      use: io.read_vector
      params:
        path: "data/districts.geojson"

    # 使用自定义步骤
    - id: get-centroids
      use: vector.centroid
      params:
        input: "$load-polygons"
        keep_attributes: true

    - id: save-centroids
      use: io.write_vector
      params:
        input: "$get-centroids"
        path: "output/district_centroids.geojson"
        format: "GeoJSON"
```

## 19.4 高级步骤开发

### 19.4.1 带 QC 功能的步骤

```python
# src/geopipe_agent/steps/vector/area_filter.py
"""
自定义步骤：按面积过滤多边形（同时记录被过滤要素的 QC 信息）
"""
import geopandas as gpd
from geopipe_agent.steps.registry import step
from geopipe_agent.engine.context import StepContext
from geopipe_agent.models.result import StepResult
from geopipe_agent.models.qc import QcIssue


@step(
    id="vector.area_filter",
    name="面积过滤",
    description="过滤掉面积小于阈值的多边形，记录被过滤要素",
    category="vector",
    params={
        "input": {
            "type": "geodataframe",
            "required": True,
            "description": "输入多边形数据（需要投影坐标系，单位：米²）",
        },
        "min_area": {
            "type": "float",
            "required": True,
            "description": "最小面积阈值（平方米）",
        },
    },
    outputs={
        "output": {
            "type": "geodataframe",
            "description": "过滤后的多边形",
        }
    },
)
def vector_area_filter(ctx: StepContext) -> StepResult:
    gdf = ctx.require_param("input")
    min_area = ctx.require_param("min_area")

    # 计算面积
    areas = gdf.geometry.area

    # 标记小面积要素
    mask_too_small = areas < min_area
    gdf_filtered = gdf[~mask_too_small].copy()

    # 为过滤掉的要素创建 QC issues
    issues = []
    too_small_gdf = gdf[mask_too_small]
    for idx, row in too_small_gdf.iterrows():
        issues.append(QcIssue(
            type="area_too_small",
            severity="info",
            feature_id=idx,
            message=f"要素面积 {areas[idx]:.2f} 平方米，小于阈值 {min_area} 平方米，已被过滤",
            field=None,
            value=areas[idx],
        ))

    stats = {
        "input_count": len(gdf),
        "output_count": len(gdf_filtered),
        "filtered_count": len(too_small_gdf),
        "min_area_threshold": min_area,
        "total_area": gdf_filtered.geometry.area.sum(),
    }

    return StepResult(
        output=gdf_filtered,
        stats=stats,
        issues=issues,
    )
```

### 19.4.2 调用外部工具的步骤

```python
# src/geopipe_agent/steps/vector/external_process.py
"""
自定义步骤：调用外部工具处理数据
"""
import subprocess
import tempfile
import os
import geopandas as gpd
from geopipe_agent.steps.registry import step
from geopipe_agent.engine.context import StepContext
from geopipe_agent.models.result import StepResult
from geopipe_agent.errors import StepExecutionError


@step(
    id="vector.postgis_simplify",
    name="PostGIS 几何简化",
    description="使用 PostGIS ST_SimplifyPreserveTopology 简化几何",
    category="vector",
    params={
        "input": {
            "type": "geodataframe",
            "required": True,
            "description": "输入数据",
        },
        "tolerance": {
            "type": "float",
            "required": True,
            "description": "简化容差",
        },
        "db_connection": {
            "type": "string",
            "required": True,
            "description": "PostgreSQL 连接字符串",
        },
    },
    outputs={
        "output": {"type": "geodataframe", "description": "简化后的数据"},
    },
)
def postgis_simplify(ctx: StepContext) -> StepResult:
    gdf = ctx.require_param("input")
    tolerance = ctx.require_param("tolerance")
    db_conn = ctx.require_param("db_connection")

    # 写入临时文件
    with tempfile.TemporaryDirectory() as tmpdir:
        input_path = os.path.join(tmpdir, "input.geojson")
        output_path = os.path.join(tmpdir, "output.geojson")

        gdf.to_file(input_path, driver="GeoJSON")

        # 调用外部工具（这里示意性地用 ogr2ogr）
        try:
            result = subprocess.run(
                [
                    "ogr2ogr",
                    "-f", "GeoJSON",
                    output_path,
                    input_path,
                    "-simplify", str(tolerance),
                ],
                capture_output=True,
                text=True,
                timeout=60,
            )

            if result.returncode != 0:
                raise StepExecutionError(
                    step_id="vector.postgis_simplify",
                    message=f"外部工具执行失败: {result.stderr}",
                    suggestion="请检查 ogr2ogr 是否已安装",
                )

            # 读取输出
            output_gdf = gpd.read_file(output_path)

        except subprocess.TimeoutExpired:
            raise StepExecutionError(
                step_id="vector.postgis_simplify",
                message="外部工具执行超时（超过 60 秒）",
            )

    return StepResult(
        output=output_gdf,
        stats={
            "feature_count": len(output_gdf),
            "tolerance": tolerance,
        },
    )
```

### 19.4.3 带进度报告的步骤

```python
# 对于大数据集，可以在 metadata 中记录进度
@step(
    id="vector.batch_geocode",
    name="批量地理编码",
    description="批量地理编码大规模地址数据",
    category="vector",
    params={
        "input": {"type": "geodataframe", "required": True, "description": "含地址字段的数据"},
        "address_field": {"type": "string", "required": True, "description": "地址字段名"},
        "batch_size": {"type": "int", "required": False, "default": 100, "description": "批次大小"},
    },
    outputs={
        "output": {"type": "geodataframe", "description": "地理编码结果"},
    },
)
def batch_geocode(ctx: StepContext) -> StepResult:
    import time
    from geopy.geocoders import Nominatim

    gdf = ctx.require_param("input")
    address_field = ctx.require_param("address_field")
    batch_size = ctx.param("batch_size", default=100)

    geocoder = Nominatim(user_agent="geopipe-batch-geocode")

    results = []
    total = len(gdf)
    success_count = 0
    fail_count = 0

    for i, (idx, row) in enumerate(gdf.iterrows()):
        address = row[address_field]
        try:
            location = geocoder.geocode(address, timeout=5)
            if location:
                results.append({
                    "geometry": {"type": "Point", "coordinates": [location.longitude, location.latitude]},
                    **row.to_dict(),
                    "geocode_success": True,
                    "geocode_confidence": 1.0,
                })
                success_count += 1
            else:
                results.append({
                    "geometry": None,
                    **row.to_dict(),
                    "geocode_success": False,
                    "geocode_confidence": 0.0,
                })
                fail_count += 1
        except Exception:
            fail_count += 1
            results.append({
                "geometry": None,
                **row.to_dict(),
                "geocode_success": False,
            })

        # 限流：每次请求后等待 1 秒
        if (i + 1) % batch_size == 0:
            time.sleep(1)

    import geopandas as gpd
    from shapely.geometry import shape

    result_gdf = gpd.GeoDataFrame(results, crs="EPSG:4326")
    if "geometry" in result_gdf.columns:
        result_gdf["geometry"] = result_gdf["geometry"].apply(
            lambda g: shape(g) if g else None
        )

    return StepResult(
        output=result_gdf,
        stats={
            "total": total,
            "success": success_count,
            "failed": fail_count,
            "success_rate": success_count / total if total > 0 else 0,
        },
        metadata={"address_field": address_field},
    )
```

## 19.5 步骤包的项目结构

建议将自定义步骤组织为独立的 Python 包：

```
my-geopipe-steps/
├── pyproject.toml
├── README.md
└── src/
    └── my_geopipe_steps/
        ├── __init__.py
        ├── vector/
        │   ├── __init__.py
        │   ├── centroid.py
        │   ├── area_filter.py
        │   └── grid_split.py
        ├── raster/
        │   ├── __init__.py
        │   └── cloud_mask.py
        └── analysis/
            ├── __init__.py
            └── accessibility.py
```

### 19.5.1 `pyproject.toml` 配置

```toml
[build-system]
requires = ["setuptools>=61"]
```

## 19.6 测试自定义步骤

### 19.6.1 单元测试

```python
# tests/test_vector_centroid.py
import pytest
import geopandas as gpd
from shapely.geometry import Polygon
from geopipe_agent.engine.context import StepContext, PipelineContext
from my_geopipe_steps.vector.centroid import vector_centroid


def make_test_gdf():
    """创建测试用 GeoDataFrame"""
    return gpd.GeoDataFrame(
        {
            "id": [1, 2, 3],
            "name": ["区域A", "区域B", "区域C"],
            "geometry": [
                Polygon([(0, 0), (1, 0), (1, 1), (0, 1)]),
                Polygon([(2, 0), (3, 0), (3, 1), (2, 1)]),
                Polygon([(4, 0), (5, 0), (5, 1), (4, 1)]),
            ],
        },
        crs="EPSG:4326",
    )


def make_step_ctx(params: dict) -> StepContext:
    """创建测试用 StepContext"""
    pipeline_ctx = PipelineContext(variables={})
    return StepContext(params=params, pipeline_ctx=pipeline_ctx, backend="native_python")


class TestVectorCentroid:

    def test_basic_centroid(self):
        """基本质心计算"""
        gdf = make_test_gdf()
        ctx = make_step_ctx({"input": gdf, "keep_attributes": True})

        result = vector_centroid(ctx)

        assert result.output is not None
        assert len(result.output) == 3
        assert result.output.geometry.geom_type.unique().tolist() == ["Point"]
        assert "name" in result.output.columns

    def test_centroid_without_attributes(self):
        """不保留属性的质心"""
        gdf = make_test_gdf()
        ctx = make_step_ctx({"input": gdf, "keep_attributes": False})

        result = vector_centroid(ctx)

        assert len(result.output.columns) == 1  # 只有 geometry 列
        assert "name" not in result.output.columns

    def test_centroid_coordinates(self):
        """验证质心坐标正确"""
        gdf = make_test_gdf()
        ctx = make_step_ctx({"input": gdf})

        result = vector_centroid(ctx)

        # 第一个正方形 (0,0)-(1,1) 的质心应为 (0.5, 0.5)
        first_centroid = result.output.geometry.iloc[0]
        assert abs(first_centroid.x - 0.5) < 1e-10
        assert abs(first_centroid.y - 0.5) < 1e-10

    def test_stats(self):
        """验证 stats 字段"""
        gdf = make_test_gdf()
        ctx = make_step_ctx({"input": gdf})

        result = vector_centroid(ctx)

        assert result.stats["feature_count"] == 3
        assert result.stats["geometry_type"] == "Point"

    def test_missing_required_param(self):
        """缺少必填参数时报错"""
        from geopipe_agent.errors import StepExecutionError
        ctx = make_step_ctx({})  # 没有 input 参数

        with pytest.raises(StepExecutionError):
            vector_centroid(ctx)
```

## 19.7 自定义步骤开发规范

### 19.7.1 必须遵守的规则

1. **返回 `StepResult`**：步骤函数必须返回 `StepResult` 对象
2. **使用 `ctx.param()` 获取参数**：不要直接访问 `ctx._params`
3. **必填参数用 `ctx.require_param()`**：自动处理缺失情况
4. **抛出 `StepExecutionError`**：不要抛出其他自定义异常
5. **线程安全**：步骤函数应是纯函数（无副作用，不使用全局状态）

### 19.7.2 推荐实践

```python
@step(
    id="vector.my_step",
    name="我的步骤",
    description="详细的功能描述",
    category="vector",
    params={
        "input": {
            "type": "geodataframe",
            "required": True,
            "description": "输入矢量数据",
        },
        "param_a": {
            "type": "float",
            "required": False,
            "default": 1.0,
            "description": "参数A，控制XXX",
        },
    },
    outputs={
        "output": {
            "type": "geodataframe",
            "description": "输出描述",
        }
    },
)
def my_step(ctx: StepContext) -> StepResult:
    # 1. 获取参数
    gdf = ctx.require_param("input")   # 必填参数
    param_a = ctx.param("param_a", default=1.0)  # 可选参数

    # 2. 参数校验
    if not isinstance(gdf, gpd.GeoDataFrame):
        from geopipe_agent.errors import StepExecutionError
        raise StepExecutionError(
            step_id="vector.my_step",
            message="input 必须是 GeoDataFrame",
            suggestion="请检查前一个步骤是否输出了矢量数据",
        )

    # 3. 执行处理
    result_gdf = process(gdf, param_a)

    # 4. 构建输出（包含有用的统计信息）
    return StepResult(
        output=result_gdf,
        stats={
            "feature_count": len(result_gdf),
            "crs": str(result_gdf.crs),
        },
    )
```

## 19.8 本章小结

本章介绍了 GeoPipeAgent 的自定义步骤开发：

1. **`@step` 装饰器**：注册步骤到全局注册表，包含 id、name、description、params、outputs
2. **`StepContext`**：获取参数（`param()`/`require_param()`）、访问其他步骤结果
3. **`StepResult`**：返回 output、stats、issues、metadata
4. **高级模式**：QC 功能、外部工具调用、进度报告
5. **项目结构**：独立 Python 包，通过 entry_points 注册
6. **测试**：单元测试（mock StepContext）和集成测试（完整流水线）

**扩展 GeoPipeAgent 的三种方式**：
- 新增步骤（本章内容）
- 新增后端（实现 BackendAdapter）
- 修改报告格式（继承 Reporter）
