# 第8章：IO 步骤数据读写

数据输入/输出（IO）是任何地理数据处理流水线的起点和终点。GeoPipeAgent 提供了四个内置的 IO 步骤，覆盖了矢量和栅格两大数据类型的读写操作。本章将详细介绍每个 IO 步骤的参数、支持的格式、使用技巧以及常见问题的解决方案。

---

## 8.1 IO 步骤概览

| 步骤 ID | 名称 | 功能 | 主要输入 | 主要输出 |
|---------|------|------|---------|---------|
| `io.read_vector` | 读取矢量数据 | 读取各种矢量格式文件 | 文件路径 | GeoDataFrame |
| `io.read_raster` | 读取栅格数据 | 读取各种栅格格式文件 | 文件路径 | rasterio dataset / numpy array |
| `io.write_vector` | 写出矢量数据 | 将矢量数据保存到文件 | GeoDataFrame + 路径 | 文件路径 |
| `io.write_raster` | 写出栅格数据 | 将栅格数据保存到文件 | 栅格数据 + 路径 | 文件路径 |

---

## 8.2 io.read_vector — 读取矢量数据

### 8.2.1 功能说明

`io.read_vector` 步骤用于从文件系统读取矢量地理数据，将其加载为 GeoPandas 的 `GeoDataFrame` 对象。支持多种主流矢量数据格式。

### 8.2.2 参数定义

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `path` | `string` | ✅ | — | 输入文件路径（支持本地路径和 URL） |
| `layer` | `string` | ❌ | `None` | 图层名称，用于多图层格式（如 GPKG、GDB） |
| `encoding` | `string` | ❌ | `None` | 字符编码（如 `UTF-8`、`GBK`），None 时自动检测 |
| `bbox` | `list` | ❌ | `None` | 空间过滤范围 `[xmin, ymin, xmax, ymax]` |
| `rows` | `number` | ❌ | `None` | 最大读取行数，用于预览或测试 |

### 8.2.3 支持的格式

| 格式 | 扩展名 | 驱动名称 | 多图层 | 编码问题 | 说明 |
|------|--------|---------|--------|---------|------|
| **Shapefile** | `.shp` | `ESRI Shapefile` | ❌ | 常见（GBK） | 最广泛使用的矢量格式，有 2GB 大小限制 |
| **GeoJSON** | `.geojson`, `.json` | `GeoJSON` | ❌ | 少见（UTF-8） | 基于 JSON 的开放格式，天然 WGS84 |
| **GeoPackage** | `.gpkg` | `GPKG` | ✅ | 少见（UTF-8） | OGC 标准，SQLite 数据库，推荐使用 |
| **GML** | `.gml` | `GML` | ✅ | 可能 | OGC 标准的 XML 格式 |
| **KML** | `.kml`, `.kmz` | `KML` | ✅ | 少见 | Google Earth 格式，总是 WGS84 |
| **CSV** | `.csv` | `CSV` | ❌ | 常见 | 需要有坐标列（x, y）或 WKT 列 |
| **FileGDB** | `.gdb` | `OpenFileGDB` | ✅ | 少见 | Esri 文件地理数据库 |

### 8.2.4 输出

| 输出 | 类型 | 说明 |
|------|------|------|
| `output` | `GeoDataFrame` | 读取到的矢量数据 |

### 8.2.5 统计信息（stats）

读取完成后，步骤会自动计算并返回以下统计信息：

| 统计项 | 类型 | 说明 | 示例值 |
|--------|------|------|--------|
| `feature_count` | `int` | 要素（行）数量 | `5000` |
| `crs` | `str` | 坐标参考系标识 | `"EPSG:4326"` |
| `geometry_types` | `list[str]` | 几何类型列表 | `["Polygon", "MultiPolygon"]` |
| `columns` | `list[str]` | 属性字段列表 | `["name", "area", "type"]` |
| `bounds` | `list[float]` | 空间范围 [xmin, ymin, xmax, ymax] | `[116.0, 39.0, 117.0, 40.0]` |

### 8.2.6 基本使用示例

#### 读取 Shapefile

```yaml
steps:
  - id: read_shp
    step: io.read_vector
    params:
      path: "data/buildings.shp"
```

#### 读取 GeoJSON

```yaml
steps:
  - id: read_geojson
    step: io.read_vector
    params:
      path: "data/points_of_interest.geojson"
```

#### 读取 GeoPackage（指定图层）

```yaml
steps:
  - id: read_gpkg
    step: io.read_vector
    params:
      path: "data/city_data.gpkg"
      layer: "buildings"
```

#### 读取带有编码的 Shapefile（中文数据）

```yaml
steps:
  - id: read_chinese_shp
    step: io.read_vector
    params:
      path: "data/中国行政区划.shp"
      encoding: "GBK"
```

#### 使用空间过滤范围读取

```yaml
steps:
  - id: read_bbox
    step: io.read_vector
    params:
      path: "data/all_buildings.shp"
      bbox: [116.3, 39.9, 116.5, 40.1]  # 北京市中心区域
```

#### 限制读取行数（用于预览/测试）

```yaml
steps:
  - id: read_preview
    step: io.read_vector
    params:
      path: "data/large_dataset.shp"
      rows: 100  # 只读取前100行
```

#### 从 URL 读取 GeoJSON

```yaml
steps:
  - id: read_remote
    step: io.read_vector
    params:
      path: "https://example.com/data/parks.geojson"
    on_error: retry  # 网络请求建议使用 retry 策略
```

### 8.2.7 内部实现逻辑

```python
@step(
    id="io.read_vector",
    name="读取矢量数据",
    description="从文件系统或 URL 读取矢量地理数据",
    category="io",
    params=[
        {"name": "path", "type": "string", "required": True,
         "description": "输入文件路径或 URL"},
        {"name": "layer", "type": "string", "required": False,
         "default": None, "description": "图层名称"},
        {"name": "encoding", "type": "string", "required": False,
         "default": None, "description": "字符编码"},
        {"name": "bbox", "type": "list", "required": False,
         "default": None, "description": "空间过滤范围"},
        {"name": "rows", "type": "number", "required": False,
         "default": None, "description": "最大读取行数"},
    ],
    outputs=[
        {"name": "output", "type": "geodataframe",
         "description": "读取到的矢量数据"},
    ],
)
def read_vector(context):
    path = context.param("path")
    layer = context.param("layer", None)
    encoding = context.param("encoding", None)
    bbox = context.param("bbox", None)
    rows = context.param("rows", None)

    # 构建读取参数
    read_kwargs = {}
    if layer is not None:
        read_kwargs["layer"] = layer
    if encoding is not None:
        read_kwargs["encoding"] = encoding
    if bbox is not None:
        read_kwargs["bbox"] = tuple(bbox)
    if rows is not None:
        read_kwargs["rows"] = rows

    # 读取数据
    gdf = gpd.read_file(path, **read_kwargs)

    # 统计信息
    stats = {
        "feature_count": len(gdf),
        "crs": str(gdf.crs) if gdf.crs else None,
        "geometry_types": list(gdf.geometry.geom_type.unique()) if not gdf.empty else [],
        "columns": list(gdf.columns),
        "bounds": gdf.total_bounds.tolist() if not gdf.empty else None,
    }

    return StepResult(output=gdf, stats=stats)
```

## 8.3 io.read_raster — 读取栅格数据

### 8.3.1 功能说明

`io.read_raster` 步骤用于从文件系统读取栅格地理数据。底层使用 `rasterio` 库进行数据读取。

### 8.3.2 参数定义

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `path` | `string` | ✅ | — | 输入栅格文件路径 |
| `band` | `number` | ❌ | `None` | 读取的波段索引（从 1 开始），None 时读取所有波段 |
| `window` | `list` | ❌ | `None` | 读取窗口 `[col_off, row_off, width, height]` |

### 8.3.3 支持的格式

| 格式 | 扩展名 | 驱动名称 | 说明 |
|------|--------|---------|------|
| **GeoTIFF** | `.tif`, `.tiff` | `GTiff` | 最常用的栅格格式，支持压缩和多波段 |
| **JPEG 2000** | `.jp2` | `JP2OpenJPEG` | 高压缩比遥感影像格式 |
| **HDF5** | `.hdf`, `.h5` | `HDF5` | 科学数据格式，支持多维数组 |
| **NetCDF** | `.nc` | `netCDF` | 气象/海洋数据常用格式 |
| **Erdas Imagine** | `.img` | `HFA` | 遥感图像处理常用格式 |
| **ASCII Grid** | `.asc` | `AAIGrid` | 文本格式栅格，便于查看但文件较大 |
| **PNG** | `.png` | `PNG` | 带地理参考的 PNG 图像 |

### 8.3.4 输出

| 输出 | 类型 | 说明 |
|------|------|------|
| `output` | `rasterio dataset / numpy array` | 栅格数据对象或数组 |

### 8.3.5 统计信息（stats）

| 统计项 | 类型 | 说明 | 示例值 |
|--------|------|------|--------|
| `shape` | `tuple` | 栅格尺寸 (bands, height, width) | `(4, 1024, 1024)` |
| `crs` | `str` | 坐标参考系 | `"EPSG:4326"` |
| `bounds` | `list[float]` | 空间范围 | `[116.0, 39.0, 117.0, 40.0]` |
| `nodata` | `float` | NoData 值 | `-9999.0` |
| `dtype` | `str` | 数据类型 | `"float32"` |
| `band_count` | `int` | 波段数量 | `4` |

### 8.3.6 使用示例

#### 读取整个 GeoTIFF

```yaml
steps:
  - id: read_dem
    step: io.read_raster
    params:
      path: "data/dem.tif"
```

#### 读取指定波段

```yaml
steps:
  - id: read_red_band
    step: io.read_raster
    params:
      path: "data/satellite_image.tif"
      band: 3  # 红色波段（Landsat Band 3）
```

#### 使用窗口读取（大文件局部读取）

```yaml
steps:
  - id: read_window
    step: io.read_raster
    params:
      path: "data/large_dem.tif"
      window: [0, 0, 512, 512]  # 从左上角读取 512x512 像素区域
```

#### 读取多光谱遥感影像

```yaml
steps:
  - id: read_satellite
    step: io.read_raster
    params:
      path: "data/landsat8_multispectral.tif"
    # 读取所有波段，后续步骤可以用 band 索引访问
```

### 8.3.7 内部实现逻辑

```python
@step(
    id="io.read_raster",
    name="读取栅格数据",
    description="从文件系统读取栅格地理数据",
    category="io",
    params=[
        {"name": "path", "type": "string", "required": True,
         "description": "输入栅格文件路径"},
        {"name": "band", "type": "number", "required": False,
         "default": None, "description": "波段索引（从1开始）"},
        {"name": "window", "type": "list", "required": False,
         "default": None, "description": "读取窗口 [col_off, row_off, width, height]"},
    ],
    outputs=[
        {"name": "output", "type": "raster",
         "description": "栅格数据对象"},
    ],
)
def read_raster(context):
    import rasterio
    from rasterio.windows import Window

    path = context.param("path")
    band = context.param("band", None)
    window_param = context.param("window", None)

    # 打开栅格文件
    src = rasterio.open(path)

    # 构建读取窗口
    window = None
    if window_param is not None:
        window = Window(
            col_off=window_param[0],
            row_off=window_param[1],
            width=window_param[2],
            height=window_param[3],
        )

    # 读取数据
    if band is not None:
        data = src.read(band, window=window)
    else:
        data = src.read(window=window)

    # 统计信息
    stats = {
        "shape": data.shape,
        "crs": str(src.crs) if src.crs else None,
        "bounds": list(src.bounds),
        "nodata": src.nodata,
        "dtype": str(data.dtype),
        "band_count": src.count,
    }

    # 封装结果（同时保留 src 和 data）
    result_data = {
        "array": data,
        "profile": src.profile.copy(),
        "transform": src.transform,
        "crs": src.crs,
        "nodata": src.nodata,
    }

    return StepResult(output=result_data, stats=stats)
```

## 8.4 io.write_vector — 写出矢量数据

### 8.4.1 功能说明

`io.write_vector` 步骤将 GeoDataFrame 写出为各种矢量数据格式。格式可以通过 `driver` 参数显式指定，也可以根据文件扩展名自动检测。

### 8.4.2 参数定义

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | `geodataframe` | ✅ | — | 要写出的 GeoDataFrame |
| `path` | `string` | ✅ | — | 输出文件路径 |
| `driver` | `string` | ❌ | 自动检测 | 输出格式驱动名称 |
| `encoding` | `string` | ❌ | `UTF-8` | 字符编码 |
| `layer` | `string` | ❌ | `None` | 图层名称（用于多图层格式） |

### 8.4.3 格式自动检测

当 `driver` 参数未指定时，GeoPipeAgent 会根据文件扩展名自动选择驱动：

| 扩展名 | 自动选择的驱动 |
|--------|--------------|
| `.shp` | `ESRI Shapefile` |
| `.geojson` | `GeoJSON` |
| `.json` | `GeoJSON` |
| `.gpkg` | `GPKG` |
| `.gml` | `GML` |
| `.kml` | `KML` |
| `.csv` | `CSV` |
| `.gdb` | `OpenFileGDB` |

```python
# 格式检测实现
EXTENSION_DRIVER_MAP = {
    ".shp": "ESRI Shapefile",
    ".geojson": "GeoJSON",
    ".json": "GeoJSON",
    ".gpkg": "GPKG",
    ".gml": "GML",
    ".kml": "KML",
    ".csv": "CSV",
}

def detect_driver(path: str) -> str:
    """根据文件扩展名检测驱动。"""
    ext = Path(path).suffix.lower()
    driver = EXTENSION_DRIVER_MAP.get(ext)
    if driver is None:
        raise ValueError(
            f"无法根据扩展名 '{ext}' 自动检测格式驱动。"
            f"请通过 driver 参数显式指定。"
            f"支持的扩展名: {list(EXTENSION_DRIVER_MAP.keys())}"
        )
    return driver
```

### 8.4.4 使用示例

#### 写出为 GeoJSON

```yaml
steps:
  - id: save_geojson
    step: io.write_vector
    params:
      input: ${process_step.output}
      path: "output/result.geojson"
```

#### 写出为 Shapefile（指定编码）

```yaml
steps:
  - id: save_shp
    step: io.write_vector
    params:
      input: ${process_step.output}
      path: "output/result.shp"
      encoding: "GBK"  # 中文属性使用 GBK 编码
```

#### 写出为 GeoPackage（指定图层）

```yaml
steps:
  - id: save_gpkg
    step: io.write_vector
    params:
      input: ${process_step.output}
      path: "output/result.gpkg"
      layer: "buildings_buffered"
```

#### 显式指定驱动

```yaml
steps:
  - id: save_explicit
    step: io.write_vector
    params:
      input: ${process_step.output}
      path: "output/result.dat"
      driver: "ESRI Shapefile"  # 显式指定，因为 .dat 扩展名无法自动检测
```

### 8.4.5 内部实现逻辑

```python
@step(
    id="io.write_vector",
    name="写出矢量数据",
    description="将 GeoDataFrame 写出为矢量数据文件",
    category="io",
    params=[
        {"name": "input", "type": "geodataframe", "required": True,
         "description": "要写出的 GeoDataFrame"},
        {"name": "path", "type": "string", "required": True,
         "description": "输出文件路径"},
        {"name": "driver", "type": "string", "required": False,
         "default": None, "description": "格式驱动名称"},
        {"name": "encoding", "type": "string", "required": False,
         "default": "UTF-8", "description": "字符编码"},
        {"name": "layer", "type": "string", "required": False,
         "default": None, "description": "图层名称"},
    ],
    outputs=[
        {"name": "output", "type": "string",
         "description": "写出的文件路径"},
    ],
)
def write_vector(context):
    from pathlib import Path

    gdf = context.param("input")
    path = context.param("path")
    driver = context.param("driver", None)
    encoding = context.param("encoding", "UTF-8")
    layer = context.param("layer", None)

    # 确保输出目录存在
    output_dir = Path(path).parent
    output_dir.mkdir(parents=True, exist_ok=True)

    # 自动检测驱动
    if driver is None:
        driver = detect_driver(path)

    # 构建写出参数
    write_kwargs = {"driver": driver, "encoding": encoding}
    if layer is not None:
        write_kwargs["layer"] = layer

    # 写出数据
    gdf.to_file(path, **write_kwargs)

    stats = {
        "feature_count": len(gdf),
        "path": str(path),
        "driver": driver,
        "file_size_mb": round(Path(path).stat().st_size / (1024 * 1024), 2),
    }

    return StepResult(output=str(path), stats=stats)
```

## 8.5 io.write_raster — 写出栅格数据

### 8.5.1 功能说明

`io.write_raster` 步骤将栅格数据（numpy 数组或 rasterio 数据集）写出为栅格文件。

### 8.5.2 参数定义

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | `raster` | ✅ | — | 输入栅格数据（包含 array、profile 等） |
| `path` | `string` | ✅ | — | 输出文件路径 |
| `driver` | `string` | ❌ | `GTiff` | 输出格式驱动名称 |
| `dtype` | `string` | ❌ | `None` | 输出数据类型，None 时保持原类型 |
| `nodata` | `number` | ❌ | `None` | NoData 值 |
| `compress` | `string` | ❌ | `None` | 压缩算法：`deflate`、`lzw`、`zstd`、`none` |

### 8.5.3 压缩选项说明

| 压缩算法 | 说明 | 压缩率 | 速度 | 适用场景 |
|---------|------|--------|------|---------|
| `deflate` | DEFLATE 压缩 | 中等 | 中等 | 通用场景，兼容性好 |
| `lzw` | LZW 压缩 | 中等 | 快 | 常用于 GIS 软件，兼容性好 |
| `zstd` | Zstandard 压缩 | 高 | 快 | 现代压缩算法，需要 GDAL 2.3+ |
| `none` | 不压缩 | 无 | 最快 | 临时文件或需要快速访问 |

### 8.5.4 使用示例

#### 基本写出

```yaml
steps:
  - id: save_raster
    step: io.write_raster
    params:
      input: ${calc_step.output}
      path: "output/ndvi.tif"
```

#### 指定压缩和数据类型

```yaml
steps:
  - id: save_compressed
    step: io.write_raster
    params:
      input: ${calc_step.output}
      path: "output/ndvi_compressed.tif"
      dtype: "float32"
      nodata: -9999
      compress: "deflate"
```

#### 写出为其他格式

```yaml
steps:
  - id: save_asc
    step: io.write_raster
    params:
      input: ${dem_step.output}
      path: "output/dem.asc"
      driver: "AAIGrid"
```

### 8.5.5 内部实现逻辑

```python
@step(
    id="io.write_raster",
    name="写出栅格数据",
    description="将栅格数据写出为栅格文件",
    category="io",
    params=[
        {"name": "input", "type": "raster", "required": True,
         "description": "输入栅格数据"},
        {"name": "path", "type": "string", "required": True,
         "description": "输出文件路径"},
        {"name": "driver", "type": "string", "required": False,
         "default": "GTiff", "description": "格式驱动名称"},
        {"name": "dtype", "type": "string", "required": False,
         "default": None, "description": "输出数据类型"},
        {"name": "nodata", "type": "number", "required": False,
         "default": None, "description": "NoData 值"},
        {"name": "compress", "type": "string", "required": False,
         "default": None, "description": "压缩算法"},
    ],
    outputs=[
        {"name": "output", "type": "string",
         "description": "写出的文件路径"},
    ],
)
def write_raster(context):
    import rasterio
    from pathlib import Path
    import numpy as np

    raster_data = context.param("input")
    path = context.param("path")
    driver = context.param("driver", "GTiff")
    dtype = context.param("dtype", None)
    nodata = context.param("nodata", None)
    compress = context.param("compress", None)

    # 确保输出目录存在
    output_dir = Path(path).parent
    output_dir.mkdir(parents=True, exist_ok=True)

    # 从输入数据中获取信息
    array = raster_data["array"]
    profile = raster_data["profile"].copy()

    # 更新 profile
    profile.update(driver=driver)

    if dtype is not None:
        profile["dtype"] = dtype
        array = array.astype(dtype)

    if nodata is not None:
        profile["nodata"] = nodata

    if compress is not None:
        profile["compress"] = compress

    # 处理数组维度
    if array.ndim == 2:
        array = np.expand_dims(array, axis=0)
    profile["count"] = array.shape[0]
    profile["height"] = array.shape[1]
    profile["width"] = array.shape[2]

    # 写出数据
    with rasterio.open(path, "w", **profile) as dst:
        dst.write(array)

    file_size = Path(path).stat().st_size
    stats = {
        "path": str(path),
        "driver": driver,
        "shape": array.shape,
        "dtype": str(array.dtype),
        "file_size_mb": round(file_size / (1024 * 1024), 2),
    }

    return StepResult(output=str(path), stats=stats)
```

## 8.7 编码处理

### 8.7.1 常见编码问题

中文 Shapefile 数据最常遇到的问题就是编码不匹配。Shapefile 的 `.dbf` 文件存储属性数据，历史上中文数据通常使用 GBK 编码，而现代软件默认使用 UTF-8。

### 8.7.2 编码识别和解决方案

| 症状 | 原因 | 解决方案 |
|------|------|---------|
| 属性值显示为乱码 | 编码不匹配 | 指定正确的 `encoding` 参数 |
| `UnicodeDecodeError` | 编码解码失败 | 指定正确的 `encoding` 参数 |
| 属性值显示为 `???` | 编码丢失 | 尝试多种编码 |

### 8.7.3 常用中文编码

| 编码名称 | Python 标识 | 说明 |
|---------|------------|------|
| GBK | `GBK` | 中文 Windows 默认编码，覆盖大部分中文字符 |
| GB2312 | `GB2312` | 早期中文编码标准，GBK 的子集 |
| GB18030 | `GB18030` | 最完整的中文编码标准，覆盖所有 Unicode 字符 |
| UTF-8 | `UTF-8` | 国际通用编码，现代软件默认选择 |
| BIG5 | `BIG5` | 繁体中文编码 |

### 8.7.4 编码处理示例

```yaml
# 读取 GBK 编码的 Shapefile
steps:
  - id: read_gbk
    step: io.read_vector
    params:
      path: "data/中国省界.shp"
      encoding: "GBK"

# 转换为 UTF-8 编码的 GeoJSON
  - id: save_utf8
    step: io.write_vector
    params:
      input: ${read_gbk.output}
      path: "output/china_provinces.geojson"
      # GeoJSON 默认 UTF-8，无需指定
```

### 8.7.5 自动编码检测（进阶）

如果不确定文件编码，可以使用以下策略：

```yaml
# 尝试默认编码读取
steps:
  - id: read_try_default
    step: io.read_vector
    params:
      path: "data/unknown_encoding.shp"
    on_error: skip

  # 如果默认失败，尝试 GBK
  - id: read_try_gbk
    step: io.read_vector
    params:
      path: "data/unknown_encoding.shp"
      encoding: "GBK"
    when: "${read_try_default.status} == 'skipped'"
    on_error: skip

  # 如果 GBK 也失败，尝试 GB18030
  - id: read_try_gb18030
    step: io.read_vector
    params:
      path: "data/unknown_encoding.shp"
      encoding: "GB18030"
    when: "${read_try_gbk.status} == 'skipped'"
```

## 8.8 大文件处理策略

### 8.8.1 问题描述

处理大型地理数据文件（数百万要素或 GB 级栅格）时，直接全量读取可能导致内存不足或处理时间过长。

### 8.8.2 矢量数据大文件策略

#### 使用 bbox 空间过滤

只读取空间范围内的数据，显著减少内存使用：

```yaml
steps:
  - id: read_large
    step: io.read_vector
    params:
      path: "data/全国POI数据.shp"
      bbox: [116.3, 39.8, 116.5, 40.0]  # 只读取目标区域
```

#### 使用 rows 限制行数

先读取少量数据进行预览和测试：

```yaml
steps:
  # 预览数据结构
  - id: preview
    step: io.read_vector
    params:
      path: "data/large_dataset.shp"
      rows: 10
```

#### 分区域处理

将大范围数据按区域分块处理：

```yaml
name: 分区域处理大文件
vars:
  area_1: [116.0, 39.0, 116.5, 39.5]
  area_2: [116.5, 39.0, 117.0, 39.5]
  area_3: [116.0, 39.5, 116.5, 40.0]
  area_4: [116.5, 39.5, 117.0, 40.0]

steps:
  - id: read_area1
    step: io.read_vector
    params:
      path: "data/large.shp"
      bbox: ${vars.area_1}

  - id: process_area1
    step: vector.buffer
    params:
      input: ${read_area1.output}
      distance: 100

  - id: save_area1
    step: io.write_vector
    params:
      input: ${process_area1.output}
      path: "output/result_area1.gpkg"
  
  # ... 对其他区域重复以上步骤
```

### 8.8.3 栅格数据大文件策略

#### 使用 window 窗口读取

只读取需要的区域：

```yaml
steps:
  - id: read_partial
    step: io.read_raster
    params:
      path: "data/large_satellite.tif"
      window: [1000, 2000, 512, 512]  # 从 (1000, 2000) 开始，读取 512x512
```

#### 使用栅格裁剪

先读取完整元数据，再按矢量边界裁剪：

```yaml
steps:
  - id: read_boundary
    step: io.read_vector
    params:
      path: "data/study_area.shp"

  - id: read_raster
    step: io.read_raster
    params:
      path: "data/large_dem.tif"

  - id: clip_raster
    step: raster.clip
    params:
      input: ${read_raster.output}
      clip_geometry: ${read_boundary.output}

  - id: save_clipped
    step: io.write_raster
    params:
      input: ${clip_raster.output}
      path: "output/dem_clipped.tif"
      compress: "deflate"
```

### 8.9.1 Shapefile 处理完整流程

```yaml
name: Shapefile 数据处理完整流程
description: |
  完整的矢量数据处理流程示例：
  1. 读取带编码的 Shapefile
  2. 投影变换到 WGS84
  3. 几何修复
  4. 缓冲区分析
  5. 保存为 GeoJSON

steps:
  # 读取 GBK 编码的 Shapefile
  - id: read_shp
    step: io.read_vector
    params:
      path: "input/城市建筑物.shp"
      encoding: "GBK"

  - id: reproject_wgs84

    when: "${read_shp.stats.crs} != 'EPSG:4326'"

  # 创建 500米 缓冲区（先投影到平面坐标系）
  - id: reproject_meter
    step: vector.reproject
    params:
      input: ${reproject_wgs84.output}
      target_crs: "EPSG:3857"

  - id: buffer_500m
    step: vector.buffer
    params:
      input: ${reproject_meter.output}
      distance: 500

  # 投影回 WGS84
  - id: reproject_back
    step: vector.reproject
    params:
      input: ${buffer_500m.output}
      target_crs: "EPSG:4326"

  # 保存结果
  - id: save_geojson
    step: io.write_vector
    params:
      input: ${reproject_back.output}
      path: "output/buildings_buffer_500m.geojson"
```

```yaml
name: 遥感影像分析流程
description: |

steps:

  - id: save_ndvi
    step: io.write_raster
    params:
      input: ${clip_ndvi.output}

  - id: ndvi_contours

      input: ${clip_ndvi.output}
      interval: 0.1

  # 保存等值线
  - id: save_contours
    step: io.write_vector
    params:
      input: ${ndvi_contours.output}
      path: "output/ndvi_contours.geojson"
```

```yaml
- id: read_data
  step: io.read_vector
```

**问题：** 无法读取或写入文件。

```
StepExecutionError: 步骤 'save_result' 执行失败
原因: PermissionError: [Errno 13] Permission denied: 'output/result.shp'
```

**解决方案：**

```bash
# 检查文件权限
ls -la output/
```

### 8.10.4 文件未找到

**问题：** 指定的输入文件不存在。

```
StepExecutionError: 步骤 'read_data' 执行失败
原因: FileNotFoundError: [Errno 2] No such file or directory: 'data/missing.shp'
```

**解决方案：**

3. 确认文件是否存在
4. Shapefile 需要 `.shp`、`.shx`、`.dbf` 三个文件齐全

### 8.10.5 内存不足

**问题：** 读取大文件时内存溢出。

```
StepExecutionError: 步骤 'read_data' 执行失败
原因: MemoryError: Unable to allocate 4.00 GiB
```

**解决方案：**

```yaml
# 方案1: 使用 bbox 过滤
- id: read_data
  step: io.read_vector
  params:

  step: io.read_vector
  params:
    path: "data/huge_dataset.shp"
    rows: 100000

  step: io.read_raster
  params:

```

### 8.10.6 Shapefile 组件文件缺失

**问题：** Shapefile 缺少必需的组件文件。

一个完整的 Shapefile 包含以下文件：

| 文件 | 必需 | 说明 |
|------|------|------|
| `.shp` | ✅ | 几何数据 |
| `.shx` | ✅ | 空间索引 |
| `.dbf` | ✅ | 属性数据 |
| `.prj` | 推荐 | 坐标参考系定义 |
| `.cpg` | 推荐 | 编码信息 |
| `.sbn`/`.sbx` | 可选 | 空间索引（Esri） |

**解决方案：** 确保传输数据时包含所有必需文件。建议使用 GeoPackage 格式（`.gpkg`）替代 Shapefile，因为它是单文件格式，不会出现文件缺失的问题。
