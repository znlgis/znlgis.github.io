# 第七章：IO 步骤详解——数据读写

## 7.1 概述

IO 步骤是 GeoPipeAgent 流水线的起点和终点，负责 GIS 数据的读取和写入。框架提供了 4 个 IO 步骤，覆盖矢量和栅格两种数据类型。

| 步骤 ID | 名称 | 说明 |
|---------|------|------|
| `io.read_vector` | 读取矢量数据 | 从文件读取矢量数据为 GeoDataFrame |
| `io.write_vector` | 写入矢量数据 | 将 GeoDataFrame 写入文件 |
| `io.read_raster` | 读取栅格数据 | 从文件读取栅格数据（数组 + 元信息） |
| `io.write_raster` | 写入栅格数据 | 将栅格数据写入 GeoTIFF 文件 |

## 7.2 io.read_vector — 读取矢量数据

### 7.2.1 功能说明

从文件读取矢量数据，返回 GeoPandas 的 `GeoDataFrame` 对象。支持多种常见矢量格式。

### 7.2.2 参数定义

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `path` | string | ✅ | — | 矢量数据文件路径 |
| `layer` | string | ❌ | — | 图层名称（多图层文件时使用） |
| `encoding` | string | ❌ | "utf-8" | 文件编码 |

### 7.2.3 支持的格式

| 格式 | 扩展名 | 说明 |
|------|--------|------|
| Shapefile | `.shp` | ESRI Shapefile，需要 `.shx`、`.dbf` 等配套文件 |
| GeoJSON | `.geojson`、`.json` | JSON 格式的矢量数据 |
| GeoPackage | `.gpkg` | OGC 标准的 SQLite 数据库格式 |
| KML | `.kml` | Google Earth 标记语言 |
| GML | `.gml` | OGC 标准的 XML 格式 |
| CSV | `.csv` | 带坐标列的 CSV 文件 |

### 7.2.4 输出

| 输出 | 类型 | 说明 |
|------|------|------|
| `output` | GeoDataFrame | 读取的矢量数据 |

### 7.2.5 统计信息

返回的 `stats` 包含：

| 键 | 类型 | 说明 |
|----|------|------|
| `feature_count` | int | 要素数量 |
| `crs` | str | 坐标参考系（如 "EPSG:4326"） |
| `geometry_types` | list[str] | 几何类型列表（如 ["Point", "MultiPoint"]） |
| `columns` | list[str] | 属性列名列表 |

### 7.2.6 使用示例

```yaml
# 基本读取
- id: read-roads
  use: io.read_vector
  params:
    path: "data/roads.shp"

# 指定图层和编码
- id: read-buildings
  use: io.read_vector
  params:
    path: "data/city.gpkg"
    layer: "buildings"
    encoding: "utf-8"

# 使用变量
- id: read-data
  use: io.read_vector
  params:
    path: "${input_path}"
```

### 7.2.7 源码实现

```python
def io_read_vector(ctx: StepContext) -> StepResult:
    import geopandas as gpd

    path = ctx.param("path")
    layer = ctx.param("layer")
    encoding = ctx.param("encoding", "utf-8")

    kwargs = {}
    if layer:
        kwargs["layer"] = layer
    if encoding:
        kwargs["encoding"] = encoding

    gdf = gpd.read_file(path, **kwargs)

    stats = {
        "feature_count": len(gdf),
        "crs": str(gdf.crs) if gdf.crs else None,
        "geometry_types": list(gdf.geometry.geom_type.unique()) if len(gdf) > 0 else [],
        "columns": list(gdf.columns),
    }

    return StepResult(output=gdf, stats=stats)
```

## 7.3 io.write_vector — 写入矢量数据

### 7.3.1 功能说明

将 GeoDataFrame 写入文件，支持多种输出格式，自动创建输出目录。

### 7.3.2 参数定义

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | GeoDataFrame | ✅ | — | 输入矢量数据 |
| `path` | string | ✅ | — | 输出文件路径 |
| `format` | string | ❌ | 根据扩展名推断 | 输出格式（GeoJSON、ESRI Shapefile、GPKG） |

### 7.3.3 使用示例

```yaml
# 写入 GeoJSON
- id: save-result
  use: io.write_vector
  params:
    input: "$buffer"
    path: "output/result.geojson"
    format: "GeoJSON"

# 写入 Shapefile
- id: save-shp
  use: io.write_vector
  params:
    input: "$buffer"
    path: "output/result.shp"
    format: "ESRI Shapefile"

# 写入 GeoPackage
- id: save-gpkg
  use: io.write_vector
  params:
    input: "$data"
    path: "output/result.gpkg"
    format: "GPKG"
```

## 7.4 io.read_raster — 读取栅格数据

### 7.4.1 功能说明

从文件读取栅格数据，返回栅格数据数组和元信息。使用 `rasterio` 库实现。

### 7.4.2 参数定义

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `path` | string | ✅ | — | 栅格数据文件路径 |

### 7.4.3 支持的格式

| 格式 | 扩展名 | 说明 |
|------|--------|------|
| GeoTIFF | `.tif`、`.tiff` | 最常用的栅格格式 |
| PNG | `.png` | 带地理信息的 PNG |
| JPEG | `.jpg`、`.jpeg` | 带地理信息的 JPEG |

### 7.4.4 统计信息

返回的 `stats` 包含：

| 键 | 类型 | 说明 |
|----|------|------|
| `width` | int | 栅格宽度（像素） |
| `height` | int | 栅格高度（像素） |
| `bands` | int | 波段数 |
| `crs` | str | 坐标参考系 |
| `bounds` | list | 空间范围 [left, bottom, right, top] |
| `dtypes` | list[str] | 数据类型列表 |

### 7.4.5 使用示例

```yaml
- id: read-dem
  use: io.read_raster
  params:
    path: "data/dem.tif"

- id: read-satellite
  use: io.read_raster
  params:
    path: "${raster_path}"
```

## 7.5 io.write_raster — 写入栅格数据

### 7.5.1 功能说明

将栅格数据写入 GeoTIFF 文件。自动创建输出目录。

### 7.5.2 参数定义

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | dict | ✅ | — | 栅格数据（包含 data、transform、crs 等） |
| `path` | string | ✅ | — | 输出文件路径 |

### 7.5.3 使用示例

```yaml
- id: save-raster
  use: io.write_raster
  params:
    input: "$calc"
    path: "output/ndvi.tif"
```

## 7.6 IO 步骤在流水线中的典型位置

IO 步骤通常在流水线的首尾位置出现：

```yaml
pipeline:
  name: "典型 IO 流程"
  steps:
    # 1. 输入——读取数据
    - id: read-input
      use: io.read_vector
      params:
        path: "data/input.shp"

    # 2. 处理——分析步骤
    - id: process
      use: vector.buffer
      params:
        input: "$read-input"
        distance: 100

    # 3. 输出——保存结果
    - id: write-output
      use: io.write_vector
      params:
        input: "$process"
        path: "output/result.geojson"
```

## 7.7 多输入多输出模式

一个流水线可以读取多个文件，也可以输出多个文件：

```yaml
pipeline:
  name: "多输入多输出"
  steps:
    - id: read-layer1
      use: io.read_vector
      params:
        path: "data/landuse.shp"

    - id: read-layer2
      use: io.read_vector
      params:
        path: "data/flood_zone.shp"

    - id: overlay
      use: vector.overlay
      params:
        input: "$read-layer1"
        overlay_layer: "$read-layer2"
        how: "intersection"

    - id: save-vector
      use: io.write_vector
      params:
        input: "$overlay"
        path: "output/intersection.geojson"
```

## 7.8 与其他步骤的衔接

IO 步骤的输出是其他分析步骤的输入基础：

- `io.read_vector` → 输出 GeoDataFrame → 供 `vector.*`、`qc.*`、`analysis.*` 步骤使用
- `io.read_raster` → 输出栅格数据字典 → 供 `raster.*`、`qc.raster_*` 步骤使用
- `io.write_vector` → 接收 GeoDataFrame → 写入文件
- `io.write_raster` → 接收栅格数据字典 → 写入 GeoTIFF

## 7.9 本章小结

本章详细介绍了 GeoPipeAgent 的四个 IO 步骤。`io.read_vector` 和 `io.write_vector` 处理矢量数据的读写，支持 Shapefile、GeoJSON、GeoPackage 等多种格式。`io.read_raster` 和 `io.write_raster` 处理栅格数据的读写，主要支持 GeoTIFF 格式。IO 步骤是流水线的基础，它们的输出直接供后续分析步骤使用。
