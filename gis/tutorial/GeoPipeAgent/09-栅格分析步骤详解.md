# 第9章：栅格分析步骤详解

> 本章将全面介绍 GeoPipeAgent 的五个栅格分析步骤。您将了解栅格投影转换、裁剪、波段数学计算、统计分析和等值线生成的参数配置与源码实现，以及 GeoPipeAgent 中栅格数据的内部表示模型。

---

## 9.1 栅格步骤概述

### 9.1.1 五个栅格步骤

| 步骤 ID | 功能 | 核心依赖 |
|---------|------|----------|
| `raster.reproject` | 栅格投影转换 | rasterio.warp |
| `raster.clip` | 栅格裁剪 | rasterio.mask |
| `raster.calc` | 栅格计算（波段数学） | numpy, ast |
| `raster.stats` | 栅格统计 | numpy |
| `raster.contour` | 等值线生成 | matplotlib / numpy |

### 9.1.2 rasterio 依赖

所有栅格步骤都依赖 `rasterio` 库。rasterio 是 Python 中最流行的栅格数据 I/O 库，基于 GDAL 构建，提供了 Pythonic 的 API。

```python
import rasterio
from rasterio.warp import calculate_default_transform, reproject, Resampling
from rasterio.mask import mask as rasterio_mask
```

### 9.1.3 栅格步骤与矢量步骤的差异

| 特性 | 矢量步骤 | 栅格步骤 |
|------|----------|----------|
| 数据类型 | GeoDataFrame | raster_info 字典 |
| 后端委托 | 大多使用 `run_backend_op` | 直接实现 |
| 核心库 | geopandas / shapely | rasterio / numpy |
| 输出格式 | GeoDataFrame | raster_info 字典（或 GeoDataFrame） |

栅格步骤不使用后端委托机制，因为 rasterio 已经提供了统一且高效的接口，不需要多后端支持。

## 9.2 raster.reproject 栅格投影转换

### 9.2.1 功能说明

`raster.reproject` 将栅格数据从源坐标参考系转换到目标坐标参考系。投影转换过程中需要对像素值进行重采样（resampling），因为源栅格和目标栅格的像素网格通常不对齐。

### 9.2.2 参数定义

| 参数 | 类型 | 必需 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | `dict` | ✅ | — | 输入栅格数据（raster_info 字典） |
| `target_crs` | `str` | ✅ | — | 目标坐标参考系（如 `"EPSG:3857"`） |
| `resampling` | `str` | ❌ | `"nearest"` | 重采样方法 |

### 9.2.3 重采样方法

| 方法 | 说明 | 适用场景 |
|------|------|----------|
| `nearest` | 最邻近采样 | 分类数据（土地利用类型等离散值） |
| `bilinear` | 双线性插值 | 连续数据（DEM、温度等），平衡速度与质量 |
| `cubic` | 三次卷积插值 | 连续数据，质量最高但速度最慢 |

重采样方法的选择对结果有显著影响：

```
最邻近 (nearest)：       双线性 (bilinear)：      三次卷积 (cubic)：
┌──┬──┬──┬──┐           ┌──┬──┬──┬──┐           ┌──┬──┬──┬──┐
│10│10│20│20│           │10│12│16│20│           │10│11│15│20│
├──┼──┼──┼──┤           ├──┼──┼──┼──┤           ├──┼──┼──┼──┤
│10│10│20│20│           │15│17│19│22│           │14│16│18│21│
├──┼──┼──┼──┤           ├──┼──┼──┼──┤           ├──┼──┼──┼──┤
│30│30│40│40│           │25│27│31│35│           │24│26│30│34│
├──┼──┼──┼──┤           ├──┼──┼──┼──┤           ├──┼──┼──┼──┤
│30│30│40│40│           │30│32│36│40│           │30│32│36│40│
└──┴──┴──┴──┘           └──┴──┴──┴──┘           └──┴──┴──┴──┘
保留原始值，有锯齿       过渡平滑                  最平滑，可能超出原始范围
```

### 9.2.4 rasterio.warp 工作流程

栅格投影转换包含三个关键步骤：

```python
from rasterio.warp import calculate_default_transform, reproject, Resampling

# 1. 计算目标变换参数
transform, width, height = calculate_default_transform(
    src_crs,        # 源坐标系
    target_crs,     # 目标坐标系
    src_width,      # 源宽度
    src_height,     # 源高度
    *src_bounds,    # 源范围 (left, bottom, right, top)
)

# 2. 准备目标数组
dst_data = np.zeros((band_count, height, width), dtype=src_dtype)

# 3. 执行投影转换
reproject(
    source=src_data,
    destination=dst_data,
    src_transform=src_transform,
    src_crs=src_crs,
    dst_transform=transform,
    dst_crs=target_crs,
    resampling=Resampling.nearest,  # 或 bilinear, cubic
)
```

### 9.2.5 源码分析

```python
@step(id="raster.reproject", ...)
def reproject_raster(ctx):
    raster_info = ctx.input("input")
    target_crs = ctx.param("target_crs")
    resampling_str = ctx.param("resampling") or "nearest"

    # 映射重采样方法字符串到 rasterio 枚举
    resampling_map = {
        "nearest": Resampling.nearest,
        "bilinear": Resampling.bilinear,
        "cubic": Resampling.cubic,
    }
    resampling = resampling_map[resampling_str]

    src_data = raster_info["data"]
    src_crs = raster_info["crs"]
    src_transform = raster_info["transform"]
    profile = raster_info["profile"]

    # 计算目标变换
    transform, width, height = calculate_default_transform(
        src_crs, target_crs,
        src_data.shape[-1], src_data.shape[-2],
        *rasterio.transform.array_bounds(
            src_data.shape[-2], src_data.shape[-1], src_transform
        ),
    )

    # 执行重投影
    dst_data = np.zeros(
        (src_data.shape[0], height, width), dtype=src_data.dtype
    )
    for i in range(src_data.shape[0]):
        reproject(
            source=src_data[i],
            destination=dst_data[i],
            src_transform=src_transform,
            src_crs=src_crs,
            dst_transform=transform,
            dst_crs=target_crs,
            resampling=resampling,
        )

    # 更新 profile
    new_profile = profile.copy()
    new_profile.update({
        "crs": target_crs,
        "transform": transform,
        "width": width,
        "height": height,
    })

    result = {
        "data": dst_data,
        "transform": transform,
        "crs": CRS.from_user_input(target_crs),
        "profile": new_profile,
        "path": raster_info.get("path"),
    }

    stats = {
        "source_crs": str(src_crs),
        "target_crs": target_crs,
        "width": width,
        "height": height,
    }

    return StepResult(output=result, stats=stats)
```

### 9.2.6 使用示例

```yaml
  params:
    input: "$steps.read_dem"
```

## 9.3 raster.clip 栅格裁剪

### 9.3.1 功能说明

`raster.clip` 使用矢量几何（多边形）对栅格数据进行空间裁剪，只保留几何范围内的像素值，范围外的像素设为 nodata。

### 9.3.2 参数定义

| 参数 | 类型 | 必需 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | `dict` | ✅ | — | 输入栅格数据 |
| `mask` | `GeoDataFrame` | ✅ | — | 裁剪掩膜（矢量多边形） |
| `crop` | `bool` | ❌ | `True` | 是否裁切到掩膜范围 |
| `nodata` | `float` | ❌ | `None` | 掩膜外的像素值 |

### 9.3.3 crop 选项

`crop` 参数控制输出栅格的范围：

```
crop=True（默认）：                   crop=False：
输出范围裁切到掩膜边界框              保持原始栅格范围

┌─────────┐ 原始栅格               ┌─────────────────┐ 原始栅格
│ ░░░░░░░ │                        │ nodata  nodata   │
│ ░┌───┐░ │                        │ ░┌───┐░ nodata   │
│ ░│数据│░ │  ──▶  ┌───┐           │ ░│数据│░ nodata   │
│ ░└───┘░ │        │数据│           │ ░└───┘░ nodata   │
│ ░░░░░░░ │        └───┘           │ nodata  nodata   │
└─────────┘                        └─────────────────┘
```

- **`crop=True`**：输出栅格的范围裁切到掩膜的边界框，减小文件体积
- **`crop=False`**：输出栅格保持原始范围，掩膜外区域填充 nodata

### 9.3.4 rasterio.mask 机制

```python
from rasterio.mask import mask as rasterio_mask

# shapes 是 GeoJSON 格式的几何列表
out_image, out_transform = rasterio_mask(
    dataset,           # rasterio 数据集
    shapes,            # 裁剪几何列表
    crop=True,         # 是否裁切范围
    nodata=nodata,     # nodata 值
    filled=True,       # 是否填充 nodata
)
```

由于 `raster.clip` 接收的是 `raster_info` 字典而非文件路径，实际实现中需要使用 `rasterio.io.MemoryFile` 创建内存中的数据集：

```python
import rasterio
from rasterio.io import MemoryFile

# 将 raster_info 写入内存文件
with MemoryFile() as memfile:
    with memfile.open(**profile) as dataset:
        dataset.write(data)

    with memfile.open() as dataset:
        out_image, out_transform = rasterio_mask(
            dataset, shapes, crop=crop, nodata=nodata
        )
```

### 9.3.5 源码分析

```python
@step(id="raster.clip", ...)
def clip_raster(ctx):
    raster_info = ctx.input("input")
    mask_gdf = ctx.param("mask")
    crop = ctx.param("crop")
    nodata = ctx.param("nodata")

    if crop is None:
        crop = True

    data = raster_info["data"]
    profile = raster_info["profile"].copy()

    # 将 GeoDataFrame 几何转为 GeoJSON 格式
    shapes = [geom.__geo_interface__ for geom in mask_gdf.geometry]

    # 使用内存文件执行裁剪
    with MemoryFile() as memfile:
        with memfile.open(**profile) as ds:
            ds.write(data)

        with memfile.open() as ds:
            out_image, out_transform = rasterio_mask(
                ds, shapes, crop=crop,
                nodata=nodata or profile.get("nodata"),
                filled=True,
            )

    # 更新 profile
    profile.update({
        "transform": out_transform,
        "height": out_image.shape[-2],
        "width": out_image.shape[-1],
    })
    if nodata is not None:
        profile["nodata"] = nodata

    result = {
        "data": out_image,
        "transform": out_transform,
        "crs": raster_info["crs"],
        "profile": profile,
        "path": raster_info.get("path"),
    }

    stats = {
        "width": out_image.shape[-1],
        "height": out_image.shape[-2],
        "crop": crop,
    }

    return StepResult(output=result, stats=stats)
```

## 9.4 raster.calc 栅格计算

### 9.4.1 功能说明

`raster.calc` 执行波段数学运算，允许用户通过数学表达式对栅格波段进行计算。这是遥感影像分析的核心操作，最典型的应用是计算各类植被指数。

### 9.4.2 参数定义

| 参数 | 类型 | 必需 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | `dict` | ✅ | — | 输入栅格数据 |
| `expression` | `str` | ✅ | — | 波段数学表达式 |
| `output_dtype` | `str` | ❌ | `"float32"` | 输出数据类型 |

### 9.4.3 波段数学表达式

表达式中使用 `B1`、`B2`、`B3` 等变量引用各波段：

| 表达式 | 说明 |
|--------|------|
| `"B1 + B2"` | 波段1 + 波段2 |
| `"(B4 - B3) / (B4 + B3)"` | NDVI（归一化植被指数） |
| `"B1 * 0.01 + 273.15"` | 温度单位转换 |
| `"np.where(B1 > 0, B1, 0)"` | 条件运算（将负值设为0） |
| `"np.sqrt(B1**2 + B2**2)"` | 多波段计算 |

### 9.4.4 NDVI 计算示例

NDVI（Normalized Difference Vegetation Index）是最常用的植被指数：

```
NDVI = (NIR - Red) / (NIR + Red)
```

其中 NIR 为近红外波段，Red 为红色波段。对于 Landsat 8 影像：

- B4 = Red（红色波段）
- B5 = NIR（近红外波段）

```yaml
- id: calc_ndvi
  step: raster.calc
  params:
    input: "$steps.read_landsat"
    expression: "(B5 - B4) / (B5 + B4)"
    output_dtype: float32
```

### 9.4.5 AST 安全验证

为防止恶意代码注入，`raster.calc` 使用 Python AST（抽象语法树）对表达式进行安全验证：

```python
# safe_eval.py
import ast

SAFE_NP_FUNCS = {
    "where", "sqrt", "abs", "log", "log10", "exp",
    "sin", "cos", "tan", "minimum", "maximum",
    "clip", "nan_to_num", "isnan", "isinf",
}

def validate_calc_ast(expression: str) -> None:
    """验证栅格计算表达式的安全性。"""
    tree = ast.parse(expression, mode="eval")

    for node in ast.walk(tree):
        # 只允许特定的节点类型
        if isinstance(node, ast.Call):
            # 只允许 np.xxx 调用，且函数名在白名单中
            if isinstance(node.func, ast.Attribute):
                if isinstance(node.func.value, ast.Name):
                    if node.func.value.id == "np":
                        if node.func.attr not in SAFE_NP_FUNCS:
                            raise ValueError(
                                f"不允许的 numpy 函数: np.{node.func.attr}"
                            )
                        continue
            raise ValueError(f"不允许的函数调用: {ast.dump(node.func)}")
```

**SAFE_NP_FUNCS 白名单：**

| 函数 | 说明 |
|------|------|
| `np.where` | 条件选择 |
| `np.sqrt` | 平方根 |
| `np.abs` | 绝对值 |
| `np.log` / `np.log10` | 对数 |
| `np.exp` | 指数 |
| `np.sin` / `np.cos` / `np.tan` | 三角函数 |
| `np.minimum` / `np.maximum` | 逐元素最小/最大值 |
| `np.clip` | 值域裁切 |
| `np.nan_to_num` | NaN 替换 |
| `np.isnan` / `np.isinf` | 值检测 |

### 9.4.6 表达式求值过程

```python
@step(id="raster.calc", ...)
def calc_raster(ctx):
    raster_info = ctx.input("input")
    expression = ctx.param("expression")
    output_dtype = ctx.param("output_dtype") or "float32"

    data = raster_info["data"]

    # 1. AST 安全验证
    validate_calc_ast(expression)

    # 2. 构建波段变量字典
    band_vars = {}
    for i in range(data.shape[0]):
        band_vars[f"B{i+1}"] = data[i].astype("float64")

    # 3. 添加 numpy 引用
    band_vars["np"] = np

    # 4. 执行计算
    result_data = eval(expression, {"__builtins__": {}}, band_vars)

    # 5. 转换输出类型
    result_data = np.array(result_data, dtype=output_dtype)

    # 6. 确保维度正确（添加波段维度）
    if result_data.ndim == 2:
        result_data = result_data[np.newaxis, ...]

    # 更新 profile
    profile = raster_info["profile"].copy()
    profile.update({
        "dtype": output_dtype,
        "count": result_data.shape[0],
    })

    result = {
        "data": result_data,
        "transform": raster_info["transform"],
        "crs": raster_info["crs"],
        "profile": profile,
        "path": raster_info.get("path"),
    }

    return StepResult(output=result, stats={
        "expression": expression,
        "output_dtype": output_dtype,
        "shape": list(result_data.shape),
    })
```

关键安全措施：

- 使用 `validate_calc_ast` 预检表达式
- `eval` 的 `globals` 设为 `{"__builtins__": {}}`，禁用所有内置函数
- 只注入波段变量和受限的 numpy 引用

## 9.5 raster.stats 栅格统计

### 9.5.1 功能说明

`raster.stats` 计算栅格数据的统计信息，包括每个波段的最小值、最大值、均值、标准差和 nodata 像素数。

### 9.5.2 参数定义

| 参数 | 类型 | 必需 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | `dict` | ✅ | — | 输入栅格数据 |

### 9.5.3 返回的统计信息

`raster.stats` 的主要输出在 `stats` 中，按波段组织：

```python
stats = {
    "bands": [
        {
            "band": 1,
            "min": 0.0,
            "max": 4523.7,
            "mean": 856.3,
            "std": 412.8,
            "nodata_count": 1234,
        },
        {
            "band": 2,
            "min": -10.5,
            "max": 3890.2,
            "mean": 723.1,
            "std": 389.4,
            "nodata_count": 1234,
        },
        # ...
    ],
    "band_count": 2,
    "width": 512,
    "height": 512,
}
```

### 9.5.4 源码分析

```python
@step(id="raster.stats", ...)
def stats_raster(ctx):
    raster_info = ctx.input("input")
    data = raster_info["data"]
    profile = raster_info["profile"]
    nodata = profile.get("nodata")

    band_stats = []
    for i in range(data.shape[0]):
        band_data = data[i]

        # 掩盖 nodata 值
        if nodata is not None:
            valid_mask = band_data != nodata
            valid_data = band_data[valid_mask]
            nodata_count = int((~valid_mask).sum())
        else:
            valid_data = band_data.ravel()
            nodata_count = 0

        band_stats.append({
            "band": i + 1,
            "min": float(np.nanmin(valid_data)) if len(valid_data) > 0 else None,
            "max": float(np.nanmax(valid_data)) if len(valid_data) > 0 else None,
            "mean": float(np.nanmean(valid_data)) if len(valid_data) > 0 else None,
            "std": float(np.nanstd(valid_data)) if len(valid_data) > 0 else None,
            "nodata_count": nodata_count,
        })

    stats = {
        "bands": band_stats,
        "band_count": data.shape[0],
        "width": data.shape[-1],
        "height": data.shape[-2],
    }

    return StepResult(output=raster_info, stats=stats)
```

## 9.6 raster.contour 等值线生成

### 9.6.1 功能说明

`raster.contour` 从栅格数据中提取等值线，将连续的栅格数据转换为矢量线要素。这是栅格转矢量的典型操作，常用于从 DEM 生成等高线。

### 9.6.2 参数定义

| 参数 | 类型 | 必需 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | `dict` | ✅ | — | 输入栅格数据 |
| `interval` | `float` | ✅ | — | 等值线间隔 |
| `min_value` | `float` | ❌ | `None` | 最小等值线值 |
| `max_value` | `float` | ❌ | `None` | 最大等值线值 |
| `band` | `int` | ❌ | `1` | 要处理的波段号 |

### 9.6.3 等值线原理

等值线连接所有具有相同值的点：

```
栅格数据：                    等值线（interval=100）：
┌────┬────┬────┬────┐
│ 50 │120 │180 │250 │        ───── 100
├────┼────┼────┼────┤        ───── 200
│100 │200 │300 │350 │        ───── 300
├────┼────┼────┼────┤
│150 │280 │400 │420 │
├────┼────┼────┼────┤
│200 │350 │450 │500 │        ───── 400
└────┴────┴────┴────┘        ───── 500
```

### 9.6.4 输出数据

`raster.contour` 的输出与其他栅格步骤不同——它返回 **GeoDataFrame**（矢量数据），而非 raster_info：

```python
# 输出的 GeoDataFrame 包含：
# - geometry: LineString 几何（等值线）
# - elevation: 等值线对应的值
```

这使得 `raster.contour` 可以直接连接到 `io.write_vector` 步骤。

### 9.6.5 源码分析

```python
@step(id="raster.contour", ...)
def contour_raster(ctx):
    raster_info = ctx.input("input")
    interval = ctx.param("interval")
    min_value = ctx.param("min_value")
    max_value = ctx.param("max_value")
    band = ctx.param("band") or 1

    data = raster_info["data"]
    transform = raster_info["transform"]
    crs = raster_info["crs"]

    # 选择波段（1-indexed 转 0-indexed）
    band_data = data[band - 1]

    # 确定等值线级别
    if min_value is None:
        min_value = float(np.nanmin(band_data))
    if max_value is None:
        max_value = float(np.nanmax(band_data))

    levels = np.arange(min_value, max_value + interval, interval)

    # 使用 matplotlib 的 contour 提取等值线
    import matplotlib.pyplot as plt

    fig, ax = plt.subplots()
    cs = ax.contour(band_data, levels=levels)
    plt.close(fig)

    # 将 contour 路径转为 shapely LineString
    from shapely.geometry import LineString

    lines = []
    elevations = []

    for level_idx, level in enumerate(cs.levels):
        for path in cs.collections[level_idx].get_paths():
            vertices = path.vertices
            if len(vertices) >= 2:
                # 像素坐标转地理坐标
                coords = [
                    transform * (x, y) for x, y in vertices
                ]
                lines.append(LineString(coords))
                elevations.append(float(level))

    # 构建 GeoDataFrame
    gdf = gpd.GeoDataFrame(
        {"elevation": elevations},
        geometry=lines,
        crs=crs,
    )

    stats = {
        "contour_count": len(gdf),
        "interval": interval,
        "min_elevation": float(levels[0]),
        "max_elevation": float(levels[-1]),
    }

    return StepResult(output=gdf, stats=stats)
```

### 9.6.6 使用示例

```yaml
# 从 DEM 生成 50 米间隔的等高线
- id: extract_contours
  step: raster.contour
  params:
    input: "$steps.read_dem"
    interval: 50
    min_value: 0
    max_value: 5000
    band: 1
```

## 9.7 栅格数据模型

### 9.7.1 raster_info 字典

GeoPipeAgent 中栅格数据以 `raster_info` 字典的形式在步骤之间传递：

```python
raster_info = {
    "data": np.ndarray,               # 栅格数据 (bands, height, width)
    "transform": rasterio.Affine,      # 仿射变换矩阵
    "crs": rasterio.crs.CRS,           # 坐标参考系
    "profile": dict,                   # rasterio profile
    "path": str | None,                # 原始文件路径（可选）
}
```

### 9.7.2 data 字段

`data` 是一个三维 NumPy 数组，维度为 `(bands, height, width)`：

```python
# 单波段 DEM 示例
data.shape = (1, 512, 512)
data.dtype = float32

# 三波段 RGB 影像示例
data.shape = (3, 1024, 1024)
data.dtype = uint8

# 访问特定波段
band1 = data[0]  # 第一波段，shape (512, 512)
band2 = data[1]  # 第二波段
```

### 9.7.3 transform 字段

仿射变换矩阵（`rasterio.transform.Affine`）定义了像素坐标到地理坐标的映射关系：

```python
from rasterio.transform import Affine

# 典型的仿射变换
transform = Affine(
    0.001,    # a: 像素宽度（x 方向分辨率）
    0.0,      # b: x 方向旋转（通常为 0）
    116.0,    # c: 左上角 x 坐标
    0.0,      # d: y 方向旋转（通常为 0）
    -0.001,   # e: 像素高度（y 方向分辨率，通常为负值）
    40.0,     # f: 左上角 y 坐标
)

# 像素坐标 (col, row) 转地理坐标 (x, y)
x, y = transform * (col, row)
```

### 9.7.4 profile 字段

`profile` 是一个字典，包含创建 rasterio 数据集所需的全部配置：

```python
profile = {
    "driver": "GTiff",            # 文件格式驱动
    "dtype": "float32",           # 数据类型
    "width": 512,                 # 宽度（像素）
    "height": 512,                # 高度（像素）
    "count": 1,                   # 波段数
    "crs": CRS.from_epsg(4326),   # 坐标参考系
    "transform": Affine(...),     # 仿射变换
    "nodata": -9999.0,            # 无数据值
    "compress": "lzw",            # 压缩方式（可选）
    "tiled": True,                # 分块存储（可选）
}
```

## 9.8 栅格步骤组合实战

### 9.8.1 DEM 处理流水线

```yaml
name: DEM 处理与分析
description: 读取 DEM，投影转换、裁剪到研究区域、计算坡度、生成等高线

steps:
  # 1. 读取数据
  - id: read_dem
    step: io.read_raster
    params:
      path: "data/srtm_dem.tif"

  - id: read_boundary
    step: io.read_vector
    params:
      path: "data/study_area.gpkg"

  # 2. 投影转换
  - id: reproject_dem
    step: raster.reproject
    params:
      input: "$steps.read_dem"
      target_crs: "EPSG:32650"
      resampling: bilinear

  # 3. 裁剪到研究区域
  - id: clip_dem
    step: raster.clip
    params:
      input: "$steps.reproject_dem"
      mask: "$steps.read_boundary"
      crop: true
      nodata: -9999

  # 4. 获取统计信息
  - id: dem_stats
    step: raster.stats
    params:
      input: "$steps.clip_dem"

  # 5. 生成等高线
  - id: contours
    step: raster.contour
    params:
      input: "$steps.clip_dem"
      interval: 100

  # 6. 保存结果
  - id: save_dem
    step: io.write_raster
    params:
      input: "$steps.clip_dem"
      path: "output/dem_clipped.tif"

  - id: save_contours
    step: io.write_vector
    params:
      input: "$steps.contours"
      path: "output/contours.gpkg"
      format: gpkg
```

### 9.8.2 遥感影像分析流水线

```yaml
name: NDVI 植被指数计算

steps:

      input: "$steps.calc_ndvi"
```

## 9.9 本章小结

本章详细介绍了 GeoPipeAgent 的五个栅格分析步骤：

1. **`raster.reproject`**：基于 `rasterio.warp` 执行栅格投影转换，支持 nearest / bilinear / cubic 三种重采样方法
2. **`raster.clip`**：基于 `rasterio.mask` 使用矢量几何裁剪栅格，支持 crop 和 nodata 选项
3. **`raster.calc`**：波段数学运算，使用 B1/B2/B3 引用波段，通过 AST 安全验证防止代码注入，白名单限制 numpy 函数调用
4. **`raster.stats`**：逐波段计算 min / max / mean / std / nodata_count 统计信息
5. **`raster.contour`**：从栅格提取等值线生成 GeoDataFrame，是栅格转矢量的桥梁

同时介绍了 GeoPipeAgent 的栅格数据模型 `raster_info`，包含 data（numpy 数组）、transform（仿射变换）、crs（坐标系）和 profile（完整配置）四个核心组成部分。
