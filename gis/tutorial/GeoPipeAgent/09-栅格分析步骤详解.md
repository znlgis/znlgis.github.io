# 第九章：栅格分析步骤详解

## 9.1 概述

栅格分析步骤（前缀 `raster`）处理栅格地理数据，共 5 个步骤：

| 步骤 ID | 名称 | 主要功能 |
|---------|------|----------|
| `raster.reproject` | 栅格投影转换 | 重投影栅格数据 |
| `raster.clip` | 栅格裁剪 | 按矢量范围裁剪栅格 |
| `raster.calc` | 栅格计算 | 波段数学运算（如 NDVI） |
| `raster.stats` | 栅格统计 | 计算 min/max/mean/std 等统计值 |
| `raster.contour` | 生成等值线 | 从栅格提取等值线矢量 |

栅格步骤内部使用 rasterio 实现，所有步骤的输入/输出均为栅格数据结构（包含 NumPy 数组 + 元信息字典）。

## 9.2 `raster.reproject`

### 功能说明

对栅格数据进行投影转换，同时支持重采样方式的指定。底层使用 rasterio 的 `warp.reproject` 函数。

### 参数说明

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | ref | ✅ | — | 输入栅格数据 |
| `target_crs` | str | ✅ | — | 目标 CRS（EPSG 代码或 PROJ 字符串） |
| `resampling` | str | ❌ | `"bilinear"` | 重采样方式 |
| `resolution` | float/list | ❌ | 自动计算 | 输出分辨率（单位：目标 CRS 的坐标单位） |

### 重采样方式

| 方式 | 适用场景 |
|------|----------|
| `nearest` | 分类数据（土地利用、分类图） |
| `bilinear` | 连续数据（DEM、温度、降水），默认 |
| `cubic` | 高质量连续数据重采样 |
| `cubic_spline` | 更平滑的连续数据 |
| `lanczos` | 高精度图像，计算开销大 |
| `average` | 下采样（降低分辨率）时保留均值 |
| `mode` | 分类数据的下采样 |

### 使用示例

```yaml
# 基本投影转换
- id: reproject-dem
  use: raster.reproject
  params:
    input: $load-dem
    target_crs: "EPSG:3857"

# 分类数据投影（使用最近邻重采样）
- id: reproject-landuse
  use: raster.reproject
  params:
    input: $load-landuse
    target_crs: "EPSG:4326"
    resampling: nearest

# 指定输出分辨率（降采样到 30 米）
- id: reproject-downsample
  use: raster.reproject
  params:
    input: $load-dem
    target_crs: "EPSG:3857"
    resampling: average
    resolution: 30
```

## 9.3 `raster.clip`

### 功能说明

使用矢量多边形范围裁剪栅格数据，范围外的像元设为 NoData。底层使用 rasterio 的 `mask` 函数。

### 参数说明

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | ref | ✅ | — | 输入栅格数据 |
| `mask` | ref | ✅ | — | 裁剪边界（矢量 GeoDataFrame，Polygon/MultiPolygon） |
| `crop` | bool | ❌ | `True` | 是否裁剪到边界的最小外接矩形（减小输出尺寸） |
| `all_touched` | bool | ❌ | `False` | 是否包含边界接触的像元 |
| `nodata` | float | ❌ | 沿用原始 nodata | 输出 NoData 值 |

### 使用示例

```yaml
# 按研究区域边界裁剪 DEM
- id: clip-dem
  use: raster.clip
  params:
    input: $load-dem
    mask: $load-boundary

# 裁剪到边界（不裁剪外接矩形，保持原始范围）
- id: clip-nofit
  use: raster.clip
  params:
    input: $load-raster
    mask: $boundary
    crop: false

# 包含边界接触像元（更完整的边界覆盖）
- id: clip-all-touched
  use: raster.clip
  params:
    input: $load-dem
    mask: $boundary
    all_touched: true
```

### 注意事项

- 栅格和矢量掩膜必须是**相同 CRS**，否则需先统一坐标系。
- 如果 `crop=True`（默认），输出栅格的范围会缩减到掩膜的边界框，可以显著减小文件大小。

## 9.4 `raster.calc`

### 功能说明

对栅格波段执行数学运算，生成新的栅格数据。通过内置的波段变量（`b1`、`b2` 等）访问各波段，使用 NumPy 表达式进行计算。

### 参数说明

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | ref | ✅ | — | 输入栅格数据 |
| `formula` | str | ✅ | — | NumPy 表达式，使用 `b1`/`b2`/... 引用各波段 |

### 波段变量命名

- `b1`：第 1 波段
- `b2`：第 2 波段
- `b3`：第 3 波段
- 以此类推……

### 使用示例

```yaml
# 计算 NDVI（归一化植被指数）
# NDVI = (NIR - RED) / (NIR + RED)
# Landsat 8: NIR = 波段5, RED = 波段4
- id: calc-ndvi
  use: raster.calc
  params:
    input: $load-landsat
    formula: "(b5 - b4) / (b5 + b4)"

# 计算 NDWI（归一化水体指数）
# NDWI = (GREEN - NIR) / (GREEN + NIR)
- id: calc-ndwi
  use: raster.calc
  params:
    input: $load-landsat
    formula: "(b3 - b5) / (b3 + b5)"

# 简单波段加权合成
- id: calc-weighted
  use: raster.calc
  params:
    input: $load-raster
    formula: "b1 * 0.3 + b2 * 0.5 + b3 * 0.2"

# 坡度计算（对 DEM 进行简单差分近似）
- id: elevation-range
  use: raster.calc
  params:
    input: $load-dem
    formula: "b1"    # 直接传递，用于后续统计

# 阈值分类（二值化）
- id: classify
  use: raster.calc
  params:
    input: $calc-ndvi
    formula: "numpy.where(b1 > 0.3, 1, 0)"    # NDVI > 0.3 为植被

# 消除负值 NDVI（水体/云区域）
- id: mask-ndvi
  use: raster.calc
  params:
    input: $calc-ndvi
    formula: "numpy.where(b1 < 0, 0, b1)"
```

### 可用的数学函数

`formula` 中可以使用 NumPy 的数学函数（通过 `numpy.` 前缀）：

- `numpy.where(condition, x, y)`：条件选择
- `numpy.log(b1)`：自然对数
- `numpy.sqrt(b1)`：开方
- `numpy.abs(b1)`：绝对值
- `numpy.clip(b1, min_val, max_val)`：截断到范围
- `numpy.nan_to_num(b1, nan=0)`：NaN 替换

## 9.5 `raster.stats`

### 功能说明

计算栅格数据的描述性统计信息（最小值、最大值、均值、标准差等），返回统计结果字典。

### 参数说明

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | ref | ✅ | — | 输入栅格数据 |
| `band` | int | ❌ | 1 | 计算统计的波段编号（从 1 开始） |

### 输出统计值

| 统计量 | 说明 |
|--------|------|
| `min` | 最小像素值（排除 NoData） |
| `max` | 最大像素值（排除 NoData） |
| `mean` | 均值（排除 NoData） |
| `std` | 标准差（排除 NoData） |
| `valid_count` | 有效像素数量（非 NoData） |
| `nodata_count` | NoData 像素数量 |
| `total_count` | 总像素数量 |
| `nodata_ratio` | NoData 比例（0.0–1.0） |

### 使用示例

```yaml
# 计算 DEM 的高程统计
- id: dem-stats
  use: raster.stats
  params:
    input: $load-dem

# 在 when 表达式中使用统计结果
- id: process-if-valid
  use: raster.clip
  params:
    input: $load-dem
    mask: $boundary
  when: "$dem-stats.nodata_ratio < 0.5"    # NoData 超过 50% 时跳过

# 计算 NDVI 统计（波段 1 是计算后的 NDVI 值）
- id: ndvi-stats
  use: raster.stats
  params:
    input: $calc-ndvi
    band: 1
```

### 典型用途

1. **质检前置**：在处理前检查数据有效性（NoData 比例、值域范围）
2. **报告生成**：输出数据统计摘要到 JSON 报告
3. **条件触发**：基于统计结果决定是否执行后续步骤

## 9.6 `raster.contour`

### 功能说明

从栅格数据提取等值线，生成矢量线要素（GeoDataFrame）。底层使用 rasterio 或 GDAL 的等值线提取算法。

### 参数说明

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | ref | ✅ | — | 输入栅格数据（通常为 DEM 或连续值栅格） |
| `interval` | float | ✅ | — | 等值线间隔（与 CRS 单位一致） |
| `base` | float | ❌ | 0 | 起始基准值（等值线 = base + n * interval） |
| `band` | int | ❌ | 1 | 提取等值线的波段编号 |
| `attr_name` | str | ❌ | `"elevation"` | 等值线属性字段名称（存储等值线高度值） |

### 使用示例

```yaml
# 生成等高线（100 米间隔）
- id: contours-100m
  use: raster.contour
  params:
    input: $load-dem
    interval: 100
    base: 0
    attr_name: "elevation"

# 从 10 米开始，每 50 米一条等高线
- id: contours-from-10
  use: raster.contour
  params:
    input: $load-dem
    interval: 50
    base: 10

# 提取 NDVI 等值线（0.1 间隔）
- id: ndvi-contours
  use: raster.contour
  params:
    input: $calc-ndvi
    interval: 0.1
    base: 0
    attr_name: "ndvi_value"

# 等值线生成后保存为矢量
- id: save-contours
  use: io.write_vector
  params:
    input: $contours-100m
    path: "output/contours.geojson"
    driver: GeoJSON
```

## 9.7 综合示例：DEM 分析流水线

```yaml
name: DEM 综合分析流水线
description: 对数字高程模型进行裁剪、统计、等值线提取和 NDVI 计算

variables:
  dem_path: "data/dem_30m.tif"
  boundary_path: "data/study_area.geojson"
  contour_interval: 50

steps:
  # 加载数据
  - id: load-dem
    use: io.read_raster
    params:
      path: ${dem_path}

  - id: load-boundary
    use: io.read_vector
    params:
      path: ${boundary_path}

  # 统一 CRS
  - id: reproject-boundary
    use: vector.reproject
    params:
      input: $load-boundary
      target_crs: $load-dem.crs    # 与 DEM 保持一致

  # 裁剪 DEM 到研究区域
  - id: clip-dem
    use: raster.clip
    params:
      input: $load-dem
      mask: $reproject-boundary

  # 质量检查：统计 NoData 比例
  - id: stats-before
    use: raster.stats
    params:
      input: $clip-dem

  # 生成等高线（仅当 NoData 比例 < 20% 时）
  - id: contours
    use: raster.contour
    params:
      input: $clip-dem
      interval: ${contour_interval}
      attr_name: "elevation"
    when: "$stats-before.nodata_ratio < 0.2"

  # 投影到 EPSG:3857 以便网络展示
  - id: reproject-dem
    use: raster.reproject
    params:
      input: $clip-dem
      target_crs: "EPSG:3857"
      resampling: bilinear

  # 最终统计
  - id: stats-final
    use: raster.stats
    params:
      input: $reproject-dem

  # 保存等高线
  - id: save-contours
    use: io.write_vector
    params:
      input: $contours
      path: "output/contours.geojson"
    on_error: skip    # 等高线提取失败时跳过

  # 保存处理后的 DEM
  - id: save-dem
    use: io.write_raster
    params:
      input: $reproject-dem
      path: "output/dem_processed.tif"
      compress: lzw

outputs:
  dem: $save-dem
  contours: $save-contours
  statistics: $stats-final
```

## 9.8 栅格处理最佳实践

### 1. CRS 一致性

栅格与矢量混合处理时，务必统一坐标系：

```yaml
# 先统一 CRS，再执行 raster.clip
- id: reproject-mask
  use: vector.reproject
  params:
    input: $boundary
    target_crs: $dem.crs    # 统一到 DEM 的 CRS
```

### 2. NoData 处理

栅格计算时注意 NoData 的传播：

```yaml
# 计算 NDVI 时，NoData 区域可能产生除零错误
- id: safe-ndvi
  use: raster.calc
  params:
    input: $landsat
    formula: "numpy.where(b5 + b4 > 0, (b5 - b4) / (b5 + b4), -9999)"
```

### 3. 内存管理

大型栅格数据处理时注意内存使用：

- 只读取需要的波段（`io.read_raster` 的 `bands` 参数）
- 先裁剪（`raster.clip`）再计算，避免对大范围栅格进行复杂运算
- 对输出使用压缩（`io.write_raster` 的 `compress` 参数）

## 9.9 小结

本章介绍了 GeoPipeAgent 的 5 个栅格分析步骤：

- **`raster.reproject`**：投影转换，支持多种重采样方式
- **`raster.clip`**：按矢量边界裁剪，支持裁剪到最小外接矩形
- **`raster.calc`**：波段数学运算，使用 NumPy 表达式（`b1`/`b2` 等）
- **`raster.stats`**：统计分析（min/max/mean/std/nodata_ratio 等）
- **`raster.contour`**：等值线提取，结果为矢量 GeoDataFrame
