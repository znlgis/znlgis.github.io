# 第九章：栅格分析步骤详解

## 9.1 概述

栅格分析是 GIS 中处理遥感影像、DEM（数字高程模型）、土地覆盖分类等数据的重要手段。GeoPipeAgent 提供了 5 个栅格分析步骤，基于 `rasterio` 和 `numpy` 实现。

| 步骤 ID | 名称 | 说明 |
|---------|------|------|
| `raster.reproject` | 栅格投影转换 | 将栅格数据投影到新的坐标参考系 |
| `raster.clip` | 栅格裁剪 | 用矢量边界裁剪栅格数据 |
| `raster.calc` | 栅格计算 | 波段数学运算（如 NDVI） |
| `raster.stats` | 栅格统计 | 计算栅格数据的统计信息 |
| `raster.contour` | 生成等值线 | 从栅格提取等值线为矢量数据 |

## 9.2 raster.reproject — 栅格投影转换

### 9.2.1 功能说明

将栅格数据从当前坐标参考系重投影到目标坐标参考系。使用 `rasterio.warp` 模块实现。

### 9.2.2 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | dict | ✅ | — | 栅格数据（来自 io.read_raster） |
| `target_crs` | string | ✅ | — | 目标 CRS（如 "EPSG:3857"） |
| `resampling` | string | ❌ | "nearest" | 重采样方法 |

### 9.2.3 重采样方法

| 方法 | 适用场景 |
|------|----------|
| `nearest` | 分类数据（土地覆盖等） |
| `bilinear` | 连续数据（DEM 等） |
| `cubic` | 高质量连续数据插值 |

### 9.2.4 使用示例

```yaml
- id: reproject-dem
  use: raster.reproject
  params:
    input: "$read-dem"
    target_crs: "EPSG:3857"
    resampling: "bilinear"
```

## 9.3 raster.clip — 栅格裁剪

### 9.3.1 功能说明

使用矢量边界（GeoDataFrame）裁剪栅格数据。使用 `rasterio.mask` 模块实现。

### 9.3.2 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | dict | ✅ | — | 栅格数据 |
| `mask` | GeoDataFrame | ✅ | — | 裁剪边界 |
| `crop` | boolean | ❌ | true | 是否裁剪到边界范围 |
| `nodata` | number | ❌ | — | 裁剪区域外的 NoData 值 |

### 9.3.3 使用示例

```yaml
- id: clip-dem
  use: raster.clip
  params:
    input: "$read-dem"
    mask: "$boundary"
    crop: true
    nodata: -9999
```

## 9.4 raster.calc — 栅格计算

### 9.4.1 功能说明

对栅格数据执行波段数学运算，支持 numpy 表达式。这是计算 NDVI、NDWI 等遥感指数的核心步骤。

### 9.4.2 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | dict | ✅ | — | 栅格数据 |
| `expression` | string | ✅ | — | 波段数学表达式 |
| `output_dtype` | string | ❌ | "float32" | 输出数据类型 |

### 9.4.3 表达式语法

表达式中使用 `B1`、`B2`、`B3` 等变量引用栅格的各个波段：

```yaml
# NDVI = (近红外 - 红光) / (近红外 + 红光)
expression: "(B4 - B3) / (B4 + B3)"

# NDWI = (绿光 - 近红外) / (绿光 + 近红外)
expression: "(B2 - B4) / (B2 + B4)"

# 简单波段差值
expression: "B2 - B1"

# 使用 numpy 函数
expression: "np.sqrt(B1**2 + B2**2)"

# 条件计算
expression: "np.where(B1 > 0, B2 / B1, 0)"
```

### 9.4.4 安全评估

栅格计算表达式使用 AST 白名单机制进行安全检查：

- **允许的运算**：加减乘除、幂运算、比较运算
- **允许的 numpy 函数**：`abs`、`sqrt`、`log`、`exp`、`sin`、`cos`、`where`、`clip`、`nan_to_num` 等
- **禁止的操作**：函数调用（除 `np.*`）、属性访问（除 `np.*`）、导入语句等

### 9.4.5 使用示例

```yaml
# 计算 NDVI
- id: ndvi
  use: raster.calc
  params:
    input: "$satellite"
    expression: "(B4 - B3) / (B4 + B3)"
    output_dtype: "float32"

# 地形坡度计算
- id: slope
  use: raster.calc
  params:
    input: "$dem"
    expression: "np.sqrt(B1**2)"
```

## 9.5 raster.stats — 栅格统计

### 9.5.1 功能说明

计算栅格数据的基本统计信息，包括最小值、最大值、均值和标准差。

### 9.5.2 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | dict | ✅ | — | 栅格数据 |

### 9.5.3 输出统计

| 键 | 类型 | 说明 |
|----|------|------|
| `min` | float | 最小值 |
| `max` | float | 最大值 |
| `mean` | float | 均值 |
| `std` | float | 标准差 |

### 9.5.4 使用示例

```yaml
- id: dem-stats
  use: raster.stats
  params:
    input: "$read-dem"
```

## 9.6 raster.contour — 生成等值线

### 9.6.1 功能说明

从栅格数据中提取等值线（等高线），生成矢量数据（GeoDataFrame）。

### 9.6.2 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | dict | ✅ | — | 栅格数据 |
| `interval` | number | ✅ | — | 等值线间距 |
| `base` | number | ❌ | 0 | 起始值 |
| `band` | number | ❌ | 1 | 使用的波段号 |

### 9.6.3 使用示例

```yaml
# 每 50 米生成等高线
- id: contours
  use: raster.contour
  params:
    input: "$dem"
    interval: 50
    base: 0

# 保存等高线为矢量
- id: save-contours
  use: io.write_vector
  params:
    input: "$contours"
    path: "output/contours.geojson"
```

## 9.7 典型栅格分析流程

### 9.7.1 NDVI 计算流程

```yaml
pipeline:
  name: "NDVI 计算"
  steps:
    - id: read-image
      use: io.read_raster
      params:
        path: "data/landsat.tif"

    - id: calc-ndvi
      use: raster.calc
      params:
        input: "$read-image"
        expression: "(B4 - B3) / (B4 + B3)"

    - id: ndvi-stats
      use: raster.stats
      params:
        input: "$calc-ndvi"

    - id: save-ndvi
      use: io.write_raster
      params:
        input: "$calc-ndvi"
        path: "output/ndvi.tif"

  outputs:
    statistics: "$ndvi-stats.stats"
```

### 9.7.2 DEM 分析流程

```yaml
pipeline:
  name: "DEM 分析"
  steps:
    - id: read-dem
      use: io.read_raster
      params:
        path: "data/dem.tif"

    - id: clip-dem
      use: raster.clip
      params:
        input: "$read-dem"
        mask: "$boundary"

    - id: dem-stats
      use: raster.stats
      params:
        input: "$clip-dem"

    - id: contours
      use: raster.contour
      params:
        input: "$clip-dem"
        interval: 100

    - id: save-contours
      use: io.write_vector
      params:
        input: "$contours"
        path: "output/contours.geojson"

  outputs:
    stats: "$dem-stats.stats"
    contours: "$save-contours"
```

## 9.8 栅格与矢量的交互

栅格步骤和矢量步骤可以在同一个流水线中混合使用：

- **矢量裁剪栅格**：`raster.clip` 接受矢量 GeoDataFrame 作为裁剪边界
- **栅格转矢量**：`raster.contour` 将栅格等值线输出为 GeoDataFrame
- **矢量写入**：等值线结果可以通过 `io.write_vector` 保存

## 9.9 本章小结

本章详细介绍了 GeoPipeAgent 的 5 个栅格分析步骤。`raster.reproject` 实现栅格投影转换，`raster.clip` 用矢量边界裁剪栅格，`raster.calc` 执行波段数学运算（如 NDVI），`raster.stats` 计算统计信息，`raster.contour` 从栅格提取等值线为矢量数据。栅格计算使用 AST 白名单机制确保表达式安全性。
