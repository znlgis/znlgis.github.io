# 第九章：栅格分析步骤详解

## 9.1 概述

GeoPipeAgent 提供 **5 个栅格分析步骤**，基于 `rasterio` 库实现，支持 GeoTIFF 等主流栅格格式。

| 步骤 ID | 功能 | 典型用途 |
|---------|------|----------|
| `raster.reproject` | 投影转换 | 统一栅格坐标系 |
| `raster.clip` | 栅格裁剪 | 按矢量边界裁剪 |
| `raster.calc` | 栅格计算 | NDVI、波段运算 |
| `raster.stats` | 栅格统计 | 最小/最大/均值/标准差 |
| `raster.contour` | 等值线生成 | DEM 等高线、等温线 |

---

## 9.2 `raster.reproject`：栅格投影转换

### 9.2.1 参数说明

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `input` | Raster | **是** | 输入栅格数据 |
| `target_crs` | string | **是** | 目标坐标系（EPSG 代码） |

### 9.2.2 使用示例

```yaml
pipeline:
  name: "栅格投影转换示例"
  steps:
    - id: load-dem
      use: io.read_raster
      params:
        path: "data/dem_wgs84.tif"

    # WGS84 → Web 墨卡托（用于距离/面积计算）
    - id: reproject-to-mercator
      use: raster.reproject
      params:
        input: "$load-dem"
        target_crs: "EPSG:3857"

    # 投影到 UTM Zone 50N（适合华北地区高精度分析）
    - id: reproject-to-utm
      use: raster.reproject
      params:
        input: "$load-dem"
        target_crs: "EPSG:32650"

    - id: save
      use: io.write_raster
      params:
        input: "$reproject-to-utm"
        path: "output/dem_utm50n.tif"
```

### 9.2.3 与矢量投影转换的区别

栅格重投影涉及**重采样**（插值），会改变像元排列，可能引入微小误差。矢量重投影则是精确的数学变换。因此：

- 栅格分析中，尽量减少不必要的重投影次数
- 优先在数据读取时选择合适坐标系，而非多次重投影

## 9.3 `raster.clip`：栅格裁剪

用矢量多边形边界裁剪栅格数据，只保留边界范围内的像元。

### 9.3.1 参数说明

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `input` | Raster | **是** | 被裁剪的栅格数据 |
| `mask` | GeoDataFrame | **是** | 裁剪边界（矢量多边形） |

**重要**：`input` 和 `mask` 必须使用相同的 CRS。

### 9.3.2 使用示例

```yaml
pipeline:
  name: "栅格裁剪示例"

  steps:
    # 加载全国 DEM
    - id: load-dem
      use: io.read_raster
      params:
        path: "data/dem_china.tif"

    # 加载研究区边界
    - id: load-boundary
      use: io.read_vector
      params:
        path: "data/study_area.geojson"

    # 统一坐标系（将矢量边界投影到与栅格相同的 CRS）
    - id: reproject-boundary
      use: vector.reproject
      params:
        input: "$load-boundary"
        target_crs: "EPSG:4326"  # 与 DEM 相同

    # 裁剪 DEM
    - id: clip-dem
      use: raster.clip
      params:
        input: "$load-dem"
        mask: "$reproject-boundary"

    - id: save-clipped
      use: io.write_raster
      params:
        input: "$clip-dem"
        path: "output/dem_study_area.tif"
```

### 9.3.3 输出 stats

```json
{
  "width": 512,
  "height": 384,
  "band_count": 1,
  "crs": "EPSG:4326",
  "resolution": [0.0001, 0.0001],
  "bbox": [116.0, 39.5, 117.0, 40.5],
  "nodata": -9999.0
}
```

## 9.4 `raster.calc`：栅格计算

对栅格数据进行数学运算，支持波段运算、归一化计算（如 NDVI）等。

### 9.4.1 参数说明

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `input` | Raster | **是** | 输入栅格（单波段或多波段） |
| `expression` | string | **是** | 计算表达式 |

### 9.4.2 表达式语法

表达式中用 `band_N` 引用第 N 个波段（从 1 开始）：

```
band_1        → 第 1 波段（原始值）
band_2        → 第 2 波段
(band_1 - band_2) / (band_1 + band_2)  → 归一化差值
band_1 * 0.001  → 单位换算
band_1 + band_2 + band_3  → 波段相加
```

### 9.4.3 使用示例

```yaml
pipeline:
  name: "栅格计算示例"

  steps:
    # 加载多光谱遥感影像
    - id: load-imagery
      use: io.read_raster
      params:
        path: "data/landsat8_multispectral.tif"
        # 假设波段顺序：B1=蓝, B2=绿, B3=红, B4=近红外, B5=短波红外

    # 计算 NDVI（归一化植被指数）
    # NDVI = (NIR - RED) / (NIR + RED)
    # 假设 band_4 = NIR（近红外），band_3 = RED（红波段）
    - id: calc-ndvi
      use: raster.calc
      params:
        input: "$load-imagery"
        expression: "(band_4 - band_3) / (band_4 + band_3)"

    # 计算 NDWI（归一化水体指数）
    # NDWI = (GREEN - NIR) / (GREEN + NIR)
    - id: calc-ndwi
      use: raster.calc
      params:
        input: "$load-imagery"
        expression: "(band_2 - band_4) / (band_2 + band_4)"

    # 计算 NDBI（归一化建筑指数）
    # NDBI = (SWIR - NIR) / (SWIR + NIR)
    - id: calc-ndbi
      use: raster.calc
      params:
        input: "$load-imagery"
        expression: "(band_5 - band_4) / (band_5 + band_4)"

    # 简单波段运算：提取单波段并缩放
    - id: extract-red
      use: raster.calc
      params:
        input: "$load-imagery"
        expression: "band_3 / 10000"   # DN 值转反射率

    # DEM 高程单位换算（厘米 → 米）
    - id: dem-to-meters
      use: io.read_raster
      params:
        path: "data/dem_cm.tif"

    - id: calc-dem-meters
      use: raster.calc
      params:
        input: "$dem-to-meters"
        expression: "band_1 * 0.01"

    - id: save-ndvi
      use: io.write_raster
      params:
        input: "$calc-ndvi"
        path: "output/ndvi.tif"

    - id: save-ndwi
      use: io.write_raster
      params:
        input: "$calc-ndwi"
        path: "output/ndwi.tif"
```

### 9.4.4 常用遥感指数表达式

| 指数 | 全称 | 表达式（以 Landsat 8 为例） | 用途 |
|------|------|---------------------------|------|
| NDVI | 归一化植被指数 | `(band_4 - band_3) / (band_4 + band_3)` | 植被覆盖 |
| NDWI | 归一化水体指数 | `(band_2 - band_4) / (band_2 + band_4)` | 水体提取 |
| NDBI | 归一化建筑指数 | `(band_5 - band_4) / (band_5 + band_4)` | 建筑物 |
| SAVI | 土壤调整植被指数 | `1.5 * (band_4 - band_3) / (band_4 + band_3 + 0.5)` | 稀疏植被 |
| EVI | 增强植被指数 | `2.5 * (band_4 - band_3) / (band_4 + 6*band_3 - 7.5*band_1 + 1)` | 高密植被 |

## 9.5 `raster.stats`：栅格统计

计算栅格数据的基本统计量，适用于 DEM 分析、数据概览等场景。

### 9.5.1 参数说明

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `input` | Raster | **是** | 输入栅格数据 |

### 9.5.2 输出 stats

```json
{
  "band_count": 1,
  "band_stats": [
    {
      "band": 1,
      "min": -10.5,
      "max": 4562.3,
      "mean": 1234.7,
      "std": 892.3,
      "nodata_count": 1250,
      "valid_count": 1047806
    }
  ],
  "crs": "EPSG:4326",
  "resolution": [0.0001, 0.0001],
  "width": 1024,
  "height": 1024
}
```

### 9.5.3 使用示例

```yaml
pipeline:
  name: "栅格统计分析"

  steps:
    - id: load-dem
      use: io.read_raster
      params:
        path: "data/dem_study_area.tif"

    # 计算 DEM 统计信息
    - id: dem-stats
      use: raster.stats
      params:
        input: "$load-dem"

    # 加载 NDVI
    - id: load-ndvi
      use: io.read_raster
      params:
        path: "data/ndvi.tif"

    - id: ndvi-stats
      use: raster.stats
      params:
        input: "$load-ndvi"

  outputs:
    dem_statistics: "$dem-stats.stats"
    ndvi_statistics: "$ndvi-stats.stats"
```

## 9.6 `raster.contour`：等值线生成

从栅格数据（尤其是 DEM）提取等值线，生成矢量等高线数据。

### 9.6.1 参数说明

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| `input` | Raster | **是** | - | 输入栅格（通常是 DEM） |
| `interval` | float | **是** | - | 等值线间距（单位与栅格值相同） |
| `attribute_name` | string | 否 | `elevation` | 等值线属性字段名 |

### 9.6.2 使用示例

```yaml
pipeline:
  name: "等高线提取示例"
  variables:
    dem_path: "data/dem_beijing.tif"
    contour_interval: 50      # 每 50 米一条等高线

  steps:
    - id: load-dem
      use: io.read_raster
      params:
        path: "${dem_path}"

    # 生成等高线（50 米间距）
    - id: contour-50m
      use: raster.contour
      params:
        input: "$load-dem"
        interval: "${contour_interval}"
        attribute_name: "elevation"

    # 细等高线（10 米间距，用于详细地形分析）
    - id: contour-10m
      use: raster.contour
      params:
        input: "$load-dem"
        interval: 10
        attribute_name: "elev_m"

    - id: save-contour-50m
      use: io.write_vector
      params:
        input: "$contour-50m"
        path: "output/contour_50m.geojson"
        format: "GeoJSON"

    - id: save-contour-10m
      use: io.write_vector
      params:
        input: "$contour-10m"
        path: "output/contour_10m.geojson"
        format: "GeoJSON"

  outputs:
    contour_50m_count: "$contour-50m.stats.feature_count"
    contour_10m_count: "$contour-10m.stats.feature_count"
```

### 9.6.3 等值线的应用场景

等值线不仅适用于高程数据，还可用于：
- **气温等温线**：temperature.tif → interval: 2（每 2℃ 一条）
- **降水等降水量线**：precipitation.tif → interval: 50（每 50mm 一条）
- **NDVI 等值线**：ndvi.tif → interval: 0.1（每 0.1 一条）
- **噪音等噪声线**：noise.tif → interval: 5（每 5dB 一条）

## 9.7 栅格矢量混合分析综合案例

### 案例：基于 DEM 的地形分析与流域提取

```yaml
pipeline:
  name: "DEM 地形综合分析"
  description: "读取 DEM，统计高程，生成等高线，叠加土地利用分析"

  variables:
    dem_path: "data/dem_study_area.tif"
    boundary_path: "data/study_area.geojson"
    contour_interval: 100    # 100 米等高线

  steps:
    # 1. 数据加载
    - id: load-dem
      use: io.read_raster
      params:
        path: "${dem_path}"

    - id: load-boundary
      use: io.read_vector
      params:
        path: "${boundary_path}"

    # 2. 确保 CRS 一致
    - id: reproject-boundary
      use: vector.reproject
      params:
        input: "$load-boundary"
        target_crs: "EPSG:4326"

    # 3. 裁剪 DEM 到研究区
    - id: clip-dem
      use: raster.clip
      params:
        input: "$load-dem"
        mask: "$reproject-boundary"

    # 4. DEM 统计
    - id: dem-stats
      use: raster.stats
      params:
        input: "$clip-dem"

    # 5. 生成等高线
    - id: contours
      use: raster.contour
      params:
        input: "$clip-dem"
        interval: "${contour_interval}"
        attribute_name: "elevation"

    # 6. 保存等高线
    - id: save-contours
      use: io.write_vector
      params:
        input: "$contours"
        path: "output/contours.geojson"
        format: "GeoJSON"

    # 7. 保存裁剪后的 DEM
    - id: save-clipped-dem
      use: io.write_raster
      params:
        input: "$clip-dem"
        path: "output/dem_clipped.tif"

  outputs:
    dem_statistics: "$dem-stats.stats"
    contour_count: "$contours.stats.feature_count"
    elevation_range: "$dem-stats.stats.band_stats"
```

## 9.8 栅格分析注意事项

### 9.8.1 NoData 值处理

```yaml
# raster.calc 中 NoData 像元会被自动跳过
# 结果中 NoData 区域保持为 NoData
- id: calc-ndvi
  use: raster.calc
  params:
    input: "$load-imagery"
    expression: "(band_4 - band_3) / (band_4 + band_3)"
    # 注意：分母为 0 时（band_4 + band_3 = 0）会产生 NaN/Inf
    # 建议数据预处理时确保数据有效性
```

使用 QC 步骤检查 NoData：
```yaml
- id: check-nodata
  use: qc.raster_nodata
  params:
    input: "$load-dem"
    max_nodata_ratio: 0.1    # NoData 比例不超过 10%
```

### 9.8.2 大型栅格处理

处理大型栅格文件（>4GB）时的建议：
1. 使用 COG（Cloud Optimized GeoTIFF）格式
2. 先裁剪到研究区再处理
3. 必要时使用 `gdal_cli` 后端（内存效率更好）

```yaml
- id: process-large-raster
  use: raster.clip
  backend: gdal_cli    # 对大文件使用 GDAL CLI 后端
  params:
    input: "$load-large-dem"
    mask: "$load-boundary"
```

## 9.9 本章小结

本章介绍了 5 个栅格分析步骤：

1. **`raster.reproject`**：栅格投影转换，涉及重采样，应减少不必要的转换
2. **`raster.clip`**：用矢量边界裁剪栅格，需统一 CRS
3. **`raster.calc`**：波段运算，支持 NDVI 等遥感指数计算
4. **`raster.stats`**：统计最小/最大/均值/标准差等基本统计量
5. **`raster.contour`**：从栅格提取等值线，生成矢量数据

**栅格分析标准流程**：加载 → 裁剪 → 统计 → 计算/变换 → 生成派生产品 → 保存
