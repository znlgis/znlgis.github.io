# 第10章：栅格分析步骤详解

GeoPipeAgent 提供了 5 个内置栅格分析步骤，覆盖波段运算、裁剪、等值线提取、投影变换和统计分析。本章将详细介绍每个步骤的参数、输出以及完整使用示例，并讲解栅格数据基础知识和遥感指数计算方法。

---

## 10.1 栅格数据基础

### 10.1.1 核心概念

| 概念 | 说明 |
|------|------|
| **波段（Band）** | 栅格数据的层，每个波段存储一种信息（如红光、近红外） |
| **分辨率（Resolution）** | 每个像元代表的地面尺寸，如 30m × 30m |
| **NoData** | 表示无效或缺失值的特殊值，如 -9999 |
| **CRS** | 坐标参考系，定义栅格在地球上的位置 |
| **数据类型（dtype）** | 像元值的存储类型：uint8, int16, float32 等 |

### 10.1.2 常见遥感波段

以 Landsat 8 为例：

| 波段编号 | 名称 | 波长范围(μm) | 分辨率 | 用途 |
|---------|------|-------------|--------|------|
| B1 | 海岸气溶胶 | 0.43-0.45 | 30m | 海岸带研究 |
| B2 | 蓝色 | 0.45-0.51 | 30m | 水体识别 |
| B3 | 绿色 | 0.53-0.59 | 30m | 植被健康 |
| B4 | 红色 | 0.64-0.67 | 30m | 植被分类 |
| B5 | 近红外(NIR) | 0.85-0.88 | 30m | 植被分析 |
| B6 | 短波红外1 | 1.57-1.65 | 30m | 土壤/植被含水量 |
| B7 | 短波红外2 | 2.11-2.29 | 30m | 矿物识别 |

## 10.2 栅格步骤总览

| 步骤 ID | 名称 | 功能 |
|---------|------|------|
| `raster.calc` | 栅格波段运算 | 波段数学运算（如 NDVI） |
| `raster.clip` | 栅格裁剪 | 按矢量边界或 bbox 裁剪 |
| `raster.contour` | 等值线提取 | 从 DEM 提取等高线 |
| `raster.reproject` | 栅格投影变换 | CRS 转换 |
| `raster.stats` | 栅格统计 | 计算统计信息和直方图 |

## 10.3 raster.calc — 栅格波段运算

### 10.3.1 功能说明

对栅格数据执行波段数学运算，使用表达式语法引用波段（B1, B2, ...）进行计算。广泛用于遥感指数计算。

### 10.3.2 参数表

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | `raster` | ✅ | — | 输入栅格数据 |
| `expression` | `string` | ✅ | — | 波段运算表达式，使用 B1, B2... 引用波段 |
| `output_dtype` | `string` | ❌ | `float32` | 输出数据类型 |

### 10.3.3 表达式语法

表达式中使用 `B1`, `B2`, `B3`... 引用波段（从 1 开始），支持标准数学运算：

```
加法:     B1 + B2
减法:     B5 - B4
乘法:     B1 * 0.5
除法:     B5 / B4
归一化:   (B5 - B4) / (B5 + B4)
幂运算:   B1 ** 2
条件:     where(B1 > 0, B1, 0)
```

### 10.3.4 常用遥感指数公式

| 指数 | 全称 | 公式 | 用途 |
|------|------|------|------|
| **NDVI** | 归一化植被指数 | `(B5 - B4) / (B5 + B4)` | 植被覆盖度评估 |
| **NDWI** | 归一化水体指数 | `(B3 - B5) / (B3 + B5)` | 水体识别 |
| **EVI** | 增强植被指数 | `2.5 * (B5 - B4) / (B5 + 6*B4 - 7.5*B2 + 1)` | 高植被区精确评估 |
| **SAVI** | 土壤调整植被指数 | `1.5 * (B5 - B4) / (B5 + B4 + 0.5)` | 裸土区域植被评估 |
| **NDBI** | 归一化建筑指数 | `(B6 - B5) / (B6 + B5)` | 城市建筑区识别 |
| **MNDWI** | 改进归一化水体指数 | `(B3 - B6) / (B3 + B6)` | 城市区域水体提取 |

### 10.3.5 使用示例

```yaml
# 计算 NDVI
- id: calc_ndvi
  step: raster.calc
  params:
    input: ${read_satellite.output}
    expression: "(B5 - B4) / (B5 + B4)"
    output_dtype: "float32"

# 计算 NDWI
- id: calc_ndwi
  step: raster.calc
  params:
    input: ${read_satellite.output}
    expression: "(B3 - B5) / (B3 + B5)"

# 计算 EVI
- id: calc_evi
  step: raster.calc
  params:
    input: ${read_satellite.output}
    expression: "2.5 * (B5 - B4) / (B5 + 6*B4 - 7.5*B2 + 1)"

# 计算 SAVI（L=0.5）
- id: calc_savi
  step: raster.calc
  params:
    input: ${read_satellite.output}
    expression: "1.5 * (B5 - B4) / (B5 + B4 + 0.5)"

# 简单波段比值
- id: band_ratio
  step: raster.calc
  params:
    input: ${read_satellite.output}
    expression: "B5 / B4"
```

## 10.4 raster.clip — 栅格裁剪

### 10.4.1 功能说明

按矢量边界或边界框（bbox）裁剪栅格数据，只保留指定范围内的像元。

### 10.4.2 参数表

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | `raster` | ✅ | — | 输入栅格数据 |
| `clip_geometry` | `geodataframe` | ❌* | `None` | 裁剪矢量边界 |
| `clip_bounds` | `list` | ❌* | `None` | 裁剪范围 `[xmin, ymin, xmax, ymax]` |

> *`clip_geometry` 和 `clip_bounds` 至少提供一个。

### 10.4.3 使用示例

```yaml
# 按矢量边界裁剪
- id: clip_by_vector
  step: raster.clip
  params:
    input: ${read_raster.output}
    clip_geometry: ${read_boundary.output}

# 按 bbox 裁剪
- id: clip_by_bbox
  step: raster.clip
  params:
    input: ${read_raster.output}
    clip_bounds: [116.0, 39.0, 117.0, 40.0]
```

## 10.5 raster.contour — 等值线提取

### 10.5.1 功能说明

从栅格数据（通常是 DEM）提取等值线，输出为矢量 GeoDataFrame。这是栅格转矢量的典型操作。

### 10.5.2 参数表

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | `raster` | ✅ | — | 输入栅格数据（通常是 DEM） |
| `interval` | `number` | ✅ | — | 等值线间距 |
| `field_name` | `string` | ❌ | `elevation` | 存储等值线值的字段名 |
| `base` | `number` | ❌ | `0` | 等值线基准值 |

### 10.5.3 输出

| 输出 | 类型 | 说明 |
|------|------|------|
| `output` | `geodataframe` | 等值线矢量数据（LineString 几何体） |

### 10.5.4 使用示例

```yaml
# 每 50 米提取一条等高线
- id: contour_50m
  step: raster.contour
  params:
    input: ${read_dem.output}
    interval: 50

# 每 100 米提取等高线（自定义字段名）
- id: contour_100m
  step: raster.contour
  params:
    input: ${read_dem.output}
    interval: 100
    field_name: "height"
    base: 0

# 从 NDVI 提取等值线
- id: ndvi_contour
  step: raster.contour
  params:
    input: ${calc_ndvi.output}
    interval: 0.1
    field_name: "ndvi_value"
```

## 10.6 raster.reproject — 栅格投影变换

### 10.6.1 功能说明

将栅格数据从当前坐标参考系转换到目标坐标参考系，支持指定输出分辨率和重采样方法。

### 10.6.2 参数表

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | `raster` | ✅ | — | 输入栅格数据 |
| `target_crs` | `string` | ✅ | — | 目标 CRS |
| `resolution` | `number` | ❌ | `None` | 输出分辨率，None 时自动计算 |
| `resampling` | `string` | ❌ | `nearest` | 重采样方法 |

### 10.6.3 重采样方法说明

| 方法 | 说明 | 适用数据类型 |
|------|------|-------------|
| `nearest` | 最近邻（默认） | 分类数据、离散值 |
| `bilinear` | 双线性插值 | 连续数据（DEM、温度） |
| `cubic` | 三次卷积插值 | 高质量连续数据 |

### 10.6.4 使用示例

```yaml
# 投影到 WGS84
- id: reproject_raster
  step: raster.reproject
  params:
    input: ${read_raster.output}
    target_crs: "EPSG:4326"
    resampling: "bilinear"

# 投影并指定分辨率
- id: reproject_resample
  step: raster.reproject
  params:
    input: ${read_raster.output}
    target_crs: "EPSG:3857"
    resolution: 30
    resampling: "cubic"
```

## 10.7 raster.stats — 栅格统计

### 10.7.1 功能说明

计算栅格数据的统计信息，包括最小值、最大值、平均值、标准差以及直方图等。

### 10.7.2 参数表

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | `raster` | ✅ | — | 输入栅格数据 |
| `band` | `number` | ❌ | `1` | 统计的波段索引 |
| `percentiles` | `list` | ❌ | `[25, 50, 75]` | 要计算的百分位数 |

### 10.7.3 输出统计信息

| 统计项 | 类型 | 说明 |
|--------|------|------|
| `min` | `float` | 最小值 |
| `max` | `float` | 最大值 |
| `mean` | `float` | 平均值 |
| `std` | `float` | 标准差 |
| `median` | `float` | 中位数 |
| `sum` | `float` | 总和 |
| `count` | `int` | 有效像元数 |
| `nodata_count` | `int` | NoData 像元数 |
| `histogram` | `dict` | 直方图（bins 和 counts） |
| `percentiles` | `dict` | 百分位数值 |

### 10.7.4 使用示例

```yaml
# 基本统计
- id: dem_stats
  step: raster.stats
  params:
    input: ${read_dem.output}

# 指定波段和百分位数
- id: band4_stats
  step: raster.stats
  params:
    input: ${read_satellite.output}
    band: 4
    percentiles: [10, 25, 50, 75, 90]

# NDVI 统计
- id: ndvi_stats
  step: raster.stats
  params:
    input: ${calc_ndvi.output}
    band: 1
```

**在 when 条件中使用统计结果：**

```yaml
- id: check_stats
  step: raster.stats
  params:
    input: ${read_dem.output}

# 仅当高差较大时提取等值线
- id: contours
  step: raster.contour
  params:
    input: ${read_dem.output}
    interval: 100
  when: "${check_stats.stats.max} - ${check_stats.stats.min} > 500"
```

## 10.8 完整栅格分析流程示例

### 10.8.1 遥感影像 NDVI 分析全流程

```yaml
name: NDVI 遥感分析全流程
description: |
  加载 Landsat 8 影像 → 计算 NDVI → 按研究区裁剪
  → 统计分析 → 提取等值线 → 保存所有结果

steps:
  # 1. 读取多光谱影像
  - id: read_satellite
    step: io.read_raster
    params:
      path: "input/landsat8_multispectral.tif"

  # 2. 计算 NDVI
  - id: calc_ndvi
    step: raster.calc
    params:
      input: ${read_satellite.output}
      expression: "(B5 - B4) / (B5 + B4)"
      output_dtype: "float32"

  # 3. 读取研究区域边界
  - id: read_boundary
    step: io.read_vector
    params:
      path: "input/study_area.geojson"

  # 4. 裁剪 NDVI 到研究区域
  - id: clip_ndvi
    step: raster.clip
    params:
      input: ${calc_ndvi.output}
      clip_geometry: ${read_boundary.output}

  # 5. 统计分析
  - id: ndvi_stats
    step: raster.stats
    params:
      input: ${clip_ndvi.output}
      percentiles: [10, 25, 50, 75, 90]

  # 6. 提取 NDVI 等值线（每 0.1 一条）
  - id: ndvi_contours
    step: raster.contour
    params:
      input: ${clip_ndvi.output}
      interval: 0.1
      field_name: "ndvi_value"

  # 7. 保存 NDVI 栅格
  - id: save_ndvi_raster
    step: io.write_raster
    params:
      input: ${clip_ndvi.output}
      path: "output/ndvi_clipped.tif"
      compress: "deflate"
      nodata: -9999

  # 8. 保存等值线矢量
  - id: save_contours
    step: io.write_vector
    params:
      input: ${ndvi_contours.output}
      path: "output/ndvi_contours.geojson"
```

### 10.8.2 DEM 地形分析流程

```yaml
name: DEM 地形分析
description: 读取 DEM → 投影 → 统计 → 提取等高线 → 保存

steps:
  - id: read_dem
    step: io.read_raster
    params:
      path: "input/srtm_dem.tif"

  # 投影到 UTM（米制单位）
  - id: reproject_dem
    step: raster.reproject
    params:
      input: ${read_dem.output}
      target_crs: "EPSG:32650"
      resampling: "bilinear"

  # 高程统计
  - id: elevation_stats
    step: raster.stats
    params:
      input: ${reproject_dem.output}
      percentiles: [5, 25, 50, 75, 95]

  # 提取等高线（每 50 米）
  - id: contours_50m
    step: raster.contour
    params:
      input: ${reproject_dem.output}
      interval: 50
      field_name: "elevation"

  # 保存等高线
  - id: save_contours
    step: io.write_vector
    params:
      input: ${contours_50m.output}
      path: "output/contours_50m.gpkg"
      layer: "contours"

  # 保存投影后的 DEM
  - id: save_dem
    step: io.write_raster
    params:
      input: ${reproject_dem.output}
      path: "output/dem_utm.tif"
      compress: "lzw"
```

### 10.8.3 栅格与矢量配合使用

```yaml
name: 栅格矢量联合分析
description: 用矢量边界裁剪栅格，将等值线结果做缓冲区分析

steps:
  # 读取矢量边界
  - id: read_boundary
    step: io.read_vector
    params:
      path: "input/watershed.shp"
      encoding: "GBK"

  # 统一投影
  - id: proj_boundary
    step: vector.reproject
    params:
      input: ${read_boundary.output}
      target_crs: "EPSG:4326"
    when: "${read_boundary.stats.crs} != 'EPSG:4326'"

  # 读取 DEM
  - id: read_dem
    step: io.read_raster
    params:
      path: "input/dem.tif"

  # 按流域边界裁剪 DEM（栅格裁剪用矢量边界）
  - id: clip_dem
    step: raster.clip
    params:
      input: ${read_dem.output}
      clip_geometry: ${proj_boundary.output}

  # 提取等高线（栅格 → 矢量转换）
  - id: contours
    step: raster.contour
    params:
      input: ${clip_dem.output}
      interval: 100
      field_name: "elevation"

  # 对等高线做缓冲区（矢量操作）
  - id: contour_buffer
    step: vector.buffer
    params:
      input: ${contours.output}
      distance: 0.001

  # 查询特定高程的等高线
  - id: high_contours
    step: vector.query
    params:
      input: ${contours.output}
      expression: "elevation >= 1000"

  # 保存高海拔等高线
  - id: save_high
    step: io.write_vector
    params:
      input: ${high_contours.output}
      path: "output/high_elevation_contours.geojson"

  # 保存裁剪后的 DEM
  - id: save_dem
    step: io.write_raster
    params:
      input: ${clip_dem.output}
      path: "output/watershed_dem.tif"
      compress: "deflate"
```

## 10.9 本章小结

| 步骤 | 核心参数 | 典型用途 |
|------|---------|---------|
| `raster.calc` | expression (波段公式) | NDVI/NDWI/EVI 遥感指数计算 |
| `raster.clip` | clip_geometry / clip_bounds | 研究区域栅格提取 |
| `raster.contour` | interval, field_name | DEM 等高线、NDVI 等值线提取 |
| `raster.reproject` | target_crs, resampling | 栅格坐标系统一 |
| `raster.stats` | band, percentiles | 栅格数据质量评估和统计分析 |

**关键要点：**
- 波段运算表达式使用 `B1, B2, ...` 引用波段
- 等值线提取是栅格转矢量的桥梁操作
- 栅格裁剪可使用矢量边界或 bbox
- 投影变换时注意选择合适的重采样方法
- 栅格与矢量步骤可自由组合构建复杂分析流程
