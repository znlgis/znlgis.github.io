# GeoPipeAgent 教程目录

GeoPipeAgent 是一个 **AI 优先（AI-Native）** 的 GIS 数据分析流水线框架，通过 YAML 声明式流水线驱动地理空间数据处理。AI 通过 Skill 文件理解框架能力，生成 YAML 格式的分析流水线，框架解析并执行，返回 JSON 结构化报告。

本教程共 20 章，从入门到进阶，全面介绍 GeoPipeAgent 的使用方法与扩展开发，基于最新重构版本编写。
