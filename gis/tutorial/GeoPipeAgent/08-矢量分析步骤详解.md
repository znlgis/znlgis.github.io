# 第八章：矢量分析步骤详解

## 8.1 概述

矢量分析是 GIS 中最基础也是最常用的分析类型。GeoPipeAgent 提供了 7 个矢量分析步骤，覆盖了缓冲区分析、裁剪、投影转换、融合、简化、查询和叠加分析等核心功能。

所有矢量步骤都支持多后端执行（`native_python`、`gdal_cli`、`gdal_python`、`qgis_process`、`pyqgis`），通过后端委托机制实现透明切换。

## 8.2 vector.buffer — 缓冲区分析

### 8.2.1 功能说明

对输入矢量数据中的每个几何要素生成指定距离的缓冲区多边形。

### 8.2.2 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | GeoDataFrame | ✅ | — | 输入矢量数据 |
| `distance` | number | ✅ | — | 缓冲区距离（单位取决于 CRS） |
| `cap_style` | string | ❌ | "round" | 端点样式：round/flat/square |

### 8.2.3 输出

| 输出 | 说明 |
|------|------|
| `output` | 缓冲区多边形 GeoDataFrame |
| `stats.total_area` | 缓冲区总面积 |

### 8.2.4 使用示例

```yaml
- id: buffer
  use: vector.buffer
  params:
    input: "$roads"
    distance: 500
    cap_style: "round"
```

### 8.2.5 注意事项

- **距离单位取决于 CRS**：如果数据使用 `EPSG:4326`（经纬度），距离单位是度；建议先投影到投影坐标系（如 `EPSG:3857`）再做缓冲区
- **cap_style 映射**：`round` → 1（圆头）、`flat` → 2（平头）、`square` → 3（方头）
- **支持后端**：`native_python`、`qgis_process`

## 8.3 vector.clip — 矢量裁剪

### 8.3.1 功能说明

使用裁剪范围（mask）裁剪输入矢量数据，只保留落在裁剪范围内的部分。

### 8.3.2 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | GeoDataFrame | ✅ | — | 输入矢量数据 |
| `clip_layer` | GeoDataFrame | ✅ | — | 裁剪范围数据 |

### 8.3.3 使用示例

```yaml
- id: clip-roads
  use: vector.clip
  params:
    input: "$roads"
    clip_layer: "$boundary"
```

## 8.4 vector.reproject — 投影转换

### 8.4.1 功能说明

将矢量数据从当前坐标参考系转换到目标坐标参考系。

### 8.4.2 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | GeoDataFrame | ✅ | — | 输入矢量数据 |
| `target_crs` | string | ✅ | — | 目标 CRS（如 "EPSG:3857"） |

### 8.4.3 使用示例

```yaml
# WGS84 转 Web Mercator
- id: reproject
  use: vector.reproject
  params:
    input: "$roads"
    target_crs: "EPSG:3857"

# 转换为 UTM 投影
- id: to-utm
  use: vector.reproject
  params:
    input: "$data"
    target_crs: "EPSG:32650"
```

### 8.4.4 常用 CRS

| CRS | 名称 | 适用场景 |
|-----|------|----------|
| EPSG:4326 | WGS84 | 全球通用地理坐标系 |
| EPSG:3857 | Web Mercator | Web 地图显示 |
| EPSG:32650 | UTM Zone 50N | 中国东部（精确距离/面积计算） |
| EPSG:4490 | CGCS2000 | 中国国家地理坐标系 |

## 8.5 vector.dissolve — 融合

### 8.5.1 功能说明

将矢量数据中的要素按指定字段进行融合（合并几何），可选地对属性进行聚合。

### 8.5.2 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | GeoDataFrame | ✅ | — | 输入矢量数据 |
| `by` | string | ❌ | — | 按此字段分组融合（不指定则全部融合） |
| `aggfunc` | string | ❌ | "first" | 属性聚合函数（first/sum/mean/count） |

### 8.5.3 使用示例

```yaml
# 按土地利用类型融合
- id: dissolve-landuse
  use: vector.dissolve
  params:
    input: "$landuse"
    by: "landuse_type"
    aggfunc: "first"

# 全部融合为一个几何
- id: dissolve-all
  use: vector.dissolve
  params:
    input: "$parcels"
```

## 8.6 vector.simplify — 几何简化

### 8.6.1 功能说明

使用 Douglas-Peucker 算法简化几何，减少顶点数量，降低数据量。

### 8.6.2 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | GeoDataFrame | ✅ | — | 输入矢量数据 |
| `tolerance` | number | ✅ | — | 简化容差（单位取决于 CRS） |
| `preserve_topology` | boolean | ❌ | true | 是否保持拓扑 |

### 8.6.3 使用示例

```yaml
- id: simplify
  use: vector.simplify
  params:
    input: "$coastline"
    tolerance: 100
    preserve_topology: true
```

### 8.6.4 注意事项

- **容差值越大，简化越多**：过大的容差可能导致几何变形
- **preserve_topology**：建议保持为 `true`，避免简化后产生自相交等拓扑问题

## 8.7 vector.query — 属性查询

### 8.7.1 功能说明

使用 Pandas query 表达式对矢量数据进行属性筛选。

### 8.7.2 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | GeoDataFrame | ✅ | — | 输入矢量数据 |
| `expression` | string | ✅ | — | Pandas query 表达式 |

### 8.7.3 使用示例

```yaml
# 筛选面积大于 1000 的要素
- id: filter-large
  use: vector.query
  params:
    input: "$parcels"
    expression: "area_sqm > 1000"

# 筛选特定类型
- id: filter-residential
  use: vector.query
  params:
    input: "$buildings"
    expression: "type == 'residential'"

# 组合条件
- id: filter-combo
  use: vector.query
  params:
    input: "$data"
    expression: "population > 10000 and area_km2 < 100"
```

### 8.7.4 查询语法

使用 Pandas DataFrame.query() 的语法，支持：

- 比较运算：`>`、`<`、`>=`、`<=`、`==`、`!=`
- 逻辑运算：`and`、`or`、`not`
- 字符串操作：`name == 'value'`
- 数学运算：`area * 2 > threshold`

## 8.8 vector.overlay — 叠加分析

### 8.8.1 功能说明

对两个矢量图层进行空间叠加分析，支持交集、并集、差集等操作。

### 8.8.2 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | GeoDataFrame | ✅ | — | 输入矢量数据 |
| `overlay_layer` | GeoDataFrame | ✅ | — | 叠加图层 |
| `how` | string | ❌ | "intersection" | 叠加方式 |

### 8.8.3 叠加方式

| how 值 | 说明 | 描述 |
|--------|------|------|
| `intersection` | 交集 | 两个图层重叠的部分 |
| `union` | 并集 | 两个图层的全部范围 |
| `difference` | 差集 | 在输入图层但不在叠加图层的部分 |
| `symmetric_difference` | 对称差 | 不重叠的部分 |

### 8.8.4 使用示例

```yaml
# 求交集
- id: overlay-intersection
  use: vector.overlay
  params:
    input: "$landuse"
    overlay_layer: "$flood_zone"
    how: "intersection"

# 求差集
- id: overlay-difference
  use: vector.overlay
  params:
    input: "$parcels"
    overlay_layer: "$protected_area"
    how: "difference"
```

## 8.9 后端委托机制

矢量步骤通过 `_delegate.py` 中的 `run_backend_op` 函数实现后端委托。当步骤声明了 `backends` 列表时，执行器会自动获取合适的后端并传入 `StepContext`：

```python
# 步骤注册时声明支持的后端
@step(
    id="vector.buffer",
    ...
    backends=["native_python", "qgis_process"],
)
def vector_buffer(ctx: StepContext) -> StepResult:
    return run_backend_op(ctx, "buffer", ...)
```

后端选择逻辑：
1. 如果步骤的 `backend` 字段有值，使用指定的后端
2. 否则使用 `BackendManager` 返回的第一个可用后端（默认 `native_python`）

## 8.10 典型分析流程

以下展示一个完整的矢量分析流水线，串联使用多个矢量步骤：

```yaml
pipeline:
  name: "综合矢量分析"
  description: "读取 → 投影 → 筛选 → 缓冲 → 简化 → 融合 → 保存"

  variables:
    input_path: "data/buildings.shp"
    filter_expr: "height > 10"

  steps:
    - id: read
      use: io.read_vector
      params:
        path: "${input_path}"

    - id: reproject
      use: vector.reproject
      params:
        input: "$read"
        target_crs: "EPSG:3857"

    - id: filter
      use: vector.query
      params:
        input: "$reproject"
        expression: "${filter_expr}"

    - id: buffer
      use: vector.buffer
      params:
        input: "$filter"
        distance: 100

    - id: simplify
      use: vector.simplify
      params:
        input: "$buffer"
        tolerance: 5

    - id: dissolve
      use: vector.dissolve
      params:
        input: "$simplify"

    - id: save
      use: io.write_vector
      params:
        input: "$dissolve"
        path: "output/result.geojson"

  outputs:
    result: "$save"
```

## 8.11 本章小结

本章详细介绍了 GeoPipeAgent 的 7 个矢量分析步骤。这些步骤覆盖了 GIS 矢量分析的核心功能，包括缓冲区分析、矢量裁剪、投影转换、属性融合、几何简化、属性查询和空间叠加分析。所有矢量步骤都支持多后端执行，可以在 NativePython、GDAL CLI、GDAL Python、QGIS Process 和 PyQGIS 之间透明切换。
