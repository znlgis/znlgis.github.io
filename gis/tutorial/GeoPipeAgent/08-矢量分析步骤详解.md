# 第八章：矢量分析步骤详解

## 8.1 概述

GeoPipeAgent 提供 **7 个矢量分析步骤**，覆盖 GIS 中最常用的矢量操作。所有矢量步骤使用 `native_python` 后端（GeoPandas + Shapely）执行。

| 步骤 ID | 功能 | 典型用途 |
|---------|------|----------|
| `vector.buffer` | 缓冲区分析 | 服务范围、影响区域 |
| `vector.clip` | 矢量裁剪 | 按边界提取数据 |
| `vector.reproject` | 投影转换 | 统一坐标系 |
| `vector.dissolve` | 要素融合 | 聚合同类区域 |
| `vector.simplify` | 几何简化 | 减少数据量 |
| `vector.query` | 属性查询 | 按条件筛选 |
| `vector.overlay` | 叠加分析 | 空间叠加运算 |

---

## 8.2 `vector.buffer`：缓冲区分析

缓冲区是最基础的 GIS 空间分析操作，在要素周围生成指定距离的缓冲多边形。

### 8.2.1 参数说明

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| `input` | GeoDataFrame | **是** | - | 输入矢量数据 |
| `distance` | float | **是** | - | 缓冲距离（单位与 CRS 相同） |
| `cap_style` | string | 否 | `round` | 端头样式：`round`/`flat`/`square` |

**重要**：`distance` 的单位取决于坐标系：
- 地理坐标系（EPSG:4326）→ 单位为**度**（约 1 度 = 111km，不推荐）
- 投影坐标系（EPSG:3857/UTM）→ 单位为**米**（推荐）

### 8.2.2 端头样式（`cap_style`）

| 值 | 说明 | 示意 |
|----|------|------|
| `round` | 圆形端头（默认，最常用） | 线端头是半圆 |
| `flat` | 平形端头 | 线端头垂直截断 |
| `square` | 方形端头 | 线端头是方形延伸 |

### 8.2.3 使用示例

```yaml
pipeline:
  name: "缓冲区分析完整示例"
  variables:
    buffer_dist: 500

  steps:
    - id: load-roads
      use: io.read_vector
      params:
        path: "data/roads.geojson"

    # 必须先投影到米制坐标系
    - id: reproject
      use: vector.reproject
      params:
        input: "$load-roads"
        target_crs: "EPSG:3857"

    # 圆形缓冲区（道路服务范围）
    - id: buffer-round
      use: vector.buffer
      params:
        input: "$reproject"
        distance: "${buffer_dist}"
        cap_style: "round"

    # 平形缓冲区（适合线段，精确端点）
    - id: buffer-flat
      use: vector.buffer
      params:
        input: "$reproject"
        distance: "${buffer_dist}"
        cap_style: "flat"

    - id: save
      use: io.write_vector
      params:
        input: "$buffer-round"
        path: "output/road_service_area.geojson"
        format: "GeoJSON"
```

### 8.2.4 输出 stats

```json
{
  "feature_count": 1250,
  "total_area": 62500000.5,
  "crs": "EPSG:3857",
  "geometry_type": "Polygon"
}
```

## 8.3 `vector.clip`：矢量裁剪

用一个多边形边界裁剪另一个矢量数据集，只保留边界内的部分。

### 8.3.1 参数说明

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `input` | GeoDataFrame | **是** | 被裁剪的数据 |
| `clip` | GeoDataFrame | **是** | 裁剪边界（必须是面类型） |

**注意**：`input` 和 `clip` 必须使用相同的 CRS，否则会报错。

### 8.3.2 使用示例

```yaml
pipeline:
  name: "矢量裁剪示例"

  steps:
    - id: load-data
      use: io.read_vector
      params:
        path: "data/national_roads.geojson"

    - id: load-boundary
      use: io.read_vector
      params:
        path: "data/beijing_boundary.geojson"

    # 统一坐标系
    - id: reproject-data
      use: vector.reproject
      params:
        input: "$load-data"
        target_crs: "EPSG:3857"

    - id: reproject-boundary
      use: vector.reproject
      params:
        input: "$load-boundary"
        target_crs: "EPSG:3857"

    # 裁剪：提取北京范围内的道路
    - id: clip-beijing
      use: vector.clip
      params:
        input: "$reproject-data"
        clip: "$reproject-boundary"

    - id: save
      use: io.write_vector
      params:
        input: "$clip-beijing"
        path: "output/beijing_roads.geojson"
        format: "GeoJSON"
```

## 8.4 `vector.reproject`：投影转换

将矢量数据从一个坐标参考系统转换到另一个坐标参考系统。

### 8.4.1 参数说明

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `input` | GeoDataFrame | **是** | 输入数据 |
| `target_crs` | string | **是** | 目标坐标系（EPSG 代码或 PROJ 字符串） |

### 8.4.2 常用投影场景

```yaml
pipeline:
  name: "投影转换示例"
  steps:
    - id: load
      use: io.read_vector
      params:
        path: "data/roads.geojson"

    # WGS84 → Web 墨卡托（用于缓冲、面积计算）
    - id: to-mercator
      use: vector.reproject
      params:
        input: "$load"
        target_crs: "EPSG:3857"

    # WGS84 → CGCS2000（中国国家标准）
    - id: to-cgcs2000
      use: vector.reproject
      params:
        input: "$load"
        target_crs: "EPSG:4490"

    # WGS84 → UTM Zone 50N（北京/华北地区精确距离）
    - id: to-utm50n
      use: vector.reproject
      params:
        input: "$load"
        target_crs: "EPSG:32650"

    # 分析完成后转回 WGS84（便于存储和展示）
    - id: to-wgs84
      use: vector.reproject
      params:
        input: "$to-mercator"
        target_crs: "EPSG:4326"
```

### 8.4.3 最佳实践：分析前后的投影流程

```
读取数据（EPSG:4326）
    ↓
投影到米制坐标系（EPSG:3857 或 UTM）
    ↓
进行空间分析（缓冲、距离、面积计算等）
    ↓
投影回 WGS84（EPSG:4326）
    ↓
保存结果
```

## 8.5 `vector.dissolve`：要素融合

将具有相同属性值的相邻或重叠要素融合为一个要素，可同时对数值属性进行聚合统计。

### 8.5.1 参数说明

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| `input` | GeoDataFrame | **是** | - | 输入数据 |
| `by` | string/list | 否 | `null` | 融合依据字段（不指定则融合所有要素） |
| `aggfunc` | string/dict | 否 | `first` | 属性聚合函数 |

### 8.5.2 `aggfunc` 可选值

| 值 | 说明 |
|----|------|
| `first` | 保留第一个值（默认） |
| `last` | 保留最后一个值 |
| `sum` | 求和 |
| `mean` | 平均值 |
| `min` | 最小值 |
| `max` | 最大值 |
| `count` | 计数 |

### 8.5.3 使用示例

```yaml
pipeline:
  name: "要素融合示例"
  steps:
    - id: load-parcels
      use: io.read_vector
      params:
        path: "data/land_parcels.geojson"

    # 按行政区代码融合地块（统计面积总和）
    - id: dissolve-by-admin
      use: vector.dissolve
      params:
        input: "$load-parcels"
        by: "admin_code"
        aggfunc: "sum"             # 数值字段求和

    # 融合所有要素为单一多边形（无分组依据）
    - id: dissolve-all
      use: vector.dissolve
      params:
        input: "$load-parcels"
        # 不指定 by，所有要素融合为一个

    # 按多字段融合（同时统计不同字段）
    - id: dissolve-multi-agg
      use: vector.dissolve
      params:
        input: "$load-parcels"
        by: "district"
        aggfunc:
          area: "sum"              # area 字段求和
          parcel_count: "count"   # parcel_count 字段计数
          land_value: "mean"      # land_value 字段平均

    - id: save
      use: io.write_vector
      params:
        input: "$dissolve-by-admin"
        path: "output/admin_areas.geojson"
        format: "GeoJSON"
```

## 8.6 `vector.simplify`：几何简化

使用 Douglas-Peucker 算法简化几何，减少顶点数量，适合缩小数据体积或优化地图渲染。

### 8.6.1 参数说明

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| `input` | GeoDataFrame | **是** | - | 输入数据 |
| `tolerance` | float | **是** | - | 简化容差（单位与 CRS 相同） |
| `preserve_topology` | bool | 否 | `true` | 是否保持拓扑关系 |

**容差参考**（不同 CRS 的适当值）：

| CRS | 容差值 | 简化程度 |
|-----|--------|----------|
| EPSG:4326（度） | 0.00001 | 轻微（约 1m） |
| EPSG:4326（度） | 0.0001 | 适中（约 10m） |
| EPSG:4326（度） | 0.001 | 较大（约 100m） |
| EPSG:3857（米） | 1 | 约 1m |
| EPSG:3857（米） | 10 | 约 10m |
| EPSG:3857（米） | 100 | 约 100m |

### 8.6.2 使用示例

```yaml
pipeline:
  name: "几何简化示例"
  variables:
    simplify_tolerance: 0.0001

  steps:
    - id: load
      use: io.read_vector
      params:
        path: "data/detailed_roads.geojson"

    # 保持拓扑的简化（推荐用于行政区划等有共享边界的数据）
    - id: simplify-topo
      use: vector.simplify
      params:
        input: "$load"
        tolerance: "${simplify_tolerance}"
        preserve_topology: true

    # 不保持拓扑（速度更快，适合独立要素）
    - id: simplify-fast
      use: vector.simplify
      params:
        input: "$load"
        tolerance: "${simplify_tolerance}"
        preserve_topology: false

    - id: save
      use: io.write_vector
      params:
        input: "$simplify-topo"
        path: "output/simplified_roads.geojson"
        format: "GeoJSON"
```

## 8.7 `vector.query`：属性查询

使用 Pandas 表达式对矢量数据进行属性条件过滤，类似 SQL 的 WHERE 子句。

### 8.7.1 参数说明

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `input` | GeoDataFrame | **是** | 输入数据 |
| `expression` | string | **是** | 过滤表达式（Pandas query 语法） |

### 8.7.2 表达式语法参考

```yaml
# 等于
expression: "road_type == '主干道'"
expression: "status == 1"

# 不等于
expression: "road_type != '小路'"

# 数值比较
expression: "speed_limit >= 60"
expression: "length > 1000"

# 范围
expression: "speed_limit >= 40 and speed_limit <= 80"

# IN 操作（包含在列表中）
expression: "road_type in ['主干道', '次干道']"

# NOT IN
expression: "road_type not in ['小路', '步道']"

# 字符串包含（需要 @str.contains）
expression: "name.str.contains('北京')"

# 空值检查
expression: "name.notna()"
expression: "note.isna()"

# 组合条件
expression: "road_type == '主干道' and speed_limit > 60 and length > 500"
expression: "status == 1 or priority > 3"
```

### 8.7.3 使用示例

```yaml
pipeline:
  name: "属性查询示例"
  variables:
    min_speed: 60
    road_class: "primary"

  steps:
    - id: load
      use: io.read_vector
      params:
        path: "data/roads.geojson"

    # 筛选高速公路
    - id: highways
      use: vector.query
      params:
        input: "$load"
        expression: "highway == 'motorway' or highway == 'trunk'"

    # 筛选速度限制高于阈值的道路
    - id: fast-roads
      use: vector.query
      params:
        input: "$load"
        expression: "speed_limit >= ${min_speed}"

    # 复合条件筛选
    - id: major-fast-roads
      use: vector.query
      params:
        input: "$load"
        expression: "road_class == '${road_class}' and speed_limit >= ${min_speed} and status == 1"

    - id: save-highways
      use: io.write_vector
      params:
        input: "$highways"
        path: "output/highways.geojson"
        format: "GeoJSON"
```

## 8.8 `vector.overlay`：叠加分析

对两个矢量图层进行空间叠加运算，是 GIS 空间分析中最重要的操作之一。

### 8.8.1 参数说明

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `input` | GeoDataFrame | **是** | 第一个输入图层 |
| `overlay` | GeoDataFrame | **是** | 第二个输入图层（叠加层） |
| `how` | string | **是** | 叠加类型（见下表） |

### 8.8.2 叠加类型（`how`）

| 值 | 说明 | 结果 |
|----|------|------|
| `intersection` | 交集 | 两层共有的部分 |
| `union` | 并集 | 两层所有部分 |
| `difference` | 差集 | input 中去掉 overlay 的部分 |
| `symmetric_difference` | 对称差 | 两层各自独有的部分 |
| `identity` | 标识 | 保留 input 所有要素，叠加 overlay 的属性 |

### 8.8.3 使用示例

```yaml
pipeline:
  name: "叠加分析示例"

  steps:
    # 加载道路缓冲区
    - id: load-buffer
      use: io.read_vector
      params:
        path: "data/road_buffer_500m.geojson"

    # 加载土地利用数据
    - id: load-landuse
      use: io.read_vector
      params:
        path: "data/landuse.geojson"

    # 统一坐标系
    - id: reproject-buffer
      use: vector.reproject
      params:
        input: "$load-buffer"
        target_crs: "EPSG:3857"

    - id: reproject-landuse
      use: vector.reproject
      params:
        input: "$load-landuse"
        target_crs: "EPSG:3857"

    # 交集：道路缓冲区内的土地利用
    - id: overlay-intersection
      use: vector.overlay
      params:
        input: "$reproject-landuse"
        overlay: "$reproject-buffer"
        how: "intersection"

    # 差集：缓冲区外的土地利用
    - id: overlay-difference
      use: vector.overlay
      params:
        input: "$reproject-landuse"
        overlay: "$reproject-buffer"
        how: "difference"

    - id: save-intersection
      use: io.write_vector
      params:
        input: "$overlay-intersection"
        path: "output/landuse_near_road.geojson"
        format: "GeoJSON"
```

## 8.9 矢量步骤综合案例

### 案例：城市商圈分析

分析城市中不同等级道路的服务范围，叠加 POI 分布，得到商圈热度分析结果。

```yaml
pipeline:
  name: "城市商圈综合分析"
  description: "分析不同等级道路服务范围内的 POI 分布"
  crs: "EPSG:4326"

  variables:
    roads_path: "data/city_roads.geojson"
    pois_path: "data/city_pois.geojson"
    boundary_path: "data/city_boundary.geojson"
    buffer_primary: 800      # 主干道服务范围 800 米
    buffer_secondary: 400    # 次干道服务范围 400 米
    working_crs: "EPSG:3857"

  steps:
    # 1. 数据加载
    - id: load-roads
      use: io.read_vector
      params:
        path: "${roads_path}"

    - id: load-pois
      use: io.read_vector
      params:
        path: "${pois_path}"

    - id: load-boundary
      use: io.read_vector
      params:
        path: "${boundary_path}"

    # 2. 数据质检
    - id: qc-roads
      use: qc.geometry_validity
      params:
        input: "$load-roads"

    # 3. 分类筛选
    - id: primary-roads
      use: vector.query
      params:
        input: "$qc-roads"
        expression: "road_type == '主干道'"

    - id: secondary-roads
      use: vector.query
      params:
        input: "$qc-roads"
        expression: "road_type == '次干道'"

    # 4. 投影转换
    - id: reproject-primary
      use: vector.reproject
      params:
        input: "$primary-roads"
        target_crs: "${working_crs}"

    - id: reproject-secondary
      use: vector.reproject
      params:
        input: "$secondary-roads"
        target_crs: "${working_crs}"

    - id: reproject-pois
      use: vector.reproject
      params:
        input: "$load-pois"
        target_crs: "${working_crs}"

    - id: reproject-boundary
      use: vector.reproject
      params:
        input: "$load-boundary"
        target_crs: "${working_crs}"

    # 5. 缓冲区分析
    - id: buffer-primary
      use: vector.buffer
      params:
        input: "$reproject-primary"
        distance: "${buffer_primary}"
        cap_style: "round"

    - id: buffer-secondary
      use: vector.buffer
      params:
        input: "$reproject-secondary"
        distance: "${buffer_secondary}"
        cap_style: "round"

    # 6. 融合缓冲区（消除重叠）
    - id: dissolve-primary
      use: vector.dissolve
      params:
        input: "$buffer-primary"

    - id: dissolve-secondary
      use: vector.dissolve
      params:
        input: "$buffer-secondary"

    # 7. 裁剪到城市边界
    - id: clip-primary
      use: vector.clip
      params:
        input: "$dissolve-primary"
        clip: "$reproject-boundary"

    # 8. 叠加分析：主干道覆盖范围内的 POI
    - id: pois-near-primary
      use: vector.overlay
      params:
        input: "$reproject-pois"
        overlay: "$clip-primary"
        how: "intersection"

    # 9. 转回 WGS84 保存
    - id: result-wgs84
      use: vector.reproject
      params:
        input: "$pois-near-primary"
        target_crs: "EPSG:4326"

    - id: save-result
      use: io.write_vector
      params:
        input: "$result-wgs84"
        path: "output/pois_near_primary_roads.geojson"
        format: "GeoJSON"

  outputs:
    primary_buffer_area: "$dissolve-primary.stats.total_area"
    pois_covered: "$pois-near-primary.stats.feature_count"
    result: "$save-result"
```

## 8.10 本章小结

本章详细介绍了 7 个矢量分析步骤：

1. **`vector.buffer`**：缓冲区分析，需要米制坐标系，支持 round/flat/square 端头
2. **`vector.clip`**：用多边形裁剪矢量，需要统一 CRS
3. **`vector.reproject`**：投影转换，分析前后必须进行
4. **`vector.dissolve`**：要素融合，支持多字段聚合统计
5. **`vector.simplify`**：几何简化，支持拓扑保持
6. **`vector.query`**：属性过滤，使用 Pandas query 语法
7. **`vector.overlay`**：叠加分析，支持 5 种叠加类型

**核心工作流**：读取 → 质检 → 投影到米制 → 空间分析 → 投影回 WGS84 → 保存
