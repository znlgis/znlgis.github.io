# 第八章：矢量分析步骤详解

## 8.1 概述

矢量分析步骤（前缀 `vector`）是 GeoPipeAgent 中使用频率最高的步骤类别，共 7 个步骤，涵盖 GIS 矢量处理的核心操作：

| 步骤 ID | 名称 | 主要功能 |
|---------|------|----------|
| `vector.buffer` | 缓冲区分析 | 生成要素的缓冲区面 |
| `vector.clip` | 矢量裁剪 | 按边界裁剪矢量数据 |
| `vector.reproject` | 投影转换 | 坐标系转换 |
| `vector.dissolve` | 融合分析 | 按字段合并要素 |
| `vector.simplify` | 几何简化 | 减少顶点数量 |
| `vector.query` | 属性查询 | 按属性条件过滤要素 |
| `vector.overlay` | 叠加分析 | 两图层的空间叠加操作 |

所有矢量步骤均以 GeoDataFrame 为输入输出格式，内部通过 GeoPandas + Shapely 实现（native_python 后端）。

## 8.2 `vector.buffer`

### 功能说明

对矢量要素生成缓冲区面（Polygon）。输入可以是点、线、面任意几何类型，输出始终为 Polygon 或 MultiPolygon。

### 参数说明

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | ref | ✅ | — | 输入 GeoDataFrame |
| `distance` | float | ✅ | — | 缓冲距离，单位与 CRS 一致（投影坐标系用米，地理坐标系用度） |
| `cap_style` | str | ❌ | `"round"` | 线端点样式：`round`（圆头）/`flat`（平头）/`square`（方头） |
| `join_style` | str | ❌ | `"round"` | 折角样式：`round`（圆角）/`mitre`（尖角）/`bevel`（切角） |
| `resolution` | int | ❌ | 16 | 圆弧近似分段数，越大越平滑但文件越大 |

### 重要注意事项：坐标系与距离单位

**缓冲区最常见的错误**：在地理坐标系（如 EPSG:4326，度为单位）中直接用米值缓冲。

```yaml
# ❌ 错误示例：WGS84 中 500 度的缓冲区
- id: wrong-buffer
  use: vector.buffer
  params:
    input: $load
    distance: 500    # 在 EPSG:4326 中，500° 毫无意义

# ✅ 正确做法：先投影到平面坐标系再缓冲
- id: reproject
  use: vector.reproject
  params:
    input: $load
    target_crs: "EPSG:3857"    # 转为 Web 墨卡托，单位为米

- id: correct-buffer
  use: vector.buffer
  params:
    input: $reproject
    distance: 500    # 500 米
```

### 使用示例

```yaml
# 基本缓冲区
- id: buffer
  use: vector.buffer
  params:
    input: $load
    distance: 1000
    cap_style: round

# 道路缓冲区（平头样式，更贴合线性要素）
- id: road-buffer
  use: vector.buffer
  params:
    input: $roads
    distance: 50
    cap_style: flat
    join_style: mitre

# 高精度圆形缓冲区（适用于精细图形输出）
- id: precise-buffer
  use: vector.buffer
  params:
    input: $points
    distance: 100
    resolution: 32    # 更多分段，更圆滑
```

## 8.3 `vector.clip`

### 功能说明

用裁剪范围（Polygon）裁剪输入矢量数据，只保留与裁剪范围重叠的要素部分。

### 参数说明

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | ref | ✅ | — | 被裁剪的 GeoDataFrame |
| `clip` | ref | ✅ | — | 裁剪范围 GeoDataFrame（Polygon/MultiPolygon） |
| `keep_geom_type` | bool | ❌ | `True` | 是否只保留与输入相同几何类型的结果 |

### 使用示例

```yaml
# 裁剪道路数据到研究区域
- id: load-roads
  use: io.read_vector
  params:
    path: "data/roads.shp"

- id: load-boundary
  use: io.read_vector
  params:
    path: "data/study_area.geojson"

- id: clip-roads
  use: vector.clip
  params:
    input: $load-roads
    clip: $load-boundary

# 保留所有几何类型的裁剪结果（包括点、线等边界交叉几何）
- id: clip-all-types
  use: vector.clip
  params:
    input: $load-roads
    clip: $load-boundary
    keep_geom_type: false
```

### 注意事项

- 裁剪操作要求两个图层使用**相同 CRS**，否则需先使用 `vector.reproject` 统一坐标系。
- 裁剪后超出范围的要素几何会被切割，属性保留。

## 8.4 `vector.reproject`

### 功能说明

将 GeoDataFrame 从一个坐标参考系（CRS）转换到另一个 CRS。

### 参数说明

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | ref | ✅ | — | 输入 GeoDataFrame |
| `target_crs` | str | ✅ | — | 目标 CRS，格式：EPSG 代码、PROJ 字符串或 WKT |

### 常用 CRS 参考

| CRS | EPSG | 用途 |
|-----|------|------|
| WGS84 经纬度 | EPSG:4326 | 全球地理坐标，默认坐标系 |
| Web 墨卡托 | EPSG:3857 | 网络地图（Google/OSM 等） |
| 中国大地坐标系 | EPSG:4490 | 中国国家标准 CGCS2000 |
| 北京 54 | EPSG:4214 | 历史遗留数据 |
| 西安 80 | EPSG:4610 | 历史遗留数据 |
| UTM Zone 50N | EPSG:32650 | 中国东部地区投影坐标 |
| 中国等面积 | EPSG:4508 | 面积计算等场景 |

### 使用示例

```yaml
# 转换到 Web 墨卡托（用于缓冲区等需要米单位的操作）
- id: reproject-mercator
  use: vector.reproject
  params:
    input: $load
    target_crs: "EPSG:3857"

# 统一多个图层的 CRS
- id: proj-roads
  use: vector.reproject
  params:
    input: $load-roads
    target_crs: "EPSG:3857"

- id: proj-boundary
  use: vector.reproject
  params:
    input: $load-boundary
    target_crs: "EPSG:3857"

# 动态对齐 CRS（将一个图层投影到另一个图层的 CRS）
- id: align-crs
  use: vector.reproject
  params:
    input: $load-points
    target_crs: $load-reference.crs    # 动态引用参考图层的 CRS
```

## 8.5 `vector.dissolve`

### 功能说明

按指定字段对 GeoDataFrame 进行融合（合并），将相同字段值的要素合并为一个要素，几何取并集。

### 参数说明

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | ref | ✅ | — | 输入 GeoDataFrame |
| `by` | str/list | ❌ | None（融合全部） | 按该字段（或字段列表）分组融合 |
| `aggfunc` | dict | ❌ | `{}` | 数值字段的聚合函数，格式：`{字段名: 聚合函数}` |

支持的聚合函数：`sum`（求和）、`mean`（均值）、`min`（最小值）、`max`（最大值）、`count`（计数）、`first`（取第一个）、`last`（取最后一个）

### 使用示例

```yaml
# 将所有要素融合为单个要素（如生成单一行政区轮廓）
- id: dissolve-all
  use: vector.dissolve
  params:
    input: $load

# 按行政区划字段融合
- id: dissolve-by-district
  use: vector.dissolve
  params:
    input: $load
    by: "district_name"

# 按字段融合并统计各组的总面积和要素数量
- id: dissolve-with-stats
  use: vector.dissolve
  params:
    input: $load
    by: "land_type"
    aggfunc:
      area: "sum"       # 各类型总面积
      parcel_id: "count"  # 各类型地块数量
      value: "mean"     # 各类型平均价值

# 按多字段融合
- id: dissolve-multi-key
  use: vector.dissolve
  params:
    input: $load
    by:
      - "province"
      - "land_type"
```

## 8.6 `vector.simplify`

### 功能说明

使用 Douglas-Peucker 算法对几何形状进行简化，减少顶点数量，降低文件大小。

### 参数说明

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | ref | ✅ | — | 输入 GeoDataFrame |
| `tolerance` | float | ✅ | — | 简化容差，单位与 CRS 一致 |
| `preserve_topology` | bool | ❌ | `True` | 是否保留拓扑（避免自相交） |

### 使用示例

```yaml
# 基本简化（投影坐标系，单位为米）
- id: simplify
  use: vector.simplify
  params:
    input: $reproject
    tolerance: 5.0    # 5 米容差

# 不保留拓扑（速度更快，但可能产生自相交）
- id: fast-simplify
  use: vector.simplify
  params:
    input: $load
    tolerance: 10
    preserve_topology: false

# 地理坐标系下简化（容差单位为度）
- id: simplify-geo
  use: vector.simplify
  params:
    input: $load    # EPSG:4326
    tolerance: 0.0001    # 约 10 米精度
```

### 选择合适的 tolerance 值

| 应用场景 | 建议 tolerance | 说明 |
|----------|----------------|------|
| 省级行政区划（全国地图） | 500–1000m | 大范围低精度 |
| 县级行政区划（省级地图） | 50–200m | 中等精度 |
| 精细地物（城市级） | 1–10m | 高精度 |
| 地理坐标系（全球） | 0.001–0.01° | 约 100m–1km |

## 8.7 `vector.query`

### 功能说明

使用 Pandas query 表达式按属性条件过滤要素，返回满足条件的子集。

### 参数说明

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | ref | ✅ | — | 输入 GeoDataFrame |
| `expr` | str | ✅ | — | Pandas query 表达式字符串 |

### 使用示例

```yaml
# 过滤字符串字段
- id: filter-type
  use: vector.query
  params:
    input: $load
    expr: "road_type == '主干道'"

# 数值范围过滤
- id: filter-length
  use: vector.query
  params:
    input: $load
    expr: "length > 1000"

# 复合条件
- id: filter-complex
  use: vector.query
  params:
    input: $load
    expr: "area > 1000 and land_type in ['居住用地', '商业用地']"

# 非空过滤
- id: filter-notnull
  use: vector.query
  params:
    input: $load
    expr: "name.notna()"

# 使用变量的动态过滤
- id: filter-with-var
  use: vector.query
  params:
    input: $load
    expr: "grade >= ${min_grade}"    # ${min_grade} 来自 variables
```

### Pandas query 语法参考

| 操作 | 示例 |
|------|------|
| 等于 | `"field == 'value'"` |
| 不等于 | `"field != 'value'"` |
| 数值比较 | `"field > 100"`, `"field between 10 and 100"` |
| 列表成员 | `"field in ['a', 'b', 'c']"` |
| 字符串包含 | `"field.str.contains('关键词')"` |
| 非空 | `"field.notna()"` |
| 逻辑与/或 | `"cond1 and cond2"`, `"cond1 or cond2"` |
| 非 | `"not cond"` |

## 8.8 `vector.overlay`

### 功能说明

执行两个矢量图层的空间叠加分析，支持交集、并集、差集、对称差等操作。

### 参数说明

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `left` | ref | ✅ | — | 左图层 GeoDataFrame |
| `right` | ref | ✅ | — | 右图层 GeoDataFrame |
| `how` | str | ✅ | — | 叠加方式：`intersection`/`union`/`difference`/`symmetric_difference`/`identity` |
| `keep_geom_type` | bool | ❌ | `True` | 是否保留与输入相同的几何类型 |

### 叠加方式说明

| 方式 | 说明 | 典型用途 |
|------|------|----------|
| `intersection` | 交集：两层重叠部分 | 提取两区域的公共区域 |
| `union` | 并集：两层合并 | 合并两个图层的所有要素 |
| `difference` | 差集：left 中不在 right 内的部分 | 从一区域中去除另一区域 |
| `symmetric_difference` | 对称差：两层各自不重叠的部分 | 识别两次调查之间的变化 |
| `identity` | 标识：保留 left 的所有要素，切割后附加 right 的属性 | 空间连接分析 |

### 使用示例

```yaml
# 交集分析：提取建筑用地中的商业区域
- id: load-buildings
  use: io.read_vector
  params:
    path: "data/buildings.shp"

- id: load-commercial
  use: io.read_vector
  params:
    path: "data/commercial_zone.shp"

- id: intersection
  use: vector.overlay
  params:
    left: $load-buildings
    right: $load-commercial
    how: intersection

# 差集分析：提取道路缓冲区外的建筑
- id: overlay-difference
  use: vector.overlay
  params:
    left: $load-buildings
    right: $road-buffer
    how: difference

# 并集分析：合并两期调查数据
- id: overlay-union
  use: vector.overlay
  params:
    left: $survey-2023
    right: $survey-2024
    how: union
```

## 8.9 综合示例：完整矢量分析流水线

```yaml
name: 城市绿地可达性分析
description: 分析研究区域内居民区到公园的可达性

variables:
  study_area: "data/study_area.geojson"
  parks: "data/parks.shp"
  residential: "data/residential.shp"
  walk_buffer: 800    # 步行800米可达范围

steps:
  # 加载数据
  - id: load-area
    use: io.read_vector
    params:
      path: ${study_area}

  - id: load-parks
    use: io.read_vector
    params:
      path: ${parks}

  - id: load-res
    use: io.read_vector
    params:
      path: ${residential}

  # 统一 CRS
  - id: proj-parks
    use: vector.reproject
    params:
      input: $load-parks
      target_crs: "EPSG:3857"

  - id: proj-res
    use: vector.reproject
    params:
      input: $load-res
      target_crs: "EPSG:3857"

  - id: proj-area
    use: vector.reproject
    params:
      input: $load-area
      target_crs: "EPSG:3857"

  # 裁剪到研究区域
  - id: clip-parks
    use: vector.clip
    params:
      input: $proj-parks
      clip: $proj-area

  - id: clip-res
    use: vector.clip
    params:
      input: $proj-res
      clip: $proj-area

  # 公园缓冲区（步行可达范围）
  - id: park-buffer
    use: vector.buffer
    params:
      input: $clip-parks
      distance: ${walk_buffer}
      cap_style: round

  # 融合缓冲区（合并重叠的公园服务范围）
  - id: dissolve-buffer
    use: vector.dissolve
    params:
      input: $park-buffer

  # 找出可达的居住用地
  - id: accessible
    use: vector.overlay
    params:
      left: $clip-res
      right: $dissolve-buffer
      how: intersection

  # 找出不可达的居住用地
  - id: not-accessible
    use: vector.overlay
    params:
      left: $clip-res
      right: $dissolve-buffer
      how: difference

  # 保存结果
  - id: save-accessible
    use: io.write_vector
    params:
      input: $accessible
      path: "output/accessible_residential.geojson"

  - id: save-not-accessible
    use: io.write_vector
    params:
      input: $not-accessible
      path: "output/not_accessible_residential.geojson"

outputs:
  accessible: $save-accessible
  not_accessible: $save-not-accessible
```

## 8.10 小结

本章详细介绍了 GeoPipeAgent 的 7 个矢量分析步骤：

- **`vector.buffer`**：缓冲区分析，需注意坐标系与距离单位匹配
- **`vector.clip`**：按边界裁剪，要求两图层 CRS 一致
- **`vector.reproject`**：坐标系转换，是很多操作的必要前置步骤
- **`vector.dissolve`**：按字段融合，支持聚合统计
- **`vector.simplify`**：Douglas-Peucker 简化，减少顶点数
- **`vector.query`**：Pandas query 表达式属性过滤
- **`vector.overlay`**：交集/并集/差集等空间叠加分析
