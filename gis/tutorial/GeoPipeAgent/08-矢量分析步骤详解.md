# 第8章：矢量分析步骤详解

> 本章将全面介绍 GeoPipeAgent 的七个矢量分析步骤，深入分析后端委托机制（`run_backend_op`）的工作原理，并通过丰富的示例展示每个步骤的参数配置和使用方法。

---

## 8.1 矢量步骤概述

### 8.1.1 七个矢量步骤总览

矢量步骤（`vector.*`）是 GeoPipeAgent 中最核心的处理步骤，涵盖了常见的矢量空间分析操作：

| 步骤 ID | 功能 | 后端支持 | 实现方式 |
|---------|------|----------|----------|
| `vector.buffer` | 缓冲区分析 | native_python, qgis_process | 后端委托 |
| `vector.clip` | 矢量裁剪 | native_python, qgis_process | 后端委托 |
| `vector.reproject` | 投影转换 | native_python, qgis_process | 后端委托 |
| `vector.dissolve` | 要素融合 | native_python | 后端委托 |
| `vector.simplify` | 几何简化 | native_python | 后端委托 |
| `vector.query` | 属性查询 | — | 直接实现 |
| `vector.overlay` | 叠加分析 | native_python | 后端委托 |

### 8.1.2 后端委托机制

大多数矢量步骤使用"后端委托"模式：步骤函数不直接实现算法逻辑，而是通过 `run_backend_op` 函数将操作委托给指定的后端（如 `native_python` 或 `qgis_process`）。这种设计的优势在于：

- **算法可替换**：同一操作可在不同后端之间切换
- **代码复用**：步骤函数只需声明参数映射，不必关心具体实现
- **扩展性好**：新增后端只需实现对应方法，不影响步骤定义

```
┌────────────┐       ┌──────────────┐       ┌──────────────────┐
│ vector.buffer │─────▶│ run_backend_op │─────▶│ native_python    │
│ (step func)  │      │ (_delegate.py) │      │ backend.buffer() │
└────────────┘       └──────────────┘       └──────────────────┘
                             │
                             ├──────────────▶ qgis_process
                             │                backend.buffer()
                             │
                             └──────────────▶ ... (其他后端)
```

## 8.2 _delegate.py 后端委托详解

### 8.2.1 run_backend_op 源码分析

```python
def run_backend_op(ctx, method, *, positional_params=None,
                   keyword_params=None, extra_stats=None):
    """
    将操作委托给当前后端执行。

    参数:
        ctx: 步骤执行上下文
        method: 后端方法名（如 "buffer", "clip"）
        positional_params: 位置参数名列表
        keyword_params: 关键字参数映射 {param_name: kwarg_name}
        extra_stats: 额外统计信息函数 (ctx, input_gdf, result_gdf) -> dict
    """
    # 1. 获取输入数据
    gdf = ctx.input("input")

    # 2. 构建位置参数
    args = [ctx.param(p) for p in (positional_params or [])]

    # 3. 构建关键字参数（跳过 None 值）
    kwargs = {
        kwarg_name: ctx.param(param_name)
        for param_name, kwarg_name in (keyword_params or {}).items()
        if ctx.param(param_name) is not None
    }

    # 4. 调用后端方法
    result_gdf = getattr(ctx.backend, method)(gdf, *args, **kwargs)

    # 5. 构建统计信息
    stats = {"feature_count": len(result_gdf)}
    if extra_stats:
        stats.update(extra_stats(ctx, gdf, result_gdf))

    return StepResult(output=result_gdf, stats=stats)
```

### 8.2.2 参数传递机制

`run_backend_op` 提供了灵活的参数传递方式：

**位置参数 (positional_params)：**

```python
# 示例：vector.buffer 传递 distance 为位置参数
positional_params = ["distance"]
# 效果：ctx.backend.buffer(gdf, ctx.param("distance"))
```

**关键字参数 (keyword_params)：**

```python
# 示例：vector.buffer 传递 cap_style 为关键字参数
keyword_params = {"cap_style": "cap_style"}
# 效果：ctx.backend.buffer(gdf, distance, cap_style=ctx.param("cap_style"))
```

关键字参数映射的格式为 `{步骤参数名: 后端方法关键字参数名}`，两者名称可以不同，增强了适配灵活性。

**None 值过滤：**

```python
if ctx.param(param_name) is not None
```

未指定的可选参数不会传递给后端方法，由后端方法使用自己的默认值。这避免了显式传递 `None` 导致的异常。

### 8.2.3 extra_stats 扩展统计

部分步骤需要返回额外的统计信息，通过 `extra_stats` 回调函数实现：

```python
# vector.buffer 的 extra_stats
def _buffer_stats(ctx, input_gdf, result_gdf):
    return {
        "total_area": float(result_gdf.geometry.area.sum()),
    }

# vector.reproject 的 extra_stats
def _reproject_stats(ctx, input_gdf, result_gdf):
    return {
        "source_crs": str(input_gdf.crs),
        "target_crs": ctx.param("target_crs"),
    }
```

## 8.3 vector.buffer 缓冲区分析

### 8.3.1 功能说明

`vector.buffer` 对输入的每个几何要素创建指定距离的缓冲区（Buffer）。缓冲区分析是 GIS 中最基础且常用的空间分析操作之一，常用于：

- 确定设施服务范围（如学校周边 500 米）
- 创建保护区缓冲带
- 交通噪音影响分析

### 8.3.2 参数定义

| 参数 | 类型 | 必需 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | `GeoDataFrame` | ✅ | — | 输入矢量数据 |
| `distance` | `float` | ✅ | — | 缓冲距离（单位取决于坐标系） |
| `cap_style` | `str` | ❌ | `"round"` | 端点样式：`round`（圆形）、`flat`（平直）、`square`（方形） |

### 8.3.3 cap_style 端点样式

```
 round (圆形)         flat (平直)          square (方形)
    ╭───╮              ┌───┐               ┌───┐
   ╱     ╲             │   │               │   │
  │       │            │   │               │   │
  │   ─── │            │───│               │───│
  │       │            │   │               │   │
   ╲     ╱             │   │               │   │
    ╰───╯              └───┘               └───┘
```

- **`round`**（默认）：端点为半圆形，最常用
- **`flat`**：端点截断为平直线
- **`square`**：端点延伸为方形

### 8.3.4 后端支持

```python
backends = ["native_python", "qgis_process"]
```

- **native_python**：调用 `gdf.buffer(distance, cap_style=...)` (shapely)
- **qgis_process**：调用 QGIS 的 `native:buffer` 算法

### 8.3.5 源码实现

```python
@step(
    id="vector.buffer",
    name="缓冲区分析",
    backends=["native_python", "qgis_process"],
    params={...},
)
def buffer(ctx):
    return run_backend_op(
        ctx,
        method="buffer",
        positional_params=["distance"],
        keyword_params={"cap_style": "cap_style"},
        extra_stats=lambda ctx, inp, res: {
            "total_area": float(res.geometry.area.sum())
        },
    )
```

### 8.3.6 使用示例

```yaml
# 为建筑物创建 500 米缓冲区
- id: buffer_buildings
  step: vector.buffer
  params:
    input: "$steps.read_buildings"
    distance: 500
    cap_style: round
```

> **注意**：`distance` 的单位取决于输入数据的坐标系。如果坐标系为 `EPSG:4326`（经纬度），则距离单位为度；建议先投影到平面坐标系（如 UTM），再执行缓冲区分析。

```python
@step(
    id="vector.clip",
```

## 8.5 vector.reproject 投影转换

### 8.5.1 功能说明

`vector.reproject` 将矢量数据从一个坐标参考系（CRS）转换到另一个坐标参考系。这是进行空间分析前的重要预处理步骤。

### 8.5.2 参数定义

| 参数 | 类型 | 必需 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | `GeoDataFrame` | ✅ | — | 输入矢量数据 |
| `target_crs` | `str` | ✅ | — | 目标坐标参考系（EPSG 代码或 WKT） |

### 8.5.3 常用坐标参考系

| EPSG 代码 | 名称 | 用途 |
|-----------|------|------|
| `EPSG:4326` | WGS 84 | GPS 经纬度坐标，全球通用 |
| `EPSG:3857` | Web Mercator | Web 地图（Google Maps、OpenStreetMap） |
| `EPSG:4490` | CGCS2000 | 中国国家大地坐标系 |
| `EPSG:32650` | UTM Zone 50N | 中国东部 UTM 投影（平面坐标，米） |

### 8.5.4 后端支持与统计信息

```python
backends = ["native_python", "qgis_process"]
```

统计信息包含源坐标系和目标坐标系：

```python
extra_stats = {
    "source_crs": "EPSG:4326",
    "target_crs": "EPSG:3857",
}
```

### 8.5.5 使用示例

```yaml
# 将 WGS84 数据转换为 UTM 投影
- id: reproject_data
  step: vector.reproject
  params:
    input: "$steps.read_data"
    target_crs: "EPSG:32650"
```

## 8.6 vector.dissolve 要素融合

### 8.6.1 功能说明

`vector.dissolve` 将具有相同属性值的要素合并为单个要素，同时可对其他属性进行聚合计算。类似于 SQL 的 `GROUP BY` 操作。

### 8.6.2 参数定义

| 参数 | 类型 | 必需 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | `GeoDataFrame` | ✅ | — | 输入矢量数据 |
| `by` | `str` | ✅ | — | 融合字段名（用于分组） |
| `aggfunc` | `str` | ❌ | `"first"` | 聚合函数 |

### 8.6.3 聚合函数说明

| aggfunc | 说明 | 适用场景 |
|---------|------|----------|
| `first` | 取每组第一个值 | 不关心属性聚合结果时 |
| `sum` | 求和 | 面积、人口等可加属性 |
| `mean` | 求平均值 | 密度、比率等属性 |
| `count` | 计数 | 统计每组包含多少要素 |

### 8.6.4 源码实现

```python
@step(
    id="vector.dissolve",
    name="要素融合",
    backends=["native_python"],
    params={...},
)
def dissolve(ctx):
    return run_backend_op(
        ctx,
        method="dissolve",
        positional_params=["by"],
        keyword_params={"aggfunc": "aggfunc"},
    )
```

### 8.6.5 使用示例

```yaml
# 按省份融合城市数据，人口求和
- id: dissolve_by_province
  step: vector.dissolve
  params:
    input: "$steps.read_cities"
    by: "province"
    aggfunc: "sum"
```

融合前后对比：

```
融合前（3 个要素）：            融合后（1 个要素）：
┌──────────┬──────┬──────┐    ┌──────────┬──────────┐
│ province │ city │ pop  │    │ province │ pop      │
├──────────┼──────┼──────┤    ├──────────┼──────────┤
│ 广东     │ 广州 │ 1500 │    │ 广东     │ 3500     │
│ 广东     │ 深圳 │ 1300 │    └──────────┴──────────┘
│ 广东     │ 珠海 │ 700  │    （几何为三城市的合并几何）
└──────────┴──────┴──────┘
```

## 8.7 vector.simplify 几何简化

### 8.7.1 功能说明

`vector.simplify` 简化几何形状，减少顶点数量以降低数据复杂度。这在 Web 展示、大比例尺缩编时非常有用。

### 8.7.2 参数定义

| 参数 | 类型 | 必需 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | `GeoDataFrame` | ✅ | — | 输入矢量数据 |
| `tolerance` | `float` | ✅ | — | 简化容差（单位取决于坐标系） |
| `preserve_topology` | `bool` | ❌ | `True` | 是否保持拓扑关系 |

### 8.7.3 Douglas-Peucker 算法

`vector.simplify` 底层使用 Douglas-Peucker 算法进行几何简化。该算法的核心思想：

1. 连接首尾两点形成一条直线
2. 找到距离该直线最远的点
3. 如果最远距离 > tolerance，保留该点并递归处理两段
4. 如果最远距离 ≤ tolerance，移除中间所有点

```
原始线段（9个顶点）：
  •───•
 /     \
•       •───•
         \
          •───•───•───•

简化后（tolerance=50，5个顶点）：
  •
 / \
•   •───•
         \
          •
```

### 8.7.4 preserve_topology 参数

| 值 | 说明 |
|------|------|
| `True`（默认） | 保证简化后几何不自交、不产生无效几何，但速度稍慢 |
| `False` | 纯 Douglas-Peucker，可能产生自交多边形，速度更快 |

### 8.7.5 使用示例

```yaml
# 简化省界数据，容差 100 米
- id: simplify_provinces
  step: vector.simplify
  params:
    input: "$steps.read_provinces"
    tolerance: 100
    preserve_topology: true
```

## 8.8 vector.query 属性查询

### 8.8.1 功能说明

`vector.query` 根据属性条件筛选要素，类似于 SQL 的 `WHERE` 子句。它是唯一不使用后端委托的矢量步骤，因为属性查询本质上是 Pandas 操作，不涉及空间算法。

### 8.8.2 参数定义

| 参数 | 类型 | 必需 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | `GeoDataFrame` | ✅ | — | 输入矢量数据 |
| `expression` | `str` | ✅ | — | Pandas query 表达式 |

### 8.8.3 Pandas query 表达式语法

`expression` 参数使用 Pandas 的 `DataFrame.query()` 语法：

| 操作 | 示例 |
|------|------|
| 等于 | `"type == '住宅'"` |
| 不等于 | `"type != '工业'"` |
| 大于/小于 | `"area > 1000"` |
| 范围 | `"area >= 500 and area <= 2000"` |
| 包含 | `"type in ['住宅', '商业']"` |
| 逻辑组合 | `"area > 1000 and floors >= 5"` |
| 字符串方法 | `"name.str.contains('学校')"` |

### 8.8.4 直接实现（无后端委托）

```python
@step(
    id="vector.query",
    name="属性查询",
    params={
        "input": {"type": "GeoDataFrame", "required": True},
        "expression": {"type": "str", "required": True,
                       "description": "Pandas query 表达式"},
    },
)
def query(ctx):
    gdf = ctx.input("input")
    expression = ctx.param("expression")

    # 直接使用 Pandas query
    result = gdf.query(expression)

    stats = {
        "input_count": len(gdf),
        "output_count": len(result),
    }

    return StepResult(output=result, stats=stats)
```

注意：统计信息包含 `input_count` 和 `output_count`，方便了解查询的过滤效果。

### 8.8.5 使用示例

```yaml
# 筛选面积大于 1000 平方米的建筑
- id: large_buildings
  step: vector.query
  params:
    input: "$steps.read_buildings"
    expression: "area > 1000"

# 筛选特定类型的兴趣点
- id: schools
  step: vector.query
  params:
    input: "$steps.read_pois"
    expression: "type == '学校' and level == '中学'"
```

## 8.9 vector.overlay 叠加分析

### 8.9.1 功能说明

`vector.overlay` 对两个矢量图层进行空间叠加分析，支持五种叠加方式。叠加分析是 GIS 中进行空间关系分析的基础操作。

### 8.9.2 参数定义

| 参数 | 类型 | 必需 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | `GeoDataFrame` | ✅ | — | 输入图层 |
| `overlay_layer` | `GeoDataFrame` | ✅ | — | 叠加图层 |
| `how` | `str` | ✅ | — | 叠加方式 |

### 8.9.3 五种叠加方式

| how | 中文名 | 说明 |
|-----|--------|------|
| `intersection` | 交集 | 只保留两个图层重叠的部分 |
| `union` | 并集 | 保留两个图层的所有部分 |
| `difference` | 差集 | 保留 input 中不与 overlay 重叠的部分 |
| `symmetric_difference` | 对称差 | 保留两个图层不重叠的部分 |
| `identity` | 标识叠加 | 保留 input 的全部，在重叠区域附加 overlay 属性 |

图示说明（A = input, B = overlay_layer）：

```
intersection:        union:             difference:
   ┌───┐                ┌───┐              ┌───┐
   │ A │                │ A │              │ A │
   │ ┌─┼─┐          ┌──┼─┼─┼──┐           │   ├─┐
   │ │█│ │          │██│█│█│██│           │███│ │
   └─┼─┘ │          └──┼─┼─┼──┘           └───┘ │
     │ B │              │ B │                    │
     └───┘              └───┘              ░░░░ = 结果
   █ = 结果          █ = 结果
```

### 8.9.4 统计信息

```python
stats = {
    "feature_count": len(result),
    "overlay_method": how,
}
```

### 8.9.5 使用示例

```yaml
# 计算建筑物与洪水淹没区的交集
- id: flood_affected
  step: vector.overlay
  params:
    input: "$steps.read_buildings"
    overlay_layer: "$steps.read_flood_zone"
    how: intersection

# 计算研究区域中未开发的区域
- id: undeveloped
  step: vector.overlay
  params:
    input: "$steps.read_study_area"
    overlay_layer: "$steps.read_built_area"
    how: difference
```

## 8.10 矢量步骤组合实战

### 8.10.1 城市绿地分析流水线

以下是一个完整的矢量分析流水线示例，模拟"分析城市公园 500 米服务范围覆盖情况"的场景：

```yaml
name: 城市公园服务范围分析
description: 分析城市公园 500 米缓冲区对居民区的覆盖情况

steps:
  # 1. 读取数据
  - id: read_parks
    step: io.read_vector
    params:
      path: "data/parks.gpkg"

  - id: read_residential
    step: io.read_vector
    params:
      path: "data/residential.gpkg"

  - id: read_boundary
    step: io.read_vector
    params:
      path: "data/city_boundary.gpkg"

  # 2. 投影转换（确保使用平面坐标系计算距离）
  - id: parks_utm
    step: vector.reproject
    params:
      input: "$steps.read_parks"
      target_crs: "EPSG:32650"

  - id: residential_utm
    step: vector.reproject
    params:
      input: "$steps.read_residential"
      target_crs: "EPSG:32650"

  - id: boundary_utm
    step: vector.reproject
    params:
      input: "$steps.read_boundary"
      target_crs: "EPSG:32650"

  # 3. 创建公园 500 米缓冲区
  - id: park_buffer
    step: vector.buffer
    params:
      input: "$steps.parks_utm"
      distance: 500

  # 4. 裁剪缓冲区到城市范围
  - id: buffer_clipped
    step: vector.clip
    params:
      input: "$steps.park_buffer"
      clip_geometry: "$steps.boundary_utm"

  # 5. 叠加分析：找出被覆盖的居民区
  - id: covered_residential
    step: vector.overlay
    params:
      input: "$steps.residential_utm"
      overlay_layer: "$steps.buffer_clipped"
      how: intersection

  # 6. 融合缓冲区（消除重叠）
  - id: merged_buffer
    step: vector.dissolve
    params:
      input: "$steps.buffer_clipped"
      by: "park_type"
      aggfunc: "count"

  # 7. 简化几何用于 Web 展示
  - id: simplified
    step: vector.simplify
    params:
      input: "$steps.merged_buffer"
      tolerance: 10

  # 8. 保存结果
  - id: save_result
    step: io.write_vector
    params:
      input: "$steps.simplified"
      path: "output/park_service_area.gpkg"
      format: gpkg

  - id: save_covered
    step: io.write_vector
    params:
      input: "$steps.covered_residential"
      path: "output/covered_residential.geojson"
      format: geojson
```

## 8.11 本章小结

本章详细介绍了 GeoPipeAgent 的七个矢量分析步骤：

1. **后端委托机制**：`run_backend_op` 函数将步骤操作委托给可替换的后端（native_python / qgis_process），实现了算法与步骤定义的解耦
2. **`vector.buffer`**：缓冲区分析，支持 round / flat / square 三种端点样式
3. **`vector.clip`**：矢量裁剪，使用裁剪几何限制数据范围
4. **`vector.reproject`**：投影转换，在不同坐标参考系之间转换数据
5. **`vector.dissolve`**：要素融合，按字段分组合并几何，支持 first / sum / mean / count 聚合
6. **`vector.simplify`**：几何简化，基于 Douglas-Peucker 算法减少顶点数
7. **`vector.query`**：属性查询，使用 Pandas query 表达式筛选要素，唯一不使用后端委托的步骤
8. **`vector.overlay`**：叠加分析，支持 intersection / union / difference / symmetric_difference / identity 五种方式

通过组合这些步骤，可以构建强大的矢量空间分析流水线，实现从数据读取到分析处理再到结果输出的完整工作流。
