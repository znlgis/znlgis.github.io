# 第七章：IO 步骤——数据读写

## 7.1 概述

IO 步骤（Input/Output）是 GeoPipeAgent 中负责数据读写的步骤类别，前缀为 `io`。GeoPipeAgent 内置 4 个 IO 步骤：

| 步骤 ID | 名称 | 方向 | 数据类型 |
|---------|------|------|----------|
| `io.read_vector` | 读取矢量数据 | 输入 | 矢量（GeoDataFrame） |
| `io.write_vector` | 写入矢量数据 | 输出 | 矢量（GeoDataFrame） |
| `io.read_raster` | 读取栅格数据 | 输入 | 栅格（NumPy 数组 + 元信息） |
| `io.write_raster` | 写入栅格数据 | 输出 | 栅格（NumPy 数组 + 元信息） |

IO 步骤通常位于流水线的开头（读取）和末尾（写入），是数据进入和离开流水线的门户。

## 7.2 `io.read_vector`

### 功能说明

读取矢量地理数据文件，返回 GeoPandas `GeoDataFrame` 对象。

### 支持的格式

通过 GeoPandas（依赖 Fiona/GDAL）读取，支持几乎所有主流矢量格式：

| 格式 | 扩展名 | 驱动名称 |
|------|--------|----------|
| Shapefile | `.shp` | ESRI Shapefile |
| GeoJSON | `.geojson` / `.json` | GeoJSON |
| GeoPackage | `.gpkg` | GPKG |
| KML | `.kml` | KML |
| GML | `.gml` | GML |
| PostGIS | `postgresql://...` | PostgreSQL |
| CSV（带坐标列） | `.csv` | CSV |
| FlatGeobuf | `.fgb` | FlatGeobuf |

### 参数说明

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `path` | str | ✅ | — | 文件路径，支持相对路径和绝对路径 |
| `layer` | str/int | ❌ | None（第一层） | 多层文件（如 GPKG）中指定图层名称或索引 |
| `encoding` | str | ❌ | 自动检测 | 文件编码，如 `"utf-8"`、`"gbk"` |
| `bbox` | list | ❌ | None | 空间过滤范围 `[minx, miny, maxx, maxy]`，只读取范围内要素 |
| `mask` | str | ❌ | None | 用于空间过滤的矢量文件路径 |

### 使用示例

```yaml
# 基本读取
- id: load
  use: io.read_vector
  params:
    path: "data/roads.shp"

# 读取 GeoPackage 指定图层
- id: load-buildings
  use: io.read_vector
  params:
    path: "data/urban.gpkg"
    layer: "buildings"

# 读取 GBK 编码的 Shapefile（常见于中文数据）
- id: load-chinese
  use: io.read_vector
  params:
    path: "data/poi.shp"
    encoding: "gbk"

# 按空间范围裁剪读取（提升大文件读取性能）
- id: load-within-bbox
  use: io.read_vector
  params:
    path: "data/national_roads.shp"
    bbox: [116.0, 39.5, 117.0, 40.5]    # 北京附近区域
```

### 输出属性

`io.read_vector` 步骤的输出可通过 `$step-id.attr` 引用以下属性：

| 属性 | 类型 | 说明 |
|------|------|------|
| `crs` | str | CRS 字符串，如 `"EPSG:4326"` |
| `feature_count` | int | 要素数量 |
| `geometry_type` | str | 主几何类型（Point/LineString/Polygon 等） |
| `columns` | list | 属性字段名称列表 |
| `bbox` | list | 数据范围 `[minx, miny, maxx, maxy]` |

### 注意事项

- **大文件处理**：对于超大 Shapefile（数百 MB 以上），建议使用 `bbox` 参数限制读取范围，或使用 GPKG 格式（支持空间索引）。
- **编码问题**：中文数据常见 GBK/GB2312 编码，如遇乱码需显式指定 `encoding`。
- **多层文件**：`.gpkg` 文件可能包含多个图层，不指定 `layer` 时读取第一个图层。

## 7.3 `io.write_vector`

### 功能说明

将 GeoDataFrame 写入矢量地理数据文件。自动创建输出目录（无需手动 `mkdir`）。

### 支持的格式

通过 GeoPandas（依赖 Fiona/GDAL）写入，支持主流矢量格式。

### 参数说明

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | ref | ✅ | — | 输入 GeoDataFrame（来自前一步骤） |
| `path` | str | ✅ | — | 输出文件路径 |
| `driver` | str | ❌ | 根据扩展名自动推断 | 输出格式驱动，如 `GeoJSON`、`GPKG`、`ESRI Shapefile` |
| `encoding` | str | ❌ | `"utf-8"` | 输出编码 |
| `layer` | str | ❌ | None | GPKG 等多层格式的图层名称 |
| `mode` | str | ❌ | `"w"`（覆盖） | 写入模式：`"w"` 覆盖、`"a"` 追加 |

### 使用示例

```yaml
# 写入 GeoJSON
- id: save-geojson
  use: io.write_vector
  params:
    input: $buffer
    path: "output/result.geojson"
    driver: GeoJSON

# 写入 Shapefile（自动推断格式）
- id: save-shp
  use: io.write_vector
  params:
    input: $reproject
    path: "output/reprojected.shp"

# 写入 GeoPackage 指定图层
- id: save-to-gpkg
  use: io.write_vector
  params:
    input: $buffer
    path: "output/analysis.gpkg"
    driver: GPKG
    layer: "buffer_results"

# 追加写入现有 GeoPackage
- id: append-to-gpkg
  use: io.write_vector
  params:
    input: $overlay
    path: "output/analysis.gpkg"
    layer: "overlay_results"
    mode: "a"

# 写入 GBK 编码（兼容某些国产 GIS 软件）
- id: save-gbk
  use: io.write_vector
  params:
    input: $result
    path: "output/result_gbk.shp"
    encoding: "gbk"
```

### 注意事项

- **自动创建目录**：输出路径中的目录不存在时会自动创建。
- **Shapefile 字段名限制**：Shapefile 格式字段名最长 10 个字符，超长字段名会被截断。
- **格式推断**：不指定 `driver` 时，根据文件扩展名自动推断格式（`.geojson` → GeoJSON，`.shp` → ESRI Shapefile 等）。

## 7.4 `io.read_raster`

### 功能说明

读取栅格地理数据文件（如 GeoTIFF），返回包含 NumPy 数组和元信息的结构化数据。

### 支持的格式

通过 rasterio 读取，支持所有 GDAL 支持的栅格格式：

| 格式 | 扩展名 | 说明 |
|------|--------|------|
| GeoTIFF | `.tif` / `.tiff` | 最常用的栅格格式 |
| Cloud Optimized GeoTIFF | `.tif`（COG） | 云端优化格式，支持 HTTP 读取 |
| IMG | `.img` | ERDAS IMAGINE 格式 |
| JPEG2000 | `.jp2` | 压缩栅格格式 |
| NetCDF | `.nc` | 科学数据格式 |
| HDF5 | `.h5` / `.hdf5` | 层次数据格式 |

### 参数说明

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `path` | str | ✅ | — | 栅格文件路径（本地文件或 `/vsicurl/` 前缀的 HTTP URL） |
| `bands` | list/int | ❌ | 所有波段 | 读取的波段编号（从 1 开始），如 `1` 或 `[1, 2, 3]` |

### 使用示例

```yaml
# 读取 GeoTIFF
- id: load-dem
  use: io.read_raster
  params:
    path: "data/dem.tif"

# 读取指定波段（如 NDVI 计算只需红光和近红外）
- id: load-landsat
  use: io.read_raster
  params:
    path: "data/landsat8.tif"
    bands: [4, 5]    # 波段 4（红光）和波段 5（近红外）

# 读取单波段
- id: load-ndvi
  use: io.read_raster
  params:
    path: "data/ndvi.tif"
    bands: 1
```

### 输出数据结构与属性

`io.read_raster` 返回一个包含以下字段的结构体：

| 字段/属性 | 类型 | 说明 |
|-----------|------|------|
| `data` | numpy.ndarray | 栅格像素值数组，形状为 `(bands, height, width)` |
| `meta` | dict | rasterio 元信息字典 |
| `crs` | str | CRS 字符串 |
| `transform` | Affine | 仿射变换矩阵 |
| `width` | int | 像素宽度 |
| `height` | int | 像素高度 |
| `band_count` | int | 波段数量 |
| `nodata` | float/None | NoData 值 |
| `resolution` | tuple | 像元大小 `(x_res, y_res)` |

## 7.5 `io.write_raster`

### 功能说明

将栅格数据写入 GeoTIFF 文件。

### 参数说明

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | ref | ✅ | — | 输入栅格数据（来自前一步骤） |
| `path` | str | ✅ | — | 输出文件路径 |
| `compress` | str | ❌ | None | 压缩方式：`lzw`、`deflate`、`jpeg` 等 |
| `nodata` | float | ❌ | 沿用输入的 nodata | 输出 NoData 值 |

### 使用示例

```yaml
# 写入 GeoTIFF
- id: save-raster
  use: io.write_raster
  params:
    input: $calc
    path: "output/ndvi.tif"

# 写入压缩 GeoTIFF（LZW 无损压缩）
- id: save-compressed
  use: io.write_raster
  params:
    input: $clip
    path: "output/dem_clip.tif"
    compress: lzw

# 自定义 NoData 值
- id: save-nodata
  use: io.write_raster
  params:
    input: $calc
    path: "output/result.tif"
    nodata: -9999
```

## 7.6 综合示例：矢量与栅格混合 IO

```yaml
name: 矢量栅格混合 IO 示例

steps:
  # 读取矢量边界
  - id: load-boundary
    use: io.read_vector
    params:
      path: "data/study_area.geojson"

  # 读取 DEM 栅格
  - id: load-dem
    use: io.read_raster
    params:
      path: "data/dem.tif"

  # 用矢量边界裁剪栅格
  - id: clip-dem
    use: raster.clip
    params:
      input: $load-dem
      mask: $load-boundary

  # 计算统计信息
  - id: stats
    use: raster.stats
    params:
      input: $clip-dem

  # 提取等值线（栅格转矢量）
  - id: contours
    use: raster.contour
    params:
      input: $clip-dem
      interval: 100    # 等高线间隔 100 米

  # 保存等值线（矢量）
  - id: save-contours
    use: io.write_vector
    params:
      input: $contours
      path: "output/contours.geojson"
      driver: GeoJSON

  # 保存裁剪后的 DEM（栅格）
  - id: save-dem
    use: io.write_raster
    params:
      input: $clip-dem
      path: "output/dem_clipped.tif"
      compress: lzw

outputs:
  contours: $save-contours
  clipped_dem: $save-dem
  elevation_stats: $stats
```

## 7.7 性能提示

### 读取大型矢量数据

```yaml
# 使用空间过滤减少内存占用
- id: load
  use: io.read_vector
  params:
    path: "data/large_roads.shp"
    bbox: [116.0, 39.5, 117.0, 40.5]    # 只读取研究区域内的要素

# 或使用属性过滤（通过 vector.query 在读取后过滤）
- id: load-all
  use: io.read_vector
  params:
    path: "data/roads.shp"

- id: filter
  use: vector.query
  params:
    input: $load-all
    expr: "road_type == '主干道'"
```

### 读取大型栅格数据

```yaml
# 只读取需要的波段
- id: load-multibands
  use: io.read_raster
  params:
    path: "data/satellite_10bands.tif"
    bands: [3, 4]    # 只读取 NDVI 所需的波段 3 和 4
```

## 7.8 小结

本章介绍了 GeoPipeAgent 的 4 个 IO 步骤：

- **`io.read_vector`**：读取矢量数据，支持几乎所有主流格式，可按范围/图层过滤
- **`io.write_vector`**：写入矢量数据，自动创建目录，支持追加写入
- **`io.read_raster`**：读取栅格数据，返回 NumPy 数组和元信息，支持按波段选择
- **`io.write_raster`**：写入 GeoTIFF，支持压缩选项

IO 步骤是流水线的入口和出口，后续所有分析步骤都建立在 IO 步骤的基础之上。下一章将介绍矢量分析步骤的详细用法。
