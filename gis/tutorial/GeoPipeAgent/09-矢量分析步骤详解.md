# 第9章：矢量分析步骤详解

GeoPipeAgent 提供了 7 个内置矢量分析步骤，覆盖了缓冲区、裁剪、融合、叠加、查询、投影变换和简化等常用空间分析操作。本章将逐一详解每个步骤的参数、输出、后端差异以及完整使用示例。

---

## 9.1 矢量步骤总览

| 步骤 ID | 名称 | 功能简述 | 后端支持 |
|---------|------|---------|---------|
| `vector.buffer` | 缓冲区分析 | 为几何要素创建缓冲区 | native_python, qgis_process |
| `vector.clip` | 矢量裁剪 | 按多边形边界裁剪数据 | native_python, qgis_process |
| `vector.dissolve` | 矢量融合 | 按字段合并几何要素 | native_python, qgis_process |
| `vector.overlay` | 叠加分析 | 交集/并集/差集等集合运算 | native_python, qgis_process |
| `vector.query` | 矢量查询 | 属性查询和空间查询 | native_python |
| `vector.reproject` | 投影变换 | 坐标参考系转换 | native_python, qgis_process |
| `vector.simplify` | 矢量简化 | 减少顶点数简化几何形状 | native_python, qgis_process |

## 9.2 vector.buffer — 缓冲区分析

### 9.2.1 功能说明

为输入矢量数据的每个几何要素创建指定距离的缓冲区（Buffer）。缓冲区是围绕几何要素一定距离范围内的区域，是 GIS 中最基础的空间分析操作之一。

### 9.2.2 参数表

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | `geodataframe` | ✅ | — | 输入的 GeoDataFrame |
| `distance` | `number` | ✅ | — | 缓冲区距离（单位取决于 CRS） |
| `cap_style` | `string` | ❌ | `round` | 端点样式：`round`（圆形）、`flat`（平头）、`square`（方形） |
| `join_style` | `string` | ❌ | `round` | 连接样式：`round`（圆形）、`mitre`（尖角）、`bevel`（斜角） |
| `resolution` | `number` | ❌ | `16` | 圆弧分段数，值越大越圆滑 |

### 9.2.3 输出

| 输出 | 类型 | 说明 |
|------|------|------|
| `output` | `geodataframe` | 包含缓冲区多边形的 GeoDataFrame |

### 9.2.4 后端支持

| 后端 | 实现方式 | 特点 |
|------|---------|------|
| `native_python` | GeoPandas + Shapely `geometry.buffer()` | 默认后端，纯 Python 实现 |
| `qgis_process` | QGIS `native:buffer` 算法 | 大数据量时可能更快 |

### 9.2.5 使用示例

```yaml
# 基本缓冲区（100米，需要投影坐标系）
- id: buffer_100m
  step: vector.buffer
  params:
    input: ${read_step.output}
    distance: 100

# 方形端点缓冲区
- id: buffer_square
  step: vector.buffer
  params:
    input: ${read_step.output}
    distance: 50
    cap_style: square

# 高精度圆形缓冲区
- id: buffer_smooth
  step: vector.buffer
  params:
    input: ${read_step.output}
    distance: 200
    resolution: 64

# 负缓冲区（向内缩小）
- id: buffer_negative
  step: vector.buffer
  params:
    input: ${read_step.output}
    distance: -10
```

> **注意：** `distance` 的单位取决于输入数据的 CRS。如果 CRS 是 EPSG:4326（经纬度），单位是度；如果是投影坐标系（如 EPSG:3857），单位是米。建议先投影到米制坐标系再做缓冲区分析。

## 9.3 vector.clip — 矢量裁剪

### 9.3.1 功能说明

使用裁剪多边形（clip geometry）对输入数据进行空间裁剪，只保留位于裁剪范围内的部分。

### 9.3.2 参数表

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | `geodataframe` | ✅ | — | 待裁剪的输入数据 |
| `clip_geometry` | `geodataframe` | ✅ | — | 裁剪范围（多边形 GeoDataFrame） |

### 9.3.3 输出

| 输出 | 类型 | 说明 |
|------|------|------|
| `output` | `geodataframe` | 裁剪后的数据，仅含裁剪范围内的要素 |

### 9.3.4 使用示例

```yaml
steps:
  - id: read_buildings
    step: io.read_vector
    params:
      path: "data/buildings.shp"

  - id: read_boundary
    step: io.read_vector
    params:
      path: "data/study_area.geojson"

  - id: clip_buildings
    step: vector.clip
    params:
      input: ${read_buildings.output}
      clip_geometry: ${read_boundary.output}

  - id: save_clipped
    step: io.write_vector
    params:
      input: ${clip_buildings.output}
      path: "output/buildings_clipped.geojson"
```

> **注意：** 裁剪操作要求两个数据集的 CRS 一致，否则会出错。如果不一致，需先用 `vector.reproject` 统一坐标系。

## 9.4 vector.dissolve — 矢量融合

### 9.4.1 功能说明

按指定字段将几何要素合并（融合）为更少的要素。同一字段值的要素合并为一个多部件几何体。如果 `by` 为 `None`，则将所有要素融合为一个。

### 9.4.2 参数表

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | `geodataframe` | ✅ | — | 输入的 GeoDataFrame |
| `by` | `string` | ❌ | `None` | 融合字段名，None 时合并所有要素 |
| `aggfunc` | `string` | ❌ | `first` | 属性聚合函数：`first`、`last`、`sum`、`mean`、`min`、`max`、`count` |

### 9.4.3 输出

| 输出 | 类型 | 说明 |
|------|------|------|
| `output` | `geodataframe` | 融合后的 GeoDataFrame |

### 9.4.4 使用示例

```yaml
# 按省份名称融合
- id: dissolve_province
  step: vector.dissolve
  params:
    input: ${read_step.output}
    by: "province"
    aggfunc: "sum"  # 面积等数值字段求和

# 全部融合为一个要素
- id: dissolve_all
  step: vector.dissolve
  params:
    input: ${read_step.output}
    # by 省略则合并所有要素
```

## 9.5 vector.overlay — 矢量叠加分析

### 9.5.1 功能说明

对两个矢量数据集执行集合运算（叠加分析），支持交集、并集、差集和对称差集四种操作。

### 9.5.2 参数表

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | `geodataframe` | ✅ | — | 第一个输入数据集 |
| `overlay` | `geodataframe` | ✅ | — | 第二个数据集（叠加层） |
| `how` | `string` | ❌ | `intersection` | 叠加方式 |

### 9.5.3 叠加方式说明

| 方式 | 说明 | 结果 |
|------|------|------|
| `intersection` | 交集 | 两个图层空间重叠的部分 |
| `union` | 并集 | 两个图层的全部区域 |
| `difference` | 差集 | input 中不与 overlay 重叠的部分 |
| `symmetric_difference` | 对称差集 | 两个图层不重叠的部分 |

### 9.5.4 使用示例

```yaml
# 交集分析：找出建筑物与洪水区的重叠部分
- id: flood_risk_buildings
  step: vector.overlay
  params:
    input: ${read_buildings.output}
    overlay: ${read_flood_zone.output}
    how: "intersection"

# 差集分析：从地块中扣除道路用地
- id: subtract_roads
  step: vector.overlay
  params:
    input: ${read_parcels.output}
    overlay: ${read_roads.output}
    how: "difference"

# 并集分析
- id: merge_areas
  step: vector.overlay
  params:
    input: ${area_a.output}
    overlay: ${area_b.output}
    how: "union"
```

## 9.6 vector.query — 矢量查询

### 9.6.1 功能说明

对矢量数据进行属性查询和/或空间查询，筛选满足条件的要素。

### 9.6.2 参数表

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | `geodataframe` | ✅ | — | 输入的 GeoDataFrame |
| `expression` | `string` | ❌ | `None` | 属性过滤表达式（Pandas query 语法） |
| `spatial_filter` | `geodataframe` | ❌ | `None` | 空间过滤范围（多边形） |

### 9.6.3 使用示例

```yaml
# 属性查询：筛选面积大于 1000 的建筑物
- id: query_large
  step: vector.query
  params:
    input: ${read_step.output}
    expression: "area > 1000"

# 属性查询：按类型筛选
- id: query_residential
  step: vector.query
  params:
    input: ${read_step.output}
    expression: "building_type == '住宅'"

# 组合条件查询
- id: query_combined
  step: vector.query
  params:
    input: ${read_step.output}
    expression: "area > 500 and floors >= 3"

# 空间查询：选择在指定范围内的要素
- id: query_spatial
  step: vector.query
  params:
    input: ${read_buildings.output}
    spatial_filter: ${read_boundary.output}

# 属性 + 空间组合查询
- id: query_both
  step: vector.query
  params:
    input: ${read_buildings.output}
    expression: "building_type == '商业'"
    spatial_filter: ${read_boundary.output}
```

## 9.7 vector.reproject — 投影变换

### 9.7.1 功能说明

将矢量数据从当前坐标参考系（CRS）转换到目标坐标参考系。

### 9.7.2 参数表

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | `geodataframe` | ✅ | — | 输入的 GeoDataFrame |
| `target_crs` | `string` | ✅ | — | 目标 CRS（如 `"EPSG:4326"`） |

### 9.7.3 常用坐标参考系

| CRS | 说明 | 单位 | 适用场景 |
|-----|------|------|---------|
| `EPSG:4326` | WGS 84 | 度 | GPS 数据、Web 地图、国际通用 |
| `EPSG:3857` | Web Mercator | 米 | Web 地图瓦片 |
| `EPSG:4490` | CGCS2000 | 度 | 中国国家大地坐标系 |
| `EPSG:4547` | CGCS2000 / 3度高斯39带 | 米 | 中国东部地区投影坐标 |
| `EPSG:32650` | UTM Zone 50N | 米 | 中国东部 UTM 投影 |

### 9.7.4 使用示例

```yaml
# 转换到 WGS84
- id: to_wgs84
  step: vector.reproject
  params:
    input: ${read_step.output}
    target_crs: "EPSG:4326"

# 转换到投影坐标系（用于面积/距离计算）
- id: to_projected
  step: vector.reproject
  params:
    input: ${read_step.output}
    target_crs: "EPSG:4547"

# 条件投影：仅当 CRS 不匹配时执行
- id: conditional_reproject
  step: vector.reproject
  params:
    input: ${read_step.output}
    target_crs: "EPSG:4326"
  when: "${read_step.stats.crs} != 'EPSG:4326'"
```

## 9.8 vector.simplify — 矢量简化

### 9.8.1 功能说明

通过减少几何体的顶点数来简化几何形状，用于降低数据复杂度和文件大小。

### 9.8.2 参数表

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | `geodataframe` | ✅ | — | 输入的 GeoDataFrame |
| `tolerance` | `number` | ✅ | — | 简化容差（单位取决于 CRS） |
| `preserve_topology` | `boolean` | ❌ | `true` | 是否保持拓扑结构（防止自相交） |

### 9.8.3 使用示例

```yaml
# 基本简化
- id: simplify
  step: vector.simplify
  params:
    input: ${read_step.output}
    tolerance: 0.001  # WGS84 约 100 米

# 不保持拓扑的简化（更快但可能产生无效几何体）
- id: simplify_fast
  step: vector.simplify
  params:
    input: ${read_step.output}
    tolerance: 0.005
    preserve_topology: false

# 条件简化：仅对大数据集简化
- id: simplify_large
  step: vector.simplify
  params:
    input: ${read_step.output}
    tolerance: 0.001
  when: "${read_step.stats.feature_count} > 50000"
```

## 9.9 _delegate.py 后端委托模式

### 9.9.1 工作原理

`_delegate.py` 是矢量步骤的后端委托辅助模块。当一个步骤支持多个后端时，通过委托模式将执行分派到不同的后端实现。

```python
# steps/_delegate.py
def delegate(context, implementations):
    """
    根据 context.backend 将执行委托给对应的后端实现。
    
    Args:
        context: StepContext 对象
        implementations: 后端名称到实现函数的映射字典
    """
    backend = context.backend
    if backend not in implementations:
        raise BackendNotAvailableError(backend, context.step_id)
    return implementations[backend](context)
```

### 9.9.2 后端差异

| 操作 | native_python 实现 | qgis_process 实现 |
|------|-------------------|-------------------|
| buffer | GeoPandas `geometry.buffer()` | `native:buffer` 算法 |
| clip | GeoPandas `gpd.clip()` | `native:clip` 算法 |
| dissolve | GeoPandas `dissolve()` | `native:dissolve` 算法 |
| overlay | GeoPandas `gpd.overlay()` | `native:union` / `native:intersection` |
| reproject | GeoPandas `to_crs()` | `native:reprojectlayer` 算法 |
| simplify | Shapely `simplify()` | `native:simplifygeometries` 算法 |

## 9.10 多步骤组合示例

### 9.10.1 完整矢量处理工作流

```yaml
name: 城市绿地缓冲区分析
description: |
  读取建筑物和绿地数据，计算每栋建筑到最近绿地的距离，
  找出距离绿地超过500米的建筑物。

steps:
  - id: read_buildings
    step: io.read_vector
    params:
      path: "data/buildings.shp"
      encoding: "GBK"

  - id: read_greenspace
    step: io.read_vector
    params:
      path: "data/greenspace.shp"
      encoding: "GBK"

  # 统一投影到米制坐标系
  - id: proj_buildings
    step: vector.reproject
    params:
      input: ${read_buildings.output}
      target_crs: "EPSG:4547"

  - id: proj_green
    step: vector.reproject
    params:
      input: ${read_greenspace.output}
      target_crs: "EPSG:4547"

  # 对绿地做 500 米缓冲区
  - id: green_buffer
    step: vector.buffer
    params:
      input: ${proj_green.output}
      distance: 500

  # 融合所有缓冲区为一个整体
  - id: dissolve_buffer
    step: vector.dissolve
    params:
      input: ${green_buffer.output}

  # 差集：找出不在绿地缓冲区内的建筑
  - id: buildings_outside
    step: vector.overlay
    params:
      input: ${proj_buildings.output}
      overlay: ${dissolve_buffer.output}
      how: "difference"

  # 简化结果几何体
  - id: simplify_result
    step: vector.simplify
    params:
      input: ${buildings_outside.output}
      tolerance: 1
      preserve_topology: true

  # 投影回 WGS84 保存
  - id: reproject_back
    step: vector.reproject
    params:
      input: ${simplify_result.output}
      target_crs: "EPSG:4326"

  - id: save
    step: io.write_vector
    params:
      input: ${reproject_back.output}
      path: "output/buildings_far_from_green.geojson"
```

## 9.11 本章小结

| 步骤 | 核心参数 | 典型用途 |
|------|---------|---------|
| `vector.buffer` | distance, cap_style | 影响范围分析、服务区分析 |
| `vector.clip` | clip_geometry | 研究区域提取 |
| `vector.dissolve` | by, aggfunc | 行政区合并、分类汇总 |
| `vector.overlay` | how (intersection/union/difference) | 空间叠加分析 |
| `vector.query` | expression, spatial_filter | 条件筛选 |
| `vector.reproject` | target_crs | 坐标系统一 |
| `vector.simplify` | tolerance, preserve_topology | 数据精简、Web展示 |
