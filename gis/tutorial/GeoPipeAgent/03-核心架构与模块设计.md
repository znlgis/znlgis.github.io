## 3.1 三阶段执行模型

GeoPipeAgent 的流水线执行遵循严格的 **四阶段模型**：Parse → Validate → Execute → Report。每个阶段都有明确的输入、输出和职责。

### 3.1.1 阶段总览

```
┌─────────────────────────────────────────────────────────────────────┐
│                     GeoPipeAgent 四阶段执行模型                      │
│                                                                     │
│  ┌──────────┐    ┌───────────┐    ┌───────────┐    ┌────────────┐  │
│  │  Parse   │───▶│ Validate  │───▶│  Execute  │───▶│  Report    │  │
│  │  解析阶段 │    │  校验阶段  │    │  执行阶段  │    │  报告阶段   │  │
│  └──────────┘    └───────────┘    └───────────┘    └────────────┘  │
│       │               │                │                 │          │
│  YAML → Model    模型 → 校验结果   校验模型 → 结果     结果 → JSON   │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 3.1.2 各阶段详细说明

**阶段一：Parse（解析）**

| 属性 | 说明 |
|------|------|
| **输入** | YAML 文件路径或 YAML 字符串 |
| **输出** | `PipelineDefinition` 数据模型 |
| **负责模块** | `engine/parser.py` |
| **可能错误** | YAML 语法错误、缺少必要字段 |

解析阶段将 YAML 文本转换为结构化的 Python 数据模型。这一步仅进行语法级别的转换，不涉及语义校验。

```python
# parser.py 的核心逻辑
def parse(yaml_path: str) -> PipelineDefinition:
    """将 YAML 文件解析为 PipelineDefinition"""
    with open(yaml_path) as f:
        raw = yaml.safe_load(f)
    
    pipeline_raw = raw.get("pipeline", {})
    
    steps = []
    for step_raw in pipeline_raw.get("steps", []):
        step_def = StepDefinition(
            id=step_raw["id"],
            use=step_raw["use"],
            params=step_raw.get("params", {}),
            when=step_raw.get("when"),
            on_error=step_raw.get("on_error", "fail"),
            backend=step_raw.get("backend"),
        )
        steps.append(step_def)
    
    return PipelineDefinition(
        name=pipeline_raw.get("name", "unnamed"),
        description=pipeline_raw.get("description", ""),
        crs=pipeline_raw.get("crs"),
        variables=pipeline_raw.get("variables", {}),
        steps=steps,
        outputs=pipeline_raw.get("outputs", {}),
    )
```

**阶段二：Validate（校验）**

| 属性 | 说明 |
|------|------|
| **输入** | `PipelineDefinition` 数据模型 |
| **输出** | 校验通过的 `PipelineDefinition` 或校验错误列表 |
| **负责模块** | `engine/validator.py` |
| **检查项** | 步骤 ID 唯一性、引用有效性、参数类型、步骤存在性 |

校验阶段在执行前对流水线定义进行全面检查，确保所有引用、类型和结构都是合法的。

```python
# validator.py 的核心逻辑
def validate(pipeline: PipelineDefinition) -> list[ValidationError]:
    """校验流水线定义，返回错误列表（空列表表示校验通过）"""
    errors = []
    
    # 1. 检查步骤 ID 唯一性
    seen_ids = set()
    for step in pipeline.steps:
        if step.id in seen_ids:
            errors.append(ValidationError(
                step_id=step.id,
                message=f"Duplicate step ID: '{step.id}'"
            ))
        seen_ids.add(step.id)
    
    # 2. 检查步骤 ID 格式
    import re
    id_pattern = re.compile(r'^[a-z0-9_-]+$')
    for step in pipeline.steps:
        if not id_pattern.match(step.id):
            errors.append(ValidationError(
                step_id=step.id,
                message=f"Invalid step ID format: '{step.id}'. "
                        f"Must match [a-z0-9_-]"
            ))
    
    # 3. 检查步骤是否已注册
    from geopipe_agent.steps.registry import get_step
    for step in pipeline.steps:
        if get_step(step.use) is None:
            errors.append(ValidationError(
                step_id=step.id,
                message=f"Unknown step type: '{step.use}'"
            ))
    
    # 4. 检查引用有效性（不允许前向引用）
    defined_ids = set()
    for step in pipeline.steps:
        for param_name, param_value in step.params.items():
            if isinstance(param_value, str) and param_value.startswith("$"):
                ref_id = param_value.lstrip("$").split(".")[0]
                if ref_id not in defined_ids:
                    errors.append(ValidationError(
                        step_id=step.id,
                        message=f"Parameter '{param_name}' references "
                                f"undefined step: '{ref_id}'"
                    ))
        defined_ids.add(step.id)
    
    # 5. 检查参数类型
    for step in pipeline.steps:
        step_info = get_step(step.use)
        if step_info:
            _validate_params(step, step_info, errors)
    
    return errors
```

**阶段三：Execute（执行）**

| 属性 | 说明 |
|------|------|
| **输入** | 校验通过的 `PipelineDefinition` |
| **输出** | `list[StepResult]` 步骤结果列表 |
| **负责模块** | `engine/executor.py` |
| **功能** | 逐步执行、变量解析、条件判断、重试、错误处理 |

执行阶段是整个框架的核心，它按顺序执行每个步骤，管理步骤间的数据传递。

```python
# executor.py 的核心逻辑
class PipelineExecutor:
    """流水线执行器"""
    
    def __init__(self, pipeline: PipelineDefinition):
        self.pipeline = pipeline
        self.context = PipelineContext(pipeline.variables)
        self.results: list[StepResult] = []
    
    def execute(self) -> list[StepResult]:
        """执行整个流水线"""
        for step_def in self.pipeline.steps:
            result = self._execute_step(step_def)
            self.results.append(result)
            
            if result.status == "success":
                self.context.set_result(step_def.id, result)
            elif step_def.on_error == "fail":
                break  # 停止流水线
            # on_error == "skip" 时继续执行
        
        return self.results
    
    def _execute_step(self, step_def: StepDefinition) -> StepResult:
        """执行单个步骤"""
        # 1. 检查 when 条件
        if step_def.when and not self._evaluate_condition(step_def.when):
            return StepResult(
                id=step_def.id, use=step_def.use,
                status="skipped", reason="Condition not met"
            )
        
        # 2. 解析参数中的引用和变量
        resolved_params = self.context.resolve_params(step_def.params)
        
        # 3. 获取步骤函数
        step_func = get_step(step_def.use)
        
        # 4. 选择后端
        backend = self._get_backend(step_def.backend)
        
        # 5. 执行步骤（带重试）
        try:
            output = step_func(**resolved_params, backend=backend)
            return StepResult(
                id=step_def.id, use=step_def.use,
                status="success", output=output,
                stats=self._compute_stats(output)
            )
        except Exception as e:
            return StepResult(
                id=step_def.id, use=step_def.use,
                status="error", error=str(e)
            )
```

**阶段四：Report（报告）**

| 属性 | 说明 |
|------|------|
| **输入** | `PipelineDefinition` + `list[StepResult]` |
| **输出** | JSON 报告（字典或文件） |
| **负责模块** | `engine/reporter.py` |
| **功能** | 汇总结果、聚合 QC 问题、计算统计、格式化输出 |

```python
# reporter.py 的核心逻辑
class PipelineReporter:
    """流水线报告生成器"""
    
    def generate(
        self,
        pipeline: PipelineDefinition,
        results: list[StepResult],
        started_at: datetime,
        finished_at: datetime,
    ) -> dict:
        """生成完整的 JSON 报告"""
        # 汇总 QC 问题
        all_qc_issues = []
        for result in results:
            if hasattr(result.output, "qc_issues"):
                all_qc_issues.extend(result.output.qc_issues)
        
        # 统计
        passed = sum(1 for r in results if r.status == "success")
        failed = sum(1 for r in results if r.status == "error")
        skipped = sum(1 for r in results if r.status == "skipped")
        
        return {
            "pipeline": pipeline.name,
            "description": pipeline.description,
            "status": "success" if failed == 0 else "failed",
            "started_at": started_at.isoformat(),
            "finished_at": finished_at.isoformat(),
            "duration_seconds": (finished_at - started_at).total_seconds(),
            "total_steps": len(results),
            "passed_steps": passed,
            "failed_steps": failed,
            "skipped_steps": skipped,
            "variables": pipeline.variables,
            "steps": [self._format_step(r) for r in results],
            "qc_issues": [self._format_qc(q) for q in all_qc_issues],
            "qc_summary": {
                "total_issues": len(all_qc_issues),
                "errors": sum(1 for q in all_qc_issues if q.severity == "error"),
                "warnings": sum(1 for q in all_qc_issues if q.severity == "warning"),
            },
            "outputs": self._format_outputs(pipeline.outputs, results),
        }
```

### 3.2.1 层间依赖规则

GeoPipeAgent 遵循严格的层间依赖规则：

```
CLI Layer       ──依赖──▶  Engine Layer
Engine Layer    ──依赖──▶  Step Layer, Model Layer, Utils Layer
Step Layer      ──依赖──▶  Backend Layer, Model Layer, Utils Layer
Backend Layer   ──依赖──▶  Model Layer, Utils Layer
Model Layer     ──依赖──▶  (无依赖)
Utils Layer     ──依赖──▶  (无依赖)
```

**关键原则：**
- 上层可以依赖下层，但下层不能依赖上层
- 同层模块之间尽量减少依赖
- Model Layer 和 Utils Layer 是纯粹的基础层，不依赖其他任何层

### 3.3.2 engine/parser.py — YAML 解析器

解析器负责将 YAML 文件转换为 `PipelineDefinition` 数据模型。

```python
"""YAML Pipeline Parser"""
from __future__ import annotations

import yaml
from pathlib import Path
from geopipe_agent.models.pipeline import PipelineDefinition, StepDefinition
from geopipe_agent.errors import ParseError


def parse(source: str | Path) -> PipelineDefinition:
    """
    解析 YAML 流水线定义。
    
    Args:
        source: YAML 文件路径或 YAML 字符串
    
    Returns:
        PipelineDefinition 数据模型
    
    Raises:
        ParseError: YAML 语法错误或缺少必要字段
    """
    # 加载 YAML
    if isinstance(source, (str, Path)) and Path(source).exists():
        with open(source, encoding="utf-8") as f:
            raw = yaml.safe_load(f)
    else:
        raw = yaml.safe_load(source)
    
    if not isinstance(raw, dict) or "pipeline" not in raw:
        raise ParseError("YAML must contain a top-level 'pipeline' key")
    
    pipeline_raw = raw["pipeline"]
    
    # 解析步骤
    steps = _parse_steps(pipeline_raw.get("steps", []))
    
    # 构建 PipelineDefinition
    return PipelineDefinition(
        name=pipeline_raw.get("name", "unnamed"),
        description=pipeline_raw.get("description", ""),
        crs=pipeline_raw.get("crs"),
        variables=pipeline_raw.get("variables", {}),
        steps=steps,
        outputs=pipeline_raw.get("outputs", {}),
    )


def _parse_steps(steps_raw: list[dict]) -> list[StepDefinition]:
    """解析步骤列表"""
    steps = []
    for i, step_raw in enumerate(steps_raw):
        if "id" not in step_raw:
            raise ParseError(f"Step at index {i} is missing 'id' field")
        if "use" not in step_raw:
            raise ParseError(f"Step '{step_raw.get('id', i)}' is missing 'use' field")
        
        step = StepDefinition(
            id=step_raw["id"],
            use=step_raw["use"],
            params=step_raw.get("params", {}),
            when=step_raw.get("when"),
            on_error=step_raw.get("on_error", "fail"),
            backend=step_raw.get("backend"),
        )
        steps.append(step)
    
    return steps
```

### 3.3.3 engine/validator.py — 流水线校验器

校验器在执行前对流水线进行全面检查：

```python
"""Pipeline Validator"""
from __future__ import annotations

import re
from dataclasses import dataclass
from geopipe_agent.models.pipeline import PipelineDefinition, StepDefinition
from geopipe_agent.steps.registry import get_step, get_step_info


@dataclass
class ValidationError:
    """校验错误"""
    step_id: str
    message: str
    severity: str = "error"  # error, warning


# 步骤 ID 合法模式
STEP_ID_PATTERN = re.compile(r'^[a-z][a-z0-9_-]*$')

# 引用模式：$step_id 或 $step_id.attr
REFERENCE_PATTERN = re.compile(r'^\$([a-z][a-z0-9_-]*)(?:\.([a-z_]+))?$')

# 变量模式：${var_name}
VARIABLE_PATTERN = re.compile(r'\$\{([a-zA-Z_][a-zA-Z0-9_]*)\}')


def validate(pipeline: PipelineDefinition) -> list[ValidationError]:
    """
    校验流水线定义。
    
    校验项目：
    1. 步骤 ID 格式
    2. 步骤 ID 唯一性
    3. 步骤类型已注册
    4. 引用有效性（无前向引用）
    5. 变量已定义
    6. 参数类型匹配
    7. 必填参数完整
    8. outputs 引用有效
    
    Returns:
        校验错误列表，空列表表示校验通过
    """
    errors: list[ValidationError] = []
    
    # 1-2. 步骤 ID 格式和唯一性
    _validate_step_ids(pipeline, errors)
    
    # 3. 步骤类型
    _validate_step_types(pipeline, errors)
    
    # 4. 引用有效性
    _validate_references(pipeline, errors)
    
    # 5. 变量定义
    _validate_variables(pipeline, errors)
    
    # 6-7. 参数类型和必填
    _validate_params(pipeline, errors)
    
    # 8. outputs 引用
    _validate_outputs(pipeline, errors)
    
    return errors


def _validate_step_ids(pipeline: PipelineDefinition, errors: list[ValidationError]):
    """校验步骤 ID"""
    seen_ids: set[str] = set()
    
    for step in pipeline.steps:
        # 格式检查
        if not STEP_ID_PATTERN.match(step.id):
            errors.append(ValidationError(
                step_id=step.id,
                message=f"Invalid step ID '{step.id}'. "
                        f"Must match pattern: [a-z][a-z0-9_-]*"
            ))
        
        # 唯一性检查
        if step.id in seen_ids:
            errors.append(ValidationError(
                step_id=step.id,
                message=f"Duplicate step ID: '{step.id}'"
            ))
        seen_ids.add(step.id)


def _validate_references(pipeline: PipelineDefinition, errors: list[ValidationError]):
    """校验步骤引用（禁止前向引用）"""
    defined_ids: set[str] = set()
    
    for step in pipeline.steps:
        # 检查参数中的引用
        _check_refs_in_params(step.id, step.params, defined_ids, errors)
        
        # 检查 when 条件中的引用
        if step.when:
            _check_refs_in_expression(step.id, step.when, defined_ids, errors)
        
        # 当前步骤加入已定义集合
        defined_ids.add(step.id)
```

### 3.3.4 engine/executor.py — 步骤执行器

执行器是框架的核心组件，负责按顺序执行步骤并管理数据流：

```python
"""Pipeline Executor"""
from __future__ import annotations

import time
import logging
from datetime import datetime
from geopipe_agent.models.pipeline import PipelineDefinition, StepDefinition
from geopipe_agent.models.result import StepResult
from geopipe_agent.engine.context import PipelineContext
from geopipe_agent.steps.registry import get_step
from geopipe_agent.backends.base import Backend, get_backend
from geopipe_agent.utils.safe_eval import safe_eval

logger = logging.getLogger(__name__)


class PipelineExecutor:
    """流水线执行器"""
    
    def __init__(
        self,
        pipeline: PipelineDefinition,
        default_backend: str = "native_python",
    ):
        self.pipeline = pipeline
        self.context = PipelineContext(pipeline.variables)
        self.default_backend = default_backend
        self.results: list[StepResult] = []
        self.started_at: datetime | None = None
        self.finished_at: datetime | None = None
    
    def execute(self) -> list[StepResult]:
        """执行整个流水线，返回步骤结果列表"""
        self.started_at = datetime.utcnow()
        logger.info(f"Starting pipeline: {self.pipeline.name}")
        
        for step_def in self.pipeline.steps:
            logger.info(f"Executing step: {step_def.id} ({step_def.use})")
            
            step_start = time.time()
            result = self._execute_step(step_def)
            result.duration_seconds = time.time() - step_start
            
            self.results.append(result)
            
            # 成功时注册结果到上下文
            if result.status == "success":
                self.context.set_result(step_def.id, result)
                logger.info(f"  ✓ {step_def.id} completed in "
                           f"{result.duration_seconds:.2f}s")
            elif result.status == "skipped":
                logger.info(f"  ⊘ {step_def.id} skipped: {result.reason}")
            else:
                logger.error(f"  ✗ {step_def.id} failed: {result.error}")
                if step_def.on_error == "fail":
                    logger.error("Pipeline aborted due to step failure")
                    break
                # on_error == "skip" → continue
        
        self.finished_at = datetime.utcnow()
        duration = (self.finished_at - self.started_at).total_seconds()
        logger.info(f"Pipeline finished in {duration:.2f}s")
        
        return self.results
    
    def _execute_step(self, step_def: StepDefinition) -> StepResult:
        """执行单个步骤"""
        # 1. 条件检查
        if step_def.when:
            try:
                condition_met = safe_eval(
                    step_def.when, 
                    self.context.get_eval_namespace()
                )
                if not condition_met:
                    return StepResult(
                        id=step_def.id, use=step_def.use,
                        status="skipped",
                        reason=f"Condition not met: {step_def.when}"
                    )
            except Exception as e:
                return StepResult(
                    id=step_def.id, use=step_def.use,
                    status="error",
                    error=f"Condition evaluation failed: {e}"
                )
        
        # 2. 解析参数
        try:
            resolved_params = self.context.resolve_params(step_def.params)
        except Exception as e:
            return StepResult(
                id=step_def.id, use=step_def.use,
                status="error",
                error=f"Parameter resolution failed: {e}"
            )
        
        # 3. 获取步骤函数
        step_func = get_step(step_def.use)
        
        # 4. 获取后端
        backend_name = step_def.backend or self.default_backend
        backend = get_backend(backend_name)
        
        # 5. 执行
        try:
            output = step_func(**resolved_params, backend=backend)
            stats = self._compute_stats(output)
            return StepResult(
                id=step_def.id, use=step_def.use,
                status="success", output=output, stats=stats
            )
        except Exception as e:
            logger.exception(f"Step {step_def.id} raised exception")
            return StepResult(
                id=step_def.id, use=step_def.use,
                status="error", error=str(e)
            )
    
    def _compute_stats(self, output) -> dict:
        """计算输出统计信息"""
        stats = {}
        
        # GeoDataFrame 统计
        if hasattr(output, "shape"):
            stats["feature_count"] = len(output)
            if hasattr(output, "crs") and output.crs:
                stats["crs"] = str(output.crs)
            if hasattr(output, "geometry"):
                stats["geometry_type"] = output.geometry.geom_type.unique().tolist()
                bounds = output.total_bounds
                stats["bounds"] = bounds.tolist()
            stats["columns"] = output.columns.tolist()
        
        # 字符串输出（文件路径）
        elif isinstance(output, str):
            stats["output_path"] = output
        
        # QC 结果
        elif hasattr(output, "qc_issues"):
            stats["issues_count"] = len(output.qc_issues)
        
        return stats
```

### 3.3.5 engine/context.py — 上下文管理

上下文管理器负责维护变量和步骤结果的命名空间，处理引用解析：

```python
"""Pipeline Context Manager"""
from __future__ import annotations

import re
from typing import Any
from geopipe_agent.models.result import StepResult

# 引用模式
REF_PATTERN = re.compile(r'^\$([a-z][a-z0-9_-]*)(?:\.([a-z_]+))?$')
VAR_PATTERN = re.compile(r'\$\{([a-zA-Z_][a-zA-Z0-9_]*)\}')


class PipelineContext:
    """
    流水线上下文，管理变量和步骤结果。
    
    支持的引用格式：
    - $step_id          → step_result.output (shorthand)
    - $step_id.output   → step_result.output
    - $step_id.stats    → step_result.stats
    - $step_id.<key>    → step_result.<key>
    - ${var_name}       → variables[var_name]
    """
    
    def __init__(self, variables: dict[str, Any] | None = None):
        self._variables: dict[str, Any] = dict(variables or {})
        self._results: dict[str, StepResult] = {}
    
    def set_variable(self, name: str, value: Any) -> None:
        """设置变量"""
        self._variables[name] = value
    
    def set_result(self, step_id: str, result: StepResult) -> None:
        """注册步骤结果"""
        self._results[step_id] = result
    
    def resolve_params(self, params: dict[str, Any]) -> dict[str, Any]:
        """解析参数中的所有引用和变量"""
        resolved = {}
        for key, value in params.items():
            resolved[key] = self._resolve_value(value)
        return resolved
    
    def _resolve_value(self, value: Any) -> Any:
        """递归解析单个值"""
        if isinstance(value, str):
            # 1. 完整引用：$step_id 或 $step_id.attr
            ref_match = REF_PATTERN.match(value)
            if ref_match:
                return self._resolve_reference(
                    ref_match.group(1), ref_match.group(2)
                )
            
            # 2. 变量替换：${var_name}
            if VAR_PATTERN.search(value):
                return self._resolve_variables(value)
            
            return value
        
        elif isinstance(value, list):
            return [self._resolve_value(item) for item in value]
        
        elif isinstance(value, dict):
            return {k: self._resolve_value(v) for k, v in value.items()}
        
        return value
    
    def _resolve_reference(self, step_id: str, attr: str | None) -> Any:
        """解析步骤引用"""
        if step_id not in self._results:
            raise ValueError(f"Step '{step_id}' not found in context")
        
        result = self._results[step_id]
        
        if attr is None or attr == "output":
            return result.output
        elif attr == "stats":
            return result.stats
        else:
            return getattr(result, attr)
    
    def _resolve_variables(self, template: str) -> Any:
        """解析变量模板"""
        # 如果整个字符串就是一个变量，返回原始类型
        full_match = re.fullmatch(r'\$\{([a-zA-Z_][a-zA-Z0-9_]*)\}', template)
        if full_match:
            var_name = full_match.group(1)
            if var_name not in self._variables:
                raise ValueError(f"Variable '{var_name}' not defined")
            return self._variables[var_name]
        
        # 否则进行字符串替换
        def replacer(match):
            var_name = match.group(1)
            if var_name not in self._variables:
                raise ValueError(f"Variable '{var_name}' not defined")
            return str(self._variables[var_name])
        
        return VAR_PATTERN.sub(replacer, template)
    
    def get_eval_namespace(self) -> dict[str, Any]:
        """获取表达式求值命名空间（用于 when 条件）"""
        ns = dict(self._variables)
        for step_id, result in self._results.items():
            ns[step_id] = result
        return ns
```

### 3.3.6 engine/reporter.py — 报告生成器

报告生成器将执行结果格式化为标准 JSON 报告：

```python
"""Pipeline Reporter"""
from __future__ import annotations

import json
from datetime import datetime
from geopipe_agent.models.pipeline import PipelineDefinition
from geopipe_agent.models.result import StepResult
from geopipe_agent.models.qc import QcIssue


class PipelineReporter:
    """流水线报告生成器"""
    
    def generate(
        self,
        pipeline: PipelineDefinition,
        results: list[StepResult],
        started_at: datetime,
        finished_at: datetime,
    ) -> dict:
        """
        生成完整的 JSON 报告。
        
        报告结构：
        - pipeline: 流水线名称
        - description: 描述
        - status: success / failed
        - timing: 开始/结束/耗时
        - steps: 各步骤详情
        - qc_issues: 所有 QC 问题
        - qc_summary: QC 汇总
        - outputs: 声明的输出
        """
        # 收集 QC 问题
        all_qc_issues = self._collect_qc_issues(results)
        
        # 统计
        passed = sum(1 for r in results if r.status == "success")
        failed = sum(1 for r in results if r.status == "error")
        skipped = sum(1 for r in results if r.status == "skipped")
        
        overall_status = "success" if failed == 0 else "failed"
        
        return {
            "pipeline": pipeline.name,
            "description": pipeline.description,
            "status": overall_status,
            "started_at": started_at.isoformat() + "Z",
            "finished_at": finished_at.isoformat() + "Z",
            "duration_seconds": round(
                (finished_at - started_at).total_seconds(), 3
            ),
            "total_steps": len(results),
            "passed_steps": passed,
            "failed_steps": failed,
            "skipped_steps": skipped,
            "variables": pipeline.variables,
            "steps": [self._format_step(r) for r in results],
            "qc_issues": [self._format_qc_issue(q) for q in all_qc_issues],
            "qc_summary": {
                "total_issues": len(all_qc_issues),
                "errors": sum(
                    1 for q in all_qc_issues if q.severity == "error"
                ),
                "warnings": sum(
                    1 for q in all_qc_issues if q.severity == "warning"
                ),
            },
            "outputs": self._format_outputs(pipeline, results),
        }
    
    def _format_step(self, result: StepResult) -> dict:
        """格式化单个步骤结果"""
        step_info = {
            "id": result.id,
            "use": result.use,
            "status": result.status,
            "duration_seconds": round(result.duration_seconds, 3),
        }
        
        if result.status == "success":
            step_info["output_type"] = type(result.output).__name__
            step_info["stats"] = result.stats
        elif result.status == "error":
            step_info["error"] = result.error
        elif result.status == "skipped":
            step_info["reason"] = result.reason
        
        return step_info
    
    def _collect_qc_issues(self, results: list[StepResult]) -> list[QcIssue]:
        """从所有步骤结果中收集 QC 问题"""
        issues = []
        for result in results:
            if result.status == "success" and hasattr(result.output, "qc_issues"):
                for issue in result.output.qc_issues:
                    issue.step_id = result.id
                    issues.append(issue)
        return issues
```

```python
"""Step Registry with @step decorator"""
from __future__ import annotations

from typing import Any, Callable
from dataclasses import dataclass, field

# 全局步骤注册表
_REGISTRY: dict[str, StepInfo] = {}


@dataclass
class StepInfo:
    """步骤元信息"""
    name: str
    description: str
    func: Callable
    params: dict[str, dict[str, Any]]
    output_type: str
    tags: list[str] = field(default_factory=list)
    backends: list[str] = field(default_factory=lambda: ["native_python"])


def step(
    name: str,
    description: str,
    params: dict[str, dict[str, Any]],
    output_type: str = "any",
    tags: list[str] | None = None,
    backends: list[str] | None = None,
) -> Callable:
    """
    步骤注册装饰器。
    
    Usage:
        @step(
            name="vector.buffer",
            description="创建缓冲区",
            params={"input": {"type": "geodataframe", "required": True}, ...},
            output_type="geodataframe",
            tags=["vector", "geometry"],
        )
        def buffer(input, distance, **kwargs):
            return input.buffer(distance)
    """
    def decorator(func: Callable) -> Callable:
        info = StepInfo(
            name=name,
            description=description,
            func=func,
            params=params,
            output_type=output_type,
            tags=tags or [],
            backends=backends or ["native_python"],
        )
        _REGISTRY[name] = info
        return func
    
    return decorator


def get_step(name: str) -> Callable | None:
    """获取步骤执行函数"""
    info = _REGISTRY.get(name)
    return info.func if info else None


def get_step_info(name: str) -> StepInfo | None:
    """获取步骤元信息"""
    return _REGISTRY.get(name)


def list_steps(category: str | None = None) -> list[StepInfo]:
    """列出所有注册步骤"""
    steps = list(_REGISTRY.values())
    if category:
        steps = [s for s in steps if s.name.startswith(f"{category}.")]
    return sorted(steps, key=lambda s: s.name)
```

### 3.3.11 utils/safe_eval.py — 安全表达式求值

```python
"""AST-based Safe Expression Evaluation"""
from __future__ import annotations

import ast
import operator
from typing import Any

# 允许的操作符
ALLOWED_OPS = {
    ast.Add: operator.add,
    ast.Sub: operator.sub,
    ast.Mult: operator.mul,
    ast.Div: operator.truediv,
    ast.FloorDiv: operator.floordiv,
    ast.Mod: operator.mod,
    ast.Pow: operator.pow,
    ast.Eq: operator.eq,
    ast.NotEq: operator.ne,
    ast.Lt: operator.lt,
    ast.LtE: operator.le,
    ast.Gt: operator.gt,
    ast.GtE: operator.ge,
    ast.And: lambda a, b: a and b,
    ast.Or: lambda a, b: a or b,
    ast.Not: operator.not_,
    ast.USub: operator.neg,
    ast.In: lambda a, b: a in b,
    ast.NotIn: lambda a, b: a not in b,
}

# 允许的内置函数
ALLOWED_BUILTINS = {
    "len": len,
    "min": min,
    "max": max,
    "sum": sum,
    "abs": abs,
    "round": round,
    "int": int,
    "float": float,
    "str": str,
    "bool": bool,
}


def safe_eval(expression: str, namespace: dict[str, Any]) -> Any:
    """
    安全地求值表达式。
    
    使用 AST 解析限制可执行的操作，防止代码注入。
    
    Args:
        expression: 表达式字符串
        namespace: 变量命名空间
    
    Returns:
        表达式求值结果
    
    Raises:
        ValueError: 表达式包含不允许的操作
    """
    tree = ast.parse(expression, mode="eval")
    return _eval_node(tree.body, namespace)


def _eval_node(node: ast.AST, ns: dict[str, Any]) -> Any:
    """递归求值 AST 节点"""
    match node:
        case ast.Constant(value=value):
            return value
        
        case ast.Name(id=name):
            if name in ns:
                return ns[name]
            if name in ALLOWED_BUILTINS:
                return ALLOWED_BUILTINS[name]
            raise ValueError(f"Undefined name: '{name}'")
        
        case ast.BinOp(left=left, op=op, right=right):
            op_func = ALLOWED_OPS.get(type(op))
            if op_func is None:
                raise ValueError(f"Operator not allowed: {type(op).__name__}")
            return op_func(_eval_node(left, ns), _eval_node(right, ns))
        
        case ast.Compare(left=left, ops=ops, comparators=comps):
            result = _eval_node(left, ns)
            for op, comp in zip(ops, comps):
                op_func = ALLOWED_OPS.get(type(op))
                if op_func is None:
                    raise ValueError(
                        f"Comparison not allowed: {type(op).__name__}"
                    )
                comp_val = _eval_node(comp, ns)
                if not op_func(result, comp_val):
                    return False
                result = comp_val
            return True
        
        case ast.BoolOp(op=op, values=values):
            op_func = ALLOWED_OPS[type(op)]
            result = _eval_node(values[0], ns)
            for value in values[1:]:
                result = op_func(result, _eval_node(value, ns))
            return result
        
        case ast.UnaryOp(op=op, operand=operand):
            op_func = ALLOWED_OPS.get(type(op))
            if op_func is None:
                raise ValueError(
                    f"Unary operator not allowed: {type(op).__name__}"
                )
            return op_func(_eval_node(operand, ns))
        
        case ast.Attribute(value=value, attr=attr):
            obj = _eval_node(value, ns)
            return getattr(obj, attr)
        
        case ast.Call(func=func, args=args, keywords=keywords):
            func_obj = _eval_node(func, ns)
            if func_obj not in ALLOWED_BUILTINS.values():
                raise ValueError(f"Function call not allowed: {func_obj}")
            eval_args = [_eval_node(a, ns) for a in args]
            eval_kwargs = {
                kw.arg: _eval_node(kw.value, ns) for kw in keywords
            }
            return func_obj(*eval_args, **eval_kwargs)
        
        case _:
            raise ValueError(
                f"AST node type not allowed: {type(node).__name__}"
            )
```

```python
    level: str | None = None,
    format_type: str | None = None,
    log_file: str | None = None,
) -> None:
    """
    初始化日志配置。
    
    Args:
        level: 日志级别（默认从环境变量 GEOPIPE_LOG_LEVEL 读取）
        format_type: 格式类型 "text" 或 "json"
        log_file: 日志文件路径
    """
    level = level or os.environ.get("GEOPIPE_LOG_LEVEL", "INFO")
    format_type = format_type or os.environ.get("GEOPIPE_LOG_FORMAT", "text")
    log_file = log_file or os.environ.get("GEOPIPE_LOG_FILE")
    
    # 创建 handler
    handlers: list[logging.Handler] = []
    
    if log_file:
        file_handler = logging.FileHandler(log_file, encoding="utf-8")
        handlers.append(file_handler)
    else:
        stream_handler = logging.StreamHandler(sys.stderr)
        handlers.append(stream_handler)
    
    # 选择 formatter
    if format_type == "json":
        formatter = JsonFormatter()
    else:
        formatter = logging.Formatter(
            fmt="%(asctime)s [%(levelname)s] %(name)s: %(message)s",
            datefmt="%Y-%m-%d %H:%M:%S",
        )
    
    for handler in handlers:
        handler.setFormatter(formatter)
    
    # 配置 root logger
    root_logger = logging.getLogger("geopipe_agent")
    root_logger.setLevel(getattr(logging, level.upper()))
    root_logger.handlers = handlers


class JsonFormatter(logging.Formatter):
    """JSON 格式日志输出"""
    
    def format(self, record: logging.LogRecord) -> str:
        log_data = {
            "timestamp": self.formatTime(record),
            "level": record.levelname,
            "logger": record.name,
            "message": record.getMessage(),
        }
        if record.exc_info:
            log_data["exception"] = self.formatException(record.exc_info)
        return json.dumps(log_data, ensure_ascii=False)
```

```python
"""AI Skill Document Generator"""
from __future__ import annotations

from geopipe_agent.steps.registry import list_steps, StepInfo


class SkillGenerator:
    """AI Skill 文档生成器"""
    
    def generate_markdown(self) -> str:
        """生成 Markdown 格式的 Skill 文档"""
        lines = ["# GeoPipeAgent Skills\n"]
        
        # 按类别分组
        categories: dict[str, list[StepInfo]] = {}
        for step_info in list_steps():
            cat = step_info.name.split(".")[0]
            categories.setdefault(cat, []).append(step_info)
        
        for cat, steps in sorted(categories.items()):
            lines.append(f"\n## {cat.upper()} Steps\n")
            for step_info in steps:
                lines.extend(self._format_step_markdown(step_info))
        
        return "\n".join(lines)
    
    def _format_step_markdown(self, info: StepInfo) -> list[str]:
        """格式化单个步骤的 Markdown"""
        lines = [
            f"\n### {info.name}\n",
            f"**Description:** {info.description}\n",
            f"**Output:** {info.output_type}\n",
            "**Parameters:**\n",
        ]
        
        for pname, pinfo in info.params.items():
            req = "required" if pinfo.get("required") else "optional"
            ptype = pinfo.get("type", "any")
            desc = pinfo.get("description", "")
            default = pinfo.get("default")
            line = f"- `{pname}` ({ptype}, {req})"
            if default is not None:
                line += f", default={default}"
            line += f": {desc}"
            lines.append(line)
        
        lines.append(f"\n**Tags:** {', '.join(info.tags)}\n")
        
        return lines
```

## 3.6 本章小结

本章深入分析了 GeoPipeAgent 的核心架构：

1. **四阶段模型**：Parse → Validate → Execute → Report，每个阶段职责明确
2. **五层架构**：CLI → Engine → Step → Backend → Model（+ Utils），层间依赖单向
3. **Engine 核心模块**：parser、validator、executor、context、reporter 各司其职
4. **Model 层**：PipelineDefinition、StepResult（含 __getattr__）、QcIssue
5. **Step 注册**：@step 装饰器 + 全局注册表，轻松扩展
6. **安全求值**：基于 AST 的 safe_eval，限制可执行操作
7. **数据流**：从 YAML 到 JSON 的完整链路清晰可追踪
8. **模块依赖**：上层依赖下层，基础层无依赖，结构清晰
