# 第11章：高级空间分析步骤

> 本章详细介绍 GeoPipeAgent 的四个高级空间分析步骤：聚类分析、热力图生成、空间插值和泰森多边形，帮助用户进行深层次的空间数据挖掘与分析。

---

## 11.1 analysis.cluster——聚类分析

### 11.1.1 功能概述

`analysis.cluster` 步骤对点要素进行空间聚类分析，支持 K-Means 和 DBSCAN 两种算法，基于 scikit-learn 实现。聚类结果以新列（`cluster_id`）的形式附加到输出 GeoDataFrame 中。

### 11.1.2 参数详解

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | geodataframe | ✅ | — | 输入点要素数据 |
| `n_clusters` | number | ❌ | 5 | 聚类数量（K-Means 时必须） |
| `algorithm` | string | ❌ | `kmeans` | 算法：`kmeans` 或 `dbscan` |
| `eps` | number | ❌ | 0.5 | DBSCAN 邻域半径 |
| `min_samples` | number | ❌ | 5 | DBSCAN 最小样本数 |
| `columns` | list | ❌ | — | 参与聚类的属性列（不指定则用坐标） |

### 11.1.3 输出说明

| 输出 | 类型 | 说明 |
|------|------|------|
| `output` | geodataframe | 包含 `cluster_id` 列的结果 |
| `stats` | dict | `n_clusters`、`silhouette_score` 等 |

### 11.1.4 使用示例

**K-Means 聚类：**

```yaml
pipeline:
  name: "POI聚类分析"
  steps:
    - id: load-poi
      use: io.read_vector
      params:
        path: "data/poi_points.geojson"

    - id: cluster
      use: analysis.cluster
      params:
        input: "$load-poi"
        n_clusters: 8
        algorithm: "kmeans"

    - id: save
      use: io.write_vector
      params:
        input: "$cluster.output"
        path: "output/poi_clustered.geojson"
```

**DBSCAN 聚类：**

```yaml
    - id: cluster-dbscan
      use: analysis.cluster
      params:
        input: "$load-poi"
        algorithm: "dbscan"
        eps: 0.01
        min_samples: 10
```

### 11.1.5 算法选择指南

| 特征 | K-Means | DBSCAN |
|------|---------|--------|
| 需要指定聚类数 | 是 | 否 |
| 能发现任意形状的簇 | 否 | 是 |
| 能识别噪声点 | 否 | 是（标记为 -1） |
| 适用场景 | 数据分布均匀 | 数据密度不均 |
| 计算复杂度 | O(n·k·i) | O(n²) |

### 11.1.6 多属性聚类

当指定 `columns` 参数时，聚类将基于指定的属性列而非空间坐标：

```yaml
    - id: attr-cluster
      use: analysis.cluster
      params:
        input: "$load-poi"
        n_clusters: 5
        columns: ["population", "gdp", "area"]
```

## 11.2 analysis.heatmap——热力图生成

### 11.2.1 功能概述

`analysis.heatmap` 步骤使用核密度估计（KDE）算法将离散点数据转换为连续密度栅格，常用于可视化事件分布密度（如犯罪热点、人口密度等）。

### 11.2.2 参数详解

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | geodataframe | ✅ | — | 输入点要素数据 |
| `bandwidth` | number | ❌ | 自动 | 核密度带宽（影响平滑程度） |
| `resolution` | number | ❌ | 100 | 输出栅格分辨率（像素数） |
| `weight_field` | string | ❌ | — | 权重字段名 |
| `kernel` | string | ❌ | `gaussian` | 核函数类型 |

### 11.2.3 输出说明

| 输出 | 类型 | 说明 |
|------|------|------|
| `output` | raster | 密度栅格数据 |
| `stats` | dict | `min_density`、`max_density`、`mean_density` |

### 11.2.4 使用示例

```yaml
pipeline:
  name: "犯罪热力图"
  steps:
    - id: load-crimes
      use: io.read_vector
      params:
        path: "data/crime_incidents.geojson"

    - id: heatmap
      use: analysis.heatmap
      params:
        input: "$load-crimes"
        bandwidth: 500
        resolution: 200

    - id: save-heatmap
      use: io.write_raster
      params:
        input: "$heatmap.output"
        path: "output/crime_heatmap.tif"
```

**加权热力图：**

```yaml
    - id: weighted-heat
      use: analysis.heatmap
      params:
        input: "$load-data"
        weight_field: "severity"
        bandwidth: 300
```

### 11.2.5 带宽选择

带宽是热力图最关键的参数：

- **小带宽**：细节丰富但可能产生噪声
- **大带宽**：平滑但可能丢失局部特征
- **自动选择**：不指定时使用 Scott's Rule 或 Silverman's Rule

## 11.3 analysis.interpolate——空间插值

### 11.3.1 功能概述

`analysis.interpolate` 步骤从离散采样点推算连续表面，支持多种插值方法。常用于从气象站点数据生成气温、降水等连续面。

### 11.3.2 参数详解

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | geodataframe | ✅ | — | 输入采样点数据 |
| `value_field` | string | ✅ | — | 用于插值的数值字段 |
| `method` | string | ❌ | `idw` | 插值方法 |
| `resolution` | number | ❌ | 100 | 输出栅格分辨率 |
| `power` | number | ❌ | 2 | IDW 权重指数 |
| `bounds` | list | ❌ | 自动 | 输出范围 [xmin, ymin, xmax, ymax] |

### 11.3.3 支持的插值方法

| 方法 | 说明 | 适用场景 |
|------|------|----------|
| `idw` | 反距离加权 | 通用，采样均匀时 |
| `linear` | 线性插值 | 变化平缓的数据 |
| `cubic` | 三次样条插值 | 需要平滑表面 |
| `nearest` | 最近邻插值 | 分类数据 |

### 11.3.4 使用示例

```yaml
pipeline:
  name: "气温插值分析"
  steps:
    - id: load-stations
      use: io.read_vector
      params:
        path: "data/weather_stations.geojson"

    - id: interpolate
      use: analysis.interpolate
      params:
        input: "$load-stations"
        value_field: "temperature"
        method: "idw"
        resolution: 200
        power: 2

    - id: contours
      use: raster.contour
      params:
        input: "$interpolate.output"
        interval: 2
        field_name: "temp"

    - id: save-surface
      use: io.write_raster
      params:
        input: "$interpolate.output"
        path: "output/temperature_surface.tif"

    - id: save-contours
      use: io.write_vector
      params:
        input: "$contours.output"
        path: "output/temp_contours.geojson"
```

### 11.3.5 IDW 权重指数的影响

| power 值 | 效果 |
|-----------|------|
| 1 | 距离影响较小，表面更平滑 |
| 2 | 标准权重，平衡局部和全局 |
| 3+ | 距离影响增大，局部特征更明显 |

## 11.4 analysis.voronoi——泰森多边形

### 11.4.1 功能概述

`analysis.voronoi` 步骤根据输入点生成泰森多边形（Voronoi 图），将平面划分为与每个点最近的区域。广泛用于服务区划分、降水分配等场景。

### 11.4.2 参数详解

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `input` | geodataframe | ✅ | — | 输入点要素 |
| `boundary` | geodataframe | ❌ | — | 裁剪边界（可选） |

### 11.4.3 使用示例

```yaml
pipeline:
  name: "气象站泰森多边形"
  steps:
    - id: load-stations
      use: io.read_vector
      params:
        path: "data/weather_stations.geojson"

    - id: load-boundary
      use: io.read_vector
      params:
        path: "data/study_area.geojson"

    - id: voronoi
      use: analysis.voronoi
      params:
        input: "$load-stations"
        boundary: "$load-boundary"

    - id: save
      use: io.write_vector
      params:
        input: "$voronoi.output"
        path: "output/voronoi_polygons.geojson"
```

### 11.4.4 应用场景

- **气象分析**：将气象站数据按泰森多边形分配降水量到子区域
- **服务区划分**：确定每个设施（学校、医院）的最近服务区域
- **市场分析**：划分零售店的最近服务范围

## 11.5 组合分析案例

### 11.5.1 综合空间分析流水线

```yaml
pipeline:
  name: "综合空间分析"
  description: "对商业网点进行聚类、密度分析和服务区划分"

  steps:
    - id: load-shops
      use: io.read_vector
      params:
        path: "data/shops.geojson"

    - id: load-boundary
      use: io.read_vector
      params:
        path: "data/city_boundary.geojson"

    - id: cluster
      use: analysis.cluster
      params:
        input: "$load-shops"
        n_clusters: 10
        algorithm: "kmeans"

    - id: heatmap
      use: analysis.heatmap
      params:
        input: "$load-shops"
        bandwidth: 1000
        resolution: 300

    - id: voronoi
      use: analysis.voronoi
      params:
        input: "$load-shops"
        boundary: "$load-boundary"

    - id: interpolate-revenue
      use: analysis.interpolate
      params:
        input: "$load-shops"
        value_field: "annual_revenue"
        method: "idw"
        resolution: 200

    - id: save-clusters
      use: io.write_vector
      params:
        input: "$cluster.output"
        path: "output/shop_clusters.geojson"

    - id: save-heatmap
      use: io.write_raster
      params:
        input: "$heatmap.output"
        path: "output/shop_density.tif"

    - id: save-voronoi
      use: io.write_vector
      params:
        input: "$voronoi.output"
        path: "output/shop_service_areas.geojson"

    - id: save-revenue
      use: io.write_raster
      params:
        input: "$interpolate-revenue.output"
        path: "output/revenue_surface.tif"

  outputs:
    clusters: "$save-clusters.output"
    density: "$save-heatmap.output"
    service_areas: "$save-voronoi.output"
    revenue_map: "$save-revenue.output"
```

## 11.6 性能与注意事项

### 11.6.1 大数据量处理建议

| 步骤 | 建议 |
|------|------|
| `analysis.cluster` | 数据量 > 10万时考虑 MiniBatch K-Means |
| `analysis.heatmap` | 降低 resolution 或先做空间采样 |
| `analysis.interpolate` | 控制 resolution 和输出范围 |
| `analysis.voronoi` | 点数 > 100万时计算较慢 |

### 11.6.2 坐标系统注意

- 聚类分析和插值建议使用**投影坐标系**（如 EPSG:3857），避免经纬度坐标导致的距离失真
- 在分析前使用 `vector.reproject` 统一坐标系

### 11.6.3 依赖要求

高级分析步骤需要额外依赖：

```bash
pip install -e ".[analysis]"
# 安装 scikit-learn, scipy 等
```

## 11.7 本章小结

本章介绍了四种高级空间分析步骤：

| 步骤 | 功能 | 输出类型 |
|------|------|----------|
| `analysis.cluster` | 空间/属性聚类 | 矢量（含 cluster_id） |
| `analysis.heatmap` | 核密度估计 | 栅格 |
| `analysis.interpolate` | 空间插值 | 栅格 |
| `analysis.voronoi` | 泰森多边形 | 矢量 |

这些步骤可以灵活组合，实现从数据探索到空间建模的完整分析流程。下一章将介绍网络分析步骤。
