# 第10章：命令行工具详解

## 10.1 概述

GDAL 提供了丰富的命令行工具，这些工具可以独立使用，无需编写代码即可完成常见的地理空间数据处理任务。

### 10.1.1 工具分类

| 类别 | 工具名 | 功能 |
|-----|-------|------|
| **栅格信息** | gdalinfo | 显示栅格数据信息 |
| **栅格转换** | gdal_translate | 格式转换、裁剪、重采样 |
| **栅格投影** | gdalwarp | 重投影、镶嵌、裁剪 |
| **栅格金字塔** | gdaladdo | 创建/删除金字塔 |
| **栅格镶嵌** | gdal_merge.py | 镶嵌多个栅格 |
| **矢量信息** | ogrinfo | 显示矢量数据信息 |
| **矢量转换** | ogr2ogr | 格式转换、投影、过滤 |
| **地形分析** | gdaldem | 坡度、坡向、山体阴影 |
| **等值线** | gdal_contour | 生成等值线 |
| **网格化** | gdal_grid | 点数据网格化 |
| **栅格计算** | gdal_calc.py | 波段运算 |
| **VRT** | gdalbuildvrt | 创建虚拟数据集 |

## 10.2 栅格工具

### 10.2.1 gdalinfo - 栅格信息查看

```bash
# 基本用法
gdalinfo input.tif

# 显示详细元数据
gdalinfo -mm input.tif      # 显示最小最大值
gdalinfo -stats input.tif   # 计算统计信息
gdalinfo -hist input.tif    # 计算直方图

# JSON 格式输出
gdalinfo -json input.tif > info.json

# 仅显示特定信息
gdalinfo -noct input.tif    # 不显示颜色表
gdalinfo -nomd input.tif    # 不显示元数据
gdalinfo -nofl input.tif    # 不显示文件列表

# 检查特定波段
gdalinfo -sd 1 input.hdf    # 子数据集1

# 显示支持的格式
gdalinfo --formats
```

### 10.2.2 gdal_translate - 格式转换

```bash
# 基本格式转换
gdal_translate -of PNG input.tif output.png
gdal_translate -of JPEG input.tif output.jpg

# 压缩 GeoTIFF
gdal_translate -co COMPRESS=LZW input.tif output.tif
gdal_translate -co COMPRESS=DEFLATE -co PREDICTOR=2 input.tif output.tif
gdal_translate -co COMPRESS=JPEG -co JPEG_QUALITY=90 input.tif output.tif

# 创建分块 GeoTIFF
gdal_translate -co TILED=YES -co BLOCKXSIZE=256 -co BLOCKYSIZE=256 input.tif tiled.tif

# 创建 Cloud Optimized GeoTIFF (COG)
gdal_translate -of COG -co COMPRESS=LZW input.tif output_cog.tif

# 更改数据类型
gdal_translate -ot Byte -scale input.tif output.tif
gdal_translate -ot Float32 input.tif output.tif

# 裁剪（按像素坐标）
gdal_translate -srcwin 0 0 500 500 input.tif clipped.tif

# 裁剪（按地理坐标）
gdal_translate -projwin 116 40 117 39 input.tif clipped.tif

# 选择波段
gdal_translate -b 1 -b 2 -b 3 input.tif rgb.tif
gdal_translate -b 4 -b 3 -b 2 input.tif false_color.tif

# 重采样
gdal_translate -outsize 50% 50% input.tif smaller.tif
gdal_translate -outsize 1000 1000 input.tif resized.tif

# 添加 Alpha 通道
gdal_translate -b 1 -b 2 -b 3 -b mask -a_nodata 0 input.tif output.tif

# 设置无效值
gdal_translate -a_nodata -9999 input.tif output.tif

# 设置空间参考
gdal_translate -a_srs EPSG:4326 input.tif output.tif

# 设置地理变换
gdal_translate -a_ullr 116 40 117 39 input.tif output.tif
```

### 10.2.3 gdalwarp - 投影变换

```bash
# 基本重投影
gdalwarp -t_srs EPSG:3857 input.tif output.tif
gdalwarp -s_srs EPSG:4326 -t_srs EPSG:32650 input.tif output.tif

# 指定重采样方法
gdalwarp -r near input.tif output.tif      # 最近邻（默认）
gdalwarp -r bilinear input.tif output.tif  # 双线性
gdalwarp -r cubic input.tif output.tif     # 三次卷积
gdalwarp -r cubicspline input.tif output.tif
gdalwarp -r lanczos input.tif output.tif   # Lanczos
gdalwarp -r average input.tif output.tif   # 平均值
gdalwarp -r mode input.tif output.tif      # 众数（分类数据）

# 指定输出分辨率
gdalwarp -tr 0.001 0.001 input.tif output.tif   # 指定像素大小
gdalwarp -ts 1000 1000 input.tif output.tif     # 指定输出尺寸

# 裁剪到边界
gdalwarp -te 116 39 117 40 input.tif output.tif

# 使用矢量边界裁剪
gdalwarp -cutline boundary.shp -crop_to_cutline input.tif output.tif
gdalwarp -cutline boundary.shp -cwhere "name='北京'" input.tif output.tif

# 设置无效值
gdalwarp -dstnodata -9999 input.tif output.tif
gdalwarp -srcnodata 0 -dstnodata -9999 input.tif output.tif

# 镶嵌多个文件
gdalwarp tile1.tif tile2.tif tile3.tif mosaic.tif

# 多线程处理
gdalwarp -multi -wo NUM_THREADS=ALL_CPUS input.tif output.tif

# 压缩输出
gdalwarp -co COMPRESS=LZW -co TILED=YES input.tif output.tif

# 处理大文件
gdalwarp -wm 500 -multi input.tif output.tif  # 500MB 内存
```

### 10.2.4 gdaladdo - 金字塔管理

```bash
# 创建金字塔（默认级别）
gdaladdo input.tif

# 指定级别
gdaladdo input.tif 2 4 8 16 32

# 指定重采样方法
gdaladdo -r average input.tif 2 4 8 16
gdaladdo -r nearest input.tif 2 4 8 16   # 分类数据
gdaladdo -r gauss input.tif 2 4 8 16

# 内部金字塔（默认）
gdaladdo input.tif

# 外部金字塔（.ovr 文件）
gdaladdo -ro input.tif 2 4 8 16

# 清除金字塔
gdaladdo -clean input.tif

# 压缩金字塔
gdaladdo --config COMPRESS_OVERVIEW LZW input.tif 2 4 8 16
```

### 10.2.5 gdal_merge.py - 镶嵌

```bash
# 基本镶嵌
gdal_merge.py -o mosaic.tif tile1.tif tile2.tif tile3.tif

# 使用文件列表
gdal_merge.py -o mosaic.tif --optfile file_list.txt

# 设置无效值
gdal_merge.py -n -9999 -a_nodata -9999 -o mosaic.tif *.tif

# 压缩输出
gdal_merge.py -co COMPRESS=LZW -o mosaic.tif *.tif

# 指定输出类型
gdal_merge.py -ot Float32 -o mosaic.tif *.tif

# 创建分离波段的影像
gdal_merge.py -separate -o stacked.tif band1.tif band2.tif band3.tif
```

### 10.2.6 gdalbuildvrt - 虚拟数据集

```bash
# 基本 VRT
gdalbuildvrt mosaic.vrt tile1.tif tile2.tif tile3.tif

# 从文件列表创建
gdalbuildvrt -input_file_list file_list.txt mosaic.vrt

# 设置无效值
gdalbuildvrt -srcnodata -9999 -vrtnodata -9999 mosaic.vrt *.tif

# 波段堆叠
gdalbuildvrt -separate stacked.vrt band1.tif band2.tif band3.tif

# 设置分辨率
gdalbuildvrt -resolution average mosaic.vrt *.tif
gdalbuildvrt -resolution highest mosaic.vrt *.tif

# 允许不同投影
gdalbuildvrt -allow_projection_difference mosaic.vrt *.tif
```

### 10.2.7 gdaldem - 地形分析

```bash
# 坡度（度）
gdaldem slope dem.tif slope.tif

# 坡度（百分比）
gdaldem slope -p dem.tif slope_percent.tif

# 坡向
gdaldem aspect dem.tif aspect.tif

# 山体阴影
gdaldem hillshade dem.tif hillshade.tif
gdaldem hillshade -z 2 -az 315 -alt 45 dem.tif hillshade.tif

# 彩色地形图
gdaldem color-relief dem.tif color_table.txt colormap.tif

# 地形粗糙度指数 (TRI)
gdaldem TRI dem.tif tri.tif

# 地形位置指数 (TPI)
gdaldem TPI dem.tif tpi.tif

# 地形粗糙度
gdaldem roughness dem.tif roughness.tif
```

**颜色表文件格式 (color_table.txt)：**

```
0 0 0 255          # 海平面：蓝色
100 0 128 0        # 100m：深绿
500 0 255 0        # 500m：绿色
1000 255 255 0     # 1000m：黄色
2000 255 128 0     # 2000m：橙色
4000 255 0 0       # 4000m：红色
8000 255 255 255   # 8000m：白色
```

### 10.2.8 gdal_contour - 等值线

```bash
# 基本等值线
gdal_contour -i 100 dem.tif contours.shp

# 指定高程字段名
gdal_contour -a elevation -i 100 dem.tif contours.shp

# 固定高程值
gdal_contour -fl 100 200 300 400 500 dem.tif contours.shp

# 输出为 GeoJSON
gdal_contour -f GeoJSON -i 100 dem.tif contours.geojson

# 3D 等值线
gdal_contour -i 100 -3d dem.tif contours3d.shp

# 忽略无效值
gdal_contour -inodata -i 100 dem.tif contours.shp
```

### 10.2.9 gdal_calc.py - 栅格计算

```bash
# NDVI 计算
gdal_calc.py -A nir.tif -B red.tif --outfile=ndvi.tif --calc="(A-B)/(A+B)"

# 条件运算
gdal_calc.py -A input.tif --outfile=output.tif --calc="A*(A>0)"

# 多波段运算
gdal_calc.py -A input.tif --A_band=1 -B input.tif --B_band=2 \
    --outfile=output.tif --calc="A+B"

# 类型转换
gdal_calc.py -A input.tif --outfile=output.tif --type=Float32 --calc="A"

# 设置无效值
gdal_calc.py -A input.tif --outfile=output.tif --NoDataValue=-9999 --calc="A"

# 复杂表达式
gdal_calc.py -A dem.tif --outfile=class.tif \
    --calc="(A<100)*1 + (A>=100)*(A<500)*2 + (A>=500)*3"
```

## 10.3 矢量工具

### 10.3.1 ogrinfo - 矢量信息

```bash
# 显示数据源信息
ogrinfo data.shp

# 显示图层详细信息
ogrinfo -al data.shp

# 仅显示摘要
ogrinfo -so data.shp layer_name

# SQL 查询
ogrinfo data.shp -sql "SELECT * FROM layer WHERE population > 1000000"

# 空间查询
ogrinfo data.shp -spat 116 39 117 40

# 显示支持的格式
ogrinfo --formats

# GeoJSON 输出
ogrinfo -json data.shp layer_name
```

### 10.3.2 ogr2ogr - 矢量转换

```bash
# 基本格式转换
ogr2ogr output.geojson input.shp
ogr2ogr -f "ESRI Shapefile" output.shp input.geojson
ogr2ogr -f "GPKG" output.gpkg input.shp

# 重投影
ogr2ogr -t_srs EPSG:3857 output.shp input.shp
ogr2ogr -s_srs EPSG:4326 -t_srs EPSG:32650 output.shp input.shp

# 属性过滤
ogr2ogr -where "population > 1000000" output.shp input.shp

# 空间过滤
ogr2ogr -spat 116 39 117 40 output.shp input.shp
ogr2ogr -clipdst 116 39 117 40 output.shp input.shp

# 使用裁剪矢量
ogr2ogr -clipsrc boundary.shp output.shp input.shp

# SQL 查询
ogr2ogr -sql "SELECT name, population FROM cities WHERE population > 1000000" \
    output.shp input.shp

# 选择字段
ogr2ogr -select "name,population" output.shp input.shp

# 重命名图层
ogr2ogr -nln new_layer_name output.shp input.shp

# 追加到现有文件
ogr2ogr -append output.shp input.shp

# 更新现有文件
ogr2ogr -update output.shp input.shp

# 覆盖现有文件
ogr2ogr -overwrite output.gpkg input.shp

# 设置编码
ogr2ogr -lco ENCODING=UTF-8 output.shp input.shp

# 简化几何
ogr2ogr -simplify 0.001 output.shp input.shp

# 分割多部分几何
ogr2ogr -explodecollections output.shp input.shp

# 转换几何类型
ogr2ogr -nlt POINT output.shp input.shp

# 写入 PostGIS
ogr2ogr -f PostgreSQL PG:"host=localhost dbname=gisdb user=postgres" input.shp

# 从 PostGIS 导出
ogr2ogr output.shp PG:"host=localhost dbname=gisdb" -sql "SELECT * FROM table"
```

### 10.3.3 常用格式转换

```bash
# Shapefile → GeoJSON
ogr2ogr -f GeoJSON output.geojson input.shp

# Shapefile → GeoPackage
ogr2ogr -f GPKG output.gpkg input.shp

# GeoJSON → Shapefile
ogr2ogr -f "ESRI Shapefile" output.shp input.geojson

# KML → Shapefile
ogr2ogr -f "ESRI Shapefile" output.shp input.kml

# CSV → GeoJSON (带坐标)
ogr2ogr -f GeoJSON output.geojson input.csv \
    -oo X_POSSIBLE_NAMES=lon -oo Y_POSSIBLE_NAMES=lat

# GeoPackage → PostGIS
ogr2ogr -f PostgreSQL PG:"host=localhost dbname=gisdb" input.gpkg

# PostGIS → GeoPackage
ogr2ogr -f GPKG output.gpkg PG:"host=localhost dbname=gisdb"
```

## 10.4 实用脚本示例

### 10.4.1 批量格式转换

```bash
#!/bin/bash
# 批量将 Shapefile 转换为 GeoJSON

INPUT_DIR="./input"
OUTPUT_DIR="./output"

mkdir -p "$OUTPUT_DIR"

for shp in "$INPUT_DIR"/*.shp; do
    filename=$(basename "$shp" .shp)
    echo "转换: $filename"
    ogr2ogr -f GeoJSON "$OUTPUT_DIR/$filename.geojson" "$shp"
done

echo "转换完成"
```

### 10.4.2 批量重投影

```bash
#!/bin/bash
# 批量重投影栅格文件

INPUT_DIR="./input"
OUTPUT_DIR="./output"
TARGET_SRS="EPSG:3857"

mkdir -p "$OUTPUT_DIR"

for tif in "$INPUT_DIR"/*.tif; do
    filename=$(basename "$tif")
    echo "重投影: $filename"
    gdalwarp -t_srs "$TARGET_SRS" -co COMPRESS=LZW \
        "$tif" "$OUTPUT_DIR/$filename"
done

echo "完成"
```

### 10.4.3 创建金字塔

```bash
#!/bin/bash
# 为所有 GeoTIFF 创建金字塔

for tif in *.tif; do
    echo "处理: $tif"
    gdaladdo -r average "$tif" 2 4 8 16 32
done
```

### 10.4.4 生成缩略图

```bash
#!/bin/bash
# 生成缩略图

INPUT="$1"
OUTPUT="thumbnail.png"
SIZE=256

gdal_translate -of PNG -outsize $SIZE 0 \
    -scale -ot Byte "$INPUT" "$OUTPUT"
```

## 10.5 本章小结

本章介绍了 GDAL 命令行工具：

1. **栅格工具**：gdalinfo、gdal_translate、gdalwarp、gdaladdo、gdal_merge.py、gdaldem、gdal_contour、gdal_calc.py
2. **矢量工具**：ogrinfo、ogr2ogr
3. **实用脚本**：批量处理、自动化任务

这些工具是日常 GIS 数据处理的利器，熟练掌握可以大大提高工作效率。

## 10.6 思考与练习

1. 使用 gdal_translate 将一个 GeoTIFF 转换为 Cloud Optimized GeoTIFF。
2. 使用 gdalwarp 将 WGS84 坐标系的栅格转换为 Web Mercator。
3. 使用 ogr2ogr 将 Shapefile 转换为 GeoJSON 并进行投影转换。
4. 编写脚本批量处理目录中的所有 GeoTIFF 文件。
5. 使用 gdal_calc.py 计算两个时期影像的差异。
