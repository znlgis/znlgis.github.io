# 第12章：矢量数据高级处理

## 12.1 空间分析

到了矢量数据的高级处理，代码的骨架会反复出现同一套模式：打开数据源、创建输出数据源、建立图层定义、复制字段、循环要素、写回结果、关闭数据源。写这类代码时最容易踩的坑不在算法，而在 OGR 的对象生命周期和坐标系单位。同一段代码在东经 116 度的投影数据上正常，换到地理坐标系（度）上算出来的缓冲区半径就只有零点几度——这类错误不会抛异常，结果看起来“差不多”，但业务上完全不成立。

本章的示例统一用 `ESRI Shapefile` 驱动输出。Shapefile 的字段名限制为 10 个字符，中文名、大写小写混排、带空格的名字会被截断或替换，涉及属性连接时要按截断后的名字取字段。正式项目里如果字段结构复杂，改用 GeoPackage 驱动（`GPKG`）能绕开这个限制，代码只需换掉驱动名。

### 12.1.1 缓冲区分析

`ogr.UseExceptions()` 一行值得单独说明。默认情况下 OGR 的 Python 绑定遇到错误只返回 None 或 0，不抛异常；打开一个不存在的文件，`ogr.Open` 返回 None，下一行 `GetLayer()` 立刻抛 `AttributeError`，出错信息离真正的原因隔了两行。开启 UseExceptions 之后，打开失败、创建图层失败、字段重复都会抛出 `RuntimeError` 并带原始错误原因，排查省很多时间。它的作用域是全局的，在一个进程里调用一次即可。

`driver.DeleteDataSource(output_path)` 用于删除同名旧文件。返回值 0 表示文件存在且删除成功，非 0 表示文件不存在，示例里直接 `pass` 忽略——这个写法是对的，但要注意它会硬删除：目录里已有同名成果会被直接覆盖，没有任何备份。批量脚本里建议在删除前先打印路径，或者给输出加时间戳后缀，避免跑错参数时把上一轮结果清空。

`geom.Buffer(distance)` 返回一个新的几何对象，不修改原始几何。`distance` 的单位是图层坐标系自身单位：投影坐标系（如 UTM、CGCS2000 高斯投影）下是米，地理坐标系下是度。用地理坐标系算一米宽的缓冲，需要先把度换算成弧长，`Buffer` 本身不做这种换算，也不考虑椭球曲率。业务要求“按米缓冲”时，正确流程是先 `Transform` 到等距或等积投影，做完缓冲再转回来，或者直接调用 GDAL 命令行 `gdal:buffer` 之外的空间库。

`dissolve=True` 分支把所有要素的缓冲区逐个 Union，最后只输出一个要素。这个循环的复杂度是 O(n) 次两两求并，几何越碎、重叠越多，Union 越慢；数千个要素的全国范围缓冲可能跑上几分钟。可用的替代方案是按网格分块求并、合并结果，或者交给 PostGIS 的 `ST_Union` / Shapely 的 `unary_union`，它们内部会做优化。Union 结果改用 `wkbMultiPolygon` 图层类型更合适，示例统一用 `wkbPolygon` 承载多部件结果，在 Shapefile 里往往能写入但读回来是 MultiPolygon，字段类型与实际不符。

非 dissolve 分支的字段复制暴露了一个容易忽略的点：示例先 `CreateField` 复制了源图层全部字段，再对每个要素逐字段 `SetField` 回填。如果只建字段不回填，属性表里是空的；如果只回填不建字段，`SetField` 返回错误被忽略，输出也没有值。两处必须成对。另外 `out_feature` 没有显式 `Destroy`，Python 绑定在离开作用域时会回收，写大数据量时依赖 GC 回收可以接受，但大批量写入的常见做法是用 `ogr.Feature` 工厂方法 `lco` 复用或者减少中间对象，这里不是性能瓶颈。

```python
from osgeo import ogr, osr

def buffer_analysis(input_path, output_path, distance, dissolve=False):
    """缓冲区分析"""
    
    ogr.UseExceptions()
    
    src_ds = ogr.Open(input_path)
    src_layer = src_ds.GetLayer()
    
    # 创建输出
    driver = ogr.GetDriverByName('ESRI Shapefile')
    if driver.DeleteDataSource(output_path) != 0:
        pass
    dst_ds = driver.CreateDataSource(output_path)
    
    dst_layer = dst_ds.CreateLayer(
        'buffer',
        src_layer.GetSpatialRef(),
        ogr.wkbPolygon
    )
    
    # 复制字段
    src_defn = src_layer.GetLayerDefn()
    for i in range(src_defn.GetFieldCount()):
        dst_layer.CreateField(src_defn.GetFieldDefn(i))
    
    dst_defn = dst_layer.GetLayerDefn()
    
    if dissolve:
        # 溶解所有缓冲区
        union_geom = None
        for feature in src_layer:
            geom = feature.GetGeometryRef()
            if geom:
                buffer_geom = geom.Buffer(distance)
                if union_geom is None:
                    union_geom = buffer_geom
                else:
                    union_geom = union_geom.Union(buffer_geom)
        
        if union_geom:
            out_feature = ogr.Feature(dst_defn)
            out_feature.SetGeometry(union_geom)
            dst_layer.CreateFeature(out_feature)
    else:
        # 单独的缓冲区
        for feature in src_layer:
            geom = feature.GetGeometryRef()
            if geom:
                buffer_geom = geom.Buffer(distance)
                
                out_feature = ogr.Feature(dst_defn)
                out_feature.SetGeometry(buffer_geom)
                
                for i in range(src_defn.GetFieldCount()):
                    out_feature.SetField(i, feature.GetField(i))
                
                dst_layer.CreateFeature(out_feature)
    
    src_ds = None
    dst_ds = None
```

### 12.1.2 叠加分析

叠加分析（intersection / union / difference）的语义和 GIS 软件里的同名工具一致：交集取两块图形的公共部分，并集合并覆盖范围，差集从第一块里挖掉第二块。OGR 提供的是逐要素的几何运算，不做自动配对，所以示例里用嵌套循环加 `SetSpatialFilter` 把候选范围缩小，再用谓词函数确认空间关系。这个模式是 Python 版空间分析的标准写法。

三处细节决定了脚本能不能跑对。第一，`SetSpatialFilter(geom)` 会在图层上设置过滤器，读完之后必须 `ResetReading()`，否则下一次循环读不到数据——示例在两层循环的外层末尾调用了它。第二，空间过滤器只做包围盒粗筛，真正的几何关系仍然要用 `Intersects`、`Contains` 判断，跳过这一步会得到大量虚假相交。第三，`Intersection` 返回新几何，原几何不受影响；对 MultiPolygon 与 MultiPolygon 求交，结果可能是 GeometryCollection，直接写进 `wkbPolygon` 图层会失败或被驱动悄悄转换，稳妥的做法是先检查 `GetGeometryName()`，必要时提取其中的 Polygon。

交集函数里字段复制的逻辑有缺陷：`CreateField` 循环遍历两个图层，遇到同名字段时抛异常被 `except` 吞掉，于是输出只有一份同名字段；而写入时只复制了 `feat1` 的属性，`feat2` 的属性一个都没写进去。业务上做空间叠加通常要保留两侧属性，正确写法是给第二层的字段加前缀（像空间连接那样）再统一写入。这类错误不会报错，通话前核对属性表才能发现。

三个函数末尾都把数据源变量置为 None。这是 OGR 释放文件句柄的方式，Python 的绑定依赖引用计数：`ds = None` 之后对象被回收，Shapefile 的 `.shp`、`.dbf`、`.shx` 才会写完整并关闭文件。没有这一步，Windows 上立刻会报“文件被另一个程序占用”，Linux 上则可能得到只写了一半的成果。`out_ds = None` 同理，而且必须在所有 `CreateFeature` 之后。

```python
from osgeo import ogr

def intersection_analysis(layer1_path, layer2_path, output_path):
    """交集分析"""
    
    ogr.UseExceptions()
    
    ds1 = ogr.Open(layer1_path)
    layer1 = ds1.GetLayer()
    
    ds2 = ogr.Open(layer2_path)
    layer2 = ds2.GetLayer()
    
    # 创建输出
    driver = ogr.GetDriverByName('ESRI Shapefile')
    out_ds = driver.CreateDataSource(output_path)
    out_layer = out_ds.CreateLayer(
        'intersection',
        layer1.GetSpatialRef(),
        ogr.wkbPolygon
    )
    
    # 添加两个图层的字段
    for layer in [layer1, layer2]:
        defn = layer.GetLayerDefn()
        for i in range(defn.GetFieldCount()):
            field_defn = defn.GetFieldDefn(i)
            try:
                out_layer.CreateField(field_defn)
            except:
                pass  # 字段已存在
    
    out_defn = out_layer.GetLayerDefn()
    
    # 执行交集
    for feat1 in layer1:
        geom1 = feat1.GetGeometryRef()
        if not geom1:
            continue
        
        layer2.SetSpatialFilter(geom1)
        
        for feat2 in layer2:
            geom2 = feat2.GetGeometryRef()
            if not geom2:
                continue
            
            if geom1.Intersects(geom2):
                intersection = geom1.Intersection(geom2)
                
                if not intersection.IsEmpty():
                    out_feat = ogr.Feature(out_defn)
                    out_feat.SetGeometry(intersection)
                    
                    # 复制属性
                    for i in range(feat1.GetFieldCount()):
                        out_feat.SetField(i, feat1.GetField(i))
                    
                    out_layer.CreateFeature(out_feat)
        
        layer2.ResetReading()
    
    ds1 = None
    ds2 = None
    out_ds = None

def union_analysis(layer1_path, layer2_path, output_path):
    """并集分析"""
    
    ogr.UseExceptions()
    
    ds1 = ogr.Open(layer1_path)
    layer1 = ds1.GetLayer()
    
    ds2 = ogr.Open(layer2_path)
    layer2 = ds2.GetLayer()
    
    # 创建输出
    driver = ogr.GetDriverByName('ESRI Shapefile')
    out_ds = driver.CreateDataSource(output_path)
    out_layer = out_ds.CreateLayer(
        'union',
        layer1.GetSpatialRef(),
        ogr.wkbPolygon
    )
    
    out_defn = out_layer.GetLayerDefn()
    
    # 收集所有几何
    union_geom = None
    
    for layer in [layer1, layer2]:
        for feature in layer:
            geom = feature.GetGeometryRef()
            if geom:
                if union_geom is None:
                    union_geom = geom.Clone()
                else:
                    union_geom = union_geom.Union(geom)
        layer.ResetReading()
    
    if union_geom:
        out_feat = ogr.Feature(out_defn)
        out_feat.SetGeometry(union_geom)
        out_layer.CreateFeature(out_feat)
    
    ds1 = None
    ds2 = None
    out_ds = None

def difference_analysis(layer1_path, layer2_path, output_path):
    """差集分析"""
    
    ogr.UseExceptions()
    
    ds1 = ogr.Open(layer1_path)
    layer1 = ds1.GetLayer()
    
    ds2 = ogr.Open(layer2_path)
    layer2 = ds2.GetLayer()
    
    # 合并 layer2 的所有几何
    union2 = None
    for feature in layer2:
        geom = feature.GetGeometryRef()
        if geom:
            if union2 is None:
                union2 = geom.Clone()
            else:
                union2 = union2.Union(geom)
    layer2.ResetReading()
    
    # 创建输出
    driver = ogr.GetDriverByName('ESRI Shapefile')
    out_ds = driver.CreateDataSource(output_path)
    out_layer = out_ds.CreateLayer(
        'difference',
        layer1.GetSpatialRef(),
        layer1.GetGeomType()
    )
    
    # 复制字段
    src_defn = layer1.GetLayerDefn()
    for i in range(src_defn.GetFieldCount()):
        out_layer.CreateField(src_defn.GetFieldDefn(i))
    
    out_defn = out_layer.GetLayerDefn()
    
    # 执行差集
    for feature in layer1:
        geom = feature.GetGeometryRef()
        if geom and union2:
            diff = geom.Difference(union2)
            if diff and not diff.IsEmpty():
                out_feat = ogr.Feature(out_defn)
                out_feat.SetGeometry(diff)
                
                for i in range(src_defn.GetFieldCount()):
                    out_feat.SetField(i, feature.GetField(i))
                
                out_layer.CreateFeature(out_feat)
    
    ds1 = None
    ds2 = None
    out_ds = None
```

### 12.1.3 空间连接

空间连接的输出一行对应一对相邻要素，是否相邻由 `join_type` 决定。示例用字典把四种空间谓词映射成函数，`contains`、`within` 互为反向：`A.Contains(B)` 表示 B 完全落在 A 内（边界情况由 GEOS 的规则决定），`A.Within(B)` 表示 A 完全落在 B 内。`touches` 表示只在边界接触、内部不相交，相邻地块共边就属于这种关系。

`SetSpatialFilter` 在这里的作用是性能优化：对每个目标要素，先把连接图层过滤到包围盒相交的候选集，再逐个判断谓词。如果不加过滤，复杂度是两层循环的笛卡尔积；加了过滤，通常能降到与目标要素相邻的那几条。真实数据里，连接图层的空间索引（Shapefile 的 `.qix`、GeoPackage 的 R-Tree）是否存在，对过滤速度影响很大，可用 `CreateSpatialIndex` 或者 `ogrinfo -sql "SELECT CreateSpatialIndex(...)"` 补建。

`break` 表示只保留第一个匹配的连接要素。一对多关系（一个行政区与多个监测站）时，只有第一个站会出现在结果里，具体是哪一个取决于连接图层的要素顺序，不具备确定性。需要保留全部匹配时，把 `break` 去掉，让每一对都生成一条记录；或者改成聚合，把多值拼成字段。

字段写入用 `target_defn.GetFieldCount() + i` 计算输出图层中的字段序号，这是正确的，因为输出图层先复制了目标字段，再追加连接字段。但注意 `join_defn.GetFieldCount()` 的 `i` 是连接图层的字段序号，如果连接图层里有与目标图层同名的字段——加上 `join_` 前缀之后已经避免了直接冲突，但 `join_` 前缀加上原名很容易超过 Shapefile 的 10 字符限制被截断，两个不同字段截断后同名时，字段创建会失败，属性写错位。生产环境里用 `GPKG` 输出更安全。

最后一个循环结束后的 `ResetReading` 与前面的写法一致，是过滤之后必须恢复读取位置。漏掉这一行，外层的下一个目标要素会在已经读到底的连接图层上继续读，直接读到空结果，表现为“只有第一条有连接结果”。

```python
from osgeo import ogr

def spatial_join(target_path, join_path, output_path, join_type='intersects'):
    """空间连接"""
    
    ogr.UseExceptions()
    
    target_ds = ogr.Open(target_path)
    target_layer = target_ds.GetLayer()
    
    join_ds = ogr.Open(join_path)
    join_layer = join_ds.GetLayer()
    
    # 创建输出
    driver = ogr.GetDriverByName('ESRI Shapefile')
    out_ds = driver.CreateDataSource(output_path)
    out_layer = out_ds.CreateLayer(
        'joined',
        target_layer.GetSpatialRef(),
        target_layer.GetGeomType()
    )
    
    # 复制目标图层字段
    target_defn = target_layer.GetLayerDefn()
    for i in range(target_defn.GetFieldCount()):
        out_layer.CreateField(target_defn.GetFieldDefn(i))
    
    # 添加连接图层字段（加前缀）
    join_defn = join_layer.GetLayerDefn()
    for i in range(join_defn.GetFieldCount()):
        field = join_defn.GetFieldDefn(i)
        new_field = ogr.FieldDefn(f'join_{field.GetName()}', field.GetType())
        new_field.SetWidth(field.GetWidth())
        out_layer.CreateField(new_field)
    
    out_defn = out_layer.GetLayerDefn()
    
    # 空间关系判断方法
    spatial_methods = {
        'intersects': lambda g1, g2: g1.Intersects(g2),
        'contains': lambda g1, g2: g1.Contains(g2),
        'within': lambda g1, g2: g1.Within(g2),
        'touches': lambda g1, g2: g1.Touches(g2),
    }
    
    check_spatial = spatial_methods.get(join_type, spatial_methods['intersects'])
    
    # 执行连接
    for target_feat in target_layer:
        target_geom = target_feat.GetGeometryRef()
        
        if not target_geom:
            continue
        
        join_layer.SetSpatialFilter(target_geom)
        
        for join_feat in join_layer:
            join_geom = join_feat.GetGeometryRef()
            
            if join_geom and check_spatial(target_geom, join_geom):
                out_feat = ogr.Feature(out_defn)
                out_feat.SetGeometry(target_geom.Clone())
                
                # 复制目标属性
                for i in range(target_defn.GetFieldCount()):
                    out_feat.SetField(i, target_feat.GetField(i))
                
                # 复制连接属性
                for i in range(join_defn.GetFieldCount()):
                    out_feat.SetField(
                        target_defn.GetFieldCount() + i,
                        join_feat.GetField(i)
                    )
                
                out_layer.CreateFeature(out_feat)
                break  # 只取第一个匹配
        
        join_layer.ResetReading()
    
    target_ds = None
    join_ds = None
    out_ds = None
```

## 12.2 几何操作

几何操作这一节的函数都是“输入一个图层、输出一个图层”，结构高度相似，真正需要理解的是每个几何方法的行为差异和容差单位。简化、凸包、质心看起来都是几行调用，用错函数得到的成果在视觉上仍然“像”正确的，只有叠在一起对比才会发现问题。

### 12.2.1 几何简化

`geom.Simplify(tolerance)` 用的是 Douglas-Peucker 算法：在容差范围内去掉对形状影响最小的顶点。容差单位同样是图层坐标系单位，投影数据下是米，地理坐标下是度——0.001 在投影数据里是 1 毫米，在地理坐标里是约 111 米，同一个参数在两个图层里效果差三个数量级。做简化之前先确认坐标系，这是最容易出错的环节。

`Simplify` 不考虑要素之间的拓扑关系：相邻地块各自简化后，共享边界可能被简化成不同的折线，出现缝隙和重叠。`SimplifyPreserveTopology` 会在简化时保护共享边界，相邻要素的公共边保持一致，适合行政区划、地块这类面数据；代价是算法更复杂、结果简化程度更低。线数据（道路、河流）没有拓扑约束，用 `Simplify` 就够。

简化的容差怎么定？经验做法是按显示比例尺反推：1:10000 的地图，图上 0.2 毫米对应实地 2 米，容差取 1 到 2 米肉眼无感；Web 地图的 14 级瓦片，一个像素约 10 米，容差取 5 到 10 米也不会被看出来。容差过大时，小面积多边形会退化成三角形甚至空几何，`Simplify` 可能返回空 Geometry，写进图层就是一个没有形状的要素，需要判空后跳过。

简化前后的要素数量不变，属性逐条复制。如果源数据里有自相交等无效几何，`Simplify` 可能抛拓扑异常，开启 `UseExceptions` 后会看到 `TopologyException` 一类的报错，这时应先在上一节 12.3 的流程里修复几何再做简化。

```python
from osgeo import ogr

def simplify_layer(input_path, output_path, tolerance, preserve_topology=True):
    """简化几何"""
    
    ogr.UseExceptions()
    
    src_ds = ogr.Open(input_path)
    src_layer = src_ds.GetLayer()
    
    driver = ogr.GetDriverByName('ESRI Shapefile')
    dst_ds = driver.CreateDataSource(output_path)
    dst_layer = dst_ds.CreateLayer(
        src_layer.GetName(),
        src_layer.GetSpatialRef(),
        src_layer.GetGeomType()
    )
    
    # 复制字段
    src_defn = src_layer.GetLayerDefn()
    for i in range(src_defn.GetFieldCount()):
        dst_layer.CreateField(src_defn.GetFieldDefn(i))
    
    dst_defn = dst_layer.GetLayerDefn()
    
    for feature in src_layer:
        geom = feature.GetGeometryRef()
        
        if geom:
            if preserve_topology:
                simplified = geom.SimplifyPreserveTopology(tolerance)
            else:
                simplified = geom.Simplify(tolerance)
            
            out_feat = ogr.Feature(dst_defn)
            out_feat.SetGeometry(simplified)
            
            for i in range(src_defn.GetFieldCount()):
                out_feat.SetField(i, feature.GetField(i))
            
            dst_layer.CreateFeature(out_feat)
    
    src_ds = None
    dst_ds = None
```

### 12.2.2 凸包和最小边界

`create_convex_hull` 把图层里所有几何塞进一个 `wkbGeometryCollection`，再对整体求凸包，得到覆盖全部要素的最小凸多边形。`multi.AddGeometry(geom)` 会复制几何，之后源图层释放也不影响结果。凸包常用作数据范围的示意、碰撞检测的粗筛、地图缩略图的定位框。

凸包与要素个数无关地保持一个多边形，即使输入是点集。要注意 `ConvexHull()` 对空几何集合返回空，对单点返回一个点而不是面，直接塞进 `wkbPolygon` 图层会失败。传入的 `src_layer.GetSpatialRef()` 可能为 None（Shapefile 缺少 `.prj` 时），这时 `CreateLayer` 仍能执行，但输出成果没有坐标系，后续叠加会错位，可在开头检查并给出提示。

`create_minimum_bounding_rectangle` 名为“最小外接矩形”，实际取的是图层范围 `GetExtent()`，得到的是与坐标轴对齐的外接矩形（MBR），不是真正意义上的最小面积外接矩形（MBR 的面积一定大于等于旋转后的最小外接矩形）。`GetExtent()` 返回 `(minX, maxX, minY, maxY)`，示例里按 `extent[0], extent[2]` 的顺序取左下角，这个索引对应关系要记牢，写反了会得到一个横竖颠倒的矩形。

构造多边形时，`wkbLinearRing` 必须首尾闭合，示例最后又加了一次 `(extent[0], extent[2])` 回到起点，这是正确的。`polygon.AddGeometry(ring)` 要求 ring 的类型匹配，直接 `AddPoint` 到 Polygon 上是错的。如果需要真正的最小外接矩形，得用 `MinimumRotatedRect` 一类的算法，OGR 的 Geometry 没有直接对应的方法，需要调 GEOS 或自己实现旋转卡壳。

```python
from osgeo import ogr

def create_convex_hull(input_path, output_path):
    """创建凸包"""
    
    src_ds = ogr.Open(input_path)
    src_layer = src_ds.GetLayer()
    
    # 合并所有几何
    multi = ogr.Geometry(ogr.wkbGeometryCollection)
    for feature in src_layer:
        geom = feature.GetGeometryRef()
        if geom:
            multi.AddGeometry(geom)
    
    # 计算凸包
    convex_hull = multi.ConvexHull()
    
    # 保存
    driver = ogr.GetDriverByName('ESRI Shapefile')
    dst_ds = driver.CreateDataSource(output_path)
    dst_layer = dst_ds.CreateLayer(
        'convex_hull',
        src_layer.GetSpatialRef(),
        ogr.wkbPolygon
    )
    
    out_feat = ogr.Feature(dst_layer.GetLayerDefn())
    out_feat.SetGeometry(convex_hull)
    dst_layer.CreateFeature(out_feat)
    
    src_ds = None
    dst_ds = None

def create_minimum_bounding_rectangle(input_path, output_path):
    """创建最小外接矩形"""
    
    src_ds = ogr.Open(input_path)
    src_layer = src_ds.GetLayer()
    
    # 获取范围
    extent = src_layer.GetExtent()
    
    # 创建矩形
    ring = ogr.Geometry(ogr.wkbLinearRing)
    ring.AddPoint(extent[0], extent[2])  # 左下
    ring.AddPoint(extent[1], extent[2])  # 右下
    ring.AddPoint(extent[1], extent[3])  # 右上
    ring.AddPoint(extent[0], extent[3])  # 左上
    ring.AddPoint(extent[0], extent[2])  # 闭合
    
    polygon = ogr.Geometry(ogr.wkbPolygon)
    polygon.AddGeometry(ring)
    
    # 保存
    driver = ogr.GetDriverByName('ESRI Shapefile')
    dst_ds = driver.CreateDataSource(output_path)
    dst_layer = dst_ds.CreateLayer(
        'mbr',
        src_layer.GetSpatialRef(),
        ogr.wkbPolygon
    )
    
    out_feat = ogr.Feature(dst_layer.GetLayerDefn())
    out_feat.SetGeometry(polygon)
    dst_layer.CreateFeature(out_feat)
    
    src_ds = None
    dst_ds = None
```

### 12.2.3 质心和点在面内

`Centroid()` 返回几何的质心，这是数学意义上的面积重心。对凹多边形，质心可能落在图形外部（比如 C 形地块的重心在缺口里）；对 MultiPolygon，质心是所有部件的联合重心，可能落在两个部件之间的空白处。把质心当作标注位置时，经常出现“标签跑到地块外面”的现象，原因就在这里。

`PointOnSurface()` 保证返回的点在几何内部（对有效的面几何而言），专门用来放置标注、生成代表点。它的计算复杂度比质心高，结果也不是唯一的——同一个多边形在不同版本的 GEOS 下可能得到不同的内部点，但对标注用途没有影响。做点面转换、生成 POI 的代表点时优先用它，做统计汇总（如人口加权中心）时用质心。

两个函数都在循环里逐要素输出一个点要素，并复制原属性。质心没有属性上的意义时也可以只保留关键字段，减少输出体积。注意点要素的 `wkbPoint` 图层类型只能容纳单点，`Centroid()` 对零面积要素（退化的线、空面）返回空几何，`SetGeometry` 会失败，判空是必要的。

```python
from osgeo import ogr

def create_centroids(input_path, output_path):
    """创建质心点"""
    
    src_ds = ogr.Open(input_path)
    src_layer = src_ds.GetLayer()
    
    driver = ogr.GetDriverByName('ESRI Shapefile')
    dst_ds = driver.CreateDataSource(output_path)
    dst_layer = dst_ds.CreateLayer(
        'centroids',
        src_layer.GetSpatialRef(),
        ogr.wkbPoint
    )
    
    # 复制字段
    src_defn = src_layer.GetLayerDefn()
    for i in range(src_defn.GetFieldCount()):
        dst_layer.CreateField(src_defn.GetFieldDefn(i))
    
    dst_defn = dst_layer.GetLayerDefn()
    
    for feature in src_layer:
        geom = feature.GetGeometryRef()
        if geom:
            centroid = geom.Centroid()
            
            out_feat = ogr.Feature(dst_defn)
            out_feat.SetGeometry(centroid)
            
            for i in range(src_defn.GetFieldCount()):
                out_feat.SetField(i, feature.GetField(i))
            
            dst_layer.CreateFeature(out_feat)
    
    src_ds = None
    dst_ds = None

def create_point_on_surface(input_path, output_path):
    """创建面内点（保证点在多边形内部）"""
    
    src_ds = ogr.Open(input_path)

```

## 12.3 拓扑处理

拓扑处理解决的是“几何本身不合法”的问题。GIS 数据从 CAD、Excel、手工绘制等来源汇总时，常见的问题包括：多边形自相交（8 字形）、环的方向错误、重复顶点、零面积要素、MultiPolygon 内部重叠。这些几何在渲染时看起来正常，但做空间分析时会抛异常或者得到错误结果，因此进入分析流程前要先验证、再修复。

### 12.3.1 几何验证

`geom.IsValid()` 按 OGC Simple Features 规范判断几何是否合法，内部调用 GEOS 的验证器。对多边形，它检查环是否闭合、是否自相交、内环是否在外环之内、相邻环是否重叠；对线，检查是否有重复点；对点，几乎总是合法。返回 False 时，`GetGeometryName()` 只能给出几何类型，给不出具体原因——示例把类型当成“原因”打印，信息量有限。

要拿到真正的原因，用 `geom.IsValid()` 之外的方式：GDAL 提供 `GetGeometryRef().IsValid()` 的详细版本需要走 `ogr` 的错误处理，或者在命令行用 `ogrinfo -sql "SELECT ST_IsValidReason(geom) ..."`。Python 侧常见的替代是调用 Shapely 的 `explain_validity`，或者自己按坐标逐环检查。生产脚本里建议把无效要素的 FID、坐标范围、几何 WKT 片段记录下来，方便人工复查。

`fix_geometries` 用 `MakeValid()` 尝试修复。GEOS 的 MakeValid 会把自相交的多边形拆成合法的多边形集合，结果类型可能从 Polygon 变成 MultiPolygon 或 GeometryCollection。示例直接把结果赋回 `geom` 然后写入同类型的输出图层，如果原图层是 `wkbPolygon`，写入 MultiPolygon 可能失败；稳妥的做法是判断结果类型，必要时取出其中的 Polygon 部分，或者把输出图层统一声明为 `wkbMultiPolygon`、`wkbGeometryCollection`。

`geom = fixed_geom` 之后又调用了 `geom.IsValid()` 判断，这一步在示例里是重复的——`MakeValid` 在没有失败时返回的就是合法几何，但保留这个判断可以挡住修复失败的情况，代价很小。修复失败的要素仍会以原样写入，因为代码没有跳过它们；写完之后应当再跑一遍 `validate_geometries` 确认无效数为零，而不是只信控制台打印的“修复了 N 个”。

```python
from osgeo import ogr

def validate_geometries(input_path):
    """验证几何有效性"""
    
    ds = ogr.Open(input_path)
    layer = ds.GetLayer()
    
    invalid_features = []
    
    for feature in layer:
        geom = feature.GetGeometryRef()
        if geom:
            if not geom.IsValid():
                invalid_features.append({
                    'fid': feature.GetFID(),
                    'reason': geom.GetGeometryName(),
                })
    
    ds = None
    
    print(f"无效几何数量: {len(invalid_features)}")
    for item in invalid_features:
        print(f"  FID {item['fid']}: {item['reason']}")
    
    return invalid_features

def fix_geometries(input_path, output_path):
    """修复几何"""
    
    src_ds = ogr.Open(input_path)
    src_layer = src_ds.GetLayer()
    
    driver = ogr.GetDriverByName('ESRI Shapefile')
    dst_ds = driver.CreateDataSource(output_path)
    dst_layer = dst_ds.CreateLayer(
        src_layer.GetName(),
        src_layer.GetSpatialRef(),
        src_layer.GetGeomType()
    )
    
    src_defn = src_layer.GetLayerDefn()
    for i in range(src_defn.GetFieldCount()):
        dst_layer.CreateField(src_defn.GetFieldDefn(i))
    
    dst_defn = dst_layer.GetLayerDefn()
    
    fixed_count = 0
    
    for feature in src_layer:
        geom = feature.GetGeometryRef()
        
        if geom:
            if not geom.IsValid():
                # 尝试修复
                fixed_geom = geom.MakeValid()
                if fixed_geom and fixed_geom.IsValid():
                    geom = fixed_geom
                    fixed_count += 1
            
            out_feat = ogr.Feature(dst_defn)
            out_feat.SetGeometry(geom)
            
            for i in range(src_defn.GetFieldCount()):
                out_feat.SetField(i, feature.GetField(i))
            
            dst_layer.CreateFeature(out_feat)
    
    print(f"修复了 {fixed_count} 个几何")
    
    src_ds = None
    dst_ds = None
```

### 12.3.2 消除缝隙和重叠

`dissolve_layer` 合并相邻要素，是消除缝隙与重叠的直接手段。按字段溶解时，先把同一字段值的几何收集到一个字典里，再逐组 Union，输出一条 MultiPolygon；不传字段时把所有几何合成一条。这个结构比逐条 Union 清晰，也便于在组内做面积排序、剔除空几何等预处理。

`groups[value].append(geom.Clone())` 里的 `Clone()` 不能省。`feature.GetGeometryRef()` 返回的是指向要素内部缓冲区的引用，要素读完、游标前进之后这块内存可能被复用，直接存引用会得到互相覆盖的几何。这类错误很难通过肉眼发现，往往表现为“溶解结果的形状像是错的”。凡是要把几何存起来延后使用，一律先 Clone。

按字段溶解时输出图层只创建了一个字段（用作分组依据的字段），其他属性全部丢弃。这是溶解的常规语义：合并后的要素没有单一属性值。如果业务要保持其他字段（比如统一取最大值、求和），需要在输出上加字段并在 Union 之后依次计算。示例里没有处理 `field` 不存在的情况，`GetFieldIndex` 返回 -1 时 `GetFieldDefn(-1)` 会抛异常，调用前应先校验。

溶解的代价集中在 Union 上。相邻要素的 Union 需要做边界求交、去重、重组，要素越多越慢，而且中间结果会产生大量临时对象。数据量在几千条以上时，考虑先用空间索引按连通区域分组，每组只做一次 `unary_union`；或者改用 PostGIS 的 `ST_Union`，让数据库在服务端完成。输出图层声明为 `wkbMultiPolygon` 是合适的，因为溶解结果天然可能是多部件。

```python
from osgeo import ogr

def dissolve_layer(input_path, output_path, field=None):
    """溶解图层"""
    
    src_ds = ogr.Open(input_path)
    src_layer = src_ds.GetLayer()
    
    driver = ogr.GetDriverByName('ESRI Shapefile')
    dst_ds = driver.CreateDataSource(output_path)
    dst_layer = dst_ds.CreateLayer(
        'dissolved',
        src_layer.GetSpatialRef(),
        ogr.wkbMultiPolygon
    )
    
    if field:
        # 按字段溶解
        src_defn = src_layer.GetLayerDefn()
        field_idx = src_defn.GetFieldIndex(field)
        field_defn = src_defn.GetFieldDefn(field_idx)
        dst_layer.CreateField(field_defn)
        
        # 收集各组的几何
        groups = {}
        for feature in src_layer:
            value = feature.GetField(field)
            geom = feature.GetGeometryRef()
            
            if geom:
                if value not in groups:
                    groups[value] = []
                groups[value].append(geom.Clone())
        
        # 溶解各组
        dst_defn = dst_layer.GetLayerDefn()
        for value, geoms in groups.items():
            union = geoms[0]
            for g in geoms[1:]:
                union = union.Union(g)
            
            out_feat = ogr.Feature(dst_defn)
            out_feat.SetField(field, value)
            out_feat.SetGeometry(union)
            dst_layer.CreateFeature(out_feat)
    
    else:
        # 溶解所有
        union = None
        for feature in src_layer:
            geom = feature.GetGeometryRef()
            if geom:
                if union is None:
                    union = geom.Clone()
                else:
                    union = union.Union(geom)
        
        if union:
            out_feat = ogr.Feature(dst_layer.GetLayerDefn())
            out_feat.SetGeometry(union)
            dst_layer.CreateFeature(out_feat)
    
    src_ds = None
    dst_ds = None
```

## 12.4 属性处理

属性处理的对象是字段而不是几何，但同样有几处 OGR 的特性需要照顾：读写模式必须显式开启、字段索引在字段创建后要重新获取、`SetFeature` 的调用方式与数据源类型有关。这些细节写错时通常不会报错，结果是数据“改了一半”或者根本没有落盘。

### 12.4.1 属性计算

`ogr.Open(input_path, 1)` 的第二个参数 1 表示以可更新模式打开，0 或缺省是只读。只读模式下 `SetFeature`、`CreateField` 都会失败，示例里因为没有开启 UseExceptions，失败被静默吞掉，现象是“脚本跑完了但字段没变”。这是属性处理类脚本最常见的问题，排查第一步就是确认打开模式。

字段创建后必须重新取 `GetLayerDefn()` 才能拿到最新的字段索引。示例在 `CreateField` 之后又调用了一次 `defn.GetLayerDefn()`，看起来像是笔误，其实是对的——`defn` 是创建字段之前拿的旧定义，不重新获取，`GetFieldIndex(field_name)` 仍然返回 -1，后面的 `SetField` 会失败。新版 GDAL 对 LayerDefn 的缓存行为有过调整，重新获取一遍是最稳的写法。

`eval(expression)` 让调用方传入类似 `area * 0.001` 这样的表达式，确实灵活，但它会把字符串当代码执行，属于典型的注入风险。脚本只在本机跑、表达式由开发者自己写时问题不大；一旦表达式来自配置文件、数据库或用户输入，就必须换成受限的表达式求值（如 `ast.literal_eval` 只能算字面量，或者用 `simpleeval` 一类的库），并在执行前做白名单校验。

示例里只把 `area` 和 `length` 放进了 `eval` 的局部作用域，`centroid`、字段值、要素 FID 都没有暴露。实际业务表达式经常需要引用字段，这时应在循环里构造一个字典作为 `eval` 的 `locals` 参数，同时用 `globals` 隔离内置函数（传 `{'__builtins__': {}}`）。性能上，`eval` 每要素解析一次表达式，几万条要素时开销可观；更好的做法是先用 `compile` 编译一次，再在循环里 `eval(code, ..., locals)`。

`calculate_geometry_fields` 里有一处隐患：它无条件 `CreateField`，对已经执行过一次的图层会抛“字段已存在”的错误。批处理脚本反复运行时要么先判断 `GetFieldIndex`，要么以追加模式打开并跳过已存在的字段。另外 `geom.Boundary().Length()` 对不同几何类型含义不同：对面返回外环加内环的总周长，对线返回端点（相当于零长度），代码只在面类型分支里调用，是对的。

```python
from osgeo import ogr

def calculate_field(input_path, field_name, expression, field_type=ogr.OFTReal):
    """计算字段值"""
    
    ds = ogr.Open(input_path, 1)  # 可写模式
    layer = ds.GetLayer()
    
    # 检查字段是否存在，不存在则创建
    defn = layer.GetLayerDefn()
    field_idx = defn.GetFieldIndex(field_name)
    
    if field_idx < 0:
        new_field = ogr.FieldDefn(field_name, field_type)
        layer.CreateField(new_field)
        field_idx = defn.GetFieldIndex(field_name)
    
    # 计算值
    for feature in layer:
        geom = feature.GetGeometryRef()
        
        # 内置变量
        area = geom.GetArea() if geom else 0
        length = geom.Length() if geom else 0
        
        # 计算表达式
        try:
            value = eval(expression)
        except:
            value = 0
        
        feature.SetField(field_name, value)
        layer.SetFeature(feature)
    
    ds = None

def calculate_geometry_fields(input_path):
    """计算几何属性字段"""
    
    ds = ogr.Open(input_path, 1)
    layer = ds.GetLayer()
    
    # 添加字段
    geom_type = layer.GetGeomType()
    
    if geom_type in [ogr.wkbPolygon, ogr.wkbMultiPolygon]:
        layer.CreateField(ogr.FieldDefn('area', ogr.OFTReal))
        layer.CreateField(ogr.FieldDefn('perimeter', ogr.OFTReal))
    
    if geom_type in [ogr.wkbLineString, ogr.wkbMultiLineString]:
        layer.CreateField(ogr.FieldDefn('length', ogr.OFTReal))
    
    layer.CreateField(ogr.FieldDefn('centroid_x', ogr.OFTReal))
    layer.CreateField(ogr.FieldDefn('centroid_y', ogr.OFTReal))
    
    # 计算值
    for feature in layer:
        geom = feature.GetGeometryRef()
        
        if geom:
            if geom_type in [ogr.wkbPolygon, ogr.wkbMultiPolygon]:
                feature.SetField('area', geom.GetArea())
                feature.SetField('perimeter', geom.Boundary().Length())
            
            if geom_type in [ogr.wkbLineString, ogr.wkbMultiLineString]:
                feature.SetField('length', geom.Length())
            
            centroid = geom.Centroid()
            feature.SetField('centroid_x', centroid.GetX())
            feature.SetField('centroid_y', centroid.GetY())
            
            layer.SetFeature(feature)
    
    ds = None
```

### 12.4.2 属性连接

属性连接按公共键把两张表拼成一张，是数据处理里出现频率最高的操作之一。示例用 Python 字典把连接表读进内存做哈希查找，比嵌套循环快得多；代价是内存占用与连接表大小成正比，几十万行以上时要考虑分批读入或者换用 SQLite / PostGIS 的 JOIN。

`join_dict[key_value] = feature` 有一处语义要明确：键重复时后读到的要素覆盖先读到的，最终只保留最后一条。如果连接表是一对多关系（一个行政区对应多条统计记录），这种写法会静默丢数据。业务上需要保留多条时，把字典的值改成列表，连接时按需要展开成多行或者聚合。另外 `feature` 对象存进字典后，数据源关闭前一直有效，但游标继续前进时要素内容是否被复用取决于驱动，稳妥的写法是只把需要的字段值取出来存成元组或字典。

`GetField(target_key)` 取出的键值可能是字符串、可能是整数，两边的类型不一致时字典查找会失败。Shapefile 的整数字段读出来是 int，CSV 读出来是 str，这种跨格式连接必须先统一类型。键值两端的空格、全角半角、大小写也是常见的不匹配来源，一次连接成功率不到 100% 时，先检查键值样例。

输出字段命名用 `join_` 前缀，同名字段不会直接冲突，但 Shapefile 的 10 字符限制会让长名字被截断，两个名字截断后相同时 `CreateField` 抛异常。示例没有捕获这个异常，会直接中断。另外循环里 `j` 计数器的自增只在字段存在时执行，与 `SetField` 的字段序号是对应的，这段逻辑本身正确；一旦前面有字段被截断或跳过，序号就会错位，属性被写到相邻字段里——这类错位比报错更难查。

```python
from osgeo import ogr

def attribute_join(target_path, join_table_path, target_key, join_key, output_path):
    """属性连接"""
    
    target_ds = ogr.Open(target_path)
    target_layer = target_ds.GetLayer()
    
    join_ds = ogr.Open(join_table_path)
    join_layer = join_ds.GetLayer()
    
    # 创建输出
    driver = ogr.GetDriverByName('ESRI Shapefile')
    out_ds = driver.CreateDataSource(output_path)
    out_layer = out_ds.CreateLayer(
        target_layer.GetName(),
        target_layer.GetSpatialRef(),
        target_layer.GetGeomType()
    )
    
    # 复制目标字段
    target_defn = target_layer.GetLayerDefn()
    for i in range(target_defn.GetFieldCount()):
        out_layer.CreateField(target_defn.GetFieldDefn(i))
    
    # 添加连接字段
    join_defn = join_layer.GetLayerDefn()
    join_key_idx = join_defn.GetFieldIndex(join_key)
    
    for i in range(join_defn.GetFieldCount()):
        if i != join_key_idx:
            field = join_defn.GetFieldDefn(i)
            new_field = ogr.FieldDefn(f'join_{field.GetName()}', field.GetType())
            out_layer.CreateField(new_field)
    
    # 建立连接表索引
    join_dict = {}
    for feature in join_layer:
        key_value = feature.GetField(join_key)
        join_dict[key_value] = feature
    
    # 执行连接
    out_defn = out_layer.GetLayerDefn()
    
    for target_feat in target_layer:
        out_feat = ogr.Feature(out_defn)
        
        # 复制几何
        geom = target_feat.GetGeometryRef()
        if geom:
            out_feat.SetGeometry(geom.Clone())
        
        # 复制目标属性
        for i in range(target_defn.GetFieldCount()):
            out_feat.SetField(i, target_feat.GetField(i))
        
        # 连接属性
        key_value = target_feat.GetField(target_key)
        if key_value in join_dict:
            join_feat = join_dict[key_value]
            j = 0
            for i in range(join_defn.GetFieldCount()):
                if i != join_key_idx:
                    out_feat.SetField(
                        target_defn.GetFieldCount() + j,
                        join_feat.GetField(i)
                    )
                    j += 1
        
        out_layer.CreateFeature(out_feat)
    
    target_ds = None
    join_ds = None
    out_ds = None
```

## 12.5 本章小结

本章的函数都遵循同一套模板，真正需要记住的是几个反复出现的前提：坐标系单位决定缓冲、简化、容差的实际含义，地理坐标系下这些参数不能按米来想；几何运算返回新对象，原几何不变，要跨要素保存必须 Clone；图层读取后要用 ResetReading 恢复游标，空间过滤之后尤其容易漏；写入完成后把数据源变量置 None，文件才会完整关闭；Shapefile 的字段名限制为 10 个字符，复杂属性结构应换 GeoPackage。把这几条记住，再对照本章代码，能避掉大部分“跑通了但结果不对”的问题。
