# 空间智能实战教程目录

「空间智能」要解决的不是「把地图做得更大」，而是让机器能看懂空间、规划空间、表达空间。本系列从工程视角出发，把这条链路拆成十二段可以动手的实践：先用 DeepSeek Harness 建立 Vibe Coding 的开发方式，再用低空 AI 巡检打通「视频 → 目标 → 位置」，用空地一体时空融合打通「航迹 → 地图」，用一张图智能体打通「自然语言 → 地图响应」，用自动驾驶覆盖「感知 → 导航 → 仿真」，用 3DGS 解决「重建 → 编辑 → 可交付」，用多模态大模型微调解决「领域能力 → 专用模型」，最后用数据底座、边缘部署、评测上线、工程化交付与技术路线把这套能力收口成可交付的系统。
