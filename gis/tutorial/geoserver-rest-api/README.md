# GeoServer REST API 开发教程

基于 [GeoServerDesktop.GeoServerClient](https://github.com/znlgis/GeoServerDesktop) 项目的完整 GeoServer REST API 中文教程。

## 教程简介

本教程全面深入地介绍如何使用 GeoServer REST API 进行 GIS 应用开发，以 GeoServerDesktop.GeoServerClient 项目为基础和示例，提供了大量实用的代码示例和最佳实践。

**当前状态**：
- ✅ **全部18章已完成**：包含详细的理论讲解、代码示例和实战案例
- ✅ **总内容量约270KB**：8000+行专业技术文档
- ✅ **100+代码示例**：涵盖所有核心API的实际使用

1. 快速浏览第 1-3 章，了解项目架构
2. 重点学习第 4-9 章的资源管理 API
3. 根据项目需求学习特定章节

1. 学习第 1-2 章和第 15 章
2. 重点学习第 11 章安全管理
3. 学习第 17 章最佳实践
