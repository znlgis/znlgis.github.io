# 第03章：几何对象模型详解

## 3.1 几何类型概述

NetTopologySuite 的几何类型基于 OGC（Open Geospatial Consortium）的 Simple Features Specification，提供了完整的二维几何模型，并扩展支持三维坐标。

### 3.1.1 几何类型层次结构

```
Geometry (抽象基类)
├── Point (点)
├── LineString (线串)
│   └── LinearRing (线性环)
├── Polygon (多边形)
└── GeometryCollection (几何集合)
    ├── MultiPoint (多点)
    ├── MultiLineString (多线)
    └── MultiPolygon (多多边形)
```

### 3.1.2 几何类型分类

| 分类 | 类型 | 维度 | 说明 |
|------|------|------|------|
| 零维 | Point | 0 | 单个点 |
| 零维 | MultiPoint | 0 | 多个点的集合 |
| 一维 | LineString | 1 | 连续的线段序列 |
| 一维 | LinearRing | 1 | 闭合的线串 |
| 一维 | MultiLineString | 1 | 多条线的集合 |
| 二维 | Polygon | 2 | 带有外环和可选内环的多边形 |
| 二维 | MultiPolygon | 2 | 多个多边形的集合 |
| 混合 | GeometryCollection | - | 任意几何类型的集合 |

## 3.2 Coordinate 坐标类

### 3.2.1 坐标类型

NetTopologySuite 提供了多种坐标类型：

```csharp
using NetTopologySuite.Geometries;

// 1. 基础二维坐标 (X, Y)
var coord2d = new Coordinate(116.4074, 39.9042);
Console.WriteLine($"X: {coord2d.X}, Y: {coord2d.Y}");

// 2. 三维坐标 (X, Y, Z) - 带高程
var coord3d = new CoordinateZ(116.4074, 39.9042, 100.0);
Console.WriteLine($"X: {coord3d.X}, Y: {coord3d.Y}, Z: {coord3d.Z}");

// 3. 带 M 值的坐标 (X, Y, M) - 线性参考
var coordM = new CoordinateM(116.4074, 39.9042, 0.5);
Console.WriteLine($"X: {coordM.X}, Y: {coordM.Y}, M: {coordM.M}");

// 4. 完整坐标 (X, Y, Z, M)
var coordZM = new CoordinateZM(116.4074, 39.9042, 100.0, 0.5);
Console.WriteLine($"X: {coordZM.X}, Y: {coordZM.Y}, Z: {coordZM.Z}, M: {coordZM.M}");
```

### 3.2.2 坐标比较

```csharp
var coord1 = new Coordinate(10.0, 20.0);
var coord2 = new Coordinate(10.0, 20.0);
var coord3 = new Coordinate(10.0, 20.001);

// 精确比较
Console.WriteLine($"coord1 == coord2: {coord1.Equals(coord2)}");  // true
Console.WriteLine($"coord1 == coord3: {coord1.Equals(coord3)}");  // false

// 二维比较（忽略 Z 值）
Console.WriteLine($"2D比较: {coord1.Equals2D(coord2)}");  // true

// 带容差的比较
Console.WriteLine($"容差比较: {coord1.Equals2D(coord3, 0.01)}");  // true

// 计算距离
Console.WriteLine($"距离: {coord1.Distance(coord3)}");
```

### 3.2.3 坐标序列

`CoordinateSequence` 用于高效存储多个坐标：

```csharp
using NetTopologySuite.Geometries;
using NetTopologySuite.Geometries.Implementation;

// 创建坐标序列工厂
var csFactory = new CoordinateArraySequenceFactory();

// 从坐标数组创建序列
var coordinates = new Coordinate[]
{
    new Coordinate(0, 0),
    new Coordinate(10, 0),
    new Coordinate(10, 10),
    new Coordinate(0, 10),
    new Coordinate(0, 0)
};
var sequence = csFactory.Create(coordinates);

// 访问坐标序列
Console.WriteLine($"坐标数量: {sequence.Count}");
Console.WriteLine($"维度: {sequence.Dimension}");

for (int i = 0; i < sequence.Count; i++)
{
    Console.WriteLine($"坐标[{i}]: ({sequence.GetX(i)}, {sequence.GetY(i)})");
}

// 创建指定大小和维度的空序列
var emptySequence = csFactory.Create(10, 3);  // 10个坐标，3维
```

## 3.3 Point 点几何

### 3.3.1 创建点

```csharp
using NetTopologySuite.Geometries;

var factory = new GeometryFactory(new PrecisionModel(), 4326);

// 方法1：使用 Coordinate 创建
var point1 = factory.CreatePoint(new Coordinate(116.4074, 39.9042));

// 方法2：使用坐标序列创建
var csFactory = new CoordinateArraySequenceFactory();
var seq = csFactory.Create(new[] { new Coordinate(116.4074, 39.9042) });
var point2 = factory.CreatePoint(seq);

// 创建三维点
var point3d = factory.CreatePoint(new CoordinateZ(116.4074, 39.9042, 100.0));

Console.WriteLine($"Point WKT: {point1.AsText()}");
Console.WriteLine($"X: {point1.X}, Y: {point1.Y}");
Console.WriteLine($"SRID: {point1.SRID}");
```

### 3.3.2 点的属性

```csharp
var point = factory.CreatePoint(new Coordinate(116.4074, 39.9042));

// 基本属性
Console.WriteLine($"几何类型: {point.GeometryType}");        // Point
Console.WriteLine($"坐标 X: {point.X}");                     // 116.4074
Console.WriteLine($"坐标 Y: {point.Y}");                     // 39.9042
Console.WriteLine($"坐标 Z: {point.Z}");                     // NaN（未设置）

// 空间属性
Console.WriteLine($"面积: {point.Area}");                    // 0
Console.WriteLine($"长度: {point.Length}");                  // 0
Console.WriteLine($"维度: {point.Dimension}");               // 0（点是零维的）

// 拓扑属性
Console.WriteLine($"边界: {point.Boundary}");                // GEOMETRYCOLLECTION EMPTY
Console.WriteLine($"外包矩形: {point.EnvelopeInternal}");    // Env[116.4074:116.4074, 39.9042:39.9042]

// 验证属性
Console.WriteLine($"是否有效: {point.IsValid}");             // true
Console.WriteLine($"是否为空: {point.IsEmpty}");             // false
Console.WriteLine($"是否简单: {point.IsSimple}");            // true
```

### 3.3.3 空点

```csharp
// 创建空点
var emptyPoint = factory.CreatePoint((Coordinate)null);
// 或者
var emptyPoint2 = Point.Empty;

Console.WriteLine($"是否为空: {emptyPoint.IsEmpty}");  // true
Console.WriteLine($"WKT: {emptyPoint.AsText()}");      // POINT EMPTY
```

## 3.4 LineString 线串几何

### 3.4.1 创建线串

```csharp
var factory = new GeometryFactory(new PrecisionModel(), 4326);

// 方法1：使用 Coordinate 数组创建
var coords = new Coordinate[]
{
    new Coordinate(0, 0),
    new Coordinate(10, 10),
    new Coordinate(20, 5),
    new Coordinate(30, 15)
};
var line = factory.CreateLineString(coords);

// 方法2：从 WKT 创建
var reader = new WKTReader(factory);
var line2 = (LineString)reader.Read("LINESTRING (0 0, 10 10, 20 5, 30 15)");

Console.WriteLine($"线串 WKT: {line.AsText()}");
```

### 3.4.2 线串的属性和方法

```csharp
var coords = new Coordinate[]
{
    new Coordinate(0, 0),
    new Coordinate(10, 0),
    new Coordinate(10, 10),
    new Coordinate(20, 10)
};
var line = factory.CreateLineString(coords);

// 基本属性
Console.WriteLine($"几何类型: {line.GeometryType}");           // LineString
Console.WriteLine($"点数量: {line.NumPoints}");                // 4
Console.WriteLine($"长度: {line.Length}");                     // 30
Console.WriteLine($"维度: {line.Dimension}");                  // 1

// 获取特定点
Console.WriteLine($"起点: {line.StartPoint.AsText()}");        // POINT (0 0)
Console.WriteLine($"终点: {line.EndPoint.AsText()}");          // POINT (20 10)
Console.WriteLine($"第二个点: {line.GetPointN(1).AsText()}");  // POINT (10 0)

// 获取坐标
var coordinates = line.Coordinates;
Console.WriteLine($"坐标数量: {coordinates.Length}");

// 判断是否闭合
Console.WriteLine($"是否闭合: {line.IsClosed}");               // false
Console.WriteLine($"是否为环: {line.IsRing}");                 // false

// 边界（线串的边界是其端点）
Console.WriteLine($"边界: {line.Boundary.AsText()}");          // MULTIPOINT ((0 0), (20 10))
```

### 3.4.3 线串操作

```csharp
var line = factory.CreateLineString(new Coordinate[]
{
    new Coordinate(0, 0),
    new Coordinate(10, 10),
    new Coordinate(20, 0)
});

// 反转线串方向
var reversed = (LineString)line.Reverse();
Console.WriteLine($"反转后: {reversed.AsText()}");

// 获取中点
var midPoint = line.InteriorPoint;
Console.WriteLine($"内部点: {midPoint.AsText()}");

// 线性参考 - 获取线上指定比例位置的点
var pointAtRatio = line.GetCoordinateN(1);  // 获取第二个坐标点

// 质心
Console.WriteLine($"质心: {line.Centroid.AsText()}");

// 简化线串
var simplified = line.Simplify(1.0);  // Douglas-Peucker 简化
Console.WriteLine($"简化后点数: {simplified.NumPoints}");
```

## 3.5 LinearRing 线性环

### 3.5.1 创建线性环

LinearRing 是闭合的线串，用于构成多边形的外环和内环。

```csharp
var factory = new GeometryFactory();

// 创建线性环（必须闭合 - 首尾坐标相同）
var ringCoords = new Coordinate[]
{
    new Coordinate(0, 0),
    new Coordinate(10, 0),
    new Coordinate(10, 10),
    new Coordinate(0, 10),
    new Coordinate(0, 0)  // 闭合点
};
var ring = factory.CreateLinearRing(ringCoords);

Console.WriteLine($"类型: {ring.GeometryType}");    // LinearRing
Console.WriteLine($"是否闭合: {ring.IsClosed}");   // true
Console.WriteLine($"是否为环: {ring.IsRing}");     // true
Console.WriteLine($"面积: {ring.Area}");           // 注意：LinearRing 本身是线，面积为0
Console.WriteLine($"长度: {ring.Length}");         // 40（周长）
```

### 3.5.2 环的方向

```csharp
// 判断环的方向
var clockwise = new Coordinate[]
{
    new Coordinate(0, 0),
    new Coordinate(0, 10),
    new Coordinate(10, 10),
    new Coordinate(10, 0),
    new Coordinate(0, 0)
};
var ccw = new Coordinate[]
{
    new Coordinate(0, 0),
    new Coordinate(10, 0),
    new Coordinate(10, 10),
    new Coordinate(0, 10),
    new Coordinate(0, 0)
};

var ringCW = factory.CreateLinearRing(clockwise);
var ringCCW = factory.CreateLinearRing(ccw);

// 使用算法判断方向
Console.WriteLine($"顺时针: {ringCW.IsCCW}");   // false
Console.WriteLine($"逆时针: {ringCCW.IsCCW}");  // true

// OGC 规范：外环为逆时针，内环为顺时针
```

## 3.6 Polygon 多边形

### 3.6.1 创建简单多边形

```csharp
var factory = new GeometryFactory(new PrecisionModel(), 4326);

// 方法1：直接使用坐标数组
var coords = new Coordinate[]
{
    new Coordinate(0, 0),
    new Coordinate(10, 0),
    new Coordinate(10, 10),
    new Coordinate(0, 10),
    new Coordinate(0, 0)  // 闭合
};
var polygon = factory.CreatePolygon(coords);

// 方法2：使用 LinearRing
var shell = factory.CreateLinearRing(coords);
var polygon2 = factory.CreatePolygon(shell);

Console.WriteLine($"WKT: {polygon.AsText()}");
Console.WriteLine($"面积: {polygon.Area}");         // 100
Console.WriteLine($"周长: {polygon.Length}");       // 40
```

### 3.6.2 创建带孔多边形

```csharp
var factory = new GeometryFactory();

// 外环（逆时针）
var shellCoords = new Coordinate[]
{
    new Coordinate(0, 0),
    new Coordinate(20, 0),
    new Coordinate(20, 20),
    new Coordinate(0, 20),
    new Coordinate(0, 0)
};
var shell = factory.CreateLinearRing(shellCoords);

// 内环/孔（顺时针）
var holeCoords = new Coordinate[]
{
    new Coordinate(5, 5),
    new Coordinate(5, 15),
    new Coordinate(15, 15),
    new Coordinate(15, 5),
    new Coordinate(5, 5)
};
var hole = factory.CreateLinearRing(holeCoords);

// 创建带孔多边形
var polygonWithHole = factory.CreatePolygon(shell, new[] { hole });

Console.WriteLine($"WKT: {polygonWithHole.AsText()}");
Console.WriteLine($"外环面积: 400");
Console.WriteLine($"内环面积: 100");
Console.WriteLine($"实际面积: {polygonWithHole.Area}");  // 300（400 - 100）
Console.WriteLine($"内环数量: {polygonWithHole.NumInteriorRings}");  // 1
```

### 3.6.3 多边形的属性和方法

```csharp
var shell = factory.CreateLinearRing(new Coordinate[]
{
    new Coordinate(0, 0), new Coordinate(20, 0),
    new Coordinate(20, 20), new Coordinate(0, 20), new Coordinate(0, 0)
});
var hole = factory.CreateLinearRing(new Coordinate[]
{
    new Coordinate(5, 5), new Coordinate(5, 15),
    new Coordinate(15, 15), new Coordinate(15, 5), new Coordinate(5, 5)
});
var polygon = factory.CreatePolygon(shell, new[] { hole });

// 基本属性
Console.WriteLine($"几何类型: {polygon.GeometryType}");         // Polygon
Console.WriteLine($"面积: {polygon.Area}");                     // 300
Console.WriteLine($"周长: {polygon.Length}");                   // 120（外环80 + 内环40）
Console.WriteLine($"维度: {polygon.Dimension}");                // 2

// 环信息
Console.WriteLine($"外环: {polygon.ExteriorRing.AsText()}");
Console.WriteLine($"内环数量: {polygon.NumInteriorRings}");     // 1
Console.WriteLine($"内环[0]: {polygon.GetInteriorRingN(0).AsText()}");

// 点数量
Console.WriteLine($"总点数: {polygon.NumPoints}");              // 10

// 质心和内部点
Console.WriteLine($"质心: {polygon.Centroid.AsText()}");
Console.WriteLine($"内部点: {polygon.InteriorPoint.AsText()}");

// 边界
Console.WriteLine($"边界: {polygon.Boundary.AsText()}");        // 外环和内环组成的 MultiLineString

// 外包矩形
Console.WriteLine($"外包矩形: {polygon.EnvelopeInternal}");
```

### 3.6.4 多边形验证

```csharp
// 创建有效多边形
var validPolygon = factory.CreatePolygon(new Coordinate[]
{
    new Coordinate(0, 0), new Coordinate(10, 0),
    new Coordinate(10, 10), new Coordinate(0, 10), new Coordinate(0, 0)
});
Console.WriteLine($"有效多边形: {validPolygon.IsValid}");  // true

// 创建自相交多边形（无效）
var selfIntersecting = factory.CreatePolygon(new Coordinate[]
{
    new Coordinate(0, 0), new Coordinate(10, 10),
    new Coordinate(10, 0), new Coordinate(0, 10), new Coordinate(0, 0)
});
Console.WriteLine($"自相交多边形: {selfIntersecting.IsValid}");  // false

// 获取无效原因
var validator = new NetTopologySuite.Operation.Valid.IsValidOp(selfIntersecting);
var error = validator.ValidationError;
if (error != null)
{
    Console.WriteLine($"错误类型: {error.ErrorType}");
    Console.WriteLine($"错误位置: {error.Coordinate}");
    Console.WriteLine($"错误信息: {error.Message}");
}

// 修复无效多边形
var buffer0 = selfIntersecting.Buffer(0);
Console.WriteLine($"修复后有效: {buffer0.IsValid}");
```

## 3.7 MultiPoint 多点

```csharp
var factory = new GeometryFactory(new PrecisionModel(), 4326);

var multiPoint2 = factory.CreateMultiPointFromCoords(coords);
```

```csharp
// 访问单个点
for (int i = 0; i < multiPoint.NumGeometries; i++)
```

## 3.8 MultiLineString 多线

### 3.8.1 创建多线

```csharp
var factory = new GeometryFactory();

// 创建多条线
var line1 = factory.CreateLineString(new Coordinate[]
```

```csharp
// 访问单条线
for (int i = 0; i < multiLine.NumGeometries; i++)
```

## 3.10 GeometryCollection 几何集合

```csharp
var factory = new GeometryFactory();

// 创建不同类型的几何

var collection = factory.CreateGeometryCollection(new Geometry[]

```

```csharp
// 遍历所有几何
foreach (var geom in collection.Geometries)

var points = collection.Geometries.OfType<Point>().ToList();
```

## 3.11 GeometryFactory 详解

### 3.11.1 工厂配置

```csharp
// 1. 默认工厂
var defaultFactory = new GeometryFactory();

// 2. 带精度模型的工厂
var precisionModel = new PrecisionModel(1000);  // 保留3位小数
var precisionFactory = new GeometryFactory(precisionModel);

// 3. 带 SRID 的工厂
var wgs84Factory = new GeometryFactory(new PrecisionModel(), 4326);

// 4. 完整配置的工厂
var fullFactory = new GeometryFactory(
    precisionModel: new PrecisionModel(10000),
    srid: 4326,
    coordinateSequenceFactory: new CoordinateArraySequenceFactory()
);

// 5. 使用全局服务获取工厂
var serviceFactory = NtsGeometryServices.Instance.CreateGeometryFactory(srid: 4326);
```

### 3.11.2 全局几何服务

```csharp
// 配置全局服务
var services = new NtsGeometryServices(
    coordinateSequenceFactory: CoordinateArraySequenceFactory.Instance,
    precisionModel: new PrecisionModel(1000),
    srid: 4326
);

// 获取默认工厂
var factory = services.CreateGeometryFactory();

// 获取指定 SRID 的工厂
var factory3857 = services.CreateGeometryFactory(3857);

// 获取指定精度的工厂
var factoryPrecise = services.CreateGeometryFactory(
    new PrecisionModel(10000), 4326);
```

### 3.11.3 工厂方法概览

```csharp
var factory = new GeometryFactory(new PrecisionModel(), 4326);

// 点
var point = factory.CreatePoint(new Coordinate(0, 0));
var multiPoint = factory.CreateMultiPoint(new[] { point });
var multiPointFromCoords = factory.CreateMultiPointFromCoords(new[] 
{ 
    new Coordinate(0, 0), new Coordinate(1, 1) 
});

// 线
var lineString = factory.CreateLineString(new[] 
{ 
    new Coordinate(0, 0), new Coordinate(10, 10) 
});
var linearRing = factory.CreateLinearRing(new[] 
{ 
    new Coordinate(0, 0), new Coordinate(10, 0), 
    new Coordinate(10, 10), new Coordinate(0, 0) 
});
var multiLineString = factory.CreateMultiLineString(new[] { lineString });

// 多边形
var polygon = factory.CreatePolygon(linearRing);
var polygonWithHoles = factory.CreatePolygon(linearRing, new LinearRing[] { });
var multiPolygon = factory.CreateMultiPolygon(new[] { polygon });

// 几何集合
var collection = factory.CreateGeometryCollection(new Geometry[] 
{ 
    point, lineString, polygon 
});

// 空几何
var emptyPoint = factory.CreateEmpty(Dimension.Point);
var emptyLine = factory.CreateEmpty(Dimension.Curve);
var emptyPolygon = factory.CreateEmpty(Dimension.Surface);
```

## 3.12 PrecisionModel 精度模型

### 3.12.1 精度模型类型

```csharp
// 1. 浮点精度（默认，最高精度）
var floating = new PrecisionModel(PrecisionModels.Floating);

// 2. 单精度浮点
var floatingSingle = new PrecisionModel(PrecisionModels.FloatingSingle);

// 3. 固定精度（指定比例因子）
var fixed1 = new PrecisionModel(1);      // 整数精度
var fixed10 = new PrecisionModel(10);    // 1位小数
var fixed100 = new PrecisionModel(100);  // 2位小数
var fixed1000 = new PrecisionModel(1000); // 3位小数

Console.WriteLine($"浮点精度类型: {floating.PrecisionModelType}");
Console.WriteLine($"固定精度比例: {fixed1000.Scale}");
```

### 3.12.2 精度的影响

```csharp
// 使用不同精度创建工厂
var highPrecision = new GeometryFactory(new PrecisionModel());
var lowPrecision = new GeometryFactory(new PrecisionModel(100));

// 创建坐标
var coord = new Coordinate(1.23456789, 2.98765432);

var pointHigh = highPrecision.CreatePoint(coord);
var pointLow = lowPrecision.CreatePoint(coord);

Console.WriteLine($"高精度: {pointHigh.AsText()}");  // POINT (1.23456789 2.98765432)
Console.WriteLine($"低精度: {pointLow.AsText()}");   // POINT (1.23 2.99)

// 精度对计算的影响
var line = highPrecision.CreateLineString(new[]
{
    new Coordinate(0, 0),
    new Coordinate(1.111111, 1.111111)
});
Console.WriteLine($"长度（高精度）: {line.Length}");

var lineLow = lowPrecision.CreateLineString(new[]
{
    new Coordinate(0, 0),
    new Coordinate(1.111111, 1.111111)
});
Console.WriteLine($"长度（低精度）: {lineLow.Length}");
```
