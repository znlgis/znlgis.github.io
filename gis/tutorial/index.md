## 🎯 推荐学习路线

### 🌱 GIS 入门路线
1. [QGIS 教程](qgis/) — 桌面 GIS 基础
2. [GDAL 教程](gdal/) — 数据处理引擎
3. [PostGIS 教程](postgis/) — 空间数据库
4. [GeoServer 教程](geoserver/) — 地图服务发布
5. [OpenLayers 教程](openlayers/) — WebGIS 开发

### 🔧 Java GIS 开发路线
1. [GeoTools 教程](geotools/) — Java GIS 工具包
2. [Geometry API Java](geometry-api-java/) — Esri 几何操作
3. [OpenGIS Utils Java](opengis-utils-for-java/) — Java GIS 工具库
4. [GeoServer 教程](geoserver/) — 服务端开发

### 💻 .NET GIS 开发路线
1. [NetTopologySuite](NetTopologySuite/) — .NET 空间计算
2. [GDAL C# 绑定](gdal/) — 数据读写
3. [OpenGIS Utils .NET](opengis-utils-for-net/) — GIS 工具库
4. [SharpMap](SharpMap/) / [Mapsui](Mapsui/) — 地图渲染

### 🐍 Python GIS 路线
1. [GDAL Python](gdal/) — 数据处理
2. [Shapely 教程](shapely/) — 几何操作
3. [GeoPandas 教程](geopandas/) — 数据分析
4. [GeoPipeAgent](GeoPipeAgent/) — AI 流水线
