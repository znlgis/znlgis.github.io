# GIS 技术教程

本栏目收录 GIS（地理信息系统）开发相关的完整技术教程，涵盖数据处理、空间数据库、地图服务、WebGIS 和三维可视化等领域。

## 🎯 推荐学习路线

### 🌱 GIS 入门路线
1. [QGIS 教程](https://znlgis.github.io/gis/tutorial/qgis/) — 桌面 GIS 基础
2. [GDAL 教程](https://znlgis.github.io/gis/tutorial/gdal/) — 数据处理引擎
3. [PostGIS 教程](https://znlgis.github.io/gis/tutorial/postgis/) — 空间数据库
4. [GeoServer 教程](https://znlgis.github.io/gis/tutorial/geoserver/) — 地图服务发布
5. [OpenLayers 教程](https://znlgis.github.io/gis/tutorial/openlayers/) — WebGIS 开发

### 🗺️ WebGIS 前端进阶路线
1. [OpenLayers 教程](https://znlgis.github.io/gis/tutorial/openlayers/) — 传统栅格/矢量地图
2. [Leaflet 教程](https://znlgis.github.io/gis/tutorial/Leaflet/) — 轻量地图与插件生态
3. [MapLibre GL JS 教程](https://znlgis.github.io/gis/tutorial/maplibre-gl-js/) — 矢量瓦片与 GPU 渲染
4. [MapLibre Native 教程](https://znlgis.github.io/gis/tutorial/maplibre-native/) — 移动端与桌面端原生渲染
5. [影像云原生全链路](https://znlgis.github.io/gis/tutorial/STAC-COG-TiTiler/) — 影像服务端上线

### ☁️ 云原生与点云路线
1. [GDAL 教程](https://znlgis.github.io/gis/tutorial/gdal/) — 栅格/矢量数据处理
2. [影像云原生全链路](https://znlgis.github.io/gis/tutorial/STAC-COG-TiTiler/) — STAC 编目 + COG 存储 + TiTiler 出图
3. [PDAL 教程](https://znlgis.github.io/gis/tutorial/PDAL/) — 点云 ETL 与流水线
4. [PostGIS 教程](https://znlgis.github.io/gis/tutorial/postgis/) — 空间入库与查询
5. [CesiumJS 教程](https://znlgis.github.io/gis/tutorial/cesium/) — 三维发布与可视化

### 🔧 Java GIS 开发路线
1. [JTS 教程](https://znlgis.github.io/gis/tutorial/jts/) — Java 拓扑套件·几何引擎
2. [GeoTools 教程](https://znlgis.github.io/gis/tutorial/geotools/) — Java GIS 工具包
3. [Geometry API Java](https://znlgis.github.io/gis/tutorial/geometry-api-java/) — Esri 几何操作
4. [OpenGIS Utils Java](https://znlgis.github.io/gis/tutorial/opengis-utils-for-java/) — Java GIS 工具库
5. [GeoServer 教程](https://znlgis.github.io/gis/tutorial/geoserver/) — 服务端开发

### 💻 .NET GIS 开发路线
1. [NetTopologySuite](https://znlgis.github.io/gis/tutorial/NetTopologySuite/) — .NET 空间计算
2. [GDAL C# 绑定](https://znlgis.github.io/gis/tutorial/gdal/) — 数据读写
3. [OpenGIS Utils .NET](https://znlgis.github.io/gis/tutorial/opengis-utils-for-net/) — GIS 工具库
4. [SharpMap](https://znlgis.github.io/gis/tutorial/SharpMap/) / [Mapsui](https://znlgis.github.io/gis/tutorial/Mapsui/) — 地图渲染

### 🛰️ 空间智能实战路线
1. [第01章：Vibe Coding 与 DeepSeek Harness](https://znlgis.github.io/gis/tutorial/kjzn/第01章-Vibe-Coding基础与DeepSeek-Harness上手/) — 建立以 agent 为中心的开发方式
2. [第02章：低空 AI 巡检实战](https://znlgis.github.io/gis/tutorial/kjzn/第02章-低空AI巡检实战/) — 上云 API 2 · YOLO26 · SAM 3.1
3. [第03章：空地一体时空融合](https://znlgis.github.io/gis/tutorial/kjzn/第03章-空地一体时空融合/) — 时空基准 · AR 投影 · 3D Tiles / splat LOD
4. [第04章：一张图「智能体」实战](https://znlgis.github.io/gis/tutorial/kjzn/第04章-一张图智能体实战/) — Function Calling 与 MCP 2026-07-28
5. [第05章：自动驾驶实战](https://znlgis.github.io/gis/tutorial/kjzn/第05章-自动驾驶实战/) — YOLO26 导航线 · CARLA · Cesium 1.147 仿真
6. [第06章：构建 3DGS](https://znlgis.github.io/gis/tutorial/kjzn/第06章-构建3DGS/) — COLMAP / VGGT-Omega → brush / gsplat → SuperSplat
7. [第07章：大模型微调](https://znlgis.github.io/gis/tutorial/kjzn/第07章-大模型微调/) — SAM 3.1 · Qwen3-VL · 蒸馏小模型
8. [第08章：空间数据底座与时空基准](https://znlgis.github.io/gis/tutorial/kjzn/第08章-空间数据底座与时空基准/) — PostGIS 3.7 · STAC 1.1 · GeoParquet / DuckDB
9. [第09章：边缘推理与端云协同部署](https://znlgis.github.io/gis/tutorial/kjzn/第09章-边缘推理与端云协同部署/) — Jetson Thor · TensorRT 11 · 端云切分
10. [第10章：智能体评测与生产上线](https://znlgis.github.io/gis/tutorial/kjzn/第10章-智能体评测与生产上线/) — 评测集 · 回归门禁 · 灰度与复盘
11. [第11章：工程化交付与验收](https://znlgis.github.io/gis/tutorial/kjzn/第11章-工程化交付与验收/) — 交付物清单 · 验收指标 · SLA
12. [第12章：空间智能技术路线与展望](https://znlgis.github.io/gis/tutorial/kjzn/第12章-空间智能技术路线与展望/) — 选型矩阵 · 趋势判断 · 行动建议

### 🐍 Python GIS 路线
1. [GDAL Python](https://znlgis.github.io/gis/tutorial/gdal/) — 数据处理
2. [Shapely 教程](https://znlgis.github.io/gis/tutorial/shapely/) — 几何操作
3. [GeoPandas 教程](https://znlgis.github.io/gis/tutorial/geopandas/) — 数据分析
4. [GeoPipeAgent](https://znlgis.github.io/gis/tutorial/GeoPipeAgent/) — AI 流水线
