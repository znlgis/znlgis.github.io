# PDAL 教程目录

PDAL（Point Data Abstraction Library）是点云领域的“GDAL”，提供统一的读写抽象、流水线式处理框架与多语言绑定。本系列共 20 章，从 LAS/LAZ 数据模型、Pipeline JSON、滤波与地面分类，讲到 Entwine/EPT 索引、Python/C++ 开发与海量点云工程实践。
