# 第12章：空间分析与测量

## 12.1 距离测量

测量功能看着简单，实质上是“选什么几何口径”的问题。同一对坐标，沿椭球面走、沿三维空间直线走、沿地形表面走，结果可以相差百分之几到百分之几十。Cesium 提供的 API 分别对应这几种口径，选错一个，量出来的数字就对不上业务预期。

另一个共性的前提是坐标从哪来。用鼠标点出来的位置是屏幕坐标经过深度缓冲反算的三维点，精度受相机距离和地形分辨率限制；用业务数据算出来的位置是明确的经纬度。测量工具的正确性首先取决于取点方式，公式本身的误差通常更小。

### 12.1.1 两点间距离

`calculateDistance` 先把经纬高转换成 `Cartesian3`（地心直角坐标），再调用 `Cesium.Cartesian3.distance` 求两点在三维空间中的欧氏距离。这条线段穿过地球内部，是一条弦，不是贴着地表走的弧。两点距离越远、夹角越大，弦和弧的差距越明显：北京到上海一千公里量级，两者相差不到 1 公里，肉眼无感；跨半球两万公里，差距可以达到数百公里。所以这个函数只适合小范围、对精度不敏感的场合，比如估算两点间直线飞行距离的粗略值。

`calculateSurfaceDistance` 用 `EllipsoidGeodesic` 求椭球面上的大地线长度，`surfaceDistance` 属性的单位是米。大地线是椭球面上两点间的最短路径，航空、航海、管线长度的业务口径都按这个算。构造 `EllipsoidGeodesic` 需要的是 `Cartographic`（弧度制的经纬度），不是 `Cartesian3`，所以示例里用 `Cartographic.fromDegrees` 而不是 `Cartesian3.fromDegrees`——这两个工厂方法的名字很像，传错类型不会编译报错，运行时才能发现 `surfaceDistance` 是 NaN。

`EllipsoidGeodesic` 还提供 `startHeading` 与 `endHeading`，即起点和终点处的大地线方位角（弧度，从正北顺时针），量测工具里显示“方向”用的就是它。大地线在长距离上不是一条恒向线，起点方位与终点方位不同，这正是“大圆航线”在地图上看起来像弧线的原因。

示例最后把米换算成公里显示，只保留两位小数。显示精度要和数据精度匹配：GPS 定位精度在米级，坐标保留六位小数（约 0.1 米）已经足够，多出来的位数是虚假精度。

```javascript
// 计算两点间直线距离
function calculateDistance(point1, point2) {
    const cartesian1 = Cesium.Cartesian3.fromDegrees(point1.lon, point1.lat, point1.height || 0);
    const cartesian2 = Cesium.Cartesian3.fromDegrees(point2.lon, point2.lat, point2.height || 0);
    return Cesium.Cartesian3.distance(cartesian1, cartesian2);
}

// 计算地表距离（大地线）
function calculateSurfaceDistance(point1, point2) {
    const geodesic = new Cesium.EllipsoidGeodesic(
        Cesium.Cartographic.fromDegrees(point1.lon, point1.lat),
        Cesium.Cartographic.fromDegrees(point2.lon, point2.lat)
    );
    return geodesic.surfaceDistance;  // 米
}

// 使用示例
const dist = calculateDistance(
    { lon: 116.4, lat: 39.9 },
    { lon: 121.5, lat: 31.2 }
);
console.log('距离:', (dist / 1000).toFixed(2), 'km');
```

### 12.1.2 折线长度测量

`measurePolylineLength` 把折线拆成若干段，逐段求 `Cartesian3.distance` 再累加。这仍然是空间直线口径：每段都是弦，地形起伏被完全忽略，山谷里的盘山公路这样量会明显偏短。要量“贴地长度”，得先把折线按地形采样加密——用 `sampleTerrainMostDetailed` 给每个点补上地形高程，中间再插值若干点，然后逐段累加。代价是接口调用次数和计算量大幅上升，交互式测量里通常不这么做，只在最终出报告时计算一次。

`DistanceMeasureTool` 是一个完整的交互式测量类，值得逐块拆开看。构造函数里创建 `ScreenSpaceEventHandler`，绑定到 `viewer.canvas` 上，这样只有鼠标落在地图画布内才会触发；绑在 `document` 上会把侧边栏、弹窗上的点击也吃进来。`measureEntities` 数组保存所有绘制出来的临时图元，是后续清理的依据。

`start` 里注册了两个输入动作：左键点击取点，右键结束。取点用 `viewer.scene.pickPosition(click.position)`，它从深度缓冲反算该屏幕位置对应的三维坐标，能拾取到地形、模型、3D Tiles 的表面。前提是深度纹理可用，浏览器或显卡不支持时 `pickPosition` 会返回 undefined，`Cesium.defined` 的判断就是在过滤这种情况；更主动的做法是先检查 `viewer.scene.pickPositionSupported`。返回值未定义时静默跳过，用户只会觉得“点了没反应”，所以界面上应当给一个提示。

`updateLine` 每次都把旧的折线移除、新建一条包含全部点的折线，`addPoint` 新加的圆点则一直保留。这种“重建”写法在点数不多时最简单，点多了每加一个点就要重建整条线，可以改成固定两条 entity：已确定的部分用 `polyline.positions` 直接改，未确定的部分跟随鼠标。注意 `measureEntities.find(e => e.polyline)` 只能找到第一条折线，如果以后加了多条测量线段，这个查找会失效，改成单独保存引用更稳。

`showDistance` 每次左键都在最新点上加一个标签，所以拖出十几个点时屏幕上会叠着十几个距离值，越往后越乱。交互式工具的常规做法是复用同一个标签，每次更新它的 `position` 与 `text`，只在测量结束时固化一次。`formatDistance` 按公里/米自动切换单位，这个细节值得保留，量测结果的单位不统一是用户投诉的常见来源。

`stop` 只移除了输入动作，没有清理已经画出来的图元，也没有销毁 handler。这个设计意味着“结束测量”和“清除测量”是两件事，调用方要自己再调 `clearMeasureEntities`；`handler` 仍然占用着 canvas 的事件，需要彻底回收时应在 `stop` 之后 `handler.destroy()`。另外从示例代码的 `this.positions` 看，坐标是直接存的 `Cartesian3`，业务上要保存测量结果的话，得在结束前转成经纬度，否则换一个场景坐标系就对不上了。

```javascript
// 测量折线总长度
function measurePolylineLength(positions) {
    let totalDistance = 0;
    for (let i = 0; i < positions.length - 1; i++) {
        totalDistance += Cesium.Cartesian3.distance(positions[i], positions[i + 1]);
    }
    return totalDistance;
}

// 交互式测量工具
class DistanceMeasureTool {
    constructor(viewer) {
        this.viewer = viewer;
        this.positions = [];
        this.handler = new Cesium.ScreenSpaceEventHandler(viewer.canvas);
        this.measureEntities = [];
    }
    
    start() {
        this.positions = [];
        this.clearMeasureEntities();
        
        // 左键添加点
        this.handler.setInputAction((click) => {
            const position = this.viewer.scene.pickPosition(click.position);
            if (Cesium.defined(position)) {
                this.positions.push(position);
                this.addPoint(position);
                
                if (this.positions.length > 1) {
                    this.updateLine();
                    this.showDistance();
                }
            }
        }, Cesium.ScreenSpaceEventType.LEFT_CLICK);
        
        // 右键结束
        this.handler.setInputAction(() => {
            this.stop();
        }, Cesium.ScreenSpaceEventType.RIGHT_CLICK);
    }
    
    addPoint(position) {
        const entity = this.viewer.entities.add({
            position: position,
            point: { pixelSize: 8, color: Cesium.Color.RED }
        });
        this.measureEntities.push(entity);
    }
    
    updateLine() {
        // 移除旧线
        const oldLine = this.measureEntities.find(e => e.polyline);
        if (oldLine) this.viewer.entities.remove(oldLine);
        
        const entity = this.viewer.entities.add({
            polyline: {
                positions: this.positions,
                width: 3,
                material: Cesium.Color.YELLOW
            }
        });
        this.measureEntities.push(entity);
    }
    
    showDistance() {
        const distance = measurePolylineLength(this.positions);
        const lastPos = this.positions[this.positions.length - 1];
        
        const entity = this.viewer.entities.add({
            position: lastPos,
            label: {
                text: this.formatDistance(distance),
                font: '14px sans-serif',
                fillColor: Cesium.Color.WHITE,
                showBackground: true,
                pixelOffset: new Cesium.Cartesian2(0, -20)
            }
        });
        this.measureEntities.push(entity);
    }
    
    formatDistance(meters) {
        if (meters >= 1000) {
            return (meters / 1000).toFixed(2) + ' km';
        }
        return meters.toFixed(2) + ' m';
    }
    
    stop() {
        this.handler.removeInputAction(Cesium.ScreenSpaceEventType.LEFT_CLICK);
        this.handler.removeInputAction(Cesium.ScreenSpaceEventType.RIGHT_CLICK);
    }
    
    clearMeasureEntities() {
        this.measureEntities.forEach(e => this.viewer.entities.remove(e));
        this.measureEntities = [];
    }
}

// 使用
const distanceTool = new DistanceMeasureTool(viewer);
distanceTool.start();
```

## 12.2 面积测量

面积比距离更容易出偏差，因为它对坐标的假设更敏感：同样的多边形，在球面上算、在某个投影平面上算、在局部切平面上算，结果都不同。选择哪种算法，取决于多边形的尺度——小区、地块用平面近似没有明显误差；省级、国家级范围必须用椭球或球面公式。

### 12.2.1 多边形面积计算

`calculatePolygonArea` 的步骤是：求所有顶点的包围球中心，以该点为原点建立东北天局部坐标系，把顶点变换到这个坐标系下，再用鞋带公式求平面多边形面积。`Transforms.eastNorthUpToFixedFrame(center)` 生成的矩阵把局部坐标转到地心坐标，取逆矩阵就把地心坐标拉回局部平面；`Matrix4.multiplyByPoint` 逐点变换。东北天坐标系里 x 轴指向东、y 轴指向北、z 轴指向天顶，所以取 x、y 分量做鞋带公式，等于把多边形投影到该点的切平面上。

鞋带公式（shoelace formula）遍历相邻顶点，累加 `x_i * y_{i+1} - x_{i+1} * y_i`，最后取绝对值除以 2。它对顶点顺序不敏感，顺时针、逆时针都能算对面积；但要求多边形不自交，自交的多边形会算出正负抵消后的净值，这是算法本身的限制，不是实现错误。顶点必须闭合吗？鞋带公式里用了 `(i + 1) % length`，最后一个点自动连回第一个点，示例传入的首尾不重复的数组是正确的，如果调用方传入了首尾相同的闭合数组，会多算一次零长度边，结果不变但没必要。

局部平面近似的误差随范围平方增长。以切点为圆心，半径 10 公里内（约一个城区）误差在十万分之一量级，可以忽略；半径 100 公里以上（一个地级市）误差进入千分之几；跨省范围用这种方法算出来的数字没有参考价值。判断标准是“多边形的外接圆半径与该点地球曲率半径之比”，比值超过 1% 就必须换椭球算法。

`calculateAreaWithTurf` 交给 Turf.js 的 `turf.area`，它按球面（或配置的椭球）计算，适合跨大范围的面积统计。注意代码里把坐标闭合了一次（`coordinates.push(coordinates[0])`），因为 GeoJSON 的 LinearRing 要求首尾相同；如果传入的 `positions` 本身已经是闭合的，就会多出一个重复点，Turf 能容忍但不规范。动态 `import` 让 Turf 成为按需加载的依赖，只在用户触发面积计算时才下载，这是打包体积敏感的项目里值得保留的写法。

```javascript
// 计算多边形面积（平面近似）
function calculatePolygonArea(positions) {
    const cartographics = positions.map(p => Cesium.Cartographic.fromCartesian(p));
    
    // 转换为平面坐标
    const center = Cesium.BoundingSphere.fromPoints(positions).center;
    const transform = Cesium.Transforms.eastNorthUpToFixedFrame(center);
    const inverseTransform = Cesium.Matrix4.inverse(transform, new Cesium.Matrix4());
    
    const localPositions = positions.map(p => {
        return Cesium.Matrix4.multiplyByPoint(inverseTransform, p, new Cesium.Cartesian3());
    });
    
    // 鞋带公式
    let area = 0;
    for (let i = 0; i < localPositions.length; i++) {
        const j = (i + 1) % localPositions.length;
        area += localPositions[i].x * localPositions[j].y;
        area -= localPositions[j].x * localPositions[i].y;
    }
    
    return Math.abs(area) / 2;
}

// 使用 Turf.js 计算更精确的面积
async function calculateAreaWithTurf(positions) {
    // 需要引入 Turf.js: npm install @turf/turf
    const turf = await import('@turf/turf');
    
    const coordinates = positions.map(p => {
        const c = Cesium.Cartographic.fromCartesian(p);
        return [Cesium.Math.toDegrees(c.longitude), Cesium.Math.toDegrees(c.latitude)];
    });
    coordinates.push(coordinates[0]); // 闭合
    
    const polygon = turf.polygon([coordinates]);
    return turf.area(polygon);  // 平方米
}
```

### 12.2.2 交互式面积测量

`AreaMeasureTool` 比距离工具多了鼠标移动的实时预览：每移动一次就把当前点拼到已确定的点后面，重画一个临时多边形，用户能直观看到“再点一下会围出什么样的形状”。预览用的是同一个 `tempPolygon` 实体，`updateTempPolygon` 里通过修改 `polygon.hierarchy` 更新顶点，而不是每次删了重建——这是比距离工具更省的做法，值得作为模板。

`updatePolygon` 在点数达到三个之后才渲染正式多边形，这个判断很重要：两个点连不成面，`polygon.hierarchy` 收到两个顶点时 Cesium 会在内部尝试三角化，可能抛出异常或者画出退化的图元。三个点是构成面的下限。

这段代码有一处明显的资源管理缺陷：`updatePolygon` 移除旧多边形后没有把它从 `measureEntities` 数组里删掉，新多边形又 push 进去，数组会不断变长，`clearMeasureEntities` 遍历时对已经被移除的实体再次调用 `remove`。Cesium 对移除不存在的实体会记录一条警告，量大的话控制台会被刷屏，清理逻辑也会变慢。正确做法是把 `tempPolygon` 单独管理，数组里只放“一旦结束就固化”的图元。

`finish` 用 `BoundingSphere.fromPoints(...).center` 求多边形的包围球中心，把面积标签放在那里。对凹多边形，包围球中心可能落在图形外面，标签会飘在空白处；更稳的位置是顶点平均值或者多边形的重心。面积单位在平方米与平方公里之间自动切换，与距离工具的做法一致。

`stop` 只移除了三个输入动作，`tempPolygon` 保持原样留在场景里。这是有意的——测量结束时用户需要看到结果；但要在“下一次开始测量”时清理干净，`start` 里调用了 `clearMeasureEntities` 并在其中把 `tempPolygon` 置空，闭环是完整的。执行顺序上，`finish` 先加标签再 `stop`，如果顺序反过来，输入动作已经移除、标签仍会加上，结果一样，但代码意图会变得难读。

交互式面积测量还有个体验问题：用户点完最后一个点通常希望“双击结束”或“点回起点闭合”，示例只支持右键。右键在某些浏览器里会弹出上下文菜单，需要额外 `preventDefault` 或者在创建 Viewer 时关掉 `contextmenu` 相关的默认行为，否则用户右键时菜单会盖住地图。

```javascript
class AreaMeasureTool {
    constructor(viewer) {
        this.viewer = viewer;
        this.positions = [];
        this.handler = new Cesium.ScreenSpaceEventHandler(viewer.canvas);
        this.measureEntities = [];
        this.tempPolygon = null;
    }
    
    start() {
        this.positions = [];
        this.clearMeasureEntities();
        
        // 左键添加点
        this.handler.setInputAction((click) => {
            const position = this.viewer.scene.pickPosition(click.position);
            if (Cesium.defined(position)) {
                this.positions.push(position);
                this.addPoint(position);
                this.updatePolygon();
            }
        }, Cesium.ScreenSpaceEventType.LEFT_CLICK);
        
        // 鼠标移动
        this.handler.setInputAction((movement) => {
            if (this.positions.length >= 2) {
                const position = this.viewer.scene.pickPosition(movement.endPosition);
                if (Cesium.defined(position)) {
                    this.updateTempPolygon(position);
                }
            }
        }, Cesium.ScreenSpaceEventType.MOUSE_MOVE);
        
        // 右键结束
        this.handler.setInputAction(() => {
            if (this.positions.length >= 3) {
                this.finish();
            }
        }, Cesium.ScreenSpaceEventType.RIGHT_CLICK);
    }
    
    addPoint(position) {
        const entity = this.viewer.entities.add({
            position: position,
            point: { pixelSize: 8, color: Cesium.Color.RED }
        });
        this.measureEntities.push(entity);
    }
    
    updatePolygon() {
        if (this.positions.length < 3) return;
        
        // 移除旧多边形
        if (this.tempPolygon) {
            this.viewer.entities.remove(this.tempPolygon);
        }
        
        this.tempPolygon = this.viewer.entities.add({
            polygon: {
                hierarchy: this.positions,
                material: Cesium.Color.YELLOW.withAlpha(0.3),
                outline: true,
                outlineColor: Cesium.Color.YELLOW
            }
        });
        this.measureEntities.push(this.tempPolygon);
    }
    
    updateTempPolygon(mousePosition) {
        if (this.positions.length < 2) return;
        
        const tempPositions = [...this.positions, mousePosition];
        
        if (this.tempPolygon) {
            this.tempPolygon.polygon.hierarchy = tempPositions;
        } else {
            this.tempPolygon = this.viewer.entities.add({
                polygon: {
                    hierarchy: tempPositions,
                    material: Cesium.Color.YELLOW.withAlpha(0.3),
                    outline: true,
                    outlineColor: Cesium.Color.YELLOW
                }
            });
            this.measureEntities.push(this.tempPolygon);
        }
    }
    
    finish() {
        const area = calculatePolygonArea(this.positions);
        const center = Cesium.BoundingSphere.fromPoints(this.positions).center;
        
        const entity = this.viewer.entities.add({
            position: center,
            label: {
                text: this.formatArea(area),
                font: '16px sans-serif',
                fillColor: Cesium.Color.WHITE,
                showBackground: true,
                backgroundColor: Cesium.Color.BLACK.withAlpha(0.7)
            }
        });
        this.measureEntities.push(entity);
        
        this.stop();
    }
    
    formatArea(squareMeters) {
        if (squareMeters >= 1000000) {
            return (squareMeters / 1000000).toFixed(2) + ' km²';
        }
        return squareMeters.toFixed(2) + ' m²';
    }
    
    stop() {
        this.handler.removeInputAction(Cesium.ScreenSpaceEventType.LEFT_CLICK);
        this.handler.removeInputAction(Cesium.ScreenSpaceEventType.MOUSE_MOVE);
        this.handler.removeInputAction(Cesium.ScreenSpaceEventType.RIGHT_CLICK);
    }
    
    clearMeasureEntities() {
        this.measureEntities.forEach(e => this.viewer.entities.remove(e));
        this.measureEntities = [];
        this.tempPolygon = null;
    }
}
```

## 12.3 高度测量

高度测量要同时回答两个问题：被点的位置在多高、它离地面有多高。前者是绝对高程，后者是相对高差。Cesium 里的高度值默认是**椭球高**——相对于 WGS84 椭球面的高度，不是我们日常说的海拔（正高，相对于大地水准面）。全球范围内两者相差可以从 -100 米到 +80 米左右，在中国区域通常在几十米量级。做工程测量、报批材料时，这个差别不能忽略；只做三维展示、相对高差比较时可以接受。

理解这一点之后再看代码：`Cesium.Cartographic.fromCartesian(position)` 拿到的 `height` 就是椭球高，`scene.pickPosition` 返回的点也带着椭球高。后面采样地形得到的 `terrainHeight` 同样是地形瓦片里的椭球高，两者相减得到的相对高差是可靠的，因为基准一致；把任何一个值当“海拔”写进报告则是错的。

```javascript
// 高度测量工具
class HeightMeasureTool {
    constructor(viewer) {
        this.viewer = viewer;
        this.handler = new Cesium.ScreenSpaceEventHandler(viewer.canvas);
        this.measureEntities = [];
    }
    
    start() {
        this.handler.setInputAction((click) => {
            const position = this.viewer.scene.pickPosition(click.position);
            if (Cesium.defined(position)) {
                this.measureHeight(position);
            }
        }, Cesium.ScreenSpaceEventType.LEFT_CLICK);
    }
    
    async measureHeight(position) {
        const cartographic = Cesium.Cartographic.fromCartesian(position);
        const clickHeight = cartographic.height;
        
        // 采样地形高度
        const terrainPositions = [Cesium.Cartographic.fromRadians(
            cartographic.longitude, cartographic.latitude
        )];
        
        await Cesium.sampleTerrainMostDetailed(
            this.viewer.terrainProvider, terrainPositions
        );
        
        const terrainHeight = terrainPositions[0].height;
        const relativeHeight = clickHeight - terrainHeight;
        
        // 显示测量结果
        const groundPosition = Cesium.Cartesian3.fromRadians(
            cartographic.longitude, cartographic.latitude, terrainHeight
        );
        
        // 垂直线
        const lineEntity = this.viewer.entities.add({
            polyline: {
                positions: [groundPosition, position],
                width: 2,
                material: new Cesium.PolylineDashMaterialProperty({
                    color: Cesium.Color.YELLOW
                })
            }
        });
        this.measureEntities.push(lineEntity);
        
        // 标签
        const labelEntity = this.viewer.entities.add({
            position: position,
            label: {
                text: `海拔: ${clickHeight.toFixed(1)}m\n相对高度: ${relativeHeight.toFixed(1)}m`,
                font: '14px sans-serif',
                fillColor: Cesium.Color.WHITE,
                showBackground: true,
                pixelOffset: new Cesium.Cartesian2(10, 0)
            }
        });
        this.measureEntities.push(labelEntity);
    }
    
    stop() {
        this.handler.removeInputAction(Cesium.ScreenSpaceEventType.LEFT_CLICK);
    }
    
    clear() {
        this.measureEntities.forEach(e => this.viewer.entities.remove(e));
        this.measureEntities = [];
    }
}
```

## 12.4 坐标拾取

坐标拾取是量测工具的基础能力，几乎所有交互都要用它。Cesium 里有两条常用路线：`scene.pickPosition` 和 `camera.getPickRay` 配合 `globe.pick`。前者从深度缓冲反算三维点，能命中地形、模型、3D Tiles、甚至点图元；后者只用射线与椭球或地形求交，只能得到地表上的点，不会命中模型。

`CoordinatePickerTool` 选的是第二条路线，注释里写“优先拾取地形”。`camera.getPickRay(screenPosition)` 从相机出发穿过屏幕像素作一条射线，`scene.globe.pick(ray, scene)` 求这条射线与地表的交点。它的好处是不依赖深度纹理，兼容性更好；代价是在没有地形数据时只能得到椭球面上的点（高度为 0），模型悬空的部分点不到。

```javascript
// 坐标拾取工具
class CoordinatePickerTool {
    constructor(viewer) {
        this.viewer = viewer;
        this.handler = new Cesium.ScreenSpaceEventHandler(viewer.canvas);
        this.coordinateDisplay = null;
    }
    
    start() {
        // 创建坐标显示面板
        this.createDisplayPanel();
        
        // 鼠标移动实时显示
        this.handler.setInputAction((movement) => {
            const position = this.getPosition(movement.endPosition);
            if (position) {
                this.updateDisplay(position);
            }
        }, Cesium.ScreenSpaceEventType.MOUSE_MOVE);
        
        // 点击复制坐标
        this.handler.setInputAction((click) => {
            const position = this.getPosition(click.position);
            if (position) {
                this.copyToClipboard(position);
            }
        }, Cesium.ScreenSpaceEventType.LEFT_CLICK);
    }
    
    getPosition(screenPosition) {
        // 优先拾取地形
        const ray = this.viewer.camera.getPickRay(screenPosition);
        const position = this.viewer.scene.globe.pick(ray, this.viewer.scene);
        
        if (Cesium.defined(position)) {
            const cartographic = Cesium.Cartographic.fromCartesian(position);
            return {
                longitude: Cesium.Math.toDegrees(cartographic.longitude),
                latitude: Cesium.Math.toDegrees(cartographic.latitude),
                height: cartographic.height
            };
        }
        return null;
    }
    
    createDisplayPanel() {
        this.coordinateDisplay = document.createElement('div');
        this.coordinateDisplay.style.cssText = `
            position: absolute;
            bottom: 10px;
            left: 10px;
            background: rgba(0,0,0,0.7);
            color: white;
            padding: 10px;
            font-family: monospace;
            border-radius: 4px;
            z-index: 1000;
        `;
        this.viewer.container.appendChild(this.coordinateDisplay);
    }
    
    updateDisplay(position) {
        this.coordinateDisplay.innerHTML = `
            经度: ${position.longitude.toFixed(6)}°<br>
            纬度: ${position.latitude.toFixed(6)}°<br>
            高度: ${position.height.toFixed(2)} m<br>
            <small>点击复制坐标</small>
        `;
    }
    
    copyToClipboard(position) {
        const text = `${position.longitude.toFixed(6)}, ${position.latitude.toFixed(6)}, ${position.height.toFixed(2)}`;
        navigator.clipboard.writeText(text);
        console.log('坐标已复制:', text);
    }
    
    stop() {
        this.handler.removeInputAction(Cesium.ScreenSpaceEventType.MOUSE_MOVE);
        this.handler.removeInputAction(Cesium.ScreenSpaceEventType.LEFT_CLICK);
        if (this.coordinateDisplay) {
            this.coordinateDisplay.remove();
        }
    }
}
```

## 12.5 本章小结

这四类工具在工程落地时共同的注意点可以归成清单：取点环节要处理 `pickPosition` 返回 undefined 的情况，并在界面上给出反馈；距离要区分空间直线与椭球面大地线，不要把两者混用在同一份报告里；面积要按范围选择平面近似或球面算法，跨市域的面积不能套用局部切平面；高度要说明是椭球高还是海拔，报告里最好注明基准；所有临时图元、事件监听、handler 都要有对应的清理路径，测量工具反复开关时不残留。

另一个容易被忽略的工程问题是精度与显示。坐标保留六位小数约等于 0.1 米，高程保留一位小数约等于 0.1 米，超过这个量级的位数只是视觉噪音。测量结果导出成 CSV 或 GeoJSON 时，坐标用十进制度还是投影坐标、高程用什么基准，应当在导出的元数据里写清楚，否则下游无法复用。

本章介绍了空间分析与测量：

1. **距离测量**：直线距离、地表距离、交互式测量
2. **面积测量**：多边形面积计算、交互式测量
3. **高度测量**：海拔高度、相对高度
4. **坐标拾取**：实时显示、复制功能

在下一章中，我们将详细介绍动画与时间系统。
