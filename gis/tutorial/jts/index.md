# JTS 教程目录

JTS（Java Topology Suite）是 Java 平台上最核心的矢量几何引擎，也是 OGC Simple Features 规范的参考实现之一。本系列共 24 章，从几何模型、空间谓词、叠加分析一路讲到空间索引、三角剖分、源码编译与二次开发，兼顾“怎么用”与“怎么改”。

> **说明**：本教程基于 JTS 1.20 / 1.21 源码编写，示例代码以 `jts-core`、`jts-io-common` 两个模块为主，运行环境为 JDK 8 及以上。
