# 实用工具与最佳实践

## 概述

OGU4J提供了一系列实用工具类，用于处理常见的GIS开发任务。本章介绍这些工具的使用方法，并总结GIS开发的最佳实践。

## 实用工具类

### ZipUtil - 压缩解压工具

Shapefile等格式通常需要压缩传输：

```java
/**
 * 压缩文件夹
 */
ZipUtil.zip("data/shapefile_folder", "output.zip");

// 指定编码
ZipUtil.zip("data/shapefile_folder", "output.zip", StandardCharsets.UTF_8);

/**
 * 解压文件
 */
ZipUtil.unzip("input.zip", "output_folder");

// 指定编码
ZipUtil.unzip("input.zip", "output_folder", StandardCharsets.UTF_8);
```

**使用场景**：
- 打包Shapefile（.shp、.shx、.dbf、.prj等）
- Web服务返回压缩的地理数据
- 批量数据分发

### EncodingUtil - 编码检测工具

处理中文数据时，正确识别编码至关重要：

```java
/**
 * 自动检测文件编码
 */
File file = new File("data/attributes.dbf");
Charset charset = EncodingUtil.getFileEncoding(file);
System.out.println("检测到编码: " + charset.name());

/**
 * 读取文件（自动编码）
 */
String content = FileUtil.readString(file, charset);
```

**支持的编码**：
- UTF-8
- GBK / GB2312 / GB18030
- BIG5
- ISO-8859-1

### SortUtil - 自然排序工具

处理包含数字的字符串排序：

```java
/**
 * 自然排序比较
 */
int result = SortUtil.compareString("第5章", "第10章");
// 结果: -1（5 < 10）

// 标准字符串排序会得到错误结果
"第5章".compareTo("第10章");  // 正数（因为"5" > "1"）
```

**使用场景**：
- 图层名称排序
- 文件名排序
- 编号排序

```java
// 对图层名称进行自然排序
List<String> layerNames = Arrays.asList(
    "layer_1", "layer_2", "layer_10", "layer_20", "layer_3");

layerNames.sort(SortUtil::compareString);
// 结果: ["layer_1", "layer_2", "layer_3", "layer_10", "layer_20"]
```

### NumUtil - 数字格式化工具

处理大数或高精度数字：

```java
/**
 * 去除科学计数法显示
 */
double value = 1.234E10;
String plain = NumUtil.getPlainString(value);
System.out.println(plain);  // 12340000000

/**
 * 用于坐标输出
 */
double x = 3.945678901234E7;  // 投影坐标
String xStr = NumUtil.getPlainString(x);
System.out.println(xStr);  // 39456789.01234
```

**使用场景**：
- 国土TXT坐标输出
- 高精度坐标处理
- 大数面积显示

### GdalCmdUtil - GDAL命令行工具

获取GDB等数据源的结构信息：

```java
/**
 * 获取GDB数据结构
 */
GdbGroupModel structure = GdalCmdUtil.getGdbDataStructure("data/sample.gdb");

// 要素数据集
for (String dataset : structure.getFeatureDatasets()) {
    System.out.println("数据集: " + dataset);
}

// 要素类
for (String fc : structure.getFeatureClasses()) {
    System.out.println("要素类: " + fc);
}

// 独立表
for (String table : structure.getTables()) {
    System.out.println("表: " + table);
}
```

## 最佳实践

### 1. 坐标系处理

**原则**：始终明确数据的坐标系

```java
// 推荐：明确设置坐标系
layer.setWkid(4490);

// 推荐：处理前检查坐标系
if (layer.getWkid() == null) {
    throw new RuntimeException("坐标系未定义");
}

// 推荐：空间分析前统一坐标系
if (!layer1.getWkid().equals(layer2.getWkid())) {
    layer2 = CrsUtil.reproject(layer2, layer1.getWkid());
}
```

**面积计算**：

```java
// 正确做法：使用投影坐标系
public double calculateArea(String wkt, Integer wkid) {
    Geometry geom = GeometryConverter.wkt2Geometry(wkt);
    
    // 经纬度需转换到投影坐标系
    if (!CrsUtil.isProjectedCRS(wkid)) {
        int projWkid = CrsUtil.getProjectedWkid(geom);
        geom = CrsUtil.transform(geom, wkid, projWkid);
    }
    
    return geom.getArea();  // 结果为平方米
}
```

### 2. 几何有效性

**原则**：处理前验证几何，处理后再次验证

```java
/**
 * 安全的几何处理流程
 */
public Geometry safeProcess(String wkt) {
    Geometry geom = GeometryConverter.wkt2Geometry(wkt);
    
    // 1. 验证输入
    if (!geom.isValid()) {
        geom = JtsGeometryUtil.validate(geom);
    }
    
    // 2. 执行操作
    Geometry result = someOperation(geom);
    
    // 3. 验证输出
    if (!result.isValid()) {
        result = JtsGeometryUtil.validate(result);
    }
    
    return result;
}
```

### 3. 异常处理

**原则**：捕获并记录详细错误信息

```java
/**
 * 批量处理时的异常处理
 */
public void batchProcess(List<OguFeature> features) {
    List<String> errors = new ArrayList<>();
    
    for (OguFeature feature : features) {
        try {
            processFeature(feature);
        } catch (Exception e) {
            String msg = String.format(
                "要素 %s 处理失败: %s - WKT: %s",
                feature.getWfId(),
                e.getMessage(),
                feature.getWkt().substring(0, Math.min(100, feature.getWkt().length()))
            );
            errors.add(msg);
            log.error(msg, e);
        }
    }
    
    if (!errors.isEmpty()) {
        log.warn("处理完成，但有 " + errors.size() + " 个错误");
    }
}
```

### 4. 资源管理

**原则**：及时释放数据库连接和文件句柄

```java
/**
 * 使用try-with-resources管理资源
 */
public OguLayer readWithCleanup(DbConnBaseModel dbConn, String tableName) {
    DataStore dataStore = null;
    try {
        dataStore = PostgisUtil.getPostgisDataStore(dbConn);
        SimpleFeatureSource source = dataStore.getFeatureSource(tableName);
        SimpleFeatureCollection fc = source.getFeatures();
        return SimpleLayerConverter.fromSimpleFeatureCollection(fc);
    } finally {
        if (dataStore != null) {
            dataStore.dispose();
        }
    }
}
```

**原则**：使用数据库端过滤，避免内存中处理全量数据

```java

OguLayer layer = SimpleLayerConverter.fromPostGIS(
    dbConn, tableName, 
    "type = '住宅' AND area > 1000",  // 属性过滤

    dbConn, tableName, null, null, GisEngineType.GEOTOOLS);
List<OguFeature> filtered = all.filter(f -> 
    "住宅".equals(f.getValue("type")) &&

);
```

### 7. 数据验证

**原则**：输入验证和输出验证

```java
/**
 * 完整的数据验证
 */
public class DataValidator {
    
    public List<String> validate(OguLayer layer) {
        List<String> errors = new ArrayList<>();
        
        // 图层级验证
        if (layer.getWkid() == null) {
            errors.add("坐标系未定义");
        }
        if (layer.getFeatures() == null || layer.getFeatures().isEmpty()) {
            errors.add("图层无要素");
        }
        
        // 要素级验证
        for (OguFeature feature : layer.getFeatures()) {
            // 几何验证
            if (feature.getWkt() == null || feature.getWkt().isEmpty()) {
                errors.add("要素 " + feature.getWfId() + " 无几何");
                continue;
            }
            
            try {
                Geometry geom = GeometryConverter.wkt2Geometry(feature.getWkt());
                if (!geom.isValid()) {
                    errors.add("要素 " + feature.getWfId() + " 几何无效");
                }
            } catch (Exception e) {
                errors.add("要素 " + feature.getWfId() + " WKT解析失败");
            }
            
            // 属性验证
            for (OguField field : layer.getFields()) {
                if (field.isRequired()) {
                    Object value = feature.getValue(field.getYwName());
                    if (value == null) {
                        errors.add("要素 " + feature.getWfId() + 
                            " 缺少必填字段 " + field.getYwName());
                    }
                }
            }
        }
        
        return errors;
    }
}
```

## 典型工作流程

### 数据导入流程

```java
/**
 * 标准数据导入流程
 */
public void importData(String sourcePath, DbConnBaseModel dbConn, 
        String tableName, Integer targetWkid) {
    
    // 1. 读取源数据
    log.info("读取源数据: {}", sourcePath);
    OguLayer layer = SimpleLayerConverter.fromShapefile(
        sourcePath, null, null, GisEngineType.GEOTOOLS);
    log.info("读取完成, 要素数: {}", layer.getFeatures().size());
    
    // 2. 验证数据
    List<String> errors = new DataValidator().validate(layer);
    if (!errors.isEmpty()) {
        log.error("数据验证失败: {}", errors);
        throw new RuntimeException("数据验证失败");
    }
    
    // 3. 坐标转换
    if (!layer.getWkid().equals(targetWkid)) {
        log.info("坐标转换: {} -> {}", layer.getWkid(), targetWkid);
        layer = CrsUtil.reproject(layer, targetWkid);
    }
    
    // 4. 几何修复
    int fixedCount = 0;
    for (OguFeature feature : layer.getFeatures()) {
        Geometry geom = GeometryConverter.wkt2Geometry(feature.getWkt());
        if (!geom.isValid()) {
            geom = JtsGeometryUtil.validate(geom);
            feature.setWkt(geom.toText());
            fixedCount++;
        }
    }
    if (fixedCount > 0) {
        log.info("修复无效几何: {} 个", fixedCount);
    }
    
    // 5. 写入数据库
    log.info("写入数据库: {}", tableName);
    SimpleLayerConverter.toPostGIS(layer, dbConn, tableName, 
        GisEngineType.GEOTOOLS);
    log.info("导入完成");
}
```

### 数据导出流程

```java
/**
 * 标准数据导出流程
 */
public void exportData(DbConnBaseModel dbConn, String tableName,
        String outputPath, String format, String whereClause) {
    
    // 1. 读取数据
    log.info("读取数据: {}, 条件: {}", tableName, whereClause);
    OguLayer layer = SimpleLayerConverter.fromPostGIS(
        dbConn, tableName, whereClause, null, GisEngineType.GEOTOOLS);
    log.info("读取完成, 要素数: {}", layer.getFeatures().size());
    
    // 2. 格式转换
    log.info("导出格式: {}, 路径: {}", format, outputPath);
    switch (format.toUpperCase()) {
        case "SHP":
        case "SHAPEFILE":
            SimpleLayerConverter.toShapefile(layer, outputPath, 
                GisEngineType.GEOTOOLS);
            break;
        case "GEOJSON":
            // GeoJSON通常使用经纬度
            if (CrsUtil.isProjectedCRS(layer.getWkid())) {
                layer = CrsUtil.reproject(layer, 4490);
            }
            SimpleLayerConverter.toGeoJSON(layer, outputPath, 
                GisEngineType.GEOTOOLS);
            break;
        case "GDB":
        case "FILEGDB":
            String layerName = FileUtil.mainName(outputPath);
            SimpleLayerConverter.toFileGDB(layer, outputPath, null, 
                layerName, GisEngineType.GDAL);
            break;
        default:
            throw new IllegalArgumentException("不支持的格式: " + format);
    }
    
    log.info("导出完成");
}
```

## 小结

本章介绍了OGU4J的实用工具和最佳实践：

### 实用工具

1. **ZipUtil**：压缩和解压缩
2. **EncodingUtil**：编码检测
3. **SortUtil**：自然排序
4. **NumUtil**：数字格式化
5. **GdalCmdUtil**：GDAL命令行工具

### 最佳实践

1. **坐标系**：始终明确坐标系，面积计算用投影坐标系
2. **几何有效性**：处理前后验证几何
3. **异常处理**：记录详细错误信息
4. **资源管理**：及时释放连接和句柄
5. **性能优化**：使用数据库端过滤
6. **日志记录**：记录关键操作和统计
7. **数据验证**：输入输出都要验证
