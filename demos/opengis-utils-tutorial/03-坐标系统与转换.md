# 坐标系统与转换

## 概述

坐标参考系统（CRS）是GIS的基础概念。不同坐标系会导致相同位置的坐标值完全不同，理解和正确处理坐标系是避免数据错误的关键。本章介绍坐标系的分类、带号计算和坐标转换方法。

## 坐标系分类

### 地理坐标系（Geographic CRS）

地理坐标系使用经度和纬度表示地球表面位置：

- **经度（Longitude）**：东西方向，范围 -180° 到 180°
- **纬度（Latitude）**：南北方向，范围 -90° 到 90°

**常用地理坐标系**：

| EPSG代码 | 名称 | 说明 |
|---------|------|------|
| 4490 | CGCS2000 | 中国2000国家大地坐标系 |
| 4326 | WGS84 | GPS和互联网地图使用 |
| 4214 | BJ54 | 北京54坐标系（已淘汰） |
| 4610 | XA80 | 西安80坐标系（已淘汰） |

### 投影坐标系（Projected CRS）

投影坐标系将球面坐标转换为平面坐标，使用米作为单位：

**中国常用投影**：
- **高斯-克吕格投影**：国家测绘标准
- **分带投影**：3度带或6度带

**CGCS2000投影坐标系**：

| EPSG代码 | 带号 | 中央经线 | 覆盖范围 |
|---------|------|----------|----------|
| 4502 | 24 | 72°E | 西藏西部 |
| 4513 | 35 | 105°E | 西南地区 |
| 4526 | 38 | 114°E | 华中地区 |
| 4527 | 39 | 117°E | 华东地区 |
| 4528 | 40 | 120°E | 东部沿海 |

**命名规律**：EPSG:4488 + 带号 = 投影坐标系代码

## 坐标系管理

### 获取支持的坐标系

```java
/**
 * 获取支持的坐标系列表
 */
public static Map<Integer, CoordinateReferenceSystem> getSupportedCRSList() {
    Map<Integer, CoordinateReferenceSystem> list = new HashMap<>();
    // CGCS2000相关坐标系（4490-4554）
    for (int i = 4490; i < 4555; i++) {
        list.put(i, CRS.decode("EPSG:" + i, true));
    }
    return list;
}

/**
 * 动态获取坐标系
 * 如果不在预置列表中，自动添加
 */
public static Map.Entry<Integer, CoordinateReferenceSystem> getSupportedCRS(Integer wkid) {
    if (!supportedCRSList.containsKey(wkid)) {
        CoordinateReferenceSystem crs = CRS.decode("EPSG:" + wkid, true);
        supportedCRSList.put(wkid, crs);
    }
    return new AbstractMap.SimpleEntry<>(wkid, supportedCRSList.get(wkid));
}
```

### 判断坐标系类型

```java
/**
 * 判断是否为投影坐标系

public static boolean isProjectedCRS(CoordinateReferenceSystem crs) {
    return crs instanceof ProjectedCRS;
}

 * 判断是否为投影坐标系（通过WKID）
```

### 判断坐标系是否相同

```java
/**
 * 判断两个坐标系是否相同
 * 需要深度比较参数，因为不同来源的坐标系定义可能略有差异
 */
public static boolean isSameCRS(CoordinateReferenceSystem sourceCrs, 
                                CoordinateReferenceSystem targetCrs) {
    if (sourceCrs instanceof ProjectedCRS && targetCrs instanceof ProjectedCRS) {
        ProjectedCRS source = (ProjectedCRS) sourceCrs;
        ProjectedCRS target = (ProjectedCRS) targetCrs;
        
        // 比较基础地理坐标系
        boolean isSameBaseCRS = isSameCRS(source.getBaseCRS(), target.getBaseCRS());
        
        // 比较投影参数
        ParameterValueGroup sourceParams = source.getConversionFromBase().getParameterValues();
        ParameterValueGroup targetParams = target.getConversionFromBase().getParameterValues();
        boolean isSameParams = sourceParams.equals(targetParams);
        
        return isSameBaseCRS && isSameParams;
    } else if (sourceCrs instanceof GeographicCRS && 
               targetCrs instanceof GeographicCRS) {
        // 比较椭球体参数
        Ellipsoid s = ((GeographicCRS) sourceCrs).getDatum().getEllipsoid();
        Ellipsoid t = ((GeographicCRS) targetCrs).getDatum().getEllipsoid();
        
        return s.getSemiMajorAxis() == t.getSemiMajorAxis()
            && s.getSemiMinorAxis() == t.getSemiMinorAxis()
            && s.getInverseFlattening() == t.getInverseFlattening();
    }
    return false;
}
```

## 带号计算

中国的3度带投影需要根据经度确定带号。

### 从几何获取带号

```java
/**
 * 从几何获取带号
 * 根据几何中心点的经度计算
 */
public static int getDh(Geometry geometry) {
    Point point = geometry.getCentroid();
    int dh = 0;
    
    if (point.getX() < 180) {
        // 经纬度坐标，根据经度计算带号
        // 3度带公式：带号 = (经度 + 1.5) / 3
        dh = (int) ((point.getX() + 1.5) / 3);
    } else if (point.getX() / 10000000 > 3) {
        // 投影坐标，从X坐标提取带号
        // 投影坐标的X值格式：带号 * 1000000 + 偏移值
        dh = (int) (point.getX() / 1000000);
    }
    return dh;
}

/**
 * 从WKT获取带号
 */
public static int getDh(String wkt) {
    Geometry geom = GeometryConverter.wkt2Geometry(wkt);
    return getDh(geom);
}

/**
 * 从投影坐标系WKID获取带号
 */
public static int getDh(int projectedWkid) {
    return projectedWkid - 4488;
}
```

### 带号与投影坐标系换算

```java
/**
 * 从带号获取投影坐标系WKID
 */
public static Integer getProjectedWkid(int dh) {
    return 4488 + dh;
}

/**
 * 从几何获取对应的投影坐标系
 */
public static Integer getProjectedWkid(Geometry geometry) {
    return getProjectedWkid(getDh(geometry));
}
```

### 智能识别几何坐标系

```java
/**
 * 根据坐标值智能判断WKID
 * 经纬度返回4490，投影坐标返回对应投影坐标系
 */
public static Integer getWkid(Geometry geometry) {
    Point point = geometry.getCentroid();
    if (point.getX() < 180) {
        return 4490;  // CGCS2000地理坐标系
    } else {
        return getProjectedWkid(getDh(geometry));
    }
}
```

## 坐标系容差

不同坐标系的容差设置不同：

```java
/**
 * 获取坐标系容差
 */
public static double getTolerance(Integer wkid) {
    CoordinateReferenceSystem crs = getSupportedCRS(wkid).getValue();
    return getTolerance(crs);
}

public static double getTolerance(CoordinateReferenceSystem crs) {
    if (isProjectedCRS(crs)) {
        return 0.0001;      // 投影坐标系：0.1毫米
    } else {
        return 0.000000001; // 地理坐标系：约0.1毫米（赤道处）
    }
}
```

**设计思路**：
- 投影坐标系以米为单位，0.0001米 = 0.1毫米
- 地理坐标系以度为单位，1度≈111km，需要更小的数值

## 坐标转换

### Geometry坐标转换

```java
/**
 * 几何对象坐标转换
 */
public static Geometry transform(Geometry geometry, 
        Integer sourceWkid, Integer targetWkid) {
    // 相同坐标系无需转换
    if (sourceWkid.equals(targetWkid)) {
        return geometry;
    }
    
    CoordinateReferenceSystem sourceCRS = getSupportedCRS(sourceWkid).getValue();
    CoordinateReferenceSystem targetCRS = getSupportedCRS(targetWkid).getValue();
    
    return transform(geometry, sourceCRS, targetCRS);
}

public static Geometry transform(Geometry geometry, 
        CoordinateReferenceSystem sourceCRS, 
        CoordinateReferenceSystem targetCRS) {
    // 相同坐标系无需转换
    if (isSameCRS(sourceCRS, targetCRS)) {
        return geometry;
    }
    
    MathTransform transform = CRS.findMathTransform(sourceCRS, targetCRS);
    return JTS.transform(geometry, transform);
}
```

### WKT字符串坐标转换

```java
/**
 * WKT格式的坐标转换
 */
public static String transform(String wkt, Integer sourceWkid, Integer targetWkid) {
    Geometry geom = GeometryConverter.wkt2Geometry(wkt);
    geom = transform(geom, sourceWkid, targetWkid);
    return geom == null ? null : geom.toText();
}
```

### 图层坐标转换

```java
/**
 * 转换图层的坐标系
 */
public static OguLayer reproject(OguLayer layer, Integer targetWkid) {
    layer.validate();
    
    // 深拷贝，避免修改原数据
    OguLayer clone = ObjectUtil.cloneByStream(layer);
    
    // 相同坐标系无需转换
    if (clone.getWkid().equals(targetWkid)) {
        return clone;
    }
    
    // 转换每个要素的几何
    for (OguFeature feature : clone.getFeatures()) {
        Geometry geometry = GeometryConverter.wkt2Geometry(feature.getWkt());
        Geometry transformed = transform(geometry, layer.getWkid(), targetWkid);
        feature.setWkt(transformed.toText());
    }
    
    // 更新图层坐标系信息
    clone.setWkid(targetWkid);
    clone.setTolerance(getTolerance(targetWkid));
    
    return clone;
}
```

## 实践案例

### 案例1：经纬度转投影坐标

```java
/**
 * 经纬度转投影坐标
 */
public void geo2Proj(String inputWkt) {
    // 某地块的经纬度坐标
    String wkt = "POLYGON((116.3 39.9, 116.4 39.9, 116.4 40.0, 116.3 40.0, 116.3 39.9))";
    Geometry geom = GeometryConverter.wkt2Geometry(wkt);
    
    // 确定带号（116.3°E位于39带）
    int dh = CrsUtil.getDh(geom);
    System.out.println("带号: " + dh);  // 39
    
    // 获取投影坐标系
    int projWkid = CrsUtil.getProjectedWkid(dh);
    System.out.println("投影坐标系: EPSG:" + projWkid);  // EPSG:4527
    
    // 坐标转换
    Geometry projGeom = CrsUtil.transform(geom, 4490, projWkid);
    System.out.println("投影后坐标: " + projGeom.toText());
    
    // 计算面积（投影坐标系下计算才准确）
    double area = projGeom.getArea();
    System.out.println("面积: " + area + " 平方米");
}
```

### 案例2：不同坐标系数据统一

```java
/**
 * 统一多源数据的坐标系
 */
public OguLayer unifyCoordinateSystem(List<OguLayer> layers, Integer targetWkid) {
    List<OguFeature> allFeatures = new ArrayList<>();
    List<OguField> fields = null;
    
    for (OguLayer layer : layers) {
        // 统一坐标系
        OguLayer reprojected = layer;
        if (!layer.getWkid().equals(targetWkid)) {
            reprojected = CrsUtil.reproject(layer, targetWkid);
        }
        
        // 收集所有要素
        allFeatures.addAll(reprojected.getFeatures());
        
        // 使用第一个图层的字段定义
        if (fields == null) {
            fields = reprojected.getFields();
        }
    }
    
    // 创建统一图层
    OguLayer result = new OguLayer();
    result.setYwName("unified_layer");
    result.setWkid(targetWkid);
    result.setFields(fields);
    result.setFeatures(allFeatures);
    
    return result;
}
```

```java
/**
 * 准备Web展示用的数据
 * Web地图通常使用WGS84或CGCS2000经纬度
 */
public OguLayer prepareForWeb(OguLayer layer) {
    // 目标坐标系：CGCS2000地理坐标系
    int targetWkid = 4490;
    
    // 如果已经是经纬度，直接返回
    if (!CrsUtil.isProjectedCRS(layer.getWkid())) {
        return layer;
    }
    
    // 转换到经纬度
    return CrsUtil.reproject(layer, targetWkid);
}
```

### 案例4：面积计算

```java
/**
 * 正确计算面积
 */
public double calculateArea(String wkt, Integer wkid) {
    Geometry geom = GeometryConverter.wkt2Geometry(wkt);
    
    // 如果是经纬度坐标，需要先转换到投影坐标系
    if (!CrsUtil.isProjectedCRS(wkid)) {
        int projWkid = CrsUtil.getProjectedWkid(geom);
        geom = CrsUtil.transform(geom, wkid, projWkid);
    }
    
    // 计算面积（平方米）
    return geom.getArea();
}

/**
 * 批量计算图层面积
 */
public void calculateLayerAreas(OguLayer layer) {
    // 准备投影坐标系
    Integer projWkid = null;
    if (!CrsUtil.isProjectedCRS(layer.getWkid())) {
        // 取第一个要素确定带号
        Geometry first = GeometryConverter.wkt2Geometry(
            layer.getFeatures().get(0).getWkt());
        projWkid = CrsUtil.getProjectedWkid(first);
    }
    
    double totalArea = 0;
    for (OguFeature feature : layer.getFeatures()) {
        Geometry geom = GeometryConverter.wkt2Geometry(feature.getWkt());
        
        // 坐标转换
        if (projWkid != null) {
            geom = CrsUtil.transform(geom, layer.getWkid(), projWkid);
        }
        
        double area = geom.getArea();
        totalArea += area;
        
        // 可以将面积写回属性
        feature.setValue("AREA", area);
    }
    
    System.out.println("图层总面积: " + totalArea + " 平方米");
    System.out.println("合计: " + (totalArea / 10000) + " 公顷");
}
```

## 常见问题

### 1. 坐标系不匹配

**现象**：叠加分析结果为空，或位置完全错误

**原因**：两组数据使用了不同的坐标系

**解决**：
```java
// 检查坐标系
System.out.println("Layer1 WKID: " + layer1.getWkid());
System.out.println("Layer2 WKID: " + layer2.getWkid());

// 统一坐标系后再分析
if (!layer1.getWkid().equals(layer2.getWkid())) {
    layer2 = CrsUtil.reproject(layer2, layer1.getWkid());
}
```

### 2. 面积计算结果异常

**现象**：计算的面积值是一个很小或很大的数

**原因**：使用经纬度坐标直接计算面积

**解决**：先转换到投影坐标系再计算

### 3. 带号选择

**问题**：如何选择合适的带号？

**建议**：
- 查看数据的经度范围
- 选择中心经度对应的带号
- 3度带公式：带号 = (经度 + 1.5) / 3

```java
// 自动确定带号
Geometry geom = GeometryConverter.wkt2Geometry(wkt);
int dh = CrsUtil.getDh(geom);
System.out.println("推荐使用 " + dh + " 带");
```

### 4. CGCS2000与WGS84的区别

**问题**：是否需要严格区分？

**说明**：
- CGCS2000和WGS84的差异在厘米级
- 一般应用可以视为相同
- 高精度测量场景需要严格区分
- 互联网地图通常使用WGS84，国内官方数据使用CGCS2000
