# 几何数据与格式转换

## 概述

在GIS开发中，几何数据有多种表示格式，最常见的包括WKT、GeoJSON和EsriJSON。理解这些格式并掌握它们之间的转换方法，是处理GIS数据的基础技能。

## 几何数据格式

### WKT（Well-Known Text）

WKT是OGC定义的几何文本格式，语法简洁直观：

```
// 点
POINT (116.397 39.908)

// 线
LINESTRING (0 0, 10 10, 20 0)

// 多边形
POLYGON ((0 0, 10 0, 10 10, 0 10, 0 0))

// 带岛洞的多边形
POLYGON ((0 0, 100 0, 100 100, 0 100, 0 0), (20 20, 80 20, 80 80, 20 80, 20 20))

// 多点
MULTIPOINT ((0 0), (10 10))

// 多线
MULTILINESTRING ((0 0, 10 10), (20 20, 30 30))

// 多面
MULTIPOLYGON (((0 0, 10 0, 10 10, 0 10, 0 0)), ((20 20, 30 20, 30 30, 20 30, 20 20)))
```

**特点**：
- 纯文本，可读性好
- 只包含几何信息，不含属性和坐标系
- 几乎所有GIS库都支持

### GeoJSON

GeoJSON是基于JSON的地理数据格式，Web开发中最常用：

```json
{
  "type": "Feature",
  "geometry": {
    "type": "Point",
    "coordinates": [116.397, 39.908]
  },
  "properties": {
    "name": "天安门",
    "type": "landmark"
  }
}
```

**特点**：
- JSON格式，前后端通用
- 包含几何和属性
- 可选的坐标系定义

### EsriJSON

EsriJSON是ArcGIS使用的JSON格式：

```json
{
  "x": 116.397,
  "y": 39.908,
  "spatialReference": {
    "wkid": 4490
  }
}
```

**特点**：
- ArcGIS生态圈标准
- 包含坐标系信息
- 结构略有不同

## 格式转换方法

### WKT与JTS Geometry互转

JTS Geometry是Java中几何对象的内存表示，是进行空间操作的基础：

```java
// WKT转Geometry
public static Geometry wkt2Geometry(String wkt) {
    WKTReader2 reader = new WKTReader2();
    return reader.read(wkt);
}

// Geometry转WKT
public static String geometry2Wkt(Geometry geometry) {
    WKTWriter2 writer = new WKTWriter2();
    return writer.write(geometry);
}
```

**使用示例**：

```java
// 创建几何对象
String wkt = "POLYGON ((0 0, 10 0, 10 10, 0 10, 0 0))";
Geometry geom = GeometryConverter.wkt2Geometry(wkt);

// 空间操作
double area = geom.getArea();
Geometry buffer = geom.buffer(5);
Geometry centroid = geom.getCentroid();

// 转回WKT
String resultWkt = GeometryConverter.geometry2Wkt(buffer);
```

### WKT与GeoJSON互转

```java
// WKT转GeoJSON
public static String wkt2Geojson(String wkt) {
    Geometry geometry = wkt2Geometry(wkt);
    return geometry2Geojson(geometry);
}

// Geometry转GeoJSON
public static String geometry2Geojson(Geometry geometry) {
    GeometryJSON gjson = new GeometryJSON(16);  // 16位小数精度
    StringWriter writer = new StringWriter();
    gjson.write(geometry, writer);
    return writer.toString();
}

// GeoJSON转WKT
public static String geojson2Wkt(String geojson) {
    Geometry geometry = geojson2Geometry(geojson);
    return geometry2Wkt(geometry);
}

// GeoJSON转Geometry
public static Geometry geojson2Geometry(String geojson) {
    GeometryJSON gjson = new GeometryJSON(16);
    return gjson.read(new StringReader(geojson));
}
```

**使用示例**：

```java
// WKT转GeoJSON
String wkt = "POINT (116.397 39.908)";
String geojson = GeometryConverter.wkt2Geojson(wkt);
// 结果: {"type":"Point","coordinates":[116.397,39.908]}

// GeoJSON转WKT
String geojson = "{\"type\":\"Polygon\",\"coordinates\":[[[0,0],[10,0],[10,10],[0,10],[0,0]]]}";
String wkt = GeometryConverter.geojson2Wkt(geojson);
// 结果: POLYGON ((0 0, 10 0, 10 10, 0 10, 0 0))
```

### WKT与EsriJSON互转

```java
// WKT转EsriJSON
public static String wkt2EsriJson(String wkt, int wkid) {
    com.esri.core.geometry.Geometry geometry = 
        OperatorImportFromWkt.local().execute(
            WktImportFlags.wktImportDefaults, 
            Geometry.Type.Unknown, 
            wkt, 
            null);
    return OperatorExportToJson.local().execute(
        SpatialReference.create(wkid), geometry);
}

// EsriJSON转WKT
public static String esriJson2Wkt(String esriJson) {
    MapGeometry mapGeometry = OperatorImportFromJson.local()
        .execute(Geometry.Type.Unknown, esriJson);
    return OperatorExportToWkt.local()
        .execute(WktExportFlags.wktExportDefaults, 
            mapGeometry.getGeometry(), null);
}
```

**使用示例**：

```java
// WKT转EsriJSON
String wkt = "POINT (116.397 39.908)";
String esriJson = GeometryConverter.wkt2EsriJson(wkt, 4490);
// 结果: {"x":116.397,"y":39.908,"spatialReference":{"wkid":4490}}

// EsriJSON转WKT
String esriJson = "{\"x\":116.397,\"y\":39.908,\"spatialReference\":{\"wkid\":4490}}";
String wkt = GeometryConverter.esriJson2Wkt(esriJson);
// 结果: POINT (116.397 39.908)
```

### GeoJSON与EsriJSON互转

通过WKT作为桥梁，可以实现任意格式间的转换：

```java
// GeoJSON转EsriJSON
public static String geoJson2EsriJson(int wkid, String geojson) {
    String wkt = geojson2Wkt(geojson);
    return wkt2EsriJson(wkt, wkid);
}

// EsriJSON转GeoJSON
public static String esriJson2GeoJson(String esriJson) {
    String wkt = esriJson2Wkt(esriJson);
    return wkt2Geojson(wkt);
}
```

## 几何基本属性

### 长度和面积

```java
// 获取长度（线的长度或面的周长）
public static double length(Geometry geom) {
    return geom.getLength();
}

// 获取面积
public static double area(Geometry geom) {
    return geom.getArea();
}
```

**重要提醒**：计算结果的单位与坐标系相关：
- 地理坐标系（经纬度）：单位是度，结果没有实际意义
- 投影坐标系：单位是米，结果为实际的米/平方米

```java
// 正确的面积计算流程
String wkt = feature.getWkt();
Geometry geom = GeometryConverter.wkt2Geometry(wkt);

// 1. 如果是经纬度坐标，先转换到投影坐标系
if (isGeographicCRS(wkid)) {
    int projWkid = CrsUtil.getProjectedWkid(geom);
    geom = CrsUtil.transform(geom, wkid, projWkid);
}

// 2. 计算面积（结果为平方米）
double areaSqm = geom.getArea();
double areaMu = areaSqm / 666.67;  // 转换为亩
```

### 中心点

```java
// 几何中心（质心）- 可能在几何外部
public static Geometry centroid(Geometry geom) {
    return geom.getCentroid();
}

// 内部中心点 - 保证在几何内部
public static Geometry interiorPoint(Geometry geom) {
```

**选择建议**：
- 标注点位时使用`interiorPoint`，确保标注在要素内部
- 统计分析时使用`centroid`，获取几何质心

## 几何有效性检查

### 拓扑有效性

几何对象必须符合特定规则才有效：

```java
/**
 * 检查几何有效性
 */
public static TopologyValidationResult isValid(Geometry geom) {
    IsValidOp isValidOp = new IsValidOp(geom);
    if (!isValidOp.isValid()) {
        TopologyValidationError error = isValidOp.getValidationError();
        return new TopologyValidationResult(false, 
            error.getCoordinate(), 
            error.getMessage());
    }
    return new TopologyValidationResult(true, null, null);
}
```

常见的拓扑错误：
- 自相交：多边形边界与自身相交
- 重复点：相邻节点坐标相同
- 环方向错误：外环应逆时针，内环应顺时针
- 岛洞错误：内环不在外环内部

### 几何修复

```java
/**
 * 修复无效几何
 */
public static Geometry validate(Geometry geom) {
    if (geom instanceof Polygon) {
        if (geom.isValid()) {
            geom.normalize();
            return geom;
        }
        Polygonizer polygonizer = new Polygonizer();
        addPolygon((Polygon) geom, polygonizer);
        return toPolygonGeometry(polygonizer.getPolygons());
    } else if (geom instanceof MultiPolygon) {
        if (geom.isValid()) {
            geom.normalize();
            return geom;
        }
        Polygonizer polygonizer = new Polygonizer();
        for (int n = geom.getNumGeometries(); n-- > 0; ) {
            addPolygon((Polygon) geom.getGeometryN(n), polygonizer);
        }
        return toPolygonGeometry(polygonizer.getPolygons());
    }
    return geom;
}
```

## ESRI几何引擎

除了JTS，还可以使用ESRI几何引擎，它基于WKT字符串操作：

```java
// 创建几何
Geometry geom = EsriGeometryUtil.createGeometryByWkt(wkt);
Geometry geom = EsriGeometryUtil.createGeometryByGeoJson(geojson);
Geometry geom = EsriGeometryUtil.createGeometryByJson(esriJson);

// 输出
String wkt = EsriGeometryUtil.toWkt(geometry);
String geojson = EsriGeometryUtil.toGeoJson(geometry);
String esriJson = EsriGeometryUtil.toEsriJson(wkid, geometry);

// 几何属性
double area = EsriGeometryUtil.area(wkt);
double length = EsriGeometryUtil.length(wkt);
String centroid = EsriGeometryUtil.centroid(wkt);
int dimension = EsriGeometryUtil.dimension(wkt);
boolean isEmpty = EsriGeometryUtil.isEmpty(wkt);
GeometryType geometryType = EsriGeometryUtil.geometryType(wkt);
```

**选择建议**：
- JTS：内存中的几何对象操作，性能更好
- ESRI：基于WKT字符串操作，接口更简洁，某些算法更健壮

## 实践案例

### 案例1：几何格式转换服务

```java
/**
 * 几何格式转换服务
 */
public class GeometryFormatService {
    
    /**
     * 通用格式转换
     * @param input 输入几何
     * @param fromFormat 源格式 (WKT/GEOJSON/ESRIJSON)
     * @param toFormat 目标格式
     * @param wkid 坐标系代码（EsriJSON需要）
     */
    public String convert(String input, String fromFormat, 
            String toFormat, Integer wkid) {
        // 统一转为WKT
        String wkt = toWkt(input, fromFormat);
        
        // 转为目标格式
        return fromWkt(wkt, toFormat, wkid);
    }
    
    private String toWkt(String input, String format) {
        switch (format.toUpperCase()) {
            case "WKT":
                return input;
            case "GEOJSON":
                return GeometryConverter.geojson2Wkt(input);
            case "ESRIJSON":
                return GeometryConverter.esriJson2Wkt(input);
            default:
                throw new IllegalArgumentException("不支持的格式: " + format);
        }
    }
    
    private String fromWkt(String wkt, String format, Integer wkid) {
        switch (format.toUpperCase()) {
            case "WKT":
                return wkt;
            case "GEOJSON":
                return GeometryConverter.wkt2Geojson(wkt);
            case "ESRIJSON":
                return GeometryConverter.wkt2EsriJson(wkt, wkid);
            default:
                throw new IllegalArgumentException("不支持的格式: " + format);
        }
    }
}
```

### 案例2：批量几何验证

```java
/**
 * 批量验证并修复几何
 */
public void validateAndFix(OguLayer layer) {
    int invalidCount = 0;
    int fixedCount = 0;
    
    for (OguFeature feature : layer.getFeatures()) {
        String wkt = feature.getWkt();
        Geometry geom = GeometryConverter.wkt2Geometry(wkt);
        
        TopologyValidationResult result = JtsGeometryUtil.isValid(geom);
        if (!result.isValid()) {
            invalidCount++;
            System.out.println("无效几何: " + feature.getWfId() + 
                " - " + result.getMessage());
            
            // 尝试修复
            try {
                Geometry fixed = JtsGeometryUtil.validate(geom);
                if (fixed.isValid()) {
                    feature.setWkt(fixed.toText());
                    fixedCount++;
                    System.out.println("  已修复");
                }
            } catch (Exception e) {
                System.out.println("  修复失败: " + e.getMessage());
            }
        }
    }
    
    System.out.println("检查完成: 发现 " + invalidCount + " 个无效几何, " +
        "成功修复 " + fixedCount + " 个");
}
```

### 案例3：计算图层统计信息

```java
/**
 * 计算图层几何统计信息
 */
public Map<String, Object> calculateStatistics(OguLayer layer) {
    Map<String, Object> stats = new HashMap<>();
    
    int featureCount = layer.getFeatures().size();
    double totalArea = 0;
    double totalLength = 0;
    int invalidCount = 0;
    
    // 先判断是否需要转换坐标系
    boolean needTransform = !CrsUtil.isProjectedCRS(layer.getWkid());
    Integer projWkid = null;
    
    for (OguFeature feature : layer.getFeatures()) {
        Geometry geom = GeometryConverter.wkt2Geometry(feature.getWkt());
        
        // 有效性检查
        if (!geom.isValid()) {
            invalidCount++;
            continue;
        }
        
        // 坐标转换（如需）
        if (needTransform) {
            if (projWkid == null) {
                projWkid = CrsUtil.getProjectedWkid(geom);
            }
            geom = CrsUtil.transform(geom, layer.getWkid(), projWkid);
        }
        
        totalArea += geom.getArea();
        totalLength += geom.getLength();
    }
    
    stats.put("featureCount", featureCount);
    stats.put("totalArea", totalArea);
    stats.put("totalLength", totalLength);
    stats.put("invalidCount", invalidCount);
    
    return stats;
}
```
