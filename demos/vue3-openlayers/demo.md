# Demo工程代码创建说明

[工程地址](https://github.com/znlgis/openlayers-vue3-demo)

## 1. 创建Vue3工程

```shell
npm create vite@latest openlayers-vue3-demo -- --template vue
```

## 2. 安装OpenLayers

```shell
npm install vue3-openlayers
```

## 3. 其他依赖

```shell
npm install axios
npm install base-64
```
