# Hermes Agent 教程目录

> 一份系统化、面向中文读者的 [Hermes Agent](https://github.com/NousResearch/hermes-agent) 学习与实战教程。Hermes Agent 是 [Nous Research](https://nousresearch.com/) 出品的 **自学习 AI 智能体**：内置完整的"经验 → 技能 → 记忆 → 用户建模"闭环，支持 CLI/TUI、Telegram、Discord、Slack、WhatsApp、Signal、企业微信、飞书、钉钉、邮件、SMS 等 15+ 平台，可在本地、Docker、SSH、Daytona、Modal、Singularity 等多种后端运行，可对接 Nous Portal、OpenRouter、Anthropic、OpenAI、Codex、GLM、Kimi、MiniMax、DeepSeek、NVIDIA NIM、HuggingFace、自托管 vLLM/Ollama/SGLang 等几乎所有主流模型供应商。本教程围绕 Hermes 的核心理念、架构、CLI、模型/工具/技能/记忆/MCP/网关/定时任务/语音/子代理/插件等模块系统讲解，帮助你从零开始把 Hermes Agent 真正用在工作中。
