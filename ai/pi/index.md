# Pi 教程目录

> 一份系统化、面向中文读者的 [Pi Agent Harness](https://github.com/earendil-works/pi) 使用与开发教程。Pi 是 [Mario Zechner](https://mariozechner.at/)（libGDX 作者、Badlogic Games 创始人）打造的**极简终端编码 Agent 工具集**：核心仅 ~1000 tokens 系统提示词 + 4 个工具（read/write/edit/bash），支持 Anthropic/OpenAI/Google/DeepSeek/Mistral/Groq 等 30+ 模型供应商，通过 TypeScript Extensions、Skills、Prompt Templates 和 Themes 实现高度可扩展性。本教程围绕 Pi 的核心理念、安装配置、交互式 TUI、工具系统、Skills、Extensions、包管理、SDK 嵌入、容器安全以及核心架构（pi-ai / pi-agent-core / pi-tui）等模块系统讲解，帮助你从零开始把 Pi 真正用在日常编码工作中。
