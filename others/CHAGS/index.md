# CHAGS 中国历史典故儿童游戏合集使用与开发教程目录

本教程结合开源仓库 [znlgis/CHAGS](https://github.com/znlgis/CHAGS)，全面剖析这款「一个典故一个小游戏」的儿童游戏合集的技术实现。教程从项目定位与技术选型出发，系统讲解五层架构（外壳 / 游戏包 / 契约 / 模板 / 平台），逐步深入到核心契约、Vue 应用外壳、内容数据模型、玩法模板库、Phaser 渲染工具箱、平台适配层、进度存档与复习调度、中英双语实现，再通过「从零开发一个新典故」的完整实战与测试、打包、分发流程融会贯通，最后以儿童向设计规范、踩坑记录与常见问题收尾。每章内容详尽，配有大量 TypeScript 代码示例，适合对 Phaser / Vue 游戏开发、儿童教育产品与工程化实践感兴趣的读者。

> 🎮 **在线试玩**：[CHAGS 典故游戏合集](https://znlgis.github.io/chags/) —— 53 个典故小游戏，手机 / 平板浏览器打开即玩，无需安装。
