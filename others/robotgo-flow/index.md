# robotgo-flow RPA 自动化使用与开发教程目录

本教程结合 robotgo-flow 官方仓库 [znlgis/robotgo-flow](https://github.com/znlgis/robotgo-flow)，全面剖析这款基于 [go-vgo/robotgo](https://github.com/go-vgo/robotgo) 构建的 Windows RPA 自动化框架。教程从概念、环境搭建与第一个工作流出发，系统讲解 YAML 工作流结构、鼠标/键盘/等待/浏览器等各类动作、交互式动作与运行时变量、图像模板匹配、人类行为模拟、CLI 命令、录制器与截图工具、错误处理与调试，再深入到 WPF 托盘应用集成、架构与源码剖析、二次开发扩展新动作，最后通过综合实战项目与最佳实践融会贯通。每章内容详尽，配有大量 YAML 与代码示例，适合从入门到进阶乃至二次开发的读者。
