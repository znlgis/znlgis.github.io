# 第09章 实时数据订阅

PocketBase 内置了基于 SSE（Server-Sent Events）的实时数据推送机制，允许客户端订阅集合或单条记录的变更事件。当数据发生创建、更新或删除操作时，订阅的客户端会即时收到通知。本章将全面讲解 PocketBase 实时订阅的各个方面。

---

## 9.1 实时订阅概述

### 9.1.1 什么是SSE

SSE（Server-Sent Events）是一种基于 HTTP 的单向通信技术，允许服务器主动向客户端推送数据。

```
SSE vs WebSocket 对比:

┌─────────────────┬───────────────────┬──────────────────┐
│     特性         │      SSE          │    WebSocket     │
├─────────────────┼───────────────────┼──────────────────┤
│ 通信方向         │ 单向（服务器→客户端）│ 双向              │
│ 协议            │ HTTP              │ WS/WSS           │
│ 自动重连         │ 内置支持           │ 需要手动实现       │
│ 数据格式         │ 文本              │ 文本/二进制        │
│ 浏览器支持       │ 广泛支持           │ 广泛支持           │
│ 代理/防火墙      │ 友好              │ 可能被阻止         │
│ 实现复杂度       │ 简单              │ 较复杂             │
└─────────────────┴───────────────────┴──────────────────┘
```

### 9.1.2 PocketBase 实时订阅架构

```
PocketBase 实时订阅工作流:

客户端                          服务器
  │                               │
  │── SSE 连接建立 ──────────────→ │
  │                               │
  │← 连接确认 (clientId) ────────── │
  │                               │
  │── 订阅集合/记录 ──────────────→ │
  │                               │
  │                    [数据变更发生] │
  │                               │
  │← 推送变更事件 ────────────────── │
  │                               │
  │                    [数据变更发生] │
  │                               │
  │← 推送变更事件 ────────────────── │
  │                               │
  │── 取消订阅 ───────────────────→ │
  │                               │
```

### 9.1.3 支持的事件类型

PocketBase 实时订阅支持三种事件类型：

| 事件类型 | 说明 | 触发时机 |
|----------|------|----------|
| `create` | 创建事件 | 新记录被创建时 |
| `update` | 更新事件 | 现有记录被更新时 |
| `delete` | 删除事件 | 记录被删除时 |

## 9.2 订阅集合变更

### 9.2.1 使用JS SDK订阅集合

订阅整个集合的所有变更事件，使用通配符 `*`：

```javascript
import PocketBase from 'pocketbase';
const pb = new PocketBase('http://127.0.0.1:8090');

// 订阅 "posts" 集合的所有变更
pb.collection('posts').subscribe('*', function (e) {
    console.log('事件类型:', e.action);  // "create", "update", "delete"
    console.log('记录数据:', e.record);
});
```

### 9.2.2 区分不同事件类型

```javascript
pb.collection('posts').subscribe('*', function (e) {
    switch (e.action) {
        case 'create':
            console.log('新文章创建:', e.record.title);
            // 将新记录添加到列表中
            addToList(e.record);
            break;

        case 'update':
            console.log('文章更新:', e.record.id, e.record.title);
            // 更新列表中的记录
            updateInList(e.record);
            break;

        case 'delete':
            console.log('文章删除:', e.record.id);
            // 从列表中移除记录
            removeFromList(e.record.id);
            break;
    }
});
```

### 9.2.3 带认证的订阅

对于需要认证才能访问的集合，必须先登录再订阅：

```javascript
const pb = new PocketBase('http://127.0.0.1:8090');

// 先登录
await pb.collection('users').authWithPassword('user@example.com', 'password123');

// 登录后订阅受保护的集合
pb.collection('private_messages').subscribe('*', function (e) {
    console.log('收到新消息:', e.record);
});
```

### 9.2.4 同时订阅多个集合

```javascript
const pb = new PocketBase('http://127.0.0.1:8090');

// 订阅文章变更
pb.collection('posts').subscribe('*', function (e) {
    console.log('[Posts]', e.action, e.record);
});

// 订阅评论变更
pb.collection('comments').subscribe('*', function (e) {
    console.log('[Comments]', e.action, e.record);
});

// 订阅通知变更
pb.collection('notifications').subscribe('*', function (e) {
    console.log('[Notifications]', e.action, e.record);
});
```

## 9.3 订阅单条记录

### 9.3.1 订阅特定记录

如果你只关心某条特定记录的变更，可以使用记录 ID 进行订阅：

```javascript
const pb = new PocketBase('http://127.0.0.1:8090');

const recordId = 'abc123def456';

// 订阅特定记录的变更
pb.collection('posts').subscribe(recordId, function (e) {
    console.log('记录变更:', e.action);
    console.log('更新后的数据:', e.record);

    if (e.action === 'update') {
        // 更新页面上显示的数据
        updatePageContent(e.record);
    }

    if (e.action === 'delete') {
        // 记录被删除，跳转到列表页
        window.location.href = '/posts';
    }
});
```

### 9.3.2 使用场景

```
单条记录订阅的典型场景:
├── 文章详情页 - 实时显示文章更新
├── 用户资料页 - 实时同步用户信息变更
├── 订单详情页 - 实时跟踪订单状态变化
├── 聊天室信息 - 实时更新聊天室名称和设置
└── 文档编辑 - 实时同步文档修改
```

### 9.3.3 动态切换订阅

```javascript
let currentSubscription = null;

async function subscribeToPost(postId) {
    // 取消之前的订阅
    if (currentSubscription) {
        await pb.collection('posts').unsubscribe(currentSubscription);
    }

    // 订阅新的记录
    currentSubscription = postId;
    pb.collection('posts').subscribe(postId, function (e) {
        console.log('文章更新:', e.record);
        renderPost(e.record);
    });
}

// 用户点击不同的文章时切换订阅
document.querySelectorAll('.post-link').forEach(link => {
    link.addEventListener('click', () => {
        subscribeToPost(link.dataset.postId);
    });
});
```

## 9.4 取消订阅

### 9.4.1 取消特定集合的特定订阅

```javascript
// 取消对特定记录的订阅
await pb.collection('posts').unsubscribe('RECORD_ID');

// 取消对集合所有记录的订阅（通配符订阅）
await pb.collection('posts').unsubscribe('*');
```

### 9.4.2 取消特定集合的所有订阅

```javascript
// 取消 "posts" 集合的所有订阅（包括通配符和特定记录）
await pb.collection('posts').unsubscribe();
```

### 9.4.3 取消所有订阅

```javascript
// 取消所有集合的所有订阅
await pb.realtime.unsubscribe();
```

### 9.4.4 在组件生命周期中管理订阅

**React 示例：**

```javascript
import { useEffect, useState } from 'react';
import PocketBase from 'pocketbase';

const pb = new PocketBase('http://127.0.0.1:8090');

function PostList() {
    const [posts, setPosts] = useState([]);

    useEffect(() => {
        // 初始加载数据
        pb.collection('posts').getFullList().then(records => {
            setPosts(records);
        });

        // 订阅实时更新
        pb.collection('posts').subscribe('*', function (e) {
            setPosts(prevPosts => {
                switch (e.action) {
                    case 'create':
                        return [...prevPosts, e.record];
                    case 'update':
                        return prevPosts.map(p =>
                            p.id === e.record.id ? e.record : p
                        );
                    case 'delete':
                        return prevPosts.filter(p => p.id !== e.record.id);
                    default:
                        return prevPosts;
                }
            });
        });

        // 组件卸载时取消订阅
        return () => {
            pb.collection('posts').unsubscribe('*');
        };
    }, []);

    return (
        <ul>
            {posts.map(post => (
                <li key={post.id}>{post.title}</li>
            ))}
        </ul>
    );
}
```

**Vue 3 示例：**

```javascript
<script setup>
import { ref, onMounted, onUnmounted } from 'vue';
import PocketBase from 'pocketbase';

const pb = new PocketBase('http://127.0.0.1:8090');
const posts = ref([]);

onMounted(async () => {
    // 初始加载
    posts.value = await pb.collection('posts').getFullList();

    // 订阅实时更新
    pb.collection('posts').subscribe('*', (e) => {
        switch (e.action) {
            case 'create':
                posts.value.push(e.record);
                break;
            case 'update':
                const index = posts.value.findIndex(p => p.id === e.record.id);
                if (index !== -1) posts.value[index] = e.record;
                break;
            case 'delete':
                posts.value = posts.value.filter(p => p.id !== e.record.id);
                break;
        }
    });
});

onUnmounted(() => {
    pb.collection('posts').unsubscribe('*');
});
</script>

<template>
    <ul>
        <li v-for="post in posts" :key="post.id">{{ post.title }}</li>
    </ul>
</template>
```

## 9.5 订阅事件格式

### 9.5.1 事件数据结构

订阅回调函数接收一个事件对象，包含以下属性：

```javascript
{
    action: "create" | "update" | "delete",
    record: {
        id: "abc123def456",
        collectionId: "xyz789",
        collectionName: "posts",
        created: "2024-01-01 00:00:00.000Z",
        updated: "2024-01-01 00:00:00.000Z",
        // ... 记录的所有字段
        title: "文章标题",
        content: "文章内容",
        author: "user123",
        status: "published"
    }
}
```

### 9.5.2 各事件类型的详细说明

**create 事件：**

```javascript
pb.collection('posts').subscribe('*', function (e) {
    if (e.action === 'create') {
        // e.record 包含新创建的完整记录数据
        console.log('新记录ID:', e.record.id);
        console.log('创建时间:', e.record.created);
        console.log('所有字段:', e.record);
    }
});
```

**update 事件：**

```javascript
pb.collection('posts').subscribe('*', function (e) {
    if (e.action === 'update') {
        // e.record 包含更新后的完整记录数据
        // 注意: 无法直接获取更新前的数据或变更的字段列表
        console.log('更新的记录ID:', e.record.id);
        console.log('更新时间:', e.record.updated);
        console.log('更新后的数据:', e.record);
    }
});
```

**delete 事件：**

```javascript
pb.collection('posts').subscribe('*', function (e) {
    if (e.action === 'delete') {
        // e.record 包含被删除的记录数据（删除前的快照）
        console.log('删除的记录ID:', e.record.id);
        console.log('被删除的数据:', e.record);
    }
});
```

### 9.5.3 事件中的expand数据

如果你在订阅时需要关联数据的展开，需要在订阅后通过 API 重新获取完整数据：

```javascript
pb.collection('posts').subscribe('*', async function (e) {
    if (e.action === 'create' || e.action === 'update') {
        // 事件中的记录可能不包含展开的关联数据
        // 需要通过 API 重新获取
        const fullRecord = await pb.collection('posts').getOne(e.record.id, {
            expand: 'author,category'
        });
        console.log('完整记录（含关联数据）:', fullRecord);
    }
});
```

## 9.6 订阅权限控制

### 9.6.1 订阅与API规则的关系

实时订阅受到集合 API 规则的约束：

```
订阅权限规则:
├── 订阅集合 (subscribe '*') → 受 ListRule 约束
├── 订阅单条记录 (subscribe 'id') → 受 ViewRule 约束
└── 如果规则为 null（锁定）→ 无法订阅
```

### 9.6.2 ListRule 对集合订阅的影响

```javascript
// 假设 posts 集合的 ListRule 为:
// @request.auth.id != ""

// 未认证用户 → 不会收到任何事件
pb.collection('posts').subscribe('*', function (e) {
    // 如果用户未登录，此回调不会被触发
    console.log(e);
});

// 认证用户 → 只收到满足 ListRule 条件的记录事件
await pb.collection('users').authWithPassword('user@example.com', 'password123');
pb.collection('posts').subscribe('*', function (e) {
    // 只有当变更的记录满足 ListRule 时，才会收到事件
    console.log(e);
});
```

### 9.6.3 ViewRule 对记录订阅的影响

```javascript
// 假设 posts 集合的 ViewRule 为:
// @request.auth.id = author || status = "published"

// 订阅特定记录时，只有满足 ViewRule 的用户才会收到事件
pb.collection('posts').subscribe('RECORD_ID', function (e) {
    // 只有当前用户是作者，或记录状态为 "published" 时，才会收到事件
    console.log(e);
});
```

### 9.6.4 权限变更的动态影响

```
当记录数据变更导致权限条件不再满足时:

场景: ListRule = "status = 'published'"

1. 记录 A 状态为 "published" → 用户可以收到事件
2. 管理员将记录 A 状态改为 "draft"
3. 用户收到一个 delete 事件（虽然记录未被删除，但对该用户来说"消失"了）
4. 管理员将记录 A 状态改回 "published"
5. 用户收到一个 create 事件（记录重新对该用户"可见"）
```

## 9.7 认证状态与订阅

### 9.7.1 Token过期对订阅的影响

```
认证 token 过期时:
├── SSE 连接本身不会立即断开
├── 但新的数据推送会受到影响（权限检查可能失败）
├── 建议在 token 即将过期前刷新
└── PocketBase JS SDK 支持自动 token 刷新
```

### 9.7.2 自动重连机制

PocketBase JS SDK 内置了自动重连机制：

```javascript
const pb = new PocketBase('http://127.0.0.1:8090');

// SDK 自动处理以下情况:
// 1. 网络断开后重连
// 2. 服务器重启后重连
// 3. SSE 连接超时后重连

// 自动重连默认是启用的
pb.collection('posts').subscribe('*', function (e) {
    console.log('收到事件:', e);
});

// 你可以监听连接状态变化
pb.realtime.onDisconnect = function () {
    console.log('连接断开');
    // 可以在UI上显示断开状态
};
```

### 9.7.3 手动刷新认证

```javascript
const pb = new PocketBase('http://127.0.0.1:8090');

// 登录
await pb.collection('users').authWithPassword('user@example.com', 'password123');

// 订阅
pb.collection('posts').subscribe('*', function (e) {
    console.log(e);
});

// 定期刷新 token（在 token 过期前）
setInterval(async () => {
    try {
        await pb.collection('users').authRefresh();
        console.log('Token 已刷新');
    } catch (err) {
        console.log('Token 刷新失败，需要重新登录');
        // 重新登录
        await pb.collection('users').authWithPassword('user@example.com', 'password123');
    }
}, 10 * 60 * 1000); // 每10分钟刷新一次
```

### 9.7.4 登出对订阅的影响

```javascript
// 登出时，所有需要认证的订阅都会失效
pb.authStore.clear();

// 建议在登出前显式取消所有订阅
async function logout() {
    // 1. 取消所有订阅
    await pb.realtime.unsubscribe();

    // 2. 清除认证状态
    pb.authStore.clear();

    // 3. 跳转到登录页
    window.location.href = '/login';
}
```

## 9.8 原生SSE实现

### 9.8.1 不使用SDK的原生实现

如果你不想使用 PocketBase JS SDK，可以使用浏览器原生的 EventSource API：

```javascript
// 步骤 1: 建立 SSE 连接
const eventSource = new EventSource('http://127.0.0.1:8090/api/realtime');

let clientId = null;

// 步骤 2: 获取 clientId
eventSource.addEventListener('PB_CONNECT', function (e) {
    const data = JSON.parse(e.data);
    clientId = data.clientId;
    console.log('连接成功，clientId:', clientId);

    // 步骤 3: 使用 clientId 订阅集合
    subscribeToCollection('posts');
});

// 步骤 4: 订阅函数
async function subscribeToCollection(collectionName) {
    const response = await fetch('http://127.0.0.1:8090/api/realtime', {
        method: 'POST',
        headers: {
            'Content-Type': 'application/json',
            // 如果需要认证，添加 Authorization 头
            // 'Authorization': 'Bearer USER_TOKEN'
        },
        body: JSON.stringify({
            clientId: clientId,
            subscriptions: [collectionName]
        })
    });

    if (response.ok) {
        console.log('订阅成功:', collectionName);
    }
}

// 步骤 5: 监听集合事件
eventSource.addEventListener('posts', function (e) {
    const data = JSON.parse(e.data);
    console.log('收到 posts 事件:');
    console.log('  操作:', data.action);
    console.log('  记录:', data.record);
});

// 步骤 6: 错误处理
eventSource.onerror = function (e) {
    console.log('SSE 连接错误:', e);
    if (eventSource.readyState === EventSource.CLOSED) {
        console.log('连接已关闭，尝试重连...');
        // EventSource 会自动重连
    }
};

// 步骤 7: 关闭连接
function disconnect() {
    eventSource.close();
    console.log('SSE 连接已关闭');
}
```

### 9.8.2 带认证的原生实现

由于 EventSource API 不支持自定义请求头，对于需要认证的场景需要额外处理：

```javascript
// 方法 1: 使用 URL 参数传递 token（不推荐用于生产环境）
// PocketBase 不直接支持此方式

// 方法 2: 先建立连接，然后在订阅请求中携带认证信息
const eventSource = new EventSource('http://127.0.0.1:8090/api/realtime');

eventSource.addEventListener('PB_CONNECT', async function (e) {
    const data = JSON.parse(e.data);
    const clientId = data.clientId;

    // 订阅时携带认证 token
    await fetch('http://127.0.0.1:8090/api/realtime', {
        method: 'POST',
        headers: {
            'Content-Type': 'application/json',
            'Authorization': 'Bearer YOUR_AUTH_TOKEN'
        },
        body: JSON.stringify({
            clientId: clientId,
            subscriptions: ['private_messages']
        })
    });
});

eventSource.addEventListener('private_messages', function (e) {
    const data = JSON.parse(e.data);
    console.log('收到私信:', data.record);
});
```

### 9.8.3 使用fetch API实现SSE（现代方式）

```javascript
// 使用 fetch + ReadableStream 实现 SSE（更灵活）
async function connectSSE(url, token) {
    const response = await fetch(url, {
        headers: {
            'Accept': 'text/event-stream',
            'Authorization': token ? `Bearer ${token}` : ''
        }
    });

    const reader = response.body.getReader();
    const decoder = new TextDecoder();
    let buffer = '';

    while (true) {
        const { done, value } = await reader.read();
        if (done) break;

        buffer += decoder.decode(value, { stream: true });

        // 解析 SSE 数据
        const lines = buffer.split('\n');
        buffer = lines.pop(); // 保留不完整的行

        let eventType = '';
        let eventData = '';

        for (const line of lines) {
            if (line.startsWith('event:')) {
                eventType = line.slice(6).trim();
            } else if (line.startsWith('data:')) {
                eventData = line.slice(5).trim();
            } else if (line === '') {
                // 空行表示事件结束
                if (eventType && eventData) {
                    handleEvent(eventType, JSON.parse(eventData));
                }
                eventType = '';
                eventData = '';
            }
        }
    }
}

function handleEvent(type, data) {
    console.log(`事件类型: ${type}`);
    console.log(`事件数据:`, data);
}
```

## 9.9 订阅过滤与优化

### 9.9.1 控制订阅粒度

```
订阅粒度选择:
├── 订阅整个集合 ('*') → 适合需要全局视图的场景
├── 订阅单条记录 ('id') → 适合详情页面
└── 订阅多个特定记录 → 适合选定列表

选择建议:
├── 列表页面 → 订阅集合 ('*')
├── 详情页面 → 订阅单条记录 ('id')
├── 仪表盘 → 订阅相关集合 ('*')
└── 通知中心 → 订阅通知集合 ('*')
```

### 9.9.2 减少不必要的数据传输

```javascript
// 技巧 1: 只在需要时订阅
// 不要在应用启动时订阅所有集合，而是在进入相应页面时才订阅

// 路由级别的订阅管理
```

```javascript
// 当收到大量事件时，使用防抖/节流来减少UI更新频率
function debounce(func, wait) {
    let timeout;
    return function (...args) {
        clearTimeout(timeout);
        timeout = setTimeout(() => func.apply(this, args), wait);
    };
}

const pendingUpdates = [];

const flushUpdates = debounce(() => {
    // 批量处理所有待处理的更新
    console.log(`批量处理 ${pendingUpdates.length} 个更新`);

    // 一次性更新状态
    setPosts(prevPosts => {
        let updated = [...prevPosts];
        for (const event of pendingUpdates) {
            switch (event.action) {
                case 'create':
                    updated.push(event.record);
                    break;
                case 'update':
                    updated = updated.map(p =>
                        p.id === event.record.id ? event.record : p
                    );
                    break;
                case 'delete':
                    updated = updated.filter(p => p.id !== event.record.id);
                    break;
            }
        }
        return updated;
    });

    pendingUpdates.length = 0;
}, 100); // 100ms 防抖

pb.collection('posts').subscribe('*', function (e) {
    pendingUpdates.push(e);
    flushUpdates();
});
```

```javascript
            await pb.collection('messages').unsubscribe('*');

        this.currentRoom = roomId;

                    this.messages.push(e.record);
                    if (this.onNewMessage) this.onNewMessage(e.record);

                    if (idx !== -1) this.messages[idx] = e.record;
                    if (this.onMessageUpdate) this.onMessageUpdate(e.record);
                    break;
                case 'delete':
                    this.messages = this.messages.filter(m => m.id !== e.record.id);
                    if (this.onMessageDelete) this.onMessageDelete(e.record.id);
                    break;
            }
        });

        return this.messages;

    }

    // 离开聊天室
    async leaveRoom() {
        await pb.collection('messages').unsubscribe('*');
        this.currentRoom = null;
        this.messages = [];
    }

    // 登出
    async logout() {
        await pb.realtime.unsubscribe();
        pb.authStore.clear();
    }
}
```

```javascript
import PocketBase from 'pocketbase';

const pb = new PocketBase('http://127.0.0.1:8090');

class NotificationSystem {
    constructor() {
        this.notifications = [];
        this.unreadCount = 0;
        this.onNotification = null;
        this.onCountChange = null;
    }

    async init() {
        // 加载未读通知
        await this.loadUnreadNotifications();

        // 订阅新通知
        pb.collection('notifications').subscribe('*', (e) => {
            // 只处理当前用户的通知
            if (e.record.user !== pb.authStore.model.id) return;

            switch (e.action) {
                case 'create':
                    this.notifications.unshift(e.record);
                    this.unreadCount++;
                    this.showBrowserNotification(e.record);
                    if (this.onNotification) this.onNotification(e.record);
                    if (this.onCountChange) this.onCountChange(this.unreadCount);
                    break;

                case 'update':
                    const idx = this.notifications.findIndex(n => n.id === e.record.id);
                    if (idx !== -1) {
                        const wasUnread = !this.notifications[idx].read;
                        const isNowRead = e.record.read;
                        this.notifications[idx] = e.record;

                        if (wasUnread && isNowRead) {
                            this.unreadCount = Math.max(0, this.unreadCount - 1);
                            if (this.onCountChange) this.onCountChange(this.unreadCount);
                        }
                    }
                    break;

                case 'delete':
                    const delIdx = this.notifications.findIndex(n => n.id === e.record.id);
                    if (delIdx !== -1) {
                        if (!this.notifications[delIdx].read) {
                            this.unreadCount = Math.max(0, this.unreadCount - 1);
                        }
                        this.notifications.splice(delIdx, 1);
                        if (this.onCountChange) this.onCountChange(this.unreadCount);
                    }
                    break;
            }
        });
    }

    async loadUnreadNotifications() {
        const result = await pb.collection('notifications').getList(1, 50, {
            filter: `user = "${pb.authStore.model.id}"`,
            sort: '-created'
        });
        this.notifications = result.items;
        this.unreadCount = this.notifications.filter(n => !n.read).length;
    }

    // 标记通知为已读
    async markAsRead(notificationId) {
        await pb.collection('notifications').update(notificationId, {
            read: true
        });
    }

    // 标记所有通知为已读
    async markAllAsRead() {
        const unread = this.notifications.filter(n => !n.read);
        const promises = unread.map(n =>
            pb.collection('notifications').update(n.id, { read: true })
        );
        await Promise.all(promises);
        this.unreadCount = 0;
        if (this.onCountChange) this.onCountChange(0);
    }

    // 显示浏览器原生通知
    showBrowserNotification(notification) {
        if ('Notification' in window && Notification.permission === 'granted') {
            new Notification(notification.title, {
                body: notification.message,
                icon: '/notification-icon.png',
                tag: notification.id
            });
        }
    }

    // 请求通知权限
    async requestPermission() {
        if ('Notification' in window) {
            const permission = await Notification.requestPermission();
            return permission === 'granted';
        }
        return false;
    }

    // 销毁
    async destroy() {
        await pb.collection('notifications').unsubscribe('*');
    }
}

// ==================== 使用示例 ====================

const notificationSystem = new NotificationSystem();

// 请求浏览器通知权限
await notificationSystem.requestPermission();

// 设置回调
notificationSystem.onNotification = (notification) => {
    console.log('新通知:', notification.title, '-', notification.message);
    // 在页面上显示 Toast 通知
};

notificationSystem.onCountChange = (count) => {
    console.log('未读通知数:', count);
    // 更新导航栏上的未读角标
    document.getElementById('notificationBadge').textContent = count;
};

// 初始化
```

```javascript
import PocketBase from 'pocketbase';

const pb = new PocketBase('http://127.0.0.1:8090');

class CollaborativeEditor {
    constructor(documentId) {
        this.documentId = documentId;
        this.document = null;
        this.onDocumentUpdate = null;
        this.onCollaboratorChange = null;
    }

    async init() {
        // 加载文档
        this.document = await pb.collection('documents').getOne(this.documentId, {
            expand: 'owner,collaborators,lastEditedBy'
        });

        // 订阅文档变更
        pb.collection('documents').subscribe(this.documentId, async (e) => {
            if (e.action === 'update') {
                // 检查是否是其他人的编辑
                if (e.record.lastEditedBy !== pb.authStore.model.id) {
                    this.document = e.record;
                    if (this.onDocumentUpdate) {
                        this.onDocumentUpdate(e.record);
                    }
                }
            }

            if (e.action === 'delete') {
                console.log('文档已被删除');
                window.location.href = '/documents';
            }
        });

        // 订阅编辑锁变更（了解其他协作者的编辑状态）
        pb.collection('edit_locks').subscribe('*', (e) => {
            if (e.record.document !== this.documentId) return;
            if (e.record.user === pb.authStore.model.id) return;

            if (this.onCollaboratorChange) {
                this.onCollaboratorChange(e.action, e.record);
            }
        });

        return this.document;
    }

    // 保存文档
    async save(content) {
        this.document = await pb.collection('documents').update(this.documentId, {
            content: content,
            lastEditedBy: pb.authStore.model.id,
            version: this.document.version + 1
        });
        return this.document;
    }

    // 获取编辑锁
    async acquireLock(section) {
        const expiresAt = new Date(Date.now() + 30000).toISOString(); // 30秒后过期
        return await pb.collection('edit_locks').create({
            document: this.documentId,
            user: pb.authStore.model.id,
            section: section,
            expiresAt: expiresAt
        });
    }

    // 释放编辑锁
    async releaseLock(lockId) {
        await pb.collection('edit_locks').delete(lockId);
    }

    // 清理
    async destroy() {
        await pb.collection('documents').unsubscribe(this.documentId);
        await pb.collection('edit_locks').unsubscribe('*');
    }
}
```

### 9.11.6 SSE降级方案

```javascript
// 当 SSE 不可用时，降级为轮询
class RealtimeManager {
    constructor(pb) {
        this.pb = pb;
        this.useSSE = true;
        this.pollingInterval = null;
        this.callbacks = {};
    }

    async subscribe(collection, topic, callback) {
        this.callbacks[`${collection}:${topic}`] = callback;

        try {
            // 尝试使用 SSE
            this.pb.collection(collection).subscribe(topic, callback);
            this.useSSE = true;
            console.log('使用 SSE 实时订阅');
        } catch (err) {
            // 降级为轮询
            console.warn('SSE 不可用，降级为轮询模式');
            this.useSSE = false;
            this.startPolling(collection);
        }
    }

    startPolling(collection) {
        let lastCheck = new Date().toISOString();

        this.pollingInterval = setInterval(async () => {
            try {
                const records = await this.pb.collection(collection).getList(1, 50, {
                    filter: `updated > "${lastCheck}"`,
                    sort: '-updated'
                });

                lastCheck = new Date().toISOString();

                for (const record of records.items) {
                    const key = `${collection}:*`;
                    if (this.callbacks[key]) {
                        this.callbacks[key]({
                            action: 'update',
                            record: record
                        });
                    }
                }
            } catch (err) {
                console.error('轮询错误:', err);
            }
        }, 5000); // 每5秒轮询一次
    }

    unsubscribe(collection, topic) {
        delete this.callbacks[`${collection}:${topic}`];

        if (this.useSSE) {
            this.pb.collection(collection).unsubscribe(topic);
        }

        if (Object.keys(this.callbacks).length === 0 && this.pollingInterval) {
            clearInterval(this.pollingInterval);
        }
    }
}
```
