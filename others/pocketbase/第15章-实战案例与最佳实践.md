# 第15章 实战案例与最佳实践

## 15.1 实战案例一：博客系统

### 15.1.1 数据模型设计

博客系统需要以下集合：

**users（Auth集合）**：
- username（Text）：用户名
- avatar（File）：头像
- bio（Text）：个人简介

**posts（Base集合）**：
- title（Text）：文章标题
- slug（Text，唯一索引）：URL友好标识
- content（Editor）：文章内容
- cover（File）：封面图片
- author（Relation → users）：作者
- tags（Select，多选）：标签
- status（Select）：状态（draft/published）
- published_at（Date）：发布时间

**comments（Base集合）**：
- post（Relation → posts）：关联文章
- user（Relation → users）：评论用户
- content（Text）：评论内容
- parent（Relation → comments）：父评论（支持嵌套回复）

### 15.1.2 API规则配置

```
// posts集合
ListRule:   "status = 'published' || author = @request.auth.id"
ViewRule:   "status = 'published' || author = @request.auth.id"
CreateRule: "@request.auth.id != ''"
UpdateRule: "author = @request.auth.id"
DeleteRule: "author = @request.auth.id"

// comments集合
ListRule:   ""
ViewRule:   ""
CreateRule: "@request.auth.id != ''"
UpdateRule: "user = @request.auth.id"
DeleteRule: "user = @request.auth.id"
```

### 15.1.3 前端集成示例

```javascript
import PocketBase from 'pocketbase';
const pb = new PocketBase('http://127.0.0.1:8090');

// 获取已发布文章列表
async function getPublishedPosts(page = 1) {
    return await pb.collection('posts').getList(page, 10, {
        filter: 'status = "published"',
        sort: '-published_at',
        expand: 'author',
        fields: 'id,title,slug,cover,created,expand.author.username,expand.author.avatar'
    });
}

// 创建文章
async function createPost(data) {
    const formData = new FormData();
    formData.append('title', data.title);
    formData.append('content', data.content);
    formData.append('slug', data.slug);
    formData.append('status', 'draft');
    formData.append('author', pb.authStore.record.id);
    if (data.cover) formData.append('cover', data.cover);
    
    return await pb.collection('posts').create(formData);
}

// 获取文章评论
async function getComments(postId) {
    return await pb.collection('comments').getFullList({
        filter: `post = "${postId}"`,
        sort: 'created',
        expand: 'user,parent'
    });
}
```

## 15.2 实战案例二：任务管理系统

### 15.2.1 数据模型

**teams（Base集合）**：
- name（Text）：团队名称
- members（Relation → users，多选）：成员列表

**projects（Base集合）**：
- name（Text）：项目名称
- team（Relation → teams）：所属团队
- description（Text）：项目描述

**tasks（Base集合）**：
- title（Text）：任务标题
- description（Editor）：详细描述
- project（Relation → projects）：所属项目
- assignee（Relation → users）：负责人
- status（Select）：状态（todo/in_progress/done）
- priority（Select）：优先级（low/medium/high）
- due_date（Date）：截止日期
- attachments（File，多文件）：附件

### 15.2.2 实时任务看板

```javascript
// 订阅任务变更实现实时看板
function initTaskBoard(projectId) {
    pb.collection('tasks').subscribe('*', (e) => {
        switch (e.action) {
            case 'create':
                addTaskToBoard(e.record);
                break;
            case 'update':
                updateTaskOnBoard(e.record);
                break;
            case 'delete':
                removeTaskFromBoard(e.record);
                break;
        }
    }, {
        filter: `project = "${projectId}"`
    });
}

// 拖拽更新任务状态
async function updateTaskStatus(taskId, newStatus) {
    await pb.collection('tasks').update(taskId, {
        status: newStatus
    });
}
```

## 15.3 实战案例三：实时聊天应用

### 15.3.1 数据模型

**channels（Base集合）**：
- name（Text）：频道名称
- members（Relation → users，多选）：成员
- type（Select）：类型（public/private/direct）

**messages（Base集合）**：
- channel（Relation → channels）：所属频道
- sender（Relation → users）：发送者
- content（Text）：消息内容
- attachments（File，多文件）：附件
- type（Select）：消息类型（text/image/file）

### 15.3.2 实时消息收发

```javascript
// 发送消息
async function sendMessage(channelId, content) {
    return await pb.collection('messages').create({
        channel: channelId,
        sender: pb.authStore.record.id,
        content: content,
        type: 'text'
    });
}

// 监听新消息
function listenMessages(channelId, onMessage) {
    pb.collection('messages').subscribe('*', (e) => {
        if (e.action === 'create' && e.record.channel === channelId) {
            onMessage(e.record);
        }
    });
}

// 加载历史消息
async function loadHistory(channelId, page = 1) {
    return await pb.collection('messages').getList(page, 50, {
        filter: `channel = "${channelId}"`,
        sort: '-created',
        expand: 'sender'
    });
}
```

## 15.4 最佳实践总结

### 15.4.1 数据建模最佳实践

1. **集合命名**：使用小写复数形式（如 posts、users、comments）
2. **字段命名**：使用 snake_case 命名（如 created_at、is_active）
3. **关联设计**：优先使用 Relation 字段而非手动存储 ID
4. **索引规划**：为常用查询和过滤字段添加索引
5. **Auth集合分离**：不同角色使用不同的 Auth 集合

### 15.4.2 API规则最佳实践

1. **默认锁定**：所有集合默认设置严格的访问规则
2. **最小权限原则**：只授予必要的最小权限
3. **所有者验证**：修改和删除操作验证资源所有者
4. **字段级控制**：使用 `@request.data` 限制可修改的字段

### 15.4.3 安全最佳实践

1. **HTTPS**：生产环境必须启用 HTTPS
2. **强密码**：管理员使用强密码并启用 MFA
3. **CORS**：限制允许的域名
4. **备份**：建立定期自动备份机制
5. **更新**：及时更新到最新版本

### 15.4.4 性能最佳实践

1. **分页查询**：始终使用分页，避免一次加载大量数据
2. **字段选择**：使用 fields 参数只返回需要的字段
3. **合理展开**：避免过度使用 expand，按需展开关联
4. **订阅粒度**：实时订阅使用最小粒度
5. **缓存策略**：前端实现合理的缓存机制

### 15.4.5 部署最佳实践

1. **容器化**：使用 Docker 部署，确保环境一致性
2. **反向代理**：使用 Nginx/Caddy 处理 HTTPS 和负载均衡
3. **监控告警**：建立健康检查和监控体系
4. **版本固定**：Docker 镜像使用固定版本号
5. **日志管理**：配置日志轮转和集中管理

## 15.5 常见问题解答（FAQ）

### Q1：PocketBase适合什么规模的项目？

PocketBase 最适合中小型项目，单实例可支持数千并发用户。对于需要水平扩展的大型分布式系统，建议结合其他方案。

### Q2：如何处理SQLite的并发写入限制？

SQLite 在 WAL 模式下可以并发读取，写入使用串行化。对于写入密集型场景，可以：
- 使用批量写入减少事务次数
- 在应用层实现写入队列
- 考虑使用消息队列异步处理

### Q3：如何实现多租户？

可以通过以下方式实现多租户：
- 在每个集合添加 tenant_id 字段
- API 规则中过滤租户数据
- 或运行多个 PocketBase 实例

### Q4：如何实现全文搜索？

PocketBase 支持基本的文本搜索（使用 `~` 操作符），对于复杂的全文搜索需求，可以集成 Meilisearch 或 Typesense。

### Q5：数据如何迁移？

- 使用 pb_migrations 目录管理数据库结构变更
- 数据迁移可以通过 JavaScript 钩子或 Go 扩展实现
- 整体迁移只需复制 pb_data 目录

### Q6：如何实现文件CDN加速？

配置 S3 兼容存储后，可以在 S3 存储桶前配置 CDN（如 CloudFront、阿里云 CDN），实现文件的全球加速访问。
