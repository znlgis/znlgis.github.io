# 第08章 文件存储与管理

PocketBase 内置了完整的文件存储功能，支持文件上传、下载、缩略图生成以及 S3 兼容的外部存储。本章将全面讲解 PocketBase 文件管理的各个方面，帮助你在应用中高效地处理文件。

---

## 8.1 文件存储概述

### 8.1.1 内置文件存储

PocketBase 默认使用本地文件系统来存储上传的文件。所有文件存储在 `pb_data/storage` 目录下，按集合和记录组织。

```
pb_data/
├── data.db              # SQLite 数据库
└── storage/
    └── {collectionId}/
        └── {recordId}/
            ├── image1.jpg
            ├── image2.png
            └── document.pdf
```

### 8.1.2 文件字段类型

在 PocketBase 中，文件通过集合中的 **File** 类型字段来管理。每个 File 字段可以配置为：

- **单文件字段：** 只允许上传一个文件
- **多文件字段：** 允许上传多个文件（可配置最大数量）

### 8.1.3 支持的功能

```
PocketBase 文件存储功能:
├── 文件上传 (单个/批量)
├── 文件下载
├── 缩略图自动生成 (图片文件)
├── 文件删除
├── MIME类型限制
├── 文件大小限制
├── S3兼容存储 (AWS S3, MinIO, 阿里云OSS 等)
└── 文件访问权限控制
```

## 8.2 文件上传

### 8.2.1 通过API上传文件

文件上传通过 `multipart/form-data` 格式的 POST 或 PATCH 请求完成。

**使用 curl 上传单个文件：**

```bash
# 创建记录并上传文件
curl -X POST http://127.0.0.1:8090/api/collections/articles/records \
  -H "Authorization: Bearer USER_TOKEN" \
  -F "title=我的文章" \
  -F "content=文章内容" \
  -F "cover=@/path/to/cover.jpg"
```

**使用 curl 上传多个文件：**

```bash
# 上传多个文件到同一个字段
curl -X POST http://127.0.0.1:8090/api/collections/galleries/records \
  -H "Authorization: Bearer USER_TOKEN" \
  -F "title=我的相册" \
  -F "images=@/path/to/photo1.jpg" \
  -F "images=@/path/to/photo2.jpg" \
  -F "images=@/path/to/photo3.png"
```

**使用 curl 更新记录中的文件：**

```bash
# 更新记录时替换文件
curl -X PATCH http://127.0.0.1:8090/api/collections/articles/records/RECORD_ID \
  -H "Authorization: Bearer USER_TOKEN" \
  -F "cover=@/path/to/new-cover.jpg"
```

### 8.2.2 使用JavaScript SDK上传

**单文件上传：**

```javascript
import PocketBase from 'pocketbase';
const pb = new PocketBase('http://127.0.0.1:8090');

// 登录
await pb.collection('users').authWithPassword('user@example.com', 'password123');

// 从文件输入获取文件
const fileInput = document.getElementById('fileInput');
const file = fileInput.files[0];

// 创建 FormData
const formData = new FormData();
formData.append('title', '我的文章');
formData.append('content', '文章内容');
formData.append('cover', file);

// 上传
const record = await pb.collection('articles').create(formData);
console.log('上传成功:', record);
```

**多文件上传：**

```javascript
// 从多文件输入获取文件
const fileInput = document.getElementById('multiFileInput');
const files = fileInput.files;

const formData = new FormData();
formData.append('title', '我的相册');

// 添加多个文件
for (let i = 0; i < files.length; i++) {
    formData.append('images', files[i]);
}

const record = await pb.collection('galleries').create(formData);
console.log('上传成功:', record);
```

**在现有记录中追加文件：**

```javascript
// 获取现有记录
const record = await pb.collection('galleries').getOne('RECORD_ID');

// 追加新文件（保留现有文件）
const formData = new FormData();
formData.append('images', newFile);

// 使用 "images+" 来追加文件，而不是替换
// 注意：需要在 formData 中标记为追加操作
const updated = await pb.collection('galleries').update('RECORD_ID', formData);
```

### 8.2.3 在浏览器中使用拖拽上传

```html
<!DOCTYPE html>
<html>
<head>
    <title>文件拖拽上传</title>
    <style>
        #dropZone {
            width: 400px;

            display: flex;
            align-items: center;
            justify-content: center;
            margin: 20px auto;
        }

            border-color: #007bff;

        }
    </style>
</head>
<body>
    <div id="dropZone">拖拽文件到此处上传</div>
    <div id="result"></div>

    <script type="module">
        import PocketBase from 'https://cdn.jsdelivr.net/npm/pocketbase@latest/dist/pocketbase.es.mjs';

        const pb = new PocketBase('http://127.0.0.1:8090');
        await pb.collection('users').authWithPassword('user@example.com', 'password123');

        dropZone.addEventListener('dragover', (e) => {
            e.preventDefault();
            dropZone.classList.add('dragover');
        });

        dropZone.addEventListener('dragleave', () => {
            dropZone.classList.remove('dragover');
        });

        dropZone.addEventListener('drop', async (e) => {
            e.preventDefault();
            dropZone.classList.remove('dragover');

            const files = e.dataTransfer.files;
            const formData = new FormData();
            formData.append('title', '拖拽上传的文件');

            for (let i = 0; i < files.length; i++) {
                formData.append('attachments', files[i]);
            }

            try {
                const record = await pb.collection('uploads').create(formData);
                document.getElementById('result').textContent = '上传成功: ' + record.id;
            } catch (err) {
                document.getElementById('result').textContent = '上传失败: ' + err.message;
            }
        });
    </script>
</body>
</html>
```

### 8.2.4 Node.js环境上传

```javascript
import PocketBase from 'pocketbase';
import fs from 'fs';
import path from 'path';

const pb = new PocketBase('http://127.0.0.1:8090');
await pb.admins.authWithPassword('admin@example.com', 'admin-password');

// 从本地文件系统读取文件
const filePath = '/path/to/document.pdf';
const fileBuffer = fs.readFileSync(filePath);
const fileName = path.basename(filePath);

// 创建 Blob 对象（Node.js 环境）
const file = new File([fileBuffer], fileName, { type: 'application/pdf' });

const formData = new FormData();
formData.append('title', '服务端上传');
formData.append('document', file);

const record = await pb.collection('documents').create(formData);
console.log('上传成功:', record.id);
```

## 8.3 文件字段配置

### 8.3.1 基本配置选项

在管理面板中创建 File 类型字段时，可以配置以下选项：

| 配置项 | 说明 | 示例值 |
|--------|------|--------|
| Max file size | 单个文件最大大小 | 5242880 (5MB) |
| Max select | 最大文件数量 | 1（单文件）, 10（多文件） |
| MIME types | 允许的文件类型 | image/jpeg, image/png, application/pdf |
| Thumbs | 缩略图尺寸配置 | 100x100, 300x300 |

### 8.3.2 MIME类型限制

常用 MIME 类型配置：

```
图片文件:
├── image/jpeg          (.jpg, .jpeg)
├── image/png           (.png)
├── image/gif           (.gif)
├── image/webp          (.webp)
├── image/svg+xml       (.svg)
└── image/bmp           (.bmp)

文档文件:
├── application/pdf                                           (.pdf)
├── application/msword                                        (.doc)
├── application/vnd.openxmlformats-officedocument.wordprocessingml.document  (.docx)
├── application/vnd.ms-excel                                  (.xls)
├── application/vnd.openxmlformats-officedocument.spreadsheetml.sheet       (.xlsx)
└── text/plain                                                (.txt)

音视频文件:
├── video/mp4           (.mp4)
├── video/webm          (.webm)
├── audio/mpeg          (.mp3)
├── audio/wav           (.wav)
└── audio/ogg           (.ogg)

压缩文件:
├── application/zip                (.zip)
├── application/x-rar-compressed   (.rar)
└── application/gzip               (.gz)
```

### 8.3.3 文件大小限制

```
文件大小以字节为单位配置:
├── 1 MB  = 1048576
├── 5 MB  = 5242880
├── 10 MB = 10485760
├── 50 MB = 52428800
└── 100 MB = 104857600
```

**注意：** 除了字段级的文件大小限制，PocketBase 还有一个全局请求体大小限制。默认情况下，单个请求最大允许约 **~10MB** 的请求体。如果需要上传更大的文件，需要调整相关配置。

### 8.3.4 配置示例

**用户头像字段：**

```
字段名: avatar
类型: File
Max select: 1
Max file size: 2097152 (2MB)
MIME types: image/jpeg, image/png, image/webp
Thumbs: 100x100, 200x200
```

**产品图片字段：**

```
字段名: images
类型: File
Max select: 10
Max file size: 5242880 (5MB)
MIME types: image/jpeg, image/png, image/webp
Thumbs: 150x150, 400x400, 800x800
```

**文档附件字段：**

```
字段名: attachments
类型: File
Max select: 5
Max file size: 10485760 (10MB)
MIME types: application/pdf, application/msword,
           application/vnd.openxmlformats-officedocument.wordprocessingml.document
Thumbs: (不配置，非图片文件无需缩略图)
```

## 8.4 文件访问

### 8.4.1 文件URL格式

PocketBase 中的文件可以通过以下 URL 格式访问：

```
http://127.0.0.1:8090/api/files/{collectionIdOrName}/{recordId}/{filename}
```

**示例：**

```
http://127.0.0.1:8090/api/files/articles/abc123def456/cover_image.jpg
http://127.0.0.1:8090/api/files/users/user789xyz/avatar_photo.png
```

### 8.4.2 通过API获取文件URL

当你通过 API 获取记录时，文件字段的值是文件名（不是完整URL）。你需要自行拼接完整的 URL。

**curl 获取记录：**

```bash
curl http://127.0.0.1:8090/api/collections/articles/records/RECORD_ID
```

**返回结果：**

```json
{
    "id": "abc123def456",
    "collectionId": "xyz789",
    "collectionName": "articles",
    "title": "我的文章",
    "cover": "cover_abc123.jpg",
    "images": ["img1_abc.jpg", "img2_def.png", "img3_ghi.jpg"],
    "created": "2024-01-01 00:00:00.000Z",
    "updated": "2024-01-01 00:00:00.000Z"
}
```

### 8.4.3 使用JS SDK获取文件URL

```javascript
import PocketBase from 'pocketbase';
const pb = new PocketBase('http://127.0.0.1:8090');

// 获取记录
const record = await pb.collection('articles').getOne('RECORD_ID');

// 获取单文件URL
const coverUrl = pb.files.getURL(record, record.cover);
console.log('封面URL:', coverUrl);
// 输出: http://127.0.0.1:8090/api/files/articles/abc123def456/cover_abc123.jpg

// 获取多文件URL
const imageUrls = record.images.map(filename => {
    return pb.files.getURL(record, filename);
});
console.log('图片URLs:', imageUrls);

// 获取缩略图URL
const thumbUrl = pb.files.getURL(record, record.cover, { thumb: '100x100' });
console.log('缩略图URL:', thumbUrl);
```

### 8.4.4 在HTML中显示文件

```html
<!-- 显示图片 -->
<img src="http://127.0.0.1:8090/api/files/articles/abc123/cover.jpg" alt="封面">

<!-- 显示缩略图 -->
<img src="http://127.0.0.1:8090/api/files/articles/abc123/cover.jpg?thumb=100x100" alt="缩略图">

<!-- 下载文件 -->
<a href="http://127.0.0.1:8090/api/files/documents/doc456/report.pdf" download>
    下载报告
</a>
```

### 8.4.5 使用token访问受保护的文件

对于需要认证才能访问的文件，需要在 URL 中附加 token 参数：

```javascript
// 获取文件访问 token
const fileToken = await pb.files.getToken();

// 在 URL 中附加 token
const protectedUrl = pb.files.getURL(record, record.cover, {
    token: fileToken
});

// 输出: http://127.0.0.1:8090/api/files/articles/abc123/cover.jpg?token=FILE_TOKEN
```

```bash
# 使用 curl 获取文件 token
FILE_TOKEN=$(curl -s -X POST http://127.0.0.1:8090/api/files/token \
  -H "Authorization: Bearer USER_TOKEN" \
  | jq -r '.token')

# 使用 token 访问受保护的文件
curl "http://127.0.0.1:8090/api/files/articles/abc123/cover.jpg?token=$FILE_TOKEN" \
  -o downloaded_cover.jpg
```

## 8.5 缩略图生成

### 8.5.1 缩略图配置

PocketBase 可以为图片文件自动生成缩略图。在 File 字段的配置中设置 `Thumbs` 选项。

**缩略图尺寸格式：**

```
{宽度}x{高度}     // 指定宽高，保持比例裁剪
{宽度}x{高度}t    // 指定宽高，保持比例适应（top 对齐）
{宽度}x{高度}b    // 指定宽高，保持比例适应（bottom 对齐）
{宽度}x{高度}f    // 指定宽高，强制拉伸（fit）
0x{高度}          // 指定高度，宽度自适应
{宽度}x0          // 指定宽度，高度自适应
```

**常用缩略图尺寸配置示例：**

```
头像: 100x100, 200x200
列表缩略图: 150x150, 300x200
详情图片: 800x600, 1200x0
```

### 8.5.2 支持的图片格式

PocketBase 的缩略图生成支持以下图片格式：

```
支持缩略图的格式:
├── JPEG (.jpg, .jpeg)
├── PNG (.png)
├── GIF (.gif) - 仅取第一帧
├── BMP (.bmp)
└── WebP (.webp)

不支持缩略图的格式:
├── SVG (.svg)
├── TIFF (.tiff)
└── 其他非标准图片格式
```

### 8.5.3 通过URL参数获取缩略图

```
# 原图
http://127.0.0.1:8090/api/files/articles/abc123/photo.jpg

# 100x100 缩略图
http://127.0.0.1:8090/api/files/articles/abc123/photo.jpg?thumb=100x100

# 300x300 缩略图
http://127.0.0.1:8090/api/files/articles/abc123/photo.jpg?thumb=300x300

# 宽度 800，高度自适应
http://127.0.0.1:8090/api/files/articles/abc123/photo.jpg?thumb=800x0

# 高度 600，宽度自适应
http://127.0.0.1:8090/api/files/articles/abc123/photo.jpg?thumb=0x600
```

**注意：** 只有在字段配置中预定义的缩略图尺寸才能使用。如果请求的尺寸未在配置中定义，则会返回原图。

### 8.5.4 JS SDK中获取缩略图

```javascript
const pb = new PocketBase('http://127.0.0.1:8090');
const record = await pb.collection('products').getOne('RECORD_ID');

// 获取不同尺寸的缩略图
const smallThumb = pb.files.getURL(record, record.image, { thumb: '100x100' });
const mediumThumb = pb.files.getURL(record, record.image, { thumb: '300x300' });
const largeThumb = pb.files.getURL(record, record.image, { thumb: '800x0' });

console.log('小缩略图:', smallThumb);
console.log('中缩略图:', mediumThumb);
console.log('大缩略图:', largeThumb);
```

### 8.5.5 响应式图片示例

```html
<!-- 使用 srcset 实现响应式图片 -->
<img
    src="http://127.0.0.1:8090/api/files/products/abc/photo.jpg?thumb=300x300"
    srcset="
        http://127.0.0.1:8090/api/files/products/abc/photo.jpg?thumb=150x150 150w,
        http://127.0.0.1:8090/api/files/products/abc/photo.jpg?thumb=300x300 300w,
        http://127.0.0.1:8090/api/files/products/abc/photo.jpg?thumb=600x600 600w
    "
    sizes="(max-width: 600px) 150px, (max-width: 1200px) 300px, 600px"
    alt="产品图片"
    loading="lazy"
>
```

### 8.5.6 缩略图缓存

PocketBase 在首次请求缩略图时生成并缓存它。后续请求将直接返回缓存的缩略图。

```
缩略图缓存位置:
pb_data/storage/{collectionId}/{recordId}/thumbs_{size}_{filename}

例如:
pb_data/storage/xyz789/abc123/thumbs_100x100_cover_abc123.jpg
```

## 8.6 文件删除

### 8.6.1 通过更新记录删除文件

**删除单文件字段的文件（使用curl）：**

```bash
# 将文件字段设置为空即可删除文件
curl -X PATCH http://127.0.0.1:8090/api/collections/articles/records/RECORD_ID \
  -H "Authorization: Bearer USER_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"cover": null}'
```

**从多文件字段中删除特定文件（使用curl）：**

```bash
# 使用 "字段名-" 语法删除指定文件
curl -X PATCH http://127.0.0.1:8090/api/collections/galleries/records/RECORD_ID \
  -H "Authorization: Bearer USER_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"images-": ["img2_def.png"]}'
```

### 8.6.2 使用JS SDK删除文件

```javascript
const pb = new PocketBase('http://127.0.0.1:8090');

// 删除单文件字段
await pb.collection('articles').update('RECORD_ID', {
    cover: null
});

// 从多文件字段中删除特定文件
await pb.collection('galleries').update('RECORD_ID', {
    'images-': ['img2_def.png']
});

// 删除多文件字段中的所有文件
await pb.collection('galleries').update('RECORD_ID', {
    images: null
});
```

### 8.6.3 删除记录时自动删除文件

当一条记录被删除时，PocketBase 会**自动删除**该记录关联的所有文件和缩略图。

```bash
# 删除记录及其所有文件
curl -X DELETE http://127.0.0.1:8090/api/collections/articles/records/RECORD_ID \
  -H "Authorization: Bearer USER_TOKEN"
```

## 8.7 S3兼容存储配置

### 8.7.1 为什么使用S3存储

```
S3 兼容存储的优势:
├── 存储容量无限制
├── 更好的文件分发（CDN 集成）
├── 数据持久性和冗余
├── 独立于应用服务器的存储
├── 适合大规模文件存储场景
└── 支持多区域部署
```

### 8.7.2 在管理面板中配置

1. 打开管理面板 (`http://127.0.0.1:8090/_/`)
2. 进入 **Settings（设置）**
3. 点击 **Files storage（文件存储）**
4. 启用 **S3 compatible storage（S3兼容存储）**
5. 填写以下配置项

### 8.7.3 AWS S3 配置

```
Endpoint:   s3.amazonaws.com
Bucket:     your-bucket-name
Region:     us-east-1
Access Key: YOUR_AWS_ACCESS_KEY
Secret:     YOUR_AWS_SECRET_KEY
Force path style addressing: false
```

**AWS IAM 策略示例：**

```json
{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Effect": "Allow",
            "Action": [
                "s3:GetObject",
                "s3:PutObject",
                "s3:DeleteObject",
                "s3:ListBucket"
            ],
            "Resource": [
                "arn:aws:s3:::your-bucket-name",
                "arn:aws:s3:::your-bucket-name/*"
            ]
        }
    ]
}
```

### 8.7.4 MinIO 配置

MinIO 是一个开源的 S3 兼容对象存储，适合自建存储。

```
Endpoint:   http://your-minio-server:9000
Bucket:     your-bucket-name
Region:     us-east-1 (或其他任意值)
Access Key: YOUR_MINIO_ACCESS_KEY
Secret:     YOUR_MINIO_SECRET_KEY
Force path style addressing: true
```

**Docker 部署 MinIO：**

```bash
# 启动 MinIO 容器
docker run -d \
  --name minio \
  -p 9000:9000 \
  -p 9001:9001 \
  -e MINIO_ROOT_USER=minioadmin \
  -e MINIO_ROOT_PASSWORD=minioadmin \
  -v /data/minio:/data \
  minio/minio server /data --console-address ":9001"

# 使用 MinIO Client 创建存储桶
docker exec -it minio mc alias set local http://localhost:9000 minioadmin minioadmin
docker exec -it minio mc mb local/pocketbase-files
```

### 8.7.5 阿里云OSS配置

```
Endpoint:   oss-cn-hangzhou.aliyuncs.com
Bucket:     your-oss-bucket
Region:     oss-cn-hangzhou
Access Key: YOUR_ALIYUN_ACCESS_KEY
Secret:     YOUR_ALIYUN_ACCESS_SECRET
Force path style addressing: false
```

**注意事项：**
- 阿里云 OSS 的 Endpoint 不需要包含 Bucket 名称
- Region 通常与 Endpoint 的区域部分相同
- 建议使用 RAM 子账户的 Access Key，避免使用主账户

Region:     ap-guangzhou
Access Key: YOUR_TENCENT_SECRET_ID

```
Endpoint:   https://{accountId}.r2.cloudflarestorage.com
Bucket:     your-bucket-name
Region:     auto
Access Key: YOUR_R2_ACCESS_KEY
Secret:     YOUR_R2_SECRET_KEY
Force path style addressing: true
```

### 8.7.8 迁移到S3存储

如果你已经有本地存储的文件并想迁移到 S3：

```
迁移步骤:
1. 配置好 S3 存储连接
2. 将 pb_data/storage 中的文件上传到 S3 存储桶（保持目录结构）
3. 在管理面板中启用 S3 存储
4. 验证文件是否可以正常访问
5. 确认无误后，可以删除本地的文件副本

⚠️ 注意: 目录结构必须与本地存储一致
   S3桶根目录/{collectionId}/{recordId}/{filename}
```

## 8.8 文件安全

### 8.8.1 文件访问权限控制

默认情况下，PocketBase 中的文件可以通过公开 URL 直接访问，不受 API 规则的限制。如果需要保护文件的访问，可以在管理面板中启用 **Protected** 选项。

### 8.8.2 受保护的文件

在字段配置中启用 "Protected" 选项后：

```
受保护的文件特性:
├── 不能通过公开 URL 直接访问
├── 需要有效的文件 token 才能访问
├── 文件 token 有有效期限制
├── 只有满足 ViewRule 的用户才能获取文件 token
└── 适用于敏感文件、付费内容等场景
```

**获取文件token并访问受保护文件：**

```javascript
const pb = new PocketBase('http://127.0.0.1:8090');

// 先登录
await pb.collection('users').authWithPassword('user@example.com', 'password123');

// 获取文件 token
const fileToken = await pb.files.getToken();

// 获取受保护文件的 URL
const record = await pb.collection('documents').getOne('RECORD_ID');
const fileUrl = pb.files.getURL(record, record.file, {
    token: fileToken
});

// fileUrl 格式:
// http://127.0.0.1:8090/api/files/documents/RECORD_ID/filename.pdf?token=FILE_TOKEN

// 在 <img> 或 <a> 中使用
document.getElementById('protectedImage').src = fileUrl;
```

### 8.8.3 安全最佳实践

```
✅ 推荐做法:
1. 对包含敏感信息的文件启用 Protected 选项
2. 使用 MIME 类型限制防止上传恶意文件
3. 设置合理的文件大小限制
4. 定期清理孤立的文件
5. 使用 S3 存储时配置私有桶策略
6. 确保文件 token 不会泄露到日志中

❌ 避免的做法:
1. 不要允许上传可执行文件 (.exe, .sh, .bat)
2. 不要将管理员文件 token 暴露在前端
3. 不要设置过大的文件大小限制
4. 不要在 URL 参数中传递长期有效的 token
```

### 8.8.4 防止文件类型攻击

```
建议限制的危险 MIME 类型:
├── application/x-executable
├── application/x-msdos-program
├── application/x-sh
├── application/x-shellscript
├── text/html (可能包含 XSS)
└── application/javascript (可能包含恶意代码)

建议的图片上传白名单:
├── image/jpeg
├── image/png
├── image/webp
└── image/gif
```

## 8.9 文件存储最佳实践

### 8.9.1 文件命名策略

PocketBase 会自动为上传的文件生成唯一的文件名，格式为：

```
{原始文件名前缀}_{随机字符串}.{扩展名}

例如:
photo_abc123xyz.jpg
document_def456uvw.pdf
```

这确保了文件名不会冲突，同时保留了原始文件名的可读性。

### 8.9.2 存储目录结构

```
pb_data/storage/
├── {collectionId_1}/
│   ├── {recordId_a}/
│   │   ├── file1.jpg
│   │   ├── file2.pdf
│   │   ├── thumbs_100x100_file1.jpg
│   │   └── thumbs_300x300_file1.jpg
│   └── {recordId_b}/
│       └── file3.png
└── {collectionId_2}/
    └── {recordId_c}/
        └── file4.docx
```

### 8.9.3 清理孤立文件

在某些异常情况下（如数据库恢复但未恢复文件、或手动删除数据库记录），可能会产生孤立的文件。

**手动清理：**

```bash
# 检查 storage 目录大小
du -sh pb_data/storage/

# 使用管理面板中的清理功能
# 或通过自定义脚本对比数据库记录和文件系统
```

### 8.9.4 文件备份策略

```
备份策略建议:
├── 本地存储:
│   ├── 定期备份 pb_data 目录（包含数据库和文件）
│   ├── 使用 rsync 进行增量备份
│   └── 示例: rsync -av pb_data/ /backup/pb_data/
│
├── S3 存储:
│   ├── 启用 S3 版本控制
│   ├── 配置 S3 生命周期策略
│   └── 使用跨区域复制提高可用性
│
└── 数据库备份:
    ├── PocketBase 内置备份功能（管理面板 → Settings → Backups）
    └── 可以配置自动定期备份
```

### 8.9.5 性能优化建议

```
性能优化:
├── 使用缩略图减少带宽消耗
├── 配置 CDN 加速文件分发
├── 使用合适的图片格式（WebP 通常比 JPEG 更小）
├── 在前端使用 loading="lazy" 延迟加载图片
├── 合理配置缩略图尺寸，避免过多的缩略图变体
└── 大文件考虑使用 S3 存储而非本地存储
```

### 8.9.7 完整的文件管理示例

```javascript
import PocketBase from 'pocketbase';

const pb = new PocketBase('http://127.0.0.1:8090');

// ==================== 文件上传管理器 ====================

class FileManager {
    constructor(pb) {
        this.pb = pb;
    }

    // 上传文件并创建记录
    async uploadFile(collectionName, data, files) {
        const formData = new FormData();

        // 添加普通字段
        for (const [key, value] of Object.entries(data)) {
            formData.append(key, value);
        }

        // 添加文件
        for (const [fieldName, fileList] of Object.entries(files)) {
            if (Array.isArray(fileList)) {
                fileList.forEach(file => formData.append(fieldName, file));
            } else {
                formData.append(fieldName, fileList);
            }
        }

        return await this.pb.collection(collectionName).create(formData);
    }

    // 获取文件URL（支持缩略图和受保护文件）
    async getFileUrl(record, filename, options = {}) {
        const params = {};

        if (options.thumb) {
            params.thumb = options.thumb;
        }

        if (options.protected) {
            params.token = await this.pb.files.getToken();
        }

        return this.pb.files.getURL(record, filename, params);
    }

    // 删除特定文件
    async deleteFile(collectionName, recordId, fieldName, filename) {
        const updateData = {};
        updateData[`${fieldName}-`] = [filename];
        return await this.pb.collection(collectionName).update(recordId, updateData);
    }

    // 替换文件
    async replaceFile(collectionName, recordId, fieldName, newFile) {
        const formData = new FormData();
        formData.append(fieldName, newFile);
        return await this.pb.collection(collectionName).update(recordId, formData);
    }
}

// ==================== 使用示例 ====================

const fm = new FileManager(pb);

// 登录
await pb.collection('users').authWithPassword('user@example.com', 'password123');

// 上传文件
const record = await fm.uploadFile('articles', {
    title: '带图片的文章',
    content: '这是文章内容'
}, {
    cover: document.getElementById('coverInput').files[0],
    images: Array.from(document.getElementById('imagesInput').files)
});

// 获取文件URL
const coverUrl = await fm.getFileUrl(record, record.cover, { thumb: '300x300' });
console.log('封面URL:', coverUrl);

// 获取受保护文件URL
const protectedUrl = await fm.getFileUrl(record, record.cover, {
    protected: true,
    thumb: '800x600'
});
console.log('受保护文件URL:', protectedUrl);

// 删除特定图片
await fm.deleteFile('articles', record.id, 'images', record.images[0]);

// 替换封面
const newCoverFile = document.getElementById('newCoverInput').files[0];
await fm.replaceFile('articles', record.id, 'cover', newCoverFile);
```
