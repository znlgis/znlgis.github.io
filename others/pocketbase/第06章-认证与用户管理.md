# 第06章 认证与用户管理

PocketBase 内置了完整的用户认证系统，支持邮箱密码登录、OAuth2 第三方登录、邮箱验证、密码重置等功能。本章将详细讲解 PocketBase 认证系统的各个方面。

---

## 6.1 认证系统概述

### Auth 集合

PocketBase 的认证功能基于 **Auth 集合** 实现。Auth 集合是一种特殊的集合类型，在 Base 集合的基础上内置了用户认证所需的系统字段和 API 端点。

### 内置系统字段

每个 Auth 集合自动包含以下字段：

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `id` | string | 用户唯一标识符（15位随机字符串） |
| `username` | string | 用户名，自动生成唯一值，可自定义 |
| `email` | string | 用户邮箱地址 |
| `emailVisibility` | bool | 邮箱是否对其他用户可见 |
| `verified` | bool | 邮箱是否已通过验证 |
| `created` | datetime | 账户创建时间 |
| `updated` | datetime | 最近更新时间 |

> **注意：** `password` 字段不会出现在 API 响应中，它以 bcrypt 加密形式存储在数据库中。

### 认证相关 API 端点

```
POST /api/collections/{collection}/auth-with-password     # 邮箱/用户名+密码登录
POST /api/collections/{collection}/auth-with-oauth2        # OAuth2 登录
POST /api/collections/{collection}/auth-refresh            # 刷新 Token
POST /api/collections/{collection}/request-verification    # 请求邮箱验证
POST /api/collections/{collection}/confirm-verification    # 确认邮箱验证
POST /api/collections/{collection}/request-password-reset  # 请求密码重置
POST /api/collections/{collection}/confirm-password-reset  # 确认密码重置
POST /api/collections/{collection}/request-email-change    # 请求邮箱变更
POST /api/collections/{collection}/confirm-email-change    # 确认邮箱变更
GET  /api/collections/{collection}/auth-methods            # 获取可用认证方式
```

### 认证流程概览

```
┌───────────────┐     POST /auth-with-password     ┌──────────────┐
│   客户端       │ ─────────────────────────────────▶ │  PocketBase  │
│  (前端应用)    │ ◀───────────────────────────────── │    服务端     │
└───────────────┘     返回 JWT Token + 用户信息      └──────────────┘
       │
       │  存储 Token (authStore)
       │
       ▼
┌───────────────┐     带 Authorization 请求          ┌──────────────┐
│   后续请求     │ ─────────────────────────────────▶ │   验证Token   │
│               │ ◀───────────────────────────────── │   返回数据    │
└───────────────┘                                    └──────────────┘
```

## 6.2 邮箱密码认证

### 6.2.1 用户注册

新用户通过标准的记录创建 API 进行注册：

```bash
# 用户注册
curl -X POST http://127.0.0.1:8090/api/collections/users/records \
  -H "Content-Type: application/json" \
  -d '{
    "username": "zhangsan",
    "email": "zhangsan@example.com",
    "password": "securePassword123",
    "passwordConfirm": "securePassword123",
    "name": "张三"
  }'
```

**响应示例（200 OK）：**

```json
{
  "id": "user_abc123def45",
  "collectionId": "col_users_id",
  "collectionName": "users",
  "username": "zhangsan",
  "email": "zhangsan@example.com",
  "emailVisibility": false,
  "verified": false,
  "name": "张三",
  "created": "2024-01-15 08:30:00.000Z",
  "updated": "2024-01-15 08:30:00.000Z"
}
```

**注册注意事项：**
- `password` 最少 8 个字符（可在集合设置中调整）
- `passwordConfirm` 必须与 `password` 一致
- `username` 会自动生成唯一值，也可自定义（需唯一）
- `email` 必须是有效的邮箱格式且唯一
- 注册成功后 `verified` 默认为 `false`

### 6.2.2 用户登录（authWithPassword）

```bash
# 使用邮箱登录
curl -X POST http://127.0.0.1:8090/api/collections/users/auth-with-password \
  -H "Content-Type: application/json" \
  -d '{
    "identity": "zhangsan@example.com",
    "password": "securePassword123"
  }'

# 使用用户名登录
curl -X POST http://127.0.0.1:8090/api/collections/users/auth-with-password \
  -H "Content-Type: application/json" \
  -d '{
    "identity": "zhangsan",
    "password": "securePassword123"
  }'
```

**登录成功响应（200 OK）：**

```json
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJjb2xsZWN0aW9uSWQiOiJ1c2Vyc19jb2wiLCJleHAiOjE3MDg1MDAwMDAsImlkIjoidXNlcl9hYmMxMjNkZWY0NSIsInR5cGUiOiJhdXRoUmVjb3JkIn0.xxxxx",
  "record": {
    "id": "user_abc123def45",
    "collectionId": "col_users_id",
    "collectionName": "users",
    "username": "zhangsan",
    "email": "zhangsan@example.com",
    "emailVisibility": false,
    "verified": false,
    "name": "张三",
    "created": "2024-01-15 08:30:00.000Z",
    "updated": "2024-01-15 08:30:00.000Z"
  }
}
```

### 6.2.3 JWT Token 说明

登录成功后返回的 `token` 是一个标准的 JWT（JSON Web Token），包含以下信息：

```json
// JWT Payload 解码后
{
  "collectionId": "users_col_id",
  "exp": 1708500000,
  "id": "user_abc123def45",
  "type": "authRecord"
}
```

**使用 Token 发起认证请求：**

```bash
# 在请求头中携带 Token
curl http://127.0.0.1:8090/api/collections/posts/records \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIs..."
```

### 6.2.4 JavaScript SDK 登录示例

```javascript
import PocketBase from 'pocketbase';

const pb = new PocketBase('http://127.0.0.1:8090');

// 邮箱密码登录
async function login(email, password) {
  try {
    const authData = await pb.collection('users').authWithPassword(email, password);

    console.log('Token:', authData.token);
    console.log('用户信息:', authData.record);
    console.log('用户ID:', authData.record.id);
    console.log('用户名:', authData.record.username);

    // Token 自动存储在 pb.authStore 中
    console.log('是否已登录:', pb.authStore.isValid);
    console.log('存储的Token:', pb.authStore.token);
    console.log('存储的用户:', pb.authStore.record);

    return authData;
  } catch (error) {
    console.error('登录失败:', error.message);
    throw error;
  }
}

// 注销
function logout() {
  pb.authStore.clear();
  console.log('已退出登录');
}
```

## 6.3 OAuth2 认证

PocketBase 支持多种 OAuth2 提供商，实现第三方一键登录。

### 6.3.1 支持的 OAuth2 提供商

PocketBase 原生支持以下 OAuth2 提供商：

| 提供商 | 标识 | 说明 |
|--------|------|------|
| Google | `google` | Google 账号登录 |
| GitHub | `github` | GitHub 账号登录 |
| Facebook | `facebook` | Facebook 账号登录 |
| Microsoft | `microsoft` | Microsoft 账号登录 |
| Apple | `apple` | Apple ID 登录 |
| Discord | `discord` | Discord 账号登录 |
| Twitter | `twitter` | Twitter 账号登录 |
| GitLab | `gitlab` | GitLab 账号登录 |
| Spotify | `spotify` | Spotify 账号登录 |
| Twitch | `twitch` | Twitch 账号登录 |
| Kakao | `kakao` | Kakao 账号登录 |
| VK | `vk` | VK 账号登录 |
| Yandex | `yandex` | Yandex 账号登录 |
| OIDC | `oidc` | 通用 OpenID Connect |

### 6.3.2 OAuth2 配置步骤

**步骤1：在第三方平台创建 OAuth 应用**

以 GitHub 为例：
1. 访问 GitHub → Settings → Developer Settings → OAuth Apps
2. 点击「New OAuth App」
3. 设置回调 URL（Callback URL）为：`http://127.0.0.1:8090/api/oauth2-redirect`
4. 获取 `Client ID` 和 `Client Secret`

**步骤2：在 PocketBase Admin UI 中配置**

1. 进入管理面板 → Settings → Auth providers
2. 启用对应的 OAuth2 提供商
3. 填入 `Client ID` 和 `Client Secret`
4. 保存设置

**步骤3：获取可用认证方式**

```bash
# 查询当前集合支持的认证方式
curl http://127.0.0.1:8090/api/collections/users/auth-methods
```

**响应示例：**

```json

  "password": {
    "enabled": true,
    "identityFields": ["email", "username"]

  "oauth2": {
    "enabled": true,

        "displayName": "GitHub",
        "state": "random_state_string",
        "codeVerifier": "code_verifier_string",
        "codeChallenge": "code_challenge_string",

        "name": "google",
```

### 6.3.3 OAuth2 登录实现（JavaScript SDK）

```javascript
import PocketBase from 'pocketbase';

const pb = new PocketBase('http://127.0.0.1:8090');

// OAuth2 登录 - 浏览器弹窗模式
async function loginWithGitHub() {
  try {
    const authData = await pb.collection('users').authWithOAuth2({
      provider: 'github'
    });

    console.log('Token:', authData.token);
    console.log('用户信息:', authData.record);
    console.log('OAuth2 元数据:', authData.meta);

    // meta 包含 OAuth2 提供商返回的原始信息
    // 如 GitHub 的头像、仓库等
    return authData;
  } catch (error) {
    console.error('OAuth2 登录失败:', error);
  }
}

// Google 登录
async function loginWithGoogle() {
  try {
    const authData = await pb.collection('users').authWithOAuth2({
      provider: 'google',
      scopes: ['email', 'profile']  // 请求的权限范围
    });

    return authData;
  } catch (error) {
    console.error('Google 登录失败:', error);
  }
}

// OAuth2 手动流程（适用于移动端或自定义流程）
async function manualOAuth2Flow() {
  // 1. 获取认证方式列表
  const authMethods = await pb.collection('users').listAuthMethods();

  // 2. 找到 GitHub 提供商
  const githubProvider = authMethods.oauth2.providers.find(
    p => p.name === 'github'
  );

  // 3. 重定向用户到 OAuth2 授权页面
  // window.location.href = githubProvider.authURL + ...

  // 4. 用户授权后，在回调页面获取 code
  // 5. 使用 code 完成登录
  const authData = await pb.collection('users').authWithOAuth2Code(
    'github',
    'authorization_code_from_callback',
    githubProvider.codeVerifier,
    'http://127.0.0.1:8090/api/oauth2-redirect'
  );
}
```

### 6.3.4 OAuth2 自动关联

当用户首次通过 OAuth2 登录时，PocketBase 会自动：
1. 创建新的用户记录
2. 将 OAuth2 账号与用户记录关联
3. 如果邮箱与已有用户匹配，则关联到已有账号

## 6.4 匿名认证

PocketBase 并不内置"匿名认证"模式，但可以通过 API 规则实现类似功能。

### 允许未认证用户访问

在集合的 API 规则中，将 List/View 规则留空即表示允许所有人（包括未认证用户）访问：

```
# 集合 API 规则配置

List/Search 规则:   （留空 = 所有人可访问）
View 规则:          （留空 = 所有人可查看）
Create 规则:        @request.auth.id != ""  （仅认证用户可创建）
Update 规则:        @request.auth.id = author  （仅作者可更新）
Delete 规则:        @request.auth.id = author  （仅作者可删除）
```

### 创建访客用户模式

如果需要实现访客模式，可以创建一个专用的访客 Auth 集合：

```javascript
// 自动创建匿名用户
async function createGuestUser() {
  const guestId = 'guest_' + Date.now();
  const guestPassword = crypto.randomUUID();

  // 注册匿名用户
  await pb.collection('guests').create({
    username: guestId,
    email: `${guestId}@guest.local`,
    password: guestPassword,
    passwordConfirm: guestPassword,
    isGuest: true
  });

  // 自动登录
  const authData = await pb.collection('guests').authWithPassword(
    `${guestId}@guest.local`,
    guestPassword
  );

  // 将凭据保存到本地存储
  localStorage.setItem('guestCredentials', JSON.stringify({
    email: `${guestId}@guest.local`,
    password: guestPassword
  }));

  return authData;
}
```

## 6.5 Token 管理

### 6.5.1 JWT Token 结构

PocketBase 使用标准的 JWT（JSON Web Token）进行认证。Token 由三部分组成：

```
Header.Payload.Signature
```

**Header（头部）：**

```json
{
  "alg": "HS256",
  "typ": "JWT"
}
```

**Payload（载荷）：**

```json
{
  "collectionId": "pbc_users_col",
  "exp": 1708500000,
  "id": "user_abc123def45",
  "type": "authRecord",
  "refreshable": true
}
```

**字段说明：**

| 字段 | 说明 |
|------|------|
| `collectionId` | 用户所属集合的 ID |
| `exp` | Token 过期时间（Unix 时间戳） |
| `id` | 用户记录 ID |
| `type` | Token 类型（`authRecord` 或 `admin`） |
| `refreshable` | 是否可刷新 |

### 6.5.2 Token 有效期设置

Token 有效期可以在 Admin UI 或 API 中配置：

**Admin UI 设置路径：** Settings → Application → Token options

```bash
# 通过 API 修改 Token 有效期（需要管理员权限）
curl -X PATCH http://127.0.0.1:8090/api/settings \
  -H "Authorization: Bearer ADMIN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "recordAuthToken": {
      "duration": 604800
    },
    "recordVerificationToken": {
      "duration": 259200
    },
    "recordPasswordResetToken": {
      "duration": 1800
    }
  }'
```

**默认有效期：**

| Token 类型 | 默认有效期 |
|------------|------------|
| Auth Token | 14 天 |
| Verification Token | 3 天 |
| Password Reset Token | 30 分钟 |
| Email Change Token | 30 分钟 |

### 6.5.3 Token 刷新

```bash
# 刷新当前 Token
curl -X POST http://127.0.0.1:8090/api/collections/users/auth-refresh \
  -H "Authorization: Bearer CURRENT_TOKEN"
```

**响应：**

```json
{
  "token": "NEW_JWT_TOKEN...",
  "record": {
    "id": "user_abc123def45",
    "username": "zhangsan",
    "email": "zhangsan@example.com",
    ...
  }
}
```

### 6.5.4 authStore 管理（JavaScript SDK）

```javascript
import PocketBase from 'pocketbase';

const pb = new PocketBase('http://127.0.0.1:8090');

// 检查登录状态
console.log('是否已认证:', pb.authStore.isValid);
console.log('当前Token:', pb.authStore.token);
console.log('当前用户:', pb.authStore.record);

// 监听认证状态变化
pb.authStore.onChange((token, record) => {
  console.log('认证状态变化');
  console.log('新Token:', token);
  console.log('新用户:', record);

  if (!token) {
    // 用户已登出，跳转到登录页
    window.location.href = '/login';
  }
});

// 自动刷新 Token
async function autoRefreshToken() {
  if (pb.authStore.isValid) {
    try {
      await pb.collection('users').authRefresh();
      console.log('Token 已刷新');
    } catch (error) {
      console.log('Token 刷新失败，需要重新登录');
      pb.authStore.clear();
    }
  }
}

// 定期刷新 Token（每小时）
setInterval(autoRefreshToken, 3600 * 1000);

// 清除认证信息（登出）
function logout() {
  pb.authStore.clear();
}

// 自定义 authStore（使用其他存储方式）
import PocketBase, { AsyncAuthStore } from 'pocketbase';

// 使用 React Native AsyncStorage
const store = new AsyncAuthStore({
  save: async (serialized) => {
    await AsyncStorage.setItem('pb_auth', serialized);
  },
  initial: await AsyncStorage.getItem('pb_auth'),
  clear: async () => {
    await AsyncStorage.removeItem('pb_auth');
  },
});

const pb = new PocketBase('http://127.0.0.1:8090', store);
```

## 6.6 邮箱验证

### 6.6.1 邮箱验证流程

```
1. 用户注册 → verified = false
2. 调用 request-verification API → 发送验证邮件
3. 用户点击邮件中的链接 → 访问确认 URL
4. 调用 confirm-verification API → verified = true
```

### 6.6.2 请求邮箱验证

```bash
# 请求发送验证邮件
curl -X POST http://127.0.0.1:8090/api/collections/users/request-verification \
  -H "Content-Type: application/json" \
  -d '{
    "email": "zhangsan@example.com"
  }'
```

**响应：** 成功返回 `204 No Content`

### 6.6.3 确认邮箱验证

```bash
# 确认邮箱验证（token 来自验证邮件中的链接）
curl -X POST http://127.0.0.1:8090/api/collections/users/confirm-verification \
  -H "Content-Type: application/json" \
  -d '{
    "token": "VERIFICATION_TOKEN_FROM_EMAIL"
  }'
```

### 6.6.4 JavaScript SDK 验证流程

```javascript
// 请求发送验证邮件
async function requestVerification(email) {
  try {
    await pb.collection('users').requestVerification(email);
    console.log('验证邮件已发送');
  } catch (error) {
    console.error('发送失败:', error);
  }
}

// 确认验证（从 URL 参数中获取 token）
async function confirmVerification(token) {
  try {
    await pb.collection('users').confirmVerification(token);
    console.log('邮箱验证成功！');

    // 刷新用户信息
    await pb.collection('users').authRefresh();
  } catch (error) {
    console.error('验证失败:', error);
  }
}
```

### 6.6.5 SMTP 配置

发送验证邮件需要先配置 SMTP 服务：

**Admin UI 配置路径：** Settings → Mail settings

```bash
      "enabled": true,
```

## 6.7 密码重置

### 6.7.1 密码重置流程

```
1. 用户提交邮箱 → 调用 request-password-reset API
2. 系统发送重置邮件 → 包含重置链接
3. 用户点击链接 → 填写新密码
4. 调用 confirm-password-reset API → 密码更新成功
```

### 6.7.2 请求密码重置

```bash
# 请求发送密码重置邮件
curl -X POST http://127.0.0.1:8090/api/collections/users/request-password-reset \
```

## 6.8 多因素认证（MFA）

PocketBase 支持多因素认证（Multi-Factor Authentication），为用户账号提供额外的安全保护层。

### 6.8.1 MFA 配置

在 Admin UI 中配置 MFA：

1. 进入 Settings → Auth 集合设置
2. 启用 MFA 选项
3. 配置 MFA 规则

**MFA 规则说明：**

MFA 规则是一个过滤表达式，决定哪些用户需要进行多因素认证：

```
# 所有用户都需要 MFA
@request.auth.id != ""

# 仅管理员角色需要 MFA
@request.auth.role = "admin"

# 仅未验证邮箱的用户需要 MFA
@request.auth.verified = false
```

### 6.8.2 MFA 认证流程

当启用 MFA 后，普通的密码登录将返回一个临时的 MFA ID，需要额外的验证步骤才能完成登录：

```
1. 用户提交邮箱+密码 → 返回 mfaId（而非 Token）
2. 使用 mfaId + 第二因素验证 → 返回最终 Token
```

```bash
# 第一步：密码验证
curl -X POST http://127.0.0.1:8090/api/collections/users/auth-with-password \
  -H "Content-Type: application/json" \
  -d '{
    "identity": "zhangsan@example.com",
    "password": "securePassword123"
  }'

# MFA 响应（需要额外验证）
# HTTP 401 返回
# {
#   "mfaId": "mfa_temp_id_xxx"
# }

# 第二步：完成 MFA 验证（例如通过邮箱 OTP）
curl -X POST http://127.0.0.1:8090/api/collections/users/auth-with-otp \
  -H "Content-Type: application/json" \
  -d '{
    "mfaId": "mfa_temp_id_xxx",
    "otpId": "otp_record_id",
    "password": "123456"
  }'
```

### 6.8.3 OTP（一次性密码）配置

PocketBase 支持通过邮箱发送一次性密码进行 MFA 验证：

```bash
# 请求 OTP
curl -X POST http://127.0.0.1:8090/api/collections/users/request-otp \
  -H "Content-Type: application/json" \
  -d '{
    "email": "zhangsan@example.com"
  }'

# 响应
# {
#   "otpId": "otp_record_id_xxx"
# }
```

### 6.8.4 JavaScript SDK MFA 登录

```javascript
async function loginWithMFA(email, password) {
  try {
    // 尝试普通登录
    const authData = await pb.collection('users').authWithPassword(
      email, password
    );
    return authData;
  } catch (error) {
    if (error.response?.mfaId) {
      // 需要 MFA 验证
      const mfaId = error.response.mfaId;

      // 请求发送 OTP
      const otpResponse = await pb.collection('users').requestOTP(email);

      // 等待用户输入 OTP（这里需要 UI 交互）
      const otpCode = prompt('请输入邮箱中收到的验证码：');

      // 使用 OTP 完成认证
      const authData = await pb.collection('users').authWithOTP(
        otpResponse.otpId,
        otpCode,
        { mfaId: mfaId }
      );

      return authData;
    }
    throw error;
  }
}
```

## 6.12 认证安全最佳实践

### 6.12.1 密码安全

```
✅ 最少 8 个字符（推荐 12+）
✅ 使用 bcrypt 加密存储（PocketBase 内置）
✅ 客户端不存储明文密码
✅ 使用 HTTPS 加密传输

⚠️ 可以在集合设置中调整密码最小长度
⚠️ PocketBase 不内置密码强度检测，建议前端实现
```

**前端密码强度检查示例：**

```javascript
function checkPasswordStrength(password) {
  let score = 0;
  const checks = {
    length: password.length >= 8,
    uppercase: /[A-Z]/.test(password),
    lowercase: /[a-z]/.test(password),
    numbers: /\d/.test(password),
    special: /[!@#$%^&*()_+\-=\[\]{}|;:,.<>?]/.test(password),
    longEnough: password.length >= 12
  };

  Object.values(checks).forEach(passed => { if (passed) score++; });

  if (score <= 2) return { level: '弱', color: 'red' };
  if (score <= 4) return { level: '中', color: 'orange' };
  return { level: '强', color: 'green' };
}
```

### 6.12.4 Token 安全

```javascript
// ✅ 使用 HttpOnly Cookie 存储 Token（更安全）
// ✅ 设置合理的 Token 有效期
// ✅ 定期刷新 Token
// ✅ 登出时清除 Token

// ❌ 不要在 URL 参数中传递 Token
// ❌ 不要在前端日志中打印 Token
// ❌ 不要将 Token 存储在全局变量中

// 安全的 Token 存储方案
class SecureAuthStore {
  constructor() {
    // 优先使用 sessionStorage（关闭浏览器后自动清除）
    this.storage = window.sessionStorage;
  }

  save(token, record) {
    this.storage.setItem('pb_token', token);
    this.storage.setItem('pb_user', JSON.stringify(record));
  }

  get token() {
    return this.storage.getItem('pb_token');
  }

  get record() {
    const data = this.storage.getItem('pb_user');
    return data ? JSON.parse(data) : null;
  }

  clear() {
    this.storage.removeItem('pb_token');
    this.storage.removeItem('pb_user');
  }
}
```

### 6.12.5 防止暴力破解

```go
// Go 扩展：登录失败次数限制
package main

import (
    "sync"
    "time"

    "github.com/pocketbase/pocketbase"
    "github.com/pocketbase/pocketbase/core"
)

type LoginTracker struct {
    attempts map[string][]time.Time
    mu       sync.Mutex
}

func (lt *LoginTracker) RecordFailure(identity string) {
    lt.mu.Lock()
    defer lt.mu.Unlock()
    lt.attempts[identity] = append(lt.attempts[identity], time.Now())
}

func (lt *LoginTracker) IsBlocked(identity string, maxAttempts int, window time.Duration) bool {
    lt.mu.Lock()
    defer lt.mu.Unlock()

    cutoff := time.Now().Add(-window)
    var recent []time.Time
    for _, t := range lt.attempts[identity] {
        if t.After(cutoff) {
            recent = append(recent, t)
        }
    }
    lt.attempts[identity] = recent
    return len(recent) >= maxAttempts
}

func main() {
    app := pocketbase.New()
    tracker := &LoginTracker{attempts: make(map[string][]time.Time)}

    // 在认证之前检查是否被锁定
    app.OnRecordAuthRequest().BindFunc(func(e *core.RecordAuthRequestEvent) error {
        identity := e.Record.Email()
        if tracker.IsBlocked(identity, 5, 15*time.Minute) {
            return &core.ApiError{
                Code:    429,
                Message: "登录尝试次数过多，请 15 分钟后再试",
            }
        }
        return e.Next()
    })

    app.Start()
}
```

6. **MFA 多因素认证**为高安全需求场景提供额外保护
