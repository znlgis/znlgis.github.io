# BambooBuddy 熊猫宝宝的一天使用与开发教程目录

本教程结合开源仓库 [znlgis/BambooBuddy](https://github.com/znlgis/BambooBuddy)，系统剖析这款面向 4–8 岁儿童的日常养成游戏：孩子照顾卡通大熊猫「竹竹 / Bamboo」，在刷牙、洗手、吃饭、穿衣、洗澡、睡觉、整理、运动、情绪、学习十件小事里，把一整套儿童友好的交互与工程实践落地。内容从产品定位与技术选型出发，依次讲解 pnpm workspace 工程结构、核心契约与游戏生命周期、Vue 应用外壳、内容数据模型与关卡变体、八个玩法模板、Phaser 渲染工具箱与裁剪、平台适配层（IndexedDB / WebAudio / TTS）、五维状态与奖励成长（累计里程碑、丰收日、竹笋小卖部）、亲密度与装扮日记家长页（两位数加法成人门、屏幕时长与每日亲子建议）、中英双语三层实现，再通过「从零开发一条新任务」的实战串起测试门禁、体积预算、Tauri/Capacitor 打包与分发，接着复盘三款隐藏小游戏（竹林小门与「竹林小路」彩蛋）如何另起一套契约，最后以踩坑记录与常见问题收尾。每章配有大量 TypeScript / Vue 源码示例，适合对 Phaser / Vue 游戏开发、儿童教育产品与前端工程化感兴趣的读者。

> 🎮 **在线试玩**：[熊猫宝宝的一天 Bamboo Buddy](https://znlgis.github.io/bamboobuddy/) —— 十个生活小任务（每条任务中英各 **2 套关卡**，按天数确定性轮换），完成四件后还会出现一扇竹林小门：三款隐藏小游戏普通模式**每天 21 局**、每款难度 Lv.1–12（跨天成长、一局即一轮，结算后回游戏厅），另有「竹林小路」彩蛋可无限畅玩（不返回游戏厅，自动接着下一局）。家长入口在小屋标题上**长按 3 秒**，再答对一道两位数加法才进得去；家长页里有今日 / 本周游戏时长、每周固定丰收日、累计里程碑与每天一句可执行的亲子建议。手机 / 平板浏览器打开即玩，无需安装。
