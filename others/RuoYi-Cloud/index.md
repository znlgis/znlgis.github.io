# RuoYi-Cloud 学习与使用教程

## 教程简介

本教程是针对 [RuoYi-Cloud](https://github.com/yangzongzhuan/RuoYi-Cloud) 微服务开发框架的全面学习指南。RuoYi-Cloud 是基于 Spring Cloud Alibaba 的分布式微服务架构，适合企业级应用开发。

### 技术栈概览

| 后端技术 | 版本 | 说明 |
|---------|------|------|
| Spring Boot | 2.7.x | 基础框架 |
| Spring Cloud | 2021.x | 微服务框架 |
| Spring Cloud Alibaba | 2021.x | 阿里巴巴微服务组件 |
| Nacos | 2.x | 注册中心&配置中心 |
| Sentinel | 1.8.x | 流量控制 |
| Seata | 1.5.x | 分布式事务 |
| MySQL | 5.7+ | 数据库 |
| Redis | 6.x | 缓存 |
| MyBatis | 3.5.x | ORM框架 |

| 前端技术 | 版本 | 说明 |
|---------|------|------|
| Vue.js | 2.6.x / 3.x | 前端框架 |
| Element UI/Plus | 2.x / 3.x | UI组件库 |
| Axios | 0.x | HTTP客户端 |
| Vuex | 3.x / 4.x | 状态管理 |
