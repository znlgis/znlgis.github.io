# Photo-Sphere-Viewer 教程目录

本教程结合 [Photo-Sphere-Viewer 官方仓库](https://github.com/mistic100/Photo-Sphere-Viewer) 的源码结构、功能模块与官方文档，面向中文读者系统介绍 Photo-Sphere-Viewer 的**原理、使用与二次开发**。Photo-Sphere-Viewer 是一款基于 Three.js 的开源 JavaScript 库，用于在网页上展示 360° 全景图，支持等距柱状投影、立方体贴图、鱼眼、视频等多种格式，并提供丰富的插件生态（标记、虚拟漫游、陀螺仪、VR 立体视图、地图集成等）。

教程围绕"**基础入门 → 核心配置 → 全景图类型 → 标记系统 → 插件开发 → 虚拟漫游 → 视频与移动端 → 地图集成 → 框架集成与实战**"这条主线展开。

> 说明：本教程基于 v5.x 版本编写。Photo-Sphere-Viewer 处于活跃开发中，具体 API 签名可能随版本演进，请以官方文档为准。
