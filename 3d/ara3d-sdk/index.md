# Ara3D-SDK 教程目录

本教程结合 [Ara3D-SDK 官方仓库](https://github.com/ara3d/ara3d-sdk) 的源码结构、包体系与示例项目，面向中文读者系统介绍 Ara3D-SDK 的**架构、使用与二次开发**。Ara3D-SDK 是一套**开源（MIT 许可）、面向 AEC（建筑、工程与施工）行业**的高性能 C# 库集合，用 `.NET 8` 编写，可独立使用，也可用于扩展 **Ara 3D Studio** 桌面应用。

它专为**海量三维数据的实时处理**而设计：核心库与几何库面向 `net8.0` 跨平台运行，文件 I/O 与完整 SDK 面向 `net8.0-windows`。教程围绕“**基础库 → 数学与 SIMD → 几何建模 → 场景模型 → 文件格式 → BIM/IFC → Studio 插件 → 二次开发与发布**”这条主线展开。

> 说明：本教程基于官方仓库 `main` 分支（版本 `1.6.x`）编写。Ara3D-SDK 处于活跃开发中，具体类名、方法签名可能随版本演进，请以你实际引用的 NuGet 包版本与源码为准。
