# SuperSplat 教程目录

本教程结合 [PlayCanvas SuperSplat 官方仓库](https://github.com/playcanvas/supersplat) 的源码结构、功能模块与官方用户手册，面向中文读者系统介绍 SuperSplat 的原理、使用与二次开发。SuperSplat 是一款免费开源、运行于浏览器的 **3D 高斯泼溅（3D Gaussian Splatting）** 编辑器，用于检查、编辑、优化和发布高斯泼溅模型。教程围绕“高斯泼溅原理 → 在线编辑器使用 → 源码架构 → 二次开发”这条主线展开，并补充数据格式、相机动画、导出发布与工程实战内容。
