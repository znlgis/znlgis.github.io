# 第02章：安装与环境配置

## 2.1 系统要求

### 2.1.1 硬件要求

在安装 PostGIS 之前，请确保您的系统满足以下最低硬件要求：

| 组件 | 最低要求 | 推荐配置 | 生产环境 |
|------|----------|----------|----------|
| CPU | 2 核 | 4 核以上 | 8 核以上 |
| 内存 | 4GB | 8GB | 16GB+ |
| 存储 | 20GB HDD | 50GB SSD | 100GB+ NVMe SSD |
| 网络 | 100Mbps | 1Gbps | 10Gbps |

### 2.1.2 软件要求

PostGIS 的主要软件依赖：

| 软件 | 版本要求 | 说明 |
|------|----------|------|
| PostgreSQL | 12+ | 数据库服务器 |
| GEOS | 3.8+ | 几何引擎 |
| PROJ | 6.0+ | 坐标转换库 |
| GDAL | 3.0+ | 栅格数据支持（可选） |
| LibXML2 | 2.9+ | XML 支持 |
| JSON-C | 0.14+ | JSON 支持 |
| SFCGAL | 1.3+ | 3D 支持（可选） |

### 2.1.3 版本兼容性

PostGIS 与 PostgreSQL 的版本兼容性：

| PostGIS 版本 | PostgreSQL 版本 | 发布日期 | 支持状态 |
|-------------|-----------------|----------|----------|
| 3.4 | 12, 13, 14, 15, 16 | 2023-08 | 当前稳定版 |
| 3.3 | 11, 12, 13, 14, 15 | 2022-08 | 维护中 |
| 3.2 | 10, 11, 12, 13, 14 | 2021-12 | 维护中 |
| 3.1 | 9.6, 10, 11, 12, 13 | 2020-12 | EOL |
| 3.0 | 9.5, 9.6, 10, 11, 12 | 2019-10 | EOL |

## 2.2 Windows 安装

### 2.2.1 使用 EDB 安装程序（推荐）

EnterpriseDB 提供了包含 PostGIS 的 PostgreSQL 一站式安装程序。

**步骤 1：下载安装程序**

访问 [PostgreSQL 官方下载页面](https://www.postgresql.org/download/windows/) 或 [EDB 下载页面](https://www.enterprisedb.com/downloads/postgres-postgresql-downloads)，下载适合您系统的安装程序。

**步骤 2：运行安装程序**

```
1. 双击下载的安装程序
2. 选择安装目录（默认 C:\Program Files\PostgreSQL\16）
3. 选择要安装的组件：
   ✓ PostgreSQL Server
   ✓ pgAdmin 4
   ✓ Stack Builder
   ✓ Command Line Tools
4. 设置数据目录
5. 设置 postgres 用户密码
6. 设置端口号（默认 5432）
7. 选择区域设置
8. 完成安装
```

**步骤 3：使用 Stack Builder 安装 PostGIS**

```
1. 从开始菜单启动 Stack Builder
2. 选择 PostgreSQL 安装实例
3. 展开 "Spatial Extensions" 类别
4. 选择 "PostGIS 3.4 Bundle for PostgreSQL 16"
5. 点击 "Next" 开始下载和安装
6. 安装过程中可选择创建空间数据库
7. 完成安装
```

### 2.2.2 验证安装

安装完成后，使用 psql 或 pgAdmin 验证安装：

```sql
-- 连接到数据库
psql -U postgres -d postgres

-- 查看 PostgreSQL 版本
SELECT version();

-- 查看可用扩展
SELECT * FROM pg_available_extensions WHERE name LIKE 'postgis%';

-- 创建测试数据库
CREATE DATABASE postgis_test;

-- 连接到测试数据库
\c postgis_test

-- 安装 PostGIS 扩展
CREATE EXTENSION postgis;

-- 验证 PostGIS 版本
SELECT PostGIS_Full_Version();
```

预期输出：


## 2.3 Linux 安装

### 2.3.1 Ubuntu/Debian 安装

**方法一：使用 apt 包管理器**

```bash
# 更新系统
sudo apt update && sudo apt upgrade -y

# 添加 PostgreSQL 官方仓库
sudo sh -c 'echo "deb http://apt.postgresql.org/pub/repos/apt $(lsb_release -cs)-pgdg main" > /etc/apt/sources.list.d/pgdg.list'
wget --quiet -O - https://www.postgresql.org/media/keys/ACCC4CF8.asc | sudo apt-key add -
sudo apt update

# 安装 PostgreSQL 和 PostGIS
sudo apt install -y postgresql-16 postgresql-16-postgis-3

# 安装额外的 PostGIS 组件（可选）
sudo apt install -y postgresql-16-postgis-3-scripts  # 数据脚本
sudo apt install -y postgresql-16-pgrouting          # 路径规划
sudo apt install -y postgresql-16-pointcloud        # 点云支持
```

**方法二：编译安装（高级用户）**

```bash
# 安装编译依赖
sudo apt install -y build-essential cmake pkg-config
sudo apt install -y libxml2-dev libgeos-dev libproj-dev libjson-c-dev
sudo apt install -y libgdal-dev xsltproc docbook-xsl docbook-mathml

# 下载 PostGIS 源码
wget https://download.osgeo.org/postgis/source/postgis-3.4.0.tar.gz
tar -xzf postgis-3.4.0.tar.gz
cd postgis-3.4.0

# 配置
./configure --with-pgconfig=/usr/lib/postgresql/16/bin/pg_config

# 编译安装
make -j$(nproc)
sudo make install
```

### 2.3.2 CentOS/RHEL 安装

```bash
# 安装 EPEL 和 PostgreSQL 仓库
sudo dnf install -y epel-release
sudo dnf install -y https://download.postgresql.org/pub/repos/yum/reporpms/EL-8-x86_64/pgdg-redhat-repo-latest.noarch.rpm

# 禁用内置 PostgreSQL 模块
sudo dnf -qy module disable postgresql

# 安装 PostgreSQL 16
sudo dnf install -y postgresql16-server postgresql16

# 初始化数据库
sudo /usr/pgsql-16/bin/postgresql-16-setup initdb

# 启动并设置开机启动
sudo systemctl start postgresql-16
sudo systemctl enable postgresql-16

# 安装 PostGIS
sudo dnf install -y postgis34_16
```

### 2.3.3 启用 PostGIS 扩展

```bash
# 切换到 postgres 用户
sudo -u postgres psql

# 在 psql 中执行

\c gis_tutorial

-- 安装可选扩展

CREATE EXTENSION fuzzystrmatch;         -- 模糊匹配（地理编码需要）

-- 验证安装
```


## 2.4 Docker 部署

### 2.4.1 使用官方 PostGIS 镜像

```bash
# 拉取官方镜像
docker pull postgis/postgis:16-3.4

# 运行容器
docker run -d \
  --name postgis \
  -e POSTGRES_USER=postgres \
  -e POSTGRES_PASSWORD=postgres \
  -e POSTGRES_DB=gis_tutorial \
  -p 5432:5432 \
  -v postgis_data:/var/lib/postgresql/data \
  postgis/postgis:16-3.4

# 查看容器状态
docker ps

# 连接到数据库
docker exec -it postgis psql -U postgres -d gis_tutorial
```

### 2.4.2 Docker Compose 部署

创建 `docker-compose.yml` 文件：

```yaml
version: '3.8'

services:
  postgis:
    image: postgis/postgis:16-3.4
    container_name: postgis_tutorial
    restart: unless-stopped
    environment:
      POSTGRES_USER: postgres
      POSTGRES_PASSWORD: postgres
      POSTGRES_DB: gis_tutorial
      # 性能优化参数
      POSTGRES_INITDB_ARGS: "--encoding=UTF8 --locale=C.UTF-8"
    ports:
      - "5432:5432"
    volumes:
      - postgis_data:/var/lib/postgresql/data
      - ./init-scripts:/docker-entrypoint-initdb.d
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U postgres"]
      interval: 10s
      timeout: 5s
      retries: 5
    # 资源限制
    deploy:
      resources:
        limits:
          cpus: '2'
          memory: 4G
        reservations:
          cpus: '1'
          memory: 2G

  # 可选：pgAdmin 管理界面
  pgadmin:
    image: dpage/pgadmin4:latest
    container_name: pgadmin
    restart: unless-stopped
    environment:
      PGADMIN_DEFAULT_EMAIL: admin@example.com
      PGADMIN_DEFAULT_PASSWORD: admin
      PGADMIN_CONFIG_SERVER_MODE: 'False'
    ports:
      - "5050:80"
    volumes:
      - pgadmin_data:/var/lib/pgadmin
    depends_on:
      - postgis

volumes:
  postgis_data:
  pgadmin_data:
```

创建初始化脚本 `init-scripts/01-init.sql`：

```sql
-- 启用 PostGIS 扩展
CREATE EXTENSION IF NOT EXISTS postgis;
CREATE EXTENSION IF NOT EXISTS postgis_topology;
CREATE EXTENSION IF NOT EXISTS postgis_raster;
CREATE EXTENSION IF NOT EXISTS fuzzystrmatch;
CREATE EXTENSION IF NOT EXISTS address_standardizer;

-- 创建示例表
CREATE TABLE IF NOT EXISTS spatial_test (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100),
    geom GEOMETRY(POINT, 4326)
);

-- 插入测试数据
INSERT INTO spatial_test (name, geom) VALUES
    ('测试点1', ST_SetSRID(ST_MakePoint(116.4074, 39.9042), 4326)),
    ('测试点2', ST_SetSRID(ST_MakePoint(121.4737, 31.2304), 4326));

-- 创建空间索引
CREATE INDEX idx_spatial_test_geom ON spatial_test USING GIST (geom);

-- 输出版本信息
SELECT PostGIS_Full_Version();
```

启动服务：

```bash
# 启动所有服务
docker-compose up -d

# 查看日志
docker-compose logs -f postgis

# 停止服务
docker-compose down

# 停止并删除数据卷
docker-compose down -v
```

## 2.7 数据导入工具配置

### 2.7.1 shp2pgsql 配置

shp2pgsql 是将 Shapefile 导入 PostGIS 的命令行工具：

```bash
# 基本用法
shp2pgsql -s 4326 -I -D -W "GBK" input.shp schema.tablename > output.sql

# 参数说明
# -s 4326    : 指定 SRID
# -I         : 创建空间索引
# -D         : 使用 dump 格式（更快）
# -W "GBK"   : 指定字符编码
# -g geom    : 指定几何列名
# -a         : 追加模式
# -c         : 创建新表（默认）
# -d         : 先删除后创建
# -p         : 仅创建表结构

# 直接导入数据库
shp2pgsql -s 4326 -I -D -W "GBK" input.shp public.my_table | psql -U postgres -d gis_db

# 导入多个 Shapefile
for shp in *.shp; do
    table_name=$(basename "$shp" .shp)
    shp2pgsql -s 4326 -I -D -W "GBK" "$shp" "public.$table_name" | psql -U postgres -d gis_db
done
```

### 2.7.2 raster2pgsql 配置

raster2pgsql 用于导入栅格数据：

```bash
# 基本用法
raster2pgsql -s 4326 -I -C -M input.tif schema.tablename > output.sql

# 参数说明
# -s 4326    : 指定 SRID
# -I         : 创建空间索引
# -C         : 设置栅格约束
# -M         : 使用 COPY 而非 INSERT
# -t 100x100 : 设置瓦片大小
# -R         : 引用外部文件（不导入数据）
# -r         : 设置常规块（regular blocking）

# 导入栅格数据
raster2pgsql -s 4326 -I -C -M -t 256x256 dem.tif public.dem | psql -U postgres -d gis_db

# 导入目录中的所有 TIFF 文件
raster2pgsql -s 4326 -I -C -M -t 256x256 *.tif public.imagery | psql -U postgres -d gis_db
```

### 2.7.3 ogr2ogr 配置

GDAL/OGR 的 ogr2ogr 是更强大的数据转换工具：

```bash
# 从 GeoJSON 导入
ogr2ogr -f "PostgreSQL" \
    PG:"host=localhost dbname=gis_db user=postgres password=postgres" \
    input.geojson \
    -nln my_table \
    -lco GEOMETRY_NAME=geom \
    -lco FID=gid \
    -lco PRECISION=NO \
    -a_srs EPSG:4326

# 从 FileGDB 导入
ogr2ogr -f "PostgreSQL" \
    PG:"host=localhost dbname=gis_db user=postgres password=postgres" \
    input.gdb \
    -nln my_table \
    -overwrite

# 导出为 GeoJSON
ogr2ogr -f "GeoJSON" \
    output.geojson \
    PG:"host=localhost dbname=gis_db user=postgres password=postgres" \
    -sql "SELECT * FROM my_table WHERE population > 100000"

# 导出为 Shapefile
ogr2ogr -f "ESRI Shapefile" \
    output.shp \
    PG:"host=localhost dbname=gis_db user=postgres password=postgres" \
    my_table

# 坐标转换
ogr2ogr -f "PostgreSQL" \
    PG:"host=localhost dbname=gis_db user=postgres password=postgres" \
    input.shp \
    -nln my_table \
    -s_srs EPSG:4490 \
    -t_srs EPSG:4326
```

```python
# postgis_test.py
import psycopg2
from geoalchemy2 import Geometry
from sqlalchemy import create_engine, Column, Integer, String
from sqlalchemy.ext.declarative import declarative_base
from sqlalchemy.orm import sessionmaker

# 方法一：使用 psycopg2 直接连接
conn = psycopg2.connect(
    host="localhost",
    port=5432,
    database="gis_tutorial",
    user="postgres",
    password="postgres"
)

cur = conn.cursor()
cur.execute("SELECT PostGIS_Full_Version();")
print(cur.fetchone()[0])

# 方法二：使用 SQLAlchemy + GeoAlchemy2
engine = create_engine('postgresql://postgres:postgres@localhost:5432/gis_tutorial')
Session = sessionmaker(bind=engine)
session = Session()

Base = declarative_base()

class City(Base):
    __tablename__ = 'cities'
    id = Column(Integer, primary_key=True)
    name = Column(String(100))
    geom = Column(Geometry('POINT', srid=4326))

# 查询示例
from geoalchemy2.functions import ST_Distance, ST_Transform
from sqlalchemy import func

# 查询距离某点最近的城市
result = session.query(
    City.name,
    ST_Distance(
        City.geom,
        func.ST_SetSRID(func.ST_MakePoint(116.4074, 39.9042), 4326)
    ).label('distance')
).order_by('distance').limit(5).all()

for city in result:
    print(f"{city.name}: {city.distance}")
```

## 2.9 常见问题排查

### 2.9.1 连接问题

**问题：无法连接到数据库**

```bash
# 检查 PostgreSQL 服务状态
sudo systemctl status postgresql

# 检查端口监听
netstat -tlnp | grep 5432
ss -tlnp | grep 5432

# 检查 pg_hba.conf 配置
cat /etc/postgresql/16/main/pg_hba.conf | grep -v "^#" | grep -v "^$"

# 检查 postgresql.conf 监听地址
grep listen_addresses /etc/postgresql/16/main/postgresql.conf

# 测试连接
psql -h localhost -U postgres -d postgres
```

**问题：认证失败**

```bash
# 修改 postgres 用户密码
sudo -u postgres psql -c "ALTER USER postgres PASSWORD 'newpassword';"

# 确保 pg_hba.conf 使用 md5 或 scram-sha-256 认证
sudo vi /etc/postgresql/16/main/pg_hba.conf
# 修改为：host all all 0.0.0.0/0 md5

# 重启服务
sudo systemctl restart postgresql
```

### 2.9.2 扩展安装问题

**问题：找不到 PostGIS 扩展**

```sql
-- 查看可用扩展
SELECT * FROM pg_available_extensions WHERE name LIKE 'postgis%';

-- 如果没有 PostGIS，需要安装
-- Ubuntu/Debian
sudo apt install postgresql-16-postgis-3

-- CentOS/RHEL
sudo dnf install postgis34_16

-- 安装扩展
CREATE EXTENSION postgis;
```

**问题：扩展版本冲突**

```sql
-- 查看已安装的扩展版本
SELECT * FROM pg_extension;

-- 更新扩展
ALTER EXTENSION postgis UPDATE;
ALTER EXTENSION postgis_topology UPDATE;

-- 查看 PostGIS 版本
SELECT PostGIS_Full_Version();
```

### 2.9.3 性能问题

**问题：空间查询慢**

```sql
-- 检查是否有空间索引
SELECT indexname, indexdef 
FROM pg_indexes 
WHERE tablename = 'my_table';

-- 创建空间索引
CREATE INDEX idx_geom ON my_table USING GIST (geom);

-- 更新表统计信息
ANALYZE my_table;

-- 使用 EXPLAIN ANALYZE 分析查询
EXPLAIN (ANALYZE, BUFFERS) 
SELECT * FROM my_table 
WHERE ST_Intersects(geom, ST_MakeEnvelope(116, 39, 117, 40, 4326));
```
