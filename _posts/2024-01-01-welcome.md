## 博客更新

博客系统已经完成全面升级，现在具备以下特色功能：

### ✨ 自动化功能

- **自动提取标题**: 无需手动配置 Front Matter，系统会自动从文档第一个 H1 标题提取页面标题

- **代码复制按钮**: 每个代码块都有一键复制功能
- **返回顶部**: 滚动时自动显示返回顶部按钮
- **外部链接**: 外部链接自动在新标签页打开
- **响应式设计**: 完美支持桌面和移动设备

### 🔍 SEO 优化

- 自动生成 sitemap.xml
- 自动生成 robots.txt
- RSS/Atom feed 支持
- SEO 元标签优化

### 📝 写作支持

- 支持 GitHub Flavored Markdown (GFM)
- 代码语法高亮
- 表格、任务列表、删除线等扩展语法
- 可选的 Front Matter

## 代码示例

博客支持完整的代码高亮功能，例如：

### Python 示例

```python
def calculate_distance(point1, point2):
    """计算两点之间的距离"""
    from math import sqrt
    
    dx = point2.x - point1.x
    dy = point2.y - point1.y
    
    return sqrt(dx**2 + dy**2)

# 使用示例
from shapely.geometry import Point

p1 = Point(0, 0)
p2 = Point(3, 4)

distance = calculate_distance(p1, p2)
print(f"距离: {distance}")  # 输出: 5.0
```

### C# 示例

```csharp
using System;
using NetTopologySuite.Geometries;

public class GisHelper
{
    public static double CalculateDistance(Point p1, Point p2)
    {
        double dx = p2.X - p1.X;
        double dy = p2.Y - p1.Y;
        
        return Math.Sqrt(dx * dx + dy * dy);
    }
}

// 使用示例
var point1 = new Point(0, 0);
var point2 = new Point(3, 4);

double distance = GisHelper.CalculateDistance(point1, point2);
Console.WriteLine($"距离: {distance}");  // 输出: 5
```

### SQL 示例

```sql
-- PostGIS 空间查询示例
SELECT 
    name,
    ST_AsText(geom) as geometry,
    ST_Area(geom) as area
FROM 
    parcels
WHERE 
    ST_Intersects(
        geom,
        ST_MakeEnvelope(120.0, 30.0, 121.0, 31.0, 4326)
    )
ORDER BY 
    area DESC
LIMIT 10;
```
