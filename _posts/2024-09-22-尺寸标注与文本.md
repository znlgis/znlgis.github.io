# 第九章：尺寸标注与文本

## 9.1 标注系统概述

### 9.1.1 标注的组成

CAD标注由以下元素组成：

```
                尺寸文字
                  ↓
         ┌───── 50.00 ─────┐
         │                 │
标注线 ──├─────────────────┤── 标注线
         │                 │
         ↑                 ↑
      箭头              箭头
         │                 │
      延伸线           延伸线
         │                 │
         ●                 ●
      起点              终点
```

**标注元素**：
- **尺寸文字**：显示测量值
- **标注线**：连接延伸线的水平/倾斜线
- **延伸线**：从被标注点引出的线
- **箭头**：标注线端点的符号
- **起点/终点**：被标注的位置

### 9.1.2 标注类型

| 类型 | 用途 | 示例 |
|------|------|------|
| 线性标注 | 测量水平/垂直距离 | 长度、宽度 |
| 对齐标注 | 测量两点间实际距离 | 斜边长度 |
| 角度标注 | 测量夹角 | 角度值 |
| 半径标注 | 标注圆/弧的半径 | R50 |
| 直径标注 | 标注圆的直径 | Ø100 |
| 弧长标注 | 测量圆弧长度 | 弧长值 |
| 坐标标注 | 标注点的坐标 | X/Y值 |

### 9.1.3 关联性标注

QCAD的标注是关联的：
- 修改被标注对象，标注自动更新
- 移动标注点，测量值自动重新计算
- 保持设计与文档的一致性

## 9.2 线性标注详解

### 9.2.1 水平标注

**功能**：标注两点间的水平距离

**操作步骤**：
1. 菜单"绘图" → "标注" → "水平"
2. 指定第一个延伸线起点
3. 指定第二个延伸线起点
4. 指定标注线位置

**命令行**：
```
命令: dimlinear
指定第一条延伸线起点: (点击或输入)
指定第二条延伸线起点: @100,50
指定标注线位置: (移动确定位置)
```

### 9.2.2 垂直标注

**功能**：标注两点间的垂直距离

**操作步骤**：
1. 菜单"绘图" → "标注" → "垂直"
2. 指定两个起点
3. 指定标注位置（在左侧或右侧）

### 9.2.3 对齐标注

**功能**：沿两点连线方向标注实际距离

**应用场景**：
- 斜边长度
- 倾斜构件尺寸
- 实际距离（非投影距离）

### 9.2.4 旋转标注

**功能**：按指定角度方向标注

**操作步骤**：
1. 选择旋转标注
2. 输入标注线角度
3. 指定标注点
4. 完成标注

### 9.2.5 基线标注

**功能**：从同一基准点创建多个标注

**操作步骤**：
1. 首先创建基准标注
2. 执行"基线"命令
3. 连续指定新的测量点
4. 自动从基准点测量

**示例**：
```
    ├──── 20 ────┤
    ├───────── 50 ─────────┤
    ├────────────── 80 ──────────────┤
基准点                              终点
```

### 9.2.6 连续标注

**功能**：端点相连的连续标注

**操作步骤**：
1. 首先创建第一个标注
2. 执行"连续"命令
3. 连续指定新的测量点
4. 自动从上一终点开始

**示例**：
```
    ├── 20 ──┼── 30 ──┼── 25 ──┤
```

## 9.3 角度与弧度标注

### 9.3.1 角度标注

**方法1：两条线定义角度**
1. 选择第一条线
2. 选择第二条线
3. 指定标注弧位置

**方法2：三点定义角度**
1. 指定角度顶点
2. 指定第一边上的点
3. 指定第二边上的点
4. 指定标注位置

### 9.3.2 弧长标注

**功能**：标注圆弧的弧长

**操作步骤**：
1. 选择圆弧
2. 指定标注位置
3. 显示带弧长符号的值

**符号**：弧长标注通常带有圆弧符号"⌒"

### 9.3.3 弧度标注选项

- 角度单位：度、弧度
- 精度设置
- 文字位置调整

## 9.4 径向标注

### 9.4.1 半径标注

**功能**：标注圆或圆弧的半径

**操作步骤**：
1. 菜单"绘图" → "标注" → "半径"
2. 选择圆或圆弧
3. 指定标注线位置

**显示格式**：R + 数值（如 R50）

**选项**：
- 文字位置：内部/外部
- 引线样式
- 中心标记

### 9.4.2 直径标注

**功能**：标注圆的直径

**操作步骤**：
1. 选择"直径标注"
2. 选择圆
3. 指定标注位置

**显示格式**：Ø + 数值（如 Ø100）

### 9.4.3 中心标记

**功能**：为圆添加中心标记

**样式**：
- 十字标记
- 中心线
- 无标记

## 9.5 坐标标注

### 9.5.1 坐标标注基础

**功能**：标注点的X或Y坐标值

**类型**：
- X坐标标注：显示点的X值
- Y坐标标注：显示点的Y值

### 9.5.2 操作步骤

1. 选择"坐标标注"工具
2. 指定要标注的点
3. 移动鼠标确定引出方向
4. 自动显示坐标值

### 9.5.3 应用场景

- 加工图中的孔位标注
- 零件的关键点定位
- 建筑图中的定位标注

## 9.6 引线标注

### 9.6.1 引线创建

**功能**：创建带引线的注释

**操作步骤**：
1. 指定引线起点（箭头位置）
2. 指定引线转折点（可选）
3. 指定引线终点
4. 输入注释文字

### 9.6.2 引线选项

| 选项 | 说明 |
|------|------|
| 箭头样式 | 实心箭头、空心箭头、点等 |
| 引线类型 | 直线、样条曲线 |
| 着落线 | 文字下方的横线 |
| 文字对齐 | 左、中、右对齐 |

### 9.6.3 多重引线

**功能**：多个箭头共用一个注释

**应用**：
- 相同说明的多个位置
- 零件标注
- 注释标注

## 9.7 标注样式

### 9.7.1 创建标注样式

**步骤**：
1. 菜单"格式" → "标注样式"
2. 点击"新建"
3. 输入样式名称
4. 设置各项参数
5. 保存样式

### 9.7.2 线条设置

| 参数 | 说明 |
|------|------|
| 颜色 | 标注线和延伸线颜色 |
| 线型 | 标注线和延伸线线型 |
| 线宽 | 标注线和延伸线线宽 |
| 延伸线偏移 | 延伸线起点与对象的间距 |
| 延伸线超出 | 延伸线超过标注线的长度 |

### 9.7.3 箭头设置

**箭头类型**：
- 实心闭合箭头
- 空心闭合箭头
- 斜线
- 建筑标记
- 圆点
- 无箭头

**箭头大小**：设置箭头尺寸

### 9.7.4 文字设置

| 参数 | 说明 |
|------|------|
| 字体 | 标注文字字体 |
| 高度 | 文字高度 |
| 颜色 | 文字颜色 |
| 位置 | 文字相对于标注线位置 |
| 对齐 | 文字与标注线对齐方式 |
| 偏移 | 文字与标注线的间距 |

### 9.7.5 主单位设置

| 参数 | 说明 |
|------|------|
| 单位格式 | 十进制、分数、科学计数等 |
| 精度 | 小数位数 |
| 前缀 | 数值前添加文字（如"约"） |
| 后缀 | 数值后添加文字（如"mm"） |
| 比例因子 | 测量值的缩放系数 |
| 舍入 | 舍入精度 |

### 9.7.6 公差设置

**功能**：显示尺寸公差

**公差格式**：
- 对称公差：±0.05
- 极限公差：+0.05/-0.02
- 极限尺寸：50.05/49.98

**设置**：
- 上偏差
- 下偏差
- 公差文字高度比例
- 对齐方式

## 9.8 文本详解

### 9.8.1 单行文本创建

**操作步骤**：
1. 菜单"绘图" → "文本" → "单行文本"
2. 指定插入点
3. 设置文本参数
4. 输入文本内容
5. 确认创建

**参数设置**：
- 高度：文本高度
- 旋转：文本角度
- 样式：文本样式
- 对齐：对齐方式

### 9.8.2 多行文本创建

**操作步骤**：
1. 选择"多行文本"工具
2. 指定文本框的两个对角点
3. 在编辑器中输入和格式化
4. 确认创建

**格式化选项**：
- 字体和字号
- 粗体、斜体、下划线
- 颜色
- 段落对齐
- 行间距
- 项目符号和编号

### 9.8.3 文本样式

**创建样式**：
1. 菜单"格式" → "文本样式"
2. 新建样式
3. 设置字体、高度等参数
4. 保存样式

**样式参数**：
| 参数 | 说明 |
|------|------|
| 样式名 | 样式的唯一标识 |
| 字体 | 字体文件 |
| 高度 | 默认文字高度 |
| 宽度因子 | 字符宽度比例 |
| 倾斜角 | 字符倾斜角度 |

### 9.8.4 特殊字符

| 代码 | 字符 | 说明 |
|------|------|------|
| %%d | ° | 度数符号 |
| %%p | ± | 正负号 |
| %%c | Ø | 直径符号 |
| %%% | % | 百分号 |
| \U+xxxx | Unicode | Unicode字符 |

### 9.8.5 文本编辑

**编辑方法**：
1. 双击文本进入编辑
2. 修改内容
3. 按Enter确认或Esc取消

**批量修改**：
1. 选择多个文本
2. 在属性面板修改共同属性
3. 统一应用更改

### 9.8.6 查找和替换

**功能**：在文档中查找和替换文本

**操作**：
1. 菜单"编辑" → "查找和替换"
2. 输入查找内容
3. 输入替换内容
4. 执行替换（单个/全部）

## 9.9 标注实践技巧

### 9.9.1 标注规范

**工程图标注原则**：
1. 标注应清晰、完整、不重复
2. 重要尺寸直接标注
3. 功能尺寸优先
4. 避免封闭尺寸链
5. 合理布置标注位置

### 9.9.2 标注布局

**布局建议**：
- 标注放在图形外部
- 相关标注对齐
- 避免标注交叉
- 留出足够间距
- 分层组织标注

### 9.9.3 常见错误

| 错误类型 | 解决方法 |
|----------|----------|
| 标注重叠 | 调整标注位置 |
| 遗漏标注 | 检查所有尺寸 |
| 重复标注 | 删除冗余标注 |
| 精度不一致 | 统一标注样式 |
| 封闭尺寸链 | 删除一个标注 |

### 9.9.4 快速标注

**快速标注命令**：
- 自动识别并标注选定对象
- 一次创建多个标注
- 提高标注效率
