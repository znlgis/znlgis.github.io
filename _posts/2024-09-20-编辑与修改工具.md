# 第七章：编辑与修改工具

## 7.1 选择操作

### 7.1.1 基本选择方法

**单击选择**：
- 直接点击对象选中
- 按住Ctrl点击添加/移除选择

**框选（窗口选择）**：
- 从左向右拖动
- 完全在框内的对象被选中
- 显示实线选择框

**交叉选择**：
- 从右向左拖动
- 框内和相交的对象都被选中
- 显示虚线选择框

**多边形选择**：
- 使用任意多边形区域选择
- 菜单："选择" → "多边形窗口选择"

### 7.1.2 选择过滤

**按属性选择**：

| 过滤条件 | 说明 |
|----------|------|
| 图层 | 选择特定图层的对象 |
| 颜色 | 选择特定颜色的对象 |
| 线型 | 选择特定线型的对象 |
| 类型 | 选择特定类型（直线、圆等） |

**使用选择过滤器**：
1. 菜单"选择" → "选择过滤器"
2. 设置过滤条件
3. 应用过滤选择

### 7.1.3 快速选择

**全选**：Ctrl+A 或 菜单"选择" → "全选"

**取消全部选择**：Escape 或 菜单"选择" → "取消选择"

**反选**：选择未选中的对象，取消已选中的

**选择相同类型**：
1. 选择一个参考对象
2. "选择" → "选择相同类型"

### 7.1.4 选择集操作

**添加到选择**：按住Shift点击

**从选择中移除**：按住Ctrl点击

**切换选择**：再次点击已选对象

## 7.2 基本编辑操作

### 7.2.1 删除（Erase）

**快捷键**：Delete 或 E

**操作步骤**：
1. 选择要删除的对象
2. 按Delete键或执行删除命令
3. 对象被移除

**批量删除**：
- 先选择多个对象
- 一次删除所有选中对象

### 7.2.2 撤销/重做

**撤销（Undo）**：
- 快捷键：Ctrl+Z
- 撤销上一步操作
- 可连续撤销多步

**重做（Redo）**：
- 快捷键：Ctrl+Y
- 恢复已撤销的操作

**撤销历史**：
- 查看操作历史
- 跳转到特定步骤

### 7.2.3 复制/剪切/粘贴

**复制到剪贴板**：
- 快捷键：Ctrl+C
- 选择对象后复制
- 可粘贴到其他文档

**剪切**：
- 快捷键：Ctrl+X
- 复制并删除原对象

**粘贴**：
- 快捷键：Ctrl+V
- 指定粘贴位置

**带基点复制**：
- Ctrl+Shift+C
- 指定复制基点
- 精确控制粘贴位置

## 7.3 变换操作

### 7.3.1 移动（Move）

**菜单路径**：修改 → 移动

**操作步骤**：
1. 选择要移动的对象
2. 执行移动命令（M）
3. 指定基点
4. 指定目标点

**命令行示例**：
```
命令: move
选择对象: (选择对象)
选择对象: Enter
指定基点: 0,0
指定第二点: 100,50
```

**选项**：
- **复制模式**：移动并复制
- **位移输入**：直接输入位移量

### 7.3.2 复制（Copy）

**菜单路径**：修改 → 复制

**操作步骤**：
1. 选择对象
2. 执行复制命令（CO或CP）
3. 指定基点
4. 指定目标点
5. 可继续指定更多目标点

**多重复制**：
- 指定一个基点
- 连续指定多个目标点
- 创建多个副本

### 7.3.3 旋转（Rotate）

**菜单路径**：修改 → 旋转

**操作步骤**：
1. 选择对象
2. 执行旋转命令（RO）
3. 指定旋转中心
4. 指定旋转角度

**角度指定方式**：
- 直接输入角度值
- 通过两点指定参考角度
- 使用参考角度+新角度

**命令行示例**：
```
命令: rotate
选择对象: (选择)
指定基点: 100,100
指定旋转角度或 [复制(C)/参照(R)]: 45
```

### 7.3.4 缩放（Scale）

**菜单路径**：修改 → 缩放

**操作步骤**：
1. 选择对象
2. 执行缩放命令（SC）
3. 指定基点
4. 指定缩放比例

**缩放比例**：
- 大于1：放大
- 小于1：缩小
- 等于1：不变

**参照缩放**：
1. 选择参照长度
2. 指定新长度
3. 自动计算比例

### 7.3.5 镜像（Mirror）

**菜单路径**：修改 → 镜像

**操作步骤**：
1. 选择对象
2. 执行镜像命令（MI）
3. 指定镜像线的第一点
4. 指定镜像线的第二点
5. 选择是否保留原对象

**镜像文字**：
- 可选择是否镜像文字内容
- 通常保持文字正向

### 7.3.6 拉伸（Stretch）

**菜单路径**：修改 → 拉伸

**功能**：选择性地移动部分对象

**操作步骤**：
1. 使用交叉选择框选
2. 框内的点被移动
3. 与框相交的对象被拉伸
4. 指定基点和位移

**应用**：
- 调整图形尺寸
- 修改形状而保持连接关系

## 7.4 修剪与延伸

### 7.4.1 修剪（Trim）

**菜单路径**：修改 → 修剪

**功能**：以边界线为界修剪对象

**操作步骤**：
1. 执行修剪命令（TR）
2. 选择边界对象（或Enter选择全部为边界）
3. 点击要修剪掉的部分

**选项**：
- **投影**：是否考虑投影相交
- **边**：延伸边界或实际边界
- **删除**：直接删除选中段

**快速修剪**：
- 直接Enter跳过边界选择
- 所有对象都作为边界
- 点击要删除的部分

### 7.4.2 延伸（Extend）

**菜单路径**：修改 → 延伸

**功能**：将对象延伸到边界

**操作步骤**：
1. 执行延伸命令（EX）
2. 选择边界对象
3. 点击要延伸的对象（靠近延伸端）

**可延伸对象**：
- 直线
- 圆弧
- 多段线
- 样条曲线

### 7.4.3 打断（Break）

**菜单路径**：修改 → 打断

**功能**：将对象在指定点处断开

**打断类型**：

**两点打断**：
1. 选择对象
2. 指定第一个断点
3. 指定第二个断点
4. 两点之间部分被删除

**单点打断**：
1. 选择对象和断点
2. 在该点处将对象分成两段

**在交点处打断**：
- 自动在与其他对象的交点处打断

### 7.4.4 合并（Join）

**功能**：将分离的对象合并为一个

**可合并类型**：
- 共线的直线
- 圆弧合并为圆或更大的弧
- 多段线段

**操作步骤**：
1. 选择第一个对象
2. 选择要合并的其他对象
3. 自动合并为单一对象

## 7.5 倒角与圆角

### 7.5.1 倒角（Chamfer）

**菜单路径**：修改 → 倒角

**功能**：在两条线的交角处创建斜切

**参数设置**：
- **距离1**：第一条边上的倒角距离
- **距离2**：第二条边上的倒角距离
- **角度**：倒角角度（代替距离2）

**操作步骤**：
1. 执行倒角命令（CHA）
2. 设置倒角参数
3. 选择第一条线
4. 选择第二条线

**命令行示例**：
```
命令: chamfer
当前倒角距离1 = 10, 距离2 = 10
选择第一条线或 [距离(D)/角度(A)/修剪(T)]: D
指定第一个倒角距离: 15
指定第二个倒角距离: 15
选择第一条线: (选择)
选择第二条线: (选择)
```

### 7.5.2 圆角（Fillet）

**菜单路径**：修改 → 圆角

**功能**：在两条线之间创建圆弧连接

**参数设置**：
- **半径**：圆角半径

**操作步骤**：
1. 执行圆角命令（F）
2. 设置圆角半径
3. 选择第一条线
4. 选择第二条线

**特殊用法**：
- **半径为0**：创建精确的角点
- **多段线圆角**：一次为整个多段线添加圆角

### 7.5.3 倒角/圆角选项

**修剪模式**：
- **修剪**：修剪到倒角/圆角
- **不修剪**：保留原有线段

**多重模式**：
- 连续应用到多组对象
- 无需重复执行命令

## 7.6 偏移与阵列

### 7.6.1 偏移（Offset）

**菜单路径**：修改 → 偏移

**功能**：创建等距平行副本

**操作步骤**：
1. 执行偏移命令（O）
2. 指定偏移距离
3. 选择要偏移的对象
4. 指定偏移方向

**可偏移对象**：
- 直线
- 圆弧
- 圆（创建同心圆）
- 多段线
- 样条曲线

**通过点偏移**：
- 选择"通过"选项
- 指定偏移副本要通过的点

### 7.6.2 矩形阵列

**菜单路径**：修改 → 阵列 → 矩形阵列

**功能**：按行列方式复制对象

**参数**：
- **行数**：阵列行数
- **列数**：阵列列数
- **行间距**：行之间的距离
- **列间距**：列之间的距离

**操作步骤**：
1. 选择对象
2. 执行矩形阵列命令
3. 设置行列数和间距
4. 预览并确认

### 7.6.3 环形阵列

**菜单路径**：修改 → 阵列 → 环形阵列

**功能**：围绕中心点复制对象

**参数**：
- **中心点**：阵列旋转中心
- **项目数**：副本总数
- **填充角度**：分布的总角度
- **旋转对象**：是否旋转各副本

**操作步骤**：
1. 选择对象
2. 指定阵列中心
3. 设置项目数和角度
4. 预览并确认

### 7.6.4 路径阵列

**功能**：沿路径分布对象

**参数**：
- **路径**：阵列路径（线、弧、多段线等）
- **项目数**：副本数量
- **间距**：相邻副本间距
- **对齐**：是否沿路径方向对齐

## 7.7 特殊修改

### 7.7.1 分解（Explode）

**功能**：将复合对象分解为基本元素

**可分解对象**：
- 块参照 → 独立对象
- 多段线 → 单独的线段和弧
- 标注 → 线、文字、箭头
- 填充 → 边界和图案线

**操作步骤**：
1. 选择要分解的对象
2. 执行分解命令（X）
3. 对象被分解为组成元素

### 7.7.2 对齐（Align）

**功能**：通过指定点对对齐和缩放对象

**操作步骤**：
1. 选择对象
2. 指定源点1和目标点1
3. 指定源点2和目标点2（可选）
4. 指定源点3和目标点3（可选）
5. 选择是否缩放

**对齐方式**：
- 1对点：仅移动
- 2对点：移动和旋转（可选缩放）
- 3对点：完全变换（3D）

### 7.7.3 匹配属性

**功能**：将属性从一个对象复制到其他对象

**可匹配属性**：
- 图层
- 颜色
- 线型
- 线宽
- 样式

**操作步骤**：
1. 执行匹配属性命令
2. 选择源对象
3. 选择目标对象
4. 属性被复制

### 7.7.4 修改属性

**批量修改属性**：
1. 选择多个对象
2. 在属性面板中修改
3. 所有选中对象同时更新

**快速属性面板**：
- 双击对象打开属性
- 修改特定属性值

## 7.8 夹点编辑

### 7.8.1 夹点基础

选中对象时显示的蓝色小方块称为夹点：

**夹点类型**：
- **端点夹点**：线段端点
- **中点夹点**：线段中点
- **圆心夹点**：圆/弧的圆心
- **象限夹点**：圆的象限点
- **控制点**：样条曲线控制点

### 7.8.2 夹点操作

**拉伸**（默认）：
- 点击夹点
- 拖动到新位置
- 修改对象形状

**移动**：
- 选择夹点后按空格
- 切换到移动模式
- 移动整个对象

**旋转**：
- 选择夹点后按两次空格
- 以夹点为中心旋转

**缩放**：
- 选择夹点后按三次空格
- 以夹点为基点缩放

**镜像**：
- 选择夹点后按四次空格
- 以夹点位置创建镜像

### 7.8.3 多功能夹点

某些对象有特殊功能夹点：

**多段线**：
- 顶点夹点：移动顶点
- 中点夹点：添加新顶点

**圆弧**：
- 端点夹点：调整端点
- 中点夹点：调整半径

**标注**：
- 调整标注位置
- 修改标注点

## 7.9 本章小结

本章详细介绍了QCAD的编辑与修改工具：

1. **选择操作**：
   - 多种选择方式
   - 选择过滤
   - 选择集管理

2. **基本编辑**：
   - 删除、撤销/重做
   - 剪切/复制/粘贴

3. **变换操作**：
   - 移动、复制、旋转
   - 缩放、镜像、拉伸

4. **修剪与延伸**：
   - 修剪、延伸
   - 打断、合并

5. **倒角与圆角**：
   - 倒角处理
   - 圆角处理

6. **偏移与阵列**：
   - 偏移复制
   - 矩形/环形/路径阵列

7. **特殊修改**：
   - 分解、对齐
   - 属性匹配

8. **夹点编辑**：
   - 直接图形编辑
   - 多模式切换

熟练掌握这些工具将大大提高绘图效率。
